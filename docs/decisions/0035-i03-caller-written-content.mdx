# 0035. 호출자가 쓴 글이나 질의를 그대로 보내는 경로는 I03 상세에 연결하지 않습니다

- 날짜: 2026-10-06
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

trudi I03 원고는 `dair.assess`가 모델이 쓴 결과 요약을, `velo.query`가 모델이 쓴 VQL을 그대로 보내는 경로를 I03.02 「증거에서 뽑은 값만 전송」의 구현 단락에 적었습니다.
모델이 쓴 자유 글이나 질의는 증거에서 뽑은 값이 아니며 I03 not_implemented가 묘사한 "무엇을 보낼지 코드가 정하지 않아 호출이 넘긴 자료를 그대로 보내는 경우"와 같은 동작입니다.
I03 scope에는 이런 경로를 어디에 쓸지 정한 문장이 없어 원고마다 판단이 갈릴 수 있었습니다.

## 결정

- I03 scope에 "호출자가 쓴 글이나 질의를 그대로 보내는 경로는 상세에 연결하지 않고 원고의 구현 단락에 씁니다. 서버의 외부 전송이 이 경로뿐이면 미구현입니다."를 더합니다.
- R02.08 exclude를 "보관한 출력 전체를 끝까지 읽는 방식은 R02.04에서 봅니다. 같은 도구가 두 방식을 모두 지원하면 함께 연결합니다."로 고칩니다. 상세 단위 변경이라 기록만 남깁니다.

## 영향

- trudi I03.02의 두 문장을 구현 단락의 사실로 고치고 I03.04 한계 단락에 모델이 옮겨 적은 도구 출력은 행 선택과 분량 한도 없이 백엔드로 나간다는 사실을 더합니다.
- mcp_dfir `get_command_result`를 R02.08에도 연결합니다.
