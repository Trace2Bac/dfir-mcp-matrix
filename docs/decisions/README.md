# 결정 기록 (ADR)

매트릭스 구조(축·셀·상세·번호·원고 형식)를 바꾼 결정을 **결정 하나에 파일 하나**로 남긴다.
첫 공개 버전부터 쓴다. 그 전의 논의는 git 이력에 있다(아래).

## 언제 쓰나

- 셀을 더하거나 나누거나 합치거나 번호를 바꿀 때.
- 셀의 범위(`scope`·미구현·비적용)나 판단 기준(†)을 바꿀 때.
- 원고 형식이나 도구가 검사하는 규칙을 바꿀 때.

상세 항목의 이름 변경·추가·합치기·지우기는 조사하며 자주 일어나므로 결정이 아니다. 셀 파일의 `retired`와 커밋 메시지로 남긴다. 문구를 다듬거나 오타를 고치는 것도 결정이 아니다.

## 쓰는 법

1. [`template.md`](template.md)를 복사해 `NNNN-short-english-title.md`로 만든다.
   - `NNNN`은 0001부터 이어지는 네 자리 번호다. 지우거나 다시 매기지 않는다.
   - 제목은 영어 소문자와 하이픈으로 쓴다(예: `0001-split-r03-status-and-limits.md`).
2. 본문은 템플릿의 항목을 채운다. 본문은 한국어로 써도 된다.
3. 앞 결정을 바꾸면 새 결정을 더하고 `상태`에 대체 관계를 적는다(앞 결정 파일의 상태도 `대체됨(NNNN)`으로 고친다).
4. 아래 목록에 한 줄을 더한다.

결정 본문의 셀 번호는 그 결정을 내린 때의 번호다. 뒤에 번호가 바뀌어도 고치지 않는다.
