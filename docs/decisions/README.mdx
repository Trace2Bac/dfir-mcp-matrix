# 결정 기록 (ADR)

결정 기록은 매트릭스의 바탕이 되는 결정과 그렇게 정한 이유를 남기는 문서입니다. 결정 하나마다 파일을 하나씩 만듭니다.
규칙 자체는 [CONTRIBUTING.md](https://github.com/Trace2Bac/dfir-mcp-matrix/blob/main/CONTRIBUTING.md)와 [원고 안내](https://github.com/Trace2Bac/dfir-mcp-matrix/blob/main/reports/README.mdx)에 있습니다. 결정 기록은 그 규칙을 왜 그렇게 정했는지 알고 싶을 때 봅니다.

## 언제 쓰나요?

다음과 같은 변경을 할 때 결정 기록을 씁니다.

- 축이나 셀을 더하거나 나누거나 합칠 때
- 여러 셀에 걸친 판정 원칙이나 원고 형식을 바꿀 때

다음 변경에는 결정 기록을 쓰지 않고 커밋 메시지에 무엇을 왜 바꿨는지 남깁니다.

- **셀 하나의 문구 수정**: 확인 사항, 확인 범위, 미구현·비적용의 뜻, 다른 셀과 차이점을 고치는 일
- **상세 항목의 변경**: 상세를 더하거나 합치거나 지우거나 이름을 바꾸는 일
- **문구 다듬기나 오타 수정**
- **작성 규칙의 변경**: 낱말과 문장 규칙은 [작성 규칙](../writing-rules/README.mdx)에서 규칙 파일로 따로 관리합니다.

다른 문서에는 결정 번호를 참조로 달지 않습니다. 결정 기록을 합치거나 다시 정리해도 다른 문서를 고치지 않게 하기 위해서입니다.

## 쓰는 법

1. [`template.mdx`](https://github.com/Trace2Bac/dfir-mcp-matrix/blob/main/docs/decisions/template.mdx)를 복사해 `NNNN-short-english-title.mdx`로 만듭니다.
   - `NNNN`은 목록의 마지막 번호 다음 번호입니다.
   - 파일 이름의 제목 부분은 영어 소문자와 하이픈으로 씁니다.
2. 무엇을 정했고 왜 그렇게 정했는지 씁니다. 작업 내역(고친 파일, 옮긴 문장 수)은 커밋 메시지에 남기고 결정 기록에는 쓰지 않습니다.
3. 앞 결정을 바꾸는 경우에는 앞 결정을 고쳐 쓰거나 새 결정을 더하고, 앞 결정의 상태를 `대체됨(NNNN)`으로 고칩니다.
4. 아래 [목록](#목록)에 한 줄을 더합니다.

## 정리 기록

2026-10-08에 그때까지의 결정 기록 48개를 위 다섯 개로 정리했습니다.

- 셀 하나의 문구를 고친 결정, 다른 결정으로 대체된 결정, 작업 내역은 지웠습니다. 남은 원칙은 주제별로 합쳐 다시 썼습니다.
- 지운 결정에만 있던 원고 작성 지침은 원고 안내의 「셀별로 원고에 적을 것」으로 옮겼습니다.
- 옛 결정 기록은 git 태그 `decisions-archive`에서 볼 수 있습니다.
