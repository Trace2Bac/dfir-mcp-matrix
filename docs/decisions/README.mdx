# 결정 기록 (ADR)

결정 기록(ADR)은 매트릭스의 구조를 바꾼 결정을 남기는 문서입니다. 결정 하나마다 파일을 하나씩 만듭니다.
여기서 구조란 축, 셀, 상세, 번호, 원고 형식을 말합니다.

결정 기록은 첫 공개 버전부터 씁니다. 그 전의 논의는 git 이력에 있습니다(아래 [첫 버전 전의 결정](#첫-버전-전의-결정) 참고).

## 언제 쓰나요?

다음과 같은 변경을 할 때 결정 기록을 씁니다.

- 셀을 더하거나 나누거나 합치거나 번호를 바꿀 때
- 셀의 범위(`scope`·미구현·비적용)나 판단 기준(†)을 바꿀 때
- 원고 형식이나 도구가 검사하는 규칙을 바꿀 때

다음 변경에는 결정 기록을 쓰지 않습니다.

- **상세 항목의 변경**: 상세의 이름을 바꾸거나, 상세를 더하거나 합치거나 지우는 일은 서버를 조사하면서 자주 일어납니다. 그래서 결정으로 보지 않고, 셀 파일의 `retired`와 커밋 메시지로 남깁니다.
- **문구 다듬기나 오타 수정**

## 쓰는 법

1. [`template.mdx`](template.mdx)를 복사해 `NNNN-short-english-title.mdx`로 만듭니다.
   - `NNNN`은 0001부터 이어지는 네 자리 번호입니다. 한 번 쓴 번호는 지우거나 다시 매기지 않습니다.
   - 파일 이름의 제목 부분은 영어 소문자와 하이픈으로 씁니다(예: `0001-split-r03-status-and-limits.md`).
2. 템플릿의 항목을 채워 본문을 씁니다. 본문은 한국어로 써도 됩니다.
3. 앞 결정을 바꾸는 경우에는 새 결정을 더합니다.
   - 새 결정의 `상태`에 어느 결정을 대체하는지 적습니다.
   - 앞 결정 파일의 상태도 `대체됨(NNNN)`으로 고칩니다.
4. 아래 [목록](#목록)에 한 줄을 더합니다.

주의: 결정 본문의 셀 번호는 그 결정을 내린 시점의 번호입니다. 나중에 셀 번호가 바뀌어도 결정 본문은 고치지 않습니다.

## 첫 버전 전의 결정

첫 공개 버전 전인 2026-09-30~10-01에 내린 결정 41개는 [`0000-pre-release-decisions.mdx`](0000-pre-release-decisions.mdx) 한 파일에 모아 두었습니다. 이 결정들은 원래 개편안 12절에 있었습니다.

- 1~40번은 커밋 `3582336`의 개편안 12절을 그대로 옮겼습니다.
- 41번(셀 6개 분할)은 원문이 커밋되지 않았습니다. 그래서 셀 구성을 비교해 다시 적었습니다.

다른 문서나 셀 정의에서 "12절 N번"이라고 쓴 것은 이 파일의 N번 결정을 가리킵니다.
