# 0030. D02 이름을 "파생물 추적"으로 바꿉니다

- 날짜: 2026-10-05
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

D02의 이름 "파생물 계보"는 데이터 계보(lineage)를 옮긴 말이라, 이름만으로는 이 셀이 무엇을 묻는지 바로 읽히지 않았습니다.
같은 셀의 question과 정의에 쓰던 "소비한 입력"(consumed input의 직역)도 어색하다는 지적이 있어 "사용한 입력"으로 함께 고쳤습니다.
D02가 실제로 묻는 것은 파생물이 어떤 입력과 어떤 실행에서 만들어졌는지 되짚을 수 있게 이어 두는가입니다.

이름을 고를 때 다른 셀이 다른 뜻으로 쓰는 말은 피했습니다.
"출처"는 R05, "근거"는 D05·D07, "기록"과 "이력"은 L축이 쓰고 있습니다.

## 결정

- D02의 이름을 "파생물 계보"에서 "파생물 추적"으로 바꿉니다. 셀 번호, question, 적용 범위, 판정 기준은 바꾸지 않습니다.
- 다른 셀 정의와 용어 사전에서 D02를 "계보"로 가리키던 문장을 "추적"으로 맞춥니다(D05.03, D06.05, L02.08, L02.10, 용어 사전의 「비적용」 예).
- 상세 이름도 새 셀 이름에 맞춰 다듬습니다. 상세 단위 변경이므로 여기에는 기록만 남깁니다.

| 상세 | 옛 이름 | 새 이름 |
|---|---|---|
| D02.01 | 증거·호출·파생물 ID 참조 | ID·경로 참조 |
| D02.04 | 양방향 조회 | 양방향 추적 조회 |
| D02.05 | 중간 입력 버전·부모 관계 | 여러 단계 파생 관계 기록 |

## 영향

- 서버 연결과 예외 표시는 바뀌지 않습니다.
- 원고의 D02 제목과 상세 소제목, trudi L02의 D02 참조 문장을 고쳤습니다.
- T08의 상세 「수집 작업의 시작·종료·취소 상태 추적」은 작업 상태를 쫓는다는 뜻으로 "추적"을 씁니다. D02의 추적은 파생물이 만들어진 입력과 실행을 되짚는다는 뜻이며, 두 쓰임은 셀의 question으로 구별합니다.
