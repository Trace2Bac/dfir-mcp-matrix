# 0005. 구현 사례가 없는 상세는 번호 없이 후보 파일에 둡니다

- 날짜: 2026-10-08(2026-10-06·10-08의 결정을 정리)
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

셀 정의에 있을 법한 방식을 미리 상세로 늘어놓아, 구현 사례가 없는 상세가 화면에 섞여 보였습니다.
이런 상세를 후보 파일로 옮긴 뒤에도 후보에 번호가 있어 정식 상세처럼 보였고, 셀 정의와 원고가 후보를 번호로 가리켰습니다.

## 결정

- 상세는 구현 사례(원고 연결이나 `seen_in`)가 있을 때만 셀 정의에 둡니다. 사례가 없는 방식은 `matrix/candidates.yaml`에 셀별로 `name`·`include`·`exclude`만 적습니다.
- 후보에는 번호를 두지 않습니다. 사례가 나오면 셀 정의로 옮기면서 새 상세처럼 번호를 붙입니다. 예전에 상세였던 후보도 새 번호를 받습니다.
- 후보는 화면에 보이지 않고 원고에서 가리킬 수 없습니다.
- 셀 정의에 사례가 없는 상세가 생기면 `validate`가 알리고, 후보에 번호가 있으면 오류로 알립니다.

## 영향

- 화면에는 실제 서버에서 확인한 방식만 보입니다.
- 후보를 지우거나 옮겨도 셀 정의와 원고를 고칠 일이 없습니다.
