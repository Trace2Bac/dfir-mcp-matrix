# 0026. 지운 상세를 셀 파일의 `retired`에 남기지 않습니다

- 날짜: 2026-10-04
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

셀 파일은 지운 상세를 `retired`에 남겼습니다. 항목마다 번호, 이름, 지운 이유(`reason`), 합친 곳(`merged_into`)을 적었습니다.
`validate`는 이 목록으로 지운 번호를 다시 쓰는지와 원고가 지운 상세를 쓰는지 검사했습니다.

- 지운 상세 32개 가운데 22개는 이유에 결정 기록 번호가 있어 결정 기록에서도 찾을 수 있었습니다.
- 셀 파일마다 지운 상세 목록을 관리하는 일이 조사에 비해 번거로웠습니다.

## 결정

- 셀 파일에서 `retired`를 없앱니다. 셀 스키마와 `validate`의 관련 검사도 없앱니다.
- 상세를 지우거나 합치면 `details`에서 빼고, 이유와 합친 곳은 커밋 메시지에 적습니다. 셀 범위를 바꾸는 변경이면 지금처럼 결정 기록을 씁니다.
- 지운 번호를 다시 쓰는지는 규칙으로 두지 않고 검사하지도 않습니다. 첫 버전을 내기 전이라 상세 번호는 아직 다시 정리할 수 있습니다.
- 원고가 지운 상세를 쓰면 `validate`는 "정의에 없는 상세"로 알립니다.
