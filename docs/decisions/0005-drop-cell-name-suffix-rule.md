# 0005. 셀 이름 끝의 "방식"을 막는 검사를 없애고 L01을 "기록 방식"으로 한다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

첫 버전 전 결정 40번은 모든 셀이 그 일을 어떤 방식으로 하는지 묻는다는 이유로 셀 이름 끝의 "방식"을 뗐고, 스키마가 " 방식"으로 끝나는 이름을 오류로 막았다.
0004에서 L01을 "기록 방식"으로 정했지만 이 검사에 걸려 "기록 경로"로 올렸다.
L01·L02는 "기록 방식 / 기록 구성"처럼 짝을 이룰 때 뜻이 가장 잘 드러난다.

## 결정

- 스키마의 셀 이름 검사(" 방식"으로 끝나면 오류)를 없앤다. 셀 이름은 묻는 일을 명사로 쓴다는 원칙만 남긴다.
- L01 이름을 "기록 방식"으로 바꾼다. 0004의 L01 이름을 대체한다.
- 다른 셀 이름은 그대로 둔다.
