# 0029. L축은 MCP 도구 호출의 서버 기록을 보고, 클라이언트 기록은 L01.10에서만 봅니다

- 날짜: 2026-10-05
- 상태: 채택(0028의 L01 범위 일부 대체, 0004의 L02 범위 보완, L01.10 범위는 0032로 보완)
- 결정한 사람: 결정권자(팀)

## 배경

결정 0028은 같은 저장소의 클라이언트 코드가 남기는 기록을 L01에 포함했습니다.
그 결과 클라이언트 자체 도구, 모델 호출, 사용자 입력의 기록도 MCP 서버 호출 기록과 같은 상세에 연결되었습니다.
L02도 요청·명령·상태와 출력 보관을 구별하기 어려웠고, 요청과 실행의 연결은 내용 상세와 호출 ID 상세를 조합해 표현할 수 있었습니다.

## 결정

L축은 MCP 도구 호출과 그 실행의 이력을 기록하고 지키는지를 봅니다.
분석 내용의 보관·관리·검증은 D축에서 봅니다.
출력이 기록 항목에 함께 담겨 있어도 각 축은 자기 역할로 평가합니다.

L01.10은 같은 저장소의 클라이언트가 MCP 도구 호출을 식별할 수 있는 기록을 서버 기록과 별도로 남기는 방식으로 좁힙니다.
요청·응답의 완전성은 연결 조건이 아닙니다.
클라이언트 자체 도구, 클라이언트 모델 호출, 사용자 입력만 남기는 기록은 연결 근거가 아니며 관련 원고에 사실로 씁니다.
클라이언트 기록의 품질은 서버 기록을 보는 L02~L04에서 평가하지 않습니다.

L02는 MCP 도구 호출의 요청, 서버가 변환한 연산·인자, 실제 외부 실행 명령, 서버 모델 호출, 결과 상태·실행 시점, 결과 참조·요약값, 호출 ID 연결을 봅니다.
SDK가 해석한 인자를 남긴 것과 전송된 요청 원문을 보관한 것을 구별합니다.
인자 배열을 공백으로 합쳐 경계를 잃는 것과 실제 셸 명령 문자열을 그대로 남기는 것도 구별합니다.
완료 항목 하나에 상태와 시점을 남기는 방식도 인정하며 비동기는 어느 단계의 상태인지 원고에 씁니다.
시각이나 사건 ID만 같은 것으로는 호출 항목의 연결을 인정하지 않습니다.

| 지우는 상세 | 설명을 남길 곳 | 이유 |
|---|---|---|
| L02.04 요청과 실행의 연결 | L02.01, L02.02·L02.03, L02.08 | 내용과 연결을 각각 평가하면 조합으로 표현됩니다. |
| L02.07 비동기 작업 최종 상태 기록 | L02.06 구현 단락 | 연결 사례가 없으며 접수·시작·완료를 설명하는 기준으로 남깁니다. |
| L02.09 외부 요청 내용 기록 | L02 scope와 구현 단락 | 연결 사례가 없으며 외부 요청이 어디까지 기록되는지 사실로 남깁니다. |

새 상세 L02.10은 출력 해시, 보관 출력의 번호·경로, 크기·행 수 같은 결과 참조·요약값을 봅니다.
해시를 남기면 원출력, 파싱 결과, 개수 요약 중 무엇을 계산한 값인지 원고에 씁니다.
출력 보관은 D01, 계보는 D02, 파생물의 기준값과 대조는 D03에서 봅니다.
L03은 서버 기록 쓰기 실패를, L04는 서버 기록을 담은 파일·DB의 위변조 방지를 봅니다.
출력 파일의 저장 실패와 출력·파생물의 위변조 확인은 D09·D03에서 봅니다.

## 영향

- L축 설명, L01~L04, D01·D03·I03·T02.10의 경계와 용어 사전을 맞춥니다.
- Camel·mulder·sift-kernel·trudi·protocol-siftpp·mcp_dfir·regipy의 기존 L01·L02 원고를 대조합니다. 부분 조사 서버에 없는 L01 원고를 새로 조사한 것처럼 만들지 않습니다.
- trudi의 클라이언트 자체 작업 기록은 T02.10 원고의 사실 설명으로 옮깁니다.
- 각 서버의 연결과 예외 표시는 고정 커밋의 코드와 새 기준으로 판단합니다. 요청·응답 누락이나 단순 완료 항목의 존재를 같은 기준으로 취급하지 않습니다.
- 결정 0028의 L01 범위를 일부 대체하며 D08 결정은 유지합니다. 결정 0004의 방식·구성 분리는 유지하고 L02 범위를 보완합니다.

mulder의 `mulder investigate` 오케스트레이터는 호출마다 MCP 도구 이름을 `orchestrator.log`에 남겨 MCP 도구 호출을 식별할 수 있으므로 L01.10 연결을 유지합니다.
