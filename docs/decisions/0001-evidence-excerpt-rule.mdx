# 0001. 근거에 코드 발췌를 붙이는 기준을 정합니다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

원고의 근거 중 일부에는 코드 발췌가 붙어 있었고, 일부에는 링크만 있었습니다.
개편안 3.1절에는 "발췌가 필요 없는 근거는 링크만 둔다"고만 적혀 있었습니다.
그래서 어떤 경우가 발췌가 필요 없는 경우인지는 원고를 쓴 사람이 그때그때 판단했습니다.
그 결과 같은 종류의 근거가 원고마다 다르게 쓰였습니다.
예를 들어 trudi `core/executor.py:81-96`처럼 한 곳에 있는 짧은 코드에도 링크만 달린 경우가 있었습니다.

## 결정

근거가 가리키는 코드 위치가 한두 곳이고 각 범위가 30줄 이하이면, 위치마다 `@발췌`를 둡니다.

링크만 두어도 되는 근거는 다음 네 가지뿐입니다.

- 코드가 아닌 근거. 예를 들어 실행 확인 기록, 문서, 예시 로그입니다.
- 코드 위치가 세 곳 이상인 근거.
- 30줄을 넘는 범위.
- 같은 셀 파일의 다른 근거에서 이미 발췌한 범위.

`check`는 이 기준에 맞지 않는 근거를 경고로 알려 줍니다.
이 검사는 `tools/pilot.py`의 `excerpt_warnings`가 하고, 기준값은 `EXCERPT_MAX`와 `EXCERPT_LINK_ONLY`에 있습니다.

## 영향

시범 원고를 쓴 서버 4개의 근거 35개에 발췌 53개를 더했습니다.
이 규칙은 `reports/README.md`의 규칙 절과 `AGENTS.md`에 적어 두었습니다.
