# 0001. 근거에 코드 발췌를 붙이는 기준을 정한다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

원고 근거 가운데 어떤 것은 코드 발췌가 있고 어떤 것은 링크만 있었다.
개편안 3.1절은 "발췌가 필요 없는 근거는 링크만 둔다"고만 적어서 필요 없는 경우가 무엇인지 원고를 쓴 사람이 그때그때 정했다.
그 결과 한 곳의 짧은 코드(예: trudi `core/executor.py:81-96`)도 링크만 있는 등 같은 종류의 근거가 서로 다르게 쓰였다.

## 결정

근거가 가리키는 코드 위치가 한두 곳이고 각 범위가 30줄 이하이면 위치마다 `@발췌`를 둔다.
링크만 두는 근거는 다음 넷뿐이다.

- 코드가 아닌 근거(실행 확인 기록, 문서, 예시 로그).
- 코드 위치가 세 곳 이상인 근거.
- 30줄을 넘는 범위.
- 같은 셀 파일의 다른 근거에 이미 발췌한 범위.

`check`가 이 기준에 어긋난 근거를 경고로 알린다(`tools/pilot.py`의 `excerpt_warnings`, 기준값 `EXCERPT_MAX`·`EXCERPT_LINK_ONLY`).

## 영향

시범 원고 4개 서버의 근거 35개에 발췌 53개를 더했다.
규칙은 `reports/README.md` 규칙 절과 `AGENTS.md`에 적었다.
