# 0011. T03 이름을 "실행 조건 확인"으로 넓히고 실행 자원 상태 확인을 더한다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

2026-10-02 검토(`docs/reviews/2026-10-02/review.md` 7번)가 mulder의 공통 자원 대기를 원고 본문이 설명하지 않는다고 짚었다.
mulder는 동기 도구를 실행하기 전에 메모리·CPU 사용률을 확인하고 기준을 넘으면 기다리며 동시에 도는 실행 수를 제한한다.
이 확인은 인자 밖의 조건으로 실행을 정하는 일이지만 T03은 호출을 허용할지만 물어 실행을 미루는 동작을 담지 못했다.

## 결정

- T03 이름을 "실행 허가 조건 확인"에서 "실행 조건 확인"으로 바꾼다.
- 질문을 "인자 밖의 조건(앞선 작업·판정 상태, 모델 밖 승인자의 승인, 원격 호출자의 신원, 서버의 실행 자원 상태)으로 호출을 허용할지와 언제 실행할지를 어떻게 정하는가?"로 넓힌다. scope와 미구현도 같은 뜻으로 고친다.
- 상세 T03.11 "실행 자원 상태 확인"을 더한다. 정해 둔 시간을 기다린 뒤 실행하는 것은 설계된 동작이라 구현에 적는다. 자원 상태를 읽지 못하면 통과시키거나 설정으로 끌 수 있으면 †를 붙인다.

## 영향

서버 5곳의 T03 원고 제목을 고쳤다. 상세 번호와 다른 연결은 그대로다.
mulder T03 원고에 T03.11(†)을 더했다.
