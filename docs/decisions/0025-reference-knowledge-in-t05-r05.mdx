# 0025. 모델에게 돌려주는 참조 지식도 T05와 R05에서 봅니다

- 날짜: 2026-10-04
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

서버는 사건 증거가 아닌 참조 지식도 모델에게 돌려줍니다. mulder `lookup_attack_technique`는 ATT&CK 자료를 조회해 돌려주고, trudi는 아티팩트 지식을 응답에 덧붙이며 `enrich.*`로 외부 위협 정보를 조회합니다.

- T05 scope는 "판단에 쓰는" 참조 자료만 적용 범위로 두어, 서버가 판단에 쓰지 않고 모델에게 돌려주기만 하는 지식 자료의 버전은 문구 밖이었습니다. mulder 원고는 이미 그 자료를 적고 있었습니다.
- R05는 증거에서 나온 결과의 출처만 물었습니다. 참조 지식의 출처와 그것이 증거가 아니라는 표시를 볼 셀이 없었습니다. 지식이나 위협 정보를 증거처럼 다루면 근거 판단이 오염됩니다.

## 결정

- T05 scope의 참조 자료를 "판단에 쓰거나 조회 결과로 모델에게 돌려주는" 자료로 넓힙니다.
- R05 question과 scope에 참조 지식을 넣습니다. 참조 지식은 공격 기법 목록, 아티팩트 지식, 악용 가능 실행 파일 목록, 외부 위협 정보 조회 결과처럼 사건 증거가 아닌 자료입니다.
- R05에 상세 둘을 더합니다. R05.09 참조 지식 원문 출처, R05.10 참조 지식과 증거 결과 구분.
- 발견사항의 분류 ID를 참조 표와 대조하는 경우는 새 상세를 두지 않고 D05.10을 「판정·분류 값 기준 대조」로 넓혀 담습니다. 기준이 코드 상수인지 참조 표인지는 원고의 구현 단락에 씁니다(상세 단위 변경).

## 영향

- mulder R05.09, trudi R05.10†를 연결했습니다.
- trudi D05.10에 기법 ID 대조 게이트를 적었습니다.
- trudi·mulder T05·T06, Camel D06에 참조 지식 자료의 버전과 사용 사실을 보강했습니다.
