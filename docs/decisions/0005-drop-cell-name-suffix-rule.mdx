# 0005. 셀 이름 끝에 "방식"을 쓰지 못하게 하던 검사를 없애고, L01 이름을 "기록 방식"으로 바꿉니다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

첫 버전 전 결정 40번은 셀 이름 끝에서 "방식"을 뗐습니다.
모든 셀이 그 일을 어떤 방식으로 하는지를 묻는다는 이유였습니다.
스키마도 " 방식"으로 끝나는 셀 이름을 오류로 막았습니다.

이 검사 때문에 0004에서 문제가 생겼습니다.
0004에서 L01 이름을 "기록 방식"으로 정했지만, 이 검사에 걸려 "기록 경로"로 바꿨습니다.
L01과 L02는 "기록 방식 / 기록 구성"처럼 짝을 이룰 때 뜻이 가장 잘 드러납니다.

## 결정

- 스키마의 셀 이름 검사(" 방식"으로 끝나면 오류)를 없앱니다. 셀 이름은 그 셀이 묻는 일을 명사로 쓴다는 원칙만 남깁니다.
- L01 이름을 "기록 방식"으로 바꿉니다. 이 결정은 0004에서 정한 L01 이름을 대체합니다.
- 다른 셀 이름은 그대로 둡니다.
