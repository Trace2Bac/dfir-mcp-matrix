# 0003. T04 이름을 "실행 형태"로 바꿉니다

- 날짜: 2026-10-01
- 상태: 대체됨(0006)
- 결정한 사람: 결정권자(팀)

## 배경

T04 "실행 격리 수준"은 다음 두 가지를 묻는 셀입니다.

- 실제 분석을 어떤 호출 방식으로 수행하는가
- 실행 주체, 권한, 작업 공간을 서버와 얼마나 분리하는가

그런데 상세에는 격리와 관계없는 실행 방식도 들어 있었습니다.
서버 프로세스 안에서 라이브러리를 호출하는 방식, 셸 명령 문자열을 실행하는 방식이 그 예입니다.
셀 이름이 실제로 다루는 내용보다 좁았던 것입니다.

"실행 방식"이라는 이름은 쓸 수 없었습니다.
셀 이름 끝에 "방식"을 붙이지 않는다는 규칙(첫 버전 전 결정 40번)에 걸리기 때문입니다.

## 결정

T04 이름을 "실행 형태"로 바꿉니다. 셀의 질문과 상세는 그대로 둡니다.

## 영향

셀 번호와 상세 번호는 바뀌지 않습니다.
T04는 시범 셀이 아니어서 고칠 원고가 없습니다.
