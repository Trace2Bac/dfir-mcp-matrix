# 0012. 운영자가 정한 원격 분석 호스트 접속도 I축에서 본다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

Camel은 기본 설정에서 MCP 서버가 SSH로 SIFT 워크스테이션에 붙어 그곳에서 포렌식 도구를 실행한다.
그 워크스테이션은 운영자가 정한 분석 호스트라 I축의 "외부"로 볼지, 실행 방식(T04)으로만 볼지가 갈렸다.

## 결정

그 연결을 여는 것은 서버 코드이므로 판단 대상이다.
운영자가 정한 원격 분석 호스트 접속도 서버 코드가 여는 연결이면 I01(연결 켜기·목적지)·I03(보내는 내용)·I04(자격증명)에서 본다.
그 호스트에서 분석을 실행하는 방식은 T04에서 본다.
I01의 `boundary`에 이 문장을 넣는다.

## 영향

Camel 원고는 이미 이 기준으로 쓰여 바뀌지 않는다.
