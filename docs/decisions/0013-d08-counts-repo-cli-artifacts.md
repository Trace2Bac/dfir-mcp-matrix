# 0013. D08에서 같은 저장소의 CLI·훅이 서버 기록으로 만드는 검토 산출물을 센다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

D08은 서버가 만드는 검토 산출물만 셌다. D08.05 제외 기준도 운영자 CLI만 내보내면 서버 구현으로 세지 않았다.
Camel은 MCP 도구로는 보고서를 만들지 않지만 같은 저장소의 `camel bake-report`(운영자 CLI)와 `camel preserve-chatlog`(클라이언트 훅)가 서버 호출 기록으로 검토 화면(`report.html`)을 만든다. 지금 기준으로는 미구현이라 검토 산출물이 없는 서버처럼 보였다.

## 결정

- 같은 저장소가 함께 내놓는 운영자 CLI·클라이언트 훅이 서버 기록을 정해진 코드로 가공해 만드는 검토 산출물은 D08 구현으로 센다. 운영자가 그것을 돌려야 만들어진다는 점은 구현 첫머리에 적는다.
- 클라이언트 모델이 안내문에 따라 쓰는 보고서 글은 세지 않고 원고에 사실로 적는다.
- D08 scope와 D08.05 제외 기준을 이에 맞게 고친다.

## 영향

Camel D08 원고를 다시 쓴다. mulder D08.05 구현에 운영자 CLI의 STIX·CSV·ATT&CK Navigator 내보내기를 더한다.
