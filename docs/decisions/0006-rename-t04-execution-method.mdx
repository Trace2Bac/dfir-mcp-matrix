# 0006. T04 이름을 "실행 방식"으로 바꿉니다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

0003에서는 T04 이름을 "실행 방식"으로 하려 했습니다.
하지만 셀 이름 끝의 "방식"을 막는 검사에 걸려 "실행 형태"로 정했습니다.
그 뒤 0005에서 이 검사를 없앴습니다.

## 결정

- T04 이름을 "실행 방식"으로 바꿉니다.
- 이 결정은 0003을 대체합니다.
- 셀의 질문과 상세는 그대로 둡니다.

## 영향

셀 번호와 상세 번호는 바뀌지 않습니다.
T04는 시범 셀이 아니어서 고칠 원고가 없습니다.
