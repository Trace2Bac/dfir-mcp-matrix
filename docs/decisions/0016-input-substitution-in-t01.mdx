# 0016. 입력을 얻지 못해 다른 입력으로 실행하는 동작을 T01에서 봅니다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

sift-kernel 전체 적용에서 한 가지 동작이 세 셀에 나뉘어 적혔습니다.
입력을 얻지 못했을 때 다른 입력으로 대신 실행하는 동작입니다.

셀 정의가 이 동작을 여러 곳에 걸치게 만들었습니다.

- T07.04 include는 도구와 경로뿐 아니라 입력의 대체도 담고 있었습니다.
- E04 scope는 엉뚱한 파일을 입력으로 쓰거나 실패를 알리지 않는 경로를 † 사유로 정했습니다. †(예외 표시)는 원고의 구현 단락에 적은 적용 범위 안에서 그 방식이 적용되지 않는 경우가 있다는 표시입니다.

그래서 다음 두 동작이 T07과 E04 원고에 겹쳐 적혔습니다.

- sift-kernel이 추출에 실패한 이미지 안 경로를 호스트 경로로 넘기는 동작
- mulder가 EVTX를 꺼내지 못하면 다른 폴더의 EVTX 파일을 모으는 동작

하지만 T07은 도구나 참조 자료가 없을 때의 처리를 묻고, E축은 원본 증거를 다룹니다.
그리고 입력이 없는지 확인하는 일은 이미 T01.02 "입력 존재·읽기 가능 검사"가 다룹니다.

## 결정

- 상세 T01.08 "입력 부재 시 다른 입력으로 대체"를 더합니다.
  - 입력 파일·경로를 찾지 못하거나 이미지에서 꺼내지 못했을 때, 거부하지 않고 다른 파일·경로·범위로 입력을 바꿔 실행하는 동작이 이 상세에 해당합니다.
- T07.04를 고칩니다.
  - include에서 입력을 뺍니다.
  - exclude에 "입력을 얻지 못해 다른 입력으로 실행하면 T01.08이다"를 더합니다.
  - 같은 입력을 다른 도구·경로로 얻는 대체는 그대로 T07에 남습니다.
- E04 scope의 † 사유를 고칩니다.
  - "엉뚱한 파일을 입력으로 씀"과 "실패를 알리지 않고 지나감"을 뺍니다.
  - 대신 "일부만 준비함"과 "누락을 알리지 않음"으로 고칩니다.
  - 입력을 얻지 못해 다른 입력으로 실행하는 경로는 T01.08에서 본다고 적습니다.

## 영향

- sift-kernel과 mulder의 T01 원고에 T01.08을 더했습니다.
- T07.04·E04.02 원고에서 같은 내용을 다루던 단락은 T01.08을 가리키는 문장으로 바꿨습니다.
- Camel은 입력을 바꿔 실행하는 경로가 없어 바꾸지 않았습니다.
