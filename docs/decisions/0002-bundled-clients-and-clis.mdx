# 0002. 서버와 함께 제공되는 클라이언트와 CLI는 정해진 경우에만 서버 구현으로 봅니다

- 날짜: 2026-10-08(2026-10-01~10-08의 결정을 정리)
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

서버 저장소에는 서버 말고도 클라이언트 코드, 훅, 설정, 사용자 CLI가 함께 들어 있는 경우가 많습니다.
이 동작을 서버 구현으로 볼지 서버마다 판정이 달랐습니다.

## 결정

- 서버와 함께 제공되는 클라이언트 코드, 훅, 설정, 사용자 CLI의 동작은 다음 경우에만 서버 구현으로 봅니다.
  - 상세가 클라이언트 쪽 방식을 묻는 경우. 다른 클라이언트로 붙으면 그 방식이 적용되지 않는다는 점은 구현 단락에 씁니다.
  - 클라이언트 쪽에서 MCP 도구 호출을 기록하는 경우
  - 서버 기록이나 서버 응답을 정해진 코드로 가공해 보고 산출물을 만드는 경우
- 그 밖에는 원고에 사실로만 씁니다. 클라이언트 모델이 안내문에 따라 직접 쓰는 보고서 글은 서버 구현으로 보지 않습니다.
- L축은 MCP 도구 호출의 서버 기록을 봅니다. 클라이언트 기록은 클라이언트 쪽 호출 기록 상세에서만 보고, 백엔드 서비스가 받은 요청을 자기 기록에 남기는 것은 서버 기록이 아닙니다.

## 영향

- 같은 코드를 서버마다 같은 기준으로 판정합니다. 클라이언트 쪽 동작을 서버 구현으로 보는 경우가 정해져 있어 다른 셀에서는 클라이언트 동작을 사실로만 적습니다.
- 규칙은 CONTRIBUTING의 「특수한 경우」에 있습니다.
