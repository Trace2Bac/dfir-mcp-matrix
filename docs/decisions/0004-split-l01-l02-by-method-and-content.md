# 0004. L01은 기록 경로, L02는 기록 구성으로 나눈다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

L01 기록 범위와 L02 기록 내용 구성은 둘 다 무엇이 기록되는지를 물었다.
L01은 사건 종류로, L02는 필드로 물어 거부 호출·외부 요청·서버 안 모델 호출이 두 셀에 함께 나왔다.

## 결정

- L01 이름을 "기록 경로"로 바꾼다. 논의한 이름은 "기록 방식"이었지만 셀 이름 끝에 "방식"을 붙이지 않는 규칙(첫 버전 전 결정 40번)에 따라 첫 버전 전 F1 판정의 이름 "호출 기록 경로"를 따랐다. 질문은 "서버 기록을 어떤 장치·경로로 만들고, 그 장치를 거치지 않는 호출은 무엇인가?"다. 장치를 거치지 않아 기록되지 않는 호출이 있으면 †를 붙인다.
- L02 이름을 "기록 구성"으로 바꾼다. 기록 항목에 어떤 사건과 내용을 어떤 형태로 남기는지를 묻는다.
- L01의 사건 종류 상세는 지운다. 거부 호출은 L02.06, 외부 요청은 L02.09, 서버 안 모델 호출은 L02.05에서 본다. 도구 호출 기록은 기록을 남기는 서버가 모두 해당해 구별하는 상세가 아니다.
- L01에 기록 장치 상세를 더한다. 공통 요청 처리 단계에서 기록, 도구별 기록 호출, 실행기 안 기록이다.
- 상태 변경(승인·삭제·초기화) 기록은 구현 사례가 확인되면 L02에 상세로 더한다. 상세는 실제 구현체가 있을 때만 둔다.

| 옛 번호 | 새 번호 | 상세 |
|---|---|---|
| L01.01 | 없음 | 도구 호출 기록 |
| L01.02 | L02.06 | 거부·검사 실패 호출 기록 |
| L01.03 | L02.09 | 외부 요청 기록 |
| L01.04 | 없음(사례 확인 뒤 L02에 더함) | 상태 변경 기록 |
| L01.05 | L02.05 | 서버 안 모델 호출 기록 |
| 없음 | L01.07 | 공통 요청 처리 단계에서 기록 |
| 없음 | L01.08 | 도구별 기록 호출 |
| 없음 | L01.09 | 실행기 안 기록 |

## 영향

셀 번호와 L02 상세 번호는 바뀌지 않아 시범 원고(L02)는 제목만 고쳤다.
L01.07~09의 `seen_in`은 첫 버전 전 분석(옛 F1 판정)에서 옮겼다. 원고를 쓸 때 기준 커밋 코드로 다시 확인한다.
L02의 상세는 시범 서버 4개 가운데 3개 상세에만 원고가 연결돼 있어 나머지 서버를 조사하며 이름·구성이 바뀔 수 있다.
