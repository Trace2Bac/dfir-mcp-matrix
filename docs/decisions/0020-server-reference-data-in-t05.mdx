# 0020. 서버 코드가 판단에 쓰는 참조 자료도 T05에서 봅니다

- 날짜: 2026-10-03
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

T05 scope는 서버가 실행하거나 불러오는 분석 도구와, 그 도구가 판단에 쓰는 참조 자료만 적용 범위로 두었습니다.

trudi 서버 코드는 분석 도구를 거치지 않고 자기 판단에 참조 자료를 씁니다.

- MITRE ATT&CK 기법 표로 기법을 매핑합니다. `install.sh`는 저장소의 표를 복사하지만 이미 파일이 있으면 복사하지 않습니다.
- 저장소의 `data/fk` 지식 시트로 응답의 해석 주의와 발견사항의 등급 상한을 정합니다.

이 자료의 버전이 바뀌면 같은 증거에서도 다른 기법 ID나 다른 등급 상한이 나옵니다. 그런데 문구상 T05 범위 밖이라 볼 곳이 없었습니다.

## 결정

- T05 scope의 참조 자료를 "분석 도구나 서버 코드가 판단에 쓰는" 자료로 넓힙니다.
- 참조 자료의 예에 지식 데이터를 더합니다.
- T05.01 include에 다음을 더합니다. 룰, 아티팩트, 매핑 파일을 저장소에 함께 넣어 커밋으로 내용이 정해지는 경우도 고정으로 봅니다.
- T06 boundary에 다음을 더합니다. 이 셀의 버전에는 참조 자료의 식별값(룰 저장소 커밋, 심볼 GUID 등)도 포함합니다.

## 영향

- trudi T05에 다음을 더했습니다.
  - T05.01: `data/fk`와 MITRE 표를 적었습니다. MITRE 표의 "이미 있으면 복사하지 않음"을 예외로 적었습니다.
  - T05.02: MITRE 표 위치를 정하는 환경변수를 적었습니다.
  - T05.04: 검토와 보고서 전 점검이 지식 시트의 SHA-256을 정책 값에 넣는다는 점을 적었습니다.
- mulder T05.01에 저장소 안의 ATT&CK 전술 표를 더했습니다.
- Camel T05 원고는 LOLBAS 자료를 이미 버전 없이 받는다고 적고 있어 바뀌지 않았습니다.
- sift-kernel과 regipy는 서버 코드가 쓰는 참조 자료가 없어 바뀌지 않았습니다.
