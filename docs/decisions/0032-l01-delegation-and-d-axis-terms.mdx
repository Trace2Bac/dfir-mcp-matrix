# 0032. L01의 미구현 정의를 고치고 D07·D08 이름과 "결론"·"부재 주장"의 뜻을 정리합니다

- 날짜: 2026-10-06
- 상태: 채택(0029의 L01.10 범위 보완)
- 결정한 사람: 결정권자(팀)

## 배경

셀 정의와 이름을 다시 읽으며 다음 문제를 확인했습니다.

- L01.06 「클라이언트·백엔드 기록에 위임」은 연결 사례가 없었고 0029 이후 정의가 다른 상세와 겹쳤습니다. 클라이언트에 맡기는 경우는 L01.10과 늘 함께 나타났습니다. 백엔드 서비스의 자체 기록에는 MCP 도구 이름과 인자가 없어 MCP 도구 호출을 식별하는 기록이 아니었습니다.
- L01 not_implemented는 "서버가 도구 호출을 기록하지 않는 경우"였습니다. L01.06을 지우면 서버 기록 없이 클라이언트 기록만 있는 서버가 미구현과 L01.10에 함께 해당하게 됩니다.
- "결론"이 두 뜻으로 쓰였습니다. D06 「결론 도출」의 결론은 서버가 규칙이나 모델로 계산한 판단입니다. D07 「결론 근거 검증」은 실제로 발견사항과 부재 주장의 근거를 심사했습니다. D06 boundary는 D07이 D06의 결과를 심사하는 것처럼 적었습니다.
- D07은 cell 문장에서 "부재 결론", 상세 이름에서 "부재 주장"을 섞어 썼습니다.
- D08 「검토 보고 산출물 구성」의 "검토"는 용어 사전의 「보고 산출물」 정의에 이미 들어 있었습니다.

## 결정

- L01.06을 지웁니다.
  - 서버가 MCP 도구 호출을 직접 기록하지 않고 같은 저장소의 클라이언트 쪽에만 MCP 도구 호출 기록이 있으면 L01.10에 연결합니다. 서버 기록이 없다는 사실은 원고에 씁니다.
  - L01 not_implemented를 "서버가 도구 호출을 기록하지 않고 같은 저장소의 클라이언트도 MCP 도구 호출을 기록하지 않는 경우"로 고칩니다.
  - 백엔드 서비스가 받은 요청을 자기 기록에 남기는 것은 서버 기록이 아니며 원고에 사실로 씁니다. 이 문장을 L01 boundary에 더합니다.
- "결론"은 서버가 도구 결과를 규칙이나 모델로 해석해 만든 판단(D06)만 가리킵니다. 모델이 기록으로 제출한 주장은 발견사항(D05)입니다.
  - D07의 이름을 「발견사항 근거 검증」으로 바꿉니다.
  - D07과 원고의 "부재 결론"을 "부재 주장"으로 맞춥니다.
  - D05·D06 scope에 발견사항과 결론의 정의를 한 문장씩 넣습니다. D06 boundary와 D06.04 exclude는 D07이 발견사항을 심사한다는 뜻으로 고칩니다.
  - 용어 사전에 「결론」과 「부재 주장」을 더합니다.
- D08의 이름을 「보고 산출물 구성」으로 바꾸고 D08 셀 안의 "검토용"을 뺍니다.
- R05 question은 범위를 바꾸지 않고 증거에서 나온 결과와 참조 지식에서 나온 결과를 나눠 묻는 두 문장으로 고칩니다.

상세 이름도 아래 표처럼 바꿉니다. 상세 단위 변경이므로 여기에는 기록만 남깁니다.

| 상세 | 옛 이름 | 새 이름 |
|---|---|---|
| D01.01 | 도구 출력 파일 저장 | 분석 도구 출력 파일 저장 |
| D01.02 | 도구가 만든 파생물 유지 | 추출·생성 파일 보관 |
| D01.05 | 보존 기간·대상 정책 | 보관 기간·대상 정책 |
| D06.02 | 시간·공간 근접성 연결 | 시각·위치 근접 연결 |

- D01.01은 분석 도구(외부 프로그램)의 표준 출력과 텍스트 출력을 봅니다. 분석 도구 없이 서버 코드가 만든 MCP 도구 응답을 그대로 파일로 남기는 것은 이 상세에 연결하지 않고 원고에 씁니다.
- D01.02의 include는 분석 도구나 서버 코드가 만든 파일로 고쳐, trudi가 서버 코드로 쓰는 CSV·JSON·보고서 연결과 맞춥니다.
- D06.02의 include에서 호스트를 뺍니다. 같은 호스트로 잇는 것은 같은 값의 키로 잇는 D06.01입니다.

| 옛 번호 | 새 번호 | 셀 |
|---|---|---|
| L01.06 | 없음 | L01(지움, 클라이언트 기록은 L01.10) |

## 영향

- 서버 연결과 예외 표시는 바뀌지 않습니다. 서버 기록 없이 클라이언트 기록만 있는 서버는 아직 없습니다.
- 원고: 다섯 서버의 D07·D08 제목 줄, D01·D06 소제목, "부재 결론" 다섯 곳을 고쳤습니다. trudi D01.01은 적용 범위를 외부 도구를 실행하는 호출로 적고 파이썬 도구의 응답 사본은 분석 도구 출력이 아니라고 밝혔습니다.
- 0029가 정한 L01.10의 범위에 서버 기록이 없는 경우를 더합니다.
