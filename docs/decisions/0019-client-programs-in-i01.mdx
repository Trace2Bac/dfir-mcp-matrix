# 0019. 서버가 연결하려고 실행하는 클라이언트 프로그램의 연결은 I01에서 봅니다

- 날짜: 2026-10-03
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

I01은 서버 코드가 스스로 여는 외부 연결을 보고, I02는 서버가 실행한 분석 도구가 스스로 여는 통신을 봅니다.
I02 scope는 그 예로 "평판 조회"를 들었습니다.

trudi의 `enrich.machinae_lookup`은 평판 사이트를 조회하는 외부 프로그램 machinae를 실행합니다.
`live.*`는 `ssh` 실행 파일로 조사 대상 단말에 접속합니다.
둘 다 서버가 외부 프로그램을 실행한다는 점에서는 I02로 읽히고, 서버가 연결하려고 그 프로그램을 부른다는 점에서는 I01로 읽혔습니다.
mulder는 같은 평판 조회를 Python 코드로 직접 하고 I01에서 봤습니다.

## 결정

- 서버 코드가 외부 연결을 하려고 실행하는 클라이언트 프로그램의 그 연결은 I01에서 봅니다.
  - `ssh`와 평판 조회 프로그램이 그 예입니다.
  - I01 boundary에 이 기준을 적습니다.
- 그 프로그램이 의도한 연결 밖에서 스스로 하는 통신은 I02에서 봅니다.
  - 업데이트 확인이나 텔레메트리 전송이 그 예입니다.
- I02 scope의 예시 "평판 조회"를 "분석 중에 도구가 스스로 하는 평판 조회"로 좁힙니다.
- 한 기능은 한 셀에서 봅니다. 의도한 연결과 부수적인 통신이 함께 있을 때만 두 셀에 나눠 적습니다.

## 영향

- trudi 원고는 이미 machinae 조회와 SSH 접속을 I01·I03에서 보고 I02에서는 I01을 가리키므로 바뀌지 않습니다.
- mulder, Camel, sift-kernel, regipy 원고는 바뀌지 않습니다.
