# 0039. 셀의 질문을 무엇을 분류하는지 밝히는 평서문(확인 사항)으로 바꿉니다

- 날짜: 2026-10-06
- 상태: 채택(0038의 질문 형식 부분 대체)
- 결정한 사람: 결정권자(팀)

## 배경

0038은 매트릭스를 분류표로 정하고 셀 질문을 "어떻게 ~하나요?"로 묻게 했습니다.
그런데 팀 검토 메모는 셀의 구성요소를 "질문"이 아니라 "확인해야 하는 사항"으로 정리했습니다.
질문형은 한 셀에 질문을 여러 개 이어 붙이기 쉬웠습니다.
T03·T10·R01·R05·L01은 질문이 두 문장 이상이었고, P04 질문은 125자였습니다.
"적재한 입력", "능력" 같은 낱말과 `scope`를 되풀이하는 열거도 질문에 들어 있었습니다.

## 결정

- 셀의 `question`을 확인 사항이라고 부르고, "~하는 방식을 분류합니다."처럼 무엇을 분류하는지 밝히는 평서문 한 문장으로 씁니다. 모든 셀이 서버를 대상으로 하므로 "서버가" 같은 주어는 쓰지 않습니다.
- 질문형이나 "~해야 한다" 같은 요구 문장은 쓰지 않습니다. 분류표(0038)이므로 요구가 아니라 분류 대상을 적습니다.
- 셀 43개의 `question`을 이 형식으로 다시 씁니다. 판정 범위는 바꾸지 않습니다. 다음은 함께 고칩니다.
  - 질문 두 개 이상을 이은 셀(T03·T10·R01·R05·L01)은 한 문장으로 합칩니다. T10의 "그 명세가 실제 처리와 맞나요?"는 상세 T10.03이 보므로 뺍니다.
  - `scope`와 같은 열거는 줄입니다. 예를 들어 T03의 조건 목록은 괄호 안 한 번으로 줄입니다.
  - P04의 "능력·단계·적재한 입력·세션 문맥", R03의 "부재" 같은 낱말은 쉬운 말로 바꾸거나 뺍니다.
- YAML 키 `question`은 그대로 둡니다. 화면과 문서에서만 "확인 사항"이라고 부릅니다.
