# 0013. 같은 저장소의 CLI·훅이 서버 기록으로 만드는 검토 산출물도 D08 구현으로 인정합니다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

이 결정 전까지 D08은 서버가 만드는 검토 산출물만 구현으로 인정했습니다.
D08.05의 제외 기준도 사용자 CLI로만 내보내는 경우는 서버 구현으로 인정하지 않았습니다.

이 기준으로는 Camel을 제대로 나타낼 수 없었습니다.

- Camel은 MCP 도구로는 보고서를 만들지 않습니다.
- 하지만 같은 저장소의 `camel bake-report`(사용자 CLI)와 `camel preserve-chatlog`(클라이언트 훅)가 서버 호출 기록으로 검토 화면(`report.html`)을 만듭니다.
- 그런데 기존 기준으로는 이것이 미구현이어서, Camel이 검토 산출물이 없는 서버처럼 보였습니다.

## 결정

- 같은 저장소가 함께 내놓는 사용자 CLI나 클라이언트 훅이 서버 기록을 정해진 코드로 가공해 검토 산출물을 만들면, D08 구현으로 인정합니다.
  - 사용자가 그 CLI나 훅을 돌려야 산출물이 만들어집니다. 이 점은 원고의 **구현** 단락 첫머리에 씁니다.
- 클라이언트 모델이 안내문에 따라 쓰는 보고서 글은 구현으로 인정하지 않습니다. 이것은 원고에 사실로 씁니다.
- 이에 맞게 D08 scope와 D08.05 제외 기준을 고칩니다.

## 영향

- Camel D08 원고를 다시 씁니다.
- mulder D08.05의 **구현** 단락에 사용자 CLI의 STIX·CSV·ATT&CK Navigator 내보내기를 더합니다.
