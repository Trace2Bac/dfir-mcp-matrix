# 0003. T04 이름을 "실행 형태"로 바꾼다

- 날짜: 2026-10-01
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

T04 "실행 격리 수준"은 실제 분석을 어떤 호출 방식으로 수행하고 실행 주체·권한·작업 공간을 서버와 얼마나 분리하는지를 묻는다.
상세에는 서버 프로세스 안 라이브러리 호출, 셸 명령 문자열 실행처럼 격리와 무관한 실행 방식도 들어 있어 이름이 내용보다 좁았다.
"실행 방식"은 셀 이름 끝에 "방식"을 붙이지 않는 규칙(첫 버전 전 결정 40번)에 걸린다.

## 결정

T04 이름을 "실행 형태"로 바꾼다. 질문과 상세는 그대로 둔다.

## 영향

셀 번호와 상세 번호는 바뀌지 않는다. T04는 시범 셀이 아니라 고칠 원고가 없다.
