# 0014. code-mode 서버에서는 SDK가 돌려주는 객체를 결과로 보고, 응답을 만드는 단계는 R01 가공으로 봅니다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

Camel은 code-mode 서버입니다. Camel에서는 결과가 다음 순서로 모델에 전달됩니다.

1. 모델이 보낸 JavaScript 코드가 SDK 메서드를 부릅니다.
2. SDK는 도구 출력을 파싱한 객체를 그 코드에 돌려줍니다.
3. 그 코드가 출력한 글이 MCP 응답이 되어 모델에 전달됩니다.

R축 셀은 응답과 도구 결과를 같은 것으로 보고 질문합니다.
그래서 code-mode 서버에서는 무엇을 결과로 볼지 의견이 갈렸습니다.

## 결정

- SDK 메서드가 호출자 코드에 돌려주는 객체를 R01~R06의 결과로 봅니다.
  - 그 객체가 응답에 실리는지는 호출자 코드가 정합니다. 이 점을 원고에 씁니다.
- 그 객체를 고르고, 거르고, 요약해 응답 글로 만드는 단계는 도구 출력 가공으로 봅니다. 그래서 R01에 상세 R01.10 "호출자 코드로 가공"을 더합니다.
- R07은 모델이 받는 글의 형태를 묻는 셀이므로, MCP 응답 글을 봅니다.
- 이 기준을 CONTRIBUTING의 판단 기준에 적습니다.

## 영향

- Camel R01 원고에 R01.10을 더했습니다.
- Camel R02~R06 원고의 **구현** 단락 첫머리에 무엇을 결과로 보는지 밝혔습니다.
- 다른 서버의 원고는 바뀌지 않습니다.
