# 0014. code-mode 서버의 결과는 SDK가 돌려주는 객체로 보고 응답 만들기는 R01 가공으로 본다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

Camel은 code-mode 서버다. 모델이 보낸 JavaScript가 SDK 메서드를 부른다. SDK는 도구 출력을 파싱한 객체를 그 코드에 돌려준다. 모델이 받는 MCP 응답은 그 코드가 찍은 글이다.
R축 셀은 응답과 도구 결과를 같은 것으로 보고 질문하므로 code-mode 서버에서는 무엇을 결과로 볼지가 갈렸다.

## 결정

- SDK 메서드가 호출자 코드에 돌려주는 객체를 R01~R06의 결과로 본다. 그 객체가 응답에 실리는지는 호출자 코드가 정한다는 점을 원고에 적는다.
- 그 객체를 골라 거르고 요약해 응답 글로 만드는 단계는 도구 출력 가공이다. R01에 상세 R01.10 "호출자 코드로 가공"을 더한다.
- 모델이 받는 글의 형태를 묻는 R07은 MCP 응답 글을 본다.
- 이 기준을 CONTRIBUTING의 판단 기준에 적는다.

## 영향

Camel R01 원고에 R01.10을 더하고 R02~R06 원고의 구현 첫머리에 결과 기준을 밝혔다. 다른 서버 원고는 바뀌지 않는다.
