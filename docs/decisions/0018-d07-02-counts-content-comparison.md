# 0018. D07.02는 서버가 근거 내용을 대조하는 것 자체를 센다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

D07 boundary는 검토를 통과해야 발견사항이 확정되는 게이트만 심사로 세고 D07.02 include는 대조가 맞지 않으면 거부하거나 등급을 낮추는 경우만 담았다.
sift-kernel의 `register_finding`은 발견사항 설명의 낱말이 인용한 호출의 원래 출력에 있는지 서버가 대조하지만 결과를 등록 응답에만 싣고 판정에 쓰지 않는다.
그래서 서버가 근거 내용을 실제로 대조하는데도 어느 상세에도 연결되지 않았다.
같은 sift-kernel 적용에서 D07.04에는 교차 확인 도구의 권고와 근거 수에 따른 등급 재계산이 적혀 R04·D07.03과 겹쳤다.

## 결정

- D07.02는 서버가 근거 내용을 대조하는 것 자체를 센다. 대조 방법과 그 결과로 거부하는지, 등급을 바꾸는지, 응답에 표시만 하는지는 구현에 적는다. D07 boundary에 이 예외를 적는다.
- D07.04 exclude에 교차 확인 도구를 권하기만 하면 R04, 근거가 늘 때 등급을 다시 계산하기만 하면 D07.03이라고 적는다.

## 영향

sift-kernel D07에 D07.02(†)를 더하고 D07.04 연결을 지웠다. D07.04에 있던 사실은 D07.03 원고로 옮겼다.
mulder와 Camel은 근거 내용을 대조하는 코드가 없어 바뀌지 않았다.
