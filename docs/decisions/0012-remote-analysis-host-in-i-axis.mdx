# 0012. 사용자가 정한 원격 분석 호스트 접속도 I축에서 봅니다

- 날짜: 2026-10-02
- 상태: 채택
- 결정한 사람: 결정권자(팀)

## 배경

Camel은 기본 설정에서 MCP 서버가 SSH로 SIFT 워크스테이션에 접속합니다. 그리고 그곳에서 포렌식 도구를 실행합니다.
이 워크스테이션은 사용자가 정한 분석 호스트입니다.
그래서 이 접속을 어떻게 볼지 의견이 갈렸습니다.

- I축의 "외부" 연결로 볼 것인가
- 실행 방식(T04)으로만 볼 것인가

## 결정

그 연결을 여는 것은 서버 코드이므로, 이 접속도 판단 대상입니다.

사용자가 정한 원격 분석 호스트 접속이라도 서버 코드가 여는 연결이면 I축의 다음 셀에서 봅니다.

- I01: 연결 켜기와 목적지
- I03: 보내는 내용
- I04: 자격증명

그 호스트에서 분석을 실행하는 방식은 T04에서 봅니다.
I01의 `boundary`에 이 기준을 넣습니다.

## 영향

Camel 원고는 이미 이 기준으로 쓰여 있어 바뀌지 않습니다.
