# 0037. T03에 E02·D04.08·T01.06과의 경계를 두고 미구현 정의를 조건 목록으로 씁니다

- 날짜: 2026-10-06
- 상태: 채택(0031 보완)
- 결정한 사람: 결정권자(팀)

## 배경

T03.01 include의 "한 번만 허용하는 작업이 이미 이루어진 경우"는 글자대로 읽으면 다른 셀에서 보는 동작까지 담습니다.
protocol-siftpp는 증거 크기·수정 시각이 바뀌면 Volatility 호출을 거부하는 동작을 E02로, mcp_dfir는 같은 심볼 파일이 있으면 다시 받지 않는 동작을 D04로, mulder는 이미 색인한 소스를 건너뛰고 `force`로 다시 실행하는 동작을 D04.08로 보냈습니다.
원고의 판단은 맞지만 셀 정의에 근거가 없었습니다. 인자로 끌 수 있는 동작을 T03.01에 넣으면 설계된 동작이 한계 단락에 들어갑니다.
protocol-siftpp는 인자 밖 조건으로 호출을 막는 코드가 있는데도 미구현이라 not_implemented 문구와도 맞지 않았습니다.

## 결정

- T03 `boundary`: "증거가 기준값과 같은지 대조해 다르면 호출을 막는 것은 E02.07·E02.08에서 봅니다. 같은 결과나 출력 파일이 이미 있어 다시 만들지 않거나 덮어쓸지를 인자로 고르게 하는 것은 D04.08에서 봅니다. 인자로 받은 ID가 등록 목록에 있는지 보는 검사는 T01.06에서 봅니다."
- T03 `not_implemented` 첫 문장: "앞선 작업·판정 상태, 모델 밖 승인자의 승인, 원격 호출자의 신원, 서버의 실행 자원 상태로 호출을 막거나 미루는 코드가 없는 경우입니다."
- T03.01 exclude의 T01.06 문장은 셀 `boundary`로 옮겼으므로 지웁니다.

## 영향

- 원고 연결은 바뀌지 않습니다. protocol-siftpp·mcp_dfir T03은 미구현, mulder 생략·`force`는 D04.08 그대로입니다.
- 고친 파일: `matrix/cells/T/T03.mdx`.
