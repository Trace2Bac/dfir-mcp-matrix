# NNNN. 지킬 규칙을 한 문장으로 씁니다

- 날짜: YYYY-MM-DD
- 상태: 시행 | 폐지 | 대체됨(NNNN)
- 적용 대상: 원고 | 셀 정의 | 안내 문서 | 결정 기록 | 모든 글
- 검사: 없음 | `check`가 경고 | `check`가 오류

## 규칙

무엇을 어떻게 쓰는지 씁니다. 지키지 않아도 되는 경우가 있으면 함께 씁니다.
