# 0001. 말할 때 쓰는 낱말 대신 글에 쓰는 낱말로 씁니다

- 날짜: 2026-10-04
- 상태: 시행
- 적용 대상: 모든 글(원고, 셀 정의, 안내 문서, 결정 기록)
- 검사: 원고는 `check`, 셀 정의는 `validate`가 아래 표의 낱말 일부를 경고합니다

## 규칙

말로 할 때 편하게 쓰는 낱말(구어)을 글에 쓰지 않습니다. 같은 뜻을 가진 글말(문어)로 씁니다.
글말이라도 어렵거나 딱딱한 한자어보다 뜻이 바로 읽히는 낱말을 고릅니다. "돌려준다", "넘긴다", "들어간다"처럼 글에서도 자연스러운 낱말은 그대로 씁니다.

자주 나오는 구어와 바꿀 말은 다음과 같습니다.

| 구어 | 글말 | 경고 |
|---|---|---|
| 깔다, 깔린, 깔리는, 까는 | 설치하다, 설치된, 설치되는, 설치하는 | 예 |
| (화면·로그에) 찍다, 찍힌다 | 출력하다, 기록한다, 적는다 | 예 |
| (서버가) 뜬다 | 시작된다, 실행된다 | 예 |
| (서버·프로세스를) 띄우다 | 실행하다, 시작하다, 다시 시작하다 | 예 |
| (명령·작업이) 돌다, (도구를) 돌리다 | 실행되다, 동작하다, 실행하다 | 예 |
| (예외를) 잡다, (잠금을) 잡다 | (예외를) 처리하다와 이어지는 동작(건너뛴다, 빈 값을 돌려준다, 실패로 정한다), (잠금을) 획득하다 | 예 |
| 그냥 | 그대로, 별도 처리 없이 | 예 |
| (파일이) 깨지다 | 손상되다, 형식이 잘못되다 | 예 |
| (적용 범위가) 걸리다 | 적용되다 | 예 |
| 근데, 엄청, 되게, 얘기, 이런 거 | 그런데, 매우(또는 빼기), 매우, 설명, 이런 것 | 예 |
| (예외를 잡아, 다음으로) 넘어가다 | 무엇을 하는지 쓰기: 건너뛴다, 다시 실행한다, 다른 방법을 쓴다, 전달된다, 다음 단계로 옮긴다 | 예 |
| 알아서 | 자동으로, 스스로 | 아니요 |

**"걸리다"는 뜻을 보고 고칩니다.**

- 적용 범위를 말할 때는 "적용된다"로 씁니다. "이 방식은 ~에 걸린다"는 "이 방식은 ~에 적용된다"로, "검사가 걸리지 않는 경로"는 "검사가 적용되지 않는 경로"로 씁니다.
- 시간이 드는 것("오래 걸리는 연산", "걸린 시간")과 상한이나 제한에 닿는 것("시간 제한에 걸리면")은 글에서도 자연스러우므로 그대로 씁니다.

## 예

| 고치기 전 | 고친 뒤 |
|---|---|
| `camel` CLI가 사건 폴더에 깔아 주는 지침 | `camel` CLI가 사건 폴더에 설치하는 지침 |
| 표준 오류에 경고를 찍는다 | 표준 오류에 경고를 출력한다 |
| 값이 있어야 서버가 뜬다 | 값이 있어야 서버가 시작된다 |
| 검사 중 오류가 나면 그냥 통과시키는 경우 | 검사 중 오류가 나면 별도 처리 없이 통과시키는 경우 |
| 목록에 없는 명령으로 읽으면 걸리지 않는다 | 목록에 없는 명령으로 읽으면 검사가 적용되지 않는다 |
| 두 함수 모두 `OSError`를 잡아 넘어간다 | `OSError`가 나면 그 파일을 건너뛴다 |
| `zipfile`이 실패하면 `7z`로 넘어간다 | `zipfile`이 실패하면 `7z`로 다시 푼다 |

## 이유

원고와 셀 정의는 여러 사람이 읽고 서로 대조하는 기록입니다. 구어는 사람마다 뜻을 다르게 받아들이기 쉽습니다.
예를 들어 "걸리다"는 "적용되다", "거부되다", "시간이 들다"로 모두 읽힙니다. 그래서 적용 범위를 말할 때 "걸리다"를 쓰면 검사가 그 경로에 적용되는지, 그 경로를 거부하는지 구별하기 어렵습니다.
