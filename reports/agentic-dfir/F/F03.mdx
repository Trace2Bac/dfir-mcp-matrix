# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
서버 패키지 `dfir-mcp`의 필수 의존성은 DuckDB와 python-registry이고 선택 의존성은 MCP SDK뿐이다 [1].
서버가 불러 쓰는 `dfir_corr`의 의존성은 DuckDB와 PyYAML이다 [2].
`server_stdio.py`는 `list_tools`와 `call_tool` 처리기만 등록하고 MCP sampling으로 클라이언트 모델에게 생성을 요청하지 않는다 [3].
`server.py`도 `initialize`, `tools/list`, `tools/call`과 알림 두 가지만 처리한다 [4].
판정 결과의 해석 문장은 서버 코드에 정해 둔 문자열이다 [5].

모델 API를 부르는 코드는 같은 저장소의 클라이언트 `dfir_agent`에만 있다 [6].
`dfir_agent`의 live 모드는 서버를 하위 프로세스로 실행하고 Anthropic API로 모델을 불러 MCP 도구 목록을 넘긴다 [6].
이 모델은 클라이언트 모델이고 서버의 처리 중에 불리지 않는다.
