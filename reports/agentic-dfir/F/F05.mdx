# F05 발견사항·결론 근거 검증

### 비적용

**판단.** 서버에는 발견사항, 결론, 부재 주장을 받거나 저장하거나 보고하는 경로가 없다.
도구 73개 가운데 발견사항이나 주장을 인자로 받는 도구가 없고 보고 산출물을 쓰는 도구도 없다 [1].
`correlate_events`가 싣는 `UNRESOLVED`는 사건끼리의 모순 표시이고 서버는 이 표시로 어떤 주장을 받아들이거나 거부하지 않는다 [2].
`match_sigma_rules`의 설명은 발견사항을 교차 확인하는 데 쓰라고 적지만 이 도구는 발견사항을 받지 않고 이벤트 파일 경로만 받는다 [3].
`dfir_corr`의 `correlate_download_to_execution`은 맞는 내려받기가 없는 실행이 있으면 결과의 `revision_required`를 참으로 두지만 MCP 도구로 등록되지 않는다 [4].

보고 산출물은 같은 저장소의 클라이언트 `dfir_agent`와 사용자 CLI `analyze.py`가 쓴다 [5][6].
클라이언트도 발견사항의 근거를 확인하지 않는다.
결정적 모드의 발견사항은 코드에 정해 둔 문장이고 근거 호출의 응답과 대조하지 않는다 [7].
`get_amcache`가 `amcache_csv_missing` 오류를 돌려준 실행에서도 그 호출을 근거로 한 `F-001`이 `confirmed`로 보고서에 실렸다 [8].
live 모드는 모델이 `REPORT:`에 적은 발견사항을 그대로 받고 `tool_calls`에 적은 호출이 실제로 있었는지 대조하지 않는다 [9][6].
`AuditLogger.verify`는 호출 기록의 해시 체인만 검증하고 발견사항을 읽지 않는다 [10].
`senior-analyst-v3.yaml`은 발견사항에 9개 절이 빠지면 경고하거나 거부하는 단계를 적지만 클라이언트 코드에는 그 검사가 없다 [11][12].
이 처리는 모두 클라이언트에서 일어나고 서버를 거치지 않는다.

[10] `AuditLogger.verify`는 줄마다 `prev_hash`와 `entry_hash`만 다시 계산해 대조한다.

```python
    @staticmethod
    def verify(path: str | Path) -> tuple[bool, str]:
        """Walk the chain end-to-end. Returns (ok, message)."""
        p = Path(path)
        if not p.exists():
            return False, f"audit log not found: {p}"

        prev = GENESIS_PREV_HASH
        n = 0
        with p.open("r", encoding="utf-8") as f:
            for lineno, raw in enumerate(f, 1):
                raw = raw.strip()
                if not raw:
                    continue
                obj = json.loads(raw)
                if obj["prev_hash"] != prev:
                    return False, f"line {lineno}: prev_hash mismatch (expected {prev[:10]}..., got {obj['prev_hash'][:10]}...)"
                body = {k: v for k, v in obj.items() if k != "entry_hash"}
                # `default=str` MUST match canonical_body() / log()
                # so verify reproduces the same canonical bytes when
                # inputs originally contained Path/datetime/etc.
                canonical = json.dumps(body, sort_keys=True, separators=(",", ":"), default=str)
                recomputed = hashlib.sha256(canonical.encode()).hexdigest()
                if recomputed != obj["entry_hash"]:
                    return False, f"line {lineno}: entry_hash mismatch (audit_id={obj['audit_id']})"
                prev = obj["entry_hash"]
                n += 1
        return True, f"chain verified: {n} entries, tail={prev[:16]}..."
```
