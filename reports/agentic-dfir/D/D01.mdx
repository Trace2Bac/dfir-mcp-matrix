# D01 파생물 보관

### D01.01 파생물 파일 보관

**구현.** 이 방식은 `sift_plaso_log2timeline`이 만드는 Plaso 저장 파일과 Plaso가 쓰는 로그 파일에 적용된다 [1].
`sift_plaso_log2timeline`은 호출 인자 `output_storage_path`로 정한 경로를 `--storage_file`로 넘겨 `log2timeline.py`를 실행한다 [1].
저장 파일은 환경변수 `DFIR_DERIVED_ROOT`가 가리키는 폴더 아래에 남고 이 값이 없으면 시스템 임시 폴더 아래 `agentic-dfir-derived` 폴더에 남는다 [2].
파일 내용은 `log2timeline.py`가 쓴 Plaso 저장 파일 그대로이고 서버는 그 파일을 가공하지 않는다 [1].
응답에는 저장 파일의 경로와 SHA-256을 싣는다 [1].
`sift_plaso_psort`는 증거 폴더나 `DFIR_DERIVED_ROOT` 아래의 저장 파일을 입력으로 받아 다시 읽는다 [3].
가짜 실행 파일로 `sift_plaso_log2timeline`을 부른 뒤에도 저장 파일은 `DFIR_DERIVED_ROOT` 아래에 남았다 [4].
서버 코드에는 저장 파일을 지우는 경로가 없다.
보관 기간, 용량, 대상을 정하는 설정이나 코드도 없다.

Plaso 20260720의 `log2timeline.py`와 `psort.py`는 `--logfile`을 받지 않으면 현재 폴더에 `<도구 이름>-<날짜>T<시각>.log.gz` 로그 파일을 만든다 [5].
`log2timeline.py`의 작업 프로세스는 같은 폴더에 프로세스 이름을 앞에 붙인 로그 파일을 따로 만든다 [6].
서버는 두 도구에 `--logfile`도 작업 폴더도 주지 않으므로 이 로그 파일은 서버 프로세스의 현재 폴더에 남는다 [1][3][7].
서버 코드에는 이 로그 파일을 지우는 경로도 없다.

그 밖의 도구는 결과를 응답으로만 돌려준다.
Zimmerman 도구를 부르는 래퍼와 `sift_plaso_psort`는 공통 함수 `_tempdir`가 호출마다 만든 임시 폴더에 도구의 CSV를 쓰게 하고 그 CSV를 읽어 응답을 만든다 [8][9][3].
`_tempdir`는 `tempfile.mkdtemp`로 폴더를 만들고 `finally`에서 `shutil.rmtree`로 폴더째 지운다 [8].
가짜 `MFTECmd`로 `sift_mftecmd_parse`를 부르면 CSV를 쓴 임시 폴더는 호출이 끝난 뒤 남지 않았다 [10].
Volatility 3·YARA 래퍼와 `sift_recmd_query_key`는 파일 출력 인자 없이 도구의 표준 출력만 받는다 [11].
Volatility 3가 사용자 홈 폴더의 캐시 폴더에 쓰는 심볼 캐시는 증거에서 나온 파생물이 아니다 [12].
`correlate_timeline`과 `dfir_corr`의 상관 분석은 DuckDB를 `:memory:`로 열어 표를 만들고 DB 파일을 만들지 않는다 [13].
한 호출이 도구의 원래 출력과 그 가공본을 함께 남기는 경로는 없다.
`sift_plaso_log2timeline`은 저장 파일만 남기고 `sift_plaso_psort`가 만든 CSV는 임시 폴더와 함께 지운다 [1][3][8].

같은 저장소의 클라이언트와 사용자 CLI가 쓰는 파일은 서버 구현으로 보지 않고 사실로 적는다.
`dfir_agent`의 결정적 모드는 사용자가 `--out`으로 준 폴더에 클라이언트 기록 `audit.jsonl`, 반복마다의 상태 `progress.jsonl`, 마지막 보고 `report.json`을 쓴다 [14].
`audit.jsonl` 항목에는 도구 출력 자체가 아니라 출력 JSON의 SHA-256 `output_digest`가 남는다 [15].
live 모드는 같은 폴더에 `live_transcript.txt`·`live_tool_calls.jsonl`·`live_summary.json`을 쓰고 `audit.jsonl`·`progress.jsonl`은 쓰지 않는다 [16].
`analyze.py`는 live 모드를 `out/<tier>/<case-id>/<시각>/` 폴더로 실행하고 사건마다 최근 폴더 10개만 남기고 나머지를 지운다 [17].
`analyze.py`의 문서 주석은 그 폴더에 `audit.jsonl`·`progress.jsonl`도 생긴다고 적는다 [18].
저장소에 커밋된 참조 실행 `examples/out/ref-01/`에는 결정적 모드가 쓴 세 파일이 있다 [19].

```python
@contextmanager
def _tempdir(prefix: str = "dfir-sift-") -> Iterator[Path]:
    """Create + clean up a per-call temporary working directory."""
    d = tempfile.mkdtemp(prefix=prefix)
    try:
        yield Path(d)
    finally:
        shutil.rmtree(d, ignore_errors=True)
```

```python
        out_dir.mkdir(parents=True, exist_ok=True)
```
