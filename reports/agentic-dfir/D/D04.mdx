# D04 출력 경로 제한

### D04.01 서버가 출력 위치 결정

**구현.** 이 방식은 Zimmerman 도구 래퍼와 `sift_plaso_psort`가 도구에 주는 CSV 출력 위치에 적용된다 [1][2].
서버는 공통 함수 `_tempdir`로 호출마다 시스템 임시 폴더 아래에 `dfir-<도구>-` 접두어의 새 폴더를 만들고 그 폴더를 도구의 출력 위치로 준다 [3][1][2].
`sift_mftecmd_parse`는 `mft.csv`, EvtxECmd 래퍼는 `evtx.csv`, PECmd 래퍼는 `prefetch.csv`, `sift_recmd_run_batch`는 `recmd.csv`를 CSV 이름으로 정해 `--csvf`로 준다 [1].
`sift_amcacheparser_parse`는 폴더만 주고 CSV 이름은 AmcacheParser가 정한다 [1].
`sift_plaso_psort`는 임시 폴더 안의 `timeline.<output_format>`을 `-w`로 준다 [2].
이 이름에 들어가는 호출 인자는 `sift_plaso_psort`의 `output_format` 하나다 [2].
서버는 `output_format`을 검사하지 않고 그 값을 붙인 경로를 그대로 `-w`로 넘긴다 [2][4].
Plaso 20260720의 `psort.py`는 출력 형식 이름이 지원하는 출력 모듈이 아니면 출력 파일을 쓰기 전에 오류로 끝난다 [5].
임시 폴더는 호출이 끝나면 지운다 [3].
Volatility 3·YARA 래퍼와 `sift_recmd_query_key`는 파일 출력 위치를 주지 않고 표준 출력만 받는다 [6].
호출자가 목적지를 정하는 인자는 `sift_plaso_log2timeline`의 `output_storage_path` 하나다 [7].
저장된 파생물을 고치거나 지우는 도구는 없다.

**한계.** `sift_plaso_psort`는 `psort.py`에 로그 파일 위치(`--logfile`)와 작업 폴더를 주지 않는다 [2][8].
Plaso 20260720의 `psort.py`는 이때 서버 프로세스의 현재 폴더에 `psort-<날짜>T<시각>.log.gz` 로그 파일을 만든다 [9].

### D04.02 실제 경로와 허용 폴더 대조

**구현.** 이 방식은 `sift_plaso_log2timeline`의 저장 파일 경로 `output_storage_path`에 적용된다 [7].
허용 폴더는 환경변수 `DFIR_DERIVED_ROOT`를 실제 경로로 바꾼 값이고 이 환경변수가 없으면 시스템 임시 폴더 아래 `agentic-dfir-derived`다 [10].
`_safe_derived_path`는 절대 경로는 그대로, 상대 경로는 허용 폴더 뒤에 붙인 뒤 `resolve()`로 링크와 `..`를 해석한 실제 경로로 바꾼다 [11].
바꾼 경로가 허용 폴더 밖이면 `PathTraversalAttempt`로 거부한다 [11].
`sift_plaso_log2timeline`은 대조에 쓴 그 경로를 `--storage_file`로 넘긴다 [7].
허용 폴더 안의 링크가 밖을 가리키는 경로와 허용 폴더 밖의 절대 경로는 거부되었고 `..`가 든 절대 경로가 허용 폴더 안으로 해석되면 그 경로에 저장 파일이 생겼다 [12].

**한계.** 서버는 `log2timeline.py`에 로그 파일 위치(`--logfile`)와 작업 폴더를 주지 않는다 [7][8].
Plaso 20260720의 `log2timeline.py`는 이때 서버 프로세스의 현재 폴더에 `log2timeline-<날짜>T<시각>.log.gz` 로그 파일을 만든다 [9].
작업 프로세스는 같은 폴더에 그 이름 앞에 프로세스 이름을 붙인 로그 파일을 따로 만든다 [13].
그래서 이 로그 파일은 허용 폴더와 대조하지 않은 위치에 생긴다.
문서와 `sift_adapters`의 모듈 설명은 출력을 만드는 어댑터가 `DFIR_DERIVED_ROOT`나 호출마다의 임시 폴더에만 쓴다고 적는다 [14].

### D04.04 이름·확장자·충돌 검사

**구현.** 이 방식은 `sift_plaso_log2timeline`의 `output_storage_path`에 적용된다 [7].
`_safe_derived_path`는 빈 값과 널 문자가 든 값을 거부한다 [11].
상대 경로는 `\`를 `/`로 바꿔 조각으로 나누고 `.`나 `..` 조각이 있으면 거부한다 [11].
절대 경로에는 이 조각 검사를 하지 않고 실제 경로 대조만 한다 [11].
`sift_plaso_log2timeline`은 그 경로에 파일이나 폴더가 이미 있으면 `FileExistsError`로 거부하고 새 `output_storage_path`를 고르라고 알린다 [7].
상위 폴더는 이 검사와 실행 파일 확인보다 먼저 만들므로 실행 파일을 찾지 못해 실패한 호출도 없던 상위 폴더를 남긴다 [7][12].
저장 파일 이름의 확장자는 검사하지 않는다.
`../x.plaso`, `a/../b.plaso`, 널 문자가 든 값은 거부되었고 같은 경로로 다시 부르면 `FileExistsError`가 났다 [12].

```python
@contextmanager
def _tempdir(prefix: str = "dfir-sift-") -> Iterator[Path]:
    """Create + clean up a per-call temporary working directory."""
    d = tempfile.mkdtemp(prefix=prefix)
    try:
        yield Path(d)
    finally:
        shutil.rmtree(d, ignore_errors=True)
```

```python
    if not isinstance(path_str, str) or not path_str:
        raise PathTraversalAttempt(f"invalid derived path: {path_str!r}")
    if "\x00" in path_str:
        raise PathTraversalAttempt("null byte in derived path")

    root = _derived_root()
    raw = Path(path_str).expanduser()
    if raw.is_absolute():
        candidate = raw.resolve()
    else:
        norm = path_str.replace("\\", "/")
        parts = [p for p in norm.split("/") if p]
        if not parts or any(p in (".", "..") for p in parts):
            raise PathTraversalAttempt(f"invalid derived path: {path_str!r}")
        candidate = (root / Path(*parts)).resolve()

    try:
        candidate.relative_to(root)
    except ValueError as e:
        raise PathTraversalAttempt(
            f"derived path escapes {DERIVED_ROOT_ENV}: {path_str!r}"
        ) from e
    if must_exist and not candidate.exists():
        raise PathTraversalAttempt(f"derived path does not exist: {path_str!r}")
    return candidate
```
