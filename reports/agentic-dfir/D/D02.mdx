# D02 파생물 추적

### 미구현

**판단.** 서버가 남기는 파생물은 `sift_plaso_log2timeline`이 만든 Plaso 저장 파일과 Plaso의 로그 파일이고 서버는 이 파일을 그것을 만든 호출이나 사용한 입력과 잇는 값을 남기지 않는다 [1].
서버 진입점은 도구 호출을 받아 등록부의 `call_tool`에 넘기고 응답을 돌려줄 뿐 호출 기록을 쓰지 않는다 [2].
`sift_plaso_log2timeline`의 응답에는 증거 경로 `source_path`, 증거가 파일이면 그 SHA-256 `source_sha256`, 저장 파일 경로, 저장 파일의 SHA-256 `storage_sha256`이 함께 실린다 [1].
이 응답은 모델에게 돌아갈 뿐 서버가 파일이나 DB에 남기지 않는다 [1][2].
저장 파일 이름과 위치는 호출 인자 `output_storage_path`가 정하고 서버는 그 이름에 호출이나 입력을 가리키는 값을 넣지 않는다 [3].
저장 파일 곁에 manifest를 두지 않는다.
`sift_plaso_psort`의 응답은 읽은 저장 파일의 경로와 SHA-256을 싣고 그 저장 파일을 만든 호출이나 증거는 가리키지 않는다 [4].

Plaso 20260720의 `log2timeline.py`는 저장 파일 안의 `session` 항목에 명령줄 인자, 시작 시각, 세션 식별자를 남긴다 [5].
명령줄 인자에는 서버가 넘긴 저장 파일 경로와 증거 경로가 들어 있다 [1][5].
이 항목은 Plaso가 쓰는 것이고 서버는 그 값을 읽지 않으며 MCP 호출과 잇는 값도 없다 [1][4].

같은 저장소의 클라이언트가 남기는 기록은 서버 구현으로 보지 않고 사실로 적는다.
`dfir_agent`의 결정적 모드는 호출마다 도구 이름, 인자 `inputs`, 응답 JSON의 SHA-256 `output_digest`, 무작위 8자 `audit_id`를 `audit.jsonl`에 남긴다 [6].
결정적 모드가 쓰는 `report.json`의 발견사항은 근거 호출의 `audit_id`를 `audit_ids`로 가리킨다 [7].
live 모드의 `live_tool_calls.jsonl`에는 반복 번호, 도구 이름, 인자만 남고 응답이나 그 해시는 남지 않는다 [8].
