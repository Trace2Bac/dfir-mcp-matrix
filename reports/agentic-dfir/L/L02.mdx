# L02 기록 구성

### L02.05 결과 상태·실행 시점 기록

**구현.** 이 방식은 진입점 `dfir_mcp.server`의 `_handle`이 실패한 호출에 남기는 표준 오류 항목에 적용된다 [1].
항목 형식은 `basicConfig`에 준 `%(asctime)s [dfir-mcp] %(levelname)s %(message)s`이다 [2].
그래서 항목마다 시각, 수준, 메시지가 남는다 [2].
등록부에 없는 도구 이름은 `INFO` 수준의 `tool not found:` 항목으로 남는다 [1].
그 밖의 예외는 `ERROR` 수준의 `tool execution failed:` 항목으로 남고 예외 종류와 메시지 뒤에 예외 추적 정보가 붙는다 [1].
그래서 항목 하나가 그 호출이 실패했다는 결과 상태, 실패 원인, 시각을 담는다 [1][2].
항목은 `call_tool`이 예외를 올린 뒤에 쓰이므로 실패가 확정된 뒤의 상태다 [1].

항목에는 도구 이름과 인자를 담는 칸이 따로 없다 [1].
도구 이름은 예외 메시지에 실릴 때와 예외 추적 정보의 함수 이름으로만 보인다 [3][4].
등록부에 없는 이름과 인자 검사 오류의 예외 메시지는 도구 이름을 담는다 [3].
인자 값은 예외 메시지에 실릴 때만 남는다 [4].
증거 폴더 밖 경로로 부른 `get_amcache`의 항목에는 모델이 준 경로 `'../../etc/passwd'`가 남았다 [4].
결과의 크기, 행 수, 해시와 JSON-RPC 요청 `id`는 항목에 없다 [1].
한 호출에서 나온 여러 줄을 잇는 호출 ID도 없다 [1].

진입점 `dfir_mcp.server_stdio`는 호출 항목을 쓰지 않는다 [5].
클라이언트 `dfir_agent`가 쓰는 `audit.jsonl`과 `live_tool_calls.jsonl`은 클라이언트 기록이다 [6].

**한계.** 성공한 호출과 오류 결과를 예외 없이 돌려준 호출은 항목을 남기지 않는다 [1][4].
그래서 기록에 항목이 없다는 사실로는 호출이 성공했는지 호출이 없었는지 구별하지 못한다.

```python
@app.call_tool()
async def handle_call_tool(name: str, arguments: dict) -> list[TextContent]:
    """Execute a registered function. Any attempt to call something not in
    _REGISTRY raises the same KeyError the in-process path would raise."""
    try:
        result = call_tool(name, arguments or {})
        return [TextContent(
            type="text",
            text=json.dumps(result, default=str, indent=2),
        )]
    except KeyError as e:
        # Surface the ToolNotFound error as a structured result so the
        # agent can reason about it rather than crashing.
        return [TextContent(
            type="text",
            text=json.dumps({"error": "ToolNotFound", "detail": str(e)}),
        )]
    except Exception as e:
        return [TextContent(
            type="text",
            text=json.dumps({"error": type(e).__name__, "detail": str(e)[:500]}),
        )]
```

```python
    def _call(self, tool_name: str, inputs: dict, *,
              output_tokens: int = 500,
              finding_ids: list | None = None) -> tuple[dict, str]:
        """Invoke an MCP tool AND log it. Returns (output, audit_id).

        finding_ids forward-declares which findings this call will support
        so the audit chain is queryable via `dfir-audit trace <fid>`.
        """
        output = call_tool(tool_name, inputs)
        aid = self.audit.log(
            tool_name=tool_name,
            inputs=inputs,
            output=output,
            iteration=self.iteration,
            token_count_in=len(json.dumps(inputs)) // 4,   # rough proxy
            token_count_out=output_tokens,
            finding_ids=finding_ids or [],
        )
        return output, aid
```
