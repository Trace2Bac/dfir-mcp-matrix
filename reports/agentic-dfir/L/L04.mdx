# L04 기록 위변조 방지

### 미구현

**판단.** 서버 기록은 진입점 `dfir_mcp.server`의 `_handle`이 실패한 호출에 남기는 표준 오류 항목뿐이다 [1].
진입점 `dfir_mcp.server_stdio`는 호출 항목을 쓰지 않는다 [2].
서버는 기록 파일이나 DB를 만들지 않고 항목을 표준 오류로 내보낸다 [3].
항목 형식은 시각, 수준, 메시지뿐이고 앞 항목의 해시나 일련번호가 없다 [3].
표준 오류를 어디에 어떻게 남길지는 서버를 실행한 쪽이 정한다 [3].
저장소의 검증 명령 `python -m dfir_audit verify`는 클라이언트 기록 `audit.jsonl`의 연쇄만 다시 계산하고 서버의 표준 오류 항목은 읽지 않는다 [4].
그래서 서버 기록의 수정, 삭제, 순서 변경을 막거나 알아차리는 장치가 없다.

클라이언트 `dfir_agent`의 결정적 모드가 쓰는 `audit.jsonl`에는 SHA-256 연쇄가 있다 [5].
항목마다 앞 항목의 `entry_hash`를 `prev_hash`로 넣고 `prev_hash`를 포함한 본문의 SHA-256을 `entry_hash`로 둔다 [5].
`verify`는 첫 항목부터 `prev_hash`와 `entry_hash`를 다시 계산해 처음 어긋난 줄을 알리고 종료 코드 1을 돌려준다 [4].
연쇄 계산에는 키가 없다 [5].
결정적 모드는 실행을 마칠 때 끝 값 앞 16자를 표준 출력에 쓸 뿐 `report.json`에는 끝 값이나 항목 수를 남기지 않는다 [6].
`audit.jsonl`의 항목 하나를 고치거나 중간 줄을 지우거나 두 줄의 순서를 바꾸면 `verify`가 그 줄을 알렸다 [7].
마지막 줄을 지운 파일, 빈 파일, 항목을 고친 뒤 모든 해시를 다시 계산한 파일은 `verify`를 통과했다 [7].
`dfir_audit/README.md`는 내용 변경, 삭제, 순서 변경이 모두 연쇄 검증을 실패하게 한다고 적는다 [8].
live 모드의 `live_tool_calls.jsonl`에는 해시나 일련번호가 없다 [9].

[4] `verify`는 `audit.jsonl`의 `prev_hash`와 `entry_hash`를 다시 계산하고 CLI는 결과에 따라 종료 코드를 돌려준다.

```python
    @staticmethod
    def verify(path: str | Path) -> tuple[bool, str]:
        """Walk the chain end-to-end. Returns (ok, message)."""
        p = Path(path)
        if not p.exists():
            return False, f"audit log not found: {p}"

        prev = GENESIS_PREV_HASH
        n = 0
        with p.open("r", encoding="utf-8") as f:
            for lineno, raw in enumerate(f, 1):
                raw = raw.strip()
                if not raw:
                    continue
                obj = json.loads(raw)
                if obj["prev_hash"] != prev:
                    return False, f"line {lineno}: prev_hash mismatch (expected {prev[:10]}..., got {obj['prev_hash'][:10]}...)"
                body = {k: v for k, v in obj.items() if k != "entry_hash"}
                # `default=str` MUST match canonical_body() / log()
                # so verify reproduces the same canonical bytes when
                # inputs originally contained Path/datetime/etc.
                canonical = json.dumps(body, sort_keys=True, separators=(",", ":"), default=str)
                recomputed = hashlib.sha256(canonical.encode()).hexdigest()
                if recomputed != obj["entry_hash"]:
                    return False, f"line {lineno}: entry_hash mismatch (audit_id={obj['audit_id']})"
                prev = obj["entry_hash"]
                n += 1
        return True, f"chain verified: {n} entries, tail={prev[:16]}..."
```

    def canonical_body(self) -> str:
        """Everything except entry_hash, in canonical JSON form.

        `default=str` MUST match what AuditLogger.verify() uses below,
        otherwise hash recomputation drifts when inputs contain a
        non-JSON-native type (Path, datetime, etc.). Also matches the
        log-time output_digest serialization for consistency.
        """
        body = {k: v for k, v in asdict(self).items() if k != "entry_hash"}

        # _phase_hypothesis() never ran, self._primary / self._alt are
