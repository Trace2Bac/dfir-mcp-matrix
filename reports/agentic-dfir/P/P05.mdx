# P05 사건 자료 정리

### P05.03 자동 정리

**구현.** 이 방식은 Zimmerman 도구 래퍼 8개와 `sift_plaso_psort`가 호출마다 만드는 임시 폴더에 적용된다 [1][2].
공통 함수 `_tempdir`는 `tempfile.mkdtemp`로 `dfir-<도구 이름>-`으로 시작하는 폴더를 만들고 `finally`에서 `shutil.rmtree`로 폴더째 지운다 [1].
래퍼는 외부 도구가 CSV를 이 폴더에 쓰게 하고 그 CSV를 읽어 응답을 만든 뒤 `with` 블록을 나가며 폴더를 지운다 [2].
도구가 실패하거나 실행 파일을 찾지 못해 예외가 나도 폴더는 지워진다 [1].
CSV를 쓰는 대체 실행 파일로 부른 호출과 실행 파일이 없어 실패한 호출 뒤에 임시 폴더에는 `dfir-`로 시작하는 폴더가 남지 않았다 [3].
지운 사실은 응답이나 기록에 남지 않는다 [1][2].

`sift_plaso_log2timeline`이 `DFIR_DERIVED_ROOT` 아래에 쓰는 Plaso 저장 파일은 서버가 지우지 않는다 [4].
사건 자료를 지우거나 초기화하는 MCP 도구는 없고 서버가 끝날 때 따로 지우는 코드도 없다.

같은 저장소의 사용자 CLI `analyze.py`는 실행할 때마다 사례별 출력 폴더 `out/<tier>/<case-id>/` 아래에서 이름이 시각 꼴인 폴더를 최근 10개만 남기고 나머지를 지운다 [5].
지우는 폴더에는 그 실행의 대화 기록, 도구 호출 목록, 발견사항, 요약 파일이 들어 있다 [5][6].
지우기에 실패하거나 예외가 나도 알리지 않고 실행을 이어 간다 [5].
이 정리는 사용자 CLI가 하므로 서버를 다른 MCP 클라이언트로 부르면 일어나지 않는다.

**한계.** `_tempdir`는 `ignore_errors=True`로 지우므로 지우지 못해도 알리지 않고 증거에서 나온 CSV가 임시 폴더에 남는다 [1].

### P05.05 원본 증거를 삭제 대상에서 제외

**구현.** 이 방식은 자동 정리에 적용된다.
자동 정리가 지우는 대상은 그 호출에서 `tempfile.mkdtemp`가 시스템 임시 폴더에 만든 폴더 하나다 [1].
증거 경로는 외부 도구의 입력 인자로만 쓰이고 지우는 대상에 포함되지 않는다 [2].
대체 실행 파일로 래퍼 세 개를 부른 뒤 증거 폴더의 파일 목록은 부르기 전과 같았다 [3].

```python
@contextmanager
def _tempdir(prefix: str = "dfir-sift-") -> Iterator[Path]:
    """Create + clean up a per-call temporary working directory."""
    d = tempfile.mkdtemp(prefix=prefix)
    try:
        yield Path(d)
    finally:
        shutil.rmtree(d, ignore_errors=True)
```

```python
def _rotate_out_dirs(case_out_root: Path, keep: int = 10) -> None:
    """Keep only the most recent `keep` timestamped run dirs for one case.

    Every analyze run writes out/<tier>/<case-id>/<timestamp>/ with a transcript,
    tool-call log, findings, etc. Left unchecked this grows without bound — basic
    housekeeping says rotate it. We keep the newest `keep` runs per case (by the
    timestamp dir name, which sorts chronologically) and delete the rest. Only
    timestamp-shaped dirs are touched; anything else is left alone. Best-effort:
    a cleanup failure never blocks the run.
    """
    try:
        if not case_out_root.is_dir():
            return
        runs = sorted(
            (p for p in case_out_root.iterdir()
             if p.is_dir() and p.name.isdigit() is False
             and len(p.name) == 15 and "T" in p.name),
            key=lambda p: p.name,
        )
        for old in runs[:-keep] if len(runs) > keep else []:
            shutil.rmtree(old, ignore_errors=True)
    except Exception:  # noqa: BLE001 — housekeeping must not break the run
        pass
```
