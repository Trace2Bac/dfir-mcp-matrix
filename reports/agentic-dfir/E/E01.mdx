# E01 증거 등록 관리

### 미구현

**판단.** 서버는 환경변수 `DFIR_EVIDENCE_ROOT`가 가리키는 증거 폴더 아래의 파일과 폴더를 경로 인자로 받아 읽지만 증거를 식별하는 목록이나 등록 정보를 남기지 않는다 [1][2].
증거를 등록하는 MCP 도구는 없다 [3].
도구는 받은 경로를 실제 경로로 변환해 증거 폴더 안에 있는지만 확인하고 그 경로가 어느 증거 항목인지는 보지 않는다 [2].
외부 도구 래퍼는 같은 확인 뒤에 경로가 있는지를 더 본다 [4].

도구 응답 대부분은 호출마다 읽은 파일의 경로와 SHA-256을 `source`나 `metadata`에 싣는다 [5].
서버는 이 값을 저장하지 않고 다음 호출에서 다시 쓰지 않는다 [5].
`list_scheduled_tasks`는 Tasks 폴더의 파일마다 경로, 크기, SHA-256을 돌려주지만 이 목록도 호출마다 새로 만든다 [6].
증거 폴더 전체의 파일 목록을 돌려주는 도구는 없다 [3].

서버 진입점은 호출 기록을 쓰지 않는다 [7].
같은 저장소의 클라이언트 `dfir_agent`의 결정적 모드는 호출 기록 `audit.jsonl`에 도구 이름과 인자를 남긴다 [8].
그 항목에는 도구 출력 대신 출력 JSON의 SHA-256 `output_digest`만 남아 응답의 증거 해시는 기록에 값으로 남지 않는다 [8].
경로 인자가 호출 기록에 남는 것은 등록 정보가 아니다.

사용자 CLI `analyze.py`는 증거 폴더 아래 파일을 200개까지 상대 경로로 나열해 모델에게 주는 첫 지시에 넣는다 [9].
이 목록은 실행마다 새로 만들고 파일로 남기지 않으며 서버가 읽지 않는다 [9].
`analyze.py`의 오류 안내는 수집 어댑터 `dfir_collector_adapter`로 증거 폴더를 만들라고 적지만 그 어댑터는 이 저장소에 없다 [10].

```python
def _safe_resolve(path_str: str) -> Path:
    if not isinstance(path_str, str) or not path_str:
        raise PathTraversalAttempt(f"invalid path: {path_str!r}")
    if "\x00" in path_str:
        raise PathTraversalAttempt("null byte in path")
    if len(path_str) > 1024:
        raise PathTraversalAttempt(f"path too long: {len(path_str)} chars (max 1024)")
    root = EVIDENCE_ROOT.resolve()
    try:
        requested = (EVIDENCE_ROOT / path_str).resolve()
    except OSError as e:
        # File-name-too-long, no-such-process, etc. — treat as path attack
        raise PathTraversalAttempt(f"path resolution failed: {e}") from e
    try:
        requested.relative_to(root)
    except ValueError as e:
        raise PathTraversalAttempt(
            f"path escapes evidence root: {path_str!r} -> {requested}"
        ) from e
    return requested
```

    """
    Resolve an evidence path under EVIDENCE_ROOT, with read-access verification.

    All SIFT adapters MUST pass user-supplied paths through this function
    before invoking subprocess. This is the boundary that makes path
    traversal structurally impossible.
