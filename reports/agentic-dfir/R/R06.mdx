# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 증거에서 나온 값을 응답에 싣고 그 가운데 비밀 값을 가리거나 빼는 처리를 두지 않는다 [1][2].
기준 커밋의 저장소 전체에 값을 가리는 함수나 비밀 값 필드를 빼는 코드가 없다 [3].

`parse_registry_hive`는 하이브와 키를 가리지 않고 키 아래 값을 모두 싣는다 [1].
도구 설명은 읽을 하이브의 예로 SAM을 적는다 [1].
이진 값은 base64 문자열 `data_base64`로 그대로 싣는다 [4].
regipy 시험 자료의 SAM 하이브에서 사용자 키 `000001F4`를 읽자 값 `F`(80바이트)와 `V`(592바이트)가 base64로 모두 실렸다 [5].
`sift_recmd_query_key`는 RECmd가 출력한 키의 값을 표준 출력 그대로 `raw_output`에 싣는다 [6].

명령 줄과 로그 줄을 싣는 도구도 값을 가리지 않는다 [2][7].
`parse_bash_history`는 명령 줄을 그대로 `commands`에 싣는다 [2].
이 도구는 `--password=` 같은 꼴을 `password_in_command`로 표시하지만 표시한 명령의 글도 바꾸지 않고 싣는다 [2].
`mysql --password=S3cretPass db` 줄은 `commands`와 `suspicious` 두 곳에 비밀번호가 보이는 채로 실렸다 [5].
`analyze_unix_auth`는 sudo 명령 전체를, `parse_linux_text_log`는 로그 줄을 240자까지, `parse_systemd_journal`은 메시지를 500자까지 싣는다 [7].
`detect_nodejs_install_hooks`는 `package.json`의 설치 스크립트를, `scan_pth_files_for_supply_chain_iocs`는 `.pth` 파일의 앞 5줄을 싣는다 [8].

`detect_credential_file_access`는 SSH 키, 클라우드 자격증명, `.env` 파일의 내용을 읽지 않고 크기와 시각만 싣는다 [9].
`parse_bash_history`는 증거 루트 안의 어느 텍스트 파일이든 빈 줄이 아닌 줄을 명령으로 싣는다 [2].
그래서 같은 자격증명 파일을 이 도구로 읽으면 내용이 가림 없이 실린다 [2][9].

`server`는 실패한 호출만 예외 종류와 메시지를 표준 오류에 남기고 `server_stdio`는 호출 기록을 남기지 않는다 [10][11].
두 진입점 모두 보고서를 만들지 않는다 [10][11].
`server`의 이 항목에도 값을 가리는 처리가 없다 [10].
같은 저장소의 클라이언트 `dfir_agent`가 결정적 모드에서 쓰는 `audit.jsonl`은 도구 인자 값과 출력의 SHA-256 `output_digest`만 남기고 출력 값은 남기지 않는다 [12].
live 모드 `--dry-run`의 `live_tool_calls.jsonl`은 결과 글 앞 200자를 `output_preview`로 가림 없이 남긴다 [13].

```python
    def _serialize_value(v):
        """Convert python-registry value to a JSON-friendly dict.
        Binary data is base64-encoded with explicit type marker; numeric
        types pass through; strings are kept as-is.
        """
        try:
            vtype = v.value_type_str()
        except Exception:
            vtype = "REG_UNKNOWN"
        try:
            raw = v.value()
        except Exception as e:
            return {"name": v.name(), "type": vtype, "error": str(e)[:100]}
        if isinstance(raw, bytes):
            import base64
            return {"name": v.name(), "type": vtype,
                    "data_base64": base64.b64encode(raw).decode("ascii"),
                    "data_size": len(raw)}
        if isinstance(raw, (int, float, str, bool)) or raw is None:
            return {"name": v.name(), "type": vtype, "data": raw}
        if isinstance(raw, list):
            return {"name": v.name(), "type": vtype,
                    "data": [str(x) for x in raw]}
        return {"name": v.name(), "type": vtype, "data": str(raw)}
```

async def handle_call_tool(name: str, arguments: dict) -> list[TextContent]:
    """Execute a registered function. Any attempt to call something not in
    _REGISTRY raises the same KeyError the in-process path would raise."""
    try:
        result = call_tool(name, arguments or {})
        return [TextContent(
            type="text",
            text=json.dumps(result, default=str, indent=2),
        )]
    except KeyError as e:
        # Surface the ToolNotFound error as a structured result so the
        # agent can reason about it rather than crashing.
        return [TextContent(
            type="text",
            text=json.dumps({"error": "ToolNotFound", "detail": str(e)}),
        )]

        return [TextContent(
            type="text",
            text=json.dumps({"error": type(e).__name__, "detail": str(e)[:500]}),
        )]
