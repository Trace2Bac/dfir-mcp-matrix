# R04 도구 결과 해석 주의

### R04.01 도구별 정적 주의

**구현.** 이 방식은 `match_sigma_rules`의 도구 설명에 적용된다 [1].
설명은 이 도구를 발견사항을 알려진 탐지 패턴으로 뒷받침하는 데 쓰라고 적고 규칙이 일반 패턴이지 사건의 답이 아니라고 적는다 [1].
응답에는 같은 문구가 없다 [2].

다른 도구의 설명에는 결과가 증명하지 못하는 것이나 해석 한계를 적은 문구가 없다 [3].
`parse_shimcache`의 설명은 ShimCache를 실행과 마지막 수정의 증거라고 적고 해석 한계를 적지 않는다 [4].
서버는 MCP 지침, 리소스, 프롬프트를 두지 않는다 [5][6].

### R04.02 결과 조건별 주의

**구현.** 이 방식은 `parse_prefetch`의 네이티브 경로와 `analyze_event_logs`의 예약 작업 경고에 적용된다 [7][8].
`parse_prefetch`는 PECmd JSON 부속 자료가 없어 파일 이름만 읽은 응답에 `note`를 붙인다 [7].
`note`는 이 결과가 네이티브 읽기 결과이고 실행 횟수와 불러온 모듈은 PECmd를 실행해야 얻는다고 적는다 [7].
`analyze_event_logs`는 경고마다 규칙의 `description`을 싣고 예약 작업 생성 규칙의 설명은 정상 작업인지 검토하라는 문구를 담는다 [8].
이 규칙은 Security 4698 사건이면 내용과 관계없이 경고를 만든다 [8].

### R04.03 추가 확인 도구·증거 추천

**구현.** 이 방식은 Volatility 래퍼 세 개, `sift_amcacheparser_parse`, `match_sigma_rules`의 도구 설명, `parse_prefetch`의 `note`에 적용된다 [9][1][7].
`sift_vol3_windows_psscan`의 설명은 결과를 pslist와 대조하라고 적는다 [9].
`sift_vol3_windows_netscan`의 설명은 원격 주소를 위협 정보와 대조하라고 적는다 [9].
`sift_amcacheparser_parse`의 설명은 Amcache의 해시로 위협 정보를 찾아보라고 적는다 [10].
`sift_vol3_windows_malfind`의 설명은 주입된 영역에서 MZ 헤더를 찾아보라고 적는다 [9].
`match_sigma_rules`의 설명은 다른 도구로 얻은 발견사항을 이 도구로 뒷받침하라고 적는다 [1].
`parse_prefetch`의 `note`는 실행 횟수와 모듈을 보려면 PECmd를 실행하라고 적는다 [7].

**한계.** 서버에는 위협 정보를 조회하는 도구가 없고 서버 코드는 외부 서비스에 요청을 보내지 않는다 [11].
`parse_prefetch`의 `note`는 PECmd를 실행하는 MCP 도구 `sift_pecmd_parse`의 이름을 적지 않는다 [7][12].

```python
def parse_prefetch(prefetch_path):
    p = _safe_resolve(prefetch_path)
    if not p.exists():
        return {"error": "file_not_found", "path": str(p)}
    sidecar = p.with_suffix(".json")
    if sidecar.exists():
        data = json.loads(sidecar.read_text(encoding="utf-8"))
        data["source"] = {"path": str(p), "sha256": _sha256(p)}
        return data
    m = re.match(r"^(.+)-([0-9A-F]{8})\.pf$", p.name, re.IGNORECASE)
    if not m:
        return {"error": "bad_prefetch_name", "name": p.name}
    return {"source": {"path": str(p), "sha256": _sha256(p)},
            "executable": m.group(1), "path_hash": m.group(2),
            "size_bytes": p.stat().st_size,
            "note": "native reader — run PECmd for run counts and loaded modules"}
```
