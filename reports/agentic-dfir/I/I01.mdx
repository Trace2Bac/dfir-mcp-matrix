# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 스스로 외부에 연결하지 않는다.
`dfir_mcp`와 `dfir_corr`의 모듈은 네트워크 모듈(`socket`, `urllib.request`, `http`)이나 HTTP 클라이언트 라이브러리를 불러오지 않는다 [1].
모듈 안의 `socket`, `urllib`, `requests` 글자는 `_v05_supply_chain`이 증거 파일에서 찾는 정규식이다 [2].
`sift_adapters`의 래퍼는 분석 도구를 하위 프로세스로 실행하고 실행기 `run_tool`은 인자 배열, 시간 제한, 작업 폴더만 넘긴다 [3].
`correlate_timeline`과 `dfir_corr`는 DuckDB를 메모리 DB로 열고 넘겨받은 사건 목록만 넣는다 [4].
`match_sigma_rules`의 규칙 묶음과 `dfir_corr`의 상관 규칙은 저장소 안의 YAML 파일을 읽고 원격에서 갱신하지 않는다 [5].
서버는 처리 중에 모델 API를 부르지 않는다 [1].
Volatility 3, Plaso, DuckDB 같은 분석 도구와 라이브러리가 스스로 여는 연결은 서버 코드가 여는 연결이 아니다.

`scripts/install.sh`는 사용자가 실행해 파이썬 패키지, Volatility 3, Plaso, Zimmerman 도구를 내려받는 설치 스크립트다 [6].
서버 코드는 이 스크립트를 부르지 않는다 [6].

외부 연결은 클라이언트에 있다.
`dfir_agent`의 live 모드는 `anthropic` SDK로 Anthropic API에 모델 호출을 보낸다 [7].
`dfir_agent/auth.py`는 `ANTHROPIC_API_KEY`나 로컬 Claude 자격증명 파일로 그 클라이언트를 만든다 [8].
로컬 자격증명의 만료가 1시간 안이면 `refresh_oauth_token`이 `https://console.anthropic.com/v1/oauth/token`에 refresh token을 보내 새 토큰을 받는다 [9].
사용자 CLI `analyze.py`는 live 모드만 실행한다 [10].
결정적 모드는 등록부의 `call_tool`과 `AuditLogger`만 불러오고 외부에 연결하지 않는다 [11].

```python
_RULES_PATH = Path(__file__).resolve().parent.parent.parent / "correlation-rules.yaml"


def load_rules(path: Path | None = None) -> dict[str, Any]:
    """Load the correlation rule pack. Caller may override with a custom
    path for testing.

    The default location is dfir_corr/correlation-rules.yaml at the
    package root. If the file is missing or yaml is not installed, we
    return an empty rule set rather than raising — the engine's
    built-in joins still work, just without operator-tunable rules
    layered on top."""
    p = path or _RULES_PATH
    if not p.exists():
        return {"rules": [], "_loaded_from": None}
    try:
        import yaml  # type: ignore
    except ImportError:
        return {"rules": [], "_loaded_from": None,
                "_error": "pyyaml not installed; rule pack ignored"}
    try:
        data = yaml.safe_load(p.read_text()) or {}
        data["_loaded_from"] = str(p)
        return data
    except Exception as exc:
        return {"rules": [], "_loaded_from": str(p), "_error": str(exc)}
```
