# I03 외부 전송 범위 구성

### 비적용

**판단.** 서버 코드는 외부 서비스에 연결하지 않으므로 조사 자료를 보내지 않는다 [1].
서버 모듈은 네트워크 모듈이나 HTTP 클라이언트 라이브러리를 불러오지 않는다 [1].

서버가 실행하는 분석 도구는 스스로 외부에 요청을 보낼 수 있다.
Volatility 3 2.28.0은 Windows 커널의 심볼 표를 로컬에서 찾지 못하면 메모리 이미지에서 찾은 커널의 PDB 이름과 GUID를 넣은 주소로 Microsoft 심볼 서버에 요청한다 [2].
서버의 Volatility 3 래퍼는 이 요청을 끄는 `--offline`을 넘기지 않는다 [3].

클라이언트 `dfir_agent`의 live 모드는 시스템 프롬프트, 도구 정의, 대화 전체를 Anthropic API에 보낸다 [4].
대화에는 서버 도구가 돌려준 결과 글이 `tool_result`로 들어간다 [5].
`_truncate_tool_result`는 결과 글이 24,000자를 넘으면 앞 24,000자만 두고 안내문을 붙이며 그 밖에는 고치지 않는다 [5][6].
클라이언트 코드는 보내기 전에 결과 글의 값을 빼거나 가리지 않는다 [5][6].
사용자 CLI `analyze.py`는 증거 폴더의 파일 경로 목록을 최대 200개까지 첫 사용자 메시지에 넣는다 [7].
결정적 모드는 외부에 아무것도 보내지 않는다 [8].

            # At 4096 a rich multi-finding report was being truncated mid-JSON,

            # back to a normal full-price call. We put the marker on the LAST

            system=[{

                "text": SYSTEM_PROMPT,

```python
def _truncate_tool_result(text: str, cap: int = _MCP_RESULT_CHAR_CAP) -> str:
    """Cap an oversized tool result and append a guidance notice.

    Returns the text unchanged when it's within budget. When it exceeds
    the cap, keeps the leading `cap` characters (the start of a JSON
    document carries the schema + first records, which is what the model
    needs to decide how to narrow) and appends the truncation notice.
    """
    if len(text) <= cap:
        return text
    return text[:cap] + _TRUNCATION_NOTICE
```

```python
    def _call(self, tool_name: str, inputs: dict, *,
              output_tokens: int = 500,
              finding_ids: list | None = None) -> tuple[dict, str]:
        """Invoke an MCP tool AND log it. Returns (output, audit_id).

        finding_ids forward-declares which findings this call will support
        so the audit chain is queryable via `dfir-audit trace <fid>`.
        """
        output = call_tool(tool_name, inputs)
        aid = self.audit.log(
            tool_name=tool_name,
            inputs=inputs,
            output=output,
            iteration=self.iteration,
            token_count_in=len(json.dumps(inputs)) // 4,   # rough proxy
            token_count_out=output_tokens,
            finding_ids=finding_ids or [],
        )
        return output, aid
```
