# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버 코드가 읽는 환경변수는 증거 폴더 `DFIR_EVIDENCE_ROOT`, Plaso 저장 파일 폴더 `DFIR_DERIVED_ROOT`, Sigma 규칙 폴더 `DFIR_SIGMA_DIR`, 분석 도구 실행 파일 경로 `DFIR_*_BIN` 9개뿐이다 [2].
도구 인자에도 자격증명을 받는 칸이 없다 [3].

자격증명은 클라이언트 `dfir_agent`의 live 모드가 Anthropic API에 접속할 때 쓴다 [4].
`dfir_agent/auth.py`는 환경변수 `ANTHROPIC_API_KEY`나 로컬 Claude 자격증명을 읽는다 [4].
로컬 자격증명은 `CLAUDE_CREDENTIALS_FILE`이 가리키는 파일, `~/.claude/.credentials.json` 같은 정해 둔 파일, macOS Keychain에서 찾는다 [5].
모델 이름을 `-`로 나눈 두 번째 부분이 `haiku`이면 로컬 자격증명을 먼저 쓰고 그 밖의 모델은 `ANTHROPIC_API_KEY`만 쓴다 [4].
토큰을 새로 받으면 원래 파일에 다시 쓰고 파일 권한을 `0o600`으로 바꾼다 [6].
`auth.py`의 로그에는 자격증명 파일 경로와 고른 방식만 남는다 [4].

live 모드는 자기 환경변수 전체를 `env`로 넘겨 `dfir_mcp.server_stdio`를 실행한다 [7].
그래서 `ANTHROPIC_API_KEY`가 있으면 서버 프로세스와 서버가 실행하는 분석 도구의 환경에도 들어간다 [7][8].
서버 코드는 이 값을 읽지 않는다 [2].
Volatility 3 2.28.0 패키지 코드가 읽는 환경변수는 캐시와 설정 파일의 위치를 정하는 `XDG_CACHE_HOME`·`APPDATA`뿐이다 [9].

[5] 로컬 자격증명 파일을 찾는 차례다.

```python
_CREDENTIALS_CANDIDATES = [
    "~/.claude/.credentials.json",          # Linux default
    "~/.config/claude/credentials.json",    # XDG-style
    "~/Library/Application Support/claude/.credentials.json",  # macOS (when Keychain is not used)
]


def _find_credentials_file() -> Optional[Path]:
    """Return the first credentials file path that exists, or None."""
    # Explicit environment-variable override
    env_path = os.environ.get("CLAUDE_CREDENTIALS_FILE")
    if env_path:
        p = Path(env_path).expanduser()
        if p.is_file():
            return p

    for candidate in _CREDENTIALS_CANDIDATES:
        p = Path(candidate).expanduser()
        if p.is_file():
            return p
    return None
```
