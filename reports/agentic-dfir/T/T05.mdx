# T05 분석 도구 검증

### T05.01 저장소·의존성 고정

**구현.** 이 방식은 `match_sigma_rules`가 쓰는 Sigma 규칙 묶음 `dfir_sigma/`와 `correlate_timeline`이 불러오는 `dfir_corr/correlation-rules.yaml`에 적용된다 [1][2].
`dfir_sigma/`에는 묶음 정보 `pack.yml`과 규칙 파일 11개가 커밋되어 있고 `match_sigma_rules`는 기본으로 이 폴더를 읽는다 [1].
`dfir_corr`는 `correlation-rules.yaml`을 패키지 폴더 기준 고정 경로에서 읽어 규칙마다 사건 쌍을 질의하고 `contradictions`를 만든다 [2].
MCP의 `correlate_timeline`은 이 `contradictions`를 응답에 옮기지 않는다 [3].
IP-KVM 장치 ID 표 `IP_KVM_VID_PID`, 이벤트 규칙 `EVENT_RULES`, 악성 `.pth` 목록 `_KNOWN_MALICIOUS_PTH`, C2 명령 패턴 `_C2_PATTERNS` 같은 판단 목록은 서버 코드의 상수라 기준 커밋이 내용을 정한다 [4].

**한계.** 환경변수 `DFIR_SIGMA_DIR`가 있으면 `match_sigma_rules`는 커밋된 `dfir_sigma/` 대신 그 폴더의 규칙을 읽는다 [5].

분석 도구와 분석 라이브러리의 버전은 저장소에 고정되어 있지 않다.
`requirements.txt`와 `dfir_mcp`의 의존성은 python-registry를 `>=1.3.1`, DuckDB를 `>=1.5.3,<2.0`으로 적는다 [6].
설치 스크립트는 Volatility 3와 Plaso를 버전 없이 pip로 설치하고 YARA는 시스템 패키지 관리자로 설치한다 [7].
Zimmerman 도구는 버전이 들어 있지 않은 배포 주소에서 zip을 받아 풀고 받은 파일의 해시는 대조하지 않는다 [7].
RECmd 배치 파일은 저장소에 없고 서버는 `--bn`에 파일 이름만 넘긴다 [8].
Volatility 3 명령에는 심볼 위치 옵션이 없어 심볼 표는 Volatility 3의 기본 설정을 따른다 [9].

### T05.02 설정·호출 인자로 지정

**구현.** 이 방식은 외부 도구 실행 파일의 위치, Sigma 규칙 묶음의 위치, YARA 규칙 파일에 적용된다 [10][5][11].
래퍼는 `_which`로 실행 파일을 찾고 도구마다 정한 환경변수 `DFIR_VOLATILITY3_BIN`·`DFIR_YARA_BIN` 같은 `DFIR_*_BIN` 9개가 실행 파일 경로를 정한다 [10].
환경변수가 없으면 `PATH`에서 찾고 그다음 저장소의 `bin/`·`bin/zimmerman/`과 옆 폴더의 수집 어댑터 `bin/`에서 찾는다 [10].
`DFIR_SIGMA_DIR`가 있으면 `match_sigma_rules`는 저장소의 `dfir_sigma/` 대신 그 폴더의 `pack.yml`과 규칙 폴더를 읽는다 [5].
YARA 래퍼는 호출 인자 `rules_path`로 받은 규칙 파일을 쓰고 이 파일도 증거 폴더 안에 있어야 한다 [11].
서버는 이렇게 지정한 실행 파일이나 규칙 파일의 버전을 확인하지 않는다 [10][11].

**한계.** `DFIR_*_BIN`이 실행할 수 없는 파일을 가리키면 `_which`는 표준 오류에 경고를 쓰고 `PATH`에서 찾은 실행 파일을 쓴다 [10].
`DFIR_YARA_BIN`을 없는 경로로 두자 경고를 쓰고 `PATH` 검색으로 넘어갔다 [12].

### T05.04 참조 자료 버전·식별값 조회

**구현.** 이 방식은 `match_sigma_rules`에 적용된다 [13].
`match_sigma_rules`는 대조를 마친 뒤 묶음 폴더의 `pack.yml`을 다시 읽어 `version` 값을 응답의 `pack_version`에 넣는다 [13].
저장소의 `pack.yml`에서 이 값은 `v2`다 [1].

**한계.** 규칙 파일은 `pack.yml`의 `rules_dir` 아래 `*.yml`을 모두 읽고 `version` 값과 규칙 내용을 대조하지 않는다 [5][13].
`pack.yml`이 없으면 `pack_version`은 `null`이 되고 규칙은 그대로 읽는다 [5][13].
규칙 파일은 그대로 두고 `pack.yml`의 `version`만 `v99`로 바꾼 폴더와 `pack.yml`이 없는 폴더를 `DFIR_SIGMA_DIR`로 주자 같은 규칙 11개로 같은 2건이 대조되었고 `pack_version`은 각각 `v99`와 `null`이었다 [12].
모듈 주석은 가장 높은 버전의 묶음을 읽는다고 적지만 코드는 지정한 폴더 하나만 읽는다 [5].
`correlation-rules.yaml`의 버전은 읽지 않는다 [2].

```python
_RULES_PATH = Path(__file__).resolve().parent.parent.parent / "correlation-rules.yaml"


def load_rules(path: Path | None = None) -> dict[str, Any]:
    """Load the correlation rule pack. Caller may override with a custom
    path for testing.

    The default location is dfir_corr/correlation-rules.yaml at the
    package root. If the file is missing or yaml is not installed, we
    return an empty rule set rather than raising — the engine's
    built-in joins still work, just without operator-tunable rules
    layered on top."""
    p = path or _RULES_PATH
    if not p.exists():
        return {"rules": [], "_loaded_from": None}
    try:
        import yaml  # type: ignore
    except ImportError:
        return {"rules": [], "_loaded_from": None,
                "_error": "pyyaml not installed; rule pack ignored"}
    try:
        data = yaml.safe_load(p.read_text()) or {}
        data["_loaded_from"] = str(p)
        return data
    except Exception as exc:
        return {"rules": [], "_loaded_from": str(p), "_error": str(exc)}
```

```python
def _repo_bin_dirs() -> list[Path]:
    """Directories the installer stages tool binaries into, searched after
    PATH so an explicit system install or env override always wins. Covers
    both the EZ Tools staging dir (bin/zimmerman/<Tool>/) and the adapter's
    own bin/ (Velociraptor). Resolved relative to this file so it works from
    any CWD and from a fresh clone without environment setup."""
    # _common.py lives at .../dfir_mcp/src/dfir_mcp/sift_adapters/_common.py
    # repo root is five parents up.
    here = Path(__file__).resolve()
    repo = here.parents[4]
    dirs = [
        repo / "bin",
        repo / "bin" / "zimmerman",
        # adapter checkout sits beside the main repo
        repo.parent / "agentic-dfir-collector-adapter" / "bin",
    ]
    return [d for d in dirs if d.is_dir()]
```
