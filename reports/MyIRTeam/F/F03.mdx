# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버 4개는 처리 중에 모델을 부르지 않는다.
네 서버의 의존성 파일은 MCP Python SDK(`mcp>=1.27,<2`) 하나만 적고 모델 API 클라이언트는 없다 [1].
네 서버는 `FastMCP`에 도구만 등록하고 MCP sampling으로 클라이언트 모델에게 생성을 요청하지 않는다 [2][3].
`myirteam-core`의 `resolve_investigation_intent`는 `agent-manifest.json`의 키워드 규칙으로 워크플로를 고르고 모델을 쓰지 않는다 [4].
`ir-collect`가 실행하는 `IR_Collect.exe` 0.24.2의 `-analyze` 경로는 사실 저장소를 만들고 Guided Hunt 규칙을 적용해 요약 JSON을 쓸 뿐 모델을 부르지 않는다 [5].
워크플로의 `agent_reasoning` 상태는 `owner`가 `calling_ai_agent`이고 서버가 실행하는 단계가 아니다 [6].
`.agents/agents.md`도 역할 이름이 모두 같은 클라이언트 모델의 작업 단계라고 적는다 [7].
