# I04 서버 자격증명 처리

### 비적용

**판단.** 네 서버의 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버 코드가 읽는 환경변수는 증거 폴더, 작업 폴더, 시간 제한, 크기 상한, 분석 도구 실행 파일 경로와 기대 해시, YARA 규칙 폴더, 수집 허용 여부를 정하는 값이다 [2].
이 가운데 자격증명은 없다 [2].
도구 45개의 입력 schema에도 키, 토큰, 비밀번호, 자격증명을 받는 속성이 없다 [3].
사용자 CLI `portable_setup.py`가 만드는 클라이언트 설정의 환경변수도 `PYTHONUTF8`, `PYTHONUNBUFFERED`, `MYIRTEAM_ROOT`, 증거 폴더, YARA 규칙 폴더, 분석 도구의 기대 해시뿐이다 [4].

`IR_Collect.exe` 0.24.2의 설정 항목에는 `VirusTotalApiKey`, `AiApiKey`, `UploadApiKey`가 있다 [5].
이 가운데 `AiApiKey`와 `UploadApiKey`는 GUI의 AI 분석 요청과 수집 ZIP 업로드가 쓴다 [5].
`VirusTotalApiKey`는 설정 화면에서 읽고 쓰기만 한다 [5].
`ir-collect`가 쓰는 명령행 경로 `-analyze`, `-correlate`, `-graph`, `-c`는 이 값을 쓰는 코드를 부르지 않는다 [5].
