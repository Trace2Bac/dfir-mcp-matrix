# I03 외부 전송 범위 구성

### 비적용

**판단.** 네 서버의 코드는 외부 서비스에 연결하지 않으므로 조사 자료를 보내지 않는다 [1].
서버 파일, `myirteam_common/evidence.py`, `portable_mcp.py`는 네트워크 모듈이나 HTTP 클라이언트 라이브러리를 불러오지 않는다 [1].
서버가 실행하는 분석 도구의 외부 전송 기능도 서버는 켜지 않는다.
`sigcheck.exe`와 `autorunsc.exe`의 `-v`는 파일 해시로 VirusTotal을 조회하고 `s`를 붙이면 조회되지 않은 파일을 올린다 [2].
`local-forensic`은 두 도구에 `-v`를 넘기지 않는다 [3].
`IR_Collect.exe` 0.24.2는 수집 ZIP 업로드와 분석 요약의 AI 분석 요청을 GUI 처리기에서만 보낸다 [4].
`ir-collect`가 쓰는 명령행 경로 `-analyze`, `-correlate`, `-graph`, `-c`는 이 코드를 부르지 않는다 [4].
