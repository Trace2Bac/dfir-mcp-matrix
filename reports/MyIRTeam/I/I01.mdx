# I01 외부 연동 대상 관리

### 비적용

**판단.** 네 서버의 코드는 스스로 외부에 연결하지 않는다 [1].
`myirteam-core`, `local-forensic`, `ir-collect`, `artifact-forensic`의 서버 파일, `myirteam_common/evidence.py`, `portable_mcp.py`는 네트워크 모듈(`socket`, `urllib`, `http`)이나 HTTP 클라이언트 라이브러리를 불러오지 않는다 [1].
서버 코드가 읽는 환경변수는 증거 폴더, 작업 폴더, 시간 제한, 크기 상한, 분석 도구 실행 파일 경로와 기대 해시, YARA 규칙 폴더, 수집 허용 여부를 정하고 접속 주소를 정하는 값은 없다 [2].
도구 45개의 입력 schema에도 호스트, URL, 서버 주소를 받는 속성이 없다 [3].
`local-forensic`의 `collect_network_context`는 대상 시스템의 DNS 캐시, 경로, 이웃, 프록시 설정을 PowerShell로 읽을 뿐 외부 연결을 열지 않는다 [4].
`get_external_tool_inventory`는 manifest와 실행 파일 해시만 읽고 서버가 분석 도구를 내려받거나 갱신하지 않는다는 안내를 응답에 싣는다 [5].
`External Tools/README.md`는 사용자가 분석 도구를 공식 출처에서 직접 받아 정해 둔 경로에 두라고 적는다 [6].

서버가 실행하는 분석 도구 가운데 평판 조회나 업로드 기능이 있는 도구도 서버는 그 기능을 켜지 않는다.
`local-forensic`은 `sigcheck.exe`와 `autorunsc.exe`에 VirusTotal 조회 옵션 `-v`를 넘기지 않는다 [7].
`IR_Collect.exe` 0.24.2의 ZIP 업로드와 AI 분석 요청은 GUI 처리기에만 있다 [8].
`ir-collect`가 쓰는 명령행 경로 `-analyze`, `-correlate`, `-graph`, `-c`는 이 코드를 부르지 않는다 [8].
분석 도구가 스스로 여는 통신은 서버 코드가 여는 연결이 아니다.

[4] `collect_network_context`는 대상 시스템의 로컬 정보를 읽는 cmdlet과 레지스트리 값만 쓴다.

```python
    script = r'''
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$maxEntries = [int]$env:FORENSIC_MAX_ENTRIES
$errors = @(); $dns = @(); $routes = @(); $neighbors = @(); $proxy = $null
try { $dns = @(Get-DnsClientCache -ErrorAction Stop | Select-Object -First $maxEntries Entry, Name, Data, Type, Status, TimeToLive) } catch { $errors += "Get-DnsClientCache: $($_.Exception.Message)" }
try { $routes = @(Get-NetRoute -ErrorAction Stop | Sort-Object RouteMetric | Select-Object -First $maxEntries DestinationPrefix, NextHop, InterfaceAlias, RouteMetric, State, Protocol) } catch { $errors += "Get-NetRoute: $($_.Exception.Message)" }
try { $neighbors = @(Get-NetNeighbor -ErrorAction Stop | Select-Object -First $maxEntries IPAddress, LinkLayerAddress, State, InterfaceAlias) } catch { $errors += "Get-NetNeighbor: $($_.Exception.Message)" }
try {
    $proxyKey = Get-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' -ErrorAction Stop
    $proxy = [PSCustomObject]@{ proxy_enable = $proxyKey.ProxyEnable; proxy_server = $proxyKey.ProxyServer; auto_config_url = $proxyKey.AutoConfigURL }
} catch { $errors += "ProxyContext: $($_.Exception.Message)" }
[PSCustomObject]@{ dns_cache = $dns; routes = $routes; neighbors = $neighbors; proxy = $proxy; errors = $errors } | ConvertTo-Json -Compress -Depth 7
'''
```
