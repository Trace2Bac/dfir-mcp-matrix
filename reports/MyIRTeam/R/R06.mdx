# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 세 증거 서버는 증거에서 나온 값을 응답에 싣고 그 가운데 비밀 값을 가리거나 빼는 처리를 두지 않는다.
네 서버와 공통 모듈의 코드에는 값을 가리는 함수가 없다 [1].
서버 코드에는 호출 기록이나 보고서를 파일로 쓰는 곳이 없으므로 증거 값이 나가는 곳은 응답이다 [1].

`local-forensic`은 대상 호스트에서 읽은 글을 그대로 싣는다 [2][3][4].
사건 조회는 사건마다 메시지 12,000자와 `properties` 값 전체를 싣고 PowerShell 채널의 4103·4104 사건도 `collect_ir_event_bundle`이 읽는 고정 목록에 포함된다 [2].
`list_running_processes`는 프로세스의 명령 줄 전체를, `list_scheduled_tasks`는 작업의 실행 인자를, `list_wmi_subscriptions`는 명령 줄 템플릿과 스크립트 본문 `ScriptText`를 싣는다 [3].
`collect_autoruns`·`list_open_handles`는 Sysinternals 출력을 그대로 돌려준다 [4].
`list_local_users_and_admins`는 `Get-LocalUser`에서 계정 이름, 상태, 시각, SID, 설명만 고른다 [5].

`artifact-forensic`은 EZ Tools CSV의 열 값을 2,000자까지, Hayabusa 레코드를 그대로 싣는다 [6][7].
레지스트리 하이브는 RECmd 배치 파일이 고른 키의 값 `ValueData`가 그대로 실린다 [6][8].
`inspect_binary_file`은 파일에서 뽑은 출력 가능 문자열을 500개까지 싣는다 [9].

`ir-collect`는 IR_Collect 요약의 Guided Hunt `evidence` 줄을 그대로 싣는다 [10].
이 줄에는 사실의 사용자, 경로와 120자를 넘으면 앞 117자로 자른 상세 설명이 들어 있다 [11].
IR_Collect 0.24.2에는 IP 주소, 메일 주소, 경로를 가리는 `SummaryPayloadAiRedactor`가 있다 [12].
이 함수는 GUI의 AI 내보내기에서만 쓰이고 서버가 실행하는 `-analyze`는 가림 없이 요약을 쓴다 [12][13].

`evidence_v1`과 `legacy` 형식은 이 결과를 똑같이 싣는다 [14].

```python
def extract_bounded_strings(path: Path, max_strings: int) -> dict[str, Any]:
    values: list[dict[str, str]] = []
    seen: set[tuple[str, str]] = set()
    truncated = False
    carry = b""
    with open(path, "rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            data = carry + chunk
            for encoding, pattern in (("ascii", ASCII_STRING_RE), ("utf-16le", UTF16LE_STRING_RE)):
                for match in pattern.finditer(data):
                    raw = match.group(0)
                    text = raw.decode(encoding, errors="replace")
                    key = (encoding, text)
                    if key in seen:
                        continue
                    seen.add(key)
                    if len(values) >= max_strings:
                        truncated = True
                        break
                    values.append({"encoding": encoding, "value": _bounded_text(text, 500) or ""})
                if truncated:
                    break
            if truncated:
                break
            carry = data[-4096:]
    return {"strings": values, "returned_string_count": len(values), "truncated": truncated}
```
