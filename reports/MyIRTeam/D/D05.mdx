# D05 파생물 저장 실패 처리

### D05.01 오류·부분 완료 표시

**구현.** 이 방식은 `collect_triage_package`가 수집 ZIP을 남기는 경로, `ir-collect`의 분석 도구에서 `IR_Collect.exe`가 파생 CSV를 쓰는 경로, `artifact-forensic`의 Hayabusa 분석에서 Hayabusa가 오류 로그를 쓰는 경로에 적용된다 [1][2][3].

`collect_triage_package`는 수집 폴더를 만들지 못하면 `error`를 담은 결과로 끝낸다 [1].
`IR_Collect.exe`를 실행한 뒤 수집 폴더에 `<evidence_id>.zip`이 없으면 `error`, 종료 코드, 표준 출력과 표준 오류의 끝 2,000자를 돌려준다 [1].
공통 응답 형식은 결과에 `error`가 있으면 응답의 `status`를 `FAILED`로 두고 그 문장을 `errors`에 싣는다 [4].
ZIP이 있으면 크기와 SHA-256을 구하는 `stat`·`sha256_file`에서 난 `OSError`를 처리하지 않아 예외가 MCP SDK까지 올라간다 [5].
MCP Python SDK 1.28.1은 도구에서 올라온 예외를 `isError`가 참인 결과로 돌려준다 [6][7].
작업 폴더를 만들 수 없게 해 `analyze_artifact_folder`에서 예외가 나게 하자 응답은 `isError`가 참이고 글은 `Error executing tool analyze_artifact_folder:`로 시작했다 [6].
`IR_Collect.exe`가 해시 파일을 쓰지 못하면 응답의 `sha256_sidecar_present`가 거짓으로 나가지만 같은 이름의 해시 파일이 앞 실행에서 남아 있으면 참으로 나간다 [5][8].

`IR_Collect.exe` 0.24.2는 원시 하이브와 SRUM DB에서 CSV를 만들다 실패하면 그 사실을 `load_warnings`에 적는다 [2].
EVTX 필터 CSV를 만들지 못한 로그가 있으면 다시 만든 수와 전체 수를 적은 경고를 `load_warnings`에 더한다 [9].
`ir-collect`는 요약의 `load_warnings`를 앞 50개까지 응답에 옮긴다 [10].
시험용 실행 파일이 요약에 경고 한 줄을 넣게 하자 그 줄은 응답의 `load_warnings`에 실렸다 [11].

Hayabusa 3.10.0은 오류 로그 파일을 만들지 못하면 panic으로 끝나 0이 아닌 종료 코드를 낸다 [3].
`artifact-forensic`은 타임라인 JSONL이 있으면 그 종료 코드로 응답의 `status`를 `DEGRADED`로 두고 경고를 싣지만 실패한 것이 오류 로그 쓰기라는 사실은 싣지 않는다 [12].

호출 안에서 지우는 작업 폴더의 출력은 보관하는 파생물이 아니다.
그 출력이 생기지 않으면 `ir-collect`는 `IR_Collect.exe`의 종료 코드와 출력 일부를 담은 오류를, `artifact-forensic`은 도구 이름과 출력이 없다는 오류를 돌려준다 [13][14].

**한계.** 서버는 수집 ZIP이 있는지만 보고 이번 실행이 쓴 파일인지 가리지 않는다 [1].
`IR_Collect.exe` 0.24.2는 ZIP으로 묶기 직전에만 같은 이름의 ZIP을 지운다 [8].
그래서 묶기 전에 수집이 예외로 끝나면 앞 실행이 남긴 같은 이름의 ZIP이 그대로 있고 서버는 그 ZIP의 크기와 해시를 담은 결과를 돌려준다 [1][8][15].
`IR_Collect.exe` 0.24.2는 수집 단계나 ZIP 해시 계산이 실패해도 ZIP을 남기고 종료 코드 2로 끝난다 [8][15].
해시 파일을 쓰다 예외가 나면 ZIP을 남긴 채 종료 코드 1로 끝난다 [8][15].
두 경우 모두 서버는 `exit_code`를 결과에 싣지만 실패를 적은 표준 출력은 버리고 응답의 `status`는 `SUCCESS`로 나간다 [5][4].
`evidence_id`에 `.`가 들어가면 `IR_Collect.exe`는 그 글자를 `_`로 바꾼 이름으로 ZIP을 쓰고 서버는 바꾸지 않은 이름을 찾으므로 ZIP이 생겨도 오류를 돌려준다 [1][16].
`load_warnings`에 경고가 있어도 응답의 `status`는 `SUCCESS`로 나간다 [4][11].
수집 경로는 `collect_triage_package`를 켜지 않아 실행하지 않았고 서버 코드와 `IR_Collect.exe` 소스로만 확인했다 [1][8].
Hayabusa가 오류 로그를 쓰지 못하는 경로도 실행하지 않았고 Hayabusa 소스로만 확인했다 [3].

### D05.03 알림 없이 계속

**구현.** 이 방식은 `ir-collect`의 분석 도구에 `work_on_copy`를 거짓으로 줄 때 `IR_Collect.exe`가 증거 폴더에 쓰는 `Registry/shellbags.csv`와 `IR_Collect.exe`가 실행 파일 폴더에 쓰는 로그 파일에 적용된다 [17][18].

`IR_Collect.exe`는 로그 파일 `logs/ir_collect.log`에 쓰다 난 예외도 버린다 [18].
서버는 이때도 `SUCCESS` 응답을 돌려준다 [4].

def infer_status_and_messages(data: Any) -> tuple[str, list[dict[str, Any]], list[dict[str, Any]]]:
    """Infer transport status without making a security assessment."""
    errors: list[dict[str, Any]] = []
    limitations = _top_level_note(data)

    if isinstance(data, str):
        stripped = data.strip()
        if _is_error_text(stripped):
            errors.append(_message("TOOL_ERROR", stripped))
            return "FAILED", errors, limitations
        return "SUCCESS", errors, limitations

    if not isinstance(data, dict):
        return "SUCCESS", errors, limitations

    if data.get("error"):
        errors.append(_message("TOOL_ERROR", data.get("error")))
        details = data.get("details")
        if details:
            errors.append(_message("TOOL_ERROR_DETAILS", details))
        return "FAILED", errors, limitations

    explicit = str(data.get("status") or "").upper()
    if explicit in {"FAILED", "ERROR"}:
        errors.append(_message("TOOL_STATUS_FAILED", data.get("message") or explicit))
        return "FAILED", errors, limitations
    degraded = explicit in {"DEGRADED", "PARTIAL"}

def safe_evidence_id(evidence_id: str) -> str:
    """Validate/normalize an evidence id used as the ZIP basename. Empty -> generated.
    Rejects path separators, traversal, and unsafe characters."""
    eid = (evidence_id or "").strip()
    if not eid:
        return "triage_" + uuid.uuid4().hex[:8]
    if not EVIDENCE_ID_RE.match(eid):
        raise ValueError("evidence_id must be 1-64 chars of letters/digits/dot/dash/underscore, "

    return eid
