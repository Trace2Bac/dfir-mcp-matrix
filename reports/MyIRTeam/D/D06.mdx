# D06 산출물 식별·재생성 처리

### D06.02 입력·작업별 고유 이름

**구현.** 이 방식은 `evidence_id`를 비워 부른 `collect_triage_package`의 수집 ZIP 이름과 `artifact-forensic`이 실행하는 Hayabusa의 오류 로그 파일 이름에 적용된다 [1][2].
`evidence_id`가 비어 있으면 서버는 `uuid4`의 16진수 앞 8자를 붙인 `triage_<난수>`를 ID로 지어 `IR_Collect.exe`에 넘긴다 [1].
그래서 다시 수집하면 다른 이름의 ZIP과 해시 파일이 생기고 앞 ZIP은 남는다 [1][3].
Hayabusa 3.10.0은 오류 로그 파일 이름을 `errorlog-YYYYMMDD_HHMMSS.log`로 지어 실행 시각을 초 단위로 넣는다 [2].
이 이름 규칙은 서버 코드가 아니라 Hayabusa가 정한다.

`evidence_id`를 주면 그 값이 ZIP 이름이 된다 [1].
같은 `evidence_id`로 다시 수집하면 `IR_Collect.exe` 0.24.2가 묶기 직전에 앞 ZIP을 지우고 새 ZIP을 쓰며 해시 파일도 덮어쓴다 [3][4].
앞 실행의 `IR_Output_<ID>` 폴더가 남아 있으면 그 폴더를 새로 만들지 않고 그 안에 다시 모은 뒤 묶는다 [5].
서버는 같은 이름의 ZIP이 이미 있는지 보지 않는다 [6].
`IR_Collect.exe` 0.24.2의 `logs/ir_collect.log`는 이름이 하나로 고정되어 있고 실행마다 그 뒤에 시각을 붙인 줄을 이어 쓴다 [7].
`ir-collect`의 `run_<난수>` 폴더와 `artifact-forensic`의 호출마다 만드는 폴더는 이름이 호출마다 다르지만 호출이 끝나면 지운다 [8][9].

**한계.** Hayabusa를 같은 초 안에 다시 실행해 오류가 나면 오류 로그 파일 이름이 같다 [2].
Hayabusa 3.10.0은 그 파일을 `File::create`로 열어 앞 파일을 알리지 않고 덮어쓴다 [2].

### D06.04 덮어쓰기 선택·충돌 감지

**구현.** 이 방식은 `ir-collect`의 분석 도구에서 `IR_Collect.exe`가 분석하는 폴더에 쓰는 파생 CSV에 적용되고 이 규칙은 서버 코드가 아니라 `IR_Collect.exe` 0.24.2가 정한다 [10][11].
`amcache_programs.csv`·`amcache_files.csv`, `shimcache_entries.csv`, `srum_app_usage.csv`·`srum_network_usage.csv`는 함께 만드는 파일 가운데 하나라도 이미 있으면 다시 만들지 않는다 [10].
EVTX 곁의 `<로그 이름>_filtered.csv`는 이미 있고 크기가 0보다 크면 다시 만들지 않고 그 파일을 분석에 쓴다 [11].
`Registry/shellbags.csv`는 이미 있고 `ShellBags_*.reg` 파일 가운데 그 CSV보다 2초 넘게 늦게 고친 것이 없으면 다시 만들지 않는다 [12].
`work_on_copy`가 참이면 호출마다 새 사본에 쓰므로 앞 호출이 쓴 CSV가 없다 [13].
`work_on_copy`가 거짓이면 앞 호출이 증거 폴더에 쓴 CSV가 남아 다음 호출에서 그 CSV를 다시 만들지 않고 쓴다 [13][10][11].
덮어쓸지 고르는 호출 인자는 없다.

`artifact-forensic`은 Hayabusa에 기존 출력 파일을 덮어쓰게 하는 `-C`를 주지만 출력 위치가 호출마다 새로 만든 폴더라 앞 파일이 없다 [9].

**한계.** 크기가 0인 `<로그 이름>_filtered.csv`는 알리지 않고 다시 쓴다 [11].
`ShellBags_*.reg` 파일이 CSV보다 늦게 고쳐졌으면 `Registry/shellbags.csv`를 알리지 않고 덮어쓴다 [12].
이미 있는 CSV가 수집 때 들어 있던 것인지 앞 분석이 쓴 것인지 가리지 않는다 [10][11].

```python
def safe_evidence_id(evidence_id: str) -> str:
    """Validate/normalize an evidence id used as the ZIP basename. Empty -> generated.
    Rejects path separators, traversal, and unsafe characters."""
    eid = (evidence_id or "").strip()
    if not eid:
        return "triage_" + uuid.uuid4().hex[:8]
    if not EVIDENCE_ID_RE.match(eid):
        raise ValueError("evidence_id must be 1-64 chars of letters/digits/dot/dash/underscore, "
                         "with no path separators.")
    return eid
```
