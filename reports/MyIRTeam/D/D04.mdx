# D04 출력 경로 제한

### D04.01 서버가 출력 위치 결정

**구현.** 이 방식은 `ir-collect`의 작업 폴더와 수집 폴더, `artifact-forensic`의 작업 폴더에 서버와 분석 도구가 쓰는 파일에 적용된다 [1][2].
두 서버의 작업 폴더와 수집 폴더는 환경변수로 정하고 호출 인자로는 바꿀 수 없다 [1][2].
`ir-collect`의 작업 폴더는 `IRCOLLECT_WORK_DIR`이고 이 값이 없으면 시스템 임시 폴더 아래 `ir-collect-mcp`다 [1].
수집 폴더는 `IRCOLLECT_COLLECT_DIR`이고 이 값이 없으면 작업 폴더 아래 `collections`다 [1].
`artifact-forensic`의 작업 폴더는 `ARTIFACT_WORK_DIR`이고 이 값이 없으면 시스템 임시 폴더 아래 `artifact-forensic-mcp`다 [2].

`ir-collect`는 분석 호출마다 작업 폴더 아래 `run_<난수>` 폴더를 만든다 [3].
그 안에 증거 사본 `input_<폴더 이름>`이나 `input_<번호>_<폴더 이름>`, ZIP을 푼 `extracted`, `IR_Collect.exe`에 출력 위치로 주는 `summary.json`·`corr.json`·`graph.json`을 서버가 정한 이름으로 둔다 [3][4].
사본 이름에 들어가는 호출 입력은 증거 폴더 실제 경로의 마지막 이름 하나다 [3].
`collect_triage_package`는 수집 폴더를 현재 폴더로 `IR_Collect.exe -c`를 실행하고 그 폴더의 `<evidence_id>.zip`을 찾는다 [5].
`evidence_id`는 경로 구분자가 없는 이름 한 조각으로만 받고 비어 있으면 서버가 `triage_<난수>`로 짓는다 [6].
`IR_Collect.exe` 0.24.2는 현재 폴더에 `IR_Output_<ID>` 폴더, `<ID>.zip`, `<ID>.zip.sha256`을 쓴다 [7].

`artifact-forensic`은 호출마다 작업 폴더 아래 `run_`·`eztool_`·`capa_`·`yara_`·`archive_member_` 접두어에 난수를 붙인 폴더를 만든다 [8].
Zimmerman 도구에는 그 폴더를 `--csv`로, `result.csv`를 `--csvf`로 준다 [9].
PECmd와 AmcacheParser는 그 폴더 안에 `result`를 앞에 붙인 CSV를 더 쓴다 [10].
Hayabusa에는 그 폴더의 `timeline.jsonl`을 `-o`로 주고 capa와 YARA의 표준 출력과 표준 오류는 그 폴더의 `stdout.bin`·`stderr.bin`에 받는다 [11][12].
ZIP 항목 사본은 `archive_member_<난수>/member/` 아래 항목 경로의 마지막 이름으로 둔다 [13].
시험용 EvtxECmd가 받은 인자는 `--csv`에 작업 폴더 아래 `eztool_<난수>` 폴더, `--csvf`에 `result.csv`였다 [14].

호출 인자로 목적지를 받는 도구는 없다.
저장된 파생물을 고치거나 지우는 도구도 없다.
`local-forensic`과 `myirteam-core`는 파일을 만들지 않는다 [15].

**한계.** `analyze_artifact_folder`·`correlate_hosts`·`expand_investigation_graph`에 `work_on_copy`를 거짓으로 주면 `IR_Collect.exe`가 호출 인자로 받은 증거 폴더 안에 파생 CSV를 쓴다 [4][16].
이 폴더는 `IRCOLLECT_EVIDENCE_ROOTS` 아래인지 대조하지만 그 목록은 읽을 증거의 위치를 허용하는 목록이다 [17].
`IR_Collect.exe` 0.24.2는 작업 폴더가 아니라 자기 실행 파일 폴더의 `logs/ir_collect.log`에 쓴다 [18].
`artifact-forensic`은 Hayabusa를 그 실행 파일 폴더에서 실행하고 `-Q`를 주지 않는다 [11].
Hayabusa 3.10.0은 오류가 있으면 현재 폴더의 `logs` 아래에 오류 로그 파일을 쓰므로 그 파일은 작업 폴더 밖의 Hayabusa 폴더에 생긴다 [19].
`IR_Collect.exe` 0.24.2는 받은 ID에서 영문자, 숫자, `-`, `_`가 아닌 글자를 `_`로 바꿔 파일 이름을 짓는다 [20].
서버는 `.`가 들어간 `evidence_id`를 받아 바꾸지 않은 이름으로 ZIP을 찾으므로 이 경우 서버가 찾는 이름과 `IR_Collect.exe`가 쓰는 이름이 다르다 [5][6][20].

### D04.04 이름·확장자·충돌 검사

**구현.** 이 방식은 `collect_triage_package`의 `evidence_id`, `analyze_triage_zip`이 푸는 ZIP 항목 이름, `artifact-forensic`이 사본으로 꺼내는 ZIP 항목 이름에 적용된다 [6][21][22].
`evidence_id`는 첫 글자가 영문자나 숫자이고 영문자, 숫자, `.`, `-`, `_`로만 된 64자 이하의 문자열만 받는다 [6].
그래서 경로 구분자와 `..`만으로 된 값은 거부된다 [6].
경로 구분자가 들어간 값, `..`, 65자 값은 `ValueError`로 거부되었고 빈 값은 `triage_<8자리 16진수>`가 되었다 [14].

`analyze_triage_zip`은 항목을 풀기 전에 모든 항목 이름을 `_normalize_zip_member`로 검사한다 [21][23].
이 함수는 빈 이름, 널 문자, `/`나 드라이브 문자로 시작하는 이름, 빈 조각이나 `.`·`..` 조각을 거부한다 [21].
Windows에서 쓸 수 없는 문자, 공백이나 점으로 끝나는 조각, `CON`·`NUL`·`COM1` 같은 예약 이름도 거부한다 [21].
대소문자를 무시하고 같은 이름이 둘 이상이면 거부한다 [23].
하나라도 거부되면 어느 항목도 풀지 않고 오류를 돌려준다 [23][24].
풀 때는 파일을 `xb` 모드로 열어 이미 있는 이름이면 실패한다 [24].
대소문자만 다른 두 항목이 들어 있는 ZIP과 상위 폴더로 가는 항목이 들어 있는 ZIP은 모두 오류로 끝났고 작업 폴더 밖에 파일이 생기지 않았다 [14].

`artifact-forensic`은 모델이 준 `member_path`와 ZIP 안 항목 이름을 `normalize_archive_member`로 같은 규칙에 따라 검사하고 2,000자를 넘거나 파일 이름이 없는 값도 거부한다 [22][25].
사본으로 꺼낼 항목들의 마지막 이름이 대소문자를 무시하고 겹치면 거부한다 [13].
함께 꺼내는 항목 `companion_member_paths`는 고른 하이브와 같은 폴더의 `<하이브 이름>.LOG1`·`<하이브 이름>.LOG2`만 받는다 [26].
사본 파일은 `xb` 모드로 연다 [27].
상위 폴더로 가는 `member_path`는 오류로 끝났고 작업 폴더에 남은 것이 없었다 [14].
목적지 이름의 확장자를 검사하는 곳은 없다.

**한계.** `evidence_id` 검사는 `.`를 받지만 `IR_Collect.exe`는 그 글자를 `_`로 바꿔 파일 이름을 짓는다 [6][20].

def safe_evidence_id(evidence_id: str) -> str:
    """Validate/normalize an evidence id used as the ZIP basename. Empty -> generated.
    Rejects path separators, traversal, and unsafe characters."""
    eid = (evidence_id or "").strip()

    if not EVIDENCE_ID_RE.match(eid):

def _normalize_zip_member(name: str, *, directory: bool = False) -> str:
    """Normalize a ZIP path for a private Windows work directory."""
    candidate = str(name or "").replace("\\", "/")
    if directory:
        candidate = candidate.rstrip("/")
    if not candidate or "\x00" in candidate:
        raise ValueError("ZIP member path is empty or contains a NUL byte.")
    if candidate.startswith("/") or re.match(r"^[A-Za-z]:", candidate):
        raise ValueError(f"unsafe ZIP member path (absolute): {name}")
    parts = candidate.split("/")
    if any(part in {"", ".", ".."} for part in parts):
        raise ValueError(f"unsafe ZIP member path (traversal): {name}")
    reserved = {"CON", "PRN", "AUX", "NUL"} | {
        f"{prefix}{number}"
        for prefix in ("COM", "LPT")
        for number in range(1, 10)
    }
    for part in parts:
        if any(character in part for character in '<>:"|?*') or part.endswith((" ", ".")):
            raise ValueError(f"unsafe ZIP member path (Windows name): {name}")
        if part.split(".", 1)[0].upper() in reserved:
            raise ValueError(f"unsafe ZIP member path (reserved name): {name}")
    return PurePosixPath(candidate).as_posix()

def normalize_archive_member(member_path: str) -> str:
    """Return a canonical relative ZIP member path or reject unsafe syntax."""
    candidate = str(member_path or "").replace("\\", "/")
    if not candidate or not candidate.strip() or "\x00" in candidate:
        raise ValueError("member_path is empty or contains a NUL byte.")
    if len(candidate) > MAX_TEXT_FIELD:
        raise ValueError(f"member_path exceeds {MAX_TEXT_FIELD} characters.")
    if candidate.startswith("/") or re.match(r"^[A-Za-z]:", candidate):
        raise ValueError(f"member_path must be relative: {member_path!r}")
    raw_parts = candidate.split("/")
    if any(part in {"", ".", ".."} for part in raw_parts):
        raise ValueError(f"member_path contains unsafe traversal syntax: {member_path!r}")
    windows_reserved = {"CON", "PRN", "AUX", "NUL"} | {
        f"{prefix}{number}"
        for prefix in ("COM", "LPT")
        for number in range(1, 10)
    }
    for part in raw_parts:
        if any(character in part for character in '<>:"|?*') or part.endswith((" ", ".")):
            raise ValueError(f"member_path contains an unsafe Windows name: {member_path!r}")
        if part.split(".", 1)[0].upper() in windows_reserved:
            raise ValueError(f"member_path contains a reserved Windows name: {member_path!r}")
    pure = PurePosixPath(candidate)
    normalized = pure.as_posix()
    if not pure.name:
        raise ValueError(f"member_path does not name a file: {member_path!r}")
    return normalized
```

    archive: zipfile.ZipFile,
    member_path: str,
    cfg: Config,
) -> tuple[zipfile.ZipInfo, str]:
    normalized = normalize_archive_member(member_path)
    if len(archive.infolist()) > MAX_ARCHIVE_MEMBERS:
        raise ValueError(
            f"archive contains more than the {MAX_ARCHIVE_MEMBERS}-member safety limit."
        )
    matches = [
        info
        for info in archive.infolist()
        if info.filename.replace("\\", "/") == normalized
    ]
    if not matches:
        raise ValueError(f"archive member was not found: {normalized}")
    if len(matches) != 1:
        raise ValueError(f"archive member name is ambiguous ({len(matches)} entries): {normalized}")
    info = matches[0]
    validate_zip_member_info(info, cfg)
    return info, normalized

def validate_archive_companion_paths(
    primary_member: str,
    companion_member_paths: list[str] | None,
) -> list[str]:
    """Allow only adjacent Registry transaction logs for one selected hive."""
    companions = list(companion_member_paths or [])
    if len(companions) > MAX_ARCHIVE_COMPANION_MEMBERS:
        raise ValueError(
            f"companion_member_paths accepts at most {MAX_ARCHIVE_COMPANION_MEMBERS} entries."
        )
    primary = PurePosixPath(primary_member)
    allowed_names = {
        f"{primary.name}.LOG1".casefold(),
        f"{primary.name}.LOG2".casefold(),
    }
    normalized: list[str] = []
    seen: set[str] = set()
    for value in companions:
        candidate = normalize_archive_member(value)
        pure = PurePosixPath(candidate)
        if pure.parent != primary.parent or pure.name.casefold() not in allowed_names:
            raise ValueError(
                "Registry companions must be the selected hive's same-directory .LOG1/.LOG2 files."
            )
        folded = candidate.casefold()
        if folded in seen:
            raise ValueError(f"duplicate companion member requested: {candidate}")
        seen.add(folded)
        normalized.append(candidate)
    return normalized
```
