# D02 파생물 추적

### 미구현

**판단.** 서버가 남기는 파생물은 수집 ZIP과 그 해시 파일, 증거 폴더를 복사하지 않고 분석할 때 분석 도구가 증거 폴더에 쓰는 CSV, 분석 도구의 로그 파일이다.
서버는 이 파생물을 그것을 만든 호출이나 사용한 입력과 잇는 값을 파생물에도 서버 기록에도 남기지 않는다.
네 서버의 코드에는 호출 기록을 쓰는 곳이 없다.

호출과 입력을 가리키는 값은 응답에만 실린다.
공통 모듈은 응답마다 새 난수로 `evidence_id`와 `snapshot_id`를 짓고 도구 결과의 `provenance`에서 `evidence_digest`·`source_folder`·`exit_code` 같은 값을 옮겨 싣는다 [1].
`ir-collect`의 분석 응답은 `provenance`에 `IR_Collect.exe`가 낸 `evidence_digest`, 분석한 폴더나 ZIP의 경로, 분석 도구의 SHA-256을 싣는다 [2].
`collect_triage_package`의 응답은 `evidence_id`, ZIP 경로, ZIP의 SHA-256, 분석 도구의 SHA-256을 싣는다 [3].
서버는 이 응답을 파일이나 DB에 남기지 않는다 [1][3].

`IR_Collect.exe` 0.24.2의 `-analyze`는 파생 CSV를 만들기 전에 입력 파일마다 해시를 계산해 요약 JSON의 `evidence`와 `evidence_digest`에 싣는다 [4].
`ir-collect`는 그 요약 JSON을 호출마다 만든 작업 폴더에 받아 읽은 뒤 폴더째 지우고 응답에는 `evidence_digest`와 `evidence` 항목 수만 남긴다 [2][5].
증거 폴더에 쓰인 파생 CSV의 이름은 고정 이름이거나 로그 이름 뒤에 `_filtered.csv`를 붙인 것이고 그 안이나 곁에 호출, 입력 파일, 해시를 적은 값이 없다 [6].

로그 파일에 들어가는 값도 호출과 잇지 않는다.
Hayabusa 3.10.0의 오류 로그 파일은 첫 줄에 명령줄 전체를 적어 서버가 넘긴 증거 경로와 출력 경로가 들어 있다 [7].
이 줄은 Hayabusa가 쓰는 것이고 서버는 그 파일을 읽지 않으며 MCP 호출을 가리키는 값도 없다 [7][8].
`IR_Collect.exe` 0.24.2의 `logs/ir_collect.log` 줄은 시각, 수준, 문장만 담는다 [9].

수집 ZIP의 이름은 호출 인자 `evidence_id`이고 인자가 비어 있으면 서버가 지은 `triage_<난수>`다 [10].
`IR_Collect.exe` 0.24.2는 ZIP으로 묶기 전에 수집 폴더에 `collection_coverage.json`을 쓰고 여기에 생성 시각, 호스트 이름, `evidence_id`, 단계별 수집 상태를 적는다 [11].
이 파일은 `IR_Collect.exe`가 쓰는 것이고 서버는 그 값을 읽지 않으며 MCP 호출을 가리키는 값도 없다 [11][3].
ZIP 안의 내용과 `<ID>.zip.sha256`은 `IR_Collect.exe`가 쓰고 서버는 그 안에 호출을 가리키는 값을 넣지 않는다 [3][12].
앞 도구의 파생물을 뒤 도구가 입력으로 쓸 때 그 관계를 기록하는 코드는 없다.
`collect_triage_package` 응답의 `next_step`은 ZIP을 증거 폴더에 옮긴 뒤 `analyze_triage_zip`으로 분석하라고 안내할 뿐이다 [3].

```python
def safe_evidence_id(evidence_id: str) -> str:
    """Validate/normalize an evidence id used as the ZIP basename. Empty -> generated.
    Rejects path separators, traversal, and unsafe characters."""
    eid = (evidence_id or "").strip()
    if not eid:
        return "triage_" + uuid.uuid4().hex[:8]
    if not EVIDENCE_ID_RE.match(eid):
        raise ValueError("evidence_id must be 1-64 chars of letters/digits/dot/dash/underscore, "
                         "with no path separators.")
    return eid
```
