# L04 기록 위변조 방지

### 비적용

**판단.** 네 서버는 MCP 도구 호출의 기록을 담은 파일이나 DB를 만들지 않는다 [1].
서버 코드는 `logging` 모듈을 불러오지 않고 로거에 항목을 쓰지 않는다 [1].
서버 프로세스의 표준 오류에는 MCP Python SDK 1.28.1이 요청 종류와 목록에 없는 도구 이름을 쓰는 진단 줄만 남는다 [2].
이 출력을 어디에 어떻게 남길지는 서버를 실행한 MCP 클라이언트가 정한다 [2].
서버 기록이 없으므로 수정, 삭제, 순서 변경을 막거나 찾아내는 장치를 볼 대상이 없다.

`usb-collect/COLLECT.bat`이 덧붙이는 `collection_log.txt`는 MCP 서버를 거치지 않는 현장 수집의 기록이다 [3].
`IR_Collect.exe` 0.24.2의 `logs/ir_collect.log`는 분석 도구의 기록이다 [4].
