# L02 기록 구성

### 비적용

**판단.** 네 서버는 MCP 도구 호출을 파일이나 DB에 남기지 않는다 [1].
서버 코드는 `logging` 모듈을 불러오지 않고 로거에 항목을 쓰지 않는다 [1].
서버 프로세스의 표준 오류에는 MCP Python SDK 1.28.1이 요청마다 쓰는 요청 종류 줄과 목록에 없는 도구 이름의 경고 줄만 남는다 [2][3].
`rich`가 설치되어 있지 않으면 `FastMCP`가 붙이는 처리기의 형식은 `%(message)s`여서 이 줄에는 시각도 없다 [2].
서버 기록이 없으므로 요청, 처리, 결과 상태, 결과 참조를 무엇으로 남기는지 볼 대상이 없다.

세 증거 서버의 응답 형식 `evidence_v1`에는 응답마다 새로 만드는 `evidence_id`, 수집 시각 `collected_at_utc`, 상태 `status`, 출처 `provenance`가 들어 있다 [4].
이 값은 도구 응답으로만 나가고 서버에 남지 않는다 [4][1].
