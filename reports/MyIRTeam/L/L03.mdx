# L03 기록 실패 처리

### 비적용

**판단.** 네 서버는 MCP 도구 호출의 기록을 쓰지 않는다 [1].
서버 코드에는 기록 파일이나 DB를 여는 곳이 없고 `logging` 모듈을 불러오는 곳도 없다 [1].
서버 프로세스의 표준 오류에 남는 줄은 MCP Python SDK 1.28.1이 요청 종류와 목록에 없는 도구 이름을 쓰는 진단 줄이다 [2].
기록을 쓰는 호출이 없으므로 쓰기가 실패할 때의 처리를 볼 대상이 없다.

`IR_Collect.exe` 0.24.2는 자기 기록 파일 `logs/ir_collect.log`에 줄을 덧붙이다 예외가 나면 그 줄을 버리고 호출한 쪽에 알리지 않는다 [3].
이 파일은 분석 도구의 기록이다 [3].
