# E01 증거 등록 관리

### 미구현

**판단.** `ir-collect`와 `artifact-forensic`은 수집해 둔 폴더, ZIP, 보고서, 아티팩트 파일을 도구마다 경로 인자로 받아 그 호출에서만 읽는다 [1].
증거를 등록하는 MCP 도구는 없고 서버는 증거를 식별하는 목록이나 등록 정보를 남기지 않는다.
받을 수 있는 경로는 증거 폴더 목록 아래로 한정되지만 이 목록은 경로를 허용하는 설정이고 증거 항목을 적은 것이 아니다 [2][3].

`inventory_evidence_path`는 받은 파일이나 폴더의 파일마다 상대 경로, 크기, 수정 시각, 확장자, SHA-256을 응답으로 돌려준다 [4].
`inventory_archive_members`는 ZIP 항목마다 경로, 크기, 압축 크기, CRC32를 돌려준다 [5].
서버는 두 목록을 저장하지 않는다 [4][5].
`evidence_v1` 응답의 `evidence_id`는 응답을 만들 때마다 `ev_`에 난수를 붙여 만드는 값이고 증거를 가리키지 않는다 [6].
같은 파일을 두 번 넘겨도 다른 `evidence_id`가 실린다 [6].

서버가 시작하는 수집도 서버 쪽 목록에 오르지 않는다.
`collect_triage_package`는 `IR_Collect.exe -c`로 서버를 실행한 호스트에서 수집해 `<evidence_id>.zip`을 수집 폴더에 쓰게 한다 [7].
`evidence_id`를 주지 않으면 서버가 `triage_`에 난수 8자리를 붙인 값을 만들어 ZIP 이름으로 쓴다 [8].
응답은 `evidence_id`, ZIP 경로, 크기, SHA-256, `.sha256` 부속 파일이 있는지, 관리자 권한 여부를 싣고 서버는 이 값을 파일로 남기지 않는다 [7].
이 도구는 환경변수 `IRCOLLECT_ALLOW_COLLECTION`과 호출 인자 `acknowledge_live_response`가 모두 켜져야 실행되고 실행해 확인하지 않았다 [7].

`IR_Collect.exe` 0.24.2는 분석할 폴더의 파일마다 SHA-256을 계산한 목록과 그 목록의 묶음 해시를 결과 JSON의 `evidence`와 `evidence_digest`에 싣는다 [9].
`ir-collect`의 응답은 `evidence_digest`만 옮기고 파일 목록은 건수 `evidence_manifest_count`로만 싣는다 [10].
기본값으로는 이 목록이 원본이 아니라 작업 폴더에 만든 사본에서 계산된다 [11].

def validate_evidence_path(path_str: str, cfg: Config) -> Path:
    """Validate a regular file or directory under an explicit evidence root."""
    if not path_str or not path_str.strip():
        raise ValueError("input_path is empty.")
    path = _resolve(path_str)
    if not cfg.evidence_roots:
        raise ValueError("no evidence roots configured (set ARTIFACT_EVIDENCE_ROOTS).")
    if not is_under_roots(path, cfg.evidence_roots):
        raise ValueError(f"path is outside the configured evidence roots: {path}")
    if path.is_symlink():
        raise ValueError(f"symbolic-link evidence paths are not accepted: {path}")
    if not path.is_file() and not path.is_dir():
        raise ValueError(f"input path does not exist: {path}")
    return path
```

def safe_evidence_id(evidence_id: str) -> str:
    """Validate/normalize an evidence id used as the ZIP basename. Empty -> generated.
    Rejects path separators, traversal, and unsafe characters."""
    eid = (evidence_id or "").strip()
    if not eid:
        return "triage_" + uuid.uuid4().hex[:8]
    if not EVIDENCE_ID_RE.match(eid):
        raise ValueError("evidence_id must be 1-64 chars of letters/digits/dot/dash/underscore, "
                         "with no path separators.")
    return eid
```
