# E03 원본 변경 방지

### E03.02 서버 코드의 원본 쓰기 제한

**구현.** 이 방식은 `ir-collect`와 `artifact-forensic`의 서버 코드가 증거 파일을 직접 여는 경로와 `ir-collect`가 `IR_Collect.exe`에 입력을 넘기는 경로에 적용된다 [1][2][3].
서버 코드는 증거를 읽기 모드로만 연다.
두 서버의 해시 계산, `inspect_binary_file`의 머리 바이트·PE 구조·문자열 읽기는 `rb`로 연다 [1][4].
해시 목록 파일은 `read_bytes`로 읽고 ZIP은 Python `zipfile`의 기본 읽기 모드로 연다 [5][6].
증거를 읽는 이 경로들에는 증거 파일에 쓰는 호출이 없다 [1][4][5][6].

`ir-collect`의 `analyze_artifact_folder`, `correlate_hosts`, `expand_investigation_graph`는 `work_on_copy`가 참(기본값)이면 증거 폴더를 작업 폴더에 복사하고 사본을 `IR_Collect.exe`에 넘긴다 [2][7].
`IR_Collect.exe` 0.24.2는 받은 폴더에 SRUM·Amcache·ShimCache CSV, 필터한 이벤트 로그 CSV, ShellBags CSV를 쓴다 [8].
관리자 권한으로 실행되면 받은 폴더의 `Amcache.hve`와 `SYSTEM` 하이브를 `reg load`로 호스트 레지스트리에 연결해 읽는다 [9].
그래서 이 쓰기와 연결은 사본에 적용된다 [2].
복사할 곳이 증거 폴더 안이면 복사하지 않고 오류를 돌려준다 [3].
`analyze_triage_zip`은 ZIP을 작업 폴더에 풀고 풀어 낸 폴더를 넘긴다 [10].
`artifact-forensic`의 ZIP 항목 도구는 항목을 작업 폴더에 꺼내고 사본을 분석 도구에 넘긴다 [11].
기본값으로 원본 폴더 목록이 호출 전후 같았고 시험용 `IR_Collect.exe`가 쓴 파일은 사본에만 생겼다 [12].
사본과 풀어 낸 파일은 이미 있으면 실패하는 방식으로 새로 만든다 [3][13].

서버가 증거 밖에 쓰는 곳은 작업 폴더와 `collect_triage_package`의 수집 폴더다 [14][15].
작업 폴더 `IRCOLLECT_WORK_DIR`·`ARTIFACT_WORK_DIR`가 증거 폴더와 겹치는지는 확인하지 않는다 [14].
EZ Tools의 CSV 출력은 `--csv`로 작업 폴더 아래 새 폴더에 쓰게 한다 [16].

**한계.** `work_on_copy`를 거짓으로 주면 `ir-collect`는 원본 폴더를 `IR_Collect.exe`에 넘기고 `provenance.warning`에 경고 문장만 싣는다 [17][7].
이때 `IR_Collect.exe`의 파생 CSV는 원본 폴더에 쓰이고 관리자 권한이면 원본 하이브가 `reg load`로 연결된다 [8][9].
시험용 `IR_Collect.exe`가 입력 폴더에 파일을 쓰게 한 실행에서 `work_on_copy`를 거짓으로 주자 그 파일이 원본 폴더에 남았다 [12].
Windows가 `reg load`로 연결한 하이브 파일에 쓰는지는 확인하지 못했다 [9].
도구 설명은 이 인자를 아주 큰 폴더의 복사를 피할 때만 쓰라고 적는다 [18].

### E03.03 외부 도구·플랫폼에 위임

**구현.** 이 방식은 `artifact-forensic`이 원본 파일의 경로를 분석 도구에 넘기는 도구와 `local-forensic`의 호스트 조회 도구에 적용된다 [16][19][20].
`parse_windows_artifact_with_eztools`, `analyze_evtx_with_hayabusa`, `analyze_file_with_capa`, `scan_file_with_yara`는 증거 폴더 아래 원본 파일이나 폴더의 경로를 그대로 분석 도구에 넘긴다 [16][19].
원본을 지키는 것은 서버 개요의 버전 기준 소스에서 분석 도구가 입력을 읽기 모드로 연다는 동작이다.

- EvtxECmd는 `FileStream`을 `FileAccess.Read`로 연다 [21].
- PECmd는 Prefetch 라이브러리 2026.5.2의 `PrefetchFile.Open`에 경로를 넘기고 이 함수는 `FileAccess.Read`로 연다 [22].
- RECmd는 하이브를 `FileAccess.Read`로 직접 열어 Registry 라이브러리 2026.5.0에 바이트로 넘긴다 [23].
- AmcacheParser는 이 라이브러리의 경로 생성자로 하이브를 `FileAccess.Read`로 연다 [24].
- 두 도구 모두 트랜잭션 로그는 `File.ReadAllBytes`로 읽어 메모리에서 적용한다 [23][24].
- MFTECmd는 앞 50바이트를 `FileAccess.Read`로 읽어 종류를 정하고 MFT 라이브러리 2026.5.1의 `$MFT`·`$J`·`$Boot`·`$SDS`와 폴더 인덱스 읽기 함수도 `FileAccess.Read`로 연다 [25].
- Hayabusa 3.10.0은 hayabusa-evtx의 `EvtxParser::from_path`로 EVTX를 `File::open`으로 연다 [26].
- capa 7.1.0은 형식 확인에서 입력을 `rb`와 `read_bytes`로 읽는다 [27].
- YARA-X 1.19.0은 `fs::File::open`으로, YARA 4.5.5는 Windows에서 `CreateFileA`에 `GENERIC_READ`를 주어 연다 [28][29].

`local-forensic`에서 원본은 서버를 실행한 Windows 호스트다 [30].
이 서버의 PowerShell 글은 코드에 정해 두었고 `Get-WinEvent`, `Get-CimInstance`, `Get-Item`, `Get-FileHash` 같은 조회 명령만 부른다 [30].
모델은 채널 이름, 이벤트 ID, 시간 범위, 이름 필터, 파일 경로 같은 값만 넘기고 이 값은 환경변수로 글에 들어간다 [30].
Sysinternals 도구 `autorunsc`, `sigcheck`, `tcpvcon`, `handle`은 코드에 정한 옵션에 `-accepteula`를 붙여 실행한다 [31].
호스트를 바꾸지 않는 것은 이 Windows 명령과 Sysinternals 도구의 동작에 맡긴다.

`ir-collect`의 `collect_triage_package`는 서버를 실행한 호스트에서 `IR_Collect.exe -c`로 수집한다 [15].
수집 폴더는 이 호스트의 `IRCOLLECT_COLLECT_DIR`이고 값이 없으면 작업 폴더 아래 `collections`다 [15][32].
`IR_Collect.exe` 0.24.2는 수집 폴더에 `IR_Output_<evidence_id>` 폴더를 만들고 수집한 파일을 쓴다 [33].
수집을 마치면 같은 폴더에 `<evidence_id>.zip`과 `<evidence_id>.zip.sha256`을 쓴다 [33].
`IR_Collect.exe`는 설정 `DeleteOutputDirAfterZip`이 끄지 않으면 `IR_Output_<evidence_id>` 폴더를 지운다 [33].
응답의 `warning`은 이 수집이 호스트에 출력을 쓴다고 적는다 [34].
이 도구는 환경변수 `IRCOLLECT_ALLOW_COLLECTION`과 호출 인자 `acknowledge_live_response`가 모두 켜져야 실행된다 [35].
두 확인을 거친 뒤 호스트에 쓰는 것을 막는 코드는 없다 [15][35].
이 도구는 실행해 확인하지 않았다.

증거를 읽기 전용으로 마운트하거나 서버를 읽기 전용 환경에서 실행하는 경로는 저장소에 없다.

**한계.** capa 7.1.0이 쓰는 vivisect는 버전이 `>=1.1.1`로만 정해져 있어 vivisect가 입력을 여는 모드는 확인하지 못했다(실제 보호 미확인) [36].
capa는 환경변수 `CAPA_SAVE_WORKSPACE`가 켜져 있으면 vivisect 작업 공간을 저장한다 [37].
서버는 분석 도구에 자기 환경변수를 그대로 물려주므로 이 값을 끄지 않는다 [38].
capa 7.1.0은 작업 공간 저장이 `IOError`로 실패하면 입력 파일의 폴더에 쓸 수 없어 저장하지 않는다는 기록을 남긴다 [37].
실제 저장 경로는 vivisect가 정하므로 확인하지 못했다(실제 보호 미확인).
Sysinternals 도구는 소스가 공개되지 않았고 Microsoft 문서는 옵션만 설명한다 [39].
그래서 `autorunsc`, `sigcheck`, `tcpvcon`, `handle`이 호스트의 파일과 레지스트리를 읽기만 하는지와 `-accepteula`가 호스트에 무엇을 남기는지는 확인하지 못했다(실제 보호 미확인) [39].
Handle 문서는 실행에 관리자 권한이 필요하다고 적는다 [39].
PowerShell 조회 명령이 호스트에 남기는 것도 확인하지 못했다.
RECmd·AmcacheParser·EvtxECmd는 입력 파일을 열지 못하고 관리자 권한이면 원시 디스크 읽기로 다시 읽는다 [23][24][40].
MFTECmd는 앞 50바이트를 읽지 못하면 원시 디스크 읽기로 다시 읽는다 [41].
원시 디스크 읽기에서 입력을 여는 모드는 확인하지 못했다.

```python
def _safe_copy_evidence_tree(source: Path, destination: Path) -> dict[str, int]:
    """Copy a directory without following symlinks or Windows junctions."""
    source = source.resolve()
    destination = destination.resolve()
    if _path_is_link_or_junction(source):
        raise ValueError(f"evidence folder cannot be a symbolic link or junction: {source}")
    if destination == source or destination.is_relative_to(source):
        raise ValueError("private work destination must not be inside the evidence source tree.")
    destination.mkdir(parents=True, exist_ok=False)
```

```python
    """Validate each folder against the allowlist and (optionally) copy to work dir."""
    if not folder_paths:

    targets: list[Path] = []
    for i, fp in enumerate(folder_paths):

        if work_on_copy:
            dst = work / f"input_{i}_{src.name}"
            _safe_copy_evidence_tree(src, dst)
            targets.append(dst)
        else:

    return targets
```

```python
def run_sysinternals_tool(
    tool_name: str,
    args: list[str],
    timeout_seconds: int = 180,
) -> str:
    """Run a bundled Sysinternals tool and return its text output."""
    try:
        tool_path = safe_tool_path(tool_name)
    except ValueError as exc:
        return f"Error: {exc}"

    if not tool_path.is_file():
        return f"Error: required tool not found: {tool_path}"

    cmd = [str(tool_path), "-accepteula", *args]
    creationflags = getattr(subprocess, "CREATE_NO_WINDOW", 0)

    try:
        result = subprocess.run(
            cmd,
            capture_output=True,
            timeout=timeout_seconds,
            check=False,
            creationflags=creationflags,
        )
```
