# T03 실행 조건 확인

### 미구현

**판단.** 네 서버에는 앞선 작업 상태, 모델 밖 승인, 호출자 신원, 실행 자원으로 호출을 막거나 미루는 코드가 없다.
세 증거 서버의 도구 함수는 인자와 경로 검사를 마치면 바로 분석 도구를 실행한다 [1][2].
`ir-collect`와 `artifact-forensic`은 실행 전에 실행 파일의 해시 대조도 한다 [1][2].
세 증거 서버의 초기화 지침은 `myirteam-core`가 워크플로를 고른 뒤에 쓰라고 안내한다 [3].
`resolve_investigation_intent`는 고른 워크플로와 다음에 부를 도구를 응답에 적기만 하고 그 결과를 서버에 남기지 않는다 [4].
증거 서버는 앞서 `myirteam-core`를 불렀는지 보지 않으며 네 서버는 서로 상태를 주고받지 않는다 [1][2].

`collect_triage_package`는 사용자가 정한 환경변수 `IRCOLLECT_ALLOW_COLLECTION`과 호출 인자 `acknowledge_live_response`가 모두 참일 때만 실행한다 [5].
환경변수는 서버가 시작할 때 한 번 읽는 설정이고 호출마다 받는 승인이 아니다 [5].
`acknowledge_live_response`는 모델이 같은 호출 안에서 정하는 값이고 서버는 사용자가 낸 승인 토큰이나 승인 기록을 받거나 대조하지 않는다 [5].

네 서버는 `mcp.run()`을 기본 전송 방식인 stdio로 실행하므로 원격 MCP 연결을 받지 않는다 [6][7].
`portable_mcp.py`는 서버 ID를 받아 정해 둔 진입점 하나를 실행할 뿐 호출자를 확인하지 않는다 [8].

서버는 실행 전에 메모리, CPU, 디스크 여유 공간을 확인하지 않는다.
ZIP 크기와 항목 수 상한, `run_static_tool`이 출력 크기가 16MiB를 넘으면 도구를 멈추는 동작은 입력과 출력의 크기 상한이고 실행 자원의 상태를 보지 않는다 [9][10].

동시 실행 수를 정하는 장치도 없다.
네 서버의 도구 함수는 모두 동기 함수이고 MCP Python SDK 1.28.1의 `FastMCP`는 동기 도구 함수를 이벤트 루프에서 `await` 없이 바로 부른다 [11].
그래서 한 호출이 분석 도구의 종료를 기다리는 동안 같은 서버의 다른 요청은 처리되지 않는다 [11].
이는 서버가 정한 제한이 아니라 SDK가 동기 함수를 부르는 방식에서 생기는 동작이다.

```python
def resolve_server_entrypoint(server_id: str, root: Path = PROJECT_ROOT) -> Path:
    """Return one fixed server path and reject arbitrary path execution."""
    relative = SERVER_ENTRYPOINTS.get(server_id)
    if relative is None:
        choices = ", ".join(sorted(SERVER_ENTRYPOINTS))
        raise ValueError(f"Unknown server {server_id!r}. Choose one of: {choices}")

    resolved_root = root.resolve()
    entrypoint = (resolved_root / relative).resolve()
    if not entrypoint.is_relative_to(resolved_root) or not entrypoint.is_file():
        raise FileNotFoundError(f"MCP server entrypoint is missing or unsafe: {entrypoint}")
    return entrypoint
```
