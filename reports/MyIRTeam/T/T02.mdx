# T02 실행 허용 범위 제한

### T02.04 고정 명령·템플릿

**구현.** 이 방식은 `local-forensic`·`ir-collect`·`artifact-forensic`이 외부 프로그램을 실행하는 모든 경로에 적용된다 [1][2][3][4].
`myirteam-core`는 외부 프로그램을 실행하지 않고 정해 둔 프로젝트 파일만 읽는다 [5].

`local-forensic`의 Sysinternals 실행 함수는 서버 코드의 이름 4개(`autorunsc.exe`·`sigcheck.exe`·`tcpvcon.exe`·`handle.exe`)만 받고 프로젝트 폴더의 `Sysinternals Suite` 아래에서 그 파일을 실행한다 [1].
인자 배열 앞에는 늘 `-accepteula`를 붙인다 [1].
도구마다 인자 배열은 코드에 정해져 있고 모델 값은 정한 자리 하나에만 들어간다 [6].
`collect_autoruns`는 `-a <분류> -ct -nobanner`, `check_file_signatures`는 `-a -h -i -ct -nobanner <경로>`를 넘긴다 [6].
`list_network_connections`는 `-a -c -n` 뒤에 `process_identifier`를 붙이고 `list_open_handles`는 `-nobanner` 뒤에 숫자면 `-p <PID>`를, 아니면 `target`을 붙인다 [6].
PowerShell로 읽는 도구 13개는 코드에 적힌 스크립트를 실행하고 모델 값은 `FORENSIC_`로 시작하는 환경변수로만 넘긴다 [2][7].
스크립트는 그 값을 `$env:`로 읽어 변수에 넣고 명령 문자열에 이어 붙이지 않는다 [7].
`collect_ir_event_bundle`은 채널 8개와 채널마다 읽을 이벤트 ID 목록을 코드에 정해 두고 모델은 시각과 건수만 정한다 [8].
`collect_autoruns`·`check_file_signatures`·`list_network_connections`·`list_open_handles`와 `collect_event_log_events`를 부르자 실행 함수가 받은 인자 배열과 환경변수가 이 틀과 같았다 [9].

`ir-collect`는 `IR_Collect.exe`에 `-analyze <폴더> <출력 파일>`, `-correlate <출력 파일> <폴더…>`, `-graph <seed_type> <seed_value> <깊이> <출력 파일> <폴더…>`를 인자 배열로 넘긴다 [3].
켜졌을 때의 `collect_triage_package`는 `-c <evidence_id>`를 넘긴다 [3].
모델 값 가운데 폴더는 허용 폴더와 대조한 실제 경로나 그 사본의 경로이고 `seed_type`·`seed_value`는 받은 문자열이다 [3].
`IR_Collect.exe` 0.24.2는 `-graph` 뒤의 인자를 자리 순서대로 읽으므로 seed 값이 `-`로 시작해도 옵션으로 읽지 않는다 [10].

`artifact-forensic`은 Hayabusa에 `json-timeline`과 `-f`나 `-d`, 출력 형식, 규칙 수준 `-m`, 프로필 `-p standard`를 정한 배열로 넘긴다 [4].
EZ Tools에는 `-f <파일> --csv <작업 폴더> --csvf result.csv`를 넘기고 PECmd에는 `-q`를, RECmd에는 고른 프로필 파일의 `--bn`과 `--nl`을 더한다 [11].
capa에는 `-j --color never <파일>`을 넘긴다 [12].
YARA-X에는 `scan`과 출력 옵션, `--threads 1`, `--timeout`을 붙인 뒤 규칙 파일과 대상 파일을 넘기고 YARA에도 정한 옵션 뒤에 규칙 파일과 대상 파일을 넘긴다 [12].
이 배열에 들어가는 경로는 모두 서버가 실제 경로로 변환한 절대 경로라 `-`로 시작하지 않는다 [13].
YARA 도구의 `rules_path`로 고른 규칙 파일은 서버가 내용을 검사하지 않고 그대로 넘긴다 [14].
Hayabusa·EZ Tools·capa·YARA-X 자리에 둔 시험용 실행 파일은 이 틀의 인자 배열을 받았다 [15].

**한계.** `list_network_connections`의 `process_identifier`와 `list_open_handles`의 `target`은 옵션 끝을 알리는 표시 없이 인자 배열에 들어간다 [6].
두 값의 검사는 `-`로 시작하는 값을 거부하지 않는다 [16][17].
`-`로 시작하는 값을 두 도구에 주자 실행 함수가 그 값을 그대로 인자 배열의 마지막 자리에 받았다 [9].
Microsoft 문서는 `tcpvcon.exe`와 `handle.exe`의 옵션을 `-`로 시작하는 낱말로 적는다 [18].
두 도구가 그 자리의 값을 옵션으로 읽는지는 소스가 공개되어 있지 않아 확인하지 못했다.

### T02.05 연산·플러그인 허용 목록

**구현.** 이 방식은 모델이 조회 종류나 분석 도구, 프로필, 모드를 고르는 인자에 적용된다 [19][20][21][22].
`collect_autoruns`의 `category`는 Autoruns 분류 글자 목록 밖의 글자가 있으면 거부한다 [19].
`collect_event_log_events`의 `channel`은 서버 코드의 이름 8개 가운데 하나여야 하고 그 이름에 대응하는 이벤트 로그만 읽는다 [20].
`parse_windows_artifact_with_eztools`·`parse_archive_member_with_eztools`의 `artifact_type`은 EZ Tools 실행 파일 5개 가운데 하나를 고르는 값이고 목록 밖의 값을 거부한다 [21].
RECmd의 `profile`은 이름 5개 가운데 하나여야 하고 서버는 그 이름을 정해 둔 프로필 파일로 바꾼다 [22].
YARA 도구의 `backend`는 `auto`·`yara`·`yara_x`(`yarax`) 가운데 하나여야 한다 [23].
목록 밖의 분류 글자, 채널, `artifact_type`, `profile`, `backend`를 주자 분석 도구를 실행하지 않고 허용 값을 적은 오류가 돌아왔다 [9][15].

### T02.08 설정으로 도구 끄기

**구현.** 이 방식은 `ir-collect`의 `collect_triage_package`에 적용된다 [24].
서버는 시작할 때 환경변수 `IRCOLLECT_ALLOW_COLLECTION`을 읽고 값이 `1`·`true`·`yes`·`on`이 아니면 수집을 끈 상태로 둔다 [24].
꺼진 상태에서도 도구는 목록에 남고 부르면 `IR_Collect.exe`를 실행하지 않고 `gated` 표시가 있는 오류를 돌려준다 [24].
켜진 상태에서는 호출 인자 `acknowledge_live_response`가 참이어야 실행하고 이 값은 모델이 호출할 때 정한다 [24].
환경변수 없이 `acknowledge_live_response`를 참으로 준 호출에 `Live collection is disabled by deployment` 오류가 돌아왔다 [25].
다른 세 서버에는 설정으로 도구를 끄는 값이 없다.

```python
def run_ircollect(cfg: Config, args: list[str], cwd: Path | None = None,
                  timeout: int | None = None) -> tuple[int, str, str]:
    """Run IR_Collect.exe with args. Returns (exit_code, stdout_text, stderr_text).
    stdout is unreliable for winexe — callers read the output FILE, not this."""
    cmd = [str(cfg.exe_path), *args]
    eff_timeout = timeout if timeout is not None else cfg.analyze_timeout
    try:
        result = subprocess.run(
            cmd,
            capture_output=True,
            timeout=eff_timeout,
            check=False,
            creationflags=CREATE_NO_WINDOW,
            cwd=(str(cwd) if cwd else None),
        )
    except subprocess.TimeoutExpired:
        return (-1, "", f"IR_Collect timed out after {eff_timeout}s.")
    except OSError as exc:
        return (-1, "", f"failed to launch IR_Collect ({cfg.exe_path}): {exc}")
    return (result.returncode, decode_output(result.stdout), decode_output(result.stderr))
```

```python
def _resolve(value: str | Path, base_dir: Path = PROJECT_ROOT) -> Path:
    """Resolve configured paths from the project root, not the caller's CWD.

    MCP clients commonly start stdio servers from their own working directory.
    Basing relative paths on ``PROJECT_ROOT`` keeps bundled tools and portable
    allowlist paths stable when this project is moved or run from a USB drive.
    """
    path = Path(os.path.expandvars(os.path.expanduser(str(value))))
    if not path.is_absolute():
        path = base_dir / path
    return path.resolve()
```

```python
def validate_rule_files(path_str: str, cfg: Config) -> list[Path]:
    if not path_str or not path_str.strip():
        raise ValueError("rules_path is empty.")
    path = _resolve(path_str)
    if not cfg.rule_roots:
        raise ValueError("no YARA rule roots configured (set YARA_RULE_ROOTS).")
    if not is_under_roots(path, cfg.rule_roots):
        raise ValueError(f"rules path is outside the configured YARA rule roots: {path}")
    if path.is_symlink():
        raise ValueError(f"symbolic-link rule paths are not accepted: {path}")
    if path.is_file():
        candidates = [path]
    elif path.is_dir():
        candidates = sorted(
            item.resolve()
            for item in path.rglob("*")
            if item.is_file() and not item.is_symlink() and item.suffix.lower() in {".yar", ".yara"}
        )
    else:
        raise ValueError(f"rules path does not exist: {path}")
    candidates = [item for item in candidates if item.suffix.lower() in {".yar", ".yara"}]
    if not candidates:
        raise ValueError(f"no .yar or .yara source files found: {path}")
    if len(candidates) > MAX_RULE_FILES:
```
