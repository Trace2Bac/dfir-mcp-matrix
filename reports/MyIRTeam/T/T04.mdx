# T04 실행 방식

### T04.01 서버 프로세스 안 분석

**구현.** 이 방식은 `artifact-forensic`의 정적 검사·목록·해시 대조 도구, `ir-collect`의 보고서 읽기, ZIP 풀기와 결과 정리, `local-forensic`의 프로세스 트리 구성과 외부 도구 목록 작성에 적용된다 [1][2][3][4][5].
`inspect_binary_file`은 서버 코드로 파일의 해시와 엔트로피를 계산하고 PE 헤더와 섹션을 읽고 문자열을 뽑는다 [1].
`inventory_evidence_path`·`inventory_archive_members`·`verify_sha256_manifest`도 외부 도구 없이 서버 코드로 파일 목록, ZIP 항목 정보, SHA-256을 만든다 [2].
ZIP 항목 도구는 고른 항목을 Python `zipfile`로 작업 폴더에 복사한 뒤 분석 함수를 부른다 [6].
EZ Tools가 쓴 CSV와 Hayabusa가 쓴 JSONL은 서버 코드가 읽어 행을 고른다 [7].
`ir-collect`의 `ingest_analysis_report`는 `IR_Collect.exe`를 실행하지 않고 서버 코드로 JSON 보고서를 읽어 정리한다 [3].
`analyze_triage_zip`은 ZIP을 서버 코드로 검사하고 풀며 `IR_Collect.exe`가 쓴 JSON도 서버 코드로 읽어 정리한다 [3].
`local-forensic`의 `build_process_tree_snapshot`은 PowerShell이 돌려준 프로세스 목록에서 부모 프로세스를 서버 코드로 찾아 붙인다 [4].
`get_external_tool_inventory`는 manifest를 읽고 실행 파일의 SHA-256을 서버 코드로 계산한다 [5].
`myirteam-core`는 프로젝트의 JSON과 문서 파일만 읽는다 [8].

### T04.02 같은 권한의 별도 프로세스

**구현.** 이 방식은 Sysinternals 도구, `IR_Collect.exe`, Hayabusa, EZ Tools, capa, YARA-X, YARA의 실행에 적용된다 [9][10][11].
`local-forensic`의 `run_sysinternals_tool`은 실행 파일 경로와 인자를 `list`로 `subprocess.run`에 넘기고 창을 만들지 않는 플래그와 시간 제한을 준다 [9].
`ir-collect`의 `run_ircollect`도 `list` 인자로 `IR_Collect.exe`를 실행한다 [10].
`artifact-forensic`의 `run_hayabusa`·`run_static_tool`·`probe_version`은 `list` 인자로 실행하고 표준 입력을 닫는다 [11][12].
`ir-collect`의 `run_ircollect`와 `local-forensic`의 `run_sysinternals_tool`·`run_powershell_json`은 표준 입력을 정하지 않는다 [10][9][13].
CPython 3.13.14의 Windows `subprocess`는 표준 입력을 정하지 않으면 서버의 표준 입력 핸들을 하위 프로세스에 넘긴다 [14].
`run_static_tool`은 표준 출력과 표준 오류를 호출마다 만든 폴더의 파일로 받고 그 폴더의 크기가 16MiB를 넘거나 시간 제한이 지나면 프로세스를 끝낸다 [11].
도구는 모두 서버와 같은 계정과 권한으로 실행되고 서버는 계정이나 권한을 바꾸지 않는다 [9][10][11].

`artifact-forensic`은 실행마다 `ARTIFACT_WORK_DIR` 아래에 새 폴더를 만들지만 그 폴더는 출력 파일을 받는 곳이고 작업 위치(`cwd`)는 실행 파일이 있는 폴더다 [11][15].
`ir-collect`는 분석 실행마다 새 작업 폴더를 만들어 사본과 출력 JSON을 두지만 작업 위치를 정하지 않고 서버의 작업 위치를 그대로 쓴다 [16][10].
`portable_mcp.py`로 실행하면 서버의 작업 위치는 프로젝트 폴더다 [17].
켜졌을 때의 `collect_triage_package`만 작업 위치를 수집 폴더 `IRCOLLECT_COLLECT_DIR`로 정하고 이 폴더는 호출마다 같다 [18].

### T04.03 셸 명령 문자열 실행

**구현.** 이 방식은 `local-forensic`이 PowerShell로 읽는 도구 13개에 적용된다 [13].
`run_powershell_json`은 `PATH`에서 `pwsh.exe`, `powershell.exe` 차례로 찾은 PowerShell을 `-NoProfile -NonInteractive -Command <스크립트>`로 실행한다 [19][13].
PowerShell이 `-Command`로 받은 스크립트 문자열을 해석해 cmdlet을 실행한다 [13][20].
스크립트는 도구마다 코드에 적힌 문자열이고 모델 값은 그 문자열에 이어 붙이지 않고 `FORENSIC_`로 시작하는 환경변수로 넘긴다 [21].
스크립트는 그 환경변수를 `$env:`로 읽어 cmdlet의 인자로 쓴다 [21].
`get_file_metadata`의 파일 경로와 `list_loaded_dlls`의 프로세스 식별자도 환경변수로 넘긴다 [22].
없는 경로로 부른 `get_file_metadata`와 `collect_event_log_events`의 실행 함수는 고정된 스크립트와 모델 값을 담은 환경변수를 받았다 [23].
Sysinternals 도구, `IR_Collect.exe`, Hayabusa, EZ Tools, capa, YARA 실행에는 셸을 거치지 않는다 [9][10][11].

```python
def run_ircollect(cfg: Config, args: list[str], cwd: Path | None = None,
                  timeout: int | None = None) -> tuple[int, str, str]:
    """Run IR_Collect.exe with args. Returns (exit_code, stdout_text, stderr_text).
    stdout is unreliable for winexe — callers read the output FILE, not this."""
    cmd = [str(cfg.exe_path), *args]
    eff_timeout = timeout if timeout is not None else cfg.analyze_timeout
    try:
        result = subprocess.run(
            cmd,
            capture_output=True,
            timeout=eff_timeout,
            check=False,
            creationflags=CREATE_NO_WINDOW,
            cwd=(str(cwd) if cwd else None),
        )
    except subprocess.TimeoutExpired:
        return (-1, "", f"IR_Collect timed out after {eff_timeout}s.")
    except OSError as exc:
        return (-1, "", f"failed to launch IR_Collect ({cfg.exe_path}): {exc}")
    return (result.returncode, decode_output(result.stdout), decode_output(result.stderr))
```

```python
def run_powershell_json(
    script: str,
    env_overrides: dict[str, str] | None = None,
    timeout_seconds: int = 120,
) -> Any:
    """Run a fixed PowerShell script and parse its JSON output."""
    executable = find_powershell()
    if not executable:
        return {"error": "PowerShell executable was not found."}

    env = os.environ.copy()
    if env_overrides:
        env.update(env_overrides)

    creationflags = getattr(subprocess, "CREATE_NO_WINDOW", 0)

    try:
        result = subprocess.run(
            [executable, "-NoProfile", "-NonInteractive", "-Command", script],
            capture_output=True,
            text=True,
            encoding="utf-8",
            errors="replace",
            timeout=timeout_seconds,
            check=False,
            env=env,
            creationflags=creationflags,
        )
```
