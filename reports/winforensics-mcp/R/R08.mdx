# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 EVTX 질의 도구와 `evtx_attack_summary`의 `TimeCreated`, `windows_search_parse`의 행, `ingest_parsed_csv`의 일부 시각에 적용된다 [1][2][3][4][5].
EVTX 파서는 레코드의 `SystemTime` 속성 문자열을 바꾸지 않고 `TimeCreated`에 싣는다 [1].
Rust `evtx` 0.11.0으로 읽은 이 값은 `2016-07-08T18:12:51.681640Z` 꼴이다 [2].
`evtx_attack_summary`도 TSV 줄마다 같은 `TimeCreated` 값을 싣는다 [3].
`windows_search_parse`는 SIDR나 대체 경로가 만든 행의 시각 필드를 바꾸지 않고 싣는다 [4].
`ingest_parsed_csv`는 정해 둔 꼴에 맞지 않는 시각 문자열을 원래 문자열 그대로 싣는다 [5].

다른 도구는 시각을 바꾼 값만 싣고 원래 값을 함께 싣지 않는다.
Prefetch, USN, SRUM, MFT, LNK, 브라우저, PCAP 도구와 `registry_get_users`·`registry_get_system_info`는 FILETIME, epoch, OLE 날짜 같은 원래 값을 ISO 8601 문자열로 바꾼 값만 싣는다 [6].
`evtx_get_stats`의 기간도 `TimeCreated`를 바꾼 값만 싣는다 [7].

### R08.02 정규화 시간과 변환 전 값 병기

**구현.** 이 방식은 레지스트리 값을 싣는 도구와 EVTX 질의의 `timestamp_precision: both`에 적용된다 [8].
레지스트리 도구는 `REG_QWORD` 값의 이름이 서버가 정해 둔 시각 값 이름 목록에 있으면 원래 정수 `data` 옆에 바꾼 값 `data_utc`를 싣는다 [8].
`data_utc`는 FILETIME의 100나노초 자릿수 7자리를 남긴 UTC 문자열이다 [8][9].
EVTX 질의에 `timestamp_precision`을 `both`로 주면 원래 `TimeCreated` 옆에 초 단위로 줄인 UTC 시각 `timestamp_second`를 싣는다 [10].

**한계.** `data_utc`는 이름 목록에 있는 `REG_QWORD` 값에만 붙는다 [8].
목록에 없는 시각 값과 이진 자료로 저장된 시각에는 바꾼 값이 없다 [8].
`TimeCreated`를 읽지 못하면 `timestamp_second`는 `null`이 되고 읽지 못했다는 표시는 없다 [10].

### R08.03 시간대·단위·정밀도 표시

**구현.** 서버가 바꾼 시각은 대부분 UTC 오프셋 `+00:00`을 붙인 ISO 8601 문자열이다 [6][7].
Prefetch, USN, SRUM, LNK, 브라우저 파서와 `registry_get_users`·`registry_get_system_info`, `evtx_get_stats`·`evtx_list_files`는 UTC 시간대를 붙인 `datetime`을 `isoformat()`으로 싣는다 [6][7].
MFT 파서는 라이브러리가 시간대 없이 준 시각에 UTC를 붙여 싣는다 [11].
`data_utc`는 필드 이름과 값 끝의 `+00:00`으로 UTC임을 밝힌다 [8].
LNK 파서는 대상 파일 시각의 필드 이름에 `_utc`를 붙인다 [12].
PCAP 도구는 `utcfromtimestamp`로 바꾼 값 끝에 `Z`를 붙인다 [13].
VirusTotal 조회 도구는 `vt-py` 0.22.0이 UTC `datetime`으로 바꿔 준 날짜 속성을 `isoformat()`으로 실으므로 값 끝에 `+00:00`이 붙는다 [14].

**한계.** 일부 시각은 시간대 표시 없이 실린다.
레지스트리 키의 마지막 쓰기 시각 `timestamp`, Amcache의 `key_timestamp`, USB의 `first_connected`는 python-registry가 시간대 없이 돌려준 UTC 값을 `isoformat()`으로 그대로 싣는다 [15][2].
`timestamp_second`는 UTC 값이지만 값과 필드 이름에 시간대가 없고 도구 설명에만 UTC라고 적는다 [10][16].
`ingest_parsed_csv`는 CSV 시각을 시간대 없는 ISO 꼴로 바꾸어 싣는다 [5].

`registry_get_usb_history`는 `first_connected`가 USBSTOR 키의 마지막 쓰기 시각이라는 것을 `first_connected_source`로 밝히지만 시간대는 밝히지 않는다 [15].
`build_timeline`은 시간대 없는 Amcache 시각과 `+00:00`이 붙은 다른 출처의 시각을 한 목록에 두고 문자열 차례로 정렬한다 [17].

같은 FILETIME이 도구마다 마지막 자리가 다르게 실린다.
Prefetch, USN, SRUM은 FILETIME을 부동소수 초로 바꾸어 마이크로초로 반올림하고 레지스트리와 LNK 파서는 정수 나눗셈으로 마이크로초 아래를 버린다 [6][9].
응답에는 어느 방식으로 줄였는지 표시가 없다 [9].
Prefetch, USN, SRUM은 1970년 이전의 FILETIME을 `None`으로 바꾸므로 시각이 기록되지 않은 경우와 응답에서 같다 [6].

def _parse_timestamp(value: str) -> Optional[str]:
    """Parse various timestamp formats to ISO format."""
    if not value or value.strip() == "":
        return None

    # Try common formats
    formats = [
        "%Y-%m-%d %H:%M:%S.%f",
        "%Y-%m-%d %H:%M:%S",
        "%Y-%m-%dT%H:%M:%S.%f",
        "%Y-%m-%dT%H:%M:%S",
        "%m/%d/%Y %H:%M:%S",
        "%m/%d/%Y %I:%M:%S %p",
    ]

    for fmt in formats:
        try:
            dt = datetime.strptime(value.strip(), fmt)
            return dt.isoformat()
        except ValueError:
            continue

    # Return as-is if no format matches
    return value.strip()
```

def filetime_to_datetime(filetime: int) -> Optional[datetime]:
    """Convert Windows FILETIME to datetime"""
    if filetime <= 0:
        return None
    try:
        # Integer arithmetic avoids loss of precision from a float Unix timestamp.
        return FILETIME_EPOCH + timedelta(microseconds=filetime // 10)
    except (ValueError, OverflowError):
        return None


def filetime_to_utc(filetime: int) -> str | None:
    """Render FILETIME in UTC, retaining its full 100-nanosecond precision."""
    timestamp = filetime_to_datetime(filetime)
    if timestamp is None:
        return None
    whole_seconds = timestamp.replace(microsecond=0).isoformat().removesuffix("+00:00")
    return f"{whole_seconds}.{filetime % 10_000_000:07d}+00:00"
```
