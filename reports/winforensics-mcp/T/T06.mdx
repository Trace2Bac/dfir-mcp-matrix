# T06 실행 환경정보 표시

### T06.01 응답 메타데이터에 버전 표시

**구현.** 이 방식은 `windows_search_parse`의 SIDR 실행 경로와 `hunt_ioc_pack`에 적용된다 [1][2].
`windows_search_parse`는 SIDR로 분석하면 응답의 `backend_metadata`에 실행 파일 경로, 실행 파일의 SHA-256, 코드에 정한 기대 버전 `0.9.2`, 빌드 기준 커밋 `c7d3744…`, `--version`이 출력한 버전 문자열을 싣는다 [1].
서버는 이 버전 문자열을 읽어 `0.9.2`가 없으면 분석을 실행하지 않으므로 실린 버전은 그 분석을 실행한 SIDR의 버전이다 [1].
실행 확인에서 저장소의 `.tools/sidr_x86`으로 실행하면 `backend_metadata.version`에 `sidr 0.9.2`가 실렸다 [3].

`hunt_ioc_pack`은 응답의 `pack`에 검사에 쓴 IoC 묶음의 `id`, `name`, `version`, `license`, `upstream`, 규칙 수를 싣는다 [2].
이 값은 묶음 파일 `pack.json`에서 읽고 `version`은 묶음을 읽을 때 반드시 있어야 하는 필드다 [4].
저장소에 들어 있는 `impacket-iocs` 묶음의 `version`은 `2026.05.21.3`이다 [5].
`ioc_pack_list`도 묶음마다 같은 버전을 돌려준다 [4].

서버의 다른 결과에는 도구나 참조 자료의 버전이 실리지 않는다.
YARA 도구의 결과는 일치한 규칙의 이름, namespace, 태그, 규칙의 `meta`를 싣고 규칙 묶음의 출처나 버전을 싣지 않는다 [6].
저장소의 규칙 안내 문서는 규칙의 출처를 `Neo23x0/signature-base`로만 적고 가져온 커밋을 적지 않는다 [7].
DiE 도구의 결과에 있는 `version`은 `diec`가 판별한 패커나 컴파일러의 버전이고 `diec` 자신의 버전이 아니다 [8].
`diec --version`을 읽는 `get_die_version`이 모듈에 있지만 서버의 처리 분기는 이 함수를 부르지 않는다 [9].
EVTX, 레지스트리, PE, Prefetch, SRUM 같은 파서 도구의 응답에는 쓴 라이브러리의 버전이 없다.
서버는 MCP SDK의 `Server`에 패키지 버전 `__version__`(1.5.0)을 주고 이 값은 초기화 응답의 `serverInfo`에만 실린다 [10].
서버는 호출 기록을 남기지 않고 모델을 부르지 않는다.

**한계.** `windows_search_parse`가 SIDR 대신 `pyesedb`로 읽으면 `backend_metadata`가 없고 `pyesedb`의 버전도 싣지 않는다 [1][11].
`hunt_ioc_pack`이 `pack_path`로 외부 묶음을 읽으면 `version`은 그 파일이 적은 값을 그대로 싣고 서버는 값의 형식을 확인하지 않는다 [4].
`hunt_ioc_pack`의 PCAP 검사는 `scapy`로 하지만 응답에 `scapy`의 버전은 없다 [2].

```python
def _sidr_rows(binary: Path, copied: Path, output: Path, timeout: int, result: dict):
    result["backend"] = "sidr"
    result["backend_metadata"] = {
        "path": str(binary),
        "sha256": _sha256(binary),
        "expected_version": SIDR_VERSION,
        "pinned_build_commit": SIDR_COMMIT,
    }
    # Redirect to files so a noisy/crashing sidecar cannot exhaust Python memory.
    with (output / "version.log").open("w+b") as version_log:
        version = subprocess.run(
            [str(binary), "--version"],
            stdout=version_log,
            stderr=subprocess.STDOUT,
            timeout=min(timeout, 10),
            check=False,
            cwd=output,
        )
        version_log.seek(0)
        version_text = version_log.read(1024).decode("utf-8", errors="replace").strip()
    result["backend_metadata"]["version"] = version_text
    if version.returncode or not re.search(r"\b0\.9\.2\b", version_text):
        raise ValueError(f"SIDR {SIDR_VERSION} is required; observed {version_text!r}")
```
