# T02 실행 허용 범위 제한

### T02.04 고정 명령·템플릿

**구현.** 이 방식은 서버의 도구 74개와 서버가 실행하는 외부 실행 파일 `diec`·SIDR, WinRM 원격 명령에 적용된다 [1][2][3][4].
모델은 `list_tools`가 정한 도구 가운데 하나를 고르고 처리기는 도구 이름마다 부를 파서 함수를 정해 둔다 [1].
목록에 없는 이름은 `Unknown tool` 오류 글을 돌려준다 [1].
`die_analyze_file`·`die_scan_directory`는 `diec`에 `-j`, 선택적인 `-d`, 파일 경로로 이루어진 인자 배열을 넘긴다 [2].
`windows_search_parse`는 SIDR에 `--version`과 `-f json -r to-file -o <출력 폴더> <입력 폴더>`를 넘긴다 [3].
SIDR에 넘기는 입력 폴더는 서버가 원본을 복사해 둔 임시 폴더다 [3].
`remote_collect_artifacts`·`remote_get_system_info`는 코드에 적힌 PowerShell 스크립트를 실행하고 모델은 접속 대상, 계정, 출력 폴더, 수집 묶음 선택만 넘긴다 [4][5].
수집 대상 원격 파일 경로는 서버 코드의 목록 `ARTIFACT_PATHS`로 정해져 있다 [5].
나머지 도구는 외부 프로그램을 실행하지 않고 서버 프로세스 안의 파서로 처리한다.

모델이 분석 규칙을 고르는 인자도 있다.
YARA 도구의 `rule_paths`에 준 `.yar`·`.yara` 파일과 폴더는 서버가 내용을 검사하지 않고 `yara.compile`에 넘긴다 [6].
`hunt_ioc_pack`의 `pack_path`에 준 IoC 묶음은 필수 필드가 있고 `rules`가 목록인지만 확인한 뒤 그 정규식으로 파일과 PCAP을 검색한다 [7].
`registry_query`·`disk_parse_srum`의 정규식 인자는 컴파일하지 못할 때만 거부한다 [8][9].
`pcap_search`의 정규식은 컴파일 예외가 오류 글로 돌아간다 [10].
서버는 정규식의 구조나 연산을 검사하지 않는다.

**한계.** `windows_search_parse`의 `sidr_path`는 모델이 실행 파일을 고르는 인자다 [11].
서버는 그 파일을 버전 확인 전에 `--version` 인자로 먼저 실행한다 [3].
버전 문자열에 `0.9.2`가 없으면 본 실행은 하지 않지만 `--version` 실행은 이미 일어난다 [3].
`sidr 0.9.1`을 출력하는 셸 스크립트를 `sidr_path`로 주자 서버가 그 스크립트를 `--version` 인자로 실행했다 [12].
`diec`에 넘기는 파일 경로 앞에는 옵션 끝을 알리는 `--`가 없어 `-`로 시작하는 경로도 그대로 인자가 된다 [2].
다만 그 이름의 파일이 있어야 `diec`을 실행한다 [2].

### T02.05 연산·플러그인 허용 목록

**구현.** 이 방식은 모델이 조회 종류나 모드를 고르는 인자에 적용된다.
`evtx_security_search`는 `event_type`을 서버 코드의 사건 종류 13개와 대조해 정해 둔 Event ID 묶음으로 바꾸고 목록에 없으면 거부한다 [13].
`evtx_attack_summary`는 `event_type` 5개마다 Event ID와 뽑을 필드를 정해 두고 목록에 없으면 거부한다 [14].
`registry_query`의 `match_mode`도 `substring`·`exact`·`regex` 밖의 값을 거부한다 [8].
이 인자들은 `inputSchema`에도 같은 값 목록이 있어 SDK가 먼저 거부한다 [15].

`disk_parse_usn_journal`의 `output_mode`는 `summary`·`deleted_files`가 아니면 모두 레코드 목록 모드로 처리한다 [16].
`inputSchema`의 값 목록 때문에 MCP 호출에서는 목록 밖의 값이 처리기에 닿지 않는다 [15].

```python
def _resolve_sidr(explicit: str | None) -> tuple[Path | None, list[str]]:
    machine = platform.machine().casefold()
    bundled_name = None
    if machine in {"aarch64", "arm64"}:
        bundled_name = "sidr"
    elif machine in {"x86_64", "amd64"}:
        bundled_name = "sidr_x86"
    candidates = (
        [explicit]
        if explicit
        else [
            os.environ.get("WINFORENSICS_SIDR_PATH"),
            str(REPO_ROOT / ".tools" / bundled_name) if bundled_name else None,
            shutil.which("sidr"),
        ]
    )
    checked = []
    for candidate in candidates:
        if not candidate:
            continue
        path = Path(candidate).expanduser().resolve()
        checked.append(str(path))
        if path.is_file() and os.access(path, os.X_OK):
            return path, checked
    return None, checked
```
