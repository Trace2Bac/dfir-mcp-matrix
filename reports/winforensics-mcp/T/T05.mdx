# T05 분석 도구 검증

### T05.01 저장소·의존성 고정

**구현.** 이 방식은 증거 파서 라이브러리, 저장소에 함께 넣은 참조 자료, Windows Search 분석에 쓰는 SIDR 실행 파일에 적용된다 [1][2][3].
`pyproject.toml`은 증거 파서 의존성을 `evtx>=0.8.0`처럼 하한만 적는다 [1].
`uv.lock`은 `evtx` 0.11.0, `python-registry` 1.3.1, `pefile` 2024.8.26, `libscca-python` 20250915, `libesedb-python` 20240420, `mft` 0.7.0, `pylnk3` 0.4.3, `libfwsi-python` 20260522와 선택 의존성 `yara-python` 4.5.4, `scapy` 2.7.0을 배포 파일 해시와 함께 고정한다 [2].
README는 소스에서 설치할 때 `uv sync`를 권하고 `uv sync`는 이 잠금 파일대로 설치한다 [4].

YARA 규칙 `winforensics_mcp/rules/*.yar`, IoC 묶음 `ioc_packs/impacket-iocs/pack.json`, Windows API 정의 DB `data/api_definitions.db`는 저장소에 들어 있어 기준 커밋이 내용을 정한다 [3].
`pyproject.toml`은 이 세 자료를 패키지에 함께 넣도록 적는다 [3].
IoC 묶음은 `version` 값 `2026.05.21.3`과 원본 저장소 주소를 적는다 [5].
YARA 규칙의 README는 원본을 `Neo23x0/signature-base`로 적지만 가져온 커밋은 적지 않는다 [6].
중요 Event ID 표와 레지스트리 키 표는 `config.py`의 상수다 [7].

SIDR 실행 파일은 `.tools/sidr`(ARM64)와 `.tools/sidr_x86`(x86_64)로 저장소에 들어 있다 [8].
각 manifest는 SIDR 0.9.2, 원본 커밋 `c7d3744`, 빌드 명령, 실행 파일의 SHA-256을 적는다 [8].
다시 빌드하는 `scripts/build_sidr.sh`는 SIDR 저장소를 그 커밋으로 checkout하고 `HEAD`가 그 커밋인지 확인한 뒤 `cargo build --locked`로 만든다 [9].

`diec`은 저장소가 버전을 정하지 않는다 [10].
MCP SDK `mcp` 1.25.0도 `uv.lock`이 고정하지만 증거를 해석하지 않는 서버 실행용 라이브러리라 이 방식으로 보지 않는다 [2].

**한계.** PyPI 설치(`uv tool install winforensics-mcp`)는 `uv.lock`을 쓰지 않고 `pyproject.toml`의 하한 범위로 의존성을 고른다 [1][4].
README가 선택 의존성까지 설치하는 방법으로 적은 `uv pip install -e ".[all]"`도 잠금 파일을 쓰지 않는다 [4].
그래서 `yara-python`·`scapy`의 고정 버전은 사용자가 잠금 파일로 선택 의존성을 설치할 때만 적용된다 [2][4].
패키지에 넣는 파일 목록에 `.tools/`가 없어 PyPI 설치본에는 저장소의 SIDR 실행 파일이 없다 [3].
서버는 SIDR 실행 파일의 SHA-256을 계산해 응답에 싣지만 manifest의 값과 대조하지 않는다 [11].

### T05.02 설정·호출 인자로 지정

**구현.** 이 방식은 SIDR 실행 파일, YARA 규칙, IoC 묶음의 위치에 적용된다 [12][13][14].
`windows_search_parse`는 `sidr_path` 인자를 주면 그 파일만 쓴다 [12].
인자가 없으면 환경변수 `WINFORENSICS_SIDR_PATH`, 실행 환경 아키텍처에 맞는 `.tools`의 실행 파일, `PATH`의 `sidr` 차례로 실행 가능한 첫 파일을 쓴다 [12].
응답의 `checked_sidr_locations`에 확인한 경로를 적는다 [15].
YARA 도구 3개는 `rule_paths`로 규칙 파일이나 폴더를 받고 없으면 패키지의 `rules` 폴더를 쓴다 [13].
`hunt_ioc_pack`은 `pack_path`로 외부 IoC 묶음 파일을, `ioc_pack_list`는 `extra_paths`로 더 볼 묶음을 받는다 [14].
`diec`은 설정이나 인자로 정하지 않고 모듈을 불러올 때 `PATH`와 정해 둔 설치 폴더 6곳에서 찾는다 [10].

**한계.** `WINFORENSICS_SIDR_PATH`가 가리키는 파일이 없거나 실행할 수 없으면 알리지 않고 다음 후보를 쓴다 [12].
이때 응답의 `checked_sidr_locations`에는 확인한 경로가 남는다 [15].
YARA 규칙은 규칙 파일 경로 목록을 키로 컴파일 결과를 1시간 동안 서버 메모리에 둔다 [16].
그래서 같은 경로의 규칙 파일 내용이 바뀌어도 1시간 안의 호출은 앞서 컴파일한 규칙을 쓴다 [16].
`compile_rules`는 규칙 파일을 namespace를 키로 한 `dict`에 모은다 [17].
namespace는 파일을 받으면 확장자를 뺀 파일 이름이고 폴더를 받으면 그 폴더 기준 상대 경로의 구분자를 `_`로 바꾼 값이다 [17].
그래서 `rule_paths`로 받은 규칙 파일 가운데 namespace가 같은 파일은 뒤에 넣은 것만 컴파일되고 앞의 파일은 응답에 알리지 않고 빠진다 [17].
이름이 같은 파일을 여러 폴더에서 주는 경우와 한 폴더 안에서 상대 경로를 `_`로 이은 값이 같아지는 경우가 여기에 해당한다 [17].

### T05.03 실행 시 버전 조회

**구현.** 이 방식은 `windows_search_parse`가 실행하는 SIDR에 적용된다 [11].
서버는 SIDR를 분석에 쓰기 전에 `--version`으로 실행해 출력 앞 1024바이트를 읽는다 [11].
읽은 버전 문자열, 실행 파일 경로, SHA-256, 기대 버전, 고정 빌드 커밋을 응답의 `backend_metadata`에 적는다 [11].
`diec`의 버전을 읽는 함수 `get_die_version`이 있지만 어느 도구도 부르지 않는다 [18].
파이썬 라이브러리의 버전은 실행 중에 읽지 않는다.

### T05.04 참조 자료 버전·식별값 조회

**구현.** 이 방식은 IoC 묶음에 적용된다 [5][19].
`ioc_pack_list`와 `hunt_ioc_pack`은 묶음 파일의 `id`·`name`·`version`·`license`를 읽어 응답에 싣는다 [19][20].
`hunt_ioc_pack`은 `upstream` 주소와 규칙 수도 싣는다 [20].
묶음을 불러올 때 이 필드가 없으면 거부한다 [21].
YARA 규칙과 Windows API 정의 DB의 버전이나 식별값은 읽지 않는다.
`yara_list_rules`는 규칙 파일마다 경로, namespace, `skipped` 값을 돌려주고 쓸 수 있는 파일 수 `usable_files`를 함께 싣는다 [22].
이 응답에 규칙 묶음의 버전이나 가져온 커밋은 없다 [22].

### T05.05 사용 전 기대값 대조

**구현.** 이 방식은 `windows_search_parse`가 실행하는 SIDR에 적용된다 [11].
서버는 SIDR로 분석하기 직전에 `--version` 출력을 기대 버전 `0.9.2`와 대조한다 [11].
출력에 `0.9.2`가 없거나 종료 코드가 0이 아니면 분석 실행 없이 `SIDR 0.9.2 is required` 오류로 끝낸다 [11].
서버는 SIDR 실행 파일의 SHA-256도 계산하지만 manifest가 적은 값과 대조하지 않고 응답에 싣기만 한다 [11].
`diec`에는 실행 전에 버전이나 해시를 대조하는 단계가 없다 [18].

**한계.** 버전 대조는 출력 어딘가에 `0.9.2`라는 낱말이 있는지만 본다 [11].
`not sidr but mentions 0.9.2`를 출력하는 셸 스크립트를 `sidr_path`로 주자 서버가 그 스크립트를 SIDR 분석 인자로 다시 실행했다 [23].

def _find_diec() -> Optional[str]:
    """Find diec executable in PATH or common locations."""
    # Check PATH first
    diec_path = shutil.which("diec")
    if diec_path:
        return diec_path

    # Check common installation locations
    common_paths = [
        "/usr/bin/diec",
        "/usr/local/bin/diec",
        "/opt/die/diec",
        "/opt/detect-it-easy/diec",
        os.path.expanduser("~/.local/bin/diec"),
        os.path.expanduser("~/DIE/diec"),
    ]

    for path in common_paths:
        if os.path.isfile(path) and os.access(path, os.X_OK):

def _sidr_rows(binary: Path, copied: Path, output: Path, timeout: int, result: dict):
    result["backend"] = "sidr"
    result["backend_metadata"] = {
        "path": str(binary),
        "sha256": _sha256(binary),
        "expected_version": SIDR_VERSION,
        "pinned_build_commit": SIDR_COMMIT,
    }
    # Redirect to files so a noisy/crashing sidecar cannot exhaust Python memory.
    with (output / "version.log").open("w+b") as version_log:
        version = subprocess.run(
            [str(binary), "--version"],
            stdout=version_log,
            stderr=subprocess.STDOUT,
            timeout=min(timeout, 10),
            check=False,
            cwd=output,
        )
        version_log.seek(0)
        version_text = version_log.read(1024).decode("utf-8", errors="replace").strip()
    result["backend_metadata"]["version"] = version_text
    if version.returncode or not re.search(r"\b0\.9\.2\b", version_text):
        raise ValueError(f"SIDR {SIDR_VERSION} is required; observed {version_text!r}")

def _resolve_sidr(explicit: str | None) -> tuple[Path | None, list[str]]:
    machine = platform.machine().casefold()
    bundled_name = None
    if machine in {"aarch64", "arm64"}:
        bundled_name = "sidr"
    elif machine in {"x86_64", "amd64"}:
        bundled_name = "sidr_x86"
    candidates = (
        [explicit]
        if explicit
        else [
            os.environ.get("WINFORENSICS_SIDR_PATH"),
            str(REPO_ROOT / ".tools" / bundled_name) if bundled_name else None,
            shutil.which("sidr"),
        ]
    )
    checked = []
    for candidate in candidates:
        if not candidate:
            continue
        path = Path(candidate).expanduser().resolve()
        checked.append(str(path))
        if path.is_file() and os.access(path, os.X_OK):
            return path, checked
    return None, checked
