# F05 발견사항·결론 근거 검증

### 비적용

**판단.** 서버에는 발견사항, 결론, 부재 주장을 받거나 저장하거나 보고하는 경로가 없다.
도구 74개 가운데 발견사항이나 주장을 인자로 받는 도구가 없고 보고 산출물을 쓰는 도구도 없다 [1][2].

서버가 스스로 만드는 판정과 부재 요약은 응답으로만 돌아간다.
`investigate_execution`은 대상이 어느 출처에서도 찾아지지 않으면 "No execution evidence found"로 시작하는 요약을 응답에 싣는다 [3].
`hunt_ioc`는 일치한 출처가 없으면 검색한 출처 수와 함께 "not found in any of the … sources searched" 요약을 응답에 싣는다 [4].
서버는 이 판정과 요약을 저장하거나 다른 도구의 입력으로 다시 받지 않는다 [3][4].

```python
def _generate_summary(
    target: str,
    execution_confirmed: bool,
    confidence: str,
    evidence_results: list[dict],
) -> str:
    """Generate human-readable summary"""
    if not execution_confirmed:
        sources_searched = [r["source"] for r in evidence_results if r.get("available", True)]
        return f"No execution evidence found for '{target}' in {', '.join(sources_searched)}"

    findings = []
    for result in evidence_results:
        if result.get("found") and result.get("finding"):
            findings.append(f"- {result['source']}: {result['finding']}")

    summary = f"Execution of '{target}' confirmed ({confidence} confidence):\n"
    summary += "\n".join(findings)

    return summary
```
