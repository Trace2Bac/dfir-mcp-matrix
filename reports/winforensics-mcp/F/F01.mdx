# F01 판단 지침

### 미구현

**판단.** 서버는 도구 설명, 서버 지침, 리소스, 응답 어디에도 조사 전체의 해석 원칙이나 발견사항·결론을 서술하고 확인하는 방식을 적지 않는다.
서버는 MCP SDK의 저수준 `Server`를 이름과 버전만으로 만들고 서버 지침(`instructions`)을 넘기지 않는다 [1].
등록한 요청 처리기는 `list_tools`와 `call_tool`뿐이어서 리소스와 프롬프트가 없다 [2].

도구 설명에 실린 주의 문구는 모두 그 도구 결과 하나의 뜻을 설명한다 [3].

- `evtx_ntlm_operational_summary`의 `unusual_only` 설명은 드문 조합이 공격 판정이 아니라고 적는다 [3].
- `evtx_correlate_logon_id`의 설명은 logon ID가 같다는 것만으로 호스트나 재부팅을 넘어 같은 세션이라고 할 수 없다고 적는다 [3].
- `windows_search_parse`의 설명은 불완전한 추출에서 결과가 0건인 것은 결론이 아니라고 적는다 [3].
- `disk_parse_srum`의 설명은 자원 카운터를 실행 시간으로 해석하지 않는다고 적는다 [3].

`evtx_ntlm_operational_summary`의 응답도 같은 뜻의 `rarity_note`를 싣지만 이 도구의 응답에만 붙는다 [4].
도구와 관계없이 응답에 붙는 문구는 공통 응답 처리기 `json_response`가 응답을 줄였을 때 넣는 `_truncation` 안내뿐이다 [5].
이 안내는 오래된 자료만 남았을 수 있다는 경고와 시간 범위나 `offset`으로 나눠 다시 부르라는 힌트이고 판단의 원칙이나 서술 방식을 다루지 않는다 [5].
