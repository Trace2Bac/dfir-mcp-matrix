# F04 발견사항·결론 기록 관리

### 비적용

**판단.** 서버에는 발견사항, 결론, 가설, 단서 메모를 받아 남기는 도구가 없다.
도구 74개는 증거 파일을 파싱하거나 조회하거나 외부 서비스에 질의하거나 원격 호스트에서 아티팩트를 수집하는 도구이고 도구 정의에 발견사항이나 메모를 인자로 받는 도구가 없다 [1].
도구 이름별 처리에도 받은 내용을 저장소에 남기는 분기가 없다 [2].

파일을 쓰는 도구는 세 개이고 모두 서버가 읽거나 받아 온 자료를 쓴다.

- `evtx_export`는 조건에 맞는 EVTX 레코드를 JSONL 파일로 쓴다 [3].
- `vt_lookup_behavior`는 `triage_dir`을 주면 VirusTotal 행위 분석 응답을 JSON 파일로 쓴다 [4].
- `remote_collect_artifacts`는 원격 호스트에서 가져온 이벤트 로그와 레지스트리 하이브를 `output_dir`에 쓴다 [5].

`investigate_execution`, `hunt_ioc` 같은 도구가 만드는 판정과 요약은 응답으로만 돌려주고 서버에 남기지 않는다 [6].
