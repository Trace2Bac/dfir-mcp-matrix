# F06 보고 산출물 구성

### 비적용

**판단.** 서버에는 사건 단위가 없고 보고 산출물을 만들거나 내보내는 도구도 없다.
도구는 호출마다 증거 파일이나 폴더 경로를 인자로 받고 사건이나 조사 세션을 가리키는 식별자를 받거나 만들지 않는다 [1].
서버는 호출 사이에 발견사항이나 호출 기록을 모아 두지 않는다 [2].

파일을 쓰는 도구는 세 개이고 어느 것도 조사의 범위, 방법, 결과, 한계, 판단의 확정 상태를 싣지 않는다.

- `evtx_export`는 조건에 맞는 EVTX 레코드만 JSONL 파일에 쓴다 [3].
- `vt_lookup_behavior`는 `triage_dir`을 주면 VirusTotal 행위 분석 응답을 그대로 JSON 파일로 쓴다 [4].
- `remote_collect_artifacts`는 원격 호스트의 이벤트 로그와 레지스트리 하이브를 `output_dir`에 복사한다 [5].

`evtx_export`는 파일의 SHA-256, 행 수, 스캔 완료 여부, 원본 파일의 경로·크기·수정 시각, 질의 조건을 파일이 아니라 응답에만 싣는다 [6].

같은 저장소에는 서버 응답을 가공해 보고 산출물을 만드는 사용자 CLI나 클라이언트 코드가 없다.
패키지의 실행 진입점은 서버 시작 `main` 하나다 [7].
