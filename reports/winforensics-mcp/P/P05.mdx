# P05 사건 자료 정리

### P05.01 모델 도구로 삭제·초기화

**구현.** 이 방식은 사건 자료를 바꿔 쓸 수 있는 도구 `remote_collect_artifacts`와 `vt_lookup_behavior`에 적용된다 [1][2].
파일을 지우는 MCP 도구는 없다.
`remote_collect_artifacts`는 인자 `output_dir` 아래 `evtx/<이름>.evtx`와 `registry/<하이브 이름>`처럼 정해 둔 이름으로 수집 파일을 쓴다 [1].
같은 `output_dir`로 다시 부르면 앞서 수집한 같은 이름의 파일을 새로 받은 내용으로 바꾼다 [3][4].
`vt_lookup_behavior`는 `triage_dir`을 주면 해시 앞 12자로 정한 `vt-behavior-<해시>.json`에 응답 전체를 쓰고 같은 이름의 파일이 있으면 바꾼다 [2].
두 도구 모두 받은 경로를 검사하지 않고 그 아래에 쓴다 [1][2].
바꾼 파일이나 앞선 내용을 기록하지 않는다 [1][2].
서버 메모리의 EVTX 캐시를 비우는 함수 `evtx_clear_cache`는 있지만 MCP 도구로 등록되어 있지 않다 [5].

**한계.** `remote_collect_artifacts`가 원격 파일을 받지 못한 항목은 실패로 응답에 실리고 `output_dir`의 앞선 수집 파일은 그대로 남는다 [6].
그래서 다시 수집한 뒤의 `output_dir`에는 이번에 받은 파일과 앞선 수집 파일이 섞일 수 있고 응답은 이 구별을 알리지 않는다 [1][6].

### P05.03 자동 정리

**구현.** 이 방식은 `windows_search_parse`, 브라우저 기록 파서, `evtx_export`가 호출 중에 만드는 작업 파일에 적용된다 [7][8][9].
`windows_search_parse`는 `TemporaryDirectory` 안에 원본 `Windows.edb`의 사본과 SIDR 출력 폴더를 만들고 호출이 끝나면 폴더째 지운다 [7].
브라우저 기록 파서는 SQLite DB와 `-wal`·`-shm`·`-journal` 파일을 `mkdtemp`로 만든 임시 폴더에 복사해 읽고 `finally`에서 그 폴더를 지운다 [8][10].
`evtx_export`는 내보내기 폴더에 `mkstemp`로 만든 `.part` 파일에 사건을 쓰고 새 이름으로 하드링크를 만든 뒤 `.part` 파일을 지운다 [9].
내보내기가 실패하면 `.part` 파일과 이번 호출이 만든 결과 파일 후보를 지운다 [9].
지운 사실은 응답이나 기록에 남지 않는다 [7][10][9].
서버가 종료될 때 따로 지우는 코드는 없다.

**한계.** 브라우저 기록 파서는 임시 폴더를 `ignore_errors=True`로 지우므로 지우지 못해도 알리지 않고 증거 DB 사본이 임시 폴더에 남는다 [10].

### P05.04 원본 증거까지 삭제 대상에 포함

**구현.** 이 방식은 `remote_collect_artifacts`의 바꿔 쓰기에 적용된다 [1].
`remote_collect_artifacts`는 `output_dir`가 어떤 폴더인지 확인하지 않고 그 아래 `evtx/`와 `registry/`의 정해 둔 이름에 수집 파일을 쓴다 [1][3].
그래서 앞서 수집해 둔 증거 파일이 있는 폴더를 `output_dir`로 주면 그 증거 파일을 새로 받은 내용으로 바꾸고 앞선 내용은 남기지 않는다 [3][4].
대상을 서버가 만든 작업 파일로 한정하는 장치는 없다 [1].
`vt_lookup_behavior`가 바꾸는 파일은 `vt-behavior-<해시>.json` 이름의 파일뿐이다 [2].

### P05.05 원본 증거를 삭제 대상에서 제외

**구현.** 이 방식은 자동 정리에 적용된다.
자동 정리가 지우는 대상은 그 호출이 `TemporaryDirectory`, `mkdtemp`, `mkstemp`로 만든 폴더와 파일이다 [7][8][9].
`evtx_export`는 파일을 지우기 전에 장치 번호와 inode가 이번 호출이 만든 `.part` 파일과 같은지 확인하고 다르면 지우지 않는다 [11].
원본 증거는 사본을 만들 때 읽기만 하고 지우는 대상에 없다 [7][8].

```python
def _copy_to_temp(db_path: Path) -> Path:
    """
    Copy database to temp location to avoid SQLite locking issues.
    Browser databases are often locked when the browser is running.
    """
    temp_dir = tempfile.mkdtemp(prefix="browser_history_")
    temp_path = Path(temp_dir) / db_path.name
    shutil.copy2(db_path, temp_path)

    # Also copy any WAL/SHM files if present
    for suffix in ['-wal', '-shm', '-journal']:
        wal_path = db_path.parent / (db_path.name + suffix)
        if wal_path.exists():
            shutil.copy2(wal_path, temp_path.parent / (temp_path.name + suffix))

    return temp_path
```
