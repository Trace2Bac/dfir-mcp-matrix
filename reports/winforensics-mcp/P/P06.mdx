# P06 조사 상태 유지

### P06.02 프로세스 메모리에만 보관

**구현.** 서버 프로세스 메모리에 두는 상태는 EVTX 파싱 결과, NTDS 메타데이터, VirusTotal 조회 결과, 컴파일한 YARA 규칙의 캐시 4개와 VirusTotal에 마지막으로 요청한 시각이다.
EVTX 캐시 `_evtx_cache`는 파일 하나를 정한 `max_scan`까지 읽어 만든 사건 목록, 원래 레코드 문자열, 레코드 번호를 담는다 [1].
키는 파일 경로, 크기, 시각, 장치·inode 번호와 `max_scan`, 사용한 파서이고 EVTX 검색·상세 조회·로그온 ID 상관·내보내기가 이 캐시를 함께 쓴다 [2][3].
NTDS 캐시 `_CACHE`는 파일 식별 정보와 `max_scan`을 키로 스키마와 객체 메타데이터를 담는다 [4].
VirusTotal 캐시 `_cache`는 조회 대상별로 응답과 조회 시각을 담는다 [5].
해시 조회는 VirusTotal이 찾지 못했다고 답한 결과도 이 캐시에 넣고 IP·도메인 조회는 찾은 결과만 넣는다 [6].
YARA 캐시 `_rule_cache`는 규칙 파일의 namespace와 경로 목록을 줄인 값을 키로 컴파일한 규칙과 넣은 시각을 담는다 [7][8].
VirusTotal 모듈은 요청 간격을 재려고 마지막 요청 시각 `_last_request_time`을 둔다 [9].
네 캐시와 마지막 요청 시각은 파일이나 DB에 쓰지 않으므로 프로세스가 끝나면 사라진다 [1][4][5][7][9].

나머지 분석 도구는 호출마다 증거 파일을 다시 읽어 결과를 만든다.
열린 사건이나 작업 목록 같은 상태는 없다.
EVTX의 이어 읽기 값 `next_cursor`와 사건 참조 `event_ref`는 원본 식별 정보, 질의 해시, 위치를 담은 문자열이고 서버는 이를 따로 저장하지 않는다 [10].
캐시가 비어 있으면 `evtx_get_event`는 참조한 레코드 번호까지 파일을 다시 읽어 그 사건을 찾는다 [11].
도구가 내보내거나 수집해 쓰는 파일은 도구의 출력이고 서버는 이 파일을 다시 읽어 상태로 쓰지 않는다.

### P06.05 만료

**구현.** 이 방식은 네 캐시에 적용된다.
EVTX 캐시는 항목이 10개를 넘으면 가장 오래 쓰지 않은 항목부터 버린다 [2].
NTDS 캐시는 항목이 2개를 넘으면 가장 오래 쓰지 않은 항목부터 버린다 [4].
VirusTotal 캐시는 항목마다 24시간의 유효 시간을 둔다 [5].
유효 시간이 지난 항목은 다시 조회할 때 버린다 [5][12].
캐시에서 꺼낸 VirusTotal 응답에는 `_cached`와 캐시에 둔 시간 `_cache_age_hours`가 붙는다 [12].
YARA 캐시는 항목마다 3,600초의 유효 시간을 둔다 [7].
같은 키를 다시 찾을 때 유효 시간이 지나 있으면 규칙을 다시 컴파일해 그 항목을 바꾼다 [13].
EVTX·NTDS 캐시의 키에는 파일 크기와 시각이 들어 있어 파일이 바뀌면 새 항목을 만든다 [2][4].

**한계.** VirusTotal 캐시에는 개수 한도가 없고 유효 시간이 지난 항목도 같은 대상을 다시 조회하기 전에는 메모리에 남는다 [5][12].
YARA 캐시에도 개수 한도가 없고 유효 시간이 지난 다른 키의 항목을 지우는 코드가 없다 [13].
YARA 캐시의 키에는 규칙 파일의 내용이나 수정 시각이 없어 유효 시간 안에는 내용이 바뀐 규칙 파일도 앞서 컴파일한 규칙으로 검사한다 [8][13].
같은 경로의 규칙 내용을 바꾼 뒤 다시 검사한 실행에서 유효 시간 안에는 바꾸기 전 규칙이 일치했다 [14].

    key = source + (max_scan, EVTX_RUST_AVAILABLE)
    if key not in _evtx_cache:

    return _evtx_cache[key]

def _rate_limit() -> None:
    """Enforce rate limiting between requests."""
    global _last_request_time
    elapsed = time.time() - _last_request_time
    if elapsed < MIN_REQUEST_INTERVAL:
        sleep_time = MIN_REQUEST_INTERVAL - elapsed
        time.sleep(sleep_time)
    _last_request_time = time.time()
```

def _get_cached(key: str) -> Optional[dict]:
    """Get cached result if not expired."""
    if key in _cache:
        result, timestamp = _cache[key]
        if datetime.now() - timestamp < CACHE_TTL:
            result = dict(result)  # Copy to avoid mutation
            result["_cached"] = True
            result["_cache_age_hours"] = round(
                (datetime.now() - timestamp).total_seconds() / 3600, 1
            )
            return result
        else:
            # Expired, remove from cache
            del _cache[key]
    return None


def _set_cached(key: str, result: dict) -> None:
    """Cache result."""
    _cache[key] = (dict(result), datetime.now())
```
