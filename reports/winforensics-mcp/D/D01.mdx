# D01 파생물 보관

### D01.01 파생물 파일 보관

**구현.** 이 방식은 `evtx_export`, `triage_dir`을 준 `vt_lookup_behavior`, `remote_collect_artifacts`에 적용된다 [1][2][3].
`vt_lookup_behavior`와 `remote_collect_artifacts`는 선택 의존성 `vt-py`·`pywinrm`이 설치되어 있을 때만 도구 목록에 오른다 [4].
서버는 이 세 도구가 쓴 파일을 호출 뒤에 지우지 않는다.

`evtx_export`는 고른 EVTX 레코드를 JSON Lines 파일 하나에 한 줄씩 쓴다 [1].
한 줄은 서버 파서가 정규화한 이벤트 `dict`이고 `fields`를 주면 고른 필드와 `event_ref`만 담는다 [5].
파일은 모델이 준 `output_dir` 안에 `evtx-export-<난수>.jsonl` 이름으로 남는다 [6].
응답에는 행 전체가 아니라 파일 경로, 해시와 건수 같은 메타데이터, 앞쪽 몇 행의 미리보기를 싣는다 [7][8].
응답 크기 상한은 미리보기 행만 줄이고 파일에 쓰는 행에는 적용되지 않는다 [7].

`vt_lookup_behavior`는 `triage_dir`을 주면 VirusTotal에서 받은 행동 요약 응답 전체를 `vt-behavior-<해시 앞 12자>.json`으로 쓴다 [2].
모델에게는 서버가 고른 도메인, URL, 명령, 레지스트리·파일 쓰기 항목과 개수만 돌려주고 원래 응답 전체는 이 파일에만 남는다 [2].

`remote_collect_artifacts`는 WinRM으로 원격 Windows의 이벤트 로그 파일과 레지스트리 하이브를 base64 문자열로 받아 디코딩해서 파일로 쓴다 [3].
파일은 모델이 준 `output_dir` 아래 `evtx/`·`registry/` 폴더에 들어간다 [9].

그 밖의 도구는 결과를 응답으로만 돌려준다.
`windows_search_parse`는 `Windows.edb` 사본과 SIDR 출력 JSON을 `TemporaryDirectory` 아래에 두고 호출이 끝나면 그 폴더를 지운다 [10].
브라우저 기록 도구는 기록 DB를 임시 폴더에 복사해 읽은 뒤 그 폴더를 지운다 [11].
VirusTotal 조회 결과의 캐시는 프로세스 메모리의 `dict`에만 둔다 [12].
`ForensicsConfig`에 출력 폴더 기본값 `./forensics_output`이 정의되어 있지만 도구 처리 코드는 이 설정을 읽지 않는다 [13].
보관 기간, 용량, 대상을 정하는 설정이나 코드는 없다.
한 호출이 도구의 원래 출력과 그 가공본을 함께 파일로 남기는 경로는 없다.
`vt_lookup_behavior`는 원래 응답만 파일로 남기고 가공한 요약은 응답에만 싣는다 [2].

**한계.** `evtx_export`가 `max_scan`이나 `max_rows`에 닿으면 파일에는 그때까지 고른 행만 남는다 [1][8].
파일이 고른 행을 모두 담지 못했다는 표시 `export_complete`는 응답에만 실리고 파일 안이나 파일 이름에는 남지 않는다 [8].

    """Budget only a preview; validate before the exporter publishes its file."""
    validate_budget(max_chars)
    result_data = {
        **data, "preview": list(data["preview"]),
        "preview_available": len(data["preview"]), "preview_returned": len(data["preview"]),
        "preview_clipped": False, "payload_clipped": False,
        "serialized_chars": 0, "returned_chars": 0,
    }
    result = _measure(result_data, True, original=True)
    if result_data["returned_chars"] <= max_chars:
        return result
    original_chars = result_data["serialized_chars"]
    while result_data["preview"]:
        result_data["preview"].pop()

        result_data["preview_clipped"] = result_data["payload_clipped"] = True
