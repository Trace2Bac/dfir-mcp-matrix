# D04 출력 경로 제한

### D04.05 서버가 파일 이름 결정

**구현.** 이 방식은 `evtx_export`와 `remote_collect_artifacts`가 쓰는 파일의 이름에 적용된다 [1][2].
`evtx_export`는 모델이 준 `output_dir` 안에 `mkstemp`로 `.evtx-export-` 접두어의 `.part` 임시 파일을 만들어 행을 쓴다 [3].
게시할 이름 `evtx-export-<난수>.jsonl`은 서버가 `uuid4`로 짓고 `os.link`로 임시 파일에 그 이름을 붙인다 [1].
그 이름이 이미 있으면 `os.link`가 `FileExistsError`를 내고 서버는 새 난수 이름으로 다시 시도한다 [1].
열 번 모두 겹치면 파일을 게시하지 않고 오류로 끝낸다 [1].
게시 이름에는 모델 입력이 들어가지 않는다 [1].

`remote_collect_artifacts`는 `output_dir` 아래 `evtx/`·`registry/` 폴더에 아티팩트별 고정 이름으로 쓴다 [2].
이 이름에도 모델 입력이 들어가지 않는다 [2].
같은 이름의 파일이 있는지 보지 않고 그 파일을 덮어쓴다 [2][4].

목적지 폴더는 파일을 쓰는 세 도구 모두 모델이 준 값을 쓴다.
`evtx_export`는 `output_dir`을 `absolute()`로 절대 경로로만 바꾸고 없는 폴더는 상위까지 만든다 [3].
`vt_lookup_behavior`는 `triage_dir`을 `resolve()`로 실제 경로로 바꾸고 상위까지 만들지만 허용 폴더와 대조하지 않는다 [5].
`vt_lookup_behavior`의 이름 조각은 모델이 준 해시 문자열의 앞 12자이고 서버는 그 문자열의 길이만 검사한다 [5][6].
`vt_lookup_behavior`도 같은 이름의 파일이 있는지 보지 않고 그 파일을 덮어쓴다 [5][4].
저장된 파생물을 고치거나 지우는 도구는 없다.

```python
def _publish_without_overwrite(
    temporary: Path, directory: Path, result: dict[str, Any],
    validate_result: Callable[[dict[str, Any]], None] | None,
    publication_candidates: list[Path],
) -> Path:
    # link() is atomic and fails if the target exists, including a symlink.
    # Both paths are in the same directory/filesystem. Do not use replace().
    for _ in range(10):
        destination = directory / f"evtx-export-{uuid.uuid4().hex}.jsonl"
        # The caller retains ownership information even if interruption occurs
        # between this helper returning and its result being assigned.
        publication_candidates.append(destination)
        result["path"] = str(destination)
        if validate_result is not None:
            validate_result(copy.deepcopy(result))
        try:
            os.link(temporary, destination)
            return destination
        except FileExistsError:
            continue
        except BaseException:
            # link() may have completed before an interruption is delivered,
            # including before this helper can return the path to its caller.
            # Remove only a hardlink to our own temporary inode; a collision or
            # unrelated file must never be unlinked by error cleanup.
            with suppress(OSError):
                owned = temporary.stat()
                _remove_owned_file(destination, (owned.st_dev, owned.st_ino))
            raise
    raise FileExistsError("Could not allocate a unique EVTX export filename")
```

def _normalize_hash(file_hash: str) -> tuple[str, str]:
    """Normalize hash and determine type."""
    file_hash = file_hash.lower().strip()
    hash_types = {32: "md5", 40: "sha1", 64: "sha256"}
    hash_type = hash_types.get(len(file_hash), "unknown")
    return file_hash, hash_type
