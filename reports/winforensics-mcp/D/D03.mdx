# D03 파생물 무결성 검증

### D03.01 기준값 자동 계산

**구현.** 이 방식은 `evtx_export`의 JSON Lines 파일에 적용된다 [1].
`evtx_export`는 행을 임시 파일에 쓰면서 쓴 바이트를 그대로 SHA-256에 넣는다 [1].
기준값은 파일 내용 전체의 SHA-256과 바이트 수, 행 수다 [1][2].
서버는 이 값을 응답의 `sha256`·`exported_bytes`·`exported_rows`에만 싣고 파일이나 다른 저장소에 남기지 않는다 [2][3].
응답 스키마는 `sha256`을 소문자 16진수 64자로 정한다 [3].

`vt_lookup_behavior`의 행동 요약 파일과 `remote_collect_artifacts`의 수집 파일에는 기준값을 계산하지 않는다 [4][5].
`remote_collect_artifacts`는 수집 파일마다 크기만 응답에 싣는다 [5][6].
원격에서 실행하는 수집 스크립트는 파일 바이트의 Base64만 출력하고 원본의 길이나 해시를 출력하지 않는다 [7].
그래서 응답의 `size_bytes`는 서버가 받아서 푼 바이트의 길이이고 원격 원본의 크기와 대조한 값이 아니다 [5][7].
내보낸 파일이나 수집 파일을 다시 읽어 기준값과 대조하는 도구는 없다.
