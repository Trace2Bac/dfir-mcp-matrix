# I01 외부 연동 대상 관리

### I01.02 자격증명 존재로 활성화

**구현.** 이 방식은 VirusTotal 조회 도구 `vt_lookup_hash`·`vt_lookup_behavior`·`vt_lookup_ip`·`vt_lookup_domain`·`vt_lookup_file`에 적용된다 [1].
다섯 도구는 `vt-py`를 불러올 수 있으면 API 키가 없어도 도구 목록에 오른다 [1].
조회 함수는 요청 전에 `check_api_key`로 API 키를 읽는다 [2].
키는 환경변수 `VIRUSTOTAL_API_KEY`에서 먼저 찾고 없으면 `~/.config/winforensics-mcp/vt_api_key` 파일에서 찾는다 [2].
둘 다 없으면 `ValueError`를 내고 VirusTotal에 요청하지 않는다 [2].
서버는 이 예외를 키 설정 방법을 적은 `error` 응답으로 돌려준다 [3].
키는 조회할 때마다 다시 읽는다 [2].
환경변수가 없을 때 키 파일을 고치면 서버를 다시 시작하지 않아도 다음 조회부터 바뀐 키를 쓴다 [2].
`vt_lookup_behavior`를 뺀 네 도구의 설명은 `VIRUSTOTAL_API_KEY` 환경변수가 필요하다고 적고 키 파일은 적지 않는다 [1].
`vt_lookup_behavior`의 설명에는 키가 필요하다는 문구가 없다 [1].

### I01.03 기본 활성화

**구현.** 이 방식은 WinRM 원격 수집 도구 `remote_collect_artifacts`·`remote_get_system_info`에 적용된다 [4].
두 도구는 `pywinrm`을 불러올 수 있으면 도구 목록에 오르고 연결을 켜는 서버 설정은 없다 [4][5].
`pywinrm`은 `pyproject.toml`의 선택 의존성 `remote`에 있다 [6].
접속할 호스트와 사용자 이름, 비밀번호나 NTLM 해시는 모두 호출 인자로 받는다 [4].
서버는 비밀번호와 NTLM 해시가 모두 없을 때만 연결하지 않고 오류를 돌려준다 [7].

저장소에는 SSH(`paramiko`)와 SMB(`smbprotocol`)로 파일을 받는 수집 클래스 `SSHCollector`·`SMBCollector`도 있다 [8].
MCP 도구는 이 두 클래스를 쓰지 않고 `WinRMCollector`만 만든다 [7][9].

### I01.05 고정 목적지

**구현.** 이 방식은 VirusTotal 조회 도구 다섯 개에 적용된다 [10].
조회 함수는 `vt.Client`에 API 키만 넘기고 접속 주소를 넘기지 않는다 [10].
`vt-py` 0.22.0의 `Client`는 `host`를 받지 않으면 `https://www.virustotal.com`을 쓴다 [11].
`trust_env`의 기본값이 거짓이어서 `HTTP_PROXY`·`HTTPS_PROXY` 환경변수의 프록시도 쓰지 않는다 [11].
접속 주소를 바꾸는 서버 설정, 환경변수, 도구 인자는 없다 [1][10].
해시·IP 주소·도메인 인자는 이 주소의 경로에만 들어간다 [10].

### I01.08 호출자가 목적지 지정

**구현.** 이 방식은 WinRM 원격 수집 도구 `remote_collect_artifacts`·`remote_get_system_info`에 적용된다 [4].
두 도구는 접속할 호스트를 인자 `host`로 받는다 [4].
`WinRMCollector`는 이 값으로 `http://{host}:5985/wsman` 주소를 만들어 `winrm.Session`에 넘긴다 [12].
서버는 이 값을 허용 목록이나 형식과 대조하지 않는다 [7][12].
도구에는 포트와 TLS를 고르는 인자가 없어 서버는 늘 `use_ssl` 기본값 거짓으로 http 5985번 포트에 NTLM 인증으로 접속한다 [12].
`pywinrm` 0.5.0은 http 주소에서 NTLM 인증을 쓰면 WinRM 메시지 암호화를 켠다 [13].
`pywinrm` 0.5.0의 `Session`은 받은 주소를 다시 해석해 호스트 뒤의 포트를 읽는다 [14].
그래서 `host`에 `evil.example:8080`을 주면 서버가 붙인 5985 대신 8080번 포트로 접속하는 주소가 만들어진다 [15].

def get_api_key() -> Optional[str]:
    """
    Get VirusTotal API key from (in order):
    1. Environment variable: VIRUSTOTAL_API_KEY
    2. Config file: ~/.config/winforensics-mcp/vt_api_key
    3. None (functions will raise error)
    """
    # Environment variable
    if key := os.environ.get("VIRUSTOTAL_API_KEY"):
        return key.strip()

    # Config file
    config_file = Path.home() / ".config" / "winforensics-mcp" / "vt_api_key"
    if config_file.exists():
        return config_file.read_text().strip()

    return None


def check_api_key() -> str:
    """Get API key or raise error if not configured."""
    key = get_api_key()
    if not key:
        raise ValueError(
            "VirusTotal API key not configured. Either:\n"
            "1. Set VIRUSTOTAL_API_KEY environment variable\n"
            "2. Create ~/.config/winforensics-mcp/vt_api_key with your key"
        )
    return key

[12] `WinRMCollector`는 `host`로 http 5985번 주소를 만들고 NTLM 인증으로 `winrm.Session`을 만든다.

```python
class WinRMCollector:
    def __init__(
        self,
        host: str,
        username: str,
        password: Optional[str] = None,
        ntlm_hash: Optional[str] = None,
        port: int = 5985,
        use_ssl: bool = False,
        transport: str = "ntlm",
    ):
        if not WINRM_AVAILABLE:
            raise ImportError("pywinrm not installed. Install with: pip install pywinrm")

        if not password and not ntlm_hash:
            raise ValueError("Either password or ntlm_hash must be provided")

        if password and ntlm_hash:
            raise ValueError("Cannot use both password and ntlm_hash - choose one")

        self.host = host
        self.username = username
        self.port = port
        self.use_ssl = use_ssl

        if ntlm_hash:
            if ":" in ntlm_hash:
                auth_password = ntlm_hash
            else:
                auth_password = f"00000000000000000000000000000000:{ntlm_hash}"
            self.password = auth_password
            self.using_pth = True
        else:
            self.password = password
            self.using_pth = False

        protocol = "https" if use_ssl else "http"
        self.url = f"{protocol}://{host}:{port}/wsman"

        self.session = winrm.Session(
            self.url,
            auth=(username, self.password),
            transport=transport,
            server_cert_validation="ignore" if use_ssl else None,
        )
```
