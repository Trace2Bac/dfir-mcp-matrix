# I04 서버 자격증명 처리

### I04.01 환경변수·설정 파일에 분리 보관

**구현.** 이 방식은 VirusTotal 조회 도구 다섯 개의 API 키에 적용된다 [1].
서버는 조회할 때마다 환경변수 `VIRUSTOTAL_API_KEY`를 먼저 읽고 값이 없으면 `~/.config/winforensics-mcp/vt_api_key` 파일을 읽는다 [1].
코드와 저장소 파일에는 키 값이 없다 [1].
서버는 키 파일의 소유자와 권한을 검사하지 않는다 [1].
키는 `vt-py` 0.22.0이 요청 헤더 `X-Apikey`에만 넣는다 [2].

WinRM 원격 수집 도구의 비밀번호와 NTLM 해시는 환경변수나 설정 파일에서 읽지 않고 호출 인자로 받는다 [3].

### I04.02 도구 인자 수신 금지

**구현.** 이 방식은 VirusTotal 조회 도구 다섯 개에 적용된다 [4].
다섯 도구의 입력 스키마에는 API 키 인자가 없고 서버가 키를 직접 읽는다 [1][4].
조회 응답은 조회 결과 필드만 담고 키는 담지 않는다 [5].
VirusTotal 오류는 `VirusTotal API error: …` 문구로 응답의 `error`에 싣는다 [5].

WinRM 원격 수집 도구 `remote_collect_artifacts`·`remote_get_system_info`에는 이 방식이 없다 [3].
두 도구는 `password`나 `ntlm_hash`를 호출 인자로 받으므로 모델이 자격증명 값을 보고 넘긴다 [3].
`ntlm_hash`에 NT 해시만 주면 서버는 앞에 0으로 채운 LM 해시 32자를 붙여 `pywinrm`에 비밀번호 자리로 넘긴다 [6].
`remote_collect_artifacts`의 응답은 수집 항목마다 이름, 성공 여부, 저장 경로, 크기, 오류만 담는다 [7].
도구 처리 중 예외가 나면 서버는 예외 문구를 `{"error": …}` 응답에 싣고 `logger.exception`으로 표준 오류에 traceback을 남긴다 [8].
서버는 이 문구에서 자격증명을 찾아 지우는 처리를 하지 않는다 [8].

def get_api_key() -> Optional[str]:
    """
    Get VirusTotal API key from (in order):
    1. Environment variable: VIRUSTOTAL_API_KEY
    2. Config file: ~/.config/winforensics-mcp/vt_api_key
    3. None (functions will raise error)
    """
    # Environment variable
    if key := os.environ.get("VIRUSTOTAL_API_KEY"):
        return key.strip()

    # Config file
    config_file = Path.home() / ".config" / "winforensics-mcp" / "vt_api_key"
    if config_file.exists():
        return config_file.read_text().strip()

    return None

async def call_tool(name: str, arguments: dict[str, Any]) -> list[TextContent] | CallToolResult:
    """Handle tool calls"""
    try:
        result = await _execute_tool(name, arguments)
        if isinstance(result, CallToolResult):
            return result
        return [TextContent(type="text", text=result)]
    except Exception as e:
        if name in {"evtx_search", "evtx_security_search", "evtx_get_event", "evtx_correlate_logon_id", "evtx_export", "evtx_ntlm_operational_summary", "security_descriptor_decode", "evtx_describe_security_descriptor", "ntds_get_object_by_sam", "ntds_get_object_sid", "ntds_get_domain_info", "ntds_get_trusts"}:
            # Keep validation/read errors small; source data is never returned in a traceback.
            return evtx_error_response(getattr(e, "message", str(e)))
