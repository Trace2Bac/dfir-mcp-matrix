# R04 도구 결과 해석 주의

### 미구현

**판단.** 도구 설명, 서버 지침, 응답 어디에도 도구 결과의 해석 한계나 추가 확인이 필요하다는 점을 적지 않는다 [1][2][3].
도구 설명은 도구가 하는 일, 인자, 돌려주는 것만 적는다 [1].
서버는 서버 지침, 리소스, 프롬프트를 두지 않는다 [2].
`run_plugin`의 응답은 regipy 플러그인의 한 줄 설명 `DESCRIPTION`을 싣고 이 설명은 플러그인이 무엇을 읽는지만 적는다 [3][4].
`list_relevant_plugins`의 응답은 질문에 맞는 플러그인을 골라 `run_plugin`을 부르라는 `instruction`을 싣는다 [5].
이 문구는 호출 순서만 안내한다 [5].

regipy 6.5.2는 검증 목록 밖 플러그인의 결과가 불완전하거나 부정확할 수 있다는 경고를 쓰는 `warn_unvalidated_plugin`을 둔다 [6].
`run_relevant_plugins`는 `include_unvalidated`가 참일 때만 이 함수를 부르고 이 함수는 경고를 로그에만 쓴다 [6][7].
서버는 `run_relevant_plugins`를 이 인자 없이 부르고 `run_plugin`은 이 함수를 거치지 않는다 [8][9].
검증 목록 밖 플러그인 13개를 `run_plugin`으로 실행한 응답은 다른 플러그인의 응답과 같은 필드만 담았다 [10].
