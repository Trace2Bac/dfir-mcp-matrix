# R02 대량 결과 전달

### R02.06 값 단위 잘림

**구현.** 이 방식은 regipy 6.5.2의 `iter_values`를 기본 인자로 부르는 플러그인이 돌려주는 레지스트리 값에 적용된다 [1][2].
regipy 6.5.2는 값 하나의 최대 길이 `MAX_LEN`을 256으로 둔다 [1].
키의 값을 읽는 `iter_values`는 기본으로 `trim_values=True`를 쓴다 [2].
이때 문자열 값은 `try_decode_binary`가 256자에서 자르고 `REG_BINARY`와 `REG_NONE` 값은 16진 문자열의 앞 256자만 남긴다 [3][2].
잘린 값에는 잘렸다는 표시가 없다 [3].
`timezone_data`는 `iter_values`를 기본 인자로 부르고 `user_assist`는 `trim_values=False`로 불러 자르지 않는다 [4].
`get_value`는 `iter_values`를 `trim_values=False`로 불러 값을 자르지 않는다 [5].
그래서 `computer_name`처럼 값을 이름으로 읽는 플러그인의 값은 잘리지 않는다 [5].
시험 하이브 8개로 실행한 결과에서 길이가 정확히 256자인 값이 `timezone_data`와 `services`의 `value`에 있었다 [6].
SYSTEM 시험 하이브의 `TimeZoneKeyName` 값은 기본 인자로 읽으면 256자, `trim_values=False`로 읽으면 512자였다 [7].

값 말고는 한도가 없다.
서버는 응답의 크기와 건수를 제한하지 않는다 [8][9].
SYSTEM 하이브 하나에 `run_all_plugins_for_hive`를 부르자 응답 글이 6,526,629바이트였다 [6].
같은 유형의 하이브를 여럿 적재하면 그 하이브들의 결과가 모두 한 응답에 들어간다 [8][9].

```python
def try_decode_binary(data, as_json=False, max_len=MAX_LEN, trim_values=True):
    try:
        value = data.decode("utf-16-le").rstrip("\x00")
    except UnicodeDecodeError:
        try:
            value = data.decode().rstrip("\x00")
        except Exception as ex:
            logger.warning(f"Could not parse data as string, formating to hex: {ex}")
            value = binascii.b2a_hex(data).decode() if as_json else data

    if trim_values:
        value = value[:max_len]

    return value
```

```python
    def get_value(
        self,
        value_name=DEFAULT_VALUE,
        as_json=False,
        raise_on_missing=False,
        case_sensitive=True,
    ):
        """
        Get a value by name. Will raise if raise_on_missing is set,
        if no value name is given, will return the content of the default value
        :param value_name: The value name to look for
        :param as_json: Whether to normalize the data as JSON or not
        :param raise_on_missing: Will raise exception if value is missing, else will return None
        :return:
        """
        value_name = value_name if case_sensitive else value_name.lower()
        for value in self.iter_values(as_json=as_json, trim_values=False):
            v = value.name if case_sensitive else value.name.lower()
            if v == value_name:
                return value.value

        if raise_on_missing:
            raise RegistryValueNotFoundException(f"Did not find the value {value_name} on subkey {self.name}")
        return None
```
