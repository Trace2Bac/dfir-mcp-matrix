# R02 대량 결과 전달

### R02.06 값 단위 잘림

**구현.** regipy 라이브러리는 값 하나의 최대 길이 `MAX_LEN`을 256으로 둔다 [1].
키의 값을 돌려주는 `iter_values`는 기본으로 `trim_values=True`를 쓴다 [2].
문자열·이진 값을 풀어 쓰는 `try_decode_binary`는 이때 값을 256자에서 자른다 [3].
잘린 값에는 표시가 없다 [3].
잘림은 `iter_values`를 기본 인자로 부르는 플러그인에만 적용되고 `trim_values=False`로 부르는 플러그인은 자르지 않는다 [4].

값 말고는 한도가 없다.
서버는 응답 크기와 건수를 제한하지 않는다 [5].
SYSTEM 하이브 하나에 `run_all_plugins_for_hive`를 부르자 응답이 6,526,629바이트였다 [6].
같은 유형의 하이브를 여럿 적재하면 모두 한 응답에 들어간다 [5].

```python
def try_decode_binary(data, as_json=False, max_len=MAX_LEN, trim_values=True):
    try:
        value = data.decode("utf-16-le").rstrip("\x00")
    except UnicodeDecodeError:
        try:
            value = data.decode().rstrip("\x00")
        except Exception as ex:
            logger.warning(f"Could not parse data as string, formating to hex: {ex}")
            value = binascii.b2a_hex(data).decode() if as_json else data

    if trim_values:
        value = value[:max_len]

    return value
```
