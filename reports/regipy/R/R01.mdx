# R01 결과 가공

### R01.01 가공 없이 전달

**구현.** 이 방식은 `run_plugin`과 `run_all_plugins_for_hive`에 적용된다 [1][2].
두 도구는 플러그인이 만든 결과를 `_serialize_plugin_results`에 넣고 그 값을 하이브 파일 이름 아래에 싣는다 [1][2].
`_serialize_plugin_results`는 `dict`와 `list`를 따라가며 `datetime` 객체만 ISO 8601 문자열로 바꾸고 다른 값은 그대로 둔다 [3].
서버는 플러그인을 `as_json=True`로 만들고 regipy 6.5.2의 플러그인은 이때 시각을 문자열로 만든다 [1][4].
시험 하이브로 플러그인 75개를 모두 실행한 결과에는 `datetime`이나 `bytes` 객체가 없었고 서버가 바꾼 값도 없었다 [5].
MCP Python SDK 1.30.0의 FastMCP는 도구가 돌려준 `dict`를 들여쓰기 2칸의 JSON 글 하나로 바꿔 응답에 싣는다 [6].

`get_registry_key`는 찾은 키에서 경로, 시각, 값마다의 이름·값·형식, 하위 키 수를 골라 `dict`를 만든다 [7].
regipy 6.5.2의 `get_key`가 돌려주는 객체에는 이 가운데 `path`, `timestamp`, `values` 속성이 없어 이 `dict`를 만드는 중 예외가 난다 [7][8].
그래서 키가 있는 경로로 불러도 이 필드가 실린 응답은 돌아오지 않았다 [9].

### R01.03 형식 변환·건수 집계

**구현.** 이 방식은 문자열을 돌려주는 `set_hive_directory`, `list_available_hives`, `list_available_plugins`와 `run_all_plugins_for_hive`의 `files_analyzed`에 적용된다 [10][11][12][2].
`set_hive_directory`와 `list_available_hives`는 적재한 하이브를 regipy가 정한 유형별로 묶고 유형마다 파일 이름을 한 줄씩 늘어놓은 글을 만든다 [10][11].
유형을 정하지 못한 하이브는 `unknown` 아래에 둔다 [10][11].
`list_available_hives`는 전체 하이브 수와 유형마다의 파일 수를 글에 싣는다 [11].
`list_available_hives`는 파일마다 전체 경로와 루트 키 이름도 모으지만 글에는 파일 이름만 싣는다 [11].
`list_available_plugins`는 플러그인을 호환 유형별로 묶어 전체 플러그인 수, 적재한 하이브로 실행할 수 있는 수, 유형마다의 상태 표시를 글로 싣는다 [12].
`run_all_plugins_for_hive`의 `files_analyzed`는 결과에 넣은 하이브 파일의 수이고 오류로 끝난 파일도 이 수에 들어간다 [2].

### R01.06 응답 항목 선별

**구현.** 이 방식은 `run_all_plugins_for_hive`가 부르는 regipy 6.5.2의 `run_relevant_plugins`에 적용된다 [2][13].
`run_relevant_plugins`는 기본값 `include_unvalidated=False`이면 검증 목록 `validated_plugins.json`에 없는 플러그인을 실행하지 않고 결과에 넣지 않는다 [13][14].
서버는 이 인자를 주지 않으므로 응답에는 검증 목록에 있는 플러그인의 결과만 실린다 [2].
regipy 6.5.2는 검증 목록을 시험 사례가 있는 플러그인의 이름으로 설명하고 목록 밖 플러그인은 잘못되었거나 불완전한 자료를 돌려줄 수 있다고 적는다 [14].
플러그인 75개 가운데 13개가 검증 목록에 없다 [15].
SYSTEM 하이브에 부르자 SYSTEM 플러그인 29개 가운데 `appcert_dlls`, `pending_file_rename`, `shares`를 뺀 26개의 결과가 실렸다 [15].
응답에는 뺀 플러그인의 이름이나 수, 뺀 규칙을 싣지 않는다 [2].
`run_plugin`은 이 목록을 보지 않고 이름으로 고른 플러그인을 실행한다 [1].

```python
def _serialize_plugin_results(results):
    """Recursively serialize plugin results, converting datetimes to strings."""
    if isinstance(results, dict):
        return {k: _serialize_plugin_results(v) for k, v in results.items()}
    elif isinstance(results, list):
        return [_serialize_plugin_results(item) for item in results]
    elif isinstance(results, datetime):
        return results.isoformat()
    else:
        return results
```

def convert_wintime(wintime: int, as_json=False) -> Union[dt.datetime, str]:
    """
    Get an integer containing a FILETIME date
    :param wintime: integer representing a FILETIME timestamp
    :param as_json: whether to return the date as string or not
    :return: datetime
    """
    # http://stackoverflow.com/questions/4869769/convert-64-bit-windows-date-time-in-python
    us = wintime / 10
    try:
        date = dt.datetime(1601, 1, 1, tzinfo=pytz.utc) + dt.timedelta(microseconds=us)
    except OverflowError:
        # If date is too big, it is probably corrupted' let's return the smallest possible windows timestamp.
        date = dt.datetime(1601, 1, 1, tzinfo=pytz.utc)
    return date.isoformat() if as_json else date

class NKRecord:
    """
    The NKRecord represents a Name Key entry
    """

    def __init__(self, cell, stream):
        stream.seek(cell.offset)
        self.header = CM_KEY_NODE.parse_stream(stream)  # type: ignore[union-attr]
        self._stream = stream

        # Sometimes the key names are ASCII and sometimes UTF-16 little endian
        if self.header.flags.KEY_COMP_NAME:
            # Compressed (ASCII) key name
            self.name = self.header.key_name_string.decode("ascii", errors="replace")
        else:
            # Unicode (UTF-16) key name
            self.name = self.header.key_name_string.decode("utf-16-le", errors="replace")
            logger.debug(f'Unicode key name identified: "{self.name}"')

        self.subkey_count = self.header.subkey_count
        self.values_count = self.header.values_count
        self.volatile_subkeys_count = self.header.volatile_subkey_count

"""
Plugin validation status tracking.

This module tracks which plugins have been validated with test cases.
Plugins without validation may return invalid or incomplete data.

Validation status is stored in validated_plugins.json, which is generated
by the validation test framework and shipped with the package.
"""

import json
import logging
from pathlib import Path

logger = logging.getLogger(__name__)

# Load validated plugins from JSON file shipped with the package
_VALIDATED_PLUGINS_FILE = Path(__file__).parent / "validated_plugins.json"

try:
    with open(_VALIDATED_PLUGINS_FILE) as f:
        VALIDATED_PLUGINS: set[str] = set(json.load(f))
except FileNotFoundError:
    logger.warning(f"Validated plugins file not found: {_VALIDATED_PLUGINS_FILE}")
    VALIDATED_PLUGINS = set()


def is_plugin_validated(plugin_name: str) -> bool:
    """Check if a plugin has validation test cases."""
    return plugin_name in VALIDATED_PLUGINS
