# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 regipy 플러그인의 결과를 가리거나 필드를 빼지 않고 응답에 싣는다 [1][2].
서버 코드에 값을 가리는 함수는 없다 [1][2].
regipy 6.5.2의 `bootkey` 플러그인은 SYSTEM 하이브의 LSA 키에서 부트 키를 모아 16진 문자열 `key`로 돌려준다 [3].
regipy 코드 주석은 부트 키를 AD 데이터베이스나 컴퓨터 계정 비밀번호 같은 민감한 정보를 암호화하는 데 쓰는 키로 설명한다 [3].
시험 SYSTEM 하이브에 `run_plugin`으로 `bootkey`를 부르자 부트 키 16진 문자열이 그대로 돌아왔다 [4].
`run_all_plugins_for_hive`에 `system`을 주었을 때도 응답의 `bootkey` 아래에 같은 값이 실렸다 [4].

`winscp_saved_sessions`는 WinSCP 세션 키의 값을 이름으로 가리지 않고 모두 결과 항목에 펼쳐 싣는다 [5].
시험 하이브의 WinSCP 세션 값에는 `HostName`, `UserName` 같은 접속 정보가 있었고 비밀번호 값은 없었다 [6].

[2] 서버가 결과에 하는 처리는 `datetime`을 문자열로 바꾸는 것뿐이다.

```python
def _serialize_plugin_results(results):
    """Recursively serialize plugin results, converting datetimes to strings."""
    if isinstance(results, dict):
        return {k: _serialize_plugin_results(v) for k, v in results.items()}
    elif isinstance(results, list):
        return [_serialize_plugin_results(item) for item in results]
    elif isinstance(results, datetime):
        return results.isoformat()
    else:
        return results
```
