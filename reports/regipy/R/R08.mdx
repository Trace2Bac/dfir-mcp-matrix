# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 `run_plugin`과 `run_all_plugins_for_hive`가 싣는 플러그인 결과의 시각 값에 적용된다 [1][2].
서버는 플러그인을 `as_json=True`로 만든다 [1].
regipy 6.5.2의 시각 변환 함수 `convert_wintime`은 FILETIME 정수를 UTC `datetime`으로 바꾸고 `as_json`이 참이면 그 ISO 8601 문자열을 돌려준다 [3].
서버의 `_serialize_plugin_results`는 결과 안의 `datetime` 객체만 `isoformat()` 문자열로 바꾸고 문자열은 그대로 둔다 [2].
시험 하이브로 플러그인 75개를 실행한 결과에는 `datetime` 객체가 없어 서버가 바꾼 시각 값이 없었다 [4].
그래서 응답의 시각은 regipy가 만든 문자열 그대로다 [2][4].
같은 결과에서 이름에 `time`, `date`, `last`, `first`가 들어간 필드에 FILETIME 크기의 정수는 없었다 [4].

`get_registry_key`는 키의 마지막 기록 시각을 `_serialize_datetime`으로 바꿔 싣도록 짜여 있다 [5].
키가 있는 경로로 불러도 이 값이 실린 응답은 돌아오지 않았다 [6].

### R08.03 시간대·단위·정밀도 표시

**구현.** 이 방식은 regipy 6.5.2의 `convert_wintime`으로 만든 시각 값에 적용된다 [3].
`convert_wintime`은 UTC 시간대가 붙은 `datetime`을 만들므로 그 ISO 8601 문자열 끝에 `+00:00`이 붙는다 [3].
시험 하이브로 플러그인을 실행한 결과에서 51개 플러그인의 시각 값이 `+00:00`이 붙은 ISO 8601 문자열이었다 [4].
`samparse`는 자기 변환 함수에서 시간대 없는 UTC 시각 문자열 끝에 `+00:00`을 붙인다 [7].

**한계.** 시간대 표기가 없는 시각 값을 싣는 플러그인이 있다.
regipy 6.5.2의 `convert_filetime2`는 FILETIME을 `%Y-%m-%d %H:%M:%S` 꼴로 바꾸어 시간대와 초 아래 자리를 싣지 않는다 [8].
`shutdown`의 `date`는 이 함수로 만든 값이다 [9].
시험 하이브 결과에서 `diag_sr`, `shutdown`, `susclient_plugin`, `winver_plugin`의 일부 시각 값은 시간대 없는 `YYYY-MM-DD HH:MM:SS` 꼴이었다 [4].
`usrclass_shellbag_plugin`의 `access_time`, `creation_time`, `modification_time`은 시간대 없는 ISO 8601 꼴이었다 [4].
응답은 이 값이 어느 시간대인지 적지 않는다 [1][2].

def _serialize_plugin_results(results):
    """Recursively serialize plugin results, converting datetimes to strings."""
    if isinstance(results, dict):
        return {k: _serialize_plugin_results(v) for k, v in results.items()}
    elif isinstance(results, list):
        return [_serialize_plugin_results(item) for item in results]
    elif isinstance(results, datetime):
        return results.isoformat()
    else:
        return results
```

def convert_wintime(wintime: int, as_json=False) -> Union[dt.datetime, str]:
    """
    Get an integer containing a FILETIME date
    :param wintime: integer representing a FILETIME timestamp
    :param as_json: whether to return the date as string or not
    :return: datetime
    """
    # http://stackoverflow.com/questions/4869769/convert-64-bit-windows-date-time-in-python
    us = wintime / 10
    try:
        date = dt.datetime(1601, 1, 1, tzinfo=pytz.utc) + dt.timedelta(microseconds=us)
    except OverflowError:
        # If date is too big, it is probably corrupted' let's return the smallest possible windows timestamp.
        date = dt.datetime(1601, 1, 1, tzinfo=pytz.utc)
    return date.isoformat() if as_json else date
```

```python
def filetime_to_datetime(filetime: int) -> Optional[str]:
    """Convert Windows FILETIME to ISO datetime string"""
    if filetime == 0 or filetime == 0x7FFFFFFFFFFFFFFF:
        return None
    try:
        # FILETIME is 100-nanosecond intervals since January 1, 1601
        epoch_diff = 116444736000000000  # Difference between 1601 and 1970 in 100-ns
        timestamp = (filetime - epoch_diff) / 10000000
        dt = datetime.utcfromtimestamp(timestamp)
        return dt.isoformat() + "+00:00"
    except (ValueError, OSError, OverflowError):
        return None
```

```python
def convert_filetime2(dte):
    try:
        epoch = dt.datetime(1601, 1, 1, 0, 0, 0)
        nt_timestamp = struct.unpack("<Q", binascii.unhexlify(dte))[0]
        epoch = dt.datetime(1601, 1, 1, 0, 0, 0)
        nt_datetime = epoch + dt.timedelta(microseconds=nt_timestamp / 10)

        return nt_datetime.strftime("%Y-%m-%d %H:%M:%S")

    except OverflowError:
        return None
```
