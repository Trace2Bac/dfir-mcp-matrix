# E03 원본 변경 방지

### E03.02 서버 코드의 원본 쓰기 제한

**구현.** `RegistryHive`는 하이브 파일을 `rb` 모드로 열어 내용 전체를 `BytesIO`에 복사하고 파일을 닫는다 [1].
헤더 해석부터 플러그인 실행까지 뒤의 모든 파싱은 이 메모리 사본에서 한다 [1].
서버 코드에는 파일을 쓰는 호출이 없다 [2].
서버가 import하는 `regipy.plugins.utils`에는 하이브를 JSON 파일로 쓰는 `dump_hive_to_json`이 있지만 어느 도구도 이 함수를 부르지 않는다 [3].
트랜잭션 로그를 적용해 복원 하이브를 쓰는 `regipy.recovery`는 서버가 import하지 않는다 [2].
마운트 옵션이나 파일 권한 같은 다른 장치는 없다.
