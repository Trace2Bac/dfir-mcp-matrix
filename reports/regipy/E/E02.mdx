# E02 증거 무결성 검증

### 미구현

**판단.** 서버는 하이브의 기준값을 계산하지도 대조하지도 않는다.
서버 코드에는 해시를 계산하거나 파일 상태 값을 읽어 남기는 호출이 없다 [1].
regipy에는 파일의 SHA-1을 계산하는 `calculate_sha1`이 있지만 서버는 이 함수를 부르지 않는다 [2][1].
regipy `RegistryHive`는 헤더의 `checksum` 필드를 해석하지만 헤더에서 다시 계산한 값과 대조하지 않는다 [3][4].
서버는 이 값을 응답에 싣지도 않는다 [5].

regipy 6.5.2의 `apply_transaction_logs`는 트랜잭션 로그 항목마다 해시 필드를 대조하고 맞지 않는 항목부터 적용을 멈춘다 [6][7][8].
서버는 이 함수가 있는 `regipy.recovery`를 불러오지 않는다 [9].
서버 모듈을 불러오고 도구를 부른 뒤에도 `regipy.recovery`는 불러와 있지 않았다 [10].

불러 둔 하이브는 불러올 때 메모리에 복사한 내용이므로 서버는 그 뒤 파일이 바뀌어도 알지 못한다 [11].
하이브 하나를 불러 둔 뒤 같은 경로의 파일을 다른 하이브로 덮어쓰고 같은 플러그인을 다시 실행하자 덮어쓰기 전과 같은 결과가 경고 없이 돌아왔다 [10].

```python
def calculate_sha1(file_path):
    sha1 = hashlib.sha1()
    with open(file_path, "rb") as f:
        while True:
            data = f.read(1024**2)
            if not data:
                break
            sha1.update(data)
    return sha1.hexdigest()
```
