# E01 증거 등록 관리

### E01.01 증거 ID·등록 목록

**구현.** 이 방식은 서버가 불러 둔 하이브 목록 `_loaded_hives`에 적용된다 [1].
`_loaded_hives`는 하이브 파일 경로를 키로, regipy `RegistryHive` 객체를 값으로 두는 프로세스 메모리의 `dict`다 [1].
서버는 시작할 때 `--hives-dir`나 `REGIPY_HIVE_DIRECTORY`의 폴더로, 실행 중에는 `set_hive_directory`로 받은 폴더로 이 목록을 채운다 [2][3].
폴더 바로 아래 파일 가운데 정해 둔 확장자를 빼고 헤더 해석에 성공한 파일이 모두 목록에 들어간다 [4].
목록은 한 번에 폴더 하나의 하이브만 담고 `set_hive_directory`를 다시 부르면 통째로 바뀐다 [3].
하이브를 하나씩 더하거나 빼는 도구는 없다 [5].
`list_available_hives`는 목록의 하이브를 유형별로 묶어 파일 이름을 돌려준다 [6].
`run_plugin`, `run_all_plugins_for_hive`, `get_registry_key`의 결과는 하이브를 파일 이름으로 구별한다 [7].
증거 ID는 따로 두지 않는다 [1].
목록은 파일에 쓰지 않으므로 프로세스가 끝나면 사라진다 [1][8].
등록 정보에 크기, 등록 시각, 등록한 주체는 없다 [1][6].

### E01.02 수집 위치와 저장 위치 기록

**구현.** 이 방식은 `_loaded_hives`의 키에 적용된다 [1][4].
키는 받은 폴더 경로에 파일 이름을 붙인 문자열이다 [4].
서버는 하이브를 다른 곳으로 옮기거나 복사해 두지 않으므로 이 값은 하이브가 놓인 저장 위치다 [4].
`set_hive_directory`의 응답 첫 줄은 받은 폴더 경로를 싣는다 [3].
`list_available_hives`는 하이브마다 경로와 루트 키 이름을 모으지만 응답에는 파일 이름만 싣는다 [6].
서버에는 대상 시스템에서 하이브를 수집하는 기능이 없어 하이브를 어디서 가져왔는지는 남기지 않는다 [5].

**한계.** 서버는 받은 폴더 경로를 절대 경로로 바꾸지 않는다 [3][4].
그래서 상대 경로로 받은 폴더는 키에도 상대 경로로 남는다 [4].
`set_hive_directory`에 상대 경로 `hives/h3`를 주자 키는 `hives/h3/SYSTEM`이었다 [9].

        hive_type = hive.hive_type or "unknown"

            by_type[hive_type] = []
        by_type[hive_type].append(Path(path).name)

    result = [f"Loaded {len(_loaded_hives)} hive(s) from {directory}:\n"]
    for hive_type, files in sorted(by_type.items()):
        result.append(f"\n{hive_type}:")
        for file in files:
            result.append(f"  - {file}")

    hives = {}
    directory_path = Path(directory)

    if not directory_path.exists():
        logger.error(f"Hive directory does not exist: {directory}")
        return hives

    # Common registry hive file patterns
    skip_extensions = {".log", ".log1", ".log2", ".sav", ".regtrans-ms", ".blf", ".tmp"}

    for file_path in directory_path.iterdir():
        if not file_path.is_file():
            continue

        # Skip transaction logs and backup files
        if file_path.suffix.lower() in skip_extensions:
            continue

        try:
            logger.info(f"Attempting to load hive: {file_path}")
            hive = RegistryHive(str(file_path))
            hives[str(file_path)] = hive
            logger.info(f"Successfully loaded {file_path.name} as {hive.hive_type}")
        except Exception as e:
            logger.warning(f"Failed to load {file_path}: {e}")
            continue
