# regipy 원고

이 파일은 서버 개요다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 그 방식이 적용되지 않는 경로나 조건이 있으면 **한계**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`c6de929`](https://github.com/mkorman90/regipy/tree/c6de929abc37d8315d1c31aba5e937db636f3303)(2026-10-18, regipy 6.5.2).
줄 번호는 모두 이 커밋 기준이다.
시범 셀 4개(E03, T03, R02, L02)는 이전 기준 커밋 `1293544`(2026-09-12, regipy 6.4.0)로 썼던 것을 이 커밋 기준으로 다시 썼다.

**범위.** `regipy_mcp_server/server.py`가 MCP 서버 하나다.
`server.py`는 MCP Python SDK의 `FastMCP`로 서버(이름 `regipy-forensics`)를 만들고 도구 7개를 등록하며 리소스, 프롬프트, 초기화 지침은 두지 않는다(실행 확인).
진입점은 `python regipy_mcp_server/server.py`이고 전송은 stdio다.
하이브 폴더는 명령줄 인자 `--hives-dir`, 환경변수 `REGIPY_HIVE_DIRECTORY`, 도구 `set_hive_directory` 가운데 하나로 정한다.
서버가 불러 쓰는 같은 저장소의 라이브러리 `regipy`(하이브 해석, 트랜잭션 로그 적용, 플러그인)는 서버가 불러 쓰는 분석 라이브러리로 본다.

`regipy_mcp_server/test_local.py`는 서버 함수를 불러 보는 사용자 시험 스크립트이고 `claude_desktop_config.example.json`은 클라이언트 설정 예시다.
`regipy-rs/`(Rust 확장), `regipy` 명령줄 도구(`regipy/cli.py` 등), `regipy_tests/`, `docs/`는 서버 구현으로 보지 않는다.
저장소 최상위의 `AGENTS.md`는 저장소 개발용 문서다.
README와 문서의 설명은 코드로 확인한 것만 사실로 쓴다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
근거의 "실행 확인"은 기준 커밋을 `git archive`로 풀어 둔 사본을 Docker 컨테이너에서 실행해 본 결과다.
컨테이너는 `python:3.12-slim`(CPython 3.12.16)에 MCP Python SDK 1.30.0과 이 사본의 `regipy`를 `full` 추가 의존성과 함께 설치한 것이다.
하이브는 저장소의 시험 자료 `regipy_tests/data`의 압축을 컨테이너 안에서 풀어 썼다.
컨테이너는 네트워크를 끈 상태(`--network none`)로 실행했다.

**외부 도구 버전 기준.** `regipy`는 기준 커밋의 소스(6.5.2)를 쓴다.
서버 README는 `mcp >= 1.0.0`만 적고 `pyproject.toml`과 `requirements.txt`에는 `mcp`가 없다.
기준 커밋 시각(2026-10-18) 전 최신 MCP Python SDK는 2.3.0(2026-10-02 공개)이다.
2.3.0에는 `mcp.server.fastmcp` 모듈이 없어 서버가 시작하지 않았다(실행 확인).
그래서 실행 확인은 그 전 최신 1.x 버전인 1.30.0(2026-09-07 공개)으로 했다.
그 밖의 Python 의존성은 설치한 때의 버전이다(pydantic 2.14.3, construct 2.10.70).

- MCP Python SDK 1.30.0의 소스는 태그 `v1.30.0`의 커밋 `8c2fa6e`, 2.3.0의 소스는 태그 `v2.3.0`의 커밋 `2118f14`, CPython 3.12.16의 소스는 태그 `v3.12.16`의 커밋 `2c2462a`로 확인한다.
- 실행 환경의 `libfwsi-python`과 `libfwps-python`은 20260522다.
- 원고에서 인용한 그 밖의 버전과 소스 커밋은 이 단락에 더한다.

**바뀔 수 있는 것.** 범위와 외부 도구 버전 기준은 조사하며 맞지 않는 곳이 나오면 검토를 거쳐 바꾼다.
