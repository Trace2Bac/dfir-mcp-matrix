# regipy 시범 전환 원고

시범 셀 원고의 머리다. 셀마다 같은 폴더의 `<셀ID>.md`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<셀ID>.yaml`을 따른다.
상세 항목마다 **구현**을 쓰고 †가 붙은 항목에는 **예외**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`1293544`](https://github.com/mkorman90/regipy/tree/1293544148a4b4dc11d2811e11c9fd7e64fa9c04)(2026-09-12, regipy 6.4.0).
줄 번호는 모두 이 커밋 기준이다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
근거의 "실행 확인"은 서버 모듈을 Python 3.14와 mcp 1.29.0에서 불러 저장소의 테스트 하이브로 돌려 본 결과다.
