# F06 보고 산출물 구성

### 비적용

**판단.** 서버에는 사건 개념이 없고 보고서를 만들거나 내보내는 도구도 없다.
도구 7개는 하이브 폴더를 정하거나 목록을 돌려주거나 하이브를 읽어 결과를 돌려주는 도구이고 결과는 응답으로만 나간다 [1].
서버 코드에는 파일을 쓰는 호출이 없다 [2].
불러 둔 하이브 목록 하나가 프로세스 전체에 공유되고 사건이나 세션을 구별하는 값은 없다 [3].

README는 화면 사진을 클라이언트 모델이 응답을 받아 쓴 답변으로 소개한다 [4].
