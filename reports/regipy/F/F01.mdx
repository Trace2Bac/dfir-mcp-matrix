# F01 판단 지침

### 미구현

**판단.** 서버는 도구 설명, 서버 지침, 리소스, 프롬프트, 응답 어디에도 조사 전체의 해석 원칙이나 발견사항·결론을 서술하고 확인하는 방식을 적지 않는다.
서버는 `FastMCP("regipy-forensics")`로 이름만 주어 만들고 `instructions`를 넘기지 않는다 [1].
MCP Python SDK 1.30.0의 `FastMCP`는 `instructions`의 기본값이 `None`이다 [2].
MCP SDK 클라이언트로 받은 `initialize` 응답의 `instructions`는 `null`이었고 리소스와 프롬프트는 없었다 [3].

도구 설명 7개는 도구가 하는 일, 인자의 예, 반환값의 형태만 적는다 [4].
`list_relevant_plugins`의 설명과 응답의 `instruction`은 질문에 맞는 플러그인을 골라 `run_plugin`으로 하나씩 실행하라고 적는다 [5].
이 문구는 다음에 부를 도구를 적을 뿐 결과를 어떻게 해석하거나 서술할지는 적지 않는다 [5].
`list_available_plugins`와 `list_relevant_plugins`가 싣는 플러그인 설명은 regipy 플러그인 클래스의 `DESCRIPTION` 한 줄이다 [6][7].
이 설명은 `Get the computer name`처럼 플러그인이 읽는 대상을 적는다 [7].
도구와 관계없이 응답에 공통으로 붙는 문구는 없다 [8].
