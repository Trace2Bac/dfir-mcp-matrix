# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
서버가 불러오는 모듈은 표준 라이브러리 `logging`, `os`, `datetime`, `pathlib`, `typing`과 MCP SDK의 `FastMCP`, regipy뿐이다 [1].
모델 API 클라이언트나 HTTP 클라이언트를 불러오지 않는다 [1].
도구 함수는 MCP `Context`를 인자로 받지 않으므로 클라이언트에 sampling 요청을 보내지도 않는다 [2].
도구는 regipy로 하이브를 읽은 결과만 돌려준다 [2].

### 근거

[1] 서버가 불러오는 모듈이다.

import logging
import os
from datetime import datetime
from pathlib import Path
