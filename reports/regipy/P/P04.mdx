# P04 조사 단위 관리

### 미구현

**판단.** 서버에는 사건이나 세션 같은 조사 단위를 식별하거나 나누는 장치가 없다.
불러 둔 하이브 목록 `_loaded_hives`와 하이브 폴더 `_hive_directory`는 서버 프로세스에 하나씩 있는 전역 값이고 모든 도구 호출이 함께 쓴다 [1].
`set_hive_directory`는 이 두 값을 바꿀 뿐 사건 ID를 받거나 만들지 않는다 [2].
도구 7개 가운데 사건이나 세션을 가리키는 인자를 받는 도구는 없다 [3].
하이브 폴더는 사용자가 시작 인자 `--hives-dir`나 환경변수 `REGIPY_HIVE_DIRECTORY`로 정하거나 모델이 `set_hive_directory`로 정한다 [4][2].
서버는 결과나 기록을 파일에 쓰지 않으므로 증거, 기록, 파생물을 둘 폴더 배치를 정하지도 않는다 [5].
