# P03 조사 진척 판단

### P03.03 미조사 범위·생략 사유 보고

**구현.** 이 방식은 `run_plugin`·`run_all_plugins_for_hive`의 하이브별 오류, 맞는 하이브가 없을 때의 응답, `get_registry_key`가 키를 찾지 못했을 때의 응답에 적용된다 [1][2][3].
`run_plugin`과 `run_all_plugins_for_hive`는 하이브 하나에서 예외가 나면 그 하이브 파일 이름 아래에 `error`와 예외 문구를 싣고 다음 하이브를 처리한다 [1][2].
`run_all_plugins_for_hive`는 처리한 하이브 수를 `files_analyzed`에 싣는다 [2].
`SYSTEM`과 손상된 시험 하이브 `corrupted_system_hive`를 불러 둔 서버에서 `run_all_plugins_for_hive`에 `system`을 주자 `SYSTEM`에는 플러그인 26개의 결과가, `corrupted_system_hive`에는 `error` 하나가 실렸다 [4].
맞는 유형의 하이브가 없으면 `run_plugin`은 필요한 유형을 `required_hive_type`에, `run_all_plugins_for_hive`는 불러 둔 유형을 `available_types`에 싣는다 [1][2].
`get_registry_key`는 키를 어느 하이브에서도 찾지 못하면 찾아본 하이브 파일 이름을 `searched_hives`에 싣는다 [3].
`list_available_plugins`는 맞는 하이브가 없어 실행할 수 없는 플러그인에 `✗`를 붙인다 [5].

이 보고는 그 호출 한 번의 범위에 그친다.
서버에는 대상별로 해야 할 작업 목록, 조사 단계, 완료 조건이 없고 모델이 진행 기록을 적는 도구도 없다 [6].

**한계.** `run_all_plugins_for_hive`가 부르는 regipy `run_relevant_plugins`는 검증 목록에 없는 플러그인을 실행하지 않고 그 사실을 결과에 싣지 않는다 [2][7].
기준 커밋의 플러그인 75개 가운데 13개가 검증 목록에 없고 `system` 유형 29개 가운데 3개가 여기에 속한다 [4].

서버는 `run_relevant_plugins`에 `continue_on_error`를 넘기지 않는다 [2].
그래서 플러그인 하나가 `ModuleNotFoundError`가 아닌 예외로 끝나면 regipy가 예외를 다시 던지고 그 하이브의 다른 플러그인 결과는 모두 빠진다 [2][7].
이때 응답의 `error`에는 예외 문구만 실리고 어느 플러그인이 실패했는지는 실리지 않는다 [2].
`corrupted_system_hive`의 `error`는 실행마다 `Did not find Lsa at ControlSet001`이거나 `No subkey AppCompatCache for b'Session Manager'`였다 [4][8].
`ModuleNotFoundError`로 끝난 플러그인은 오류 로그만 남기고 결과에서 빠진다 [7].
응답에는 그 플러그인이 빠졌다는 사실이 실리지 않는다 [2][7].
의존 모듈을 불러오지 못하게 한 실행에서 `run_all_plugins_for_hive`의 `ntuser` 결과에는 `ntuser_shellbag_plugin` 키만 없었다 [9].

`set_hive_directory`는 확장자로 건너뛴 파일과 하이브로 열지 못한 파일을 응답에 싣지 않는다 [10].

`get_registry_key`는 하이브마다 난 예외 문구를 `results`에 담지만 찾은 키가 하나도 없으면 `results`를 버리고 `searched_hives`만 돌려준다 [3].
regipy 6.5.2의 `get_key`가 돌려주는 `NKRecord`에는 서버가 읽는 `path` 속성이 없어 키를 찾아도 예외가 난다 [3][11].
`SYSTEM` 하이브에 있는 키 `\Select`를 주자 `found`가 거짓인 응답이 돌아왔고 예외 문구는 실리지 않았다 [4].

```python
class NKRecord:
    """
    The NKRecord represents a Name Key entry
    """

    def __init__(self, cell, stream):
        stream.seek(cell.offset)
        self.header = CM_KEY_NODE.parse_stream(stream)  # type: ignore[union-attr]
        self._stream = stream

        # Sometimes the key names are ASCII and sometimes UTF-16 little endian
        if self.header.flags.KEY_COMP_NAME:
            # Compressed (ASCII) key name
            self.name = self.header.key_name_string.decode("ascii", errors="replace")
        else:
            # Unicode (UTF-16) key name
            self.name = self.header.key_name_string.decode("utf-16-le", errors="replace")
            logger.debug(f'Unicode key name identified: "{self.name}"')

        self.subkey_count = self.header.subkey_count
        self.values_count = self.header.values_count
        self.volatile_subkeys_count = self.header.volatile_subkey_count
```
