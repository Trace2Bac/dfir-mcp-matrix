# D06 산출물 식별·재생성 처리

### 비적용

**판단.** 서버는 파생물을 담은 파일이나 DB를 만들지 않는다.
도구 결과는 응답으로만 나가고 서버 코드에는 파일이나 DB에 쓰는 호출이 없다 [1][2].
같은 도구를 같은 인자로 다시 부르면 서버는 메모리에 불러 둔 하이브로 플러그인을 다시 실행해 새 응답을 만든다 [3].
