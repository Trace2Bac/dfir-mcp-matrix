# D05 파생물 저장 실패 처리

### 비적용

**판단.** 서버는 도구 출력, 파생물, 보고 산출물을 저장하지 않고 응답으로만 돌려준다.
도구 7개는 결과를 `str`이나 `dict`로 돌려준다 [1].
서버 코드에는 파일이나 DB에 쓰거나 파일을 복사하는 호출이 없다 [2].
