# D01 파생물 보관

### 미구현

**판단.** 서버는 도구 결과를 응답으로 돌려주기만 하고 파일이나 DB에 남기지 않는다.
도구 7개는 결과를 `str`이나 `dict`로 돌려준다 [1].
서버 코드에는 파일을 쓰거나 폴더를 만드는 호출이 없다 [2].
서버 로그는 `logging.basicConfig`에 파일을 주지 않고 설정하므로 파일로 남지 않는다 [3].
regipy 플러그인은 결과를 플러그인 객체의 `entries`에 담고 서버는 그 값을 응답에 옮긴 뒤 객체를 버린다 [4][5].
서버가 불러오는 `regipy.plugins.utils`에는 하이브를 JSON 줄 파일로 쓰는 `dump_hive_to_json`이 있지만 서버는 이 함수를 부르지 않는다 [6][7].
하이브 폴더와 작업 폴더를 둔 컨테이너에서 도구 7개를 모두 부른 뒤 새로 생긴 파일이 없었다 [8].

서버가 호출 사이에 남기는 것은 하이브를 불러올 때 regipy가 메모리에 복사한 하이브 내용과 그 해석 객체다 [9].
이 사본은 프로세스 메모리에만 있고 서버가 다시 시작하면 사라진다 [9].
