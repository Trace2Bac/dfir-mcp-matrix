# T08 실행 종료 판별

### T08.06 프로세스 안 분석 예외를 실패로 구별

**구현.** 이 방식은 regipy를 불러 하이브를 해석하는 도구 3개 `run_plugin`, `run_all_plugins_for_hive`, `get_registry_key`에 적용된다 [1][2][3].
세 도구는 하이브 파일마다 regipy 호출을 `try`로 감싸고 예외가 나면 그 파일의 결과를 오류로 둔다 [1][2][3].
`run_plugin`과 `run_all_plugins_for_hive`는 그 파일의 결과를 `{"error": <예외 문구>}`로 두고 다음 파일을 처리한다 [1][2].
플러그인의 `run()`이 예외를 내게 바꾸자 두 도구 모두 `SYSTEM`의 결과가 그 예외 문구를 담은 `error`였다 [4].
`get_registry_key`는 그 파일의 결과를 `{"found": false, "error": <예외 문구>}`로 둔다 [3].
서버가 처리하지 않은 예외는 MCP Python SDK 1.30.0의 FastMCP가 `Error executing tool <도구>: <문구>` 오류로 바꾸고 응답의 `isError`를 참으로 둔다 [5].
`set_hive_directory`에 파일 경로를 주어 난 `NotADirectoryError`가 이렇게 돌아왔다 [6].
서버는 플러그인 실행에 시간 제한을 두지 않는다 [1][2].

**한계.** `get_registry_key`는 찾은 하이브가 하나도 없으면 파일마다의 결과를 버리고 `found`가 거짓인 응답만 돌려준다 [3].
그래서 예외가 난 경우와 키가 없는 경우가 같은 응답이 된다 [3].
regipy 6.5.2의 `get_key`가 돌려주는 `NKRecord`에는 `path`, `timestamp`, `values` 속성이 없다 [7].
`get_registry_key`는 키를 찾으면 이 속성을 읽으므로 `AttributeError`가 나고 키가 있어도 `found`가 거짓인 응답이 된다 [3][7].
SYSTEM 하이브에 있는 키 `\ControlSet001\Control\TimeZoneInformation`과 루트 `\`로 부르자 모두 `found`가 거짓이었다 [8].

`run_all_plugins_for_hive`가 부르는 `run_relevant_plugins`는 `continue_on_error`가 거짓이면 플러그인 하나의 예외를 다시 내보낸다 [9].
그래서 같은 하이브에서 앞서 성공한 플러그인의 결과도 응답에 실리지 않고 그 파일의 결과는 오류 하나가 된다 [2][9].
손상 하이브에 `run_all_plugins_for_hive`를 부르자 결과가 `error` 하나였고 같은 하이브에 `run_plugin`으로 부른 `computer_name`은 결과를 돌려주었다 [6].
플러그인 목록 `PLUGINS`는 `set`이다 [10].
같은 호출을 프로세스 다섯 개에서 실행하자 `error`의 문구가 `Did not find Lsa at ControlSet001`과 `No subkey AppCompatCache for b'Session Manager'` 사이에서 바뀌었다 [11].

regipy 6.5.2의 `iter_values`는 값 레코드를 해석하지 못하면 오류 로그만 남기고 그 키의 나머지 값을 돌려주지 않는다 [12].
플러그인 결과에는 값이 빠졌다는 표시가 없다 [12][1].
손상 하이브에 `run_all_plugins_for_hive`를 부른 실행에서 서버 표준 오류에 `Could not parse VK at 155686, registry hive is probably corrupted.`가 남았다 [11].

`set_hive_directory`는 `RegistryHive`로 열다 예외가 난 파일을 경고 로그만 남기고 건너뛴다 [13].
응답은 적재한 파일만 늘어놓고 건너뛴 파일을 적지 않는다 [14].
하이브가 아닌 파일이 섞인 폴더를 주자 응답에는 적재한 `SAM`만 있었다 [15].

```python
class NKRecord:
    """
    The NKRecord represents a Name Key entry
    """

    def __init__(self, cell, stream):
        stream.seek(cell.offset)
        self.header = CM_KEY_NODE.parse_stream(stream)  # type: ignore[union-attr]
        self._stream = stream

        # Sometimes the key names are ASCII and sometimes UTF-16 little endian
        if self.header.flags.KEY_COMP_NAME:
            # Compressed (ASCII) key name
            self.name = self.header.key_name_string.decode("ascii", errors="replace")
        else:
            # Unicode (UTF-16) key name
            self.name = self.header.key_name_string.decode("utf-16-le", errors="replace")
            logger.debug(f'Unicode key name identified: "{self.name}"')

        self.subkey_count = self.header.subkey_count
        self.values_count = self.header.values_count
        self.volatile_subkeys_count = self.header.volatile_subkey_count
```
