# T06 실행 환경정보 표시

### 미구현

**판단.** 서버는 regipy로 결과를 내지만 응답 어디에도 regipy나 해석 라이브러리의 버전을 싣지 않는다 [1][2].
`run_plugin`의 응답은 플러그인 이름, 플러그인 설명, 하이브 유형, 하이브 파일마다의 결과만 담는다 [1].
`run_all_plugins_for_hive`의 응답은 하이브 유형, 결과를 담은 파일 수, 결과만 담는다 [2].
`get_registry_key`의 응답은 키 경로와 찾아본 하이브 파일 이름을 담고 문자열을 돌려주는 도구 3개는 하이브와 플러그인 목록만 담는다 [3][4].
regipy 6.5.2는 패키지 버전을 `__version__`으로 두지만 서버는 이 값을 읽지 않는다 [5][6].
서버가 표준 오류에 쓰는 로그 줄에도 버전이 없다 [7].
서버는 파일을 쓰지 않으므로 버전을 적을 파생물이 없다 [6].

서버 자신의 버전도 싣지 않는다.
서버는 `FastMCP`를 이름만 주어 만들고 MCP Python SDK 1.30.0은 버전이 없으면 초기화 응답 `serverInfo.version`에 `mcp` 패키지의 버전을 넣는다 [8][9].
초기화 응답의 `serverInfo`는 이름 `regipy-forensics`, 버전 `1.30.0`이었다 [10].

서버는 모델을 부르지 않는다.
