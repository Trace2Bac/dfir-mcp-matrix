# T10 도구 명세 구성

### T10.01 처리 함수에서 명세 생성

**구현.** 이 방식은 서버가 등록하는 도구 7개 모두에 적용된다 [1].
서버는 도구 함수마다 `@mcp.tool()`만 붙이고 이름, 설명, 입력 schema를 따로 주지 않는다 [1].
MCP Python SDK 1.30.0의 FastMCP는 함수 이름을 도구 이름으로, docstring 전체를 설명으로 쓰고 함수 서명에서 입력 schema를 만든다 [2].
docstring은 도구가 하는 일을 적은 문장과 `Args:`, `Returns:` 단락으로 쓰여 있다 [3].
입력 schema는 인자마다 `title`, 자료형, 기본값만 싣는다 [4].
SDK 1.30.0은 반환 형식이 `str`인 함수에는 `result` 하나를 둔 출력 schema를 만들고 형식 인자 없는 `dict`인 함수에는 만들지 않는다 [5].
그래서 `set_hive_directory`, `list_available_hives`, `list_available_plugins` 3개만 출력 schema가 있고 이 3개의 응답에만 `structuredContent`가 실린다 [4].
도구 annotation은 없고 초기화 응답의 `tools.listChanged`는 거짓이다 [4].
서버는 `FastMCP`를 이름만 주어 만들고 리소스, 프롬프트, 서버 지침을 두지 않는다 [6][4].
명세를 바꾸는 시작 인자나 환경변수는 없다 [7].

서버 README는 MCP SDK를 `mcp >= 1.0.0`으로만 적는다 [8].
기준 시각 전 최신 SDK 2.3.0의 `mcp.server.fastmcp`는 불러오면 `ModuleNotFoundError`를 낸다 [9].
이 원고는 실행 확인에 쓴 SDK 1.30.0이 만든 명세를 적는다.

**한계.** 다음 도구는 설명이 알리는 것과 처리 코드의 동작이 다르다.

`list_available_plugins`와 `run_all_plugins_for_hive`의 설명은 `hive_type`의 예로 `SYSTEM`, `SOFTWARE`, `NTUSER`, `SAM`을 적는다 [10].
처리 코드는 이 값을 regipy가 정한 소문자 유형 이름과 대소문자를 구별해 대조한다 [11][12].
SYSTEM 하이브를 적재한 서버에서 `SYSTEM`을 주자 `list_available_plugins`는 플러그인 0개를, `run_all_plugins_for_hive`는 `No SYSTEM hive loaded` 오류를 돌려주었다 [4].

`get_registry_key`의 설명은 `key_path`의 예로 앞에 백슬래시가 없는 `ControlSet001\Control\TimeZoneInformation`을 적는다 [13].
regipy 6.5.2의 `get_key`는 경로에 백슬래시가 있으면 백슬래시로 나눈 첫 조각을 버리고 나머지를 루트 아래에서 찾는다 [14].
그래서 이 예의 경로로 부르면 루트 아래에서 `ControlSet001`이 아니라 `Control`을 찾는다 [14].
이 예의 경로로 부르자 `found`가 거짓인 응답이 돌아왔다 [4].
설명은 키의 값과 하위 키 정보를 돌려준다고 적는다 [13].
키가 있는 경로로 불러도 처리 코드에서 예외가 나 `found`가 거짓인 응답이 돌아왔다 [15].

`list_relevant_plugins`의 설명은 질문에 도움이 될 플러그인을 돌려준다고 적는다 [16].
처리 코드는 `question`을 응답에 되돌려 싣기만 하고 적재한 유형에 맞는 플러그인을 모두 돌려준다 [16].
하이브 8개를 적재한 서버에서 `usb devices`와 뜻 없는 문자열로 부르자 둘 다 같은 플러그인 75개가 돌아왔다 [17].

`run_all_plugins_for_hive`의 설명은 그 유형에 맞는 플러그인을 모두 실행하고 모든 플러그인의 결과를 합쳐 돌려준다고 적는다 [18].
처리 코드가 부르는 regipy 6.5.2의 `run_relevant_plugins`는 검증 목록 `validated_plugins.json`에 없는 플러그인을 실행하지 않는다 [18][19].
SYSTEM 하이브에 부르자 `system` 유형 플러그인 29개 가운데 26개의 결과만 돌아왔다 [20].

def run_all_plugins_for_hive(hive_type: str) -> dict:
    """
    Run all compatible plugins for a specific hive type.

    Args:
        hive_type: Type of hive (e.g., 'SYSTEM', 'SOFTWARE', 'NTUSER', 'SAM')

    Returns:
        Combined results from all plugins
    """
    if not _loaded_hives:
        return {"error": "No hives loaded. Use set_hive_directory first."}

    compatible_hives = _get_hives_by_type(hive_type)

        available_types = {h.hive_type for h in _loaded_hives.values()}
        return {"error": f"No {hive_type} hive loaded", "available_types": sorted(available_types)}

    # Run all plugins on all compatible hives
    all_results = {}
    for path, hive in compatible_hives:
        try:
            results = run_relevant_plugins(hive, as_json=True)
            serialized_results = _serialize_plugin_results(results)
