# T04 실행 방식

### T04.01 서버 프로세스 안 분석

**구현.** 이 방식은 서버의 모든 분석 경로에 적용된다 [1][2].
서버는 regipy를 Python 모듈로 불러와 하이브 해석과 플러그인 실행을 자기 프로세스 안에서 한다 [1][2].
서버 코드가 불러오는 모듈은 표준 라이브러리 `logging`, `os`, `datetime`, `pathlib`, `typing`과 MCP SDK, regipy뿐이다 [1].
regipy 6.5.2의 `RegistryHive`는 하이브 파일을 `rb` 모드로 열어 전체를 읽은 뒤 메모리의 `BytesIO`에서 해석한다 [3].
서버는 적재한 `RegistryHive` 객체를 `_loaded_hives`에 담아 프로세스가 끝나거나 폴더를 다시 적재할 때까지 쓴다 [4].
셸백 플러그인이 쓰는 선택 의존성 모듈 `pyfwsi`도 플러그인이 실행될 때 같은 프로세스에 불러온다 [5].
외부 실행 파일을 실행하거나 원격 API에 작업을 맡기는 경로는 없다 [1].
그래서 분석은 서버와 같은 계정, 파일, 네트워크 권한으로 실행된다.
