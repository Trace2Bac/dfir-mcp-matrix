# T03 실행 조건 확인

### T03.01 선행 결과 대조

**구현.** 이 방식은 적재한 하이브를 쓰는 도구 4개 `run_plugin`, `run_all_plugins_for_hive`, `list_relevant_plugins`, `get_registry_key`와 `list_available_hives`에 적용된다 [1][2].
서버는 적재한 하이브를 프로세스 전역 `dict` `_loaded_hives`에 둔다 [3].
이 상태는 서버가 시작할 때 `--hives-dir`나 `REGIPY_HIVE_DIRECTORY`로 받은 폴더를 읽거나 모델이 `set_hive_directory`를 부를 때 채워진다 [4].
적재한 하이브를 쓰는 도구 4개는 `_loaded_hives`가 비어 있으면 하이브를 읽지 않고 `set_hive_directory`를 먼저 부르라는 `error`를 돌려준다 [1].
`list_available_hives`는 같은 확인을 하고 같은 안내를 문자열로 돌려준다 [2].
하이브를 0개 적재한 서버에서 `run_plugin`은 `{"error": "No hives loaded. Use set_hive_directory first."}`를, `list_available_hives`는 `No hives loaded. Use set_hive_directory to load hives.`를 돌려주었다 [5].
이 확인을 건너뛰고 하이브를 읽는 도구나 인자는 없다 [1].

이 확인은 적재한 하이브가 하나라도 있는지만 본다 [1].
`list_available_plugins`는 이 확인을 하지 않고 하이브가 없으면 플러그인 75개를 모두 실행할 수 없다고 표시한다 [6][5].
`set_hive_directory`에는 앞선 상태로 호출을 막는 조건이 없다 [7].
승인, 호출자 인증, 실행 자원 확인, 동시 실행 수 제한은 없다 [8].

**한계.** `set_hive_directory`에 폴더가 아닌 파일 경로를 주면 `iterdir()`가 `_loaded_hives`를 바꾸기 전에 예외를 낸다 [7][9].
그래서 그 호출은 오류로 끝나도 앞서 적재한 하이브가 남고 이어 부른 도구는 그 하이브로 답한다 [7].
하이브 8개를 적재한 서버에서 파일 경로로 `set_hive_directory`를 부르자 `isError`가 참인 결과가 돌아왔고 이어 부른 `list_available_hives`는 하이브 8개를 보였다 [5].
없는 폴더를 주면 `_loaded_hives`가 빈 `dict`로 바뀌어 적재한 하이브를 쓰는 도구가 모두 이 확인에서 거부된다 [7][9][5].

```python
def _initialize_hives(hive_dir: Optional[str] = None):
    """
    Initialize hives from the specified directory or environment variable.

    Priority:
    1. Command-line argument (hive_dir parameter)
    2. REGIPY_HIVE_DIRECTORY environment variable
    3. If neither is set, hives must be loaded manually via set_hive_directory tool
    """
    global _loaded_hives, _hive_directory

    # Try parameter first, then environment variable
    _hive_directory = hive_dir or os.getenv("REGIPY_HIVE_DIRECTORY")

    if not _hive_directory:
        logger.warning("No hive directory specified. Use set_hive_directory tool or pass --hives-dir argument.")
        return

    logger.info(f"Loading hives from: {_hive_directory}")
    _loaded_hives = _load_hives_from_directory(_hive_directory)
    logger.info(f"Loaded {len(_loaded_hives)} hive(s)")
```
