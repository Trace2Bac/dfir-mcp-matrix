# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 외부에 연결하지 않는다.
서버가 불러오는 모듈은 표준 라이브러리 `logging`, `os`, `datetime`, `pathlib`, `typing`과 MCP SDK의 `FastMCP`, regipy뿐이다 [1].
서버 코드에는 URL이나 호스트 이름이 없고 소켓이나 HTTP 연결을 여는 호출도 없다 [2].
서버는 `mcp.run()`을 인자 없이 부르고 MCP Python SDK 1.30.0의 `run`은 전송을 정하지 않으면 stdio로 실행한다 [3][4].
네트워크를 끈 컨테이너에서 연결 함수를 감싸 두고 도구 7개를 모두 부르자 연결이나 이름 해석 시도가 없었다 [5].
