# I02 분석 도구 통신 차단

### 미구현

**판단.** 서버는 regipy를 Python 라이브러리로 불러 하이브를 해석하지만 그 통신을 끊거나 끄는 장치가 없다 [1].
서버 코드에는 regipy에 넘기는 통신 설정이나 네트워크를 끊는 처리가 없다 [2].
저장소에는 서버를 네트워크 없는 컨테이너나 network namespace에서 실행하는 구성이 없다 [3].
README는 클라이언트 설정에서 Python으로 `server.py`를 직접 실행하게 한다 [4].

regipy 6.5.2의 하이브 해석과 플러그인 코드에는 소켓, HTTP 클라이언트, 하위 프로세스를 쓰는 곳이 없다 [5].
플러그인 코드가 쓰는 네트워크 관련 모듈은 문자열을 디코딩하는 `urllib.parse.unquote` 하나다 [6].
셸백 플러그인 두 개는 셸 항목과 속성 저장소를 해석하려고 C 라이브러리 바인딩 `pyfwsi`와 `pyfwps`를 불러온다 [7][8].
이 두 라이브러리가 스스로 통신하는지는 소스로 확인하지 않았다.
네트워크를 끈 컨테이너에서 연결 함수를 감싸 두고 도구 7개를 모두 부르자 연결이나 이름 해석 시도가 없었다 [9].
