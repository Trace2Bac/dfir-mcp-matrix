# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다.
서버 코드에는 외부 연결이 없다 [1].
서버가 읽는 환경변수는 하이브 폴더를 정하는 `REGIPY_HIVE_DIRECTORY` 하나다 [2].
클라이언트 설정 예시 파일은 Python 실행 파일 경로, `server.py` 경로, `--hives-dir`의 폴더만 적는다 [3].

### 근거

[1] 서버 파일 전체다: [`regipy_mcp_server/server.py:1-431`](https://github.com/mkorman90/regipy/blob/c6de929abc37d8315d1c31aba5e937db636f3303/regipy_mcp_server/server.py#L1-L431).

[2] 서버는 `os.getenv`로 `REGIPY_HIVE_DIRECTORY`만 읽는다.

```python
    # Try parameter first, then environment variable
    _hive_directory = hive_dir or os.getenv("REGIPY_HIVE_DIRECTORY")
```

[`regipy_mcp_server/server.py:83-84`](https://github.com/mkorman90/regipy/blob/c6de929abc37d8315d1c31aba5e937db636f3303/regipy_mcp_server/server.py#L83-L84)

[3] 클라이언트 설정 예시 파일 전체다.

```json
{
  "mcpServers": {
    "regipy": {
      "command": "C:\\Users\\marti\\anaconda3\\envs\\regipy\\python.exe",
      "args": [
        "c:\\Users\\marti\\Documents\\GitHub\\regipy\\regipy_mcp_server\\server.py",
        "--hives-dir",
        "C:\\Users\\marti\\Downloads\\hives"
      ]
    }
  }
}
```
