# L04 기록 위변조 방지

### 미구현

**판단.** 서버 기록은 서버 코드, regipy, MCP SDK가 로거에 쓰는 항목이고 서버는 이 항목을 표준 오류로만 내보낸다 [1][2].
서버 코드에서 로그를 설정하는 곳은 `basicConfig` 한 곳이고 기록 파일이나 DB를 여는 곳은 없다 [1][3].
항목 형식은 수준, 로거 이름, 메시지뿐이고 앞 항목의 해시나 일련번호가 없다 [2].
README와 클라이언트 설정 예시는 서버 실행 명령과 인자만 적고 표준 오류를 남길 곳을 정하지 않는다 [4].
regipy 패키지가 설치하는 명령은 하이브 해석, 플러그인 실행, 비교, 트랜잭션 로그 처리용이고 기록을 다시 계산해 어긋난 항목을 알려 주는 명령은 없다 [5].
그래서 서버 기록의 수정, 삭제, 순서 변경을 막거나 알아차리는 장치가 없다.
