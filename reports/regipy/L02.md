# L02 기록 내용 구성

### 비적용

**판단.** 서버는 도구 호출을 파일이나 DB에 남기지 않는다 [1].
표준 오류로 나가는 진단 로그만 켜 둔다 [1].
이 로그에는 하이브를 적재한 시도·성공·실패와 플러그인 오류가 찍힌다 [2].
성공한 호출은 도구 이름도 인자도 로그에 남지 않는다 [2].
호출 기록이 없으므로 요청 내용을 무엇으로 기록하는지 볼 대상이 없다.
