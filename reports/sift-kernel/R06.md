# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 증거에서 나온 값을 응답·호출 기록·보고서에 싣고 그 가운데 비밀 값을 가리거나 빼는 처리를 두지 않는다.

응답에서는 분류 도구 연산이 외부 도구 출력을 파서 결과나 기본 처리의 글로 그대로 싣는다 [1][2].
`extract_file`은 `icat`이 표준 출력으로 낸 파일 내용을 받아 기본 처리로 앞 1만 자를 응답에 싣는다 [2][3].
그래서 비밀번호 해시나 키를 담은 파일을 뽑으면 그 내용이 가림 없이 모델에게 간다 [2][3].
`parse_bash_history` 처리기는 뽑은 파일의 줄을 200줄까지 그대로 결과에 담는다 [4].
`parse_browser_saved_passwords`는 비밀번호를 꺼내지 않고 브라우저 데이터베이스를 먼저 뽑으라는 안내만 돌려준다 [5].

호출 기록 쪽에서는 서버가 원래 출력 전체를 호출 기록 항목 ID 이름의 파일로 저장한다 [6].
`register_finding`은 근거로 든 호출의 원래 출력에서 설명과 낱말이 가장 많이 겹치는 줄을 200자까지 `provenance_snippets`로 돌려준다 [7].

보고서에서는 markdown 보고서가 발견사항 설명을 그대로 쓴다 [8].
html 보고서의 `escapeHtml`은 HTML 특수 문자만 바꾸는 함수라 값을 가리지 않는다 [9].

function parseLinuxLog(tool: string, raw: string): unknown {
  const lines = raw.split("\n").filter(l => l.trim());
  switch (tool) {
    case "parse_auth_log":
      return { entries: lines.slice(0, 100).map(l => ({ raw: l, has_sudo: l.includes("sudo"), has_ssh: l.includes("sshd"), has_failed: l.includes("Failed") })), total_lines: lines.length };
    case "parse_bash_history":
      return { commands: lines.slice(0, 200), total: lines.length };
    case "parse_cron_jobs":
      return { entries: lines.filter(l => !l.startsWith("#")).map(l => ({ raw: l })), total: lines.length };
    default:
      return { lines: lines.slice(0, 100), total: lines.length };
  }
}

function escapeHtml(s: string): string {
  return s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;").replace(/'/g, "&#39;");
