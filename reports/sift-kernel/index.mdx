# sift-kernel 원고

이 파일은 서버 개요다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 그 방식이 적용되지 않는 경로나 조건이 있으면 **한계**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`ea51bec`](https://github.com/Sathvik-1007/sift-kernel/tree/ea51bec90d4cb543e4aa6063af6e85ae3e4d9396)(2026-06-16).
줄 번호는 모두 이 커밋 기준이다.

**범위.** `src/`의 MCP 서버(`src/index.ts`가 시작하는 stdio·HTTP 서버)를 본다.
모델에게 보이는 MCP 도구는 늘 보이는 커널 도구와 분석 분류마다 하나인 분류 도구이고, 분류 도구는 `operation` 인자로 `src/domain/capability-graph.ts`의 연산을 고른다.
저장소의 `full-investigation.mjs`·`scripts/`는 이 서버를 부르는 MCP 클라이언트 스크립트다.
상세가 클라이언트 쪽 방식을 묻는 경우(예: T02.01)나 같은 저장소의 CLI·클라이언트가 서버 기록으로 산출물을 만드는 경우(F06)에만 이 스크립트를 구현으로 세고, 그 밖에는 원고에 사실로만 적는다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
근거의 "실행 확인"은 WSL Ubuntu 26.04와 Node 22.23.3에서 서버를 MCP 클라이언트로 불러 본 결과다.
그 환경에는 `ewfverify`·`foremost`·`tshark`가 없었고 서버를 루트 권한 없이 실행했다.

**외부 도구 버전 기준.** 서버는 외부 도구 버전을 고정하지 않는다(T05).
README는 SIFT Workstation을 전제하지만 저장소 안의 설치 코드는 Arch 저장소에서 최신 패키지를 받는 `install-forensic-tools.sh`뿐이다.
그래서 원고의 외부 도구 동작은 기준 커밋 날짜(2026-06-16)에 나와 있던 최신 릴리스의 소스로 확인했다.
Sleuth Kit 4.15.0, libewf 20240506, YARA 4.5.5, Plaso 20260512, regipy 6.2.1, Wireshark 4.6.6이다.
Volatility 3 2.28.0, bulk_extractor 2.1.1, libesedb 20240420, libevtx 20251118, evtx 0.12.2, GNU binutils 2.46.1, hashdeep 4.4, util-linux 2.42.2, RegRipper3.0 `ec96dd4`, Perl 5.42.2(Getopt::Long 2.58), glibc 2.43, click 8.4.1도 같은 기준이다.
foremost는 관리되는 공개 저장소가 없어 설치 스크립트가 쓰는 Arch 패키지 1.5.7-7의 원본 tarball로 확인했다.
Zimmerman 도구는 GitHub 태그가 배포 빌드를 따르지 않아 기준 날짜의 master 커밋으로 확인했고 `SBECmd`는 소스가 공개되지 않았다.
