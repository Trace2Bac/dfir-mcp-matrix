# F03 서버 안 모델 입력 구성

### 비적용

**판단.** sift-kernel은 처리 중에 모델을 부르지 않는다.
서버가 쓰는 의존 패키지는 MCP SDK, SQLite 바인딩, 재시도, ID 생성, 결과 형식, schema 검사 라이브러리이고 모델 API 클라이언트나 HTTP 클라이언트는 없다 [1].
서버가 MCP SDK에서 가져오는 요청 schema는 도구·리소스·프롬프트의 목록과 호출에 쓰는 6개다 [2].
서버를 만들 때 밝히는 능력도 도구·리소스·프롬프트이고 클라이언트 모델을 부르는 sampling 요청(`createMessage`)을 보내는 코드는 없다 [3].
추론 엔진, 상관 그래프, 탐지기, 편향 경고는 서버 코드의 규칙과 계산으로 결과를 만든다.
탐지기 모듈의 머리 주석과 html 보고서의 상관 절도 모델 추론을 쓰지 않는다고 적는다 [4].
그래서 서버 안 모델에게 넘길 입력이 없다.
