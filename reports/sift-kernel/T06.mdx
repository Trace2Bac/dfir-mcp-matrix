# T06 실행 환경정보 표시

### 미구현

**판단.** sift-kernel은 외부 도구를 실행해 결과를 내지만 그 도구의 버전을 응답·호출 기록·파생물 어디에도 싣지 않는다.
서버는 외부 도구에 버전을 묻지 않고 연산마다 정한 분석 인자만 넘긴다 [1].
실행기가 돌려주는 실행 결과는 표준 출력·표준 오류·종료 코드·걸린 시간뿐이다 [2].
분류 도구 연산의 응답은 결과·이상 징후·다음 작업 권고·진척·추론 상태·`inference_constraint`·호출 기록 ID·걸린 시간으로 이루어지고 버전 필드가 없다 [3].
호출 기록 항목도 연산 이름·인자·출력 해시·원래 출력 파일 경로·시각·성공 여부 같은 값만 담는다 [4].
연산 이름으로 기록하므로 실행기가 다른 이름의 실행 파일로 바꿔 실행해도 실제로 실행한 프로그램이 남지 않는다(T07에서 본다).
`raw` 폴더의 원래 출력 파일에는 도구의 표준 출력만 들어가므로 도구가 출력에 버전을 적었을 때만 그 줄이 남는다 [5].
서버는 그 줄을 읽지 않는다.
`generate_report`가 쓰는 보고서도 만든 시각·단계·진척률·실행 횟수·기록 체인 상태만 머리에 적고 도구 버전은 적지 않는다 [6].

서버 자신의 버전은 `package.json`의 `0.1.0`이고 명령 행 `--version`이 같은 값을 출력한다 [7].
MCP 서버 객체를 만들 때는 이와 다른 상수 `1.0.0`을 버전으로 준다 [8].
MCP SDK 1.29.0은 이 값을 초기화 응답의 `serverInfo`로 보낸다 [9].
이 값은 분석 응답·호출 기록·보고서와 묶이지 않고 패키지 버전과도 달라 T06.05에는 연결하지 않는다.
서버는 모델을 부르지 않으므로 T06.06을 보지 않는다 [10].
