# I03 외부 전송 범위 구성

### 비적용

**판단.** sift-kernel 서버 코드는 외부 서비스에 조사 자료를 보내지 않는다.
서버 코드가 스스로 여는 외부 연결이 없다는 판단은 I01에서 본다.
서버의 의존 패키지에는 HTTP 클라이언트가 없고 `node:http`는 요청을 받는 서버를 여는 데만 쓴다 [1][2].
분석 도구는 서버 호스트에서 로컬 실행 파일로 돌고 서버 코드가 도구 출력을 다른 호스트로 넘기는 단계는 없다 [3].

`hash_and_lookup`의 명세 설명과 방법론 안내는 파일 해시를 알려진 악성코드 DB나 위협 정보와 대조한다고 적는다 [4].
이 연산은 로컬 `hashdeep`의 출력을 해시 목록으로 파싱해 돌려줄 뿐이고 해시 값을 외부 서비스로 보내지 않는다 [4].
분석 도구가 스스로 여는 통신은 I02에서 본다.
