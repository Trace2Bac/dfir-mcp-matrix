# I04 서버 자격증명 처리

### 비적용

**판단.** sift-kernel 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다.
서버 코드가 스스로 여는 외부 연결이 없다는 판단은 I01에서 본다.
서버 코드가 다루는 비밀값은 HTTP 전송의 bearer token과 보고서 HMAC 키이고 둘 다 외부에 붙을 때 쓰지 않는다 [1][2][3].

bearer token은 시작 인자 `--token`으로 받고 HTTP 전송을 고르면 값이 있어야 서버가 뜬다 [1].
HTTP 전송은 요청의 `Authorization` 헤더를 이 값과 대조해 맞지 않으면 401로 거부한다 [2].
이 값은 서버로 들어오는 원격 호출자를 확인하는 데만 쓰이므로 T03에서 본다.

환경변수 `SIFT_KERNEL_HMAC_SECRET`은 보고서에 붙이는 HMAC-SHA256 값의 키이고 없으면 서버가 무작위 키를 만든다 [3].
이 키로 산출물에 HMAC을 붙이는 일은 D03에서 본다.
`--sudo`로 띄우면 실행기가 분석 도구 앞에 `sudo`를 붙이지만 서버 코드는 비밀번호를 넘기지 않는다 [4].
