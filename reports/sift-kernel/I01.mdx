# I01 외부 연동 대상 관리

### 비적용

**판단.** sift-kernel 서버 코드는 스스로 외부에 연결하지 않는다.
서버가 쓰는 의존 패키지는 MCP SDK, SQLite 바인딩, 재시도, ID 생성, 결과 형식, schema 검사 라이브러리이고 HTTP 클라이언트는 없다 [1].
`src`가 불러오는 Node 내장 모듈은 `node:fs`·`node:fs/promises`·`node:path`·`node:crypto`·`node:child_process`·`node:http`뿐이다 [2].
`node:http`는 HTTP 전송에서 요청을 받는 서버를 여는 데만 쓴다 [3].
`node:child_process`는 분석 도구 실행기 `ProcessExecutor`에서만 쓰고 실행기는 허용 목록에 든 실행 파일을 셸 없이 실행한다 [4].
분석 도구가 실행 중에 스스로 여는 통신은 I02에서 본다.

`hash_and_lookup`의 명세 설명은 파일 해시를 알려진 악성코드 DB와 대조한다고 적는다 [5].
이 연산이 실행하는 것은 로컬 `hashdeep`이고 해시를 원격으로 조회하는 코드는 없다 [5].

저장소의 `install-forensic-tools.sh`는 운영자가 루트 권한으로 돌려 `pacman`으로 분석 도구 패키지를 받는 설치 스크립트다 [6].
서버 코드는 이 스크립트를 부르지 않는다 [6].
그래서 이 내려받기는 서버 밖 설치 명령이고 I01의 판단에 넣지 않는다.

```bash
#!/bin/bash
# Install SIFT forensic tools on CachyOS/Arch
# Run with: sudo bash install-forensic-tools.sh

set -e

echo "Installing forensic packages from official repos..."
pacman -S --noconfirm sleuthkit volatility3 wireshark-cli foremost hashdeep 2>/dev/null || {
  echo "pacman failed, trying individual packages..."
  pacman -S --noconfirm sleuthkit || true
  pacman -S --noconfirm volatility3 || true  
  pacman -S --noconfirm wireshark-cli || true
  pacman -S --noconfirm foremost || true
  pacman -S --noconfirm hashdeep || true
}
```
