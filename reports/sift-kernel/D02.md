# D02 파생물 계보

### D02.01 증거·호출·파생물 ID 참조

**구현.** 이 방식은 원래 출력 파일, 이미지에서 꺼낸 파일, 발견사항, 마크다운·JSON 보고서에 걸린다.
원래 출력 파일 이름은 그 출력을 만든 호출 기록 항목의 ID이고 항목의 `raw_output_path` 열에 그 파일 경로가 들어간다 [1][2].
항목에는 도구 이름과 인자 `params`가 들어간다 [2].
이벤트 로그·레지스트리 연산의 `params.path`는 서버가 이미지에서 꺼내 출력 폴더에 쓴 파일의 경로로 바뀐 값이라서 그 항목이 꺼낸 파일을 가리킨다 [3].
분석 연산이 읽은 증거 이미지 경로는 조사 상태에서 외부 도구 인자에 붙고 항목에는 들어가지 않는다 [4].
증거 경로가 남는 항목은 `mount_evidence` 항목의 `image_path`뿐이다 [5].
그래서 분석 호출의 원래 출력에서 그 호출이 읽은 이미지로 가려면 앞선 `mount_evidence` 항목을 차례로 찾아야 한다 [4][5].

발견사항은 근거 호출 기록 항목 ID 목록 `evidence`를 가지고 `register_finding`은 그 ID가 모두 호출 기록에 있어야 받는다 [6].
`trace_provenance`는 발견사항 ID를 받아 그 `evidence`에 든 호출 기록 항목을 돌려준다 [7].
마크다운 보고서는 발견사항마다 근거 항목 ID를 적고 JSON 보고서는 발견사항 객체를 `evidence`와 함께 싣는다 [8].
HTML 보고서는 발견사항마다 근거 수만 적는다 [8].
보고서 생성은 호출 기록에 항목을 남기지 않아 보고서 파일에서 그것을 만든 호출로 가는 ID는 없다 [9].

호출 기록 항목의 `findings` 열은 모든 경로에서 빈 목록으로 들어간다 [10].
그 열로 발견사항의 근거 항목을 찾는 `traceProvenance` 함수는 정의만 있고 서버가 부르지 않는다 [11].
호출에서 그것을 근거로 삼은 발견사항으로 가는 조회가 없어 D02.04에는 연결하지 않는다.
호출 기록 행의 출력 해시는 파서 결과의 해시이고 소비한 입력의 해시는 어디에도 없어 D02.02에는 연결하지 않는다 [2][10].
파일 파생물 곁에 manifest를 두지 않아 D02.03에도 연결하지 않는다.

서버 안 처리기 연산은 도구 이름으로 고른 앞선 항목의 원래 출력 파일을 모두 읽어 분석한다 [12].
처리기 호출의 항목에는 어느 항목의 출력을 읽었는지 남지 않는다 [10][12].
`filter_timeline`·`get_timeline_context`가 읽는 `timeline.plaso`도 고정 경로로만 가리키고 어느 `generate_timeline` 실행이 만든 파일인지 기록하지 않는다 [13].
중간 입력의 실행 ID나 해시를 남기는 곳이 없어 D02.05에는 연결하지 않는다.

연결이 없는 파생물도 있다.
비동기 연산의 항목은 원래 출력 경로와 출력 해시를 비운 채 실행을 띄울 때 만들어지고 출력 파일 이름의 job ID는 항목에 들어가지 않는다 [14].
`recovered/`·`carved/`·`be_out/`·`timeline.plaso`에는 그것을 만든 호출을 적은 곳이 없다 [13].
Zimmerman 도구의 CSV와 Volatility 덤프 파일도 그렇고 이 파일들은 D01에서 본다.

**예외.** `mount_evidence`의 pcap 분기는 원래 출력을 파일에 쓰고도 항목의 `raw_output_path`를 빈 문자열로 남긴다 [15].
`reset_investigation`은 호출 기록 행을 모두 지우지만 원래 출력 파일과 보고서 파일은 남긴다 [16].
그 뒤 원래 출력 파일 이름의 ID와 보고서에 적힌 근거 ID는 없는 항목을 가리킨다.
꺼낸 파일 이름 `extracted_<inode>_<이름>`에는 이미지와 파티션 오프셋이 들어가지 않는다 [3].
다른 이미지나 파티션에서 같은 inode와 이름의 파일을 꺼내면 같은 경로에 덮어써서 앞 호출 항목의 `params.path`가 나중에 꺼낸 파일을 가리킨다 [3][17].
