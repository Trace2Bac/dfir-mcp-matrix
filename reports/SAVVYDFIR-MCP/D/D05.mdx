# D05 파생물 저장 실패 처리

### D05.01 오류·부분 완료 표시

**구현.** 이 방식은 디스크 아티팩트 추출 도구, `extract_windows_artifacts`, `extract_srum`·`extract_shimcache`, `load_memory`, 보고서·그래프 도구에 적용된다 [1][2][3][4][5][6][7].
`extract_prefetch`·`get_amcache`·`extract_mft_timeline`·`summarize_evtx`·`extract_registry_run_keys`는 파싱 전에 `_preflight_artifact_persistence`로 출력 폴더를 만들고 시험 파일을 써 본다 [1][8].
쓸 수 없으면 외부 도구 실행이나 파싱을 시작하지 않고 `status: error`와 `artifact_persistence.status: transient`, 고칠 방법 `fix_hint`를 돌려준다 [1].
사건 폴더의 `artifacts/mft`를 읽기 전용으로 바꾸고 `extract_mft_timeline`을 부르자 이 오류를 돌려받았다 [9].
파싱 뒤 CSV 복사가 실패하면 `_persist_csv`는 임시 경로를 돌려주고 `_finalize_artifact_persistence`는 그 경로를 영구 위치가 아닌 것으로 판정한다 [10].
그러면 응답의 `status`는 `warning`, `csv_path`는 비고 `warning` 문구와 `artifact_persistence.status: transient`가 실린다 [2][10].
사용자 활동 추출 도구는 같은 경우 `status: warning`과 다시 실행하라는 `note`를 싣는다 [11].

`extract_windows_artifacts`는 `icat`이 실패하거나 시간 제한을 넘거나 대상 파일을 열지 못하면 그 파일을 `failures`에 넣고 다음 파일로 간다 [3].
실패하거나 시간 제한을 넘은 파일은 반쯤 쓴 대상 파일을 지운다 [3].
실패나 빈 종류가 있으면 응답의 `status`는 `partial_success`, 꺼낸 파일이 하나도 없으면 `warning`이다 [12].
`extract_srum`은 네트워크 CSV를 쓰다 `OSError`가 나면 `csv_path`를 비우고 `agent_instruction`에 CSV 저장이 실패했다고 적는다 [4].
이때 `status`는 `success`로 남는다 [4].
`generate_graph`는 출력 폴더를 만들지 못하면 오류 응답을 돌려준다 [7].
`generate_report`는 보고서 파일 쓰기 예외를 따로 처리하지 않으므로 바깥 `except`가 `status: error`로 돌려준다 [6].
`extract_shimcache`·`extract_srum`은 `/cases` 아래 폴더를 만들다 난 예외를 처리하지 않아 호출이 오류로 끝난다 [13][14].
`/cases`에 쓸 수 없는 환경에서 MCP 클라이언트로 두 도구를 부르자 `is_error`가 참인 결과와 `Permission denied: '/cases'` 문구를 돌려받았다 [15].
`load_memory`는 `7z`가 0이 아닌 값으로 끝나면 표준 오류를 담은 오류 응답을 돌려주고 풀 폴더를 만들다 난 예외도 오류 응답으로 바꾼다 [5].

### D05.02 저장 확인·검증

**구현.** 이 방식은 재사용 판단을 하는 디스크 아티팩트 추출 도구와 `build_timeline`에 적용된다 [16][17][18].
`extract_mft_timeline`·`extract_usn_journal`·`summarize_evtx`와 사용자 활동 추출 도구는 CSV가 영구 위치에 남았을 때만 재사용 부속 자료를 쓴다 [16].
사용자 활동 추출 도구는 파싱 실패가 하나라도 있거나 행이 0개여도 부속 자료를 쓰지 않는다 [16].
다음 호출은 스키마 2 부속 자료가 있고 그 값이 맞을 때만 앞 CSV를 완료된 결과로 다시 쓴다 [17].
상태 캐시 항목도 CSV가 영구 위치에 남았을 때만 `state.json`에 쓴다 [19].
`build_timeline`은 `log2timeline.py`가 끝난 뒤 `pinfo.py`로 저장 파일을 다시 읽고 이벤트 수를 얻는다 [18].
이벤트 수가 0이면 오류를 돌려주고 상태 캐시에 올리지 않는다 [18].

**한계.** 확인 없이 앞 결과를 쓰는 경로가 있다.
상태 캐시는 항목이 있으면 CSV가 있고 비어 있지 않은지만 보고 다시 쓴다 [20].
`extract_windows_artifacts`의 재사용은 종류별 폴더에 정해 둔 파일이 있는지만 보고 응답에 `content_presence_only_no_evidence_fingerprint`를 적는다 [21].
`extract_srum`은 내보내기 폴더가 이미 있으면 `esedbexport`를 실행하지 않고 그 폴더를 쓴다 [22].
`build_timeline`은 `pinfo.py`가 실패하거나 이벤트 수를 읽지 못해도 `pinfo_validation_error`만 적고 계속한다 [18].

### D05.03 알림 없이 계속

**구현.** 이 방식은 `list_deleted_files`, `list_processes`·`scan_processes`의 상세 응답, 재사용 부속 자료 쓰기에 적용된다 [23][24][25].
`list_deleted_files`는 JSON 파일 쓰기에서 난 `OSError`를 처리해 `storage_path`를 비우고 `status: success`를 돌려준다 [23].
요약 응답의 `note`에서는 파일 위치 문장만 빠지고 실패를 알리는 문구는 없다 [23].
`deleted_files.json` 자리에 폴더를 만들어 두고 `list_deleted_files`를 부르자 `status: success`, `storage_path: null`, `warning: null`이 돌아왔다 [26].
메모리 CSV 저장 함수는 모든 예외를 처리해 `None`을 돌려주고 `list_processes`·`scan_processes`는 `status: success`를 그대로 둔다 [24].
요약 응답은 데이터 위치 자리에 `not persisted`를 적지만 상세 응답에는 저장 실패가 실리지 않는다 [24].
`write_reuse_sidecar_v2`는 부속 자료 쓰기 `OSError`를 처리해 아무것도 알리지 않는다 [25].

def _persist_csv(tmp_csv_path: str, tool_short_name: str) -> str:
    """Copy a tempdir CSV to a persistent artifact path and return the new path.

    Pattern: $OUTPUT_BASE/<case_id>/artifacts/<tool_short_name>/<filename>
    Allows run_analysis() to query the full dataset after the tool returns.
    Returns the persistent path on success, original path on failure.
    """
    import shutil as _shutil
    src_path = Path(tmp_csv_path)
    if not src_path.exists():
        return tmp_csv_path
    base = _artifact_output_dir(tool_short_name)
    try:
        base.mkdir(parents=True, exist_ok=True)
        dest = base / src_path.name
        _shutil.copy2(str(src_path), str(dest))
        return str(dest)
    except OSError:
        return tmp_csv_path
```

def get_valid_cached_artifact(
    state_manager: CaseStateManager,
    cache_key: str,
    *,
    path_key: str,
    required_keys: Optional[Iterable[str]] = None,
) -> Optional[dict[str, Any]]:
    """Return cached metadata only when the backing artifact still exists."""
    cached = state_manager.get_artifact_cache(cache_key)
    if not isinstance(cached, dict):
        return None

    for key in required_keys or ():
        if key not in cached or cached[key] is None or cached[key] == "":
            return None

    artifact_path = cached.get(path_key)
    if not isinstance(artifact_path, str) or not artifact_path:
        return None

    path = Path(artifact_path)
    if not path.exists() or not path.is_file() or path.stat().st_size == 0:
        return None

    return cached
```
