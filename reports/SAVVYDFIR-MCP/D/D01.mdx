# D01 파생물 보관

### D01.01 파생물 파일 보관

**구현.** 이 방식은 디스크 아티팩트 추출 도구, 메모리 프로세스 목록 도구, 이미지 안 파일 꺼내기, 메모리 덤프 압축 풀기, 탐지·타임라인 도구, 보고서·그래프 도구가 만드는 파일에 적용된다 [1][2][3][4][5][6][7][8][9].
디스크 아티팩트 추출 도구는 환경변수 `OUTPUT_BASE` 아래 `<case_id>/artifacts/<도구 이름>/` 폴더에 CSV를 남긴다 [1].
이 `case_id`는 `start_investigation`이 manifest에서 읽어 상태에 올린 값이고 `OUTPUT_BASE`가 없으면 `/cases`를 쓴다 [1].
`extract_mft_timeline`처럼 Zimmerman 도구를 실행하는 도구는 도구가 임시 폴더에 쓴 CSV를 `_persist_csv`로 그 폴더에 복사한다 [2][1].
임시 폴더는 `tempfile.TemporaryDirectory`로 만들어 호출이 끝나면 지워진다 [2].
`extract_prefetch`와 사용자 활동 추출 도구(`extract_shellbags`·`extract_lnk_files` 등)는 서버가 파싱한 행을 `_persist_rows_as_csv`로 CSV에 써서 같은 폴더에 남긴다 [3].
`list_deleted_files`는 파싱한 레코드 전체와 실행한 `fls` 명령 문자열을 담은 `deleted_files.json`을 같은 규칙의 폴더에 쓴다 [4].
`list_processes`·`scan_processes`는 Volatility 3 결과 행을 `artifacts/pslist/`·`artifacts/psscan/` 아래 메모리 덤프 이름 폴더의 CSV로 쓴다 [5].

`extract_windows_artifacts`는 이미지 안의 레지스트리 하이브, EVTX, `$MFT` 같은 파일을 `icat`으로 꺼내 `artifacts/raw/<종류>/` 아래에 남긴다 [6].
`load_memory`는 `file` 명령 결과에 `zip`이 들어 있거나 확장자가 `.zip`인 덤프를 `7z`로 `output_dir`(기본 `/evidence/memory`)에 풀고 푼 파일을 지우지 않는다 [7].
`sigma_hunt`는 Chainsaw 결과 JSON을, `hayabusa_hunt`는 Hayabusa CSV를 분석 폴더 아래 `<case_id>/sigma_hunt/`·`<case_id>/hayabusa/`에 남긴다 [8].
분석 폴더는 환경변수 `SAVVYDFIR_ANALYSIS_DIR`이 가리키는 폴더이고 이 값이 없으면 작업 폴더의 `./analysis`다 [10].
`build_timeline`은 Plaso 저장 파일을, `query_timeline`은 `psort.py`가 쓴 CSV를 이 값과 관계없이 작업 폴더의 `./analysis` 아래에 남긴다 [11].
`extract_shimcache`는 AppCompatCacheParser가 쓴 CSV를 `/cases/shimcache/<case_id>/`에 남긴다 [12].
`extract_srum`은 `esedbexport` 내보내기 폴더와 네트워크 사용량 CSV를 `/cases/srum/` 아래에 남긴다 [13].
`generate_report`는 작업 폴더의 `./reports/<case_id>/`에 `report.html`과 `report.json`을 쓴다 [9].
`generate_graph`는 `graph.html`과 `graph.json`을 기본으로 같은 보고서 폴더에, `output_path`를 주면 그 위치에 쓴다 [14].
재사용 판단에 쓰는 부속 자료 `<CSV 이름>.savvyreuse.json`도 디스크 아티팩트 CSV 곁에 남는다 [15].
발견사항, 실행 기록, 재사용 색인은 분석 폴더의 JSON 파일 `state.json` 하나에 들어간다 [10][16].
서버는 `state.json`을 고칠 때마다 임시 파일 `state.json.tmp`에 전체를 쓴 뒤 이름을 바꾼다 [16].
사건 하나에서 도구를 차례로 실행하자 사건 폴더에 CSV와 부속 자료가, 작업 폴더의 `analysis`·`reports`에 Plaso 저장 파일, Chainsaw JSON, psort CSV, 보고서 파일이 남았다 [17].

외부 도구의 표준 출력 원문은 파일로 남지 않는다.
`SafeRunner`는 표준 출력을 메모리에만 받고 호출 기록에는 종료 코드, 표준 출력 줄 수, 표준 오류 앞 120자만 남긴다 [18].
`scan_network`·`detect_injection`·`list_dlls`와 YARA 도구는 결과를 응답으로만 돌려주고 파일을 쓰지 않는다 [19].

보관 기간이나 보관 대상을 정하는 설정과 코드는 없다.
남긴 파생물을 지우는 MCP 도구는 없다 [1][4].

**한계.** 호출이 오류로 끝나도 파일이 남는 도구가 있다.
`build_timeline`은 `log2timeline.py`가 저장 파일을 쓴 뒤 상태 관리자에 없는 메서드 `augment_execution`을 불러 호출이 오류로 끝난다 [11][20].
`query_timeline`은 `psort.py`가 CSV를 쓴 뒤 정의되지 않은 이름 `case_id`를 참조해 오류로 끝난다 [11][20].
두 도구 모두 오류 응답에 남은 파일의 경로를 싣지 않는다 [21].
`load_memory`는 푼 파일 가운데 메모리 덤프를 찾지 못하면 호출을 오류로 끝내고 푼 파일은 남긴 채 그 목록을 `extracted_files`로 싣는다 [22].

버전 기준 Hayabusa v4.1.0에는 서버가 넘기는 `csv-timeline` 명령이 없어 `hayabusa_hunt`의 Hayabusa 실행은 오류로 끝나고 CSV가 남지 않는다 [23][24].
Hayabusa의 이 동작은 소스로 확인했고 Hayabusa를 실행하지 않았다.

### D01.03 도구 출력·가공본 별도 보관

**구현.** 이 방식은 `extract_srum`과 `extract_registry_run_keys`에 적용된다 [13][25].
`extract_srum`은 `esedbexport`가 `SRUDB.dat`의 테이블을 내보낸 폴더 `<이름>.export/`를 지우지 않는다 [13].
서버는 그 폴더의 네트워크 사용량 테이블을 읽어 응용 프로그램 이름을 붙인 행을 `<이름>_srum_network.csv`로 따로 쓴다 [13].
응답에는 두 위치가 `export_dir`과 `csv_path`로 함께 실린다 [13].
`extract_registry_run_keys`는 RECmd가 쓴 CSV의 행을 합쳐 다시 쓴 `registry_combined.csv`를 남긴다 [25].
서버가 그 행을 분류해 발견사항으로 올리지 않은 레코드는 `registry_suppressed.csv`로 같은 폴더에 따로 남는다 [25][26].
다른 디스크 아티팩트 추출 도구는 외부 도구가 쓴 CSV와 서버가 파싱한 행 CSV 가운데 하나만 남긴다 [2][3].

**한계.** 두 파일이 모두 남지 않는 경우가 있다.
`extract_srum`은 네트워크 CSV를 쓰다 `OSError`가 나면 내보내기 폴더만 남긴다 [13].
`extract_registry_run_keys`는 발견사항으로 올리지 않은 레코드가 없으면 `registry_suppressed.csv`를 쓰지 않는다 [25].

```python
def _persist_csv(tmp_csv_path: str, tool_short_name: str) -> str:
    """Copy a tempdir CSV to a persistent artifact path and return the new path.

    Pattern: $OUTPUT_BASE/<case_id>/artifacts/<tool_short_name>/<filename>
    Allows run_analysis() to query the full dataset after the tool returns.
    Returns the persistent path on success, original path on failure.
    """
    import shutil as _shutil
    src_path = Path(tmp_csv_path)
    if not src_path.exists():
        return tmp_csv_path
    base = _artifact_output_dir(tool_short_name)
    try:
        base.mkdir(parents=True, exist_ok=True)
        dest = base / src_path.name
        _shutil.copy2(str(src_path), str(dest))
        return str(dest)
    except OSError:
        return tmp_csv_path
```

```python
    rows: list[dict[str, Any]],
    *,
    tool_short_name: str,
    filename: str,
) -> Optional[str]:
    """Persist structured rows as a reusable CSV artifact."""

        with tempfile.TemporaryDirectory(prefix=f"savvydfir_{tool_short_name}_rows_") as tmp_dir:
            tmp_csv = os.path.join(tmp_dir, filename)
            _write_csv_rows(
                [{key: "" if value is None else str(value) for key, value in row.items()} for row in rows],
                tmp_csv,
            )

    except Exception:
        return None
```
