# D03 파생물 무결성 검증

### D03.01 기준값 자동 계산

**구현.** 이 방식은 `_finalize_tool_response`를 거치는 도구가 응답에 싣는 파생물 파일에 적용된다 [1].
기준값은 파일 내용 전체의 SHA-256이고 키를 쓰지 않는다 [2].
해시 대상은 응답의 정해 둔 경로 필드 14개(`csv_path`·`storage_path`·`output_path`·`report_path` 등)와 `provenance`·`handle`의 경로 가운데 `input` 역할이 아닌 파일이다 [3][4].
모델이 해시 도구를 부르지 않아도 도구 호출이 끝날 때 서버가 계산한다 [1].
기준값은 경로, 해시, 역할, `source: computed`를 묶은 항목으로 호출 기록의 `linked` 항목과 `state.json` 실행 기록의 `artifact_hashes`에 남고 응답에도 실린다 [1][5].
상태 캐시나 재사용 부속 자료로 앞 CSV를 다시 쓰는 호출도 새 실행 ID 아래 그 CSV의 해시를 다시 계산해 남긴다 [1][6].
`list_deleted_files`·`extract_mft_timeline`·`sigma_hunt`·`generate_report`를 실행하자 응답과 실행 기록에 남긴 파일의 SHA-256이 들어갔다 [7].

해시를 남기지 않는 파생물도 있다.
`extract_shimcache`·`extract_srum`은 `_finalize_tool_response`를 거치지 않아 CSV의 해시가 없다 [8].
`generate_graph`의 `graph.html`·`graph.json`과 `generate_report`의 `report.json`은 응답 필드 이름이 해시 대상 목록에 없다 [3][9].
`merge_host_graphs`·`build_reports_index`의 출력, `extract_windows_artifacts`가 꺼낸 파일, `load_memory`가 푼 파일, 재사용 부속 자료도 해시하지 않는다 [10][11][12].
`extract_windows_artifacts`는 꺼낸 폴더를 `export_dir`로 싣고 서버는 폴더를 해시하지 않는다 [11][2].

서버는 남긴 해시를 파일과 다시 대조하지 않는다.
앞 CSV를 다시 쓸지 정하는 상태 캐시는 파일이 있고 비어 있지 않은지만 보고 재사용 부속 자료는 입력의 크기와 수정 시각만 본다 [13][14].
사건 폴더 CSV 끝에 행을 더한 뒤 새 상태에서 `extract_mft_timeline`을 부르자 그 CSV를 `fingerprint_verified`로 다시 썼고 바뀐 내용의 새 해시를 남겼다 [15].
`verify_integrity`는 원본 증거만 검사하고 파생물의 해시를 계산하거나 대조하는 MCP 도구는 없다 [16].

**한계.** 해시를 계산하지 않고 넘기는 경로가 있다.
상태가 `error`인 응답, 실행 ID가 없는 응답, 이미 `linked` 항목이 있는 실행은 해시를 계산하지 않는다 [1].
`build_timeline`·`query_timeline`은 이 커밋에서 늘 오류 응답으로 끝나므로 남은 저장 파일과 CSV에 해시가 없다 [17].
해시나 기록을 쓰다 예외가 나면 응답에 `phase7_link_warning`만 붙이고 기준값을 남기지 않는다 [1].

```python
def _sha256_file(path: str) -> Optional[str]:
    target = Path(path)
    if not target.is_file():
        return None
    digest = hashlib.sha256()
    with target.open("rb") as fh:
        for chunk in iter(lambda: fh.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()
```

```python
def get_valid_cached_artifact(
    state_manager: CaseStateManager,
    cache_key: str,
    *,
    path_key: str,
    required_keys: Optional[Iterable[str]] = None,
) -> Optional[dict[str, Any]]:
    """Return cached metadata only when the backing artifact still exists."""
    cached = state_manager.get_artifact_cache(cache_key)
    if not isinstance(cached, dict):
        return None

    for key in required_keys or ():
        if key not in cached or cached[key] is None or cached[key] == "":
            return None

    artifact_path = cached.get(path_key)
    if not isinstance(artifact_path, str) or not artifact_path:
        return None

    path = Path(artifact_path)
    if not path.exists() or not path.is_file() or path.stat().st_size == 0:
        return None

    return cached
```
