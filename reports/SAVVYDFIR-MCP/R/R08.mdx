# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 탐지 도구의 hit, `extract_shimcache`, `extract_pca`, `query_timeline`에 적용된다 [1][2][3][4].
`sigma_hunt`·`query_sigma_results`는 Chainsaw hit의 `system_time`이나 `timestamp` 문자열을 바꾸지 않고 `preview`와 `actionable_hits`의 `timestamp`에 싣는다 [1].
기준 등급 아래 hit의 규칙별 요약도 그 문자열을 비교해 처음·마지막 값을 `first_ts`·`last_ts`에 싣는다 [5].
`extract_shimcache`는 AppCompatCacheParser CSV의 `LastModifiedTimeUTC` 문자열을 `last_mod`에 그대로 싣는다 [2].
`extract_pca`는 `PcaAppLaunchDic.txt` 줄의 `|` 뒤 문자열을 `termination_timestamp_utc`에 그대로 싣는다 [3].
`query_timeline`은 psort의 시각 문자열이 정해 둔 네 형식에 맞지 않으면 원래 문자열을 `timestamp`에 싣는다 [4].

**한계.** `actionable_hits`의 `timestamp`는 32자에서 자른다 [6].
(실행 확인) `2019-03-22T05:32:02.123456789+00:00`을 넣자 `actionable_hits`에는 `2019-03-22T05:32:02.123456789+00`이 실렸고 `preview`에는 원래 값이 실렸다 [6].
Chainsaw v2.16.5는 EVTX 사건 시각으로 `evtx` 0.12.2가 쓴 `SystemTime` 문자열을 읽는다 [7].
`evtx` 0.12.2는 이 문자열을 소수점 아래 6자리와 `Z`로 쓴다 [8].
Chainsaw는 이 값을 UTC RFC 3339 문자열로 다시 쓰고 소수점 아래는 값에 따라 없애거나 3자리·6자리로 쓴다 [9].
그래서 Chainsaw EVTX hit의 시각 문자열은 32자를 넘지 않고 `actionable_hits`에서 잘리지 않는다 [6][9].
이 부분은 소스로 확인했고 Chainsaw를 실행하지 않았다.

### R08.03 시간대·단위·정밀도 표시

**구현.** 이 방식은 서버가 시각을 `datetime`으로 바꿔 싣는 도구와 필드 이름에 UTC를 붙인 도구에 적용된다 [10][11][12][13][14][15][3][4].
`_dt_to_iso`는 시간대가 있는 `datetime`을 `+00:00`이 붙은 ISO 8601 문자열로 바꾼다 [10].
EZ 도구 CSV를 읽는 `_parse_dt`는 시간대가 없는 문자열을 읽어 UTC 시간대를 붙인다 [11].
MFT·EVTX·Amcache·레지스트리 응답의 시각은 이 두 함수를 거쳐 `+00:00`이 붙는다 [12].
`extract_browser_history`는 Chromium WebKit 시각과 Firefox 시각을 UTC ISO 8601 문자열로 바꿔 `timestamp_utc`에 싣는다 [13].
`extract_recycle_bin`의 `deletion_time_utc`, `extract_powershell_history`의 `file_mtime_utc`, `extract_pca`의 `termination_timestamp_utc`는 필드 이름으로 UTC를 밝힌다 [14][15][3].
`query_timeline`은 `+00:00`이나 `Z`가 붙은 초 단위 문자열을 읽으면 `+00:00`이 붙은 문자열로 싣는다 [4].
원래 문자열과 바꾼 값을 같은 항목에 함께 싣는 도구는 없다.

**한계.** `_parse_dt`의 형식 목록은 소수점 아래 6자리까지만 읽는다 [11].
EvtxECmd와 MFTECmd의 기본 시각 형식은 `yyyy-MM-dd HH:mm:ss.fffffff`로 소수점 아래 7자리를 쓴다 [16].
그래서 기본 형식의 EZ 도구 CSV에서는 `_parse_dt`가 `None`을 돌려준다 [11][16].
(실행 확인) `2019-03-22 05:32:02.1234567`을 넣자 `None`이 돌아왔고 6자리 값은 `+00:00`이 붙은 값으로 바뀌었다 [11].
`summarize_evtx`는 시각을 읽지 못하면 현재 시각으로 채우고 이 사실을 표시하지 않는다 [17].
(실행 확인) 7자리 `TimeCreated`가 있는 EvtxECmd 행을 바꾸자 `timestamp`가 실행한 때의 현재 시각이 되었다 [17].
`extract_mft_timeline`의 `si_created`·`fn_created`는 같은 이유로 `null`이 된다 [18].
(실행 확인) 7자리 `Created0x10`·`Created0x30`이 있는 MFTECmd 행을 바꾸자 두 값이 `None`이었다 [18].
메모리 도구의 `_parse_vol_dt`는 시간대가 없는 ISO 형식만 읽는다 [19].
Volatility 3 2.28.2의 JSON 출력은 시간대가 있는 `datetime`을 `isoformat()`으로 쓰므로 `+00:00`이 붙는다 [20].
(실행 확인) `2019-03-22T05:32:02+00:00`을 `_parse_vol_dt`에 넣자 `None`이 돌아왔고 이 값을 `CreateTime`으로 둔 행의 `create_time`도 `None`이었다 [19].
`extract_recycle_bin`의 `deletion_time_utc`는 초 아래 값을 버리고 시간대 표기 없이 쓴다 [14].
`extract_pca`의 `termination_timestamp_utc`는 파일의 문자열을 바꾸지 않은 값이고 서버는 그 문자열의 시간대를 확인하지 않은 채 필드 이름에 UTC를 붙인다 [3].

```python
def _parse_dt(value: str) -> Optional[datetime]:
    """Parse a datetime string from an EZ Tools CSV into a ``datetime`` object.

    EZ Tools uses ISO 8601 format with varying levels of precision.  Returns
    ``None`` if the value is empty or unparseable.
    """
    if not value or value.strip() in ("", "N/A", "null", "NULL", "None"):
        return None
    value = value.strip()
    # Normalise to a form Python can parse
    for fmt in (
        "%Y-%m-%dT%H:%M:%S.%fZ",
        "%Y-%m-%dT%H:%M:%SZ",
        "%Y-%m-%dT%H:%M:%S.%f",
        "%Y-%m-%dT%H:%M:%S",
        "%Y-%m-%d %H:%M:%S.%f",
        "%Y-%m-%d %H:%M:%S",
        "%m/%d/%Y %H:%M:%S",
        "%m/%d/%Y %I:%M:%S %p",
    ):
        try:
            dt = datetime.strptime(value, fmt)
            return dt.replace(tzinfo=timezone.utc)
        except ValueError:
            continue
    return None
```

```python
def _webkit_to_iso(value: str) -> str:
    """Convert a Chromium WebKit timestamp (micros since 1601-01-01) to UTC ISO."""
    try:
        micros = int(value)
    except (TypeError, ValueError):
        return ""
    if micros <= 0:
        return ""
    try:
        epoch = datetime(1601, 1, 1, tzinfo=timezone.utc)
        return (epoch + timedelta(microseconds=micros)).isoformat()
    except (OverflowError, OSError, ValueError):
        return ""


def _gecko_to_iso(value: str) -> str:
    """Convert a Firefox/Gecko timestamp (micros since 1970-01-01) to UTC ISO."""
    try:
        micros = int(value)
    except (TypeError, ValueError):
        return ""
    if micros <= 0:
        return ""
    try:
        return datetime.fromtimestamp(micros / 1_000_000, tz=timezone.utc).isoformat()
    except (OverflowError, OSError, ValueError):
        return ""
```

```python
def _filetime_to_iso_utc(filetime: int) -> Optional[str]:
    """Convert a 64-bit Windows FILETIME to an ISO-8601 UTC string (or None)."""
    try:
        if filetime <= 0:
            return None
        seconds = (filetime - _FILETIME_EPOCH_DELTA) / 10_000_000.0
        dt = datetime(1970, 1, 1, tzinfo=timezone.utc) + timedelta(seconds=seconds)

        return None
```
