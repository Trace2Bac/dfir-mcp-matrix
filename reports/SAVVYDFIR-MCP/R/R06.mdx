# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 증거에서 나온 비밀 값을 응답과 남긴 파일에 싣고 그 값을 가리거나 빼는 처리를 두지 않는다.
호출 기록과 보고서를 쓰는 코드에도 이 값을 가리는 처리가 없다 [1].

응답에서는 증거의 글을 그대로 싣는 도구가 비밀번호가 들어간 줄도 그대로 돌려준다.
`extract_powershell_history`는 PSReadLine 기록의 줄을 행마다 `command`에 그대로 담고 `preview`에 싣는다 [2][3].
(실행 확인) `-AsPlainText`로 만든 비밀번호와 `net user` 명령의 비밀번호가 들어간 합성 기록을 주자 두 비밀번호가 `preview`의 `command`에 그대로 실렸다 [2].
`summarize_evtx`의 `detailed` 형식은 EvtxECmd 행의 `PayloadData1`과 나머지 열을 `message_summary`·`extra_fields`에 담는다 [4].
이 값은 증거 글을 감싸는 `<EVIDENCE_CONTENT>` 표시만 붙고 내용은 바뀌지 않는다 [5][6].
`run_analysis`는 사건 폴더의 CSV를 모델이 보낸 질의로 읽어 고른 행을 그대로 돌려준다 [7].

남긴 파일에서도 값을 바꾸지 않는다.
사용자 활동 도구는 파싱한 행 전체를 사건 폴더 아래 CSV로 남기고 응답의 `csv_path`에 그 경로를 싣는다 [3][8].
추출 도구는 외부 도구가 쓴 CSV를 그대로 사건 폴더 아래로 복사한다 [9].

가림 코드는 그래프 생성에만 있고 이 셀에 해당하지 않는다.
`scripts/investigation_graph.py`의 `_build_infra_redactions`는 그래프 HTML에 들어가는 설치 경로, 사용자 홈 폴더, 사건·증거·마운트 폴더 경로를 자리표시자로 바꾼다 [10].
이 함수의 설명은 증거 내용은 건드리지 않는다고 적는다 [10].
`_sanitize_advisory`는 FK 지식 문구에서 숫자와 단정하는 낱말을 바꾸는 함수이고 증거 값을 다루지 않는다 [11].
보고서 요약의 `_strip_internal_tokens`는 발견사항·실행 ID와 ATT&CK 코드를 문장에서 지우는 함수이고 증거 값을 다루지 않는다 [12].

```python
def fence_evidence_content(
    text: Optional[str],
    max_chars: int = DEFAULT_EVIDENCE_EXCERPT_MAX_CHARS,
) -> Optional[str]:
    """Fence model-facing evidence content so it is treated as data, not instruction.

    The default 1600-character cap is intentional: it keeps excerpts small
    enough to avoid prompt flooding while still preserving enough raw context
    for a reviewer or follow-up pivot. Full raw artifacts stay recoverable via
    persisted CSV/storage handles and provenance paths.
    """
    if not text:
        return None
    cleaned = str(text).replace("\x00", "")
    cleaned = re.sub(r"[\x01-\x08\x0b\x0c\x0e-\x1f\x7f]", "", cleaned).strip()
    if not cleaned:
        return None
    if len(cleaned) > max_chars:
        cleaned = cleaned[: max_chars - 3].rstrip() + "..."
    return f"<EVIDENCE_CONTENT>{cleaned}</EVIDENCE_CONTENT>"
```

```python
def _persist_csv(tmp_csv_path: str, tool_short_name: str) -> str:
    """Copy a tempdir CSV to a persistent artifact path and return the new path.

    Pattern: $OUTPUT_BASE/<case_id>/artifacts/<tool_short_name>/<filename>
    Allows run_analysis() to query the full dataset after the tool returns.
    Returns the persistent path on success, original path on failure.
    """
    import shutil as _shutil
    src_path = Path(tmp_csv_path)
    if not src_path.exists():
        return tmp_csv_path
    base = _artifact_output_dir(tool_short_name)
    try:
        base.mkdir(parents=True, exist_ok=True)
        dest = base / src_path.name
        _shutil.copy2(str(src_path), str(dest))
        return str(dest)
    except OSError:
        return tmp_csv_path
```

```python
def _sanitize_advisory(text: Any, cap: int = _FIELD_CAP) -> str:
    """Strip promotion numerics/phrasing and cap length (no gate thresholds leak)."""
    s = str(text or "").strip()
    s = _PROMO_NUM_RE.sub("", s)
    s = _PROMO_WORD_RE.sub("strongly-corroborated", s)
    s = re.sub(r"\s+", " ", s).strip()
    if len(s) > cap:
        s = s[: cap - 1].rstrip() + "…"
    return s
```
