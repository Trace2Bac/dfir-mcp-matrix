# E02 증거 무결성 검증

### E02.04 도구를 요청해 검증

**구현.** 이 방식은 `verify_integrity`에 적용된다 [1].
모델이 이 도구를 부를 때만 서버가 받은 경로에 `ewfverify`를 실행기 `SafeRunner.run`으로 실행한다 [1][2].
`ewfverify`는 EWF 파일에 담긴 취득 해시와 이미지 데이터에서 다시 계산한 해시를 대조하고 결과를 표준 출력과 종료 코드로 낸다 [3].
기준값은 이미지를 만들 때 EWF 파일에 담긴 해시이고 서버는 기준값을 따로 계산하거나 저장하지 않는다 [1].
`_parse_ewfverify_output`은 출력에서 저장 해시와 계산 해시를 정규식으로 찾는다 [4].
둘 다 찾으면 두 값이 같은지로, 찾지 못하면 종료 코드가 0인지로 `verified`를 정한다 [4].
결과는 응답의 `data`·`verified`와 발견사항 하나로 남는다 [5].
`verified`가 `true`이면 무결성이 확인되었다는 발견사항, 저장 해시를 찾지 못했으면 검증할 수 없다는 발견사항, 두 해시가 다르면 `defense_evasion` 유형의 발견사항을 만든다 [5].
응답 정리 단계는 알고리즘이 `sha256`일 때만 계산 해시를 실행 기록의 `artifact_hashes`에 넣는다 [6].
다른 도구의 입력 경로가 그 값과 같으면 그 해시를 가져다 붙이고 없으면 `unhashed_primary_input`으로 표시하며 다시 대조하지 않는다 [7].
사건 시작, 증거를 읽는 도구, 보고서 생성은 증거의 해시를 계산하거나 대조하지 않는다 [8].

**한계.** 버전 기준 환경의 `ewfverify` 20140807은 `MD5 hash stored in file:`과 `MD5 hash calculated over data:` 뒤에 해시를 출력한다 [3].
`_HASH_RE`는 알고리즘 이름 바로 뒤에 `:`이나 `=`와 해시가 오는 형식만 찾으므로 이 출력에서 두 해시를 하나도 찾지 못한다 [4].
그래서 `stored_hash`는 `null`, `computed_hash`는 `<unparseable>`이 되고 `verified`는 종료 코드로만 정해진다 [3][4].
정상 E01 이미지에서는 `verified`가 `true`였지만 `data`에 두 해시가 없었고 `artifact_hashes`는 비어 있었다 [3].
데이터 1바이트를 바꾼 E01 이미지에서 `ewfverify`는 두 해시가 다르다고 출력하고 종료 코드 1로 끝났다 [3].
서버는 저장 해시를 찾지 못한 경우로 처리해 `verified: false`와 함께 검증할 수 없으니 조사를 계속하라는 확신도 0.5의 발견사항을 만들었다 [3][5].
두 해시가 다를 때 만드는 `defense_evasion` 발견사항은 저장 해시를 찾았을 때만 만들어지므로 이 출력 형식에서는 만들어지지 않는다 [5].
`verify_integrity`는 `verified`가 거짓이어도 응답의 `status`를 `success`로 둔다 [9].
응답에는 대조 결과 `data`·`verified`와 발견사항 ID `findings_created`만 실리고 해시가 다르다는 경고 문장은 사건 상태에 저장한 발견사항의 설명에만 들어간다 [5][9].
도구 설명은 원시 이미지면 `sha256sum`으로 계산한다고 적지만 그런 코드는 없다 [10][2].
원시 이미지에서는 `ewfverify`가 실패하고 해시 없이 검증할 수 없다는 발견사항만 남았다 [3].
도구 설명은 계산한 해시가 사건을 닫을 때의 해시와 맞아야 한다고 적지만 닫을 때 대조하는 코드는 없다 [11][8].
서버를 다시 시작한 뒤 사건 ID를 받는 도구를 부르기 전에는 발견사항을 저장하지 못해 오류로 끝난다 [12].

```python
def _extract_verify_integrity_hash(response: dict[str, Any]) -> Optional[dict[str, str]]:
    data = response.get("data")
    if not isinstance(data, list) or not data or not isinstance(data[0], dict):
        return None
    record = data[0]
    algorithm = str(record.get("algorithm") or "").strip().lower()
    computed_hash = str(record.get("computed_hash") or "").strip().lower()
    image_path = _normalize_path_ref(record.get("image_path"))
    if algorithm != "sha256" or not computed_hash or not image_path:
        return None
    return {
        "path": image_path,
        "sha256": computed_hash,
        "role": "input",
        "source": "verify_integrity",
    }
```
