# I03 외부 전송 범위 구성

### 비적용

**판단.** 서버 코드가 켜는 외부 연결은 RECmd의 배치 파일 내려받기뿐이고 이 연결로 조사 자료를 보내지 않는다 [1][2].
`sift_mcp/`와 서버 도구가 실행하는 `scripts/` 모듈은 네트워크 모듈이나 HTTP 클라이언트 라이브러리를 불러오지 않는다 [1].
`serve_graph`는 웹 서버를 열지 않고 사용자가 실행할 명령과 주소를 글로 돌려준다 [3].
`extract_registry_run_keys`의 `sync_batch`가 켜는 RECmd의 `--sync`는 GitHub의 고정 주소에서 배치 파일을 받기만 한다 [2].
