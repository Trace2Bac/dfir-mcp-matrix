# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버 코드가 읽는 환경변수는 분석·출력 폴더, 위임 대기열·위임 기록 경로, 도구 끄기, 시간 제한, 메모리 상한, 판정 문턱값 같은 실행 설정이고 이 가운데 자격증명은 없다 [2].
도구 65개의 입력 schema에도 API 키, 토큰, 비밀번호를 받는 속성이 없다 [3].
서버 코드가 켜는 외부 연결은 `extract_registry_run_keys`의 `sync_batch`가 켜는 RECmd의 배치 파일 내려받기뿐이다 [1][4].
RECmd는 이 파일을 공개 GitHub 저장소의 고정 주소에서 자격증명 없이 내려받는다 [4].
