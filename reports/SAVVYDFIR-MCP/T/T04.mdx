# T04 실행 방식

### T04.01 서버 프로세스 안 분석

**구현.** 이 방식은 Prefetch, 브라우저 기록, 휴지통, PowerShell 기록, 예약 작업, PCA를 해석하는 도구와 사건 상태로 계산하는 도구에 적용된다 [1][2].
`extract_prefetch`는 외부 실행 파일 없이 `pyscca` 라이브러리를 서버 프로세스에 불러 Prefetch 파일을 읽는다 [2].
`extract_browser_history`는 브라우저 DB 사본을 서버 프로세스의 `sqlite3`로 읽기 전용으로 연다 [1].
`extract_recycle_bin`은 `$I` 파일을 `struct`로, `extract_scheduled_tasks`는 작업 XML을 `xml.etree.ElementTree`로, `extract_powershell_history`는 기록 파일을 글자 그대로 서버 프로세스에서 읽는다 [1].
`extract_srum`은 `esedbexport`가 내보낸 표 파일을 서버 프로세스에서 읽어 해석한다 [3].
`compare_disk_and_memory`는 사건 상태의 발견사항과 앞선 도구 실행이 남긴 CSV를 서버 프로세스에서 대조한다 [4].
`sigma_scan`은 사건 상태의 발견사항에 서버 코드의 탐지기를 적용한다 [5].
`query_sigma_results`는 `sigma_hunt`가 쓴 JSON을 서버 프로세스에서 읽어 거른다 [6].

### T04.02 같은 권한의 별도 프로세스

**구현.** 이 방식은 외부 도구를 실행하는 모든 도구에 적용된다 [7][8][9].
Zimmerman 도구, Sleuth Kit, Volatility 3, Plaso, YARA를 쓰는 도구는 실행기 `SafeRunner.run`을 거친다 [7][8].
`SafeRunner.run`은 인자 목록을 `subprocess.run`에 `shell=False`로 넘겨 셸 없이 자식 프로세스로 실행한다 [7].
셸 메타 문자를 담은 인자는 해석되지 않고 글자 그대로 실행 파일에 넘어갔다 [10].
`sigma_hunt`·`hayabusa_hunt`·`analyze_vss`·`extract_shimcache`·`extract_srum`·`extract_windows_artifacts`·`load_memory`와 레지스트리 하이브 정리 함수는 `SafeRunner`를 거치지 않고 `subprocess.run`이나 `subprocess.Popen`에 인자 목록을 직접 넘긴다 [9].
이 경로들도 셸을 거치지 않는다 [9].
`generate_graph`·`merge_host_graphs`·`build_reports_index`는 저장소의 `scripts/` 스크립트를 서버와 같은 파이썬(`sys.executable`)으로 실행한다 [11].
`run_analysis`는 질의를 같은 파이썬의 `sift_mcp.analysis_worker` 자식 프로세스에서 평가한다 [12].
이 자식 프로세스는 pandas를 불러오기 전에 `RLIMIT_AS`로 주소 공간을 제한하지만 계정과 파일 권한은 서버와 같다 [12].

자식 프로세스는 서버의 계정과 환경변수를 그대로 물려받는다 [7][9].
작업 위치(`cwd`)를 따로 주는 곳은 Plaso 실행과 그래프·색인 스크립트뿐이다 [13][11].
Plaso는 서버의 작업 위치에 쓸 수 없을 때만 `/tmp`를 작업 위치로 쓰고 그래프·색인 스크립트는 저장소 루트를 작업 위치로 쓴다 [13][11].
호출마다 새 작업 폴더를 만들어 작업 위치로 쓰는 곳은 없다.
`analyze_vss`와 하이브 정리 함수가 만드는 임시 폴더는 마운트 위치와 입출력 폴더이고 작업 위치가 아니다 [9].

외부 도구를 서버와 다른 계정으로 실행하는 코드는 도구가 실행하는 경로에 없다.
`sudo`를 붙이는 코드는 MCP 도구 목록에 없는 `mount_image`와 마운트 명령의 인자 목록만 돌려주는 `_ntfs_mount_argv`에만 있다 [14].
`_ntfs_mount_argv`를 MCP로 부르자 인자 목록만 돌아오고 마운트 폴더는 생기지 않았다 [15].
컨테이너, namespace, seccomp로 외부 도구를 서버와 나누는 코드도 없다.
