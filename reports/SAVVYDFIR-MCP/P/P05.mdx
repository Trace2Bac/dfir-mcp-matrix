# P05 사건 자료 정리

### P05.01 모델 도구로 삭제·초기화

**구현.** 이 방식은 `start_investigation`에 적용된다 [1].
같은 사건 ID로 `start_investigation`을 다시 부르면 사건 상태의 `status`와 `triage_status`를 `IN_PROGRESS`로 되돌린다 [1].
레인 6개도 `PENDING` 상태로 다시 기록한다 [2].
레인을 다시 기록하는 함수는 상태, 맡은 에이전트, 요약, 시작·완료 시각을 처음 값으로 바꾸고 실행 ID·발견사항 ID·`data_gaps` 목록은 합쳐 남긴다 [3].
`COMPLETE_WITH_GAPS`로 기록한 레인이 있는 사건에서 다시 부르자 그 레인은 `PENDING`, 맡은 에이전트 `null`, 빈 요약이 되었고 `data_gaps` 1건은 남았다 [4].
발견사항과 실행 기록은 지우지 않는다 [1].
응답의 `case_reuse_warning`은 새 발견사항이 앞선 발견사항에 이어 붙는다고 알리고 지우려면 사용자가 `state.json`과 `audit.jsonl`을 옮기거나 지우라고 적는다 [5].
`start_investigation`은 호출 기록 항목을 남기지 않아 이 초기화도 호출 기록에 남지 않는다 [4].

추출 도구 함수에는 재사용 판정 파일을 지우는 `force_reparse` 인자가 있지만 MCP 도구는 이 인자를 받지 않는다 [6][7].
상태 파일, 호출 기록, 추출 출력 폴더를 지우는 도구나 사용자 명령은 없다.

**한계.** 매니페스트에 적은 메모리 덤프가 없어 오류로 끝나는 호출도 레인을 처음 값으로 되돌린 뒤 오류를 돌려준다 [2][8].

### P05.03 자동 정리

**구현.** 이 방식은 추출 도구의 임시 폴더, `extract_windows_artifacts`의 실패한 사본, `analyze_vss`의 임시 마운트 폴더, 전문 에이전트 작업 대기열에 적용된다 [9][10][11][12].
추출 도구는 외부 도구의 출력과 하이브·DB 사본을 `tempfile.TemporaryDirectory`나 `mkdtemp`로 만든 `savvydfir_` 접두어의 임시 폴더에 두고 호출이 끝나면 지운다 [9].
CSV 출력은 지우기 전에 사건의 출력 폴더로 복사한다 [13].
`extract_windows_artifacts`는 `icat`이 실패하거나 시간 제한 300초를 넘긴 파일을 지운다 [10].
`analyze_vss`는 `ewfmount`와 `vshadowmount`에 쓴 임시 폴더를 `fusermount -u`를 실행한 뒤 지운다 [11].
`record_analysis_lane`이 레인을 기록하면 그 레인 작업 대기열의 맨 앞 항목이 같은 사건의 것일 때 그 항목을 뺀다 [12][14].
서버를 불러올 때 작업 대기열 파일에 쓸 수 없으면 그 파일을 지운다 [15].
임시 폴더, 실패한 사본, 대기열 항목을 지운 사실은 서버 운영 로그와 호출 기록 어디에도 남지 않는다 [9][10][11][12].
쓸 수 없는 대기열 파일을 지울 때만 그 경로를 표준 오류의 서버 운영 로그에 쓴다 [15].

### P05.05 원본 증거를 삭제 대상에서 제외

**구현.** 이 방식은 위 자동 정리 경로와 `start_investigation`의 초기화에 적용된다 [9][10][11][12][1].
지우는 대상은 서버가 만든 임시 폴더, 서버가 쓴 사본 파일, 작업 대기열 항목과 파일이다 [9][10][12][15].
받은 증거 경로를 지울 경로로 쓰는 코드는 없다 [16].
`start_investigation`의 초기화는 상태 파일 안의 값만 바꾼다 [1][3].
ext4 이미지에서 파일을 꺼내고 브라우저 DB를 읽은 뒤 이미지 크기와 DB·`-wal`·`-shm` 파일 크기는 그대로였다 [17].

**한계.** `analyze_vss`는 `fusermount -u`의 종료 코드를 보지 않고 임시 마운트 폴더를 지운다 [11].
이 폴더는 원본 이미지를 드러낸 FUSE 마운트 지점이고 해제가 실패한 상태에서 지우기가 무엇에 적용되는지는 `vshadowmount`가 없는 환경이라 확인하지 못했다 [11].

```python
def _persist_csv(tmp_csv_path: str, tool_short_name: str) -> str:
    """Copy a tempdir CSV to a persistent artifact path and return the new path.

    Pattern: $OUTPUT_BASE/<case_id>/artifacts/<tool_short_name>/<filename>
    Allows run_analysis() to query the full dataset after the tool returns.
    Returns the persistent path on success, original path on failure.
    """
    import shutil as _shutil
    src_path = Path(tmp_csv_path)
    if not src_path.exists():
        return tmp_csv_path
    base = _artifact_output_dir(tool_short_name)
    try:
        base.mkdir(parents=True, exist_ok=True)
        dest = base / src_path.name
        _shutil.copy2(str(src_path), str(dest))
        return str(dest)
    except OSError:
        return tmp_csv_path
```

```python
def mark_delegate_processed(lane_id: str) -> None:
    """Pop the head delegate from the specified lane's queue.

    Args:
        lane_id: Lane identifier whose head delegate should be removed.
    """
    if not lane_id:
        return

    queue = _read_queue()
    lane_queue = queue.get(lane_id, [])

    if lane_queue:
        # Remove head of queue
        lane_queue.pop(0)
        queue[lane_id] = lane_queue
        _write_queue(queue)
```
