# I02 분석 도구 통신 차단

### 미구현

**판단.** 서버는 외부 분석 도구를 실행하지 않고 Sleuth Kit Java 바인딩을 라이브러리로 부른다 [1].
서버는 이 라이브러리의 통신을 끊거나 끄는 설정을 두지 않는다.
MCP 코드가 부르는 Sleuth Kit 메서드는 사건 DB 조회와 이미지·로컬 파일·보고서 파일 읽기다 [1].
Sleuth Kit 4.15.0의 Java 바인딩 소스에서 `java.net`을 쓰는 곳은 JNI 라이브러리를 JAR 안에서 찾는 `getResource`, URL 문자열에서 호스트를 떼는 처리, PostgreSQL 연결 주소 조립과 연결 실패 진단, PostgreSQL 사건 DB를 만들 때 DB 이름을 인코딩하는 처리다 [2].
이 소스에서 룰, 심볼, 업데이트를 내려받는 코드는 찾지 못했다 [2].
PostgreSQL 연결은 다중 사용자 사건에서 Autopsy 본체가 사용자 설정으로 정한 사건 DB 서버로 가는 연결이다 [3].

서버가 쓰는 다른 라이브러리는 Java 쪽의 Javalin 7.1.0·Jackson 2.18.2·joda-time, NetBeans 플랫폼 API와 래퍼의 MCP TypeScript SDK 1.27.1이다 [4][5].
joda-time은 타임라인 조회 기간을 만드는 데 쓰고 NetBeans 플랫폼 API `NbPreferences`는 MCP 사용 설정을 읽고 쓰는 데 쓴다 [5].
Javalin은 `127.0.0.1`에서 요청을 받는 HTTP 서버로 쓰고 Jackson은 JSON 변환에 쓴다 [4].
이 라이브러리들이 스스로 통신하는지는 소스로 확인하지 않았다.
