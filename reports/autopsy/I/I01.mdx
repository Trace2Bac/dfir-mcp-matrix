# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 외부에 연결을 열지 않는다.
Java HTTP 서버는 `127.0.0.1`의 포트에서 요청을 받기만 하고 바깥으로 연결을 열지 않는다 [1].
STDIO 래퍼가 여는 연결은 `http://127.0.0.1:<포트>/mcp` 하나이고 받는 쪽은 같은 서버의 Java HTTP 서버다 [2][3].
래퍼는 포트만 `mcp-config.properties`에서 읽고 호스트는 코드에 `127.0.0.1`로 정해 둔다 [2].

`TskQueryService`는 케이스 DB와 증거 내용을 Autopsy 본체가 만든 `SleuthkitCase`로 읽는다 [4].
다중 사용자 케이스에서는 `SleuthkitCase`가 PostgreSQL 서버의 케이스 DB에 연결한다 [5][6].
이 연결의 대상은 Autopsy 본체가 케이스를 열 때 사용자 설정 `UserPreferences.getDatabaseConnectionInfo()`로 정한다 [5].
MCP 코드는 케이스가 열리면 그 `SleuthkitCase`를 받아 질의에 쓰고 연결 대상을 고르거나 바꾸지 않는다 [4].

### 근거

[1] Java HTTP 서버는 `127.0.0.1`에서 요청을 받는다.

```text
        int port = readOrCreateConfigPort();
        app.start("127.0.0.1", port); // localhost only — never 0.0.0.0
```

[2] 래퍼가 연결할 주소는 `127.0.0.1`과 설정 파일의 포트로 만든다.

const MCP_PORT = readConfigPort();
const MCP_BASE_URL = `http://127.0.0.1:${MCP_PORT}`;
