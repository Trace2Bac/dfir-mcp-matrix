# I03 외부 전송 범위 구성

### 비적용

**판단.** 서버 코드는 외부 서비스에 조사 자료를 보내지 않는다.
STDIO 래퍼가 보내는 요청은 같은 서버의 Java HTTP 서버로 가는 `tools/list`·`tools/call` 요청뿐이다 [1].
도구 결과는 래퍼가 MCP 클라이언트에 돌려주는 응답의 글 내용에 실린다 [2].
사용자 문서는 MCP 클라이언트가 자료를 어디로 보내는지와 그 서버의 보존·공유 정책을 사용자가 알아야 한다고 안내한다 [3].
문서가 예로 드는 Anthropic 서버로의 전송은 MCP 클라이언트가 하는 일이고 서버 코드가 여는 연결이 아니다 [3].

### 근거

[1] 래퍼는 받은 MCP 요청을 `127.0.0.1`의 Java HTTP 서버로 넘긴다.

```javascript
        res = await fetch(`${MCP_BASE_URL}/mcp`, {
            method: "POST",
            headers: {
                "Content-Type": "application/json",
                "Authorization": `Bearer ${token}`
            },
            body: JSON.stringify({ jsonrpc: "2.0", id: "1", method, params }),
            signal: controller.signal
        });
```

[2] 래퍼는 Java 서버의 결과를 JSON 글로 바꿔 MCP 클라이언트에 돌려준다.

```javascript
server.setRequestHandler(CallToolRequestSchema, async (request) => {
    const toolName = request.params.name;
    log("INFO", `tools/call ${toolName}`);
    try {
        const result = await callJava("tools/call", {
            name: toolName,
            arguments: request.params.arguments ?? {}
        });
        return {
            content: [{ type: "text", text: JSON.stringify(result, null, 2) }]
        };
```
