# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다.
서버가 다루는 비밀 값은 Java HTTP 서버가 시작할 때 만들어 파일로 STDIO 래퍼에 넘기는 Bearer 토큰 하나다 [1][2][3].
이 토큰은 같은 서버의 두 프로그램 사이에서 호출자를 확인하는 값이고 외부 서비스 접속에 쓰는 자격증명이 아니다 [3][4].

다중 사용자 사건의 DB 서버 접속 정보는 Autopsy 본체가 사건을 열 때 `UserPreferences.getDatabaseConnectionInfo()`로 읽는다 [5].
MCP 코드는 이 접속 정보를 읽지 않고 본체가 연 `SleuthkitCase`와 사건 표시 이름만 받는다 [6].

### 근거

[1] 토큰은 서버 객체를 만들 때 `SecureRandom`으로 만든다.

```text
    private String generateToken() {
        byte[] bytes = new byte[32];
        new SecureRandom().nextBytes(bytes);
        return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
    }
```
