# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 `get_os_accounts`의 확장 속성 `extendedAttributes`에 적용된다 [1].
서버는 확장 속성 값으로 Sleuth Kit `getDisplayString()`이 만든 글을 바꾸지 않고 그대로 싣는다 [1].
이 메서드는 `DATETIME` 값을 `yyyy-MM-dd HH:mm:ss z` 꼴로 JVM 기본 시간대에 맞춰 바꾸고 0은 `0000-00-00 00:00:00`으로 바꾼다 [2].
서버의 다른 시각 값은 이 경로를 거치지 않고 서버가 UTC ISO 8601로 바꾼다 [3].

### R08.03 시간대·단위·정밀도 표시

**구현.** 서버는 Sleuth Kit이 저장한 epoch 초 값을 `epochToIso`로 UTC 오프셋을 붙인 ISO 8601 문자열로 바꿔 싣는다 [3].
`ZoneOffset.UTC`로 만든 문자열이므로 값 끝에 UTC 표기 `Z`가 붙고 정밀도는 초 단위다 [3].
이 변환은 `query_files`·`get_object_children`의 파일 시각, 아티팩트와 파일 속성 `attributes`의 `DATETIME` 값, `query_timeline`의 이벤트 시각, `list_reports`의 만든 시각, `get_os_accounts`의 계정 생성 시각에 적용된다 [4][5][6][7][8].
`query_data_sources`·`get_hosts`·`get_data_source_tree`는 밀리초로 저장된 데이터 소스 추가 시각을 1,000으로 나눠 같은 방식으로 바꾼다 [9][10].
`summarize_timeline`은 집계에 쓴 시작·끝 시각을 같은 꼴로 싣는다 [11].
원래의 epoch 값은 어느 응답에도 함께 싣지 않는다 [3][4].
`query_data_sources`·`get_hosts`·`get_data_source_tree`는 데이터 소스에 설정된 시간대 `timezone`을 시각 값과 따로 싣는다 [9][10].

**한계.** `epochToIso`는 0 이하의 값을 `null`로 바꾼다 [3].
그래서 시각이 기록되지 않은 경우와 1970-01-01 00:00:00 UTC, 그 이전 시각이 응답에서 모두 `null`로 같다 [3].

`get_os_accounts`의 확장 속성 시각은 이 변환을 거치지 않으므로 같은 응답 안에서 계정 생성 시각은 UTC ISO 8601이고 확장 속성의 시각은 Autopsy를 실행한 컴퓨터의 시간대 약어가 붙은 다른 꼴이다 [7][1][2].

    private static String epochToIso(long epochSeconds) {
        if (epochSeconds <= 0) {
            return null;
        }
        return Instant.ofEpochSecond(epochSeconds)
                .atOffset(ZoneOffset.UTC)
                .format(DateTimeFormatter.ISO_OFFSET_DATE_TIME);
    }

    Map<String, Object> summarizeTimeline(JsonNode args) throws TskCoreException {
        TimelineManager tm = skCase.getTimelineManager();
        long startEpoch = parseTimeArg(args, "startTime", tm.getMinEventTime());
        long endEpoch   = parseTimeArg(args, "endTime",   tm.getMaxEventTime());

        TimelineFilter.RootFilter filter = buildTimelineFilter(args);

        Map<TimelineEventType, Long> counts = tm.countEventsByType(
                startEpoch, endEpoch, filter, TimelineEventType.HierarchyLevel.CATEGORY);

        long total = 0;
        Map<String, Long> byCategory = new LinkedHashMap<>();
        for (Map.Entry<TimelineEventType, Long> entry : counts.entrySet()) {
            byCategory.put(entry.getKey().getDisplayName(), entry.getValue());
            total += entry.getValue();
        }

        Map<String, Object> result = new LinkedHashMap<>();
        result.put("startTime",   epochToIso(startEpoch));
        result.put("endTime",     epochToIso(endEpoch));
        result.put("totalEvents", total);
        result.put("byCategory",  byCategory);
        return result;
    }
