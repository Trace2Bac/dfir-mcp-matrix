# T07 도구 부재 처리

### 비적용

**판단.** 서버의 도구 호출은 서버 코드 밖의 모듈인 Sleuth Kit Java 바인딩을 쓴다 [1][2].
이 라이브러리는 Autopsy 설치본에 함께 배포되고 서버가 시작할 때 함께 실리며 서버는 이것 밖의 외부 도구를 쓰지 않는다 [3][4].
서버는 외부 프로그램을 실행하지 않고 룰, 맵, 심볼 같은 참조 자료도 읽지 않는다.
Java 쪽 MCP 패키지와 STDIO 래퍼에는 프로세스를 실행하는 코드가 없다 [5].
`get_server_status`를 뺀 17개 도구는 질의 서비스 `TskQueryService`의 메서드가 처리하고 이 메서드들은 케이스가 열릴 때 받은 `SleuthkitCase`의 조회·읽기 메서드만 부른다 [1][2].
`SleuthkitCase`는 Autopsy가 `Core` 모듈의 라이브러리로 싣는 Sleuth Kit Java 바인딩 `sleuthkit-4.15.0.jar`의 클래스다 [3].
이 라이브러리는 Autopsy 프로그램이 시작할 때 MCP 패키지와 같은 모듈에 실리므로 도구를 부르는 시점에 그 라이브러리만 없는 상태가 생기지 않는다 [3].
STDIO 래퍼는 Node.js 내장 모듈과 MCP TypeScript SDK만 불러온다 [4].

래퍼가 호출마다 읽는 토큰 파일은 서버가 쓰는 작업 파일이다 [6].
래퍼가 요청을 넘기는 Autopsy HTTP 서버는 서버를 이루는 다른 프로그램이다 [6].
토큰 파일이 없으면 래퍼는 HTTP 요청을 보내지 않고 `tools/call`에서는 케이스를 먼저 열라는 문구를 오류로 돌려준다 [6].
파일 내용을 읽는 `get_file_content`는 디스크 이미지 파일이 케이스에 등록되어 있지 않으면 Sleuth Kit이 0바이트를 돌려주고 서버도 빈 내용을 돌려준다 [7].
디스크 이미지는 증거이고 도구나 참조 자료가 아니다.
