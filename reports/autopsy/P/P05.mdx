# P05 사건 자료 정리

### P05.02 사용자 명령으로 삭제·초기화

**구현.** 사용자가 Autopsy 옵션 창에서 MCP 서버를 끄면 서버는 메모리에 둔 조사 상태를 버린다 [1].
서버가 메모리에 두는 조사 상태는 열린 사건을 질의하는 객체(질의 서비스) `TskQueryService`이고 이 객체는 열린 사건의 사건 DB 객체와 표시 이름을 가진다 [2][3].
옵션 창의 `store`는 사용 설정이 꺼지면 `disableServer`를 부른다 [1].
`disableServer`는 서버 객체 `McpServer`를 비우고 `stop`을 불러 HTTP 서버를 멈추며 `stop`은 토큰 파일을 지운다 [4].
질의 서비스는 그 서버 객체가 만든 프로토콜 처리기의 필드에 있으므로 서버 객체와 함께 버려진다 [3][5].
이 동작은 사건 DB, 사건 폴더, 원본 이미지를 건드리지 않는다.
서버를 꺼도 STDIO 래퍼의 `mcp-stdio.log`와 `mcp-stdio.log.1`은 지워지지 않는다 [6].

### P05.03 자동 정리

**구현.** 서버는 사건이 닫힐 때 메모리의 질의 서비스를 스스로 비운다.
Autopsy가 사건을 닫으며 `CURRENT_CASE` 이벤트를 보내면 서버는 `clearCase`로 질의 서비스를 `null`로 바꾼다 [7][8].
그 뒤 도구 호출은 닫힌 사건을 질의하지 못하고 사건이 열려 있지 않다는 오류를 받는다 [9].
이 정리는 사건 DB, 사건 폴더, 원본 이미지를 건드리지 않는다.
사건 DB를 닫는 일은 Autopsy 본체의 사건 닫기가 한다.

STDIO 래퍼는 실패한 도구 호출의 도구 이름과 오류 문구를 호출 기록 `mcp-stdio.log`에 덧붙인다 [6].
이 파일이 1MB를 넘으면 래퍼는 다음 줄을 쓰기 전에 파일 이름을 `mcp-stdio.log.1`로 바꾼다 [6].
그때 이미 있던 `mcp-stdio.log.1`은 이름을 바꾼 파일로 대체되어 앞선 기록이 지워진다 [10].
서버가 쓰는 파일은 토큰 파일, 포트 설정 파일, `mcp-stdio.log`, `mcp-stdio.log.1`이고 사건 자료를 파일이나 DB에 쓰지 않는다 [11][6].
사건이 닫혀도 래퍼는 `mcp-stdio.log`와 `mcp-stdio.log.1`을 지우지 않는다 [6].

**한계.** 진행 중인 호출은 비우기 전에 가져온 질의 서비스로 계속 질의한다 [9].

### P05.05 원본 증거를 삭제 대상에서 제외

**구현.** 이 방식은 옵션 창에서 서버를 끌 때, 사건이 닫힐 때, 래퍼가 기록 파일 이름을 바꿀 때 지우는 대상에 적용된다 [1][7][6].
지우는 대상은 메모리의 질의 서비스, 토큰 파일 `mcp-token`, 고정 이름의 기록 파일 `mcp-stdio.log.1`로 코드에 정해져 있다 [4][8][6].
토큰 파일과 기록 파일은 `%LOCALAPPDATA%\autopsy\mcp` 아래의 정한 이름이다 [11][6].
어느 정리도 모델이나 사용자가 준 경로를 대상으로 받지 않는다 [1][4][6].
사건 DB, 사건 폴더, 원본 이미지는 지우는 대상에 없다.

const MAX_LOG_BYTES = 1 * 1024 * 1024; // 1 MB — rotate when exceeded

function log(level, message) {
    // Only ERROR level is persisted to disk. INFO/DEBUG calls are no-ops
    // by design — they would be too noisy in production and are visible
    // during development via a debugger or by temporarily removing this guard.
    if (level !== "ERROR") return;
    try {
        // Rotate if the log has grown too large
        try {
            if (fs.statSync(LOG_PATH).size > MAX_LOG_BYTES) {
                fs.renameSync(LOG_PATH, LOG_PATH + ".1");
            }
        } catch { /* file doesn't exist yet — that's fine */ }

        const line = `${new Date().toISOString()} [${level}] ${message}\n`;
        fs.appendFileSync(LOG_PATH, line, "utf8");
    } catch { /* never let logging crash the process */ }
}

        String localAppData = System.getenv("LOCALAPPDATA");
