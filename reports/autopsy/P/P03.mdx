# P03 조사 진척 판단

### 미구현

**판단.** 서버는 무엇을 조회했는지나 무엇이 남았는지 기록하거나 응답에 싣지 않는다.
도구 처리는 사건 DB를 질의해 결과를 돌려줄 뿐 호출 내용을 저장하지 않는다 [1].
Java 쪽은 잘못된 JSON, 예상하지 못한 예외, 포트 설정·토큰 파일 처리의 실패만 기록한다 [2][3].
STDIO 래퍼의 `mcp-stdio.log`에는 `ERROR` 수준 줄만 남는다 [4].
`get_case_summary`는 사건 이름, 데이터 소스 수, 전체 파일 수, 아티팩트 수만 돌려준다 [5].
ingest 모듈이 어느 데이터 소스에서 실행되었는지나 끝났는지를 돌려주는 도구는 없다 [6].
`get_server_status`는 서버가 실행 중인지와 사건이 열렸는지만 알린다 [7].
그래서 수행한 범위와 완료 판단은 모델과 사용자에게 맡겨진다.
