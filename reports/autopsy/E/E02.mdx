# E02 증거 무결성 검증

### 미구현

**판단.** MCP 서버에는 증거의 해시를 계산하거나 기준값과 대조하는 도구가 없다 [1].
MCP 도구가 응답에 싣는 해시는 모두 Autopsy 본체가 사건 DB에 써 둔 값을 옮긴 것이다.

`query_files`는 파일마다 사건 DB의 MD5·SHA-256·SHA-1 값을 `md5Hash`·`sha256Hash`·`sha1Hash`로 싣는다 [2].
파일의 MD5·SHA-256은 본체의 해시 조회 ingest 모듈이 파일 내용을 읽어 계산하고 사건 DB에 쓴다 [3].
이 모듈은 SHA-1을 계산하지 않는다 [3].
`query_files`의 인자 `md5`·`sha256`은 사건 DB의 해시 열과 같은 값인 파일을 고르는 조건이고 파일 내용을 다시 읽지 않는다 [4].
`query_data_sources`는 디스크 이미지의 MD5·SHA-1·SHA-256을 사건 DB에서 읽어 싣는다 [5].
이미지 해시의 계산과 대조는 본체의 데이터 소스 무결성 ingest 모듈이 한다 [6].
이 모듈은 값이 다르면 `TSK_VERIFICATION_FAILED` 분석 결과를 남긴다 [6].
`query_analysis_results`는 이 분석 결과를 다른 분석 결과와 같은 방식으로 조회해 싣는다 [7].
`get_file_content`는 파일 내용을 읽을 때 저장된 해시와 대조하지 않는다 [8].
