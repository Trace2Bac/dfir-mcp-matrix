# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
STDIO 래퍼의 의존성은 MCP TypeScript SDK 하나이고 래퍼가 여는 HTTP 연결은 `127.0.0.1`의 Autopsy MCP 주소로 가는 `fetch`뿐이다 [1][2].
래퍼는 MCP sampling으로 클라이언트 모델에게 생성을 요청하지 않고 `tools/list`와 `tools/call`만 처리한다 [3].
Java 쪽 도구 처리는 Sleuth Kit의 사건 DB API만 부른다 [4].
요청 처리 경로의 세 클래스가 가져오는 것은 Jackson, Javalin, Joda-Time, Sleuth Kit, Autopsy `Case`와 Java 표준 라이브러리다 [4].
모델은 사용자가 실행하는 MCP 클라이언트(Claude Desktop 등)에 있고 그 모델이 서버의 도구를 부른다 [5].

```javascript
async function callJava(method, params) {
    const token = readToken(); // fresh read each call — handles case reopen
    log("INFO", `-> ${method}`);

    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), CALL_TIMEOUT_MS);

    let res;
    try {
        res = await fetch(`${MCP_BASE_URL}/mcp`, {
            method: "POST",
            headers: {
                "Content-Type": "application/json",
                "Authorization": `Bearer ${token}`
            },
            body: JSON.stringify({ jsonrpc: "2.0", id: "1", method, params }),
            signal: controller.signal
        });
```

```javascript
server.setRequestHandler(CallToolRequestSchema, async (request) => {
    const toolName = request.params.name;
    log("INFO", `tools/call ${toolName}`);
    try {
        const result = await callJava("tools/call", {
            name: toolName,
            arguments: request.params.arguments ?? {}
        });
        return {
            content: [{ type: "text", text: JSON.stringify(result, null, 2) }]
        };
    } catch (err) {
        log("ERROR", `tools/call ${toolName} failed: ${err.message}`);
        return {
            content: [{ type: "text", text: `Autopsy is not reachable: ${err.message}` }],
            isError: true
        };
    }
});
```
