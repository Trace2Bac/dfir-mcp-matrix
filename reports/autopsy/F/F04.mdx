# F04 발견사항·결론 기록 관리

### 비적용

**판단.** 서버에는 발견사항, 결론, 가설을 받아 남기는 도구가 없다.
도구 18개는 모두 케이스 DB를 조회하거나 파일·보고서 내용을 읽는 도구이고 도구 이름을 처리 메서드로 나누는 곳에 기록을 받는 도구가 없다 [1].
도구 정의에도 발견사항이나 메모를 인자로 받는 도구가 없다 [2].
`query_tags`는 검사자가 Autopsy 화면에서 붙인 태그와 그 설명을 읽어 돌려주고 태그를 만들거나 고치지 않는다 [3].
사용자 문서는 MCP 클라이언트가 Autopsy 자료를 읽기만 하고 바꾸는 명령을 내릴 수 없다고 적는다 [4].

### 근거
