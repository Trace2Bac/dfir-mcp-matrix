# D02 파생물 추적

### 비적용

**판단.** 서버는 파생물을 남기지 않는다.
도구 결과는 응답으로만 나간다.
서버가 쓰는 파일은 포트 설정 파일, 인증 토큰 파일, 래퍼의 오류 기록 파일이다 [1][2].
래퍼의 오류 기록 줄에는 인자나 결과를 담는 칸이 없고 도구 이름과 오류 문구만 있다 [2].
오류 문구에는 Java 쪽 예외 문구가 그대로 실리므로 객체 ID나 질의 조건 같은 인자 값이 섞일 수 있다 [2][3].
응답 항목의 ID는 Autopsy 본체가 만든 객체를 가리키고 서버가 보관한 자료를 가리키는 ID는 없다 [4][5].
