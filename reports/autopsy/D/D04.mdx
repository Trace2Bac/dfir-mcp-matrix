# D04 출력 경로 제한

### 비적용

**판단.** 서버는 파생물을 담은 파일이나 DB를 만들거나 고치거나 지우지 않는다.
도구 처리 코드는 케이스 DB를 조회하고 파일과 보고서를 읽기만 한다 [1].
어떤 도구도 읽을 대상이나 출력 위치의 경로를 인자로 받지 않는다 [1].
`query_files`의 `pathContains`는 케이스 DB의 부모 경로 열을 거르는 검색 조건이다 [2].
내용을 읽는 `get_file_content`와 `get_report_content`는 대상을 객체 ID `objectId`로 고른다 [3].

서버가 쓰는 파일은 파생물이 아니고 위치가 코드에 정해져 있다.
Java 코드는 환경변수 `LOCALAPPDATA` 아래 `autopsy\mcp` 폴더에 `mcp-config.properties`와 `mcp-token`을 둔다 [4].
래퍼도 같은 폴더에 `mcp-stdio.log`를 둔다 [5].

        String localAppData = System.getenv("LOCALAPPDATA");

            return Path.of(localAppData, "autopsy", "mcp");
        }
        return Path.of(System.getProperty("user.home"), "AppData", "Local", "autopsy", "mcp");
