# verdict-dfir 원고

이 파일은 서버 개요다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 그 방식이 적용되지 않는 경로나 조건이 있으면 **한계**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`acada5c`](https://github.com/TimothyVang/verdict-dfir/tree/acada5c6b91545639d5a470ba0d92c0e29e73063)(2026-07-09).
줄 번호는 모두 이 커밋 기준이다.

**범위.** 저장소 `TimothyVang/verdict-dfir`는 VERDICT DFIR 플랫폼의 분석 도구 저장소다.
이 원고는 저장소의 MCP 서버 두 개를 한 서버로 본다.
두 서버는 저장소 최상위 `.mcp.json`에 함께 등록되고 같은 사건 폴더와 호출 기록을 쓰는 한 제품이므로 원고는 문장마다 어느 서버의 동작인지 밝힌다.

- `findevil-mcp`(`services/mcp/`, Rust)는 MCP SDK 없이 직접 구현한 stdio JSON-RPC 서버다. 프로토콜 버전 `2024-11-05`로 응답하고 도구 43개를 둔다(실행 확인). 사건 열기, 디스크·메모리·로그·레지스트리·네트워크 분석 도구를 둔다. 분석 도구는 Volatility 3, Hayabusa, Sleuth Kit, Plaso, Velociraptor 같은 외부 실행 파일을 하위 프로세스로 실행한다.
- `findevil-agent-mcp`(`services/agent_mcp/`, MCP Python SDK 저수준 `Server`)는 호출 기록 추가·검증, manifest 서명·검증, 발견사항 검증, 모순 탐지, 판정, 상관 분석, 사건 간 기억 같은 도구 14개를 둔다(실행 확인). 이 서버가 불러 쓰는 `services/agent/`의 `findevil_agent` 패키지는 서버 프로세스에서 실행되므로 서버 구현으로 본다.

두 서버 모두 MCP 리소스, 프롬프트, 초기화 지침을 두지 않는다(실행 확인).
두 서버를 띄우는 `scripts/run-mcp-rust.sh`, `scripts/run-mcp-python.sh`와 이들이 읽는 `scripts/lib/project-env.sh`(실행 상태 폴더 지정)는 서버 시작 경로로 본다.
SIFT 가상 머신에 SSH로 붙는 `.mcp.json.sift`와 컨테이너에 붙는 `.mcp.json.docker`는 같은 두 서버를 다른 곳에서 띄우는 클라이언트 설정이다.
`.mcp.json`에 함께 등록된 `n8n-mcp`, `playwright`, `puppeteer`, `qmd`는 이 저장소의 서버가 아니므로 원고에 사실로만 적는다.
플랫폼의 다른 저장소 `caseforge-core`(제어기)와 `verdict-opencode`(에이전트 실행기)도 이 원고의 범위가 아니다.

`scripts/verdict`와 그것이 실행하는 `scripts/find_evil_auto.py`는 두 서버를 MCP 클라이언트로 띄워 정해진 차례로 도구를 부르는 사용자 CLI다.
`scripts/`의 보고서 생성 스크립트(`render_report.py`, `build-offline-report.py`, `ground_verdict.py` 등), `CLAUDE.md`, `.claude/`(skill `verdict`, 경로 검사 훅), `agent-config/`(에이전트 지침 문서와 `expert-rules.json`)는 클라이언트 자료와 사용자 CLI다.
이 클라이언트 자료와 사용자 CLI는 상세가 클라이언트 쪽 방식을 묻는 경우, 클라이언트가 MCP 도구 호출을 기록하는 경우, 클라이언트가 서버 기록이나 응답으로 보고 산출물을 만드는 경우에만 구현으로 보고 그 밖에는 원고에 사실로만 적는다.
`apps/web/`(대시보드), `.claude/skills/dev-loop/`(개발용), `scripts/`의 시험·벤치마크·설치·배포 스크립트, `goldens/`, `docs/`, `packer/`, `ci/`, 각 패키지의 `tests/`는 서버 구현으로 보지 않는다.
README와 문서의 설명(도구 수, 보장 문구, 서명·검증 설명)은 코드로 확인한 것만 사실로 쓴다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
외부 라이브러리와 분석 도구의 동작은 아래 버전 기준의 소스로 확인했다.
근거의 "실행 확인"은 기준 커밋을 `git archive`로 풀어 둔 사본을 WSL의 Ubuntu 26.04에서 실행해 본 결과다.
`findevil-mcp`는 사본을 `cargo build --release --locked`로 빌드했다(rustc 1.93.1, 잠금 파일 `Cargo.lock`의 의존성).
`findevil-agent-mcp`는 `services/agent_mcp`에서 `uv sync --frozen`으로 잠금 파일 `uv.lock`의 의존성을 설치했다(CPython 3.12.15, MCP Python SDK 1.27.0).
서버는 저장소의 시작 스크립트로 띄웠고 실행 상태 폴더 `PROJECT_LOCAL`은 사본 밖의 시험 폴더로 지정했다.
서버와 시험 스크립트는 네트워크 namespace를 새로 만든 상태(`unshare -rn`)로 실행해 바깥 네트워크에 닿지 않게 했다.
설치되지 않은 분석 도구는 받은 인자를 기록하는 시험용 실행 파일로 바꿔 서버 쪽 처리만 확인했다.
입력은 직접 만든 시험용 파일과 공개 시험 자료만 썼다.

**외부 도구 버전 기준.** Rust 의존성은 `Cargo.lock`, Python 의존성은 `services/agent_mcp/uv.lock`이 고정한 버전을 쓴다(MCP Python SDK 1.27.0, pydantic 2.13.3, cryptography 46.0.7, sigstore 3.6.7, duckdb 1.6.0.dev12, mitreattack-python 5.4.6).
`rust-toolchain.toml`은 Rust 1.88.0을 고정하지만 실행 확인 빌드는 rustc 1.93.1로 했다.
분석 도구는 저장소의 설치 스크립트 `scripts/install-dfir-tools.sh`가 기본값으로 정한 버전을 기준으로 한다(Volatility 3 2.11.0, Hayabusa 2.19.0, Chainsaw 2.13.0, Velociraptor 0.74.6, pandoc 3.1.11.1).
이 설치 스크립트는 `scripts/setup`과 `INSTALL.md`가 안내하는 기본 설치 경로다.
`--docker` 경로의 `docker/dfir.Dockerfile`과 최상위 `requirements.txt`는 Volatility 3를 2.27.0으로 고정하므로 컨테이너 경로에서는 버전이 다르다.
이 스크립트가 버전을 정하지 않고 SIFT Workstation이나 시스템 패키지에 맡기는 도구는 기준 커밋 시각(2026-07-09 17:32Z) 전 최신 릴리스를 쓴다.

- MCP Python SDK 1.27.0은 태그 `v1.27.0`의 커밋 `6524782`로 확인한다.
- pydantic 2.13.3은 태그 `v2.13.3`의 커밋 `9e9a111`로 확인한다.
- sigstore-python 3.6.7은 태그 `v3.6.7`의 커밋 `2cb4a17`로 확인한다.
- Volatility 3 2.11.0은 태그 `v2.11.0`의 커밋 `5e75cff`로 확인한다.
- Sleuth Kit은 설치 스크립트가 정하지 않으므로 기준 시각 전 최신 릴리스 4.15.0(태그 `sleuthkit-4.15.0`, 커밋 `01de034`)으로 확인한다.
- Velociraptor 0.74.6 실행 파일은 릴리스 `v0.74`의 자산이고 저장소에 `v0.74.6` 태그가 없다. 아티팩트 정의는 가장 가까운 태그 `v0.74.5`의 커밋 `0490409`로 확인한다.
- GitHub CLI는 설치 스크립트가 정하지 않으므로 기준 시각 전 최신 릴리스 2.96.0(태그 `v2.96.0`, 커밋 `b300f2e`)으로 확인한다.
- Rust 크레이트 mail-parser 0.11.4는 저장소에 같은 태그가 없어 crates.io 패키지가 적은 원본 커밋 `250f3a1`로 확인한다.
- 원고에서 인용한 그 밖의 분석 도구와 라이브러리 버전은 이 단락에 더한다.

**바뀔 수 있는 것.** 범위와 외부 도구 버전 기준은 조사하며 맞지 않는 곳이 나오면 검토를 거쳐 바꾼다.
