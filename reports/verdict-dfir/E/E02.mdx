# E02 증거 무결성 검증

### E02.01 등록 시 기준값 자동 계산

**구현.** 이 방식은 `findevil-mcp`의 `case_open`에 적용된다 [1].
`case_open`은 모델이 요청하지 않아도 등록할 이미지 전체의 SHA-256을 1 MiB씩 읽어 계산한다 [1][2].
분할 EWF는 찾은 조각을 번호 차례로 이어 읽은 바이트 전체를 해시 하나로 계산한다 [1][2].
기준값은 응답의 `image_hash`와 사건 폴더 `case.json`의 `image_hash`에 남는다 [1][3].
기준값 계산 전에 받은 경로와 조각이 링크가 아닌 일반 파일인지 확인한다 [1].
`case_open`으로 E01·E02 조각을 등록하자 두 조각을 이은 바이트의 해시가 `image_hash`에 실렸다 [4].

**한계.** 기준값은 등록할 때 보이는 조각으로만 계산한다.
마지막 조각이 빠진 분할 이미지는 남은 조각만으로 해시를 계산하고 알리지 않는다 [5].
`findevil-mcp`의 다른 도구는 증거를 읽을 때 이 기준값과 대조하지 않는다 [6].
`findevil-agent-mcp`의 `verify_finding`은 도구를 다시 실행해 도구 출력의 해시를 대조할 뿐 증거의 기준값을 읽지 않는다 [7].
`manifest_finalize`의 `extra`에 이미지 해시를 넣을 수 있지만 서버는 그 값을 `case.json`과 대조하지 않는다 [8].

### E02.04 도구를 요청해 검증

**구현.** 이 방식은 `case_open`의 선택 인자 `expected_sha256`에 적용된다 [1][9].
모델이 `expected_sha256`을 주면 계산한 해시와 대소문자를 가리지 않고 대조한다 [1].
기준값은 모델이 준 값이고 서버가 앞서 `case.json`에 남긴 값을 꺼내 대조하는 도구는 없다 [1][6].
사용자 CLI `scripts/find_evil_auto.py`는 폴더 증거의 디스크 이미지를 등록할 때 자기 목록에서 계산한 해시를 `expected_sha256`으로 넘긴다 [10].

### E02.05 불일치 시 중단·경고

**구현.** 이 방식은 `case_open`의 해시 대조에 적용된다 [1].
해시가 다르면 사건 폴더를 만들기 전에 `ImageHashMismatch` 오류로 끝나고 서버는 이를 JSON-RPC 오류 코드 `-32602`로 돌려준다 [1][11].
오류 문구에는 기대값과 계산한 값이 함께 실린다 [12].
`expected_sha256`을 `00`으로 주자 `image hash mismatch: expected 00, got …` 오류가 돌아왔다 [4].

**한계.** 대조가 실패해도 서버는 그 사실을 파일에 남기지 않는다 [1].
같은 이미지를 `expected_sha256` 없이 다시 등록하면 대조 없이 사건이 만들어진다 [1].

```rust
fn sha256_files(paths: &[PathBuf]) -> Result<String, CaseOpenError> {
    let mut hasher = Sha256::new();
    let mut buf = vec![0u8; SHA_BUFFER_SIZE];
    for path in paths {
        let file = File::open(path).map_err(|source| CaseOpenError::ImageUnreadable {
            path: path.clone(),
            source,
        })?;
        let mut reader = BufReader::with_capacity(SHA_BUFFER_SIZE, file);
        loop {
            let n = reader
                .read(&mut buf)
                .map_err(|source| CaseOpenError::ImageUnreadable {
                    path: path.clone(),
                    source,
                })?;
            if n == 0 {
                break;
            }
            hasher.update(&buf[..n]);
        }
    }
    let digest = hasher.finalize();
    Ok(hex_encode(&digest))
}
```
