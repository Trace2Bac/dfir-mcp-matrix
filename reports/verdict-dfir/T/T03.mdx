# T03 실행 조건 확인

### T03.01 선행 결과 대조

**구현.** 이 방식은 `findevil-mcp`의 `disk_extract_artifacts`에 적용된다 [1].
이 도구는 사건 폴더의 자원 기록 `session_resources.json`에서 `mount_id`의 `disk_mount` 자원을 찾는다 [1].
찾은 자원의 `status`가 `mounted`가 아니면 이미지를 읽지 않고 `mount resource is not mounted`로 거부한다 [1].
`status`는 `disk_mount`가 `mounted`로 적고 `disk_unmount`가 `unmounted`로 바꾼다 [2].
`ewfmount`가 없어 파일 시스템을 마운트하지 않고 Sleuth Kit으로 이미지를 직접 읽기로 한 자원도 `mounted`로 적힌다 [3].
`disk_unmount`로 해제한 `mount_id`로 `disk_extract_artifacts`를 부르자 `mount resource is not mounted`로 거부되었다 [4].

`disk_unmount`는 자원의 `status`를 보지 않으므로 이미 해제한 자원도 다시 해제한다 [2].
같은 `mount_id`로 `disk_unmount`를 두 번 부르자 두 번 모두 성공했다 [4].

다른 도구는 앞선 호출의 결과나 상태로 호출을 막지 않는다.
- 도구 설명은 `verify_finding`과 `detect_contradictions`를 `judge_findings`보다 먼저, `manifest_finalize`를 마지막에 부르라고 적지만 서버는 이 차례를 확인하지 않는다 [5].
- `judge_findings`는 발견사항마다 검증 결과가 하나씩 있어야 받지만 그 검증 결과는 모델이 같은 호출의 인자로 넘기는 값이다 [6].
- `detect_contradictions`의 `resolution_required`는 응답 항목에 적히기만 하고 `judge_findings`의 입력에는 모순 처리 결과를 받는 인자가 없다 [7].

`manifest_finalize`는 호출 기록에 앞선 `tool_call_output` 항목이 없는 `finding_approved` 항목이 있으면 manifest를 쓰지 않는다 [8].
이 확인은 발견사항이 인용한 호출이 기록에 있는지 보는 것이고 그 기록 항목은 모델이 `audit_append`로 직접 추가할 수 있다 [8][9].

승인, 호출자 인증, 실행 자원 확인, 동시 실행 수 제한은 두 서버 모두에 없다.
두 서버는 stdio로만 실행되어 원격 MCP 연결을 받지 않는다 [10].
`.mcp.json.sift`는 SSH로 SIFT 가상 머신의 두 서버를 실행하지만 이 연결의 인증은 클라이언트의 `ssh`가 하고 서버는 호출자를 확인하지 않는다 [11].
`findevil-mcp`는 표준 입력에서 한 줄을 읽어 처리하고 응답을 쓴 뒤 다음 줄을 읽으므로 도구 호출은 하나씩 차례로 실행된다 [10].
이는 서버가 정한 제한이 아니라 처리 반복문의 구조에서 생기는 동작이다.

```python
def _uncited_findings(audit_log: AuditLog) -> list[str]:
    """finding_approved records whose tool_call_id is absent from the chain
    so far. Chain order matters: a finding cannot cite a future tool call."""
    seen_tool_calls: set[str] = set()
    uncited: list[str] = []
    for record in audit_log.iter_records():
        if record.kind == "tool_call_output":
            tcid = str(record.payload.get("tool_call_id") or "")
            if tcid:
                seen_tool_calls.add(tcid)
        elif record.kind == "finding_approved":
            cited = str(record.payload.get("tool_call_id") or "")
            if not cited or cited not in seen_tool_calls:
                uncited.append(str(record.payload.get("finding_id") or f"seq-{record.seq}"))
    return uncited
```

```rust
pub fn run_stdio_server_with_streams<R, W>(input: R, mut output: W) -> std::io::Result<()>
where
    R: Read,
    W: Write,
{
    let registry = build_registry();
    let mut reader = BufReader::new(input);
    let mut line = String::new();

    loop {
        line.clear();
        let n = reader.read_line(&mut line)?;
        if n == 0 {
            // EOF — peer closed.
            break;
        }
        let trimmed = line.trim();
        if trimmed.is_empty() {
            continue;
        }
        if let Some(response) = dispatch(trimmed, &registry) {
            writeln!(output, "{response}")?;
            output.flush()?;
        }
    }
    Ok(())
}
```
