# I03 외부 전송 범위 구성

### I03.01 해시 전송

**구현.** 이 방식은 `findevil-agent-mcp`의 `manifest_finalize`가 여는 Sigstore 서명 연결, Rekor 투명성 기록 연결, RFC 3161 시각 인증 서버 연결에 적용된다 [1][2].
`signer`가 `sigstore`이면 서명자는 manifest 본문을 정규화한 바이트를 sigstore 3.6.7의 `sign_artifact`에 넘긴다 [3][4].
`sign_artifact`는 이 바이트의 SHA-256 다이제스트에 서명하고 Rekor에는 다이제스트, 서명, 서명 인증서를 담은 `hashedrekord` 항목을 보낸다 [5].
Fulcio에는 임시 공개 키와 토큰의 신원을 담은 인증서 요청과 토큰을 보낸다 [6].
manifest 본문 자체는 보내지 않는다 [5].
`anchor_transparency`를 켜면 `_build_statement`가 Merkle 루트를 `subject`의 다이제스트로, 고정 문구를 `predicate`로 둔 in-toto 문장을 만들어 Rekor에 올린다 [7].
Rekor에 올리지 못하면 `openssl ts -query`로 Merkle 루트 다이제스트의 시각 인증 요청을 만들어 시각 인증 서버에 보낸다 [8].
Merkle 루트는 도구 출력 해시와 승인된 발견사항 항목 해시를 잎으로 만든 값이다 [9].
그래서 바깥으로 나가는 조사 자료는 해시 값뿐이다 [5][7][8].
manifest의 `extra`에 들어가는 이미지 경로 같은 값은 서명한 본문의 다이제스트에만 반영된다 [4][5].
바깥 네트워크가 없는 상태에서 두 경로를 실행하자 TUF 저장소와 시각 인증 서버의 이름 해석에서 멈췄고 보낸 내용은 코드로만 확인했다 [10].

### I03.05 민감 값 빼기·가림 후 전송

**구현.** 이 방식은 `expert_miss_capture`가 `gh issue create`로 GitHub 이슈를 만드는 경로에 적용된다 [11].
서버는 이슈 제목과 본문에 사건을 가리키는 값을 `_github_case_label`로 만든다 [11].
환경변수 `FINDEVIL_MISS_GH_REDACT`가 `1`이면 `case_id` 대신 `case_id`의 SHA-256 앞 12자리를 `case_sha256_prefix=`로 넣는다 [11].
`FINDEVIL_MISS_GH_REDACT`를 `1`로 두고 기록용 시험 실행 파일 `gh`를 부르자 제목과 본문의 사건 값이 `case_sha256_prefix=02905559c06a`였다 [12].

본문에는 사건 값 말고 `edit_type`, `finding_id`, `expert_name`, `edit_text`가 들어간다 [13].
`edit_text`는 호출한 쪽이 쓴 수정 글이고 서버가 고르거나 가리지 않고 그대로 본문 끝에 넣는다 [13][12].

**한계.** `FINDEVIL_MISS_GH_REDACT`가 `1`이 아니면 가림이 적용되지 않고 `case_id=<값>`을 그대로 넣는다 [11].
`FINDEVIL_MISS_GH_REDACT` 없이 기록용 시험 실행 파일 `gh`를 부르자 제목과 본문의 사건 값이 `case_id=case-123`이었다 [12].
가림은 `case_id`에만 적용되고 `finding_id`와 전문가 이름 `expert_name`은 `FINDEVIL_MISS_GH_REDACT`가 켜져 있어도 그대로 보낸다 [13][12].

```python
def _build_statement(merkle_root_hex: str) -> Any:
    """Build the in-toto DSSE Statement whose subject is the Merkle root."""
    from sigstore.dsse import StatementBuilder, Subject  # type: ignore[import-not-found]

    return StatementBuilder(
        subjects=[Subject(name=_SUBJECT_NAME, digest={"sha256": merkle_root_hex})],
        predicate_type=_PREDICATE_TYPE,
        predicate={
            "tool": "verdict-dfir",
            "note": "audit-chain Merkle root transparency anchor",
        },
    ).build()
```

```python
def _rfc3161_timestamp(merkle_root_hex: str, tsa_url: str) -> str:
    """Return a base64 RFC-3161 timestamp token over the root digest.

    Builds an ``openssl ts`` query over the SHA-256 imprint (the Merkle root is
    already a SHA-256 digest) and POSTs it to the TSA. Requires ``openssl`` +
    network; raises otherwise so the caller degrades to a ``none`` block.
    """
    if not _openssl_available():
        raise RuntimeError("openssl not found on PATH; cannot build an RFC-3161 token")
    with tempfile.TemporaryDirectory() as td:
        tsq = Path(td) / "request.tsq"
        _run_openssl(
            [
                "ts",
                "-query",
                "-digest",
                merkle_root_hex,
                "-sha256",
                "-cert",
                "-out",
                str(tsq),
            ]
        )
        tsr_bytes = _post_timestamp(tsa_url, tsq.read_bytes())
    return base64.b64encode(tsr_bytes).decode("ascii")
```

```python
def _post_timestamp(tsa_url: str, request_bytes: bytes) -> bytes:
    # Fixed https TSA URL + RFC-3161 content type; only fires on the opt-in path.
    req = urllib.request.Request(
        tsa_url,
        data=request_bytes,
        headers={"Content-Type": "application/timestamp-query"},
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=_OPENSSL_TIMEOUT_S) as resp:
        return resp.read()
```

```python
def _github_case_label(case_id: str) -> str:
    if os.environ.get("FINDEVIL_MISS_GH_REDACT") == "1":
        digest = hashlib.sha256(case_id.encode("utf-8")).hexdigest()[:12]
        return f"case_sha256_prefix={digest}"
    return f"case_id={case_id}"
```
