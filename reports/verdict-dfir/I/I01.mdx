# I01 외부 연동 대상 관리

### I01.01 명시적 설정으로 활성화

**구현.** 이 방식은 `findevil-agent-mcp`의 `manifest_finalize`가 Merkle 루트를 외부 투명성 기록에 올리는 경로와 `expert_miss_capture`가 GitHub 이슈를 만드는 경로에 적용된다 [1][2].
`manifest_finalize`는 인자 `anchor_transparency`가 참이면 먼저 `require_rekor_enabled`로 환경변수 `FINDEVIL_REKOR_ENABLE`을 확인한다 [1][3].
이 값이 비었거나 `0`, `false`, `no`, `off`이면 `RekorAnchorDisabledError`를 올려 연결하지 않는다 [3].
`expert_miss_capture`는 환경변수 `FINDEVIL_MISS_GH_ENABLED`가 `1`이고 `PATH`에서 `gh`를 찾았을 때만 `gh issue create`를 실행한다 [2].
`FINDEVIL_REKOR_ENABLE` 없이 `anchor_transparency`를 켠 `manifest_finalize`는 `RekorAnchorDisabledError`를 담은 오류 결과를 받았다 [4].
`FINDEVIL_MISS_GH_ENABLED` 없이 부른 `expert_miss_capture`는 `gh`를 실행하지 않았고 `github_issue_url`이 `null`이었다 [4].
이 값을 `1`로 두고 기록용 시험 실행 파일 `gh`를 `PATH` 앞에 두자 `gh issue create`가 실행되었다 [5].

`manifest_finalize`의 인자 `signer`를 `sigstore`로 주는 서명 경로에는 이런 환경변수 조건이 없다 [6].
이 경로는 인자 하나로 Sigstore의 TUF 저장소, Fulcio, Rekor에 연결한다 [6][7].
`FINDEVIL_REKOR_ENABLE`과 `SIGSTORE_ID_TOKEN` 없이 `signer`를 `sigstore`로 주자 서버가 `tuf-repo-cdn.sigstore.dev`의 이름 해석을 시도했고 실패한 뒤 `ed25519`로 서명했다 [4].
`findevil-mcp`의 서버 코드는 외부에 연결하지 않는다 [8].

### I01.02 자격증명 존재로 활성화

**구현.** 이 방식은 `manifest_finalize`가 Merkle 루트를 Rekor에 올리는 경로에 적용된다 [9].
`_submit_to_rekor`는 환경변수 `SIGSTORE_ID_TOKEN`이 비어 있으면 Sigstore 서비스에 연결하기 전에 예외를 올린다 [9].
`anchor_merkle_root`는 이 예외를 받으면 Rekor 대신 RFC 3161 시각 인증 서버로 바꾼다 [10].
`FINDEVIL_REKOR_ENABLE=1`과 `anchor_transparency`를 주고 토큰 없이 부르자 manifest의 `transparency_log`에 Rekor에는 토큰이 없어 올리지 않았다는 까닭과 시각 인증 서버의 이름 해석 실패가 함께 남았다 [11].

**한계.** 토큰이 없을 때 바꾸는 시각 인증 서버 연결은 자격증명 없이 이루어진다 [10][12].
`signer`가 `sigstore`인 서명은 `SigningContext.production`으로 TUF 저장소에서 신뢰 정보를 받은 뒤에 토큰을 확인한다 [13][7].
그래서 이 서명 경로는 토큰이 없어도 TUF 저장소에 연결한다 [4].

### I01.04 호출별 선택

**구현.** 이 방식은 `manifest_finalize`의 인자 `signer`와 `anchor_transparency`에 적용된다 [14].
`signer`는 `stub`, `ed25519`, `sigstore` 가운데 하나이고 기본값은 `ed25519`다 [14].
`sigstore`를 고르면 서버는 Sigstore 서명자를 먼저 쓰고 실패하면 `ed25519`, `stub` 순서로 바꾼다 [6].
`anchor_transparency`는 기본값이 거짓이고 참으로 준 호출에서만 투명성 기록에 연결한다 [14][1].
이 인자로 연결을 켜려면 `FINDEVIL_REKOR_ENABLE`도 켜져 있어야 한다 [1][3].

### I01.05 고정 목적지

**구현.** 이 방식은 `manifest_finalize`가 여는 Sigstore 연결과 RFC 3161 시각 인증 서버 연결에 적용된다 [6][9][10].
서명 경로와 Rekor 경로 모두 sigstore 3.6.7의 `SigningContext.production`을 쓴다 [7][9].
`SigningContext.production`은 Fulcio `https://fulcio.sigstore.dev`, Rekor `https://rekor.sigstore.dev`, TUF 저장소 `https://tuf-repo-cdn.sigstore.dev`의 운영 서비스 주소를 쓴다 [13].
시각 인증 서버 주소는 `anchor.py`의 상수 `_DEFAULT_TSA_URL`인 `https://freetsa.org/tsr`다 [10].
`anchor_merkle_root`의 인자 `rekor_url`은 결과 블록의 `url` 필드에만 쓰이고 실제로 올리는 곳을 바꾸지 않는다 [10][15].
`manifest_finalize`는 이 인자를 넘기지 않고 도구 입력에도 목적지 인자가 없다 [1][14].

### I01.06 설정으로 목적지 지정

**구현.** 이 방식은 `expert_miss_capture`가 실행하는 `gh issue create`에 적용된다 [16].
서버는 `gh`에 레이블, 제목, 본문만 넘기고 대상 저장소를 정하는 `--repo`를 넘기지 않는다 [16].
기록용 시험 실행 파일 `gh`가 받은 인자에도 `--repo`가 없었다 [5].
GitHub CLI 2.96.0은 저장소를 따로 정하지 않은 명령을 환경변수 `GH_REPO`나 작업 폴더의 로컬 저장소에 적용한다 [17].
그래서 이슈를 만들 저장소는 `gh` 설정과 서버를 실행한 폴더의 git 원격이 정하고 도구 인자로는 바꿀 수 없다 [16][17].

```python
def _submit_to_rekor(merkle_root_hex: str) -> tuple[Any, str]:
    """Keyless-sign a DSSE Statement over the root and submit it to Rekor.

    Returns ``(log_entry, body_b64)``. Requires ``$SIGSTORE_ID_TOKEN`` and
    network — raises on any missing prerequisite so the caller can degrade.
    Isolated as a single function so tests can monkeypatch it without touching
    the live log.
    """
    from sigstore.oidc import IdentityToken  # type: ignore[import-not-found]
    from sigstore.sign import SigningContext  # type: ignore[import-not-found]

    token = os.environ.get(_ID_TOKEN_ENV)
    if not token:
        raise RuntimeError(
            f"no OIDC identity token in ${_ID_TOKEN_ENV}; keyless Rekor signing "
            "needs one (acquire via Sigstore's OIDC flow)"
        )

    statement = _build_statement(merkle_root_hex)
    ctx = SigningContext.production()
    identity = IdentityToken(token)
    with ctx.signer(identity) as signer:
        bundle = signer.sign_dsse(statement)
    entry = bundle.log_entry
    return entry, str(entry.body)
```
