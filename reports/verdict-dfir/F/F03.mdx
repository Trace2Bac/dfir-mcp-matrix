# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 두 서버는 도구를 처리하는 중에 모델을 부르지 않는다.
`findevil-mcp`는 MCP SDK와 HTTP 클라이언트 없이 stdio로 JSON-RPC를 처리하고 외부 프로그램은 분석 도구만 실행한다 [1][2].
`findevil-agent-mcp`의 도구 14개가 불러오는 `findevil_agent` 모듈은 판정, 검증, 서명, 기억 저장 모듈이고 모델 API를 부르지 않는다 [3][4].
`findevil_agent` 패키지에는 모델을 부르는 `llm`과 `agentloop`이 있고 의존성에 `anthropic`이 있다 [5][6].
서버를 시작한 뒤 불러온 모듈에는 `findevil_agent.llm`, `findevil_agent.agentloop`, `anthropic`이 없었다 [4].
`findevil-agent-mcp`는 MCP sampling으로 클라이언트 모델에게 생성을 요청하지 않는다 [7].
판정과 검증 모듈은 모델 없이 정해 둔 규칙과 다시 실행한 도구 출력만 쓴다 [8][9].

[7] 서버는 `list_tools`와 `call_tool` 처리기만 등록하고 처리기는 도구 처리 함수를 부를 뿐이다.
```python
    @server.call_tool()
    async def call_tool(name: str, arguments: dict[str, Any]) -> list[TextContent]:
        spec = specs.get(name)
        if spec is None:
            log.warning("agent_mcp_unknown_tool", tool=name)
            return _error_content(f"unknown tool: {name!r}", kind="unknown_tool")

        try:
            validated = spec.input_model.model_validate(arguments)
        except ValidationError as exc:
            log.warning(
                "agent_mcp_validation_error",
                tool=name,
                errors=exc.errors(include_url=False),
            )
            return _error_content(f"input validation failed: {exc}", kind="validation")

        try:
            result = await spec.handler(validated)
        except Exception as exc:
            log.error(
                "agent_mcp_handler_exception",
                tool=name,
                exc_type=type(exc).__name__,
                exc=str(exc),
            )
            return _error_content(f"{type(exc).__name__}: {exc}", kind="handler")

        return _to_text_content(result, tool=name)
```
