# F04 발견사항·결론 기록 관리

### F04.01 자유 노트

**구현.** 이 방식은 `findevil-agent-mcp`의 `memory_remember`에 적용된다 [1].
`memory_remember`는 사건 ID, 종류 `kind`, 키, 글 `value`, SHA-256을 받아 사건을 넘나드는 기억 저장소에 한 행으로 남긴다 [1][2].
행의 시각 `ts`는 호출자가 주면 그 값이고 주지 않으면 서버가 정한 시각이다 [1][2].
도구 설명은 IOC, 해시, TTP, 호스트 이름과 함께 발견사항 요약 `finding_summary`를 남길 종류로 적는다 [3].
`value`는 판정 필드가 없는 글이고 서버는 그 내용을 해석하지 않는다 [1][2].
클라이언트 엔진은 CONFIRMED 발견사항마다 기법 ID나 `finding_id`를 키로, 설명을 `value`로 하여 `finding_summary` 행을 남긴다 [4].
`memory_recall`은 같은 저장소에서 글이 맞는 행을 찾아 사건 ID와 행의 시각 `ts`와 함께 돌려준다 [5].
`finding_summary` 행 하나를 남기고 다시 찾자 키, 글, 사건 ID, 저장 시각이 돌아왔다 [6].

**한계.** `kind`는 도구 설명에만 다섯 값이 적혀 있고 서버는 값을 검사하지 않는다 [1][3].
목록에 없는 `kind`를 준 시험 입력도 저장되었다 [6].
같은 키로 다시 저장하면 앞 행을 남긴 채 새 행을 더하고 두 행 모두 검색된다 [2][6].

### F04.03 근거 증거·호출 참조

**구현.** 이 방식은 `findevil-agent-mcp`의 `audit_append`로 남기는 `finding_approved` 기록에 적용된다 [7][8].
`audit_append`는 종류 `kind`와 내용 `payload`를 받아 사건의 호출 기록 `audit.jsonl`에 한 줄로 더한다 [7].
도구 설명은 `finding_approved`를 종류의 예로 적는다 [9].
`payload`의 필드는 서버가 정하지 않고 호출자가 정한다 [7].
서버 코드 가운데 `manifest_finalize`는 `finding_approved` 기록의 `tool_call_id`를 그 발견사항이 인용한 호출로, `finding_id`를 그 발견사항의 ID로 읽는다 [10][11].
클라이언트 엔진은 최종 발견사항마다 `finding_id`, 등급, `tool_call_id`, 발견사항 전체와 그 SHA-256을 `payload`에 넣는다 [12].
`finding_approved`에 `tool_call_id`를 넣어 남긴 기록은 `audit.jsonl`에 그대로 남았다 [13].

**한계.** `audit_append`는 `finding_approved` 기록에 `tool_call_id`가 있는지 검사하지 않는다 [7][9].
`tool_call_id`가 없는 기록도 받으며 인용한 호출이 기록에 있는지는 `manifest_finalize`를 부를 때에야 대조한다 [10].
INFERRED 발견사항이 기대는 사실의 ID `derived_from`은 엔진이 넣는 발견사항 전체 안에만 있고 서버 코드는 이 값을 근거 참조로 읽지 않는다 [12][10].

### F04.05 수정·철회 이력

**구현.** 이 방식은 `findevil-agent-mcp`의 `expert_miss_capture`에 적용된다 [14].
`expert_miss_capture`는 사람 전문가가 자동으로 만든 보고서를 고친 내용을 사건 ID, `finding_id`, 고친 종류 `edit_type`, 고친 글 `edit_text`, 전문가 이름과 함께 받는다 [14][15].
받은 내용은 `expert_misses.jsonl`에 `expert_miss` 종류의 해시 체인 기록으로 더해져 순번 `seq`와 시각이 붙는다 [15][16].
`edit_type`은 `connector`, `playbook`, `rule`, `qa`, `escalation`, `language` 가운데 하나여야 하고 `edit_text`는 4000자까지 받는다 [14].
`finding_id` `F-1`을 고친 기록을 남기자 `expert_misses.jsonl`에 순번 0의 기록이 생겼다 [13].
사용자 CLI `find_evil_auto.py`는 실행 중 발견사항의 등급이 바뀌면 앞 등급과 바뀐 등급, 계기가 된 `tool_call_id`, 사유를 `verdict_revision` 기록으로 `audit_append`에 넘긴다 [17].
서버 코드는 이 기록을 읽지 않는다 [18].

**한계.** 이 기록은 고친 사실과 고친 글만 남기고 고치기 전 값은 남기지 않는다 [15].
`audit.jsonl`의 `finding_approved` 기록은 바뀌지 않고 서버에는 발견사항을 고치거나 철회하는 도구가 없다 [7][19].
`finding_id`는 선택 인자여서 어느 발견사항을 고쳤는지 없이도 기록된다 [14].

### F04.06 파일·DB에 저장

**구현.** 이 방식은 `findevil-agent-mcp`의 `audit_append`, `memory_remember`, `expert_miss_capture`에 적용된다 [7][1][14].
`audit_append`와 `expert_miss_capture`는 호출자가 준 경로의 JSONL 파일 끝에 한 줄을 쓰고 `fsync`한 뒤 돌려준다 [16].
쓸 때마다 파일을 다시 열어 마지막 줄의 순번과 해시를 읽으므로 서버를 다시 시작해도 같은 파일에 이어 쓴다 [16][20].
`memory_remember`는 호출자가 준 경로의 SQLite FTS5 DB에 행을 더하고 바로 commit한다 [2].
세 도구 모두 프로세스 메모리에 발견사항을 두지 않는다 [7][1][14].
저장 경로는 모두 호출자가 인자로 주므로 같은 사건의 발견사항이 어느 파일에 남는지는 클라이언트가 정한다 [7][1][14].

```python
    def remember(
        self,
        *,
        case_id: str,
        kind: str,
        key: str,
        value: str,
        sha256: str,
        ts: str | None = None,
        case_path: str | None = None,
    ) -> None:
        now = ts or datetime.now(tz=UTC).isoformat().replace("+00:00", "Z")
        self._conn.execute(
            "INSERT INTO memories(case_id, kind, key, value, sha256, ts) VALUES (?, ?, ?, ?, ?, ?)",
            (case_id, kind, key, value, sha256, now),
        )
        self._conn.execute(
            "INSERT INTO meta(case_id, case_path, first_seen_ts, last_updated_ts) "
            "VALUES (?, ?, ?, ?) "
            "ON CONFLICT(case_id) DO UPDATE SET last_updated_ts=excluded.last_updated_ts, "
            "case_path=COALESCE(excluded.case_path, meta.case_path)",
            (case_id, case_path, now, now),
        )
        self._conn.commit()
```

```python
def mem_confirmed_for_remember(merged: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Keep only CONFIRMED findings — the only ones worth remembering (G5)."""
    return [f for f in merged if f.get("confidence") == "CONFIRMED"]


def mem_remember_payload(finding: dict[str, Any]) -> dict[str, Any] | None:
    """Build a memory_remember payload for a CONFIRMED finding, else None."""
    if finding.get("confidence") != "CONFIRMED":
        return None
    description = finding.get("description") or ""
    key = finding.get("mitre_technique") or finding.get("finding_id") or ""
    if not key or not description:
        return None
    digest = hashlib.sha256(f"{key}\n{description}".encode()).hexdigest()
    return {
        "kind": "finding_summary",
        "key": str(key),
        "value": str(description),
        "sha256": f"sha256:{digest}",
    }
```

```python
def _uncited_findings(audit_log: AuditLog) -> list[str]:
    """finding_approved records whose tool_call_id is absent from the chain
    so far. Chain order matters: a finding cannot cite a future tool call."""
    seen_tool_calls: set[str] = set()
    uncited: list[str] = []
    for record in audit_log.iter_records():
        if record.kind == "tool_call_output":
            tcid = str(record.payload.get("tool_call_id") or "")
            if tcid:
                seen_tool_calls.add(tcid)
        elif record.kind == "finding_approved":
            cited = str(record.payload.get("tool_call_id") or "")
            if not cited or cited not in seen_tool_calls:
                uncited.append(str(record.payload.get("finding_id") or f"seq-{record.seq}"))
    return uncited
```

```python
        """Append one record. Thread-safe. fsyncs before returning."""
```

```python
    def _load_tail(self) -> None:
        """Populate ``_next_seq`` + ``_last_hash`` from any existing file."""
        if not self.path.is_file():
            return
        last_line: bytes | None = None
        count = 0
        with self.path.open("rb") as f:
            for raw in f:
                raw = raw.rstrip(b"\n")
                if not raw:
                    continue
                last_line = raw
                count += 1
        if last_line is None:
            return
        try:
            obj = json.loads(last_line)
        except json.JSONDecodeError as exc:
            raise AuditLogError(
                f"audit log {self.path}: last line is not valid JSON: {exc}"
            ) from exc
        if not isinstance(obj, dict) or "seq" not in obj:
            raise AuditLogError(f"audit log {self.path}: last line is not an audit record")
        self._next_seq = int(obj["seq"]) + 1
        self._last_hash = hash_line(last_line)
        if count != self._next_seq:
            raise AuditLogError(
                f"audit log {self.path}: seq-count mismatch "
                f"(file has {count} lines but last seq is {obj['seq']})"
```
