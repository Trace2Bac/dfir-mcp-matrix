# D04 출력 경로 제한

### D04.01 서버가 출력 위치 결정

**구현.** 이 방식은 `findevil-mcp`의 `case_open`, `disk_mount`, `disk_extract_artifacts`, `bulk_extract`, `pst_parse`, `srum_parse`와 두 서버의 주입 문자열 기록에 적용된다 [1][2][3][4][5][6][7].
사건 폴더의 상위 위치는 환경변수 `FINDEVIL_HOME`이 정하고 값이 없으면 `$HOME/.findevil`이다 [1].
시작 스크립트 `run-mcp-rust.sh`와 `run-mcp-python.sh`는 `project-env.sh`를 읽어 `FINDEVIL_HOME`을 `$PROJECT_LOCAL/findevil`로, `TMPDIR`을 `$PROJECT_LOCAL/tmp`로 정한 뒤 서버를 실행한다 [8].
`case_open`은 UUIDv4로 `case_id`를 짓고 `cases/<case_id>/`를 만든다 [1].
다른 도구는 호출 인자 `case_id`가 영문자·숫자·`-`·`_`만으로 된 값일 때만 사건 폴더를 찾는다 [9].
사건 폴더 아래 위치는 서버가 `mounts/<mount_id>/`, `extracted/disk/<extract_id>/`, `extracted/bulk_extract/<이미지 파일 이름>/`, `extracted/pst/pst-export-<UUID>/`, `_xartifact/srum-<pid>-<나노초>/`로 정한다 [2][3][4][5][6].
`bulk_extract`의 폴더 이름은 이미지 파일 이름에서 영문자·숫자·`.`·`-`·`_` 밖의 문자를 `_`로 바꾼 한 조각이다 [10].
주입 문자열 기록은 `FINDEVIL_INJECTION_LEDGER`가 있으면 그 경로이고 없으면 `FINDEVIL_HOME`의 `injection_alerts.jsonl`이며 둘 다 없으면 쓰지 않는다 [7].
상위 폴더로 가는 값을 `case_id`로 주자 `disk_extract_artifacts`가 거부했다 [11].
`.mcp.json.sift`와 `.mcp.json.docker`는 시작 스크립트를 거치지 않고 서버 실행 파일을 직접 실행하며 `FINDEVIL_HOME`을 넘기지 않는다 [12].
이 실행 환경에 `FINDEVIL_HOME`이 없으면 실행 계정의 `~/.findevil`이 사건 폴더의 상위 위치다 [1].

`findevil-agent-mcp`의 파일 쓰기 도구는 쓸 경로를 호출 인자로 받아 그대로 쓰고 없는 상위 폴더를 만든다 [13].
그런 인자는 `audit_append`의 `path`, `manifest_finalize`의 `output_path`, `memory_remember`의 `store_path`, `pool_handoff`의 `audit_path`, `expert_miss_capture`의 `ledger_path`, `memory_remember`·`memory_recall`·`accuracy_compare`의 `audit_log_path`다 [13].
`expert_miss_capture`는 `ledger_path`가 절대 경로인지만 검사한다 [14].
사건 폴더와 관계없는 깊은 경로를 `audit_append`의 `path`로 주자 상위 폴더까지 만들고 파일을 썼다 [15].
사용자 CLI `find_evil_auto.py`는 이 인자를 자기 실행 폴더 안의 경로로 정해 넘긴다 [16].
`argsafe`의 `validate_passthrough_args`는 출력 플래그 값이 증거·마운트 폴더 아래인지 보는 함수지만 이 함수를 부르는 도구는 없다 [17].
저장소의 Claude Code 훅은 `Write`·`Edit`·`Read` 도구의 `file_path`에만 적용되고 MCP 도구 인자에는 적용되지 않는다 [18].

**한계.** `disk_mount`와 `vss_mount`는 호출 인자 `mount_point`가 있으면 그 경로를 검사 없이 폴더로 만들어 마운트 지점으로 쓴다 [2][19].
사건 폴더 밖 경로를 `mount_point`로 주자 두 도구 모두 그 폴더를 만들었고 `disk_mount`는 그 경로를 `session_resources.json`에 남겼다 [11].

### D04.04 이름·확장자·충돌 검사

**구현.** 이 방식은 `findevil-mcp`의 `disk_extract_artifacts`가 이미지 안 경로로 목적지를 정할 때 적용된다 [3].
`safe_join`은 이미지 안 경로를 `/`로 나눠 빈 조각, `.`, `..`를 건너뛰고 나머지 조각만 출력 폴더 아래에 붙인다 [20].
`fls` 출력의 inode 값은 숫자와 `-`만 있을 때 받고 아니면 그 줄을 건너뛴다 [21].
inode 값은 `icat` 인자이면서 삭제 항목 폴더 이름에 들어간다 [3].
상위 폴더로 가는 이미지 안 경로를 낸 시험용 `fls`로 추출하자 그 파일은 출력 폴더 안에 생겼다 [11].
두 검사는 실제 경로로 바꾸지 않는 문자열 검사다 [20][21].

**한계.** `..`를 건너뛴 결과가 다른 항목과 같은 경로가 되면 `File::create`가 앞 파일을 덮어쓰고 이미 있는 이름인지는 보지 않는다 [3][20].
이 경우는 코드로만 확인했다.

### D04.06 실행 환경의 쓰기 위치 제한

**구현.** 이 방식은 컨테이너 실행 구성 `.mcp.json.docker`로 두 서버를 실행할 때 적용된다 [12].
`run-dfir-container.sh`는 저장소 폴더를 컨테이너의 `/workspace`에 읽고 쓰게, 증거 경로를 `/evidence`에 읽기 전용으로 붙여 컨테이너를 시작한다 [22].
`.mcp.json.docker`는 `docker exec`로 이 컨테이너 안에서 두 서버를 실행하므로 서버가 부르는 분석 도구도 컨테이너 안에서 실행된다 [12].
이 실행에서 호스트에 붙는 폴더는 이 둘뿐이라 도구가 호스트에 파일을 남길 수 있는 위치는 저장소 폴더다 [22].
사용자 CLI는 이 실행에서 `audit.jsonl`과 `run.manifest.json`을 `/workspace/tmp/auto-runs/<case_id>/` 아래로 정한다 [16].
이미지의 환경변수에는 `FINDEVIL_HOME`이 없어 `findevil-mcp`의 사건 폴더는 컨테이너 계정의 `~/.findevil`에 생기고 호스트에 붙은 폴더 밖이다 [23][1].
컨테이너는 디스크 마운트를 위해 `SYS_ADMIN` 권한과 `/dev/fuse`를 받고 AppArmor 프로필 없이 시작한다 [22].
이 실행 구성은 코드로만 확인했고 컨테이너를 실행하지 않았다.

기본 `.mcp.json`은 호스트에서, `.mcp.json.sift`는 SSH로 붙은 SIFT VM에서 서버를 실행하고 이 두 실행에는 이 장치가 없다 [24][12].

```rust
/// A filesystem-safe, deterministic stem for the staging directory.
///
/// Derived from the image file name at runtime (never a baked-in
/// literal). Keeps ASCII alphanumerics, `.`, `-`, `_`; folds everything
/// else to `_`. Empty input yields `image`.
#[must_use]
pub fn sanitize_stem(image: &Path) -> String {
    let raw = image
        .file_name()
        .and_then(|n| n.to_str())
        .unwrap_or("image");
    let cleaned: String = raw
        .chars()
        .map(|c| {
            if c.is_ascii_alphanumeric() || matches!(c, '.' | '-' | '_') {
                c
            } else {
                '_'
            }
        })
        .collect();
    if cleaned.is_empty() {
        "image".to_string()
    } else {
        cleaned
    }
}
```

```rust
/// Join an image-internal path under `base`, keeping only normal components so a
/// hostile image filename can't escape the output directory.
fn safe_join(base: &Path, rel: &str) -> PathBuf {
    let mut dest = base.to_path_buf();
    for part in rel.replace('\\', "/").split('/') {
        if part.is_empty() || part == "." || part == ".." {
            continue;
        }
        dest.push(part);
    }
    dest
}
```
