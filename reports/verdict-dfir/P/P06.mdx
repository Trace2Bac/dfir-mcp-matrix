# P06 조사 상태 유지

### P06.03 조사 상태를 파일·DB에 저장

**구현.** 이 방식은 `findevil-mcp`의 사건 폴더와 `findevil-agent-mcp`의 호출 기록 파일, 기억 DB에 적용된다 [1][2][3].
`case_open`은 사건 ID, 이미지 경로, 해시, 크기, 등록 시각, 표시 이름을 사건 폴더의 `case.json`에 쓴다 [1].
`disk_mount`·`disk_extract_artifacts`·`disk_unmount`는 마운트와 꺼내기 항목을 사건 폴더의 `session_resources.json`에 적는다 [4][5].
항목마다 ID, 종류, 상태, 만든 시각과 바꾼 시각, 이미지 경로, 마운트 위치, 상위 항목, 꺼낸 파일 목록, 실행한 명령이 남는다 [5].
꺼낸 파일은 사건 폴더의 `extracted/` 아래에 남는다 [6].
`findevil-agent-mcp`의 `audit_append`·`memory_remember` 같은 도구는 모델이 준 경로의 해시 체인 JSONL 파일과 SQLite 기억 DB에 쓴다 [2][3].
두 서버의 주입 문구 정리 기록은 `FINDEVIL_HOME`의 `injection_alerts.jsonl`에 쌓인다 [7].

두 서버는 조사 상태를 프로세스 메모리에 두지 않는다.
`findevil-mcp`는 시작할 때 도구 목록만 만들고 호출마다 사건 폴더의 파일을 다시 읽는다 [8][5].
`findevil-agent-mcp`도 시작할 때 도구 목록만 만들고 호출마다 `AuditLog`와 `MemoryStore`를 새로 연다 [9][2][3].

**한계.** `case_open`의 응답은 사건 DB 경로 `db_path`(`evidence.ddb`)를 돌려주지만 이 파일을 만드는 도구는 없다 [10].
`case_open`을 실행한 사건 폴더에 `evidence.ddb`는 없었다 [11].
`vss_mount`는 마운트를 `session_resources.json`에 적지 않고 `mount_id`를 응답으로만 돌려준다 [12].
기억 DB의 기록은 `memory_recall`이 기록 시각이 오래될수록 신뢰도를 낮춰 정렬할 뿐 지우거나 만료하지 않는다 [13].

### P06.04 재시작 뒤 자동 복구

**구현.** 이 방식은 `findevil-mcp`의 마운트 기록과 `findevil-agent-mcp`의 호출 기록 해시 체인에 적용된다 [5][14].
`disk_extract_artifacts`·`disk_unmount`는 호출마다 받은 `case_id`의 `session_resources.json`을 읽어 `mount_id`의 항목을 찾는다 [5].
그래서 서버를 다시 시작해도 모델이 앞서 받은 `case_id`와 `mount_id`로 이어서 부를 수 있다 [5].
한 서버 프로세스에서 `mode: mock` 마운트를 등록하고 다른 서버 프로세스에서 그 `mount_id`로 꺼내기와 마운트 해제가 이어졌다 [15].
`AuditLog`는 만들어질 때 파일의 마지막 줄을 읽어 다음 `seq`와 앞 줄 해시를 정한다 [14].
서버를 다시 시작한 뒤 같은 파일에 덧붙인 줄은 `seq` 2와 앞 프로세스 마지막 줄의 해시를 받았다 [16].

**한계.** 마운트 기록의 상태는 실제 마운트 상태와 대조하지 않는다 [5][17].
`ewfmount`가 없어 이미지를 바로 읽기로 한 항목도 상태가 `mounted`로 남는다 [18].
`AuditLog`는 마지막 줄이 JSON으로 읽히지 않거나 줄 수와 `seq`가 맞지 않으면 오류를 내고 이어 쓰지 않는다 [14].
서버가 시작할 때 사건 폴더나 호출 기록을 스스로 읽는 코드는 없고 모델이 `case_id`나 파일 경로를 다시 넘겨야 상태가 읽힌다 [8][9].

pub fn run_stdio_server_with_streams<R, W>(input: R, mut output: W) -> std::io::Result<()>
where
    R: Read,
    W: Write,
{
    let registry = build_registry();
    let mut reader = BufReader::new(input);
    let mut line = String::new();

    loop {
        line.clear();
        let n = reader.read_line(&mut line)?;
        if n == 0 {
            // EOF — peer closed.
            break;
        }
        let trimmed = line.trim();
        if trimmed.is_empty() {
            continue;
        }
        if let Some(response) = dispatch(trimmed, &registry) {
            writeln!(output, "{response}")?;
            output.flush()?;
        }
    }
    Ok(())
}

        """Populate ``_next_seq`` + ``_last_hash`` from any existing file."""
        if not self.path.is_file():
            return
        last_line: bytes | None = None
        count = 0
        with self.path.open("rb") as f:
