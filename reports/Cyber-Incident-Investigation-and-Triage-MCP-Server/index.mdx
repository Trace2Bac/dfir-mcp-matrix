# Cyber-Incident-Investigation-and-Triage-MCP-Server 원고

이 파일은 서버 개요다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 그 방식이 적용되지 않는 경로나 조건이 있으면 **한계**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`39e8509`](https://github.com/abhiii011/Cyber-Incident-Investigation-and-Triage-MCP-Server/tree/39e85090231cf0c9b7edcb1700d169372e50d8b1)(2026-09-03).
줄 번호는 모두 이 커밋 기준이다.

**범위.** 저장소 전체가 MCP 서버 하나다.
`server.py`의 `create_server`가 MCP Python SDK의 저수준 `Server`(이름 `forensics`)를 만들고 도구 31개를 등록한다.
도구 31개 가운데 22개는 `server.py`에 직접 적고 9개(레지스트리, Prefetch, Shellbags, LNK, 점프 목록, MFT, Amcache, ShimCache, 이벤트 로그)는 `core/tool_generator.py`가 `config/forensic_tools.yaml`에서 만든다.
서버는 MCP 리소스, 프롬프트, 초기화 지침(`instructions`)을 두지 않는다.
진입점은 둘이다.
`main.py`는 stdio로 실행되고 Windows 전용 모듈 `msvcrt`를 불러온다.
`remote_server.py`는 Starlette와 uvicorn으로 SSE 전송을 연다.
`main.py`는 시작할 때 출력 폴더를 만들고 이미지 등록부 파일을 읽지만 `remote_server.py`는 둘 다 하지 않고 서버 객체만 만든다.
`handlers/`, `mounters/`, `utils/`, `core/`, `models/`, `app_config.py`, `config/`는 서버 구현이다.
다만 `mounters/cleanup_wsl_mounts.py`는 서버가 불러오지 않고 사용자가 따로 실행하는 정리 스크립트라 원고에 사실로만 적는다.
KAPE와 그 모듈이 부르는 Zimmerman 도구, SleuthKit, Arsenal Image Mounter, Volatility 3, UnifiedLogReader, chainbreaker, apfs-fuse, hashcat, Windows PowerShell은 서버가 하위 프로세스로 실행하거나 불러 쓰는 분석 도구로 본다.
`utils/fsevents_parser.py`는 mac_apt의 FSEvents 파서를 옮겨 온 코드이고 서버 구현으로 본다.
`install.ps1`과 `install.bat`은 저장소가 지원하는 실행 환경을 만드는 설치 스크립트로 본다.
README의 설명(도구 수, 보장 문구 등)은 코드로 확인한 것만 사실로 쓴다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
분석 도구의 동작은 아래 버전 기준의 소스로 확인했다.
근거의 "실행 확인"은 Windows 11 Pro(10.0.26200)에서 기준 커밋을 `git archive`로 풀어 둔 사본을 CPython 3.13.14로 실행해 본 결과다.
파이썬 의존성은 기준 커밋 날짜(2026-09-03) 이전에 올라온 버전으로 설치했다(`mcp` 1.29.1, `pydantic` 2.13.5, `PyYAML` 6.0.3, `psutil` 7.2.2, `requests` 2.34.2, `python-registry` 1.3.1, `lz4` 4.4.5, `biplist` 1.0.3, `pefile` 2024.8.26).
도구는 `main.py`로 띄운 stdio 서버에 MCP SDK 클라이언트로 부르거나 처리기 함수를 같은 프로세스에서 불러 확인했다.
그 환경에는 KAPE, Zimmerman 도구, SleuthKit, Arsenal Image Mounter, Volatility 3, UnifiedLogReader, chainbreaker, apfs-fuse, hashcat이 없었다.
없는 분석 도구는 받은 인자와 실행 조건을 기록하는 시험용 실행 파일로 바꿔 서버 쪽 처리만 확인했다.
이미지 마운트(드라이버 설치와 관리자 권한이 필요한 경로, WSL 경로), 해시 크래킹, ngrok 공개 터널은 실행하지 않았다.
`remote_server.py`는 직접 실행하지 않고 그 모듈의 Starlette 앱을 `127.0.0.1`에만 열어 확인했다.

**외부 도구 버전 기준.** 저장소는 분석 도구를 담지 않고 버전도 고정하지 않는다.
`install.ps1`은 KAPE, Zimmerman 도구, SleuthKit, Arsenal Image Mounter, Volatility 3, UnifiedLogReader가 이미 `Tools\`에 있다고 적지만 `.gitignore`는 이 폴더를 저장소에서 뺀다.
`requirements.txt`는 `mcp<2` 말고는 버전을 적지 않는다.
그래서 설정 파일이 버전을 드러내는 SleuthKit을 빼면 기준 커밋 날짜(2026-09-03)의 최신 릴리스나 기본 브랜치 커밋을 기준으로 한다.

- SleuthKit: `config/config.yaml`의 경로가 `sleuthkit-4.14.0-win32`다. 4.14.0(`sleuthkit/sleuthkit` 태그 `sleuthkit-4.14.0`, `c6efd66`)을 기준으로 한다.
- Volatility 3: 2.28.0(`volatilityfoundation/volatility3` 태그 `v2.28.0`, `d61335e`)이다.
- hashcat: 7.1.2(`hashcat/hashcat` 태그 `v7.1.2`, `c75f446`)다.
- Zimmerman 도구: GitHub 태그가 배포 빌드를 따르지 않아 기준 날짜의 기본 브랜치 커밋으로 확인한다. RECmd `bcd0ac3`, LECmd `8107efc`, EvtxECmd(`EricZimmerman/evtx`) `03a7a1f`, JLECmd `4cba3cc`, PECmd `acdf082`, AppCompatCacheParser `0cf059f`, MFTECmd `6aadd87`, AmcacheParser `2904455`이다. SBECmd는 공개 소스를 찾지 못해 문서로만 확인한다.
- KAPE와 Arsenal Image Mounter: 소스가 공개되어 있지 않다. 동작은 배포처 문서로만 확인한다.
- UnifiedLogReader: 기준 날짜의 기본 브랜치 커밋 `39f774e`(`ydkhatri/UnifiedLogReader`)다.
- mac_apt: `utils/fsevents_parser.py`의 출처로 기준 날짜의 커밋 `0edb4cd`(`ydkhatri/mac_apt`)와 대조한다.
- chainbreaker: `install.ps1`이 기본 브랜치를 설치한다. 기준 날짜의 커밋 `2eb467d`(`n0fate/chainbreaker`)다.
- apfs-fuse: `install.ps1`이 기본 브랜치를 내려받아 빌드한다. 기준 날짜의 커밋 `66b86bd`(`sgan81/apfs-fuse`)다.
- KAPE 문서와 모듈 정의: 기준 날짜의 `EricZimmerman/KapeDocs` 커밋 `6fbfee8`과 `EricZimmerman/KapeFiles` 커밋 `13c564b`로 확인한다.
- `pyngrok`: `remote_server.py`가 불러오지만 `requirements.txt`와 설치 스크립트에 없다. 기준 날짜의 최신 릴리스 8.1.2(`alexdlaird/pyngrok` 태그 `8.1.2`, `eb90e21`)로 확인한다. 이 라이브러리가 받는 ngrok 에이전트는 소스가 공개되어 있지 않아 문서로만 확인한다.
- MCP Python SDK: `mcp<2`를 만족하는 1.29.1(`modelcontextprotocol/python-sdk` 태그 `v1.29.1`, `b222713`)이다.
- Python: README는 3.10~3.13을 적는다. 실행 확인에는 CPython 3.13.14를 썼다.

**바뀔 수 있는 것.** 범위와 외부 도구 버전 기준은 조사하며 맞지 않는 곳이 나오면 검토를 거쳐 바꾼다.
