# L01 기록 방식

### L01.01 공통 요청 처리 단계에서 기록

**구현.** 이 방식은 서버가 받는 모든 MCP 도구 호출이 지나는 `call_tool` 처리기에 적용된다 [1].
`create_server`가 저수준 `Server`에 등록한 `call_tool`은 처리기를 고르기 전에 `Tool called: <도구 이름> with arguments: <인자>` 줄을 쓴다 [1].
이 줄은 `config/forensic_tools.yaml`에서 만든 도구 9개, `server.py`에 직접 적은 도구 22개, 목록에 없는 도구 이름에 모두 쓰인다 [1][2].
처리기에서 난 예외가 `call_tool`까지 올라오면 `call_tool`은 예외 추적 정보를 담은 `ERROR` 줄을 한 번 더 쓴다 [2].
두 줄은 `server` 모듈 로거가 쓰고 루트 로거의 처리기가 받는다 [1][3].
stdio 진입점 `main.py`는 `setup_logging`으로 루트 로거에 `forensic_output/logs/mcp_server_<시작 시각>.log` 파일 처리기 하나만 붙이고 수준을 `DEBUG`로 둔다 [3][4].
`main.py`는 표준 오류를 저장소 폴더의 `stderr.log`로 바꿔 덧붙여 쓴다 [4].
SSE 진입점 `remote_server.py`는 모듈을 불러올 때 `basicConfig`로 작업 폴더의 `remote_server.log`와 표준 출력에 `INFO` 수준 이상의 줄을 쓰게 한다 [5].
stdio 서버에 도구 10개를 차례로 부르자 `mcp_server_<시각>.log`에 호출마다 `Tool called` 줄이 남았고 목록에 없는 이름 `no_such_tool`의 호출도 남았다 [6].
`remote_server`의 앱을 `127.0.0.1`에만 열어 SSE로 도구 2개를 부르자 같은 줄이 `remote_server.log`와 표준 출력에 남았다 [7].
같은 저장소에는 MCP 도구 호출을 기록하는 클라이언트 코드, 훅, 사용자 CLI가 없다.

**한계.** MCP Python SDK 1.29.1이 입력 schema 검사에서 거부한 호출은 `call_tool`에 오지 않아 `Tool called` 줄이 남지 않는다 [8].
SDK는 이 호출에 요청 종류만 적은 `Processing request of type CallToolRequest` 줄과 `DEBUG` 수준 줄을 남기고 이 줄들에는 인자가 없다 [8][9][3].
필수 인자 `kape_module` 없이 `kape_parse_artifact`를 부르자 `Input validation error` 결과가 돌아왔고 `Tool called` 줄은 남지 않았다 [10].

### L01.02 도구별 기록 호출

**구현.** 이 방식은 도구 8개의 본문이 부르는 두 기록 함수 묶음에 적용된다 [11][12].

- `prepare_disk_image`, `crack_hash`, `analyze_macos_plist`, `analyze_macos_unified_logs`, `analyze_macos_keychain`, `analyze_macos_fsevents`는 `core/operation_logging.py`의 `log_operation_start`·`log_operation_success`·`log_operation_error`를 직접 부른다 [11].
- `kape_parse_artifact`와 `get_kape_modules_catalog`는 `core/logging_setup.py`의 `log_kape_operation`을 직접 부른다 [12].

`operation_logging`은 모듈을 불러올 때 `forensic_output/operations_logs/operations_<날짜>.log`에 쓰는 `forensic_operations` 로거를 만든다 [13].
이 로거는 상위 로거로 전파를 끄지 않아 같은 항목이 루트 로거의 `mcp_server_<시각>.log`에도 남는다 [13][6].
`log_kape_operation`은 부를 때마다 `forensic_output/kape_logs/kape_operations.log`를 덧붙이기 모드로 열고 항목 하나를 쓴다 [14].
`kape_parse_artifact`는 KAPE를 실행하기 전과 끝난 뒤에 이 함수를 한 번씩 부르고 `get_kape_modules_catalog`는 실행이 끝난 뒤 한 번 부른다 [12].
나머지 도구 23개의 본문은 두 기록 함수를 부르지 않는다 [11][12].
이 도구들은 공통 단계의 `Tool called` 줄과 처리기마다 다르게 쓰는 로거 줄만 남긴다 [1][6].

**한계.** `kape_parse_artifact`는 결과 폴더에 이미 파일이 있으면 저장해 둔 결과를 돌려주고 `log_kape_operation`을 부르지 않는다 [15].
KAPE 실행 파일이 설정 경로에 없을 때도 이 함수를 부르기 전에 오류를 돌려준다 [15].

```python
    @server.call_tool()
    async def call_tool(name: str, arguments: dict):
        """Route tool calls to appropriate handlers (with lazy loading for performance)"""
        try:
            logger.info(f"Tool called: {name} with arguments: {arguments}")
            
            from core.tool_generator import get_tool_handler_mapping
            yaml_mapping = get_tool_handler_mapping()
            
            if name in yaml_mapping:
                handler_path = yaml_mapping[name]
                module_path, function_name = handler_path.rsplit('.', 1)
                
                import importlib
                module = importlib.import_module(module_path)
                handler = getattr(module, function_name)
                
                return await handler(
                    paths=arguments.get("paths", []),
                    modules=arguments.get("modules", ["all"]),
                    output_format=arguments.get("output_format", "csv")
                )
```

```python
def setup_logging(log_dir):
    """Setup logging configuration with file output only (no console)."""
    log_dir = Path(log_dir)
    log_dir.mkdir(parents=True, exist_ok=True)
    
    log_filename = log_dir / f"mcp_server_{datetime.now().strftime('%Y%m%d_%H%M%S')}.log"
    
    # File logging only - no console handler to avoid buffer conflicts with MCP stdio
    logging.basicConfig(
        level=logging.DEBUG,
        format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
        handlers=[
            logging.FileHandler(log_filename, encoding='utf-8')
        ]
    )
    
    logger = logging.getLogger("forensic_mcp")
    logger.setLevel(logging.DEBUG)
    
    logger.info(f"Logging initialized. Log file: {log_filename}")
    return logger
```

```python
def log_kape_operation(operation_type, command, return_code, output, error, kape_logs_dir):
    """Log KAPE operations to audit log for forensic defensibility"""
    from datetime import datetime
    import hashlib
    
    log_file = Path(kape_logs_dir) / "kape_operations.log"
    log_file.parent.mkdir(parents=True, exist_ok=True)
    
    timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
    operation_hash = hashlib.sha256(f"{timestamp}{command}".encode()).hexdigest()[:16]
    
    log_entry = f"""
{'='*80}
OPERATION ID: {operation_hash}
TIMESTAMP: {timestamp}
TYPE: {operation_type}
COMMAND: {command}
RETURN CODE: {return_code}
{'='*80}
OUTPUT:
{output}
{'='*80}
ERRORS:
{error}
{'='*80}
"""
    
    with open(log_file, 'a', encoding='utf-8') as f:
        f.write(log_entry)
```
