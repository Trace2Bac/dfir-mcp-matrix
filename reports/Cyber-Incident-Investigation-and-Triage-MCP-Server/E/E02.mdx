# E02 증거 무결성 검증

### E02.01 등록 시 기준값 자동 계산

**구현.** 이 방식은 디스크 이미지를 준비하는 `prepare_disk_image`에 적용된다 [1].
`prepare_disk_image`는 모델의 요청 없이 `ExtractionManager.calculate_image_hash`로 이미지의 해시를 계산한다 [1].
해시는 이미지 파일의 앞 10 MiB(파일이 더 작으면 파일 전체)를 한 번에 읽은 SHA-256이다 [2].
EWF 이미지는 첫 조각 파일 자체의 바이트를 읽으므로 이 값은 담긴 매체 데이터의 해시가 아니다 [2].
설정 파일의 `hash_algorithm`을 읽는 코드는 없고 해시 종류는 `calculate_image_hash`에 정해져 있다 [2][3].
값은 등록부 항목의 `hash`에 들어가 `prepared_images_registry.json`에 저장되고 응답에 `Hash:`로 실린다 [4][5].
값의 앞 12글자는 이미지 ID `unique_image_id`의 끝에 들어간다 [4].
`list_prepared_images`는 이 값을 `SHA256 Hash:`로, `kape_parse_artifact`는 `Image Hash:`로 응답에 싣는다 [6][7].

등록한 해시를 다시 계산해 현재 이미지와 대조하는 코드는 없다.
같은 이미지를 다시 준비하면 해시를 새로 계산하지만 앞 항목의 값과 대조하지 않는다 [8].
앞 항목은 그 키가 실제 경로와 같은 표기이면 지우고 다르면 지우지 않는다 [8][9][10].
파일의 SHA-256 전체를 계산하는 `calculate_file_hash`는 `image_handlers.py`가 불러오기만 하고 부르지 않는다 [11].
해시를 계산하는 MCP 도구는 없고 `analyze_memory`가 받는 메모리 파일과 로컬 경로로 받은 증거 파일은 해시하지 않는다 [12].

**한계.** 앞 10 MiB 뒤의 내용은 해시에 들어가지 않는다 [2].
11 MiB 시험 이미지의 10 MiB 뒤 바이트 하나를 바꾼 사본은 원래 이미지와 같은 해시를 냈고 앞부분의 바이트 하나를 바꾼 사본은 다른 해시를 냈다 [13].
응답과 `list_prepared_images`는 이 값을 범위 없이 `Hash`·`SHA256 Hash`로 적어 이미지 전체의 해시인지 구별되지 않는다 [5][6].
파일을 읽다 예외가 나거나 읽은 바이트가 없으면 이미지 경로 문자열의 MD5를 해시 자리에 넣고 응답에는 그 사실을 적지 않는다 [2].
없는 파일 경로로 이 함수를 부르자 32글자 MD5 값을 돌려주었다 [13].
크기가 0인 파일도 경로 문자열의 MD5를 돌려준다 [2].
Arsenal 드라이브나 WSL LVM 마운트가 살아 있는 이미지를 다시 준비하면 해시를 계산하지 않고 등록부의 값을 응답에 싣는다 [8].

[2] `calculate_image_hash`는 앞 10 MiB를 SHA-256으로 해시하고 실패하면 경로 문자열의 MD5를 돌려준다.

```python
        try:
            if not os.path.exists(image_path):
                raise FileNotFoundError(f"Image path does not exist: {image_path}")

            file_size = os.path.getsize(image_path)
            if file_size == 0:
                logger.warning(f"Image file is empty: {image_path}")
                return hashlib.md5(image_path.encode()).hexdigest()

            hash_obj = hashlib.sha256()
            sample_size = min(sample_size_mb * 1024 * 1024, file_size)
            
            with open(image_path, 'rb') as f:
                chunk = f.read(sample_size)
                if not chunk:
                    logger.warning(f"Could not read from image file: {image_path}")
                    return hashlib.md5(image_path.encode()).hexdigest()
                hash_obj.update(chunk)
            
            full_hash = hash_obj.hexdigest()
            
            logger.info(f"Image hash calculated: {full_hash} (Sample size: {len(chunk)} bytes)")
            return full_hash
            
        except Exception as e:
            logger.error(f"Failed to calculate image hash: {e}")
            fallback_hash = hashlib.md5(image_path.encode()).hexdigest()
            logger.info(f"Using fallback hash: {fallback_hash}")
            return fallback_hash
```
