# E01 증거 등록 관리

### E01.01 증거 ID·등록 목록

**구현.** 이 방식은 디스크 이미지를 준비하는 `prepare_disk_image`에 적용되고 증거를 등록하는 경로는 이것 하나다 [1].
`prepare_disk_image`는 이미지 경로를 키로 등록부 `PREPARED_IMAGES`에 항목 하나를 넣고 항목마다 `unique_image_id`를 둔다 [1][2].
`unique_image_id`는 이미지 파일 이름 줄기, 판별한 OS, 이미지 앞 10 MiB의 SHA-256 앞 12글자를 이은 값이다 [2][3].
등록부는 바뀔 때마다 `prepared_images_registry.json`에 다시 쓴다 [4].
`list_prepared_images`는 등록한 이미지마다 이름, 해시, 파일시스템, OS, 접근 위치, 준비 시각, 사건 폴더, 원래 경로를 돌려준다 [5].
이름 줄기가 `disk01`인 시험 이미지를 준비하자 등록부에는 이미지 경로를 키로 한 항목 하나가 생기고 `unique_image_id`는 `disk01_windows_5e492a138d5e`였다 [6].

등록부를 거치지 않는 증거 입력도 있다.
`analyze_memory`는 메모리 파일 경로를 받아 등록하지 않고 Volatility 3에 넘긴다 [7].
Windows 아티팩트 도구와 `identify_file_type`은 준비한 이미지 밖의 로컬 경로도 등록 없이 분석한다 [8][9].

**한계.** 같은 이미지를 다시 준비하면 앞 항목을 지우고 새 항목으로 바꾸므로 등록부에는 마지막 준비만 남는다 [10].
다만 등록부 키는 받은 경로 문자열이고 다시 준비할 때는 실제 경로로 바꾼 값으로 앞 항목을 찾는다 [1][10].
그래서 앞 준비의 경로 표기가 실제 경로와 다르고 새 준비의 표기와도 다르면 앞 항목이 남아 같은 이미지의 항목이 둘 생긴다 [1][10].
같은 시험 이미지를 소문자 표기와 상대 경로로 차례로 준비하자 같은 `unique_image_id`의 항목 두 개가 남았다 [11].
`cleanup_prepared_image`는 항목을 지운다 [12].
Arsenal로 준비한 항목은 마운트 객체를 담아 등록부 파일에 쓰다 끊기므로 파일이 JSON으로 읽히지 않는다 [4][13].
Arsenal 꼴의 항목을 넣고 저장하자 파일은 121바이트에서 끊겼고 다시 읽은 등록부는 비어 있었다 [14].

### E01.02 수집 위치와 저장 위치 기록

**구현.** 이 방식은 `prepare_disk_image`가 만드는 등록부 항목에 적용된다 [2].
항목의 `image_path`에 받은 이미지 경로가 들어가고 등록부의 키도 이미지 경로다 [1][2].
서버는 이미지를 다른 곳으로 옮기지 않으므로 이 경로가 증거가 놓인 저장 위치다.
항목에는 서버가 만든 접근 위치 `access_point`와 사건 폴더 `case_dir`도 들어간다 [2].
WSL로 마운트한 항목에는 WSL 안의 마운트 위치 `mount_point`가 더 들어간다 [15].
서버에는 단말에서 증거를 수집하는 기능이 없어 증거를 어디서 가져왔는지는 남기지 않는다.

### E01.03 크기·등록 시각·등록자 기록

**구현.** 이 방식은 `prepare_disk_image`가 만드는 등록부 항목에 적용된다 [2].
항목의 `prep_time`에 준비한 시각이 서버 시간대의 ISO 문자열로 들어간다 [2].
`prepare_disk_image`는 이미지 파일 크기를 읽어 응답에 바이트 수와 GB로 싣는다 [1][16].
크기는 등록부 항목에 넣지 않는다 [2].
등록한 주체를 담는 필드는 없다 [2].

**한계.** 같은 이미지를 같은 경로 표기로 다시 준비하면 `prep_time`이 새 시각으로 바뀌어 처음 등록한 시각이 남지 않는다 [10][1].
시험 이미지를 두 번 준비하자 `list_prepared_images`의 `Prepared` 값은 두 번째 준비 시각이었다 [6].

```python
def save_prepared_images(prepared_images, base_output_dir):
    """Save prepared images registry to disk (excluding non-serializable objects)"""
    registry_file = Path(base_output_dir) / "prepared_images_registry.json"
    
    try:
        serializable_images = {}
        for path, info in prepared_images.items():
            serializable_info = {k: v for k, v in info.items() if k != 'mounter'}
            serializable_images[path] = serializable_info
        
        with open(registry_file, 'w') as f:
            json.dump(serializable_images, f, indent=2)
        logger.info(f"Saved prepared images registry: {len(serializable_images)} images")
    except Exception as e:
        logger.error(f"Failed to save prepared images registry: {e}")
```
