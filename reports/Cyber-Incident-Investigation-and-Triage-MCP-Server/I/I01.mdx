# I01 외부 연동 대상 관리

### I01.03 기본 활성화

**구현.** 이 방식은 SSE 진입점 `remote_server.py`의 ngrok 연결에 적용된다 [1].
`remote_server.py`를 직접 실행하면 환경변수 `USE_NGROK`의 기본값 `true`에 따라 `start_ngrok`이 실행되고 그 뒤에 uvicorn이 `0.0.0.0`에서 요청을 받는다 [1].
`start_ngrok`은 `pyngrok`의 `ngrok.connect`에 로컬 포트만 넘겨 ngrok 서비스로 가는 터널을 연다 [2].
`USE_NGROK`를 `true`가 아닌 값으로 두면 연결하지 않는다 [1].
`pyngrok`은 `requirements.txt`에 없고 `install.ps1`도 설치하지 않는다 [3].
`pyngrok`을 불러오지 못하면 `start_ngrok`은 `pyngrok not installed` 오류 줄만 쓰고 `None`을 돌려주며 서버는 터널 없이 요청을 받는다 [2][1].
`pyngrok`이 없는 환경에서 `remote_server` 모듈의 `start_ngrok`을 부르자 이 오류 줄이 `remote_server.log`에 남고 `None`이 돌아왔다 [4].
터널 연결이 다른 이유로 실패해도 `ngrok failed` 줄만 쓰고 서버는 계속 요청을 받는다 [2].
stdio 진입점 `main.py`에는 ngrok 연결이 없다 [5].
서버 코드가 스스로 여는 외부 연결은 이 연결뿐이다 [6].
`requirements.txt`에 있는 `requests`를 불러오는 서버 코드는 없다 [6].

### I01.06 설정으로 목적지 지정

**구현.** 이 방식은 같은 ngrok 연결에 적용된다 [2].
서버 코드는 `ngrok.connect`에 로컬 포트만 넘기고 접속할 ngrok 서버 주소를 넘기지 않는다 [2].
로컬 포트는 환경변수 `PORT`가 정하고 기본값은 8000이다 [1].
`pyngrok` 8.1.2는 설정 객체를 받지 않으면 기본 설정으로 ngrok 에이전트를 시작하고 그 에이전트의 로컬 API에 터널을 만들라고 요청한다 [7].
ngrok 문서는 에이전트가 접속할 ngrok 서버 주소를 설정 파일의 `connect_url`로 정한다고 적고 사용자 지정 주소를 쓸 때 이 값을 정하라고 적는다 [8].
도구 인자로는 목적지를 바꾸지 못한다 [2].

**한계.** ngrok 에이전트는 소스가 공개되어 있지 않아 접속 주소를 정하는 방식을 ngrok 문서로만 확인했다 [8].

```python
def start_ngrok(port: int) -> str | None:
    try:
        from pyngrok import ngrok

        token = os.environ.get("NGROK_AUTHTOKEN")
        if token:
            ngrok.set_auth_token(token)

        tunnel = ngrok.connect(port)
        public_url = tunnel.public_url

        logger.info("=" * 60)
        logger.info("NGROK PUBLIC URL : %s", public_url)
        logger.info("SSE  ENDPOINT    : %s/sse", public_url)
        logger.info("=" * 60)
        print(f"\n  Remote MCP Server is LIVE!")
        print(f"  Public URL : {public_url}/sse")
        print(f"  Press Ctrl+C to stop.\n")
        return public_url
    except ImportError:
        logger.error("pyngrok not installed – run:  pip install pyngrok")
    except Exception as exc:
        logger.error("ngrok failed: %s", exc)
    return None
```
