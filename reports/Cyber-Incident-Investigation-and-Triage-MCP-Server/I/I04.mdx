# I04 서버 자격증명 처리

### I04.01 환경변수·설정 파일에 분리 보관

**구현.** 이 방식은 `remote_server.py`가 ngrok 연결에 쓰는 인증 토큰에 적용된다 [1].
`start_ngrok`은 환경변수 `NGROK_AUTHTOKEN`을 읽고 값이 있으면 `ngrok.set_auth_token`에 넘긴다 [1].
값이 없으면 `set_auth_token`을 부르지 않고 바로 `ngrok.connect`를 부른다 [1].
저장소의 코드와 설정 파일에는 토큰 값을 적은 곳이 없다 [2].
`pyngrok` 8.1.2의 `set_auth_token`은 `ngrok config add-authtoken <토큰>`을 실행해 토큰을 ngrok 설정 파일에 저장한다 [3].
`pyngrok` 8.1.2는 설정 객체를 만들 때 `NGROK_AUTHTOKEN`을 스스로 읽고 ngrok 에이전트를 시작하는 명령 행에 `--authtoken`으로 붙인다 [4].
그래서 서버가 `set_auth_token`을 부르지 않아도 토큰은 에이전트 실행 인자로 전달된다 [4].
`set_auth_token`이 저장한 토큰은 서버가 끝난 뒤에도 ngrok 기본 설정 파일에 남는다 [3][4].
ngrok 문서는 설정 파일의 `authtoken`을 에이전트가 ngrok 서비스에 접속할 때 쓰는 인증 토큰으로 적는다 [5].
서버 코드는 토큰 값을 기록이나 오류 글에서 지우는 처리를 두지 않는다 [1].
`pyngrok` 8.1.2의 `set_auth_token`은 이 명령을 `subprocess.check_output`으로 실행하고 실패할 때 나는 `CalledProcessError`를 처리하지 않는다 [3].
CPython의 `CalledProcessError` 문구에는 토큰이 들어 있는 명령 목록이 그대로 들어간다 [6].
`start_ngrok`은 이 예외를 `ngrok failed: %s` 줄로 `remote_server.log`와 표준 출력에 쓴다 [1][7].
이 경로는 ngrok을 실행하지 않아 소스로만 확인했다.
분석 도구 하위 프로세스는 `env`를 따로 받지 않아 `NGROK_AUTHTOKEN`을 포함한 서버 프로세스의 환경변수를 그대로 물려받는다 [8].

### I04.02 도구 인자 수신 금지

**구현.** 이 방식은 같은 ngrok 인증 토큰에 적용된다 [1].
토큰은 `remote_server.py`를 실행할 때 `start_ngrok`이 환경변수에서 읽고 도구 호출과 관계없이 쓰인다 [1].
도구 31개의 입력 schema에는 토큰이나 외부 접속용 자격증명을 받는 인자가 없다 [9].
schema에서 이름에 `pass`가 들어간 인자는 `analyze_macos_keychain`의 `password` 하나이고 이 값은 증거 Keychain 파일을 복호화하는 데 쓰인다 [9][10].

### 근거

[1] `start_ngrok`은 환경변수의 토큰을 `pyngrok`에 넘기고 실패하면 예외 문구를 기록 줄에 쓴다.

```python
def start_ngrok(port: int) -> str | None:
    try:
        from pyngrok import ngrok

        token = os.environ.get("NGROK_AUTHTOKEN")
        if token:
            ngrok.set_auth_token(token)

        tunnel = ngrok.connect(port)
        public_url = tunnel.public_url

        logger.info("=" * 60)
        logger.info("NGROK PUBLIC URL : %s", public_url)
        logger.info("SSE  ENDPOINT    : %s/sse", public_url)
        logger.info("=" * 60)
        print(f"\n  Remote MCP Server is LIVE!")
        print(f"  Public URL : {public_url}/sse")
        print(f"  Press Ctrl+C to stop.\n")
        return public_url
    except ImportError:
        logger.error("pyngrok not installed – run:  pip install pyngrok")
    except Exception as exc:
        logger.error("ngrok failed: %s", exc)
    return None
```
