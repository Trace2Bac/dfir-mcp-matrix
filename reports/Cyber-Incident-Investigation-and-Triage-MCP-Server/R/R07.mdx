# R07 증거 내용과 지시 구분

### R07.03 경계 태그 표시

**구현.** 이 방식은 `read_text_file`과 `read_csv_data`에 적용된다 [1][2].
`read_text_file`은 읽은 파일 내용을 ```` ``` ```` 표시와 닫는 표시 사이에 싣고 머리말과 꼬리말은 그 밖에 둔다 [1].
`read_csv_data`는 CSV 줄을 ```` ```csv ```` 표시와 닫는 표시 사이에 싣고 분석 머리말과 반환 수 꼬리말은 그 밖에 둔다 [2].
여는 표시와 닫는 표시는 같은 코드에서 함께 붙는다 [1][2].
두 처리기는 서버 문구의 줄을 줄바꿈 문자가 아니라 `\`와 `n` 두 글자로 나누므로 표시는 머리말과 같은 줄에 붙는다 [1][2].
`read_csv_data`는 CSV 줄 사이도 같은 두 글자로 이어 표시와 증거 글이 한 줄에 실린다 [2].
다른 도구는 증거에서 온 글을 이런 표시로 감싸지 않는다 [3].
모든 도구는 `TextContent` 글 하나를 돌려주고 `structuredContent`나 증거 전용 필드를 두지 않는다 [3][4].

**한계.** 서버는 내용 안의 ```` ``` ````를 바꾸거나 막지 않는다 [1][2].
그래서 증거 글 안에 같은 표시나 `\n` 두 글자가 있으면 서버가 붙인 표시나 줄 구분과 글자로 구별되지 않는다 [1][2].
`read_text_file`은 내용이 빈 값이면 표시를 붙이지 않는다 [1].
`read_text_file`은 줄바꿈 문자로 끝나지 않는 마지막 줄의 끝에서 `n`·`r`·`\` 글자를 지운다 [5].
