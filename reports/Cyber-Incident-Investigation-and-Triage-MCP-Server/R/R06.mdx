# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 증거에서 나온 비밀 값을 응답에 그대로 싣고 가리거나 빼는 코드가 없다.
서버 코드와 처리기에는 값을 가린 문자열로 바꾸거나 필드를 빼는 함수가 없다 [1][2].
`analyze_macos_keychain`은 chainbreaker 출력을 응답 본문에 그대로 싣고 비밀번호, 인증서, 키 가운데 무엇을 꺼낼지는 `dump_type`으로 정한다 [1].
`crack_hash`는 크래킹한 값을 응답 본문의 `Password:` 뒤에 그대로 싣는다 [2].
시험용 대체 실행 파일로 `crack_hash`를 불러 응답에 그 값이 가림 없이 실리는 것을 확인했다 [3].
`create_server`의 `call_tool`은 모든 호출의 인자를 서버 로그에 그대로 적는다 [4].
그래서 `crack_hash`가 받은 해시 전체와 `analyze_macos_keychain`이 받은 `password`가 서버 로그에 남는다 [4].
`analyze_macos_keychain`은 `Executing:` 줄에서 `password`를 빼지만 바로 앞 `Command base:` 줄에는 `--password`와 그 값이 든 명령 목록을 적는다 [5].
`crack_hash`는 운영 기록의 시작 항목에 해시를 앞 50자까지 적는다 [6].
