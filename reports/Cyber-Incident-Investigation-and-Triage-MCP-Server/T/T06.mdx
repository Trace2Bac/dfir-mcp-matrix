# T06 실행 환경정보 표시

### 미구현

**판단.** 서버는 분석 도구를 실행해 결과를 응답과 파생물로 내지만 실행한 도구, 참조 자료, 서버 자신의 버전을 응답, 호출 기록, 파생물 어디에도 싣지 않는다.
KAPE 모듈을 실행하는 도구의 응답은 모듈 이름, 상태, 실행 시간, 출력 폴더만 싣는다 [1].
MFTECmd와 AmcacheParser를 실행하는 도구의 응답은 실행한 명령 문자열 `command`와 출력 파일 목록을 싣고 실행 파일의 버전은 싣지 않는다 [2].

Volatility 3의 시작 문구는 서버가 읽지 않고 도구 출력째 넘긴다.
`analyze_memory`는 Volatility의 표준 출력을 결과로 싣고 표준 오류의 앞 500자를 `Info/Warnings` 아래에 붙인다 [3].
Volatility 3 2.28.0은 `Volatility 3 Framework <버전>` 문구를 JSON·CSV 출력이면 표준 오류에, 그 밖이면 표준 출력에 쓴다 [4].
실행 확인에서 이 문구를 표준 오류에 쓰는 시험용 `vol.py`로 부르면 응답의 `Info/Warnings` 아래에 그 줄이 그대로 실렸다 [5].
`get_kape_modules_catalog`는 `kape.exe --mlist .`의 표준 출력을 그대로 돌려준다 [6].
KAPE는 소스가 공개되어 있지 않아 이 출력에 KAPE의 버전이 들어 있는지는 확인하지 못했다.

버전처럼 보이는 다른 값은 실행한 도구와 묶이지 않는다.
`prepare_disk_image`는 APFS 파일 시스템을 찾으면 `SleuthKit 4.14.0 has LIMITED APFS support` 문구를 붙이는데 이 문구는 코드에 적은 글이다 [7].
`config/forensic_tools.yaml`의 `version`은 도구 명세를 만드는 코드가 읽지 않는다 [8].
서버는 MCP Python SDK의 `Server`에 이름 `forensics`만 주므로 초기화 응답의 `serverInfo.version`에는 SDK 패키지 버전이 들어간다 [9].
실행 확인에서 `serverInfo.version`은 `1.29.1`이었다 [5].

서버가 남기는 기록과 파생물에도 버전이 없다.
`forensic_operations` 기록은 도구 이름과 인자, 결과 요약만 남긴다 [10].
`kape_operations.log`는 실행 ID, 시각, 종류, 명령, 종료 코드, 출력만 남긴다 [11].
SleuthKit 접근 준비가 쓰는 `.forensic_metadata.json`은 `forensic_tool`에 `SleuthKit`만 적고 버전을 적지 않는다 [12].
서버는 처리 중에 모델을 부르지 않는다.

    """Log the start of a forensic operation"""

```python
def log_kape_operation(operation_type, command, return_code, output, error, kape_logs_dir):
    """Log KAPE operations to audit log for forensic defensibility"""
    from datetime import datetime
    import hashlib
    
    log_file = Path(kape_logs_dir) / "kape_operations.log"
    log_file.parent.mkdir(parents=True, exist_ok=True)
    
    timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
    operation_hash = hashlib.sha256(f"{timestamp}{command}".encode()).hexdigest()[:16]
    
    log_entry = f"""
{'='*80}
OPERATION ID: {operation_hash}
TIMESTAMP: {timestamp}
TYPE: {operation_type}
COMMAND: {command}
RETURN CODE: {return_code}
{'='*80}
OUTPUT:
{output}
{'='*80}
ERRORS:
{error}
{'='*80}
"""
    
    with open(log_file, 'a', encoding='utf-8') as f:
        f.write(log_entry)
```
