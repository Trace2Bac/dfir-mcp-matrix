# F05 발견사항·결론 근거 검증

### 비적용

**판단.** 서버에는 발견사항, 결론, 부재 주장을 받거나 저장하거나 보고하는 경로가 없다.
도구 31개 가운데 발견사항이나 주장을 인자로 받는 도구가 없고 보고 산출물을 쓰는 도구도 없다 [1][2].

서버가 스스로 만드는 판정은 응답 글이나 서버 로그에만 남는다.

- `analyze_macos_plist`는 지속성 수단 후보 표시를 응답 글에 싣고 저장하지 않는다 [3].
- `analyze_shimcache`가 센 의심 경로 수는 서버 로그의 진행 줄에만 적힌다 [4].
- 서버는 이 표시와 수를 다른 도구의 입력으로 다시 받거나 저장소에서 다시 읽지 않는다 [2].
