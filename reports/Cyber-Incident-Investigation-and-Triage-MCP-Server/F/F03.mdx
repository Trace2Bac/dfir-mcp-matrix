# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
의존성 목록은 MCP SDK, 설정·시스템 라이브러리, 증거 파서뿐이고 모델 API 클라이언트가 없다 [1].
서버는 저수준 `Server`에 `list_tools`와 `call_tool`만 등록하고 MCP sampling으로 클라이언트 모델에게 생성을 요청하지 않는다 [2].
stdio 서버의 `initialize` 응답이 알린 기능은 `tools`뿐이었다 [3].
SSE 진입점 `remote_server.py`도 같은 `create_server`로 만든 서버를 연다 [4].
지속성 수단 후보 표시 같은 판정 문구와 응답 글은 모두 서버 코드가 문자열로 조립한다 [5].

### 근거
