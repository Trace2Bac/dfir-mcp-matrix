# P03 조사 진척 판단

### 미구현

**판단.** 서버는 수행한 작업과 남은 작업을 대조하지 않고 완료 판단을 모델에 맡긴다.
서버가 모델에게 돌려주는 조사 기록은 명령 기록과 분석 메모 둘이다 [1][2].
`get_command_history`는 지금까지 실행한 명령마다 번호, 명령 문자열, 실행 시각, 종료 코드를 실행한 차례대로 돌려준다 [1][3].
이 목록은 서버가 컨테이너에서 실행한 명령과 심볼 도구의 내려받기·검색을 차례대로 적은 것이고 증거 항목별로 묶이지 않는다 [3][4].
`list_files`와 분석 메모 도구의 호출은 이 목록에 남지 않는다 [5].
서버에는 증거 유형마다 해야 할 작업을 정해 둔 목록이 없고 명령 기록을 그런 목록과 대조하는 코드도 없다 [6].

분석 메모는 모델이 `add_analyst_note`로 적는 발견사항 기록이다 [2].
메모의 `status`는 `benign`, `malicious`, `unknown` 가운데 하나이고 발견사항 하나의 판정을 나타낸다 [7].
메모에는 대상별로 마친 작업이나 다루지 않은 범위를 적는 필드가 없다 [7].

서버 지침은 분석을 시작하기 전에 실행한 명령과 분석 메모를 검토해 같은 명령과 분석을 되풀이하지 말라고 적는다 [8].
서버는 모델이 이 검토를 했는지 확인하지 않고 조사 단계나 완료 조건도 두지 않는다 [6][8].
등록한 도구 18개 가운데 진척이나 남은 범위를 돌려주는 도구는 없다 [6].
