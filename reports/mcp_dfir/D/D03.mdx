# D03 파생물 무결성 검증

### 미구현

**판단.** 서버는 남긴 파생물의 해시를 계산하지도 대조하지도 않는다.
`CommandHistoryManager.dump`는 명령 결과를 파일에 쓰기만 하고 목록 항목 `CommandRecordSummary`에는 번호, 명령, 시각, 종료 코드만 있다 [1][2].
`get_command`는 결과 본문 파일을 읽어 돌려줄 뿐 저장할 때와 내용이 같은지 확인하지 않는다 [3].
`AnalystNoteManager.dump`도 분석 메모의 목록 파일과 본문 파일을 쓰기만 한다 [4].
컨테이너 안 분석 도구가 `/artifacts`에 만든 파일의 해시나 크기를 서버가 남기는 곳은 없다 [5].
`list_files`는 `artifacts` 폴더의 파일마다 이름, 경로, 크기를 응답으로 돌려줄 뿐 그 값을 남기거나 앞 값과 대조하지 않는다 [6].

`get_hash`는 모델이 준 컨테이너 안 경로에 `md5sum`·`sha1sum`·`sha256sum`·`sha512sum` 가운데 하나를 실행하는 도구다 [7].
이 도구는 증거와 파생물을 가리지 않고 모델이 불러야 실행된다 [7].
사건 폴더의 `analysis`와 `artifacts`가 컨테이너에 연결되어 있어 `get_hash`에 `/analysis/command_history/1.txt`나 `/artifacts` 아래 경로를 주면 그 파일의 해시가 새 명령 결과로 저장된다 [8][9].
서버는 그 값을 기준값으로 따로 남기지 않고 나중에 대조하는 도구도 없다 [7].

    def exec_stream(self, ctx: Context, command_list: list[str]) -> CommandRecordSummary:
        if self.container is None:
            raise RuntimeError("No docker container is currently running")

        ctx.report_progress(f"Running command {' '.join(command_list)}")
        output = []
        exit_code = 0
        try:
            for stream, data in self.docker.execute(self.container, command_list, stream=True):
                if stream == "stdout":
                    output.append(data.decode())
        except DockerException as ex:
            exit_code = ex.return_code if ex.return_code is not None else 1
            output.append(str(ex))
        result = "".join(output)
        return command_history_manager.add_command(
            CommandRecord(
                command=" ".join(command_list),
                result=result,
                exit_code=exit_code,
            )
        )
```

def get_hash(
    ctx: Context, file_path: str, algorithm: Literal["md5", "sha1", "sha256", "sha512"]
) -> CommandRecordSummary:
    if algorithm.lower() not in HASHING_ALGORITHMS:
        raise KeyError(
            f'Unsupported hashing algorithm "{algorithm}", this function supports: {", ".join(HASHING_ALGORITHMS)}'
        )

    command_list = [f"{algorithm.lower()}sum", file_path]
    return docker_manager.exec_stream(ctx, command_list)
```
