# F06 보고 산출물 구성

### 미구현

**판단.** 서버는 사건 폴더 단위로 명령 기록과 분석 메모를 남기지만 보고 산출물을 만들거나 내보내는 도구가 없다.
서버는 `--case-dir`로 받은 사건 폴더 아래 `analysis`에 명령 기록 목록, 결과 본문 파일, 분석 메모를 둔다 [1].
등록한 도구 18개는 파일 찾기, 압축 풀기, 해시, 명령 기록 읽기, Volatility와 Sleuth Kit 실행, 심볼 내려받기, 분석 메모 읽기와 쓰기다 [2].
명령 기록과 분석 메모를 모아 증거 목록, 수행 범위, 발견사항과 근거, 한계를 담은 파일을 만드는 도구나 함수는 없다 [2].
사용자 CLI의 인자는 버전 출력, 사건 폴더 지정, 폴더 만들기, 사건 폴더 비우기, 컨테이너 지우기이고 보고서를 만드는 인자는 없다 [3].
서버 기록이나 서버 응답을 가공해 보고서를 만드는 클라이언트 코드나 훅도 저장소에 없다.

저장소 README는 예시 사건 폴더의 분석 메모 파일 하나를 예시 보고서로 가리킨다 [4].
이 파일은 사용자가 분석 메모에 보고서를 만들어 달라고 요청하자 클라이언트 모델이 `add_analyst_note`로 넘긴 `description`이다 [5].
서버는 이 글을 다른 분석 메모와 같은 경로로 받아 `description`을 `<title>.md`에 그대로 쓴다 [6].
그 글의 증거 해시, 실행한 명령의 표, 결론은 모두 모델이 쓴 것이고 서버가 명령 기록에서 채운 부분은 없다 [5][6].
`add_analyst_note`는 값을 돌려주지 않아 응답에 파일 경로가 실리지 않는다 [7].
