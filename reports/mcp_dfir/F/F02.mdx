# F02 발견사항·결론 도출

### 미구현

**판단.** 서버는 분석 도구의 출력을 저장하고 모델이 준 조건으로 골라 돌려줄 뿐 규칙으로 판정하거나 결과끼리 잇거나 점수를 매기지 않는다.
실행 도구는 모델이 준 인자를 붙인 명령을 컨테이너에서 실행하고 `exec_stream`은 표준 출력 조각을 이어 붙인 글을 명령 결과로 넘긴다 [1].
명령이 0이 아닌 코드로 끝나면 `exec_stream`은 그 글 뒤에 `DockerException`의 문구를 붙일 뿐 출력의 내용을 읽어 분류하지 않는다 [1].
`get_command_result`는 결과 본문을 `head`·`tail`·`head_bytes`·`tail_bytes`로 자르고 모델이 준 정규식 `regex`에 맞는 줄만 골라 돌려준다 [2].
`search_linux_symbols`는 모델이 준 정규식에 맞는 심볼 이름을 고른다 [3].
이 조건은 모두 호출 인자이고 서버 코드에 정해 둔 키워드, 값 목록, 가중치는 없다 [2][3].
`run_find`가 인자에 `-exec`가 들어 있으면 거부하는 것은 실행할 명령의 인자 검사이고 결과 항목을 분류하지 않는다 [4].
분석 메모의 `status`는 모델이 `benign`·`malicious`·`unknown` 가운데 골라 넘기는 값이다 [5].
서버는 이 값을 받은 그대로 목록에 넣고 명령 결과에서 계산하지 않는다 [6].
Volatility 플러그인과 Sleuth Kit 도구가 내는 판정은 그 도구의 출력에 들어 있고 서버는 그 출력을 고치지 않는다 [1].
서버는 처리 중에 모델을 부르지 않는다.
예시 사건 폴더의 분석 메모에 실린 판정과 본문은 클라이언트 모델이 `add_analyst_note`의 인자로 넘긴 값이다 [7].

    def exec_stream(self, ctx: Context, command_list: list[str]) -> CommandRecordSummary:
        if self.container is None:
            raise RuntimeError("No docker container is currently running")

        ctx.report_progress(f"Running command {' '.join(command_list)}")
        output = []
        exit_code = 0
        try:
            for stream, data in self.docker.execute(self.container, command_list, stream=True):
                if stream == "stdout":
                    output.append(data.decode())
        except DockerException as ex:
            exit_code = ex.return_code if ex.return_code is not None else 1
            output.append(str(ex))
        result = "".join(output)
        return command_history_manager.add_command(
            CommandRecord(
                command=" ".join(command_list),
                result=result,
                exit_code=exit_code,
            )
        )
```

def run_find(ctx: Context, arguments: list[str]) -> CommandRecordSummary:
    """Runs: find <arguments>"""
    if " ".join(arguments).find("-exec") != -1:
        raise RuntimeError("Cannot run exec in find")
    return docker_manager.exec_stream(ctx=ctx, command_list=["find", *arguments])
```
