# F05 발견사항·결론 근거 검증

### 미구현

**판단.** 서버는 분석 메모를 받아 저장하지만 그 근거가 있는지와 내용이 맞는지를 확인하지 않는다.
`add_analyst_note`는 받은 `AnalystNote`를 `AnalystNoteManager.add_note`에 넘기고 `add_note`는 요약을 목록에 넣은 뒤 파일에 쓴다 [1].
이 경로에서 메모에 적용되는 검사는 FastMCP가 인자를 `AnalystNote`의 필드 자료형과 대조하는 것 하나다 [2][3].
`AnalystNote`에는 근거가 된 명령 번호나 증거 경로를 담는 필드가 없어 서버가 대조할 근거 참조가 없다 [2].
본문 `description`에 명령 번호나 해시를 적어도 서버는 그 글을 명령 기록 목록이나 결과 본문 파일과 대조하지 않는다 [1].
명령을 하나도 실행하지 않은 사건 폴더에서 `status`가 `malicious`이고 `description`이 빈 메모를 더하자 오류 없이 저장되었다 [3].
`status`는 모델이 고른 값을 그대로 저장하고 서버가 근거의 수나 종류로 정하거나 바꾸지 않는다 [1].
`benign`으로 정리한 메모와 `unknown`으로 둔 메모도 같은 경로로 받고 그 판정에 필요한 조회를 했는지 대조하는 코드는 없다 [1].
메모를 고치는 `update_analyst_note`도 받은 메모를 근거 확인 없이 `AnalystNoteManager.update_note`에 넘긴다 [4].
이 도구는 있는 제목으로 부르면 오류로 끝나 저장한 메모를 고치지 못한다 [4][3].
서버 지침은 가정하지 말고 결론을 내릴 수 없으면 추가 조사가 필요하다고 표시하라고 적지만 서버는 이를 지켰는지 확인하지 않는다 [5].
메모를 검토해 확정하는 상태 값이나 도구는 없다 [6].
같은 저장소에는 서버에 붙는 클라이언트 코드나 검토 단계를 실행하는 코드가 없다.

```python
    def update_note(self, title: str, note: AnalystNote) -> AnalystNote:
        for index, note in enumerate(self.note_list):
            if note.title == title:
                self.note_list[index] = note.summary()
                self.dump(note)
                return note
        raise KeyError(f"No note with title '{title}'")
```
