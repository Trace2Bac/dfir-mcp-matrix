# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
패키지의 의존성은 `attrs`·`loguru`·`mcp`·`python_on_whales`·`requests`이고 모델 API 클라이언트는 없다 [1].
서버 코드가 `requests`로 요청을 보내는 주소는 Microsoft 심볼 서버와 GitHub의 Linux 심볼 저장소 두 곳이다 [2][3].
도구 함수가 FastMCP `Context`로 부르는 것은 `report_progress`뿐이고 MCP sampling으로 클라이언트 모델에게 생성을 요청하는 호출은 없다 [4].
분석 도구를 실행하는 컨테이너는 네트워크 `none`으로 만든다 [5].
그래서 서버가 모델에게 넘길 입력을 구성하는 경로가 없다.
예시 사건 폴더의 조사는 MCP 클라이언트인 Claude Code에서 했고 모델은 클라이언트 쪽에 있다 [6].
