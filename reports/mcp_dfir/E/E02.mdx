# E02 증거 무결성 검증

### E02.02 도구를 요청해 기준값 계산

**구현.** 이 방식은 `get_hash`에 적용된다 [1].
`get_hash`는 모델이 부를 때만 컨테이너에서 `md5sum`, `sha1sum`, `sha256sum`, `sha512sum` 가운데 `algorithm`에 맞는 명령을 `file_path`에 실행한다 [1].
해시 범위는 받은 파일 하나의 내용 전체다 [1].
`file_path`는 컨테이너 안 경로이고 서버는 그 경로가 `/evidence` 아래인지 확인하지 않는다 [1].
응답은 명령 번호, 명령 문자열, 실행 시각, 종료 코드이고 해시 값은 응답에 실리지 않는다 [2][3].
해시 명령의 출력은 사건 폴더의 결과 본문 파일 `analysis/command_history/<번호>.txt`에 남고 모델은 `get_command_result`로 읽는다 [2][3].
명령 문자열과 종료 코드는 명령 기록 목록 `analysis/command_history.json`에 남는다 [2].
서버는 이 값을 증거의 기준값으로 따로 보관하지 않고 어느 도구도 이 값을 다시 읽어 지금 증거와 대조하지 않는다 [4].
같은 파일에 `get_hash`를 다시 부르면 새 번호의 명령 기록이 하나 더 생기고 서버는 앞 명령 기록의 값과 비교하지 않는다 [3].
서버가 시작할 때나 증거를 처음 읽을 때 스스로 해시하는 경로는 없다 [5].
서버 지침은 증거 목록을 만들라고 적고 해시를 계산하라고는 적지 않는다 [6].
저장소 예시 사건의 명령 기록은 첫 항목이 증거 파일의 `sha256sum`이다 [7].

**한계.** 해시 명령이 실패해도 `get_hash`는 오류 응답이 아니라 `exit_code`가 1인 정상 응답을 돌려준다 [2][8].
없는 파일을 주자 `isError`가 거짓인 응답이 돌아왔고 결과 본문 파일에는 해시 대신 Docker 실행 오류 문구가 남았다 [8].
서버가 다른 사건 폴더에 연결된 같은 이름의 컨테이너를 다시 쓰면 `get_hash`는 그 컨테이너에 연결된 폴더의 파일을 해시한다 [9][10].
이름이 같은 다른 사건 폴더로 서버를 실행해 같은 이름의 파일을 해시하자 앞 사건 폴더에 있는 파일의 해시가 이 사건 폴더의 명령 기록에 남았다 [10].

### 근거

[1] `get_hash`는 알고리즘 이름으로 해시 명령을 정해 받은 경로에 실행한다.

```python
def get_hash(
    ctx: Context, file_path: str, algorithm: Literal["md5", "sha1", "sha256", "sha512"]
) -> CommandRecordSummary:
    if algorithm.lower() not in HASHING_ALGORITHMS:
        raise KeyError(
            f'Unsupported hashing algorithm "{algorithm}", this function supports: {", ".join(HASHING_ALGORITHMS)}'
        )

    command_list = [f"{algorithm.lower()}sum", file_path]
    return docker_manager.exec_stream(ctx, command_list)
```

[2] `exec_stream`은 표준 출력과 종료 코드를 명령 기록에 넣고 요약만 돌려준다.

```python
    def exec_stream(self, ctx: Context, command_list: list[str]) -> CommandRecordSummary:
        if self.container is None:
            raise RuntimeError("No docker container is currently running")

        ctx.report_progress(f"Running command {' '.join(command_list)}")
        output = []
        exit_code = 0
        try:
            for stream, data in self.docker.execute(self.container, command_list, stream=True):
                if stream == "stdout":
                    output.append(data.decode())
        except DockerException as ex:
            exit_code = ex.return_code if ex.return_code is not None else 1
            output.append(str(ex))
        result = "".join(output)
        return command_history_manager.add_command(
            CommandRecord(
                command=" ".join(command_list),
                result=result,
                exit_code=exit_code,
            )
        )
```

[3] (실행 확인) `get_hash`에 `/evidence/notes.txt`와 `sha256`을 주면 `number`, `command`, `date_run`, `exit_code`만 담긴 응답이 돌아온다.
`get_command_result`로 그 번호를 읽으면 호스트에서 계산한 그 파일의 SHA-256과 같은 값이 `sha256sum` 출력 형식으로 돌아온다.

[4] 명령 결과를 다시 읽는 곳은 `get_command_result`가 부르는 `get_command`뿐이다.

```python
    def get_command(self, command_number: int) -> CommandRecord:
        for command in self.command_summary_list:
            if command.number == command_number:
                with open(file=config.command_record_directory / f"{command_number}.txt", encoding="utf-8") as file:
                    return CommandRecord(
                        command=command.command,
                        date_run=command.date_run,
                        result=file.read(),
                        exit_code=command.exit_code,
                    )
        raise KeyError(f"Could not find command with number {command_number}")
```
