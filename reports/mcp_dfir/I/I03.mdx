# I03 외부 전송 범위 구성

### I03.02 메타데이터·추출 값 전송

**구현.** 이 방식은 `download_windows_symbol`과 `download_linux_symbol`이 보내는 요청에 적용된다 [1][2].
`download_windows_symbol`은 PDB 이름, GUID, age를 Microsoft 심볼 서버 주소의 경로에 넣어 GET 요청을 보낸다 [1].
세 값은 모델이 인자로 준다 [1].
저장소의 예시 사건에서는 심볼이 없어 실패한 `windows.info`의 출력에 Volatility 3가 메모리 이미지를 훑어 찾은 커널의 PDB 이름과 GUID·age가 실렸다 [3].
모델은 그 값을 `download_windows_symbol`의 인자로 넘겼다 [4].
`download_linux_symbol`은 심볼 저장소 안의 파일 경로 `symbol_path`를 GitHub 주소의 경로에 넣어 GET 요청을 보낸다 [2].
심볼 맵에 있는 경로에는 배포판 이름과 커널 버전이 들어 있다 [5].
`search_linux_symbols`는 심볼 맵 전체를 받아 정규식을 서버 프로세스 안에서 대조하므로 정규식은 요청에 실리지 않는다 [6].
세 요청은 모두 본문이 없는 GET이고 서버 코드에는 증거 파일이나 그 내용을 올리는 곳이 없다 [1][2][6].
서버는 요청에 헤더를 더하지 않는다 [1][2].
보낼 값의 종류는 도구가 정하고 값은 모델이 준다 [1][2].
보내기 전에 값을 고르거나 가리는 처리는 없다 [1][2].

Docker 데몬에는 Docker CLI가 컨테이너 이름, 이미지 이름, 컨테이너에 연결할 호스트 쪽 폴더 경로, 실행할 명령 줄을 보낸다 [7][8].
명령 줄에는 모델이 준 증거 경로와 검색 문자열이 그대로 들어 있다 [8].
증거는 데몬이 컨테이너에 연결한 `evidence` 폴더에서 컨테이너가 읽고 서버 코드가 데몬으로 올리지 않는다 [7].
Docker 데몬이 서버와 다른 호스트에 있는 구성은 실행으로 확인하지 않았다.

**한계.** 서버는 `pdb_name`·`guid`·`symbol_path`의 형식을 검사하지 않으므로 모델이 준 문자열이 무엇이든 요청 경로에 들어간다 [1][2].
`pdb_name`을 `nosuchfile.pdb`로, `guid`를 0 32개로 주자 그 값을 넣은 주소로 요청이 나갔고 오류 문구에 그 주소가 실렸다 [9].

def _download_windows_pdb(ctx: Context, pdb_name: str, guid: str, age: int) -> tuple[str, CommandRecordSummary]:
    """Downloads a pdb file and returns the internal path"""
    guid = guid.replace("-", "")  # Normalize path
    url = f"{WINDOWS_SYMBOL_SERVER}/{pdb_name}/{guid}{age}/{pdb_name}"
    ctx.report_progress(f"Pulling symbol from {url}")
    output_file_name = f"{guid}_{pdb_name}"
    external_path = config.windows_symbols_directory / "raw" / output_file_name
    external_path.parent.mkdir(mode=500, parents=True, exist_ok=True)
    internal_path = f"/symbols/windows/raw/{output_file_name}"

    response = requests.get(url)

    if response.status_code == HTTPStatus.NOT_FOUND:
        raise RuntimeError(
            f"PDB not found on symbol server. Check that pdb_name and guid are correct.\nURL attempted: {url}"
        )

    response.raise_for_status()
    external_path.write_bytes(response.content)
```

def download_linux_symbol(ctx: Context, symbol_path: str) -> CommandRecordSummary:
    """Download a symbol map from the Abyss-W4tcher/volatility3-symbols repository"""

    # Download json file from repo
    url = f"{LINUX_SYMBOL_REPO_BASE_URL}/{symbol_path}"

    response.raise_for_status()

    # Save json file
    config.linux_symbols_directory.mkdir(mode=500, parents=True, exist_ok=True)
    file_name = symbol_path.rsplit("/", maxsplit=1)[-1]
    file_path = config.linux_symbols_directory / file_name
    file_path.write_bytes(response.content)
```

[6] `search_linux_symbols`는 인자 없는 주소에서 목록을 받고 정규식은 받은 목록에 `re.search`로 대조한다.

```python
def search_linux_symbols(ctx: Context, regex: str) -> CommandRecordSummary:
    """Load linux symbol map from Abyss-W4tcher/volatility3-symbols and search for symbols matching the regex"""

    # Download symbol map if it doesn't exist
    if not config.linux_symbol_map_json.exists():
        ctx.report_progress("Downloading linux symbol map from github.com/Abyss-W4tcher/volatility3-symbols")
        response = requests.get(url=LINUX_SYMBOL_MAP_SOURCE)
        response.raise_for_status()
        config.linux_symbols_directory.mkdir(mode=500, parents=True, exist_ok=True)
        config.linux_symbol_map_json.write_bytes(response.content)

    # Parse the symbol map
    with open(config.linux_symbol_map_json, encoding="utf-8") as symbol_map_file:
        symbol_map: dict = json.load(symbol_map_file)

    # Return the a list of matches
    out_list = []
    for symbol_name, file_path_list in symbol_map.items():
        if re.search(regex, symbol_name):
            out_list.append(SymbolSearchResult(symbol_name=symbol_name, file_path_list=file_path_list))
```

        if self.container is None:
            raise RuntimeError("No docker container is currently running")

        ctx.report_progress(f"Running command {' '.join(command_list)}")
        output = []
        exit_code = 0
