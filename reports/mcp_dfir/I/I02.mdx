# I02 분석 도구 통신 차단

### I02.03 네트워크 차단

**구현.** 이 방식은 서버가 컨테이너에서 실행하는 분석 도구 전부에 적용된다 [1].
서버는 컨테이너를 만들 때 `networks=["none"]`을 넘긴다 [1].
Volatility 3, The Sleuth Kit 도구, `strings`·`grep`·`find`·`tar`·해시 명령은 모두 `exec_stream`이 이 컨테이너 안에서 실행한다 [2].
서버가 만든 컨테이너의 `NetworkMode`는 `none`이었고 컨테이너 안의 네트워크 장치는 `lo`뿐이었다 [3].
컨테이너 안에서 `raw.githubusercontent.com`에 보낸 HTTPS 요청은 이름 풀이에서 실패했고 IP 주소로 직접 연 연결은 `Network is unreachable`로 실패했다 [3].
서버는 Volatility 3 명령에 `--offline`을 붙이지 않는다 [4].
이미지 안의 Volatility 3는 `OFFLINE` 기본값이 거짓이어서 Windows 커널 심볼이 없으면 Microsoft 심볼 서버에서 PDB를 받으려 한다 [5].
저장소의 예시 사건 폴더에는 `windows.info`가 `http://msdl.microsoft.com/download/symbols/…`를 받으려다 `Symbol file could not be downloaded from remote server` 경고를 남기고 종료 코드 1로 끝난 명령 기록이 있다 [6].
심볼은 컨테이너 밖의 서버 프로세스가 심볼 도구로 받아 `/symbols`에 연결되는 폴더에 둔다 [7].
`Dockerfile`에는 네트워크 설정이 없고 네트워크를 끊는 것은 서버 코드가 컨테이너를 만들 때 넘기는 인자다 [1][8].

서버 프로세스가 불러 쓰는 라이브러리는 `attrs`, `loguru`, `mcp`, `python_on_whales`, `requests`다 [9].
서버 프로세스에는 이 라이브러리들의 통신을 끊거나 끄는 설정이 없다.
`requests`는 심볼 도구가 요청을 보낼 때만 불린다 [7].
python-on-whales 0.81.0은 `PATH`에서 `docker` 실행 파일을 찾아 실행하고 찾지 못하면 예외를 낸다 [10].
이 라이브러리들이 그 밖에 스스로 통신하는지는 소스 전체로 확인하지 않았다.

**한계.** 서버는 같은 이름의 컨테이너가 이미 있으면 네트워크 설정을 확인하지 않고 그 컨테이너를 쓴다 [11].
컨테이너 이름은 사건 폴더 이름에 `-forensics`를 붙인 값이다 [12].
그 이름의 컨테이너를 기본 네트워크로 미리 실행해 두자 서버가 그 컨테이너에서 명령을 실행했다 [13].
그 컨테이너 안에서 `raw.githubusercontent.com`에 보낸 HTTPS 요청은 200으로 돌아왔다 [13].

```python
    def exec_stream(self, ctx: Context, command_list: list[str]) -> CommandRecordSummary:
        if self.container is None:
            raise RuntimeError("No docker container is currently running")

        ctx.report_progress(f"Running command {' '.join(command_list)}")
        output = []
        exit_code = 0
        try:
            for stream, data in self.docker.execute(self.container, command_list, stream=True):
                if stream == "stdout":
                    output.append(data.decode())
```

[3] (실행 확인) 서버가 만든 컨테이너를 `docker inspect`로 보자 `HostConfig.NetworkMode`가 `none`이었다.
서버가 실행 중일 때 `docker exec`로 그 컨테이너에서 `ls /sys/class/net`을 실행하자 `lo`만 나왔다.
같은 컨테이너에서 `python3`의 `urllib.request.urlopen`으로 `https://raw.githubusercontent.com/…/README.md`를 열자 `Temporary failure in name resolution`으로 끝났다.
`socket.create_connection`으로 IP 주소의 443번 포트에 연결하자 `[Errno 101] Network is unreachable`로 끝났다.
