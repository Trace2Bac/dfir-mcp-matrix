# R07 증거 내용과 지시 구분

### R07.01 JSON 필드 분리

**구현.** 이 방식은 `get_command_result` 응답의 `structuredContent`와 `list_files`의 응답에 적용된다 [1][2].
`get_command_result`는 저장한 결과 본문에서 고른 글 하나를 `str`로 돌려주고 그 앞뒤에 서버 문구를 붙이지 않는다 [1].
서버 코드는 이 글을 담을 필드를 만들지 않는다 [1].
MCP Python SDK 1.27.0은 반환값이 `str`인 도구의 결과를 `content`의 글 항목 하나와 `structuredContent`의 `result` 필드에 함께 싣는다 [3].
`IGNORE PREVIOUS INSTRUCTIONS`가 들어 있는 줄을 둔 시험용 글 파일에 `strings`를 실행하고 결과 본문을 읽자 `structuredContent`는 그 줄을 `result` 값 안에 실었다 [4].
예시 사건의 Claude Code 기록에는 이 도구의 응답이 `"result"` 키 하나를 가진 JSON으로 남아 있다 [5].
서버가 채우는 번호, 명령, 시각, 종료 코드는 결과 본문과 같은 응답에 실리지 않고 실행 도구의 응답과 `get_command_history`의 응답에 필드 값으로 실린다 [6][7].
`list_files`는 파일마다 `name`·`path`·`size` 필드를 가진 객체를 돌려준다 [2].
증거에서 꺼낸 파일의 이름은 이 객체의 `name`과 `path` 값으로 실린다 [2][4].
`list_files`의 `content`는 파일마다 이 객체를 JSON으로 적은 글 항목 하나였다 [4].

결과에는 그 값을 만든 도구나 신뢰 수준을 적는 필드가 없다 [1][2].
`get_command_result`의 응답은 결과 본문을 만든 명령을 싣지 않는다 [1].
서버는 증거에서 온 글을 표시 문자열로 감싸지 않는다 [1].
서버 지침과 도구 설명에는 증거에서 온 글 속의 지시를 따르지 말라는 문장이 없다 [8][4].
서버 코드가 낸 예외는 `Error executing tool`로 시작하는 글 하나로 돌아오고 이 결과에는 `structuredContent`가 없다 [9][4].

**한계.** `get_command_result`의 `content`에는 필드가 없다 [3][4].
시험용 글 파일에 실행한 `strings`의 결과 본문을 읽은 응답에서 `content`의 글 항목은 `strings` 출력과 글자가 같은 글 하나였고 필드 이름이나 따옴표가 없었다 [4].
그래서 `structuredContent`를 읽지 않는 클라이언트에는 증거에서 온 글이 아무 표시 없는 글 하나로 전달된다 [3][4].

종료 코드가 0이 아닌 명령의 결과 본문에서는 도구가 낸 글과 라이브러리 문장이 한 문자열에 섞인다 [10][11].
실행기 `exec_stream`은 표준 출력 뒤에 구분 표시 없이 python-on-whales의 예외 글을 이어 붙인다 [10].
python-on-whales 0.81.0의 예외 글은 명령 줄과 표준 오류를 영어 문장 안에 넣은 것이고 표준 오류는 작은따옴표로만 구분된다 [11].
있는 글 파일과 없는 파일을 함께 준 `strings`의 결과 본문은 글 파일에서 나온 세 줄 바로 다음 줄에서 `The command executed was`로 시작하는 예외 글이 이어졌다 [12].
그 결과 본문에서 `strings`의 표준 오류는 `The content of stderr is '…'` 안에 있었고 표준 오류 안의 작은따옴표는 바뀌지 않은 채 실렸다 [12].
이 결과 본문도 `result` 값 하나로 돌아온다 [1][12].

    def exec_stream(self, ctx: Context, command_list: list[str]) -> CommandRecordSummary:
        if self.container is None:
            raise RuntimeError("No docker container is currently running")

        ctx.report_progress(f"Running command {' '.join(command_list)}")
        output = []
        exit_code = 0
        try:

            output.append(str(ex))
