# D03 파생물 무결성 검증

### 비적용

**판단.** 서버는 성공한 호출이 끝난 뒤에 남기는 파생물이 없다.
실시간 캡처 도구 4개가 쓰게 하는 `temp_capture.pcap`은 응답을 돌려주기 전에 지운다 [1].
`analyze_pcap`과 `extract_credentials`는 받은 pcap을 읽기만 하고 파일을 쓰지 않는다 [2].
`check_ip_threats`를 뺀 도구 6개를 부른 뒤 서버의 현재 폴더와 `/tmp`에 새 파일이 없었다 [3].
서버가 불러오는 모듈에는 해시를 계산하는 모듈이 없고 서버 코드는 캡처 파일이나 응답의 해시를 계산하지 않는다 [4].
`extract_credentials`가 응답에 싣는 `Hash=` 값은 캡처 안의 Kerberos 필드를 이어 붙인 문자열이고 서버가 계산한 기준값이 아니다 [5].
