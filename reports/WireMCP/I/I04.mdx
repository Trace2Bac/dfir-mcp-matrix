# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버 코드가 여는 외부 연결은 `check_threats`와 `check_ip_threats`가 URLhaus 목록을 받는 GET 요청뿐이다 [1][2].
두 처리기는 `axios.get`에 주소만 넘기고 `auth` 설정이나 인증 헤더를 주지 않는다 [1].
요청 주소에도 사용자 이름이나 비밀번호가 들어 있지 않다 [1].
로컬 수신 프로그램이 받은 요청에는 `Authorization` 헤더가 없었다 [3].
서버 코드는 환경변수를 tshark에 넘길 `env`를 만드는 데만 쓰고 설정 파일을 읽지 않는다 [2].
`extract_credentials`가 응답에 싣는 사용자 이름, 비밀번호, Kerberos 해시 문자열은 pcap 파일에서 꺼낸 값이고 서버가 외부 접속에 쓰는 자격증명이 아니다 [4].
axios 1.10.0은 환경변수에서 찾은 프록시 주소에 사용자 이름과 비밀번호가 있으면 이를 `Proxy-Authorization` 헤더로 프록시에 보낸다 [5].
서버 코드는 이 값을 읽거나 넘기지 않는다 [1][2].
