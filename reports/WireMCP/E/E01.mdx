# E01 증거 등록 관리

### 미구현

**판단.** 서버는 증거를 등록하는 도구를 두지 않고 증거를 식별하는 목록이나 등록 정보를 남기지 않는다.
`analyze_pcap`과 `extract_credentials`는 pcap 파일 경로 `pcapPath`를 호출마다 인자로 받아 그 호출에서만 읽는다 [1][2].
두 도구는 `fs.access`로 그 경로가 있는지만 확인하고 경로를 `tshark -r`에 넘긴다 [1][2].
두 도구의 응답 첫 줄 `Analyzed PCAP: <경로>`는 모델이 준 경로를 그대로 옮긴 것이고 파일의 크기, 시각, 해시는 응답에 없다 [3].
서버 코드에서 `fs`를 쓰는 곳은 경로 확인 `fs.access`와 임시 파일 삭제 `fs.unlink`뿐이고 받은 경로를 호출 밖의 변수나 파일에 남기는 처리는 없다 [4].
표준 오류에는 `Analyzing PCAP file: <경로>` 같은 줄이 출력된다 [5].
이 줄은 서버 운영 로그에 경로 인자가 남는 것이고 증거를 식별하는 목록이 아니다.
같은 파일을 다시 넘기면 서버는 `tshark`를 다시 실행해 새 응답을 만들고 앞선 호출을 가리키는 값을 싣지 않는다 [1][2].

서버가 시작하는 수집도 서버 쪽 목록에 오르지 않는다.
`capture_packets`, `get_summary_stats`, `get_conversations`, `check_threats`는 서버를 실행한 호스트의 네트워크 인터페이스에서 `duration`초 동안 잡은 트래픽을 서버 작업 폴더의 `temp_capture.pcap`에 쓴다 [6].
네 도구는 이 파일을 `tshark -r`로 다시 읽은 뒤 `fs.unlink`로 지운다 [6].
응답에는 캡처 결과만 실리고 캡처한 인터페이스 이름과 캡처 파일 이름은 실리지 않는다 [6].
`capture_packets`를 루프백 인터페이스 `lo`로 1초 부르자 응답은 `Captured packet data (JSON for LLM analysis):` 아래 빈 목록이었고 호출 뒤 작업 폴더에 `temp_capture.pcap`이 남지 않았다 [7].

```javascript
    {
      pcapPath: z.string().describe('Path to the PCAP file to analyze (e.g., ./demo.pcap)'),
    },
    async (args) => {
      try {
        const tsharkPath = await findTshark();
        const { pcapPath } = args;
        console.error(`Extracting credentials from PCAP file: ${pcapPath}`);
  
        await fs.access(pcapPath);
  
        // Extract plaintext credentials
        const { stdout: plaintextOut } = await execAsync(
          `${tsharkPath} -r "${pcapPath}" -T fields -e http.authbasic -e ftp.request.command -e ftp.request.arg -e telnet.data -e frame.number`,
          { env: { ...process.env, PATH: `${process.env.PATH}:/usr/bin:/usr/local/bin:/opt/homebrew/bin` } }
        );

        // Extract Kerberos credentials
        const { stdout: kerberosOut } = await execAsync(
          `${tsharkPath} -r "${pcapPath}" -T fields -e kerberos.CNameString -e kerberos.realm -e kerberos.cipher -e kerberos.type -e kerberos.msg_type -e frame.number`,
          { env: { ...process.env, PATH: `${process.env.PATH}:/usr/bin:/usr/local/bin:/opt/homebrew/bin` } }
        );
```
