# T09 대상 시스템 대응 조치 처리

### 비적용

**판단.** 서버는 조사하는 대상 시스템의 상태를 바꾸는 도구를 두지 않는다.
실시간 캡처 도구 4개가 읽는 곳은 서버를 실행한 호스트의 네트워크 인터페이스이고 서버는 그 패킷을 `tshark -i <interface> -w temp_capture.pcap`으로 파일에 받는다 [1].
서버가 캡처에 주는 인자는 인터페이스, 출력 파일, 자동 정지 시간뿐이고 패킷을 보내거나 연결을 끊는 인자는 없다 [1].
캡처하는 동안 인터페이스를 promiscuous 모드로 여는 것은 Wireshark 4.0.17 캡처 설정의 기본값이고 서버는 이 값을 바꾸는 `-p` 인자를 주지 않는다 [1][2].
`analyze_pcap`과 `extract_credentials`는 받은 pcap 파일을 `tshark -r`로 읽기만 한다 [3].
`temp_capture.pcap`은 서버 자신의 작업 파일이고 읽은 뒤 `fs.unlink`로 지운다 [4].
`check_threats`와 `check_ip_threats`가 하는 외부 통신은 URLhaus 목록을 받는 HTTP GET 요청뿐이다 [5].
그래서 조치 전후 상태, 변경 내역, 되돌림을 남길 대상 시스템 조치가 없다.
