# T06 실행 환경정보 표시

### 미구현

**판단.** 서버는 `tshark`와 URLhaus 목록으로 결과를 내지만 응답 어디에도 그 버전을 싣지 않는다 [1][2][3].
도구 7개의 응답은 `content`에 글 블록 하나만 싣고 그 글은 머리 문구, 결과 목록, `tshark` 출력으로만 이루어진다 [1][4][5][2].
`capture_packets`와 `analyze_pcap`의 JSON에는 `tshark`가 패킷마다 붙인 `_index`, `_type`, `_score`와 고른 필드 값만 있다 [3].
`check_threats`와 `check_ip_threats`의 응답은 URLhaus 목록을 언제 받았는지나 목록의 식별값을 싣지 않는다 [5].
`findTshark`가 찾은 실행 파일 경로는 서버의 표준 오류에만 쓰이고 응답에는 실리지 않는다 [6].
버전을 알려 주는 별도 도구나 리소스도 없다 [7].

서버 자신의 버전도 싣지 않는다.
서버는 `McpServer`에 이름 `wiremcp`와 버전 `1.0.0`을 주고 이 값은 초기화 응답의 `serverInfo`에만 실린다 [8][9].
서버는 호출 기록 파일을 남기지 않고 실시간 캡처 도구의 임시 파일 `temp_capture.pcap` 말고는 파일을 쓰지 않는다 [7].
서버는 모델을 부르지 않는다 [7].
