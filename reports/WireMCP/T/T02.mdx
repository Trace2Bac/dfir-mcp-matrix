# T02 실행 허용 범위 제한

### T02.04 고정 명령·템플릿

**구현.** 이 방식은 `tshark`를 실행하는 도구 6개에 적용된다 [1][2][3][4].
도구마다 `tshark`의 옵션과 출력 필드를 코드에 적은 명령 문자열을 두고 모델이 준 값만 그 안에 끼워 넣는다 [1][2][3][4].
실시간 캡처 도구 4개는 `-i <interface> -w temp_capture.pcap -a duration:<duration>`으로 캡처한 뒤 도구마다 정해 둔 읽기 명령을 실행한다 [1][2].
읽기 명령은 `capture_packets`가 `-T json`과 `-e` 필드 9개, `get_summary_stats`가 `-qz io,phs`, `get_conversations`가 `-qz conv,tcp`, `check_threats`가 `-T fields -e ip.src -e ip.dst`다 [1][2].
`analyze_pcap`은 `-T json`과 `-e` 필드 10개, `extract_credentials`는 평문 자격증명 필드 5개와 Kerberos 필드 6개를 읽는 `-T fields` 명령 두 개를 실행한다 [3][4].
모델이 고르는 값은 `interface`, `duration`, `pcapPath`뿐이고 표시 필터, 출력 필드, 통계 종류, 실행 파일은 고를 수 없다 [1][3][5].
`check_ip_threats`는 외부 프로그램을 실행하지 않는다 [6].

`tshark` 위치를 찾는 `findTshark`는 `PATH`에서 찾지 못하면 코드에 적은 경로 목록의 실행 파일을 `-v`로 실행해 본다 [7].
이 목록은 모델이 바꿀 수 없다 [7].

**한계.** 서버는 모델이 준 값을 따옴표 처리나 문자 검사 없이 명령 문자열에 넣고 Node.js의 `exec`로 실행한다 [1][3][8].
`interface`와 `duration`은 따옴표 없이, `pcapPath`는 큰따옴표 안에 들어간다 [1][3].
Node.js 22.17.0의 `exec`는 명령 문자열을 POSIX에서 `/bin/sh -c`에, Windows에서 `cmd.exe`에 넘긴다 [9].
그래서 `interface`에 공백을 넣으면 뒤의 글자가 `tshark`의 다른 옵션으로 읽히고 셸 메타 문자를 넣으면 셸이 해석한다 [1][9].
`duration`은 zod `number` 검사를 거치므로 숫자만 들어간다 [5].
셸 메타 문자를 넣은 `interface` 값과 그런 문자가 들어간 이름의 `pcapPath`로 도구를 부르자 두 경우 모두 셸이 그 문자를 해석해 `tshark`가 아닌 명령이 실행되었다 [10].

[7] `findTshark`는 `which`로 찾지 못하면 코드에 적은 경로를 차례로 시험한다.

```javascript
async function findTshark() {
  try {
    const tsharkPath = await which('tshark');
    console.error(`Found tshark at: ${tsharkPath}`);
    return tsharkPath;
  } catch (err) {
    console.error('which failed to find tshark:', err.message);
    const fallbacks = process.platform === 'win32'
      ? ['C:\\Program Files\\Wireshark\\tshark.exe', 'C:\\Program Files (x86)\\Wireshark\\tshark.exe']
      : ['/usr/bin/tshark', '/usr/local/bin/tshark', '/opt/homebrew/bin/tshark', '/Applications/Wireshark.app/Contents/MacOS/tshark'];
    
    for (const path of fallbacks) {
      try {
        await execAsync(`${path} -v`);
        console.error(`Found tshark at fallback: ${path}`);
        return path;
      } catch (e) {
        console.error(`Fallback ${path} failed: ${e.message}`);
      }
    }
    throw new Error('tshark not found. Please install Wireshark (https://www.wireshark.org/download.html) and ensure tshark is in your PATH.');
  }
}
```
