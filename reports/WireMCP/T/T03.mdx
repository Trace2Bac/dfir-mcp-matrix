# T03 실행 조건 확인

### 미구현

**판단.** 서버에는 도구 인자 밖의 조건으로 호출을 막거나 미루는 코드가 없다.
도구 처리기 7개는 받은 인자로 바로 `tshark`를 찾아 실행하거나 URLhaus 목록을 내려받는다 [1].
서버는 앞선 호출의 결과나 작업 상태를 남기지 않고 승인이나 호출자를 확인하는 코드도 없다 [1].
서버는 `StdioServerTransport` 하나로만 연결을 받는다 [2].
실행 전에 메모리나 디스크 같은 자원 상태를 확인하는 코드도 없다 [1].
캡처 시간 `duration`에는 상한이 없고 `tshark` 실행에는 시간 제한이 없다 [3][4].
프롬프트 7개는 분석할 내용을 적지만 호출 순서나 승인을 적지 않는다 [5].

동시 실행 수를 정하는 장치도 없다.
MCP TypeScript SDK 1.15.0은 요청마다 처리기를 Promise로 시작하고 앞 요청이 끝나기를 기다리지 않는다 [6].
도구 처리기는 `exec`의 결과를 `await`하는 비동기 함수라서 여러 호출이 함께 진행된다 [1].
URLhaus 내려받기에도 요청 사이 간격이나 횟수 제한이 없고 `check_threats`와 `check_ip_threats`는 호출마다 목록 전체를 내려받는다 [7].

실시간 캡처 도구 4개는 모두 서버 작업 폴더의 같은 이름 `temp_capture.pcap`에 캡처를 쓰고 읽은 뒤 지운다 [3].
캡처 시간 3초와 1초인 `capture_packets` 두 호출을 겹쳐 보내자 두 호출 모두 `tshark`가 파일이 중간에 끊겼다는 오류를 내 오류 응답으로 끝났다 [8].
