# F06 보고 산출물 구성

### 비적용

**판단.** 서버에는 사건 단위가 없고 보고 산출물을 만들거나 내보내는 도구도 없다.
도구 7개의 인자에는 사건이나 조사 세션을 가리키는 식별자가 없고 서버도 그런 식별자를 만들지 않는다 [1].
서버는 호출 사이에 판정이나 출력을 모아 두지 않는다 [2].
서버가 만드는 파일은 실시간 캡처 도구 4개가 tshark로 쓰는 캡처 파일 `temp_capture.pcap`뿐이다 [3].
이 파일은 잡은 패킷을 담고 조사의 범위, 방법, 결과, 한계, 판단의 확정 상태를 싣지 않는다 [3].

MCP 프롬프트 7개는 모델에게 살펴볼 항목과 보안 권고를 적고 보고서 파일을 쓰라고 하지는 않는다 [4].
README는 모델이 서버 출력으로 사람이 읽을 보고서를 만들 수 있다고 적는다 [5].
이 보고서는 클라이언트 모델이 직접 쓰는 글이다.
저장소의 파일은 `index.js`, `package.json`, `README.md`, `Wire-MCP.png`, `LICENSE`, `.gitignore`뿐이다 [6].
같은 저장소에는 서버 응답을 정해진 코드로 가공해 보고 산출물을 만드는 사용자 CLI나 클라이언트 코드가 없다 [6].
