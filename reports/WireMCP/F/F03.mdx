# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
`package.json`의 의존성은 MCP TypeScript SDK, HTTP 클라이언트 `axios`, 실행 파일을 찾는 `which`, 인자 schema용 `zod`, 이름이 같은 npm 패키지 `child_process`·`util`이고 모델 API 클라이언트는 없다 [1].
`axios`는 `check_threats`와 `check_ip_threats`가 URLhaus 목록을 내려받을 때만 쓴다 [2].
`index.js`에는 MCP sampling으로 클라이언트 모델에게 생성을 요청하는 `createMessage` 호출이 없다 [3].
MCP SDK 클라이언트로 서버를 실행하자 `initialize` 응답의 기능은 `completions`, `prompts`, `tools`였다 [4].
도구 응답의 글은 모두 서버 코드가 tshark 출력과 문자열 조립으로 만든다 [3].
