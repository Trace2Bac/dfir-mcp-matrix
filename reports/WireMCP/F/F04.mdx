# F04 발견사항·결론 기록 관리

### 비적용

**판단.** 서버에는 발견사항, 결론, 가설, 단서 메모를 받아 남기는 도구가 없다.
도구 7개의 입력 인자는 네트워크 인터페이스 `interface`, 캡처 시간 `duration`, 대조할 주소 `ip`, pcap 경로 `pcapPath`뿐이다 [1].
발견사항이나 메모를 받는 인자는 없다 [1].
서버가 만드는 파일은 실시간 캡처 도구 4개가 tshark로 작업 폴더에 쓰는 캡처 파일 `temp_capture.pcap`뿐이다 [2].

`check_threats`·`check_ip_threats`의 위협 판정과 `extract_credentials`의 자격증명 목록은 응답으로만 돌려주고 서버에 남기지 않는다 [3].
서버는 호출 사이에 판정이나 출력을 담아 두는 변수나 저장소를 두지 않는다 [4].
