# F01 판단 지침

### 미구현

**판단.** 서버는 도구 설명, 서버 지침, 리소스, 프롬프트, 응답 어디에도 조사 전체의 해석 원칙이나 발견사항·결론을 서술하고 확인하는 방식을 적지 않는다.
서버는 MCP TypeScript SDK의 `McpServer`를 이름 `wiremcp`와 버전만 주어 만들고 `instructions`를 넘기지 않는다 [1].
MCP TypeScript SDK 1.15.0의 `Server`는 받은 `instructions`가 있을 때만 `initialize` 응답에 싣는다 [2].
MCP SDK 클라이언트로 받은 `initialize` 응답에는 `instructions`가 없었고 리소스 목록 요청은 `Method not found` 오류였다 [3].

MCP 프롬프트 7개는 도구마다 하나씩 있고 모델에게 살펴볼 항목을 번호 목록으로 적는다 [4].

- `capture_packets_prompt`와 `analyze_pcap_prompt`는 트래픽 종류와 패턴, IP와 포트나 프로토콜, 눈에 띄는 사건이나 이상, 보안 우려를 살펴보라고 적는다 [4].
- `summary_stats_prompt`와 `conversations_prompt`는 프로토콜 분포, 통신량, 활발한 IP 쌍, 이상한 통신 패턴을 살펴보라고 적는다 [4].
- `check_threats_prompt`와 `check_ip_threats_prompt`는 URLhaus 목록과 대조하고 악성 활동을 찾고 보안 권고를 내라고 적는다 [4].
- `extract_credentials_prompt`는 평문 자격증명, Kerberos 인증 시도, 해시된 자격증명을 찾고 자격증명 처리 권고를 내라고 적는다 [4].

이 문구는 무엇을 살펴볼지만 정한다 [4].
확정하지 못한 결론을 어떻게 쓸지, 관찰과 해석을 나눌지, 근거를 다시 확인할지는 적지 않는다 [4].
MCP SDK 클라이언트로 받은 프롬프트 7개의 글에 이 문구가 그대로 실렸다 [3].

도구 설명 7개는 도구가 잡거나 읽는 대상과 돌려주는 자료의 형태만 적는다 [5].
도구와 관계없이 응답에 공통으로 붙는 문구는 없다 [6].
`extract_credentials`의 응답 끝 글은 암호화된 자격증명을 John the Ripper나 hashcat으로 크래킹할 수 있다고 적고 Kerberos 메시지 유형마다 쓸 모드를 적는다 [7].
이 글은 그 도구 결과에 이어 실행할 도구를 적을 뿐 결과를 어떻게 해석하거나 서술할지는 적지 않는다 [7].

  version: '1.0.0',
