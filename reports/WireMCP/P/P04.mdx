# P04 조사 단위 관리

### 미구현

**판단.** 서버에는 사건이나 세션 같은 조사 단위를 정하거나 나누는 장치가 없다.
도구 7개는 인터페이스와 캡처 시간, IP, pcap 경로만 인자로 받고 사건 ID나 세션 ID를 받지 않는다 [1].
서버는 증거, 기록, 파생물을 둘 폴더 배치를 정하지 않는다.
서버가 쓰는 파일은 실시간 캡처 도구 4개가 함께 쓰는 고정 이름 `temp_capture.pcap` 하나다 [2].
이 이름은 상대 경로이고 `tshark`와 `fs.unlink`는 서버 프로세스의 작업 폴더를 기준으로 이 경로를 정한다 [2][3].
서버는 작업 폴더를 정하지 않고 호출이나 조사마다 파일 이름을 나누지 않는다 [2].
서버는 stdio 전송으로만 실행하므로 서버 프로세스 하나에 연결이 하나다 [4].
서버 코드에는 연결이나 호출별로 상태를 나누는 코드가 없다 [4].
