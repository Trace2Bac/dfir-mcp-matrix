# P03 조사 진척 판단

### 미구현

**판단.** 서버는 대상별로 수행한 작업과 남은 작업을 표현하지 않고 완료 판단을 모델에 맡긴다.
서버에는 대상마다 해야 할 작업 목록, 조사 단계, 완료 조건이 없고 모델이 진행을 적는 도구도 없다 [1].
서버는 호출 기록을 남기지 않으므로 앞선 호출을 다시 읽어 집계할 자료도 없다 [2].

도구 응답은 그 호출 한 번의 결과만 싣고 다루지 못한 범위를 싣지 않는다.

- `capture_packets`와 `analyze_pcap`은 패킷 JSON이 720,000자를 넘으면 앞부분 패킷만 남기고 응답에는 잘랐다는 사실이나 뺀 패킷 수를 싣지 않는다 [3][4].
- 두 도구가 표준 오류에 남기는 줄은 패킷을 자른 뒤의 수를 두 번 적어 원래 패킷 수도 남지 않는다 [3][4].
- `check_threats`와 `check_ip_threats`는 URLhaus 목록을 내려받지 못해도 응답에 대조하지 못했다는 사실을 싣지 않고 위협이 없을 때와 같은 문장을 싣는다 [5][6].
- `extract_credentials`는 정해 둔 메시지 유형에 맞지 않는 Kerberos 줄을 항목으로 만들지 않고 뺀 줄 수를 싣지 않는다 [7].
