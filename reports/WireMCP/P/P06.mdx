# P06 조사 상태 유지

### 미구현

**판단.** 서버는 조사 상태를 두지 않는다.
도구는 호출마다 캡처하거나 받은 pcap 파일을 다시 읽어 응답을 만들고 결과를 보관하지 않는다 [1][2].
`check_threats`와 `check_ip_threats`는 호출마다 URLhaus 목록을 새로 내려받고 받은 목록을 담아 두지 않는다 [3].
`findTshark`도 호출마다 `tshark` 실행 파일을 다시 찾는다 [4].
실시간 캡처 도구가 쓰는 `temp_capture.pcap`은 한 호출 안의 중간 파일이고 다음 호출은 이 파일을 읽지 않고 새로 캡처해 다시 쓴다 [1].

요청 사이에 프로세스에 남는 값은 `McpServer` 객체 `server`와 `console.log`의 출력을 표준 오류로 보내도록 바꾼 설정이다 [5].
이 값은 서버 객체와 설정이고 조사에서 부른 도구나 받은 결과를 담지 않는다 [5].
조사 상태를 지니는 것은 클라이언트와 모델이다.
