# T09 대상 시스템 대응 조치 처리

### 비적용

**판단.** mulder는 조사하는 대상 시스템에 접속하거나 그 상태를 바꾸는 도구를 두지 않는다.
MCP 도구는 `run_parallel`(`app.py`)을 빼면 모두 `src/mulder/server/tools` 아래 모듈에서 등록된다 [1].
이 모듈들은 증거 파일·이미지·패킷 기록·덤프를 읽는 분석, 사건 DB와 발견사항 관리, 작업 관리를 맡는다 [1].
휴대전화 도구 모듈도 증거를 읽기만 한다고 적는다 [2].
서버 코드가 여는 외부 연결은 `enrich_iocs`가 공개 위협 정보 서비스에 IOC 평판·위치를 묻는 HTTP 요청과 YARA 도구가 룰 클론을 갱신하는 `git pull`이다 [3][4].
두 연결 모두 조사 대상 시스템이 아닌 제3자 서비스로 간다 [3][4].
`git pull`이 바꾸는 것은 서버가 설치한 룰 클론이다 [4].
복합 도구 모듈(`composite/lateral.py`·`composite/misc.py`·`composite/persistence.py`)에 나오는 `winrm`·`taskkill`·`wmic`은 증거에서 찾는 검색어다 [5].
그래서 조치 전후 상태·변경 내역·되돌림을 남길 대상이 없다.

    skip_sources: list[str] | None = None,

    """Enrich IOCs against public threat intelligence APIs.

        iocs: List of IOC strings (IPs, domains, MD5/SHA1/SHA256 hashes).
        skip_sources: Optional list of source names to skip (e.g.,
            ``["virustotal"]`` if no API key is configured).

    Returns:
        List of enrichment dicts, one per IOC, containing source
        results and an aggregate threat score.
    """
