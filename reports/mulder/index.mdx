# mulder 원고

셀 원고의 머리다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 예외 표시가 붙은 항목에는 **예외**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`3164843`](https://github.com/calebevans/mulder/tree/3164843baf74c7fe69e7121dbd6150f8f77ce660)(2026-09-19, v1.5.2 뒤 2커밋).
줄 번호는 모두 이 커밋 기준이다.

**범위.** `mulder serve`가 띄우는 MCP 서버(`src/mulder/server`)를 본다.
`mulder investigate` 오케스트레이터는 그 서버를 쓰는 MCP 클라이언트다.
상세가 클라이언트 쪽 방식을 묻는 경우(예: T02.03 클라이언트 도구 선택, T02.10 클라이언트 자체 도구 우회 차단)에는 오케스트레이터 동작도 구현으로 세고, 다른 클라이언트로 붙으면 적용되지 않는다는 점은 그 상세의 구현 단락에 적는다.
그 밖의 셀에서는 오케스트레이터 동작을 원고에 사실로만 적는다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
근거의 "실행 확인"은 저장소 사본에서 서버 함수를 직접 불러 본 결과다.

**외부 도구 버전 기준.** 서버는 외부 도구 버전을 대부분 고정하지 않는다.
`src/mulder/assets/assets.lock`에 내려받을 주소와 SHA-256을 적은 도구(capa·Chainsaw·DIE·FLOSS·Hayabusa)는 그 버전을 기준으로 한다.
나머지 도구는 저장소 `Dockerfile`의 실행 이미지 `ubuntu:22.04`에서 apt로 설치되는 패키지 버전을 기준으로 소스를 확인한다.
예를 들어 hashdeep은 Ubuntu 22.04 패키지 4.4-7.1이고 원본은 hashdeep 4.4다.
