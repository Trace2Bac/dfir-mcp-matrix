# E02 증거 무결성 검증

### E02.01 등록·첫 접근 시 자동 해시

**구현.** 사건을 만드는 `scan_evidence`는 분류기가 증거로 알아본 파일마다 모델의 요청 없이 SHA-256을 계산한다 [1][2].
값은 `evidence_registry`에 파일 경로·크기·등록 시각과 함께 들어간다 [2].
응답은 해시를 마쳤다고 알리고 해시에 실패한 파일이 있으면 그 수를 경고로 붙인다 [1].
등록한 값을 쓰는 곳은 `finalize_report`가 보고서에 싣는 것과 CLI `mulder report`뿐이다 [3].
등록한 SHA-256을 다시 계산해 현재 증거와 대조하는 코드는 없어 E02.05~E02.08에는 들지 않는다 [3].

`verify_evidence_integrity`는 이름과 달리 증거 파일을 읽지 않는다 [4].
이 도구는 사건 DB에 적재한 도구 출력을 다시 해시해 적재 때의 값과 대조하므로 D03에서 본다 [4].

**예외.** 응답은 등록한 파일 수와 관계없이 "Evidence hashing complete"라고 적는다 [1].
분류기가 알아보지 못한 파일, 분할 이미지의 둘째 조각부터, 로그 폴더와 iOS 백업 안의 파일은 증거 폴더 안에 있어도 해시하지 않는다 [2][5].
`extract_archive`가 푼 파일도 해시하지 않는다 [5].
저장소 사본에서 `extract_archive`가 안내한 폴더로 사건을 만들자 해시한 파일이 0건인데도 응답은 해시를 마쳤다고 적었다 [6].
같은 ID의 사건이 이미 있으면 `scan_evidence`는 해시 단계 전에 돌아간다 [1].
분석 도구는 받은 경로가 등록·해시된 파일인지 보지 않으므로 해시하지 않은 파일도 분석 입력이 된다 [7].

### E02.02 요청한 검증 도구에서 해시

**구현.** 모델이 `run_hashdeep`을 부르면 받은 경로를 `hashdeep -r -l`로 해시하고 출력을 사건 DB에 `hashdeep.hashes`로 적재한다 [8].
도구 설명은 경로 아래 모든 파일의 MD5·SHA-1·SHA-256을 계산한다고 적는다 [8].
이 출력을 `evidence_registry`의 값과 대조하는 코드는 없다 [3].
`run_hashdeep`은 받은 경로를 등록 목록에 넣지 않는다 [8].

### E02.03 전체 파일 해시

**구현.** `scan_evidence`의 자동 해시는 파일을 64 KiB씩 끝까지 읽어 모든 바이트를 해시한다 [2].
EWF 이미지는 `.E01` 파일 자체의 바이트를 해시하므로 이 값은 담긴 매체 데이터의 해시가 아니다 [2].
분할 이미지는 첫 조각 하나만 해시한다(E02.01의 예외).
`run_hashdeep`은 받은 경로 아래 파일을 파일 단위로 해시한다 [8].

### E02.04 분할·논리 범위 해시

**구현.** `extract_file_by_inode`는 이미지 안의 inode 하나를 `icat`으로 읽고 내용이 이진이면 그 바이트의 SHA-256과 크기를 응답에 싣는다 [9].
같은 도구에서 내용이 텍스트이면 해시하지 않고 사건 DB에 적재한다 [9].
`extract_optical_file`은 광학 디스크 이미지에서 파일 하나를 사건 폴더 아래로 꺼낸 뒤 꺼낸 파일의 SHA-256을 응답에 싣는다 [10].
두 값은 응답에만 들어가고 호출 기록에는 응답 전체의 해시만 남는다 [11].
서버는 이 값을 기준값으로 보관하지 않고 다시 대조하지도 않는다 [3].

```python
    def verify_evidence_integrity(self) -> list[dict[str, object]]:
        """Verify indexed source data against stored window hashes.

        Recomputes BLAKE2b from stored windows in a single streaming query
        ordered by source_id, comparing each hash to the windows_hash
        recorded at ingestion. Sources without a stored hash are reported
        as ``no_hash_recorded``.
        """
        sources = self.get_sources()
        no_hash_ids = {s.source_id for s in sources if not s.windows_hash}

        computed: dict[int, tuple[Any, int]] = {}

        with self._engine.connect() as conn:
            stream = conn.execute(
                text("SELECT source_id, raw_text FROM windows ORDER BY source_id, window_id")
            )
            for row in stream:
                sid: int = row[0]
                if sid in no_hash_ids:
                    continue
                if sid not in computed:
                    computed[sid] = (hashlib.blake2b(digest_size=32), 0)
                h, count = computed[sid]
                h.update(row[1].encode())
                computed[sid] = (h, count + 1)
```
