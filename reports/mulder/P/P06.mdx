# P06 조사 상태 유지

### P06.02 프로세스 메모리에만 보관

**구현.** 열린 사건 문맥 `_ctx`(사건 ID, DB 연결, 호출 기록 객체)는 모듈 전역 변수 하나다 [1].
세션마다 문맥을 따로 두는 코드가 없어 `--transport streamable-http`로 실행하면 연결한 클라이언트가 모두 같은 열린 사건을 쓴다 [1][2].
job store의 작업·batch·전달한 결과 목록, EVTX·TSK 추출 폴더 목록, `source` 목록 캐시, 디스크 이미지 정보 캐시, IOC 조회 캐시도 프로세스 메모리에만 있다 [3].
이 상태에는 유효 시간이나 개수 한도가 없고 프로세스가 끝나면 사라진다 [3].

### P06.03 조사 상태를 파일·DB에 저장

**구현.** 사건 DB에는 적재한 `source`와 `window`, 발견사항, `narrative`, 증거 해시 목록, 북마크, 진행 기록(`progress`), 키-값 표(`kv_store`)가 있다 [4].
`kv_store`에는 `run_fls`가 찾은 파티션 오프셋과 EVTX 추출 폴더 경로 같은 중간값이 들어간다 [5].
호출 기록은 `AuditLog`가 호출마다 JSONL 한 줄을 덧붙이고 `fsync`로 디스크에 쓴다 [6].
북마크와 진행 기록의 docstring은 DB에 남아 문맥 압축 뒤에도 남는다고 적는다 [7].

### P06.04 재시작 뒤 자동 복구

**구현.** `--case-id`를 주고 서버를 실행하면 `init_server`가 그 사건의 DB를 바로 연다 [8].
`--case-id`가 없으면 모델이 `open_case`를 불러야 같은 사건을 다시 읽는다 [8].
사건을 열 때 `AuditLog`는 기존 JSONL을 처음부터 읽어 호출 ID 목록과 도구별 호출 횟수를 다시 만든다 [9].
그래서 다시 시작한 서버에서도 발견사항의 인용 확인과 마감 조건이 앞 프로세스의 호출 기록을 본다 [9].
파티션 오프셋은 `kv_store`에서 다시 읽는다 [5].

**한계.** EVTX 추출 폴더는 서버가 정상 종료할 때 지우지만 `kv_store`의 폴더 경로는 남는다 [10].
다시 시작한 서버에서 `index_evtx_file`은 그 경로를 읽고 폴더가 없어 `run_evtx_parser`를 먼저 부르라는 오류를 낸다 [11].
`run_evtx_parser`를 `force` 없이 다시 부르면 그 이미지에서 만든 `evtx.manifest` `source`가 있어 건너뛴다 [12].
job store의 batch는 다시 만들어지지 않는다.

```python
    def _append(self, entry: dict[str, object]) -> None:
        """Append ``entry`` to the JSONL log file and update in-memory indexes."""
        with self._lock:
            self._log_path.parent.mkdir(parents=True, exist_ok=True)
            with open(self._log_path, "a") as fh:
```

```python
    def _load_existing(self) -> None:
        """Populate in-memory indexes from an existing JSONL file."""
        if not self._log_path.exists():
            return
        parse_errors = 0
        with open(self._log_path) as fh:
            for line in fh:
                line = line.strip()
                if not line:
                    continue
                try:
                    entry = json.loads(line)
                except json.JSONDecodeError:
                    parse_errors += 1
                    continue
                if isinstance(entry, dict):
                    self._index_entry(cast(dict[str, object], entry))
        if parse_errors > 0:
            logger.warning(
                "Audit log %s: %d lines failed to parse (possible corruption)",
                self._log_path,
                parse_errors,
            )
```

```python
    """Remove all extraction temp directories."""
    with _evtx_lock:
        dirs = list(_evtx_extract_dirs.values())
        _evtx_extract_dirs.clear()
    for path in dirs:
```
