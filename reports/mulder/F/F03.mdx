# F03 서버 안 모델 입력 구성

### 비적용

**판단.** mulder 서버는 도구 호출을 처리하는 동안 모델을 부르지 않는다.
저장소에서 모델 SDK `claude_agent_sdk`를 가져오는 곳은 오케스트레이터의 세션 모듈뿐이다 [1].
`mulder serve`가 실행하는 서버 코드(`src/mulder/server`)와 서버가 쓰는 보고서·DB 모듈은 오케스트레이터 모듈을 가져오지 않는다 [2].
서버 코드에는 MCP sampling으로 클라이언트에게 모델 생성을 요청하는 호출도 없다 [2].
서버가 밖으로 HTTP 요청을 보내는 곳은 `enrich_iocs`가 IOC 평판을 묻는 ip-api·AbuseIPDB·OTX·VirusTotal 요청이다 [3].
`mulder investigate` 오케스트레이터는 이 서버를 쓰는 MCP 클라이언트이고 그 모델 호출은 서버가 도구를 처리하는 중의 호출이 아니다 [1].
