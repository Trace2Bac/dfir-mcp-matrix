# E01 증거 등록 관리

### E01.01 증거 ID·등록 목록

**구현.** 증거를 등록하는 경로는 사건을 만드는 `scan_evidence` 하나다 [1].
`scan_evidence`는 받은 `evidence_path`를 분류기로 훑어 증거 목록을 만들고 새 사건 DB를 만든 뒤 목록의 파일마다 등록 함수를 부른다 [1].
등록 함수는 파일마다 `evidence_registry` 표에 행 하나를 넣고 행에는 자동 증가 `id`와 파일 경로가 들어간다 [2][3].
해시에 실패한 파일은 행을 넣지 않고 그 수를 응답의 경고 문구로 알린다 [1][2].

이 목록을 읽는 곳은 보고서를 쓰는 `finalize_report`와 CLI `mulder report`뿐이다 [4].
목록을 모델에게 돌려주는 MCP 도구는 없다 [4].
분석 도구는 목록을 보지 않고 받은 경로에 파일이 있는지만 확인한다 [5].

**예외.** 분류기가 증거로 알아보지 못한 파일은 증거 폴더 안에 있어도 목록에 오르지 않는다 [6].
`.pdf`·`.docx`·`.csv`·`.json`·이미지 같은 확장자와 분류기가 모르는 확장자의 파일, 경로 조각 하나라도 점으로 시작하는 파일이 여기에 포함된다 [6].
분할 이미지는 첫 조각(`.E01`·`.001`)만 목록에 오르고 `.E02`·`.002` 같은 나머지 조각은 빠진다 [7].
분류기는 로그 폴더와 iOS 백업을 폴더 항목 하나로 넣고 등록 함수는 파일이 아닌 항목을 건너뛰므로 그 안의 파일도 빠진다 [2][8].

`extract_archive`가 푼 파일은 목록에 넣지 않는다 [9].
응답은 푼 폴더로 `scan_evidence`를 부르라고 안내한다 [9].
기본 풀기 폴더는 `~/.mulder/cases/extracted` 아래라 경로에 점으로 시작하는 조각 `.mulder`가 있다 [10].
저장소 사본에서 이 안내대로 사건을 만들자 `evidence_registry`는 0건이었고 응답은 "Evidence hashing complete"라고 적었다 [11].

같은 ID의 사건 DB가 이미 있으면 `scan_evidence`는 그 사건을 열고 분류 결과만 돌려주며 등록 함수를 부르지 않는다 [1][12].
`replace`가 참이어도 적재한 자료가 있는 사건이면 같다 [12].

### E01.02 수집 위치와 저장 위치 기록

**구현.** `evidence_registry`의 파일 경로는 분류기가 실제 경로로 변환한 증거 루트 아래의 절대 경로다 [2][13].
서버는 증거를 다른 곳으로 옮기지 않으므로 이 경로는 증거가 놓인 저장 위치다.
사건 단위로는 `case_metadata`의 `evidence_root`에 `scan_evidence`가 받은 경로를 실제 경로로 변환한 값이 남는다 [3][13].
서버에는 단말에서 증거를 수집하는 기능이 없어 증거를 어디서 가져왔는지는 남기지 않는다.
등록 경로에 포함되지 않는 증거는 E01.01의 예외와 같은 이유로 위치도 남지 않는다.

### E01.03 크기·등록 시각·등록자 기록

**구현.** `evidence_registry`의 행마다 바이트 크기 `size_bytes`와 등록 시각 `registered_at`이 들어간다 [3].
크기는 해시하면서 읽은 바이트 수이고 등록 시각은 행을 넣을 때의 UTC 시각이다 [2][3].
등록한 주체를 담는 열은 없다 [3].
SHA-256 해시도 같은 행에 들어가고 E02에서 본다.

[2] 등록 함수는 파일 항목만 SHA-256을 계산해 행을 넣고 실패한 파일을 따로 모은다.

```python
    for item in manifest:
        fp = Path(str(item.get("path", "")))
        if not fp.is_file():
            continue
        try:
            h = _hashlib.sha256()
            size = 0
            with open(fp, "rb") as f:
                while True:
                    chunk = f.read(65536)
                    if not chunk:
                        break
                    h.update(chunk)
                    size += len(chunk)
            ctx.db.register_evidence_file(
                file_path=str(fp),
                sha256=h.hexdigest(),
                size_bytes=size,
            )
        except Exception as exc:
            logger.warning("Failed to hash evidence file %s: %s", fp, exc)
            failed_files.append(str(fp))
    return failed_files
```
