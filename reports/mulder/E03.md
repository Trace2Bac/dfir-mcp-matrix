# E03 원본 변경 방지

### E03.01 실행 환경의 읽기 전용 강제

**구현.** README의 컨테이너 실행 안내와 `Makefile`의 `container-run`은 증거 폴더를 컨테이너의 `/evidence`에 `:ro`로 붙인다 [1].
이 실행에서는 서버 코드든 외부 도구든 `/evidence` 아래 원본에 쓰려 하면 운영체제가 거부한다 [1].

디스크 이미지 파서 5개(`run_prefetch_parser`·`run_amcache_parser`·`run_shimcache_parser`·`run_mft_parser`·`run_registry_parser`)는 TSK로 파일을 꺼내지 못하면 이미지를 마운트해 읽는다 [2].
마운트는 `xmount`가 이미지에서 고른 파티션을 평면 파일로 보이게 하고 그 위에 `ntfs-3g`나 `fuse2fs`를 `ro` 옵션으로 올린다 [3].
서버는 `xmount`에 쓰기를 캐시 파일로 받는 `--cache` 인자를 넘기지 않는다 [3].
파서는 이 마운트 아래 파일을 읽는다 [2].

**예외.** README가 먼저 안내하는 설치 실행과 MCP 서버 설정은 컨테이너 없이 호스트에서 `mulder`를 돌린다 [4].
이 실행에는 증거 폴더를 읽기 전용으로 붙이는 장치가 없다 [4].
`run_dislocker`의 복호화 모드는 BitLocker 볼륨을 `dislocker-fuse`로 마운트하면서 읽기 전용 옵션을 넘기지 않는다 [5].

### E03.02 서버 코드의 원본 쓰기 제한

**구현.** 증거 폴더 안의 SQLite를 제자리에서 여는 경로는 `readonly_sqlite_uri`가 만든 `mode=ro` URI로 연다 [6].
Android 앱 DB 조회(`parse_android_artifacts`), iOS 백업의 `Manifest.db`와 대체 경로(`parse_ios_artifacts`), `decrypt_app_data`의 첫 시도가 이 경로다 [7].
`read_evidence_file`, `scan_evidence`의 해시 계산, 광학 디스크 파일 꺼내기는 원본을 `rb` 모드로 연다 [8].
조회문을 받는 `query_sqlite_from_image`는 원본 대신 `icat`으로 임시 폴더에 꺼낸 사본을 연다 [9].
그 사본에도 `mode=ro` URI와 조회·읽기·함수 호출만 허용하는 authorizer를 건다 [9].

**예외.** `mode=ro` URI로 WAL 모드 DB를 열자 DB 옆에 `-shm`·`-wal` 파일이 새로 생겼고 연결을 닫은 뒤에도 남았다 [10].
쓰던 프로그램이 남긴 `-shm`이 이미 있으면 그 내용이 바뀌었다 [10].
`readonly_sqlite_uri`의 설명은 증거 폴더에 아무것도 쓰지 않는다고 적는다 [6].
`decrypt_app_data`는 `mode=ro`로 열리지 않는 DB를 SQLCipher로 다시 열 때 URI 없이 원본 경로를 넘긴다 [11].
이 연결이 원본이나 옆 파일에 쓰는지는 확인하지 못했다.

### E03.03 외부 도구·플랫폼에 위임

**구현.** TSK·Volatility·plaso 같은 외부 도구에는 증거 경로를 읽기 인자로 그대로 넘기고 결과를 표준 출력이나 임시 폴더로 받는다 [12].
서버 코드에는 이 도구들이 원본에 쓰지 못하게 막는 장치가 없다.
원본 보호는 외부 도구가 증거를 읽기만 한다는 데 달려 있다.

**예외.** 외부 도구가 원본을 바꾸지 않는지는 실행해 확인하지 않아 실제 보호 미확인이다.
설치 실행에서는 E03.01의 읽기 전용 연결이 없어 이 도구들의 동작 말고는 원본을 지키는 것이 없다 [4].

```python
_ALLOWED_SQLITE_OPS: frozenset[int] = frozenset(
    {
        sqlite3.SQLITE_SELECT,
        sqlite3.SQLITE_READ,
        sqlite3.SQLITE_FUNCTION,
    }
)


def _readonly_authorizer(
    action: int, arg1: object, arg2: object, db_name: object, trigger: object
) -> int:
    """SQLite authorizer that only permits read operations."""
    if action in _ALLOWED_SQLITE_OPS:
        return sqlite3.SQLITE_OK
    return sqlite3.SQLITE_DENY
```
