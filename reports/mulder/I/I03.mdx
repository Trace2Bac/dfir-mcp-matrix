# I03 외부 전송 범위 구성

### I03.01 해시 전송

**구현.** 이 방식은 IOC 평판 조회 도구 `enrich_iocs`의 OTX·VirusTotal 질의에 있다 [1].
`classify_ioc`가 MD5·SHA1·SHA256 형식으로 나눈 IOC는 OTX와 VirusTotal에 해시 값만 보낸다 [1][2].
해시 값은 요청 주소의 경로에 들어가고 파일 내용은 올리지 않는다 [2].
두 서비스는 API 키가 있을 때만 질의하고 그 조건은 I01에서 본다.

### I03.02 메타데이터·추출 값 전송

**구현.** 이 방식도 `enrich_iocs`에 있다 [1].
IPv4 주소는 ip-api·AbuseIPDB·OTX·VirusTotal에, 도메인은 OTX·VirusTotal에 보낸다 [2][3].
보낼 값은 모델이 `iocs` 인자로 고른다 [4].
서버는 `classify_ioc`로 값의 형식을 나누고 IPv4·도메인·해시 형식이 아닌 값은 `unknown`으로 두어 어느 서비스에도 보내지 않는다 [1][3].
사설 IP 주소나 `fileserver.corp.local` 같은 내부 호스트 이름을 걸러 내는 처리는 없어 형식만 맞으면 그대로 나간다 [1].
ip-api 질의는 평문 HTTP라 IP 주소가 암호화되지 않은 채 나간다 [2].
YARA 스캔 도구의 룰 갱신은 원격에서 받아 오기만 하고 조사 자료를 보내지 않는다 [5].

```python
def classify_ioc(value: str) -> IOCType:
    """Classify an IOC string by type.

    Args:
        value: Raw IOC string to classify.

    Returns:
        The detected IOC type.
    """
    value = value.strip()
    if _IPV4_RE.match(value):
        return "ipv4"
    if _SHA256_RE.match(value):
        return "sha256"
    if _SHA1_RE.match(value):
        return "sha1"
    if _MD5_RE.match(value):
        return "md5"
    if _DOMAIN_RE.match(value):
        return "domain"
    return "unknown"
```
