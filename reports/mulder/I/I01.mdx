# I01 외부 연동 대상 관리

### I01.02 자격증명 존재로 활성화

**구현.** 이 방식은 IOC 평판 조회 도구 `enrich_iocs`의 VirusTotal·AbuseIPDB·OTX 질의에 있다 [1].
서버는 호출마다 `_load_api_keys`로 환경변수 `VIRUSTOTAL_API_KEY`·`ABUSEIPDB_API_KEY`·`OTX_API_KEY`를 읽고 값이 있는 서비스만 모은다 [1].
`_enrich_single_ioc`는 키를 모은 서비스에만 요청하고 키가 없는 서비스는 건너뛴다 [2].

### I01.03 기본 활성화

**구현.** 이 방식은 `enrich_iocs`의 ip-api 질의와 YARA 스캔 도구 3개의 룰 갱신에 있다 [2][3].
IOC가 IPv4 형식이면 `enrich_iocs`는 API 키와 관계없이 ip-api에 질의한다 [2].
`yara_scan_files`·`yara_scan_memory`·`yara_scan_with_volatility`는 룰을 준비하는 `_build_rules_args`에서 먼저 `_update_community_rules`를 부른다 [3].
`_update_community_rules`는 `signature-base` 클론에서 `git pull --ff-only`를 실행하고 서버 프로세스마다 한 번만 실행된다 [4].
클론이 없거나 서버 사용자가 클론에 쓸 수 없으면 갱신을 건너뛴다 [4].
두 연결 모두 끄는 설정이나 환경변수가 없다 [2][4].
모델이 `rules` 인자로 자기 룰을 넘겨도 갱신이 먼저 실행된다 [3].
도구 설명은 `signature-base` 룰을 쓴다고만 적고 스캔할 때 원격에서 룰을 받아 온다는 말은 없다 [5].

### I01.04 호출별 선택

**구현.** 이 방식은 `enrich_iocs`에 있다 [6].
`enrich_iocs`는 `skip_sources` 인자로 이번 호출에서 건너뛸 서비스 이름을 받는다 [6].
서비스 이름이 이 목록에 있으면 그 서비스에 질의하지 않는다 [2].
무엇을 건너뛸지는 모델이 정한다 [6].
YARA 스캔 도구에는 룰 갱신을 건너뛰는 인자가 없다 [3].

### I01.05 고정 목적지

**구현.** 이 방식은 `enrich_iocs`의 네 서비스에 있다 [7].
ip-api는 `http://ip-api.com/json/`, AbuseIPDB는 `https://api.abuseipdb.com/api/v2/check`, OTX는 `https://otx.alienvault.com/api/v1/`, VirusTotal은 `https://www.virustotal.com/api/v3/`로 시작하는 주소를 코드에 고정했다 [7].
이 주소를 바꾸는 설정·환경변수·인자는 없다 [7].
IOC 값은 이 주소의 경로나 질의 값에만 들어간다 [7].
ip-api 질의는 TLS 없이 평문 HTTP로 나간다 [7].
도구 문서도 질의 대상을 이 네 서비스로 적는다 [8].

### I01.06 설정으로 목적지 지정

**구현.** 이 방식은 YARA 스캔 도구 3개의 룰 갱신에 있다 [3].
서버 코드는 원격 주소를 넘기지 않고 클론 폴더에서 `git pull`만 실행하므로 목적지는 클론의 git 원격 설정이 정한다 [4].
서버가 읽는 클론은 환경변수 `MULDER_ASSET_ROOT`가 있으면 그 폴더에서만 찾고 없으면 `/opt`와 `~/.local/share/mulder/assets`에서 차례로 찾는다 [9].
`mulder setup`이 클론을 만들면 원격은 `https://github.com/Neo23x0/signature-base.git`이다 [10].
컨테이너 이미지의 클론도 같은 주소를 원격으로 둔다 [11].
`/opt`에 미리 있던 클론을 읽으면 원격은 그 클론을 만든 설치가 정한다 [9].
호출 인자로는 갱신 목적지를 바꾸지 못한다 [3].

```python
def _load_api_keys() -> dict[str, str]:
    """Load available API keys from environment variables.

    Returns:
        Map of source name to API key for sources with configured keys.
    """
    keys: dict[str, str] = {}
    for source_name, env_var in _ENRICHMENT_SOURCES.items():
        val = os.environ.get(env_var, "").strip()
        if val:
            keys[source_name] = val
        else:
            logger.debug("No API key for %s (env var %s not set)", source_name, env_var)
    return keys
```

```python
def _update_community_rules() -> None:
    """Pull latest YARA rules from signature-base (best-effort, once per session)."""
    global _rules_updated  # noqa: PLW0603
    with _rules_lock:
        if _rules_updated:
            return
        _rules_updated = True
    # Resolve once: four separate lookups could disagree if a concurrent
    # ``mulder setup`` publishes the clone mid-function.
    base = _signature_base_dir()
    if base is None or not (base / ".git").is_dir():
        return
    if not (os.access(base, os.W_OK) and os.access(base / ".git", os.W_OK)):
        # A pull has to write objects, refs and the worktree, and git also
        # refuses to touch a clone owned by another user. The container image
        # ships a root-owned, SHA-pinned clone under /opt and runs the server
        # as `mulder`, so there the pinned rules are the rules by design.
        logger.info(
            "YARA rules: %s is not writable by this user; using the installed checkout as-is",
            base,
        )
        return
    try:
        proc = subprocess.run(
            ["git", "-C", str(base), "pull", "--ff-only", "-q"],
            capture_output=True,
            text=True,
            timeout=30,
            check=False,
        )
```
