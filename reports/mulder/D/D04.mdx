# D04 출력 경로 제한

### D04.01 서버가 출력 위치 결정

**구현.** 파일로 남는 파생물은 서버가 cases 폴더(`--db-dir`) 아래에 정한 이름으로 쓴다 [1].
사건 DB·호출 기록·보고서·로그 사본·Plaso 저장 파일은 `<case_id>`에 정해진 확장자를 붙인 이름이다 [1].
`extract_archive`의 기본 목적지, `extract_optical_file`의 폴더, `carve_sqlite_from_raw`의 폴더도 서버가 정한다 [1].
호출 인자는 `case_id`와 압축·이미지 파일 이름의 `stem` 한 조각으로만 경로에 들어간다 [1][2].
그 밖의 추출 도구는 `tempfile`이 만든 임시 폴더에 쓴다 [3].
호출자가 목적지를 고르는 인자는 `extract_archive`의 `extract_to` 하나다 [4].

**한계.** `extract_optical_file`은 서버가 정한 폴더 뒤에 광학 디스크 이미지 안의 파일 경로를 그대로 붙여 목적지를 만든다 [5].
이미지에서 읽은 이름은 경로 구분자나 `..`를 검사하지 않으므로 그런 이름의 항목을 꺼내면 `extracted/` 밖에 쓴다 [5].
`run_binwalk`에 `extract=True`를 주면 서버는 목적지도 작업 폴더도 주지 않고 `binwalk -e`를 실행한다 [6].
풀어낸 파일의 위치는 binwalk가 정하고 서버는 검사하지 않으며 실제 위치는 확인하지 못했다 [6].
도구 설명은 임시 폴더에 푼다고 적는다 [6].

### D04.02 실제 경로와 허용 폴더 대조

**구현.** `extract_archive`는 `extract_to`를 받으면 `resolve_allowed_path`로 cases 폴더 아래 `extracted/` 안인지 대조하고 밖이면 `invalid_input`으로 거부한다 [4].
`resolve_allowed_path`는 있는 경로는 링크까지 해석한 실제 경로로, 없는 경로는 non-strict로 변환해 허용 폴더와 경로 조각 단위로 비교한다 [7].
대조에 쓴 실제 경로를 돌려주고 `extract_archive`는 그 경로에 압축을 푼다 [4][7].

### D04.03 파생물 ID로만 수정·삭제

**구현.** 저장된 발견사항은 `update_finding`·`delete_finding`이 `finding_id`로 골라 고치거나 지운다 [8].
북마크는 `remove_bookmark`가 `bookmark_id`로 골라 지운다 [8].
`scan_evidence`의 `replace`는 `case_id`로 정한 사건 DB와 그 옆 호출 기록·보고서·Plaso 저장 파일을 지운다 [9].
파생물을 경로로 받아 고치거나 지우는 도구는 없다 [8].

### D04.04 이름·확장자·충돌 검사

**구현.** `validate_case_id`는 경로 구분자나 제어 문자가 든 `case_id`를 거부해 사건 파일 이름을 한 조각으로 묶는다 [10].
실제 경로로 변환하지 않는 문자열 검사다 [10].
`extract_archive`는 zip 항목 가운데 `/`로 시작하거나 `..`가 든 이름을 건너뛴다 [11].
tar 항목은 같은 이름 검사에 더해 `..`가 든 링크 대상을 건너뛰고 절대 경로 링크 대상은 상대 경로로 바꾼다 [11].

**한계.** `.7z`·`.rar` 압축과 파이썬이 열지 못한 zip은 `7z x`에 넘기고 서버는 항목 이름을 보지 않는다 [12].
zip을 풀다 압축 방식을 다루지 못하거나 zip 형식 오류가 나서 `7z`를 쓰면 앞에서 건너뛴 항목이 든 압축 전체를 `7z`에 넘긴다 [11][12].
`7z`가 위험한 항목 이름을 어떻게 다루는지는 확인하지 못했다 [12].

```python
def _archive_slot(archive: Path) -> str:
    """Return a per-archive directory name that cannot collide.

    ``archive.stem`` alone is ambiguous: two unrelated archives called
    ``evidence.zip`` collect in the same slot, and the second call then takes
    the "already extracted" path and reports the *first* archive's files as
    its own.  Appending a digest of the resolved source path keeps the name
    readable while making it unique to one archive on disk.
    """
    digest = hashlib.blake2b(str(archive).encode(), digest_size=6).hexdigest()
    return f"{archive.stem}-{digest}"
```

def _resolve(path: Path) -> Path:
    """Resolve *path*, permitting absence but rejecting other resolution errors."""
    try:
        return path.resolve(strict=True)
    except FileNotFoundError:
        return path.resolve(strict=False)

```python
def _extract_zip(archive: Path, dest: Path) -> list[str]:
    """Extract a zip archive to *dest* and return paths relative to *dest*.

    Falls back to the ``7z`` binary when Python's zipfile module cannot
    handle the compression method (e.g. deflate64, LZMA).
    """
    try:
        with zipfile.ZipFile(archive, "r") as zf:
            for member in zf.namelist():
                if member.startswith("/") or ".." in member:
                    logger.warning("Skipping unsafe zip entry: %r", member)
                    continue
                zf.extract(member, dest)
    except (NotImplementedError, zipfile.BadZipFile):
        if not shutil.which("7z"):
            raise
        return _extract_7z(archive, dest)
    return [str(f.relative_to(dest)) for f in dest.rglob("*") if f.is_file()]


def _safe_tar_filter(member: tarfile.TarInfo, path: str) -> tarfile.TarInfo | None:
    """Allow extraction but neutralize absolute symlinks and path traversal."""
    if member.name.startswith("/") or ".." in member.name:
        return None
    if member.issym() or member.islnk():
        if ".." in member.linkname:
            return None
        if member.linkname.startswith("/"):
            member.linkname = member.linkname.lstrip("/")
    return member
```
