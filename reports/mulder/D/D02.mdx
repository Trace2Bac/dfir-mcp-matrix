# D02 파생물 추적

### D02.01 ID·경로 참조

**구현.** 사건 DB에 넣은 도구 출력은 `sources` 행 하나로 남고 그 출력의 `window`는 `source_id`로 그 행을 가리킨다 [1].
`sources` 행에는 도구가 넘긴 증거 경로 `source_path`, 추출기 이름, 출력 해시가 들어간다 [1][2].
그 행을 만든 호출의 `tool_call_id`를 담는 열은 없다 [1].
호출 기록 항목에는 호출 ID·도구 이름·인자·`output_hash`·시각이 들어가고 그 호출이 만든 `source` 이름이나 `source_id`는 들어가지 않는다 [3][4].
적재 도구의 `output_hash`는 적재 요약 `dict`의 해시라서 보관한 출력과 해시로도 이어지지 않는다 [4].
`source` 행과 그것을 만든 호출은 같은 증거 경로 인자와 시각을 맞춰 보는 방법으로만 짝지을 수 있다 [1][3].

호출 기록에는 `finding` 항목으로 `finding_id`와 `evidence_refs`가 남고 그 항목에는 `submit_finding` 호출 자신의 `tool_call_id`가 없다 [5].
발견사항에서 근거 호출을 거쳐 `source` 행까지 따라가는 `get_provenance_chain`이 정의돼 있지만 서버 도구는 이 함수를 부르지 않는다 [6].
`get_source_stats`는 발견사항의 `sources` 이름으로 `source`마다 인용 여부만 돌려준다 [7].

`extract_archive`가 푼 폴더는 곁에 출처 파일을 둔다 [8].
`extract_optical_file`·`carve_sqlite_from_raw`가 남긴 파일과 `finalize_report`의 보고서 파일에는 그것을 만든 호출이나 입력을 적은 곳이 없다 [9].

**한계.** `submit_finding`은 `sources`의 이름이 사건 DB의 `source`에 있는지 보지 않는다 [10].
`sources` 테이블의 이름 열에는 unique 제약이 없고 다시 실행한 도구는 같은 이름의 행을 하나 더 만든다 [1][11].
그래서 발견사항의 `source` 이름 참조는 어느 실행의 행인지 가리지 못한다 [1][11].
`run_plaso`가 남기는 `plaso.stats` 행의 `source_path`는 사건마다 하나인 저장 파일을 가리키므로 다시 실행하면 앞 실행의 행도 새 저장 파일을 가리킨다 [12].
`filter_timeline`·`export_timeline_slice`가 적재하는 `plaso.filtered`·`plaso.slice`의 `source_path`도 같은 저장 파일을 가리킨다 [13].
그래서 `run_plaso`를 다시 실행한 뒤에는 이 두 행도 자신을 만든 저장 파일이 아니라 새 저장 파일을 가리킨다 [13][12].

### D02.03 파생물 측 manifest

**구현.** `extract_archive`는 압축을 다 푼 뒤 풀기 폴더에 `.mulder-extraction-complete.json`을 쓴다 [8].
이 파일에는 원래 압축 파일 경로·푼 파일 수·완료 시각이 들어간다 [8].
이 파일에는 압축 파일이나 푼 파일의 해시가 없고 푼 호출의 `tool_call_id`도 없다 [8].
다른 파일 파생물 곁에는 manifest를 두지 않는다 [9].

**한계.** manifest를 쓰지 못하면 경고 로그만 남기고 manifest 없이 성공으로 돌려준다 [8].

```python
    def get_provenance_chain(self, finding_id: str, db: CaseDB) -> ProvenanceChain:
        """Trace a finding back through tool calls to original evidence files."""
        finding_entry = self._finding_entries.get(finding_id)
        if finding_entry is None:
            raise KeyError(f"No finding with id '{finding_id}' in the audit log")

        raw_refs = finding_entry.get("evidence_refs", [])
        if isinstance(raw_refs, list):
            evidence_refs = [x for x in raw_refs if isinstance(x, str)]
        else:
            evidence_refs = []
        tool_calls, queried_source_names = self._resolve_tool_calls(evidence_refs)
        sources = self._resolve_sources(queried_source_names, db)

        return ProvenanceChain(
            finding_id=finding_id,
            tool_calls=tool_calls,
            sources=sources,
        )
```

```python
        def _do_register() -> int:
            """Insert source row and return its auto-generated ID."""
            now = datetime.now(timezone.utc).isoformat()
            case_id = self._get_case_id()
            with self._engine.begin() as conn:
                result = conn.execute(
                    insert(sources_t).values(
                        case_id=case_id,
                        source_name=source_name,
                        source_path=source_path,
                        source_hash=source_hash,
                        extractor=extractor,
                        line_count=line_count,
                        ingested_at=now,
                    )
                )
                if result.inserted_primary_key is None:
                    raise RuntimeError(
                        "INSERT did not return a primary key for source registration"
                    )
                return int(result.inserted_primary_key[0])
```
