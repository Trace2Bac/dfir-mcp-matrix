# D10 산출물 식별·재생성 처리

### D10.02 입력·작업별 고유 이름

**구현.** 이 방식은 `extract_archive`가 압축을 푸는 기본 목적지 폴더에 적용된다 [1].
기본 목적지 이름은 압축 파일 `stem`에 실제 경로의 BLAKE2b 앞 6바이트를 붙여 이름이 같은 다른 압축과 겹치지 않는다 [1].
이 값은 압축 파일의 경로마다 같으므로 같은 압축을 다시 풀면 같은 폴더를 쓴다 [1].

다른 파일 파생물은 이 방식 없이 고정 이름을 쓴다 [2].
`carve_sqlite_from_raw`의 `carved_<오프셋>.sqlite`는 이미지·사건과 관계없이 오프셋이 같으면 같은 이름이다 [2].
`extract_optical_file`의 폴더는 이미지 `stem`만 쓰므로 다른 폴더의 같은 이름 이미지와 한 폴더를 쓴다 [2].
`run_plaso`의 저장 파일과 `finalize_report`의 보고서는 사건마다 이름이 하나다 [2].

**한계.** `extract_to`로 `extracted/` 자체나 다른 압축을 이미 푼 폴더를 고르면 경로 해시 없이 그 폴더에 겹쳐 푼다 [3][4].

### D10.03 버전·이력 보존

**구현.** 이 방식은 사건 DB에 적재하는 도구 출력에 적용된다 [5].
사건 DB에 출력을 넣을 때마다 `register_source`가 새 `source_id`와 적재 시각으로 `sources` 행을 하나 더 넣고 앞 행을 지우지 않는다 [5].
`search`는 `window`마다 `source_id`를 붙여 돌려주므로 같은 이름의 두 실행을 가를 수 있다 [6].

**한계.** `get_raw_output`은 이름이 같거나 이름 뒤에 `.`이 붙은 `source`의 `window`를 `window_id` 차례로 이어 붙이고 어느 실행의 것인지 표시하지 않는다 [7].
`finalize_report`가 보고서에 싣는 원문 목록은 `source` 이름을 키로 두 실행의 `window`를 한 목록에 넣는다 [7].
`list_sources`가 돌려주는 행에는 적재 시각이 없어 같은 이름의 행 가운데 어느 것이 나중 실행인지 `source_id` 크기로만 짐작한다 [8].

### D10.04 덮어쓰기 선택·충돌 감지

**구현.** 이 방식은 추출 도구 15개, `start_extraction_batch`, `extract_archive`에 적용된다 [9][10][11].
추출 도구 15개는 같은 이름 접두어의 `source`가 이미 있으면 다시 실행하지 않고 `skipped`와 기존 `source` 이름을 돌려준다 [9].
증거 경로를 받는 도구는 `source_path`가 같은 `source`가 있을 때만 건너뛴다 [9].
`force=True`를 넘기면 다시 실행하고 그 결과는 D10.03처럼 새 행으로 남는다 [9].
`start_extraction_batch`도 같은 검사로 작업을 건너뛴다 [10].
`extract_archive`는 풀기 폴더의 완료 표시가 같은 압축 경로를 가리키면 다시 풀지 않고 `already_extracted`와 파일 목록을 돌려준다 [11].

이 방식이 없는 파일 파생물은 같은 이름이 이미 있는지 보지 않는다.
`run_plaso`의 저장 파일, `finalize_report`의 보고서, `extract_optical_file`과 `carve_sqlite_from_raw`의 파일은 같은 이름이면 알리지 않고 덮어쓴다 [12].
그래서 같은 사건에서 `run_plaso`를 다시 실행하면 앞 실행의 저장 파일은 남지 않는다 [12].

**한계.** 이미 있는지는 `source_path` 문자열이 같은지로 보므로 같은 증거를 다른 경로 문자열(상대 경로, 링크)로 넘기면 알아채지 못하고 다시 실행한다 [9].
`extract_to`로 다른 압축을 이미 푼 폴더를 고르면 완료 표시가 다른 압축을 가리켜 다시 풀고 그 폴더의 앞 파일과 완료 표시를 알리지 않고 덮어쓴다 [13][11].
새 완료 표시는 마지막에 푼 압축 하나만 적으므로 그 폴더에 남은 앞 압축의 파일은 완료 표시에 출처가 적히지 않는다 [13].

[1] 압축 해제 기본 폴더 이름은 `stem`과 실제 경로의 해시다.

```python
def _archive_slot(archive: Path) -> str:
    """Return a per-archive directory name that cannot collide.

    ``archive.stem`` alone is ambiguous: two unrelated archives called
    ``evidence.zip`` collect in the same slot, and the second call then takes
    the "already extracted" path and reports the *first* archive's files as
    its own.  Appending a digest of the resolved source path keeps the name
    readable while making it unique to one archive on disk.
    """
    digest = hashlib.blake2b(str(archive).encode(), digest_size=6).hexdigest()
    return f"{archive.stem}-{digest}"
```

```python
def _extraction_is_complete(dest: Path, archive: Path) -> bool:
    """Return True only if *dest* holds a finished extraction of *archive*."""
    marker = dest / _COMPLETION_MARKER
    if not marker.is_file():
        return False
    try:
        recorded = json.loads(marker.read_text())
    except (OSError, json.JSONDecodeError):
        return False
    return bool(recorded.get("archive") == str(archive))
```
