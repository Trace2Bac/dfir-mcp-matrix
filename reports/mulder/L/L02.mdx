# L02 기록 구성

### L02.01 MCP 요청 기록

**구현.** 서버 기록에 남는 `tool_call` 항목은 도구 이름 `tool_name`과 인자 `params`를 담는다 [1].
항목에는 이와 함께 호출 ID `tool_call_id`, 결과 해시 `output_hash`, 소요 시간 `duration_ms`, 기록 시각 `timestamp`가 들어간다 [1].
`params`에 넣을 값은 기록을 부르는 도구가 정해 넘긴다 [1].
`audited_tool`을 붙인 도구 5개는 도구 본문에 전달된 키워드 인자를 그대로 넣는다 [2].
이는 MCP SDK가 해석한 값이며 전송된 요청 전체를 그대로 보관하는 것은 아니다.
응답 함수를 쓰는 도구는 대개 받은 인자로 `params`를 만든다 [3].
`scan_evidence`는 `MULDER_CASE_ID`로 `case_id`를 바꾸기 전에 받은 값으로 `params`를 만든다 [3].

서버가 고친 값이나 실제 실행 명령은 항목에 없다.
외부 명령을 실행하는 `run_cli_tool`도 실행한 명령 줄 `cmd` 대신 도구가 넘긴 `params`를 기록한다 [4].
그래서 L02.02·L02.03에는 연결하지 않는다.

항목에는 성공·실패를 구별하는 결과 상태 필드가 없다 [1].
`error_response`는 오류 문구로 만든 해시만 `output_hash`에 넣으므로 오류 항목이 성공 항목과 같은 모양이다 [5].
그래서 L02.05에는 연결하지 않는다.
외부 요청을 보내는 `enrich_iocs`는 사건 ID와 IOC 개수만 남기고 어느 서비스에 무엇을 물었는지와 응답은 남기지 않는다 [6].
YARA 스캔 도구가 룰 저장소에서 `git pull`을 실행한 일과 그 결과는 서버 로그에만 남는다 [7].
외부 요청 내용은 별도 상세로 연결하지 않고 이 기록 범위를 사실로 남긴다.
서버 안에서 모델을 부르는 도구는 없어 L02.04는 볼 대상이 없다.

**한계.** 여러 도구가 받은 인자 일부를 빼거나 요약값으로 바꿔 기록한다.
`run_volatility_batch`는 `force`를 뺀다 [8].
`extract_file_by_inode`는 `filesystem_type`·`image_path`를 빼고 `inode`만 넣는다 [9].
`submit_finding`은 `description`·`event_time_start`·`event_time_end`를 뺀다 [10].
`enrich_iocs`는 IOC 목록 대신 개수를 넣는다 [6].
`decode_payload`는 입력 `data` 대신 길이를 넣는다 [11].
YARA 스캔 도구는 `rules` 대신 룰을 넘겼는지만 참·거짓으로 넣는다 [12].
`run_parallel`과 `start_extraction_batch`는 하위 작업의 인자를 빼고 도구 이름 목록만 넣는다 [13].
위는 확인한 도구이고 153개 도구의 기록 인자를 모두 받은 인자와 대조하지는 않았다.

같은 저장소의 `mulder investigate` 오케스트레이터는 자기 프로세스에서 사건을 열고 `_tool_dispatch_sync`로 `check_finalize_readiness` 같은 도구 함수를 MCP 없이 직접 부른다 [14].
그 도구 본문이 기록을 부르므로 이 호출도 서버의 호출 기록 파일에 `tool_call` 항목으로 남는다 [15].
항목에는 쓴 프로세스를 가르는 필드가 없다 [1].

### L02.06 결과 참조·요약값 기록

**구현.** 서버의 `tool_call` 항목은 결과를 가리키는 `output_hash`를 담는다 [1].
`tool_response`는 응답을 만들기 전 `results` 객체의 JSON을, `windowed_response`는 결과 전체 대신 전체 개수와 반환 개수를 담은 객체를 해시한다 [16][17].
`hash_output`은 키를 정렬한 JSON 바이트의 BLAKE2b 값을 만든다 [18].
따라서 같은 필드라도 도구 출력 내용의 해시와 개수 요약의 해시를 구별해야 한다.
`error_response`는 오류 문구를 넣은 객체의 해시를 남긴다 [5].

**한계.** `audited_tool`의 성공 경로는 결과 객체를 해시하지만 예외 경로는 해시 대신 고정 문자열 `error`를 남긴다 [19].
이 값으로는 실패 호출의 출력 내용을 가리킬 수 없다.

### L02.07 호출 ID로 항목 연결

**구현.** 한 호출이 여러 항목을 낳는 경로는 `run_parallel`과 백그라운드 배치다 [20][21].
`run_parallel`은 자기 항목의 `tool_call_id`로 배치 ID를 쓰고 하위 호출의 ID를 `sub_calls`에 담는다 [20].
하위 호출을 부르는 동안에는 문맥 변수 `current_batch_id`에 같은 배치 ID를 넣는다 [22].
응답 함수는 이 값을 하위 항목의 `batch_id`에 넣는다 [23].
백그라운드 작업도 실행 전에 `current_batch_id`에 그 작업의 배치 ID를 넣는다 [21].

**한계.** `audited_tool`과 본문에서 `log_tool_call`을 직접 부르는 도구는 `batch_id`를 넘기지 않아 배치 안에서 불려도 항목에 배치 ID가 없다 [24].
`start_extraction_batch`의 항목에는 배치 ID가 없어 그 배치의 하위 항목과 이어지지 않는다 [25].
배치 ID는 그 항목의 `output_hash`를 만드는 입력에만 들어간다 [25].
`submit_finding`이 쓰는 `finding` 항목과 `tool_call` 항목은 서로의 ID를 담지 않는다 [26].
`run_parallel`이 자기 항목을 남기지 못하고 끝나면 하위 항목의 `batch_id`가 가리키는 항목이 없다 [20].

    def log_tool_call(
        self,
        tool_call_id: str,
        tool_name: str,
        params: Mapping[str, object],
        output_hash: str,
        duration_ms: float = 0,
        sub_calls: list[str] | None = None,
        batch_id: str | None = None,
    ) -> None:
        """Record a tool invocation as one JSONL line and index ``tool_call_id``."""
        entry: dict[str, object] = {
            "type": "tool_call",
            "tool_call_id": tool_call_id,
            "tool_name": tool_name,
            "params": dict(params),
            "output_hash": output_hash,
            "duration_ms": duration_ms,
            "timestamp": datetime.now(timezone.utc).isoformat(),
        }
        if sub_calls is not None:
            entry["sub_calls"] = sub_calls
        if batch_id is not None:
            entry["batch_id"] = batch_id
        self._append(entry)

_HASH_PREFIX = "blake2b:"
_HASH_DIGEST_SIZE = 32


def _blake2b_hex(data: bytes) -> str:
    return _HASH_PREFIX + hashlib.blake2b(data, digest_size=_HASH_DIGEST_SIZE).hexdigest()


def hash_output(output: object) -> str:
    """Return a BLAKE2b commitment to the complete JSON form of *output*."""
    raw = json.dumps(output, sort_keys=True, default=str)
    return _blake2b_hex(raw.encode())
