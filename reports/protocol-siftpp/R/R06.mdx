# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 증거에서 나온 값을 응답에 그대로 싣고 그 가운데 비밀 값을 가리거나 빼는 처리를 두지 않는다.
Volatility 출력은 행과 열을 바꾸지 않고 `result`나 `result_text`에 실린다 [1].
비밀번호 해시나 키를 꺼내는 플러그인은 허용 목록에 없다 [2].
그러나 `vol_cmdline`의 `Args`와 `vol_pstree`의 `Cmd`는 프로세스 명령줄 전체를 싣는다 [3].
명령줄에 넘긴 비밀번호나 토큰도 가림 없이 모델에게 간다 [1][3].
`vol_svcscan`의 서비스 실행 경로와 `vol_malfind`의 메모리 내용 hexdump도 그대로 실린다 [3].

서버 호출 기록에는 Volatility 출력 대신 출력의 해시와 바이트 수만 남는다 [4].
클라이언트 `siftpp-investigate`는 발견사항마다 근거 도구 출력의 앞 400자를 `output_excerpt`로 보고서 `report.json`에 싣는다 [5].

def _excerpt(result: dict[str, Any], limit: int = 400) -> str:
    if result.get("result") is not None:
        return json.dumps(result["result"], default=str)[:limit]
    return str(result.get("result_text", ""))[:limit]
