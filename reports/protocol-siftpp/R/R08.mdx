# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 서버는 시각 값을 바꾸지 않고 Volatility JSON 렌더러가 낸 문자열을 그대로 전달한다 [1].
Volatility 3 2.28.0의 JSON 렌더러는 `datetime` 값을 `isoformat()` 문자열로 출력한다 [2].
`pslist`·`psscan`의 생성·종료 시각, `netscan`의 연결 생성 시각, `dlllist`의 적재 시각 같은 값이 이 문자열로 `result`에 실린다 [2].

### R08.03 시간대·단위·정밀도 표시

**구현.** Volatility 3 2.28.0은 Windows FILETIME을 UTC 시간대가 붙은 `datetime`으로 바꾼다 [3].
JSON 렌더러의 `isoformat()`은 이 값에 `+00:00` 오프셋을 붙여 출력하고 서버는 그 문자열을 바꾸지 않는다 [2][1].
그래서 응답의 시각 문자열에는 시간대가 값으로 실린다.
FILETIME이 0이면 Volatility는 값 대신 해당 없음 표시를 내고 JSON 렌더러는 이를 `null`로 출력한다 [2][3].
범위를 벗어나 변환할 수 없는 FILETIME도 Volatility가 변환 불가 표시를 내므로 `null`로 출력된다 [2][3].
서버 문구나 도구 설명은 시간대를 따로 말하지 않는다 [4].
