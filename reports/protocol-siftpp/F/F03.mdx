# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
서버 모듈 `server.py`·`volatility.py`·`audit.py`가 가져오는 것은 표준 라이브러리, FastMCP, 서버 자신의 호출 기록 모듈과 해시 함수뿐이고 모델 API 클라이언트는 없다 [1].
서버 도구 11개는 Volatility 플러그인 실행, 증거 메타데이터 반환, 증거 해시 재계산만 한다 [2].
Volatility 실행기는 고정한 인자 배열로 `vol`만 실행한다 [3].

모델 API는 클라이언트 `siftpp-investigate`가 부른다 [4].
클라이언트는 Anthropic SDK의 `messages.create`로 Investigator와 Skeptic 모델을 부르고 서버 도구는 MCP로 부른다 [4][5].
그래서 모델에게 보내는 시스템 지시와 검토 요청은 클라이언트가 구성하고 서버 구현으로 보지 않는다.
