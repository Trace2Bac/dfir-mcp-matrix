# P03 조사 진척 판단

### 미구현

**판단.** 서버는 무엇을 수행했고 무엇이 남았는지 표현하지 않는다.
서버가 두는 상태는 증거 파일 경로와 그 해시·크기·수정 시각, 호출 기록 객체뿐이다 [1][2].
호출 기록에는 실행한 Volatility 명령이 남지만 서버는 그 기록을 다시 읽어 집계하거나 작업 목록과 대조하지 않는다 [3].
`verify_evidence_integrity`의 설명은 조사 끝에 부르라고 적지만 서버는 이 도구를 불렀는지 확인하지 않는다 [4].

진척과 완료 판단은 클라이언트 `siftpp-investigate`의 코드가 한다 [5].
클라이언트는 아직 검토를 받지 않은 발견사항이 없거나 정한 반복 횟수 `max_iterations`(기본 3)에 이르면 반복을 멈춘다 [5][6].
마지막 차례에 나온 발견사항까지 검토한 뒤 `verify_evidence_integrity`를 불러 조사를 끝낸다 [5].
Investigator가 조사를 끝낼지는 모델이 정하고 한 번의 차례에서 모델과 도구 사이의 왕복은 24회로 제한된다 [6][7].

def _build_runner() -> VolatilityRunner:
    evidence = os.environ.get("SIFTPP_EVIDENCE")
    if not evidence:
        raise RuntimeError("Set SIFTPP_EVIDENCE to the path of the memory image")
    audit = AuditLogger(os.environ.get("SIFTPP_AUDIT_LOG", "analysis/audit.jsonl"))
    runner = VolatilityRunner(
        guard=EvidenceGuard.open(evidence),
        audit=audit,
        agent=os.environ.get("SIFTPP_AGENT", "investigator"),
        offline=os.environ.get("SIFTPP_VOL_OFFLINE") == "1",
    )
    runner.session_start()
    return runner


def get_runner() -> VolatilityRunner:
    global _runner
    if _runner is None:
        _runner = _build_runner()
    return _runner

```python
def verify_chain(path: str | Path) -> tuple[bool, int]:
    """Re-derive the hash chain. Returns (ok, n_records). Proves the audit log
    was not tampered with: any edit to a past record breaks the chain."""
    prev = _GENESIS
    n = 0
    with Path(path).open("r", encoding="utf-8") as fh:
        for line in fh:
            line = line.strip()
            if not line:
                continue
            n += 1
            rec = json.loads(line)
            stored = rec.pop("hash", None)
            if stored != sha256_hex(prev + _canonical(rec)):
                return False, n
            prev = stored
    return True, n
```
