# P05 사건 자료 정리

### 미구현

**판단.** 서버는 호출 기록 파일을 남기지만 이를 지우거나 초기화하는 기능이 없다.
서버 코드가 쓰는 파일은 호출 기록 하나이고 기록 객체는 파일에 덧붙이기만 한다 [1].
기존 파일이 있으면 지우지 않고 마지막 항목에 이어 쓴다 [2].
등록한 도구 11개 가운데 파일이나 상태를 지우는 도구는 없다 [3].
증거 해시 기준값과 실행기 같은 메모리 상태는 서버 프로세스가 끝나면 사라지고 이를 비우는 도구도 없다 [4].

사용자 CLI에도 사건 출력 폴더를 지우는 명령은 없다.
`siftpp-verify`와 `siftpp-gui`의 공격 시험은 임시 폴더에 합성 증거를 만들어 서버를 실행하고 시험이 끝나면 그 폴더를 지운다 [5].
이 폴더는 시험용 자료라 사건 자료가 아니다.

```python
_runner: VolatilityRunner | None = None


def _build_runner() -> VolatilityRunner:
    evidence = os.environ.get("SIFTPP_EVIDENCE")
    if not evidence:
        raise RuntimeError("Set SIFTPP_EVIDENCE to the path of the memory image")
    audit = AuditLogger(os.environ.get("SIFTPP_AUDIT_LOG", "analysis/audit.jsonl"))
    runner = VolatilityRunner(
        guard=EvidenceGuard.open(evidence),
        audit=audit,
        agent=os.environ.get("SIFTPP_AGENT", "investigator"),
        offline=os.environ.get("SIFTPP_VOL_OFFLINE") == "1",
    )
    runner.session_start()
    return runner


def get_runner() -> VolatilityRunner:
    global _runner
    if _runner is None:
        _runner = _build_runner()
    return _runner
```
