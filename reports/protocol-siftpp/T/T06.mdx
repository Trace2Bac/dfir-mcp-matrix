# T06 실행 환경정보 표시

### 미구현

**판단.** 서버는 Volatility 3으로 결과를 내지만 응답, 호출 기록 어디에도 Volatility나 심볼의 버전을 싣지 않는다.
Volatility 도구의 응답과 `tool_call` 기록에는 실행한 인자 배열이 있어 `vol` 실행 파일의 경로는 보이지만 버전은 없다 [1][2].
`vol_info`가 출력하는 심볼 파일 위치 `Symbols` 같은 값은 플러그인 출력 본문으로 `result`에 실릴 뿐 서버가 읽어 따로 싣지 않는다 [1][3].
Volatility가 실패하면 표준 오류 끝 2,000자를 `stderr`에 싣는다 [1].
실행 확인에서 이 글은 `Volatility 3 Framework 2.28.0` 줄로 시작했다 [4].
이 줄은 도구 출력 본문이고 실패한 호출에만 나타난다 [1][4].

서버 자신의 버전도 싣지 않는다.
서버는 FastMCP를 이름만 주어 만들고 MCP Python SDK 1.27.2는 버전이 없으면 초기화 응답 `serverInfo.version`에 `mcp` 패키지의 버전을 넣는다 [5][6].
그래서 `serverInfo.version`은 `pyproject.toml`의 서버 버전 0.1.0이 아니라 `1.27.2`다 [4][7].

서버는 모델을 부르지 않는다.
클라이언트 `siftpp-investigate`의 호출 기록 `model_call`에는 정지 사유와 토큰 수만 있고 모델 이름은 없다 [8].
