# T10 도구 명세 구성

### T10.01 처리 함수에서 명세 생성

**구현.** 서버는 도구 함수 11개에 `@mcp.tool()`만 붙이고 이름, 설명, 입력 schema를 따로 적지 않는다 [1].
MCP Python SDK 1.27.2의 FastMCP는 함수 이름을 도구 이름으로, docstring을 설명으로, 함수 서명을 입력 schema로 쓴다 [2].
그래서 `vol_dlllist`·`vol_malfind`만 선택 인자 `pid`(정수 또는 `null`)를 알리고 나머지 9개는 인자가 없는 schema를 알린다 [3].
반환형이 `str`이라 FastMCP는 모든 도구에 `result` 문자열 하나를 담는 출력 schema를 붙이고 응답의 `structuredContent`에 같은 JSON 글을 `result`로 한 번 더 싣는다 [3][4].
annotation과 서버 지침은 없고 `tools/list_changed`도 알리지 않는다 [3].
실행 설정이나 클라이언트에 따라 명세를 바꾸는 코드는 없다 [1].

`evidence_metadata`의 응답은 플러그인 정의 `READ_ONLY_PLUGINS`의 `summary`로 도구 9개를 다시 설명한다 [5].
이 요약은 docstring과 따로 적은 문장이라 두 설명의 글이 다르지만 플러그인과 동작은 같다 [1][5].
이 요약은 도구 목록 명세가 아니라 도구 응답이다.

**한계.** `evidence_metadata`의 설명은 응답의 해시를 "acquisition sha256 (chain of custody)"라 부르고 `verify_evidence_integrity`의 설명은 증거가 "acquisition" 때와 같은지 확인한다고 적는다 [6].
실제 기준값은 증거를 수집할 때의 해시가 아니라 이 서버 프로세스가 처음 증거를 열 때 계산한 해시다 [7].
서버를 시작하기 전이나 서버를 다시 시작하는 사이에 증거가 바뀌었으면 이 도구는 바뀐 파일을 기준으로 `unchanged: true`를 돌려준다 [8].
서버 프로세스에서 처음 부른 도구가 `verify_evidence_integrity`이면 이 도구는 같은 호출 안에서 잇달아 계산한 두 해시를 비교한다 [9].

`vol_malfind`의 도구 설명은 결과를 "private RWX, no file backing" 영역이라고 적지만 Volatility 3 2.28.0의 `windows.malware.malfind`는 쓰기 권한이 없는 실행 영역과 비공개 메모리가 아닌 매핑 영역도 결과에 싣는다 [10][11].

```python
@mcp.tool()
def evidence_metadata() -> str:
    """Evidence path, size, acquisition sha256 (chain of custody), and the list
    of available read-only tools. Call this first."""
    r = get_runner()
    return _dump({
        "path": str(r.guard.path),
        "sha256": r.guard.sha256,
        "bytes": r.guard.size,
        "read_only": True,

    })
```

```python
    @classmethod
    def open(cls, path: str | Path) -> "EvidenceGuard":
        p = Path(path)
        if not p.is_file():
            raise FileNotFoundError(f"Evidence file not found: {p}")
        g = cls(path=p)
        st = p.stat()
        g.size = st.st_size
        g._mtime_ns = st.st_mtime_ns
        g.sha256 = g.full_sha256()  # acquisition hash (chain of custody)
        return g
```
