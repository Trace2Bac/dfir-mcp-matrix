# T03 실행 조건 확인

### 미구현

**판단.** 서버에는 도구 인자 밖의 조건으로 호출을 막거나 미루는 코드가 없다.
도구 함수는 실행기를 얻은 뒤 바로 Volatility를 실행하거나 증거 정보를 돌려준다 [1].
앞선 호출의 결과, 조사 단계, 승인, 자원 사용률을 보는 곳이 없다 [1][2].
`evidence_metadata`를 먼저, `verify_evidence_integrity`를 마지막에 부르라는 순서는 도구 설명에만 있다 [3].
서버는 stdio 서버로 실행되어 원격 MCP 연결을 받지 않으므로 T03.09·T03.10은 해당하지 않는다.

증거 파일의 크기나 수정 시각이 바뀌면 Volatility 도구가 거부되지만 이 조건은 인자 밖 조건이 아니라 증거 무결성 대조다.

동시 실행 수를 정하는 장치도 없다.
다만 도구 함수가 모두 동기 함수라서 MCP Python SDK 1.27.2의 FastMCP는 이벤트 루프에서 함수를 바로 부른다 [4].
한 호출이 끝날 때까지 다른 요청을 처리하지 못하므로 도구 호출은 하나씩 차례로 실행된다 [4][5].
이는 서버가 정한 제한이 아니라 SDK가 동기 함수를 부르는 방식에서 생기는 동작이라 T03.12에 연결하지 않는다.
