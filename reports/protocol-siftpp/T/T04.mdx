# T04 실행 방식

### T04.02 같은 권한의 별도 프로세스

**구현.** Volatility 도구 9개는 `subprocess.run`에 인자 배열을 넘겨 Volatility 3의 `vol`을 자식 프로세스로 실행한다 [1].
셸을 거치지 않고 표준 입력은 `DEVNULL`로 막으며 표준 출력과 표준 오류를 받는다 [1].
자식 프로세스는 서버와 같은 계정, 파일, 네트워크 권한으로 실행된다.
작업 폴더(`cwd`)를 따로 정하지 않으므로 서버 프로세스의 작업 폴더에서 실행된다 [1].

`evidence_metadata`는 분석을 실행하지 않고 보관한 값을 돌려준다 [2].
`verify_evidence_integrity`는 서버 프로세스 안에서 `hashlib`으로 증거를 해시한다 [3].
Dockerfile은 서버와 Volatility를 한 컨테이너의 같은 가상 환경에 설치하고 컨테이너 안에서 둘을 나누지 않는다 [4].

        h = hashlib.sha256()
        with self.path.open("rb") as fh:
