# L01 기록 방식

### L01.08 도구별 기록 호출

**구현.** 이 방식은 `verify_evidence_integrity`에 적용된다 [1].
이 도구는 실행기의 `verify_integrity`를 부르고 이 함수가 증거 해시를 다시 계산한 뒤 `evidence_integrity` 항목을 쓴다 [1][2].

**예외.** 첫 호출에서 실행기를 만들지 못하거나 해시를 다시 계산하다 증거 파일을 읽지 못하면 항목 없이 호출이 끝난다 [3][2].

### L01.09 실행기 안 기록

**구현.** Volatility 도구 9개는 실행기 `VolatilityRunner.run`이 `vol`을 실행한 뒤 호출마다 `tool_call` 항목을 쓴다 [4].
실행기를 처음 만들 때는 증거를 연 사실을 `evidence_opened` 항목으로 쓴다 [3].
항목은 기록 객체 `AuditLogger`가 환경변수 `SIFTPP_AUDIT_LOG`의 JSONL 파일에 덧붙인다 [5].
시간 초과로 끊긴 실행과 종료 코드가 0이 아닌 실행도 항목이 남는다 [4].

**예외.** `evidence_metadata`는 실행기를 거치지 않고 보관한 값을 돌려주므로 호출 항목이 남지 않는다 [6].
첫 호출이면 실행기를 만들면서 `evidence_opened`만 남는다 [3][6].
실행기가 항목을 쓰기 전에 예외를 내면 그 호출은 기록되지 않는다 [4].
그런 경우는 `pid` 거부, `vol` 부재, Volatility 실행 전후의 증거 크기·수정 시각 변경, `subprocess.run` 자체의 `OSError`다 [4].
첫 호출에서 증거가 설정되지 않았거나 증거 파일이 없어 실행기를 만들지 못한 호출도 기록되지 않는다 [3].
실행 뒤의 비교에서 증거 변경이 드러나면 Volatility는 이미 실행되었지만 항목이 남지 않는다 [4].
등록하지 않은 도구 이름은 FastMCP가 처리기를 부르기 전에 거부하므로 기록되지 않는다 [7].

### L01.10 클라이언트의 MCP 호출 기록

**구현.** 이 방식은 저장소의 클라이언트 `siftpp-investigate`가 `_exec_mcp`를 통해 서버 도구를 부를 때 적용된다 [8].
클라이언트는 출력 폴더의 `audit.jsonl`에 MCP 도구 이름을 담은 `tool_call` 항목을 서버 기록 `mcp-server.jsonl`과 별도로 남긴다 [9][8].
호출한 역할은 `agent`에 적는다 [8].
서버가 거부하여 서버 기록에 남지 않은 호출도 오류 응답이 값으로 돌아오면 클라이언트 기록에 남는다 [10][8].
서버 기록과 클라이언트 기록은 서로의 항목 ID나 해시를 참조하지 않는다 [9][5].
이것은 MCP 호출을 별도로 기록하는 방식이며 기록의 내용·위변조 방지는 L02~L04에서 평가하지 않는다.
다른 MCP 클라이언트로 붙으면 이 기록은 생기지 않는다.

모델 호출, 클라이언트 자체 발견사항·검토 제출, 역할 사이 메시지와 조사 시작·끝도 같은 파일에 남지만 L01.10의 연결 근거는 아니다 [11][12].

**예외.** 같은 클라이언트가 조사 시작에 직접 부르는 `evidence_metadata`와 끝에 부르는 `verify_evidence_integrity`는 도구 이름을 가진 호출 항목으로 기록하지 않는다 [12].
그 결과 일부는 `run_start`·`run_end`에 남지만 어느 MCP 도구를 호출했는지는 기록하지 않는다 [12].
`_exec_mcp`에서 `mcp.call`이 예외를 내면 도구 호출 항목 없이 오류 문구만 모델에게 돌려준다 [8].

        """Re-hash the FULL evidence file and prove it equals acquisition.

    def log(self, event: str, **fields: Any) -> dict[str, Any]:
        with self._lock:
            self._seq += 1
            record: dict[str, Any] = {
                "seq": self._seq,
                "ts": datetime.now(timezone.utc).isoformat(),
                "event": event,
                **fields,
                "prev_hash": self._prev_hash,

            record["hash"] = sha256_hex(self._prev_hash + _canonical(record))
            self._prev_hash = record["hash"]

            if self._echo:
                self._echo_line(record)
            return record

    async def call(self, name: str, arguments: dict[str, Any] | None = None) -> dict[str, Any]:
        assert self.session is not None, "session not started"
        result = await self.session.call_tool(name, arguments or {})
        text = "".join(getattr(c, "text", "") for c in result.content)
        try:
            return json.loads(text)
        except (json.JSONDecodeError, ValueError):
            return {"result_text": text, "exit_code": 1 if result.isError else 0}
