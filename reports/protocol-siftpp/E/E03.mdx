# E03 원본 변경 방지

### E03.02 서버 코드의 원본 쓰기 제한

**구현.** 이 방식은 서버 코드가 증거를 읽으려고 여는 `EvidenceGuard.full_sha256`에 적용된다 [1].
서버 코드가 증거를 읽으려고 여는 곳은 SHA-256을 계산하는 이 함수 하나이고 `rb` 모드로 연다 [1].
이 함수는 처음 증거를 열 때와 `verify_evidence_integrity`에서 불린다 [2][3].
나머지는 `stat`으로 크기와 수정 시각을 읽는다 [2][4].
서버 코드가 쓰기 모드로 여는 파일은 호출 기록뿐이다 [5].
등록한 도구 가운데 파일을 쓰거나 지우는 도구는 없다 [6].

호출 기록을 쓰는 경로에는 원본 쓰기를 막는 장치가 없다.
서버는 `SIFTPP_AUDIT_LOG`가 `SIFTPP_EVIDENCE`와 같은 파일인지 확인하지 않는다 [7].
두 값이 같은 파일을 가리키면 호출 기록 객체 `AuditLogger`는 증거 파일을 덧붙이기 모드로 연다 [8].
`AuditLogger`는 파일이 이미 있으면 먼저 UTF-8 글로 읽고 마지막 줄을 JSON으로 읽는다 [9].
그래서 UTF-8로 읽을 수 없는 바이트가 든 일반 메모리 이미지에서는 이 단계에서 예외가 나고 아무것도 쓰지 않는다 [9].
빈 파일이나 마지막 줄이 JSON 객체인 글 파일이면 서버는 기준 해시를 계산한 뒤 `evidence_opened` 항목을 증거 파일에 덧붙인다 [7][10].

### E03.03 외부 도구·플랫폼에 위임

**구현.** Volatility 도구 9개는 증거 파일을 외부 도구 Volatility 3에 넘겨 읽게 하고 원본 보호를 Volatility의 동작에 맡긴다 [11].
서버는 실행 파일, 출력 형식, 증거 경로, 플러그인 이름을 인자 배열에 고정하고 모델은 `vol_dlllist`·`vol_malfind`의 `pid`만 정한다 [11].
`pid`는 0 이상의 정수만 받아 `--pid` 뒤에 들어가므로 Volatility 옵션으로 읽힐 값을 넘길 수 없다 [11].
플러그인 목록에는 파일을 쓰는 `windows.dumpfiles`·`windows.memmap --dump`·`*.procdump`가 없다 [12].
목록 안의 `windows.pslist`·`windows.psscan`·`windows.dlllist`·`windows.malfind`에도 파일을 쓰는 `--dump` 옵션이 있지만 서버는 이 옵션을 넘기지 않는다 [11][13].

Volatility 3 2.28.0의 `FileLayer`는 증거 파일을 늘 `rb` 모드로 연다 [14].
Volatility는 심볼 캐시를 증거 옆이 아니라 자기 캐시 폴더에 쓴다 [15].
증거 파일에 쓰기 권한을 막는 마운트나 파일 권한 설정은 저장소에 없다.
`evidence_metadata` 응답의 `read_only`는 서버 코드에 적은 상수 `True`이고 서버는 이 값을 싣기 전에 증거 파일의 권한이나 마운트를 확인하지 않는다 [16].

    def full_sha256(self) -> str:
        h = hashlib.sha256()
        with self.path.open("rb") as fh:
            for chunk in iter(lambda: fh.read(1 << 20), b""):
                h.update(chunk)

    def open(cls, path: str | Path) -> "EvidenceGuard":
        p = Path(path)
        if not p.is_file():
            raise FileNotFoundError(f"Evidence file not found: {p}")
        g = cls(path=p)
        st = p.stat()
        g.size = st.st_size
        g._mtime_ns = st.st_mtime_ns
        g.sha256 = g.full_sha256()  # acquisition hash (chain of custody)

        with self._lock:

    def _resume(self) -> None:
        """Continue an existing log's chain instead of restarting it."""
        last = None
        with self.path.open("r", encoding="utf-8") as fh:
            for line in fh:
                line = line.strip()
                if line:
                    last = line
        if last:
            rec = json.loads(last)
            self._seq = int(rec.get("seq", 0))
            self._prev_hash = rec.get("hash", _GENESIS)

        spec = _BY_TOOL.get(tool)
        if spec is None:
            # Architectural guard: only curated read-only tools may run.
