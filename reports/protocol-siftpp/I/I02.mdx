# I02 분석 도구 통신 차단

### I02.01 오프라인 옵션

**구현.** 환경변수 `SIFTPP_VOL_OFFLINE`이 `1`이면 서버는 Volatility 도구 9개의 인자 배열에 `--offline`을 넣는다 [1][2].
Volatility 3 2.28.0의 `--offline`은 전역 값 `OFFLINE`을 켠다 [3].
이 값이 켜지면 Volatility가 URL을 열 때 쓰는 처리기가 http·https 요청을 `OfflineException`으로 막는다 [4].
그래서 맞는 심볼이 없을 때 Microsoft 심볼 서버(`http://msdl.microsoft.com/download/symbols`)에서 PDB를 받는 요청도 막힌다 [4][5].
원격 심볼 목록 조회도 `OFFLINE`이 꺼져 있고 원격 목록 주소가 정해졌을 때만 일어난다 [6].
서버는 원격 목록 주소를 정하는 `-u`를 넘기지 않는다 [1].

`siftpp-investigate`는 `--offline`을 주었을 때만 이 환경변수를 서버에 넘긴다 [7].
`siftpp-spoliation-test`와 `siftpp-verify`·`siftpp-gui`의 공격 시험은 늘 이 값을 넘긴다 [8].

**한계.** 이 환경변수가 없으면 `--offline`을 넣지 않으므로 Volatility는 심볼을 찾지 못할 때 Microsoft 심볼 서버에 접속한다 [1][5].
`siftpp-investigate`의 `--offline`은 기본값이 거짓이다 [7].
서버 단독 실행(`siftpp-mcp`)도 이 환경변수를 정하지 않으면 온라인으로 실행한다 [2].
Volatility 3 2.28.0은 사용자 설정 폴더의 `vol.json`을 읽어 그 값을 인자 기본값으로 쓴다 [9].
그래서 `--offline`이 없으면 이 파일의 `remote_isf_url`로도 원격 심볼 목록 조회가 켜진다 [9][6].
`--offline`을 주면 이 값보다 먼저 적용되어 원격 목록 주소를 정하지 않는다 [3].
분석 도구 프로세스의 네트워크를 끊는 다른 장치는 저장소에 없다.
