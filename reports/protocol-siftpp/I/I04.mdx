# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다(I01).
서버 코드가 읽는 환경변수는 증거 경로, 호출 기록 경로, 에이전트 이름, 오프라인 여부와 기록을 표준 오류에도 출력할지 정하는 `SIFTPP_ECHO`뿐이다 [1][2].

자격증명은 클라이언트 `siftpp-investigate`가 모델 API에 접속할 때 쓴다 [3].
DeepSeek 키는 환경변수 `DEEPSEEK_API_KEY`에서, Anthropic 자격증명은 Anthropic SDK의 기본 경로(`ANTHROPIC_API_KEY` 등)에서 읽는다 [3].
클라이언트는 작업 폴더의 `.env`가 있으면 그 값을 아직 없는 환경변수로 넣는다 [4].
클라이언트는 서버를 실행할 때 자기 환경변수 전체를 서버 프로세스에 넘기므로 이 키도 서버와 Volatility 프로세스의 환경에 들어간다 [5].
Volatility 3 2.28.0 패키지 코드가 읽는 환경변수는 캐시와 설정 파일의 위치를 정하는 `XDG_CACHE_HOME`·`APPDATA`뿐이다 [6].
그래서 서버 코드와 Volatility는 이 키를 읽지 않는다 [1][6].

```python
def _load_dotenv(path: Path = Path(".env")) -> None:
    """Load simple KEY=VALUE pairs from an ignored local .env file."""
    if not path.is_file():
        return
    for raw in path.read_text(encoding="utf-8").splitlines():
        line = raw.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        key, value = line.split("=", 1)
        key = key.strip().lstrip("\ufeff")
        value = value.strip().strip("\"'")
        if key and key not in os.environ:
            os.environ[key] = value
```

        "SIFTPP_EVIDENCE": str(evidence),
        "SIFTPP_AUDIT_LOG": str(server_audit),
