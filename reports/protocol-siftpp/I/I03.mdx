# I03 외부 전송 범위 구성

### 비적용

**판단.** 서버 코드는 외부 서비스에 연결하지 않으므로 조사 자료를 보내지 않는다.
Volatility가 Microsoft 심볼 서버에 보내는 요청은 PDB 이름과 GUID로 만든 주소이고 서버 코드가 아니라 분석 도구가 여는 통신이다 [1].

클라이언트 `siftpp-investigate`는 서버 도구 응답 글을 40,000자까지 잘라 모델 API에 그대로 보낸다 [2].
이 응답에는 Volatility가 증거에서 읽은 프로세스 명령줄, 서비스 경로, 메모리 hexdump가 들어 있다.
보내기 전에 값을 고르거나 가리는 처리는 없다 [2].
모델 API는 사용자가 고른 Anthropic이나 DeepSeek이다.

### 근거

[1] Volatility 3 2.28.0이 PDB 주소를 만드는 곳이다: [`volatility3/framework/symbols/windows/pdbconv.py:944-972`](https://github.com/volatilityfoundation/volatility3/blob/d61335e2a54961bfd619fe6cd7f7b27f01481604/volatility3/framework/symbols/windows/pdbconv.py#L944-L972).
