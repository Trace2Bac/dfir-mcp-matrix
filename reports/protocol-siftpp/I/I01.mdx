# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 스스로 외부에 연결하지 않는다.
`src/protocol_siftpp/mcp_server/`와 서버가 쓰는 `audit.py`·`schema.py`는 네트워크 라이브러리를 불러오지 않는다 [1].
서버가 하는 일은 stdio로 MCP 요청을 받고 Volatility를 자식 프로세스로 실행하고 호출 기록 파일을 쓰는 것이다 [2][3].

외부 연결은 서버 밖의 클라이언트와 사용자 CLI에 있다.
`siftpp-investigate`는 Anthropic API나 DeepSeek의 Anthropic 호환 주소 `https://api.deepseek.com/anthropic`에 모델 요청을 보낸다 [4].
`siftpp-download-case`는 SANS 사례 압축 파일을 코드에 적은 Egnyte 주소에서 내려받는다 [5].
`siftpp-gui`는 기본값 `127.0.0.1:8732`에서 웹 요청을 받는다 [6].
