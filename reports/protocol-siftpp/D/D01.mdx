# D01 파생물 보관

### 미구현

**판단.** 서버는 Volatility 출력을 응답으로 돌려주기만 하고 파일이나 DB에 남기지 않는다.
실행기는 표준 출력을 메모리에서 해시하고 잘라 응답에 담은 뒤 버린다 [1].
서버 기록에는 출력의 SHA-256과 바이트 수만 남고 출력 자체는 남지 않는다 [2].
서버 코드가 쓰는 파일은 호출 기록 하나다 [3].
Volatility에 파일을 쓰는 `--dump` 옵션을 넘기지 않고 파일을 쓰는 플러그인도 허용 목록에 없다 [4][5].
Volatility가 자기 캐시 폴더에 쓰는 심볼 캐시는 증거에서 나온 파생물이 아니다.

그래서 잘린 결과의 나머지나 처음 실행의 출력 전체는 같은 명령을 다시 실행해야 얻는다.
클라이언트 `siftpp-investigate`는 발견사항마다 근거 도구 출력의 앞 400자와 출력 해시를 `report.json`에 남긴다 [6].
