# D03 파생물 무결성 검증

### 비적용

**판단.** 서버는 파생물을 남기지 않는다.
서버가 계산하는 해시는 증거 파일의 해시와 Volatility 표준 출력 전체의 해시 `output_sha256`이다 [1].
`output_sha256`은 응답과 호출 기록에 남지만 그 출력을 보관하지 않으므로 서버가 다시 대조할 대상이 없다 [1][2].
같은 명령을 다시 실행해 출력 해시를 비교하는 도구도 없다 [3].

클라이언트 `siftpp-investigate`는 보고서 `report.json`·`report.md`의 해시를 남기지 않는다 [4].
`siftpp-report`는 HTML 보고서에 클라이언트 기록의 해시 체인 검증 결과를 싣지만 보고서 파일 자체를 해시하지 않는다 [5].

```python
def audit_summary(audit_path: Path) -> dict[str, Any]:
    if not audit_path.is_file():
        return {}
    ok, n = verify_chain(audit_path)
    events = [json.loads(line) for line in audit_path.read_text(encoding="utf-8").splitlines() if line.strip()]
    kinds: dict[str, int] = {}
    for e in events:
        kinds[e.get("event", "?")] = kinds.get(e.get("event", "?"), 0) + 1
    return {"ok": ok, "records": n, "kinds": kinds}
```
