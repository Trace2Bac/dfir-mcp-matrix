# D07 결론 근거 검증

### 비적용

**판단.** 서버에는 발견사항이나 부재 결론을 받거나 저장하거나 보고하는 경로가 없다 [1].

근거를 검토하는 단계는 클라이언트 `siftpp-investigate`에 있다 [2].
이 단계는 클라이언트 오케스트레이터가 실행하므로 서버 구현으로 세지 않고 여기에 사실로 적는다.
클라이언트는 Investigator가 낸 발견사항마다 Skeptic 모델을 부른다 [2].
Skeptic은 서버 도구를 다시 불러 반증을 찾고 `submit_review`로 판정 `confirmed`·`inferred`·`refuted`와 확신도를 낸다 [2][3].
클라이언트는 이 판정과 확신도로 발견사항의 `status`와 `confidence`를 덮어쓴다 [2].
Skeptic이 판정을 내지 않고 차례를 끝내면 `inferred`와 원래 확신도와 0.4 가운데 작은 값으로 정한다 [2].
`refuted`이거나 확신도 0.7 미만의 `inferred`이거나 확신도가 0.5 미만이면 Investigator에게 다시 조사하게 한다 [4][5].
다시 조사할 때 원래 발견사항은 그대로 남고 새로 낸 주장이 새 발견사항으로 더해져 다시 검토를 받는다 [5].
반복 횟수 `max_iterations`에 이르면 다시 조사하지 않고 남은 발견사항을 검토한 뒤 끝낸다 [5].

클라이언트는 근거가 있는지 직접 대조하지 않는다.
`cited_tools`에 적은 도구 이름 가운데 출력 해시가 있는 호출이 없는 이름(아직 부르지 않았거나 `isError`로 끝난 호출만 있는 이름)은 알리지 않고 빠진다 [6][7].
그런 호출이 있는 도구는 그 가운데 가장 마지막 호출 하나를 근거로 붙인다 [6][7].
근거가 하나도 없는 발견사항도 그대로 받아 Skeptic에게 넘긴다 [6][8].
Skeptic에게는 근거마다 출력 앞 400자 가운데 300자만 보인다 [8].

```python
How to work:
- Independently re-run the relevant read-only tools yourself; do not trust the \

  - `inferred`   — plausible, but not directly shown by the evidence.
```

```python
    def needs_reinvestigation(self) -> bool:
        """A refuted or weakly inferred finding re-enters the Investigator."""
        if self.status == FindingStatus.refuted:
            return True
        if (
            self.status == FindingStatus.inferred
            and self.confidence < INFERRED_REINVESTIGATION_THRESHOLD
        ):
            return True
        return self.confidence < 0.5
```

```python
def render_review_request(f: Finding) -> str:
    cited = ", ".join(sorted({e.tool for e in f.evidence})) or "(none cited)"
    excerpts = "\n".join(
        f"  - {e.tool} (sha256 {e.output_sha256[:12]}…): {e.output_excerpt[:300]}"
        for e in f.evidence
    ) or "  (no evidence attached)"
    return f"""\
Finding to verify (try to refute it):
  claim: {f.claim}
  severity: {f.severity.value}
  investigator confidence: {f.confidence:.2f}
  cited tools: {cited}
Evidence the investigator attached:
{excerpts}

Re-examine the evidence yourself with the tools, then call submit_review."""
```
