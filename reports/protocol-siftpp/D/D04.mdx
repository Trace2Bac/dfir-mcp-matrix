# D04 출력 경로 제한

### 비적용

**판단.** 서버 코드가 쓰는 파일은 호출 기록 하나뿐이고 파생물을 담은 파일이나 DB는 만들지 않는다 [1].
서버는 Volatility에 파일을 쓰는 `--dump`를 넘기지 않으므로 증거에서 나온 파일이 생기지 않는다 [2].

클라이언트 `siftpp-investigate`가 쓰는 파일은 사용자 CLI의 동작이라 서버 구현으로 보지 않고 사실로 적는다 [3][4].
출력 폴더는 `--out`으로 정하고 없으면 `analysis/<사건 ID>`이며 그 안에 `audit.jsonl`·`mcp-server.jsonl`·`report.json`·`report.md`를 둔다 [3][4].
