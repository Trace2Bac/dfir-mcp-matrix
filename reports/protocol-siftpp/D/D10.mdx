# D10 산출물 식별·재생성 처리

### 비적용

**판단.** 서버 코드가 쓰는 파일은 호출 기록 하나뿐이고 파생물을 담은 파일이나 DB는 만들지 않는다 [1].

보고서 파일은 클라이언트 `siftpp-investigate`와 사용자 CLI `siftpp-report`가 쓰므로 서버 구현으로 세지 않고 사실로 적는다 [2][3][4].
`siftpp-investigate`는 `--out`과 `--case-id`가 없으면 시작한 UTC 시각으로 사건 ID를 만들고 출력 폴더 `analysis/<사건 ID>`를 실행마다 따로 둔다 [2].
그 폴더에 쓰는 보고서 이름은 `report.json`·`report.md`로 정해져 있다 [3].
같은 `--out`으로 다시 실행하면 `report.json`·`report.md`를 알리지 않고 덮어쓴다 [3].
`siftpp-report`도 `--out`이 없으면 실행 폴더의 `report.html`을 알리지 않고 덮어쓴다 [4].
