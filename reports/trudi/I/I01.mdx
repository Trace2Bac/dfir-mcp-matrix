# I01 외부 연동 대상 관리

### I01.01 명시적 설정으로 활성화

**구현.** 이 방식은 OpenAI 호환 모델 백엔드와 원격 단말 SSH 접속에 있다 [1][2].
모델 백엔드는 `reason.*` 검토 도구와 `dair.assess`가 모델을 부를 때 여는 연결이고 `misc.submit_finding`도 `reason.evaluate_finding`을 거쳐 이 연결을 쓴다 [1][3][4].
`reason.*`의 `_active_backend`는 `REASON_BACKEND`에 값이 있으면 그 값을 쓴다 [1].
값이 없으면 `ANTHROPIC_API_KEY`가 있을 때 Claude 백엔드를 고르고 `REASON_URL`이 있을 때 OpenAI 호환 백엔드를 고른다 [1].
`dair.assess`는 `DAIR_BACKEND`·`DAIR_URL`로 같은 규칙을 따른다 [3].
OpenAI 호환 백엔드는 `REASON_URL`이 비어 있으면 요청하지 않고 오류를 돌려준다 [2].
`REASON_API_KEY`가 비어 있으면 인증 헤더만 빼고 요청하므로 이 백엔드를 켜는 것은 주소 설정이다 [5].
`install.sh`가 복사해 만드는 `.env` 견본은 두 백엔드를 `claude`로 적고 OpenAI 호환 설정은 주석으로 둔다 [6].

SSH 접속은 `live.hosts`를 뺀 `live.*` 도구 12개와 대응 조치 도구 `respond.execute_action`·`respond.revert_action`에 있다 [7][8].
서버는 호스트 설정 파일 `live_hosts.json`에 등록한 호스트에만 접속하고 파일이 없거나 읽지 못하면 등록된 호스트가 없는 것으로 본다 [9].
등록 항목에 사용자나 호스트가 없거나 SSH 키 파일 경로가 항목에도 `TRUDI_LIVE_SSH_KEY`에도 없으면 `ssh`를 실행하지 않고 오류를 돌려준다 [9].

**예외.** `misc.batch_run`은 모델이 준 argv를 그대로 실행한다 [10].
그래서 모델이 이 도구로 `ssh`를 직접 부르면 `live_hosts.json` 등록과 키 파일 설정 없이 SSH 연결이 생긴다 [10].

### I01.02 자격증명 존재로 활성화

**구현.** 이 방식은 VirusTotal·AbuseIPDB 조회 도구, Claude 모델 백엔드, Velociraptor 연동에 있다 [11][12][13].
`enrich.vt_lookup_hash`·`enrich.vt_lookup_ip`·`enrich.vt_lookup_domain`은 `VIRUSTOTAL_API_KEY`가, `enrich.abuseipdb_check`는 `ABUSEIPDB_API_KEY`가 비어 있으면 요청하지 않고 키가 없다는 결과를 돌려준다 [11].
두 키는 모듈을 불러올 때 한 번 읽으므로 값을 바꾸면 서버를 다시 시작해야 한다 [11].
`server.py`는 도구 모듈을 불러오기 전에 `load_dotenv()`로 `.env`를 읽는다 [14].
Claude 백엔드는 `ANTHROPIC_API_KEY`가 비어 있으면 요청하지 않고 오류를 돌려준다 [12].
`.env` 견본은 `REASON_BACKEND`·`DAIR_BACKEND`를 `claude`로 두므로 견본대로 설치하면 이 키가 모델 호출을 켜고 끈다 [6].

`velo.*` 도구와 이를 부르는 `monitor.baseline_capture`·`monitor.start_watcher`는 Velociraptor API 설정 파일이 없으면 `velociraptor`를 실행하지 않고 오류를 돌려준다 [13].
이 파일은 Velociraptor 서버가 `config api_client`로 만들어 주는 API 클라이언트 설정이고 저장소의 데모 구성은 여기에 `administrator` 역할을 붙인다 [15].
`velo.py` 설명도 이 설정을 역할이 붙은 접속 자격으로 다룬다 [16].
`monitor.start_watcher`가 시작하는 감시 프로세스도 설정 파일이 없으면 접속하지 않고 끝난다 [17].

### I01.03 기본 활성화

**구현.** 이 방식은 `enrich.machinae_lookup`에 있다 [18].
이 도구는 OSINT 조회 도구 machinae를 실행하고 machinae가 공개 사이트에 지표를 조회한다 [18].
외부 조회가 이 도구의 목적이므로 이 셀에서는 서버가 일부러 여는 외부 연결로 본다.
서버는 키나 설정을 확인하지 않고 호출마다 machinae를 실행한다 [18].
`enrich.enrichment_status`도 machinae를 키 없이 늘 쓸 수 있는 항목으로 적는다 [19].
서버에는 이 조회를 끄는 설정이 없다 [18].
machinae가 설치되어 있지 않으면 실행이 실패해 연결이 생기지 않는다.
SIFT Workstation 설치 정의 v2026.04.21은 machinae를 pip로 설치하고 `/usr/local/bin/machinae`에 링크를 둔다 [20].
어느 사이트에 조회할지는 machinae 설정이 정하고 그 내용은 I01.06에 적는다.

### I01.04 호출별 선택

**구현.** 이 방식은 `live.hosts`를 뺀 `live.*` 도구 12개에 있다 [7].
이 도구들은 호출마다 `host` 인자로 `live_hosts.json`에 등록한 호스트의 이름을 받는다 [7].
모델은 `live.hosts`로 등록된 이름 목록을 받아 그 가운데 하나를 고른다 [7].
`respond.execute_action`·`respond.revert_action`은 호스트를 인자로 받지 않고 사건 설정의 `host`나 하나뿐인 등록 호스트를 쓴다 [21].

### I01.05 고정 목적지

**구현.** 이 방식은 VirusTotal·AbuseIPDB 조회 도구 4개에 있다 [22].
VirusTotal은 `https://www.virustotal.com/api/v3/`, AbuseIPDB는 `https://api.abuseipdb.com/api/v2/check`로 시작하는 주소를 코드에 고정했다 [22].
이 주소를 바꾸는 설정·환경변수·인자는 없다 [22].
인자로 받은 해시·IP 주소·도메인은 VirusTotal 주소의 경로와 AbuseIPDB 질의 값에만 들어간다 [22].
서버는 이 값의 형식을 검사하지 않고 보내는 값은 I03에서 본다.

### I01.06 설정으로 목적지 지정

**구현.** 이 방식은 모델 백엔드, SSH 접속, Velociraptor 연동, machinae 조회에 있다 [23][24][25][26].
Claude 백엔드는 Anthropic SDK 클라이언트를 `base_url` 없이 만든다 [23].
Anthropic Python SDK 1.8.0은 이때 환경변수 `ANTHROPIC_BASE_URL`이 있으면 그 주소를, 없으면 `https://api.anthropic.com`을 쓴다 [27].
OpenAI 호환 백엔드는 `REASON_URL`(`dair.assess`는 `DAIR_URL`)에 `/v1/chat/completions`를 붙여 요청한다 [24].
두 변수가 비어 있으면 옛 이름 `FOUNDATION_SEC_URL`을 읽는다 [1][3].
모델 이름을 정하지 않았으면 같은 주소의 `/v1/models`를 먼저 조회한다 [28].

SSH 접속 대상은 `live_hosts.json` 항목의 사용자·호스트·포트가 정한다 [9].
설정 파일 위치는 `TRUDI_LIVE_HOSTS_CONFIG`가 있으면 그 경로이고 없으면 `~/cases/.common/live_hosts.json`이다 [25].

Velociraptor 도구는 `velociraptor` 실행 파일에 `--api_config`로 API 설정 파일을 넘겨 실행한다 [13].
실행 파일은 `TRUDI_VELO_BIN`, 설정 파일은 `TRUDI_VELO_API_CONFIG`가 정하고 값이 없으면 `velociraptor`와 `~/.config/trudi/velociraptor/api.config.yaml`을 쓴다 [29].
접속할 Velociraptor 서버 주소는 이 API 설정 파일에 들어 있다 [15].
`monitor.start_watcher`가 시작하는 감시 프로세스도 같은 환경변수로 실행 파일과 설정 파일을 정한다 [17].

machinae 조회에서 서버는 설정 파일을 넘기지 않고 지표와 종류만 넘긴다 [18].
machinae 1.4.11은 작업 폴더의 `machinae.yml`, `/etc/machinae.yml`, 환경변수 `MACHINAE_CONFIG`가 가리키는 파일 차례로 처음 찾은 설정을 읽고 `/etc/machinae.local.yml`·`~/.machinae.yml`을 덧씌운다 [26].
사이트를 고르는 `-s`를 주지 않으면 설정에서 `default: false`가 아닌 사이트를 모두 조회한다 [26].
SIFT 설치 정의는 machinae 저장소 기본 브랜치의 `machinae.yml`을 `/etc/machinae.yml`로 내려받는다 [20].
기준 커밋 날짜의 그 파일에는 사이트 50개가 있고 그 가운데 24개가 기본으로 켜져 있다 [30].

이 목적지를 쓰는 서버 도구는 호출 인자로 목적지를 바꾸지 못한다.

**예외.** `misc.batch_run`은 모델이 준 argv를 그대로 실행하므로 모델이 이 도구로 `ssh`를 직접 부르면 접속할 호스트를 인자로 정한다 [10].
같은 도구로 `velociraptor`에 다른 `--api_config` 파일을 넘기면 그 파일에 적힌 Velociraptor 서버로 접속한다 [10][13][15].
machinae 1.4.11은 `-c`로 받은 설정 파일을 기본 위치의 설정 파일보다 먼저 읽는다 [31].
그래서 같은 도구로 machinae에 다른 설정 파일을 넘기면 그 파일이 정한 사이트로 조회한다 [10][31].
Velociraptor와 machinae의 이 경로는 코드로만 확인했고 실행하지 않았다.

### I01.09 목적지 허용 목록

**구현.** 이 방식은 SSH 접속에 있다 [9].
`live.*`와 `respond.*`가 넘긴 호스트 이름이 `live_hosts.json`에 없으면 서버는 `ssh`를 실행하지 않고 등록된 이름 목록을 담은 오류를 돌려준다 [8][9].
코드 설명은 이 방식을 모델이 임의의 호스트로 SSH 접속하지 않게 하는 장치로 적는다 [32].
모델 백엔드 주소, Velociraptor 서버 주소, machinae 사이트에는 서버가 대조하는 허용 목록이 없다.

**예외.** `misc.batch_run`은 모델이 준 argv를 허용 목록 없이 그대로 실행한다 [10].
그래서 모델이 이 도구로 `ssh`를 직접 부르면 `live_hosts.json`에 없는 호스트에도 접속할 수 있다 [10].
`live.*`와 `respond.*`는 호출할 때마다 `live_hosts.json`을 다시 읽는다 [9][25].
그래서 모델이 같은 도구로 이 파일에 항목을 써 넣으면 허용 목록 자체가 바뀐다 [10][9].
curl 같은 다른 프로그램이 여는 통신은 I02에서 본다.

def live_hosts() -> dict:
    """List configured live endpoints.

    hosts = list_configured_hosts()

@mcp.tool()
@output_safe
def live_processes(host: str) -> dict:
    """Snapshot the full process list on a live endpoint.

    Returns: ps -eo pid,ppid,user,etimes,start,cmd output. Use as the live

def _load_hosts(path: Optional[str] = None) -> dict:
    # Resolve LIVE_HOSTS_CONFIG at call time (not def time) so monkeypatch in
    # tests + runtime env changes both take effect.
    if path is None:
        path = LIVE_HOSTS_CONFIG
    if not os.path.exists(path):
        return {}
    try:
        with open(path) as f:
            return json.load(f) or {}
    except (OSError, json.JSONDecodeError, ValueError):
        return {}


def _resolve_host(host: str) -> dict:
    hosts = _load_hosts()
    cfg = hosts.get(host)
    if not cfg:
        raise SSHConfigError(
            f"host {host!r} not found in {LIVE_HOSTS_CONFIG}. "
            f"Available: {sorted(hosts.keys()) or '(none configured)'}"
        )
    if not cfg.get("user") or not cfg.get("host"):
        raise SSHConfigError(
            f"host {host!r} config is missing required keys (user, host)"
        )
    identity = cfg.get("identity") or os.environ.get("TRUDI_LIVE_SSH_KEY")
    if not identity:
        raise SSHConfigError(
            f"host {host!r}: no identity file in config and TRUDI_LIVE_SSH_KEY env unset"
        )
    return {
        "user": cfg["user"],
        "host": cfg["host"],
        "port": int(cfg.get("port") or 22),
        "identity": os.path.expanduser(identity),
    }
