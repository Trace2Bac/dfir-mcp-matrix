# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 증거에서 나온 비밀 값을 응답·호출 기록·보고서에 싣고 그 값을 가리거나 빼는 처리를 두지 않는다.

응답에서는 자격증명을 꺼내는 도구가 꺼낸 값을 그대로 돌려준다.
`vol.hashdump`·`vol.cachedump`·`vol.lsadump`는 메모리 이미지에서 NTLM 해시, 캐시된 도메인 자격증명, LSA secret을 꺼내는 Volatility 플러그인을 실행한다 [1].
세 도구는 실행기 결과를 그대로 돌려주고 실행기는 도구의 표준 출력을 `stdout`에 싣는다 [1][2].
`net.http_session_inventory`는 패킷 캡처에서 찾은 `Authorization` 헤더 값과 쿠키 값을 세션마다 `auth_headers`·`cookies`에 싣는다 [3].
`misc.cs_beacon_config`는 비컨 설정을 모두 풀어 `settings`에 담고 응답의 `matches`에 싣는다 [4][5].
이 설정 이름에는 `SSH_Password_Plaintext`·`Proxy_User`·`Proxy_Password`가 있다 [4].

증거에서 찾아 인자로 다시 넘긴 비밀번호도 가리지 않는다.
`img.bde_mount`는 BitLocker 복구 비밀번호를 `bdemount`의 `-r` 인자로 넣는다 [6].
실행기는 인자를 공백으로 이은 명령 줄을 결과의 `cmd`에 싣고 호출 기록 항목에도 그대로 적는다 [2][7].

기록에서는 실행기가 표준 출력 앞 600자를 호출 기록의 `stdout_excerpt`에 남기고 전체를 호출마다 사이드카 파일로 남긴다 [7].
그래서 위 도구가 꺼낸 해시와 비밀번호가 호출 기록과 사이드카에 그대로 남는다.
사이드카는 `analysis/` 아래 파일을 읽는 `read.output`으로 다시 읽힌다(R02.08) [8].

보고서에서는 `misc.export_execution_log`가 호출 기록 전체를 JSON으로, 항목마다 `cmd`와 출력 앞 300자를 Markdown으로 쓴다 [9].

가림 코드는 두 곳에 있지만 이 셀에 해당하지 않는다.
Velociraptor 실행기는 기록하는 명령 줄에서 `--api_config` 경로를 `<redacted>`로 바꾼다 [10].
이 값은 서버가 외부에 접속할 때 쓰는 설정이라 I04에서 본다.
미들웨어의 `_arg_shapes`는 인자 이름과 자료형만 적고 값은 적지 않는다 [11].
이 함수는 도구 예외 기록과 입력 검사 실패 문구, 백그라운드 작업 등록에만 쓰이고 비밀 값을 골라 가리는 처리가 아니다 [11].
실행기를 거치는 도구의 인자 값은 위처럼 `cmd`에 그대로 남는다 [2].

def _vol(image: str, plugin: str, extra: list[str] | None = None,
         output_dir: str | None = None, timeout: int = VOL_TIMEOUT) -> dict:
    # -o OUTPUT_DIR is a global Volatility flag — must come before the plugin name.
    # Plugin-specific args (--pid, --dump, etc.) go in extra, after the plugin.
    if output_dir:
        os.makedirs(output_dir, exist_ok=True)   # Volatility refuses a missing -o dir
    out_flags = ["-o", output_dir] if output_dir else []
    cmd = [VOL, "-s", vol3_symbols()] + out_flags + ["-f", image, "-r", "json", plugin] + (extra or [])
    return run(cmd, timeout=timeout)

```python
def _arg_shapes(args: dict | None) -> str:
    """Argument NAMES and python types — never values — so a validation
    failure is diagnosable from the trace (which field, which type)."""
    try:
        return ", ".join(f"{k}:{type(v).__name__}" for k, v in (args or {}).items()
                         if not str(k).startswith("_"))[:400]
    except Exception:
        return ""
```
