# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 실행기 `run`의 결과를 그대로 돌려주는 도구는 외부 도구가 출력한 시각 문자열을 바꾸지 않고 `stdout`에 싣는다 [1].
서버는 일부 도구에서 외부 도구가 시각을 출력하는 방식을 환경변수나 인자로 정한다.
TSK 도구 일부는 `env TZ=UTC`를 앞에 붙여 실행하고 `tsk.mactime`은 `-z UTC`를 넘긴다 [2].
`net.pcap_identity_timeline`은 tcpdump `-tttt` 출력의 시각 문자열을 그대로 `timestamp`에 둔다 [3].

서버가 시각을 다시 만드는 도구는 원래 값을 버린다.
`misc.chat_db_export`는 Skype·WhatsApp의 Unix 시각을 초 단위 UTC ISO 문자열로 바꾸고 원래 정수는 싣지 않는다 [4].
WhatsApp 시각은 밀리초 값을 1000으로 나눈 몫으로 바꿔 밀리초를 버린다 [4].
`ez.pecmd`의 libscca 대체 파서는 실행 시각을 ISO 문자열로 바꿔 CSV에 쓰고 원래 FILETIME 값은 쓰지 않는다 [5].
`af.timestomp_drift`는 MFTECmd CSV의 시각을 `datetime`으로 파싱한 뒤 `isoformat()`으로 다시 적는다 [6][7].
`misc.device_install_inventory`는 setupapi.dev.log의 시각을 초 단위까지만 남기고 `/`를 `-`로 바꾼다 [8].
이 도구들은 바꾼 값과 원래 값을 함께 싣지 않아 R08.02에는 연결하지 않는다.

### R08.03 시간대·단위·정밀도 표시

**구현.** `misc.chat_db_export`는 바꾼 시각을 `ts_utc`·`start_utc`·`finish_utc` 필드에 두고 값 끝에 `+00:00`을 붙인다 [4][9].
`ez.pecmd`의 libscca 대체 파서는 시간대 정보가 없는 시각에 UTC를 붙여 `+00:00`이 든 ISO 문자열로 쓴다 [5].

서버가 만든 다른 시각에는 시간대 표기가 없다.
`af.timestomp_drift`는 CSV 값에 시간대 표기가 없으면 시간대 없는 `isoformat()` 값을 `si_ts`·`fn_ts`에 적는다 [7][6].
서버 지침은 시각이 늘 UTC라고 적지만 이 문장은 응답 값의 표시가 아니므로 이 상세의 구현으로 세지 않는다 [10].

**한계.** `misc.device_install_inventory`의 `first_seen`·`last_seen`·`coverage_window`에는 시간대가 없고 코드 주석은 이 값을 로그의 현지 시각이라고 적는다 [8][11].
서버 지침이 시각은 늘 UTC라고 적으므로 이 값은 UTC로 잘못 읽힌다 [10].

```python
def _utc(ts) -> str:
    """Unix seconds → UTC ISO string; '' on anything unparseable."""
    try:
        return datetime.fromtimestamp(
            int(ts), tz=timezone.utc).isoformat(timespec="seconds")
    except (TypeError, ValueError, OSError, OverflowError):
        return ""
```

```python
def _parse_iso(ts: str) -> Optional[datetime.datetime]:
    """Parse an MFTECmd / EvtxECmd ISO-ish timestamp. Returns None on failure."""
    if not ts:
        return None
    s = str(ts).strip().replace("Z", "+00:00")
    for fmt in (None, "%Y-%m-%d %H:%M:%S.%f", "%Y-%m-%d %H:%M:%S"):
        try:
            if fmt is None:
                return datetime.datetime.fromisoformat(s)
            return datetime.datetime.strptime(s, fmt)
        except (ValueError, TypeError):
            continue
    return None
```
