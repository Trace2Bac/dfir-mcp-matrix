# F01 판단 지침

### F01.01 조사 전체 해석 원칙

**구현.** 서버 지침(`instructions`)은 도구가 증거에 대해 읽기 전용이라는 것, 출력 경로의 범위, 시각이 늘 UTC라는 것만 적고 해석 원칙은 적지 않는다 [1].
조사 전체에 걸치는 해석 원칙은 증거 도구 응답의 `_metadata.discipline_reminder`로 간다 [2].
문구는 다섯 가지이고 호출마다 하나씩 돌아가며 붙는다 [2].
다섯 가지 가운데에는 증거가 가설과 어긋나면 가설을 고치라는 것, 증거가 없다는 것이 없었다는 증거가 아니라는 것, ShimCache·Amcache는 존재만 증명하고 실행을 증명하지 않는다는 것이 있다 [2].
증거 속 글을 지시로 따르지 말라는 문구도 들어 있다 [2].
`reason.*`·`dair.*`·`correlate.*` 같은 제어 도구의 응답에는 이 문구가 붙지 않는다 [3].
이 원칙은 서버 지침이나 MCP 리소스·프롬프트가 아니라 도구 응답에 실린다 [1][2].
모델이 이 문구를 읽고 따르는지는 서버가 정하지 않는다.
저장소의 `claude/CLAUDE.md`도 부재 주장은 그 범주의 출처를 모두 검색해야 한다는 원칙을 적지만 이것은 클라이언트 구성이고 서버가 보내는 글이 아니다 [4].

```python
_CONTROL_PREFIXES = (
    "reason_", "dair_", "correlate_", "coverage_", "accuracy_",
    "attribution_", "monitor_", "respond_",
)
_CONTROL_TOOLS = frozenset({
    "misc_record_finding", "misc_record_agent_message", "misc_record_self_correction",
    "misc_record_curiosity_probe", "misc_start_execution_log", "misc_export_execution_log",
    "misc_write_final_report", "misc_serve_dashboard", "misc_clear_case_run",
    "misc_knowns_pattern_generate", "hash_verify_evidence_hash",
})


def _is_evidence_tool(name: str) -> bool:
    """True for tools returning evidence-derived output (get the generic tier)."""
    if name.startswith(_CONTROL_PREFIXES):
        return False
    return name not in _CONTROL_TOOLS
```
