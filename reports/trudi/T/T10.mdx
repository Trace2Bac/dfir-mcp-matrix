# T10 도구 명세 구성

### T10.01 처리 함수에서 명세 생성

**구현.** 이 방식은 `server.py`가 namespace로 붙이는 모듈 25개의 MCP 도구 모두에 적용된다 [1].
도구 함수는 `@mcp.tool()`로 등록하고 FastMCP 3.4.7이 함수 docstring을 도구 설명으로, 함수 서명을 입력 schema로 만든다 [2].
docstring에 적힌 인자 설명은 schema의 인자 설명으로 들어가고 `Context` 인자는 schema에서 빠진다 [2].
예를 들어 `vol.pslist`의 설명은 docstring 한 줄이고 입력 schema의 인자는 `image`와 `pid`다 [3].
출력 경로 인자를 검사하는 데코레이터 `output_safe`는 `@wraps`로 원래 함수를 감싸고 코드 주석은 FastMCP가 원래 서명을 읽도록 `@mcp.tool()` 아래에 두라고 적는다 [4].
그래서 명세와 처리기가 같은 함수 정의에서 나온다 [2][4].

서버 지침(`instructions`)은 증거를 읽기만 한다는 것, 출력 폴더, 시각 기준만 적는다 [5].
서버 코드는 도구 annotation, 목록 변경 알림, MCP 리소스와 프롬프트를 등록하지 않는다 [5].

**한계.** `hash.directory`의 docstring은 상한에 닿아 멈추면 돌려준 `next_start_path`를 `start_after`로 넘겨 이어 부르라고 안내한다 [6].
재귀 순회에서 이어 부르면 `next_start_path` 뒤에 순회할 하위 폴더의 파일 가운데 전체 경로 문자열이 `next_start_path`보다 작은 파일이 빠진다 [7].
`plaso.export_csv`의 설명은 `query_filter`를 추가 필터라고 적지만 코드는 `time_filter`가 있으면 `query_filter`를 넘기지 않는다 [8].
`respond.list_actions`의 설명은 모든 제안이 권고일 뿐 실행되지 않는다고 적는다 [9].
그런데 `respond.execute_action`은 같은 제안 파일의 조치를 실행한다 [9].
`carve.foremost_carve`의 설명은 함수에 없는 인자 `output_file`을 설명하고 실제 인자 `config_file`은 설명하지 않는다 [10].

### T10.04 실행 설정·클라이언트별 명세 변경

**구현.** 이 방식은 `server.py`를 직접 실행할 때 모든 도구의 설명에 적용된다 [11].
환경변수 `TRUDI_SLIM_TOOL_DESCRIPTIONS`가 `1`이면 `slim_tool_descriptions`가 하위 서버의 도구 설명을 실행 중에 바꾼다 [11][12].
설명은 첫 단락만 남기고 공백을 한 칸으로 줄인 뒤 300자를 넘으면 300자 안의 마지막 문장 끝이나 300자에서 자른다 [13].

입력 schema는 바꾸지 않는다 [12][14].
OpenCode 등록 스크립트는 OpenCode 설정의 서버 환경에 이 값을 `1`로 넣는다 [15].
코드 주석은 Claude Code에는 이 값을 켜지 않는다고 적는다 [11][14].
같은 등록 스크립트가 출력 상한 `TRUDI_OUTPUT_CAP`·`TRUDI_OUTPUT_LINE_CAP`도 함께 줄인다 [15].

**한계.** 축약은 둘째 단락부터 버리므로 그 단락에 적힌 주의와 계약이 모델에게 보이지 않는다 [13].

다섯 요약 밖에서 둘째 단락 이후에 주의나 계약을 적은 도구를 모두 세지는 않았다.

### T10.05 등록 이름 변환

**구현.** 이 방식은 `server.py`가 붙이는 모든 도구에 적용된다 [1].
FastMCP는 namespace를 주어 mount한 하위 서버의 도구 이름 앞에 `<namespace>_`를 붙인다 [17].
`normalize_tool_names_sync`는 `server.py`를 import할 때 하위 서버 도구 가운데 이름이 이미 `<namespace>_`로 시작하는 도구에서 그 접두어 하나를 뗀다 [18][19].
그래서 `tsk` namespace로 붙인 함수 `tsk_mmls`는 `tsk_tsk_mmls`가 아니라 `tsk_mmls`라는 이름으로 보인다 [19].
뗀 이름이 비거나 같은 모듈의 다른 도구 이름과 겹치면 바꾸지 않는다 [19].
이름은 첫 `list_tools` 전에 정해지고 미들웨어의 허용 목록도 바뀐 이름을 쓴다 [18][20].

```python
def output_safe(func):
    """Decorator that validates any output_* / storage_file kwarg against the
    evidence read-only policy before calling the wrapped function.

    Apply BELOW @mcp.tool() so MCP introspects the original signature:

        @mcp.tool()
        @output_safe
        def my_tool(image: str, output_dir: str) -> dict: ...
    """
    sig = inspect.signature(func)
    relevant = tuple(n for n in _OUTPUT_PARAM_NAMES if n in sig.parameters)
    if not relevant:
        return func

    @wraps(func)
    def wrapper(*args, **kwargs):
        try:
            bound = sig.bind_partial(*args, **kwargs)
        except TypeError:
            # Signature mismatch — let the wrapped function raise its own error.
            return func(*args, **kwargs)
        for name in relevant:
            value = bound.arguments.get(name)
            if value:
                assert_output_safe(value)
        return func(*args, **kwargs)

    return wrapper
```

```python
def _iter_files(directory: str, recursive: bool, start_after: str = ""):
    """Deterministic (sorted) walk so a capped run can be resumed from
    `next_start_path`. Yields absolute file paths; symlinks are not followed."""
    root = os.path.abspath(directory)
    # Hidden entries are skipped, as the previous glob("**/*") walk did.
    if not recursive:
        try:
            names = sorted(n for n in os.listdir(root) if not n.startswith("."))
        except OSError:
            return
        for n in names:
            p = os.path.join(root, n)
            if os.path.isfile(p) and not os.path.islink(p) and p > start_after:
                yield p
        return
    for dirpath, dirnames, filenames in os.walk(root, followlinks=False):
        dirnames[:] = sorted(d for d in dirnames if not d.startswith("."))
        for n in sorted(f for f in filenames if not f.startswith(".")):
            p = os.path.join(dirpath, n)
            if p <= start_after:
                continue
            if os.path.isfile(p) and not os.path.islink(p):
                yield p
```

```python
async def slim_tool_descriptions(namespaces, cap: int = CAP,
                                 overrides: dict[str, str] | None = None) -> int:
    """Rewrite every tool's description in place. Returns tools changed.

    `namespaces` is server.NAMESPACES: (namespace, child FastMCP) pairs. The
    mutation MUST happen on the child servers — the composed parent's
    get_tool() returns copies for mounted tools, so a parent-level rewrite
    does not survive to list_tools(). OVERRIDES keys use the mounted name
    (f"{namespace}_{child tool name}"). Parameter schemas are never touched;
    empty descriptions stay empty.
    """
    if overrides is None:
        overrides = OVERRIDES
    changed = 0
    for ns, child in namespaces:
        for t in await child.list_tools():
            live = await child.get_tool(t.name)
            desc = live.description or ""
            if not desc:
                continue
            mounted = f"{ns}_{t.name}"
            new = overrides.get(mounted) or slim_text(desc, cap)
            if new != desc:
                live.description = new
                changed += 1
    return changed
```

```python
    """First paragraph, whitespace-collapsed, sentence-aware cap."""
    para = desc.split("\n\n", 1)[0]
    para = _WS.sub(" ", para).strip()

    if m >= 40:
```

```python
async def normalize_tool_names(namespaces) -> int:
    """Strip one redundant ``<ns>_`` prefix from each child tool's name.

    ``namespaces`` is server.NAMESPACES: (namespace, child FastMCP) pairs.
    Mutation targets the CHILD servers (the composed parent's get_tool
    returns copies for mounted tools; mounting resolves names dynamically,
    so renaming works whether called before or after mount). Returns the
    number of tools renamed. Defensive: never renames to an empty string or
    onto an existing sibling name.
    """
    renamed = 0
    for ns, child in namespaces:
        prefix = ns + "_"
        tools = await child.list_tools()
        names = {t.name for t in tools}
        for t in tools:
            if not t.name.startswith(prefix):
                continue
            new = t.name[len(prefix):]
            if not new or new in names:
                continue
            live = await child.get_tool(t.name)
            child.local_provider.remove_tool(t.name)
            live.name = new
            child.add_tool(live)
            names.discard(t.name)
            names.add(new)
            renamed += 1
    return renamed
```
