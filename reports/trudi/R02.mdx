# R02 대량 결과 전달

### R02.01 문자·항목 상한

**구현.** 외부 도구 실행기는 표준 출력을 51,200자에서 자르고 그다음 150줄에서 자른다 [1][2].
두 상한은 운영자가 환경변수 `TRUDI_OUTPUT_CAP`·`TRUDI_OUTPUT_LINE_CAP`로 정하고 모델은 바꾸지 못한다 [1].
서버 안에서 결과 목록을 만드는 도구에는 도구별 건수 인자가 있다.
예를 들어 `evtx_filter`는 `max_results`(기본 200)에 이르면 읽기를 멈춘다 [3].

**예외.** `evtx_filter`의 `max_results`처럼 서버가 만든 목록의 상한은 모델이 인자로 올린다 [3].

### R02.02 전체·반환 건수 표시

**구현.** 줄 상한에서 자른 출력 끝에는 생략한 줄 수를 적은 꼬리말을 붙인다 [4].
`strings_grep`은 상한을 넘어서도 센 전체 일치 수 `match_count`와 돌려준 수 `returned`를 나누어 싣고 상한에 걸리면 두 수를 적은 안내를 붙인다 [5].
전체 건수와 반환 건수를 함께 싣는 도구는 일부다.

**예외.** 줄 상한 꼬리말의 생략 줄 수는 문자 상한으로 먼저 자른 뒤에 센 값이다 [2][4].
두 상한이 함께 걸리면 원래 출력의 줄 수를 알 수 없다.

### R02.03 페이지·커서 조회

**구현.** 이 방식은 `hash.directory`와 `monitor.check_alerts`에 적용된다 [6][7].
`hash.directory`는 파일 수·바이트·시간 상한에 닿으면 멈추고 마지막으로 처리한 파일 경로를 `next_start_path`로 돌려주며 그 값을 `start_after`로 넘겨 다시 부르라고 안내한다 [6].
이어 부르면 경로 문자열이 `start_after`보다 큰 파일만 처리한다 [8].
`monitor.check_alerts`는 순번이 `since_seq`보다 큰 경보를 순번 차례로 `max_alerts`(기본 50)개까지 돌려준다 [7].
경보마다 순번 `seq`가 실려 있어 마지막 경보의 순번을 다음 `since_seq`로 넘기면 이어 읽는다 [7][9].
응답에는 남은 경보가 있는지 알리는 표시가 없다 [7].
`monitor.ack_alert`는 경보 파일에 `consumed`를 쓰기만 하고 `monitor.check_alerts`는 이 값으로 경보를 거르지 않는다 [7][10].

**예외.** `hash.directory`의 재귀 순회는 폴더마다 파일을 이름순으로 내보낸 뒤 하위 폴더로 내려가지만 재개 필터는 전체 경로의 문자열 크기로 처리한 파일을 가린다 [8].
그래서 `z.txt`와 `a/one.txt`가 있는 폴더를 `max_files=1`로 해싱하면 첫 응답은 `z.txt`에서 멈추고 그 값으로 이어 부른 응답은 `a/one.txt` 없이 `truncated`가 거짓인 성공으로 끝난다 [6][8].
커서가 하위 폴더의 파일이면 경로가 커서보다 큰 상위 폴더 파일은 이어 부를 때 다시 해싱된다 [8].
`output_manifest`를 주고 이어 부르면 결과를 목록 파일 끝에 덧붙이므로 다시 해싱한 파일은 목록에 두 번 들어간다 [11].
다시 해싱하는 경로는 코드로만 확인했고 실행하지는 않았다.
도구 주석은 이어 부르면 빠지거나 겹치는 파일이 없다고 적는다 [12].

### R02.07 건수 없는 잘림 표시

**구현.** 문자 상한만 걸린 출력에는 `truncated: true`만 붙는다 [2].
실행기는 원래 길이 `_stdout_chars`를 계산하지만 호출 기록에만 쓰고 응답에서 뺀다 [13].

### R02.08 보관한 출력의 일부 재조회

**구현.** 실행기는 잘리기 전의 표준 출력 전체를 호출 기록 옆 `analysis/.tool_output/<호출 ID>.txt`에 남긴다 [14].
도구 응답에는 그 호출 ID `_trudi_call_id`가 실린다 [15].
`read.output`은 `analysis/` 아래 파일을 읽어 질의어가 많이 든 줄부터 한 번에 문자 상한(기본 51,200자)까지 돌려준다 [16].
줄 위치를 지정해 이어 읽는 인자가 없어 보관한 출력 전체를 끝까지 다시 읽지는 못한다 [16].
도구 응답은 사이드카 경로를 싣지 않고 그 경로는 저장소의 클라이언트 훅 안내 문구에 있다 [17].

**예외.** 사이드카 파일은 8,388,608자까지만 남기므로 그보다 긴 출력은 보관본도 잘린다 [14].

```python
def _apply_line_cap(text: str, max_lines: int) -> tuple[str, bool]:
    """Trim text to max_lines, appending a footer if trimmed."""
    lines = text.splitlines(keepends=True)
    if len(lines) <= max_lines:
        return text, False
    omitted = len(lines) - max_lines
    return "".join(lines[:max_lines]) + _TRUNCATION_FOOTER.format(n=omitted), True
```

```python
@mcp.tool()
@output_safe
def check_alerts(case_id: str, since_seq: int = 0, max_alerts: int = 50) -> dict:
    """Return alerts with seq > since_seq, oldest first, capped at max_alerts.

    Does NOT mark consumed — that's `ack_alert`'s job. Idempotent reads
    are useful for the /loop pattern: each tick pulls the same un-acked
    alerts until they're processed.
    """
    _ensure_layout(case_id)
    alerts_dir = _alerts_dir(case_id)
    alerts: list[dict] = []
    for path in sorted(alerts_dir.glob("*_*.json")):
        try:
            seq_str = path.stem.split("_", 1)[0]
            seq = int(seq_str)
        except (ValueError, IndexError):
            continue
        if seq <= since_seq:
            continue
        try:
            data = json.loads(path.read_text())
        except (OSError, json.JSONDecodeError):
            continue
        data["_path"] = str(path)
        alerts.append(data)
        if len(alerts) >= max_alerts:
            break
    return {"success": True, "alerts": alerts, "count": len(alerts)}
```

```python
def _iter_files(directory: str, recursive: bool, start_after: str = ""):
    """Deterministic (sorted) walk so a capped run can be resumed from
    `next_start_path`. Yields absolute file paths; symlinks are not followed."""
    root = os.path.abspath(directory)
    # Hidden entries are skipped, as the previous glob("**/*") walk did.
    if not recursive:
        try:
            names = sorted(n for n in os.listdir(root) if not n.startswith("."))
        except OSError:
            return
        for n in names:
            p = os.path.join(root, n)
            if os.path.isfile(p) and not os.path.islink(p) and p > start_after:
                yield p
        return
    for dirpath, dirnames, filenames in os.walk(root, followlinks=False):
        dirnames[:] = sorted(d for d in dirnames if not d.startswith("."))
        for n in sorted(f for f in filenames if not f.startswith(".")):
            p = os.path.join(dirpath, n)
            if p <= start_after:
                continue
            if os.path.isfile(p) and not os.path.islink(p):
                yield p
```

```python
@mcp.tool()
@output_safe
def ack_alert(case_id: str, alert_id: str) -> dict:
    """Mark an alert consumed (set consumed=true on the alert JSON)."""
    _ensure_layout(case_id)
    alerts_dir = _alerts_dir(case_id)
    for path in alerts_dir.glob("*_*.json"):
        try:
            data = json.loads(path.read_text())
        except (OSError, json.JSONDecodeError):
            continue
        if data.get("alert_id") == alert_id:
            data["consumed"] = True
            data["consumed_at_utc"] = time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime())
            path.write_text(json.dumps(data, indent=2))
            return {"success": True, "alert_id": alert_id, "path": str(path)}
    return {"success": False, "error": f"alert_id {alert_id!r} not found under {alerts_dir}"}
```
