# D01 파생물 보관

### D01.01 파생물 파일 보관

**구현.** 이 방식은 호출 기록 항목을 남기는 도구 호출의 출력 텍스트 파일과, 외부 도구나 서버 코드가 쓰기 위치에 만드는 파일에 적용된다 [1][2][3].
호출 기록 함수 `record_tool_call`은 출력 텍스트가 비어 있지 않으면 길이와 관계없이 그 텍스트를 파일로 쓰고 경로를 항목의 `stdout_path`에 넣는다 [1].
파일 위치는 호출 기록 파일과 같은 폴더의 `.tool_output/<호출 ID>.txt`이고 임시 파일에 쓴 뒤 이름을 바꾸어 만든다 [4].
외부 도구 실행기 `run`은 표준 출력 전체를 이 파일로 넘기고 모델에게 돌려주는 사본만 응답 상한으로 자른다 [5].
carve 명령을 별도 프로세스 작업으로 실행하는 `net.tcpxtract_streams`는 `misc.job_status`가 끝난 작업의 표준 출력 파일을 8 MiB까지 읽어 같은 방식으로 남긴다 [6][7].
스스로 기록하지 않는 파이썬 도구는 미들웨어가 성공 응답 JSON을 출력 텍스트로 넘겨 같은 파일에 남긴다 [8].
`read.output`은 도구가 쓴 출력 파일에서 고른 줄을 자기 호출의 `.tool_output` 파일에 남기고 읽은 파일은 그대로 둔다 [9].
이 두 경로의 파일은 분석 도구의 출력이 아니라 MCP 도구 응답의 사본이다.
`.tool_output` 파일에 남길 출력 길이의 상한은 사용자가 환경변수 `TRUDI_STDOUT_SIDECAR_CAP`로 정하고 기본값은 `8 * 1024 * 1024`다 [7].
외부 도구 실행기와 파일 쓰기 함수가 이 상한에서 출력을 자른다 [5][4].
파일 쓰기 함수는 텍스트가 상한보다 길면 항목에 `stdout_partial`을 적는다 [4][10].

`run_with_output_file`을 쓰는 도구(`tsk.icat`·`tsk.mactime`·`misc.evtx_dump` 등)는 도구의 표준 출력을 모델이 준 `output_path`에 바로 쓰고 항목의 `output_path`에 그 경로를 넣는다 [11].
이 도구들의 `.tool_output` 파일에는 출력 파일 경로를 알리는 한 줄만 남는다 [11][5].
분석 도구가 낸 원래 표준 출력 텍스트는 `run`을 거치는 도구에서는 상한까지 `.tool_output` 파일에, `run_with_output_file`을 쓰는 도구에서는 전체가 `output_path` 파일에 그대로 남는다 [5][11].
호출 기록 파일에는 항목마다 표준 출력 앞 600자와 표준 오류 앞 512자가 함께 들어간다 [12][1].
호출 기록 파일은 JSON 파일이라 D01.03에는 연결하지 않았다.

외부 도구에 쓰기 위치를 넘기는 도구와 서버 코드가 직접 파일을 쓰는 도구는 그 위치에 파일 파생물을 남긴다 [2][3].
`ez.*`는 CSV 폴더와 파일 이름을, `plaso.create_timeline`·`plaso.create_targeted`는 Plaso 저장 파일 경로를 외부 도구에 넘긴다 [2].
`carve.*`·`img.photorec_carve`·`tsk.recover`·`net.tcpxtract_streams`는 복구한 파일을 둘 폴더를, 덤프를 쓰는 `vol.*`는 `-o` 폴더를 외부 도구에 넘긴다 [2].
`plaso.export_csv`·`plaso.export_json`·`plaso.filter_incident_window`는 `psort.py`에 쓰기 위치를 넘겨 Plaso 저장 파일에서 CSV·JSON Lines 파일을 만든다 [2].
`misc.chat_db_export`·`misc.device_install_inventory`는 서버가 파싱한 결과를 CSV로, `misc.cs_beacon_config`·`net.http_session_inventory`·`misc.knowns_pattern_generate`는 JSON으로 쓴다 [3].
`misc.write_final_report`는 Markdown 보고서를, `misc.export_execution_log`는 호출 기록의 JSON·Markdown 사본을, `accuracy.export_report`는 정확도 보고서를 쓴다 [3].
서버는 이 파일들을 호출 뒤에 지우지 않는다.
파일 위치는 대부분 모델이 준 인자다.

보관 기간이나 보관 대상을 정하는 설정과 코드는 없다.
한 호출이 원래 출력과 가공본을 함께 남기는 도구는 없어 D01.04에는 연결하지 않았다.
`net.tcpdump_extract_ips`는 tcpdump 표준 출력만 `.tool_output` 파일에 남기고 그 출력에서 뽑은 IP 목록은 응답에만 싣는다 [13].
`net.http_session_inventory`·`net.pcap_identity_timeline`은 원래 출력을 지우고 `output_path`를 주었을 때만 가공본 JSON을 남긴다 [14][3].

**한계.** 출력 파일에 도구 출력 전체가 남지 않는 경로가 있다.
외부 도구 실행기는 표준 오류를 파일로 쓰지 않고 호출 기록 항목에 512자까지만 남긴다 [12].
SSH 도구와 Velociraptor 도구는 표준 출력을 51,200자와 150줄 상한으로 자른 문자열만 호출 기록 함수에 넘겨 잘린 부분은 어디에도 남지 않는다 [15][1].
`net.http_session_inventory`·`net.pcap_identity_timeline`은 tcpdump 출력을 `/tmp` 임시 파일로 받아 읽은 뒤 지운다 [14].
이 tcpdump 호출의 `.tool_output` 파일에는 지워진 임시 파일의 경로를 알리는 한 줄만 남는다 [14][11].
`misc.evtx_filter`는 찾는 이벤트 ID에 맞은 이벤트만 출력 텍스트로 남기고 이벤트마다 XML을 2,000자에서 자른다 [16].
`strings.extract`·`tsk.indxparse`·`misc.capa_analyze`·`hash.hashdeep_compute`·`hash.md5deep_scan`은 응답 상한으로 자른 표준 출력을 `output_path` 파일에 쓴다 [17][5].
앞의 세 도구는 150줄 상한까지 적용된 문자열을 쓴다 [17].

상한보다 긴 출력은 앞부분만 남는다 [5][4].
상한의 주석은 바이트라고 적지만 코드는 UTF-8로 풀어 낸 문자열의 글자 수로 자르므로 여러 바이트로 적는 글자가 많은 출력은 파일이 8 MiB보다 커진다 [7][5].
외부 도구 실행기는 파일 쓰기 함수에 넘기기 전에 이미 상한에서 자르므로 이 경로에서는 `stdout_partial`이 서지 않는다 [5][10].
같은 이유로 항목의 `stdout_chars`에는 원래 길이가 아니라 자른 뒤의 길이가 들어간다 [5][1].

```python
    def _write_sidecar_text(self, name: str, text: str) -> tuple[str | None, bool, str]:
        """Atomically write `text` to `.tool_output/<name>` (capped at
        STDOUT_SIDECAR_CAP). Returns (path, partial, error); never raises."""
        try:
            from core.paths import STDOUT_SIDECAR_CAP
            d = self.stdout_sidecar_dir()
            if not d:
                return None, False, ""
            os.makedirs(d, exist_ok=True)
            partial = len(text) > STDOUT_SIDECAR_CAP
            body = text[:STDOUT_SIDECAR_CAP]
            import tempfile
            stem = os.path.splitext(name)[0]
            fd, tmp = tempfile.mkstemp(prefix=f".{stem}-", suffix=".tmp", dir=d)
            try:
                with os.fdopen(fd, "w", encoding="utf-8", errors="replace") as fh:
                    fh.write(body)
                final = os.path.join(d, name)
                os.replace(tmp, final)
            except Exception:
                try:
                    os.unlink(tmp)
                except OSError:
                    pass
                raise
            return final, partial, ""
        except Exception as e:
            return None, False, str(e)[:200]
```

```python
def _read(path: str, cap: int = 8 * 1024 * 1024) -> str:
    try:
        with open(path, "rb") as f:
            return f.read(cap).decode("utf-8", "replace")
    except OSError:
        return ""
```

```python
        between _next_id() and _append_entry() — no lock is held across the
        write and the filename is unique per cid, so the _flush re-entrancy
        hazard does not apply. Never raises: a failed sidecar is recorded on
        the entry (`stdout_sidecar_error`) and the entry is still written."""
        final, partial, err = self._write_sidecar_text(f"{cid}.txt", text)
        if final:
            entry["stdout_path"] = final
            if partial:
                entry["stdout_partial"] = True
        elif err:
            _warn(f"stdout sidecar for call {cid} failed: {err}")
            entry["stdout_sidecar_error"] = err
```

```python
    """
    Extract all unique IP addresses from a PCAP.
    Returns sorted unique source and destination addresses.
    """
    import re
    result = run(["tcpdump", "-r", pcap_file, "-nn", "-q"], needs_sudo=True, timeout=120)
    if not result["success"]:

            "success": False,
            "pcap": pcap_file,

            "_trudi_call_id": result.get("_trudi_call_id"),

        "success": True,
        "pcap": pcap_file,
        "unique_ips": sorted(ips),
        "count": len(ips),
        "_trudi_call_id": result.get("_trudi_call_id"),
    }
```

```python
def _run_tcpdump_ascii(cmd: list[str], timeout: int) -> dict:
    """Run a large tcpdump ASCII extraction without the normal stdout cap."""
    import os
    import tempfile

    fh = tempfile.NamedTemporaryFile(
        prefix="trudi-tcpdump-", suffix=".txt", dir="/tmp", delete=False
    )
    path = fh.name
    fh.close()
    raw = run_with_output_file(cmd, output_path=path, needs_sudo=True, timeout=timeout)
    if raw.get("success"):
        try:
            with open(path, "r", encoding="utf-8", errors="replace") as f:
                raw["stdout"] = f.read()
        except OSError as e:
            raw["success"] = False
            raw["stderr"] = f"failed to read tcpdump output {path}: {e}"
    try:
        os.unlink(path)
    except OSError:
        pass
    return raw
```
