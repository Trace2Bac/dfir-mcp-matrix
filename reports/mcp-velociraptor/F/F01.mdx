# F01 판단 지침

### 미구현

**판단.** 서버는 도구 설명, 서버 지침, 리소스, 프롬프트, 응답 어디에도 조사 전체의 해석 원칙이나 결론을 서술하고 확인하는 방식을 적지 않는다.
서버는 `FastMCP("velociraptor-mcp")`로 이름만 주어 만들고 `instructions`를 넘기지 않는다 [1].
MCP Python SDK 1.28.1의 `FastMCP`는 `instructions`의 기본값이 `None`이다 [2].
서버 코드에는 `@mcp.tool()`로 등록한 도구 78개만 있고 리소스나 프롬프트를 등록하는 곳이 없다 [3].
MCP 클라이언트 세션으로 받은 `initialize` 응답의 `instructions`는 `None`이었고 리소스, 리소스 템플릿, 프롬프트 목록은 비어 있었다 [4].

도구 설명은 도구가 수집하거나 찾는 대상과 인자, 반환값을 적는다 [3].
해석에 관한 문장은 `windows_execution_shimcache` 설명의 한 곳이고 ShimCache 항목이 실제 실행을 뜻하지 않을 수 있다고 적는다 [5].
이 문장은 그 도구 결과 하나의 해석 주의다.
`windows_event_log_cleared`·`windows_timestomp`·`windows_malfind`·`windows_wmi_persistence`의 설명은 `Detect`로 시작해 도구가 찾는 대상을 적고 결과를 어떻게 확인하거나 서술할지는 적지 않는다 [6].
모든 도구의 응답은 `ok`와 `data`, 또는 `ok`와 `error`만 담은 JSON 글이고 도구와 관계없이 붙는 안내 문구가 없다 [7].

같은 저장소의 `agent_poc/mcp_agent.py`에는 주어진 증거에만 근거해 결론을 내고 불확실한 점을 밝히라는 시스템 지시 `ANALYST_SYSTEM_PROMPT`가 있다 [8].
이 지시는 `agent_poc`가 직접 부르는 모델에게 주는 글이고 서버가 MCP 응답이나 도구 설명으로 주는 안내가 아니다 [8][9].
다른 MCP 클라이언트로 서버에 붙으면 이 지시는 전달되지 않는다.

```python
def _json_success(data) -> str:
    return json.dumps({"ok": True, "data": data}, default=str)


def _json_error(message: str) -> str:
    return json.dumps({"ok": False, "error": message})


def _run_json_tool(func, *args, **kwargs) -> str:
    try:
        return _json_success(func(*args, **kwargs))
    except Exception as exc:
        return _json_error(str(exc))
```

```python
    async def chat(
        self,
        user_message: str,
        allowed_tools: Optional[Collection[str]] = None,
        system_prompt: Optional[str] = None,
    ) -> str:
        """Send a message and get a response with tool calling."""
        if system_prompt and (
            not self.conversation_history
            or self.conversation_history[0].get("role") != "system"
        ):
            self.conversation_history.append({
                "role": "system",
                "content": system_prompt,
            })

        self.conversation_history.append({
            "role": "user",
            "content": user_message,
        })

        tools = self.get_tool_definitions(allowed_tools)
        if self.model_provider in {"azure", "azure_openai"}:
            return await self._chat_azure_openai(tools)
        return await self._chat_ollama(tools)
```
