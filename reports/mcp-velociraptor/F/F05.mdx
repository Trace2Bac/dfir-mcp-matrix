# F05 발견사항·결론 근거 검증

### 비적용

**판단.** 서버에는 발견사항, 결론, 부재 주장을 받거나 저장하거나 보고하는 경로가 없다.
도구 78개는 Velociraptor에 조회, 수집, hunt, 대응 조치를 요청하고 그 결과를 돌려주는 도구이고 기록을 받는 도구가 없다 [1].
보고 산출물을 쓰거나 내보내는 도구도 없다 [1].
`windows_event_log_cleared`처럼 탐지를 내세운 도구의 결과 행은 Velociraptor 아티팩트가 낸 행이고 서버는 그 근거를 다시 확인하지 않고 옮긴다 [2].
같은 저장소의 `agent_poc/mcp_agent.py`는 도구 응답으로 증거 묶음을 만들어 모델에게 넘기고 모델이 쓴 요약을 결과 파일에 싣는다 [3].
`agent_poc`는 모델이 쓴 요약을 증거 묶음과 대조하지 않고 응답이 빈 글일 때만 고정 형식의 글로 바꾼다 [3].
이 처리는 MCP 클라이언트 코드에서 일어나고 서버를 거치지 않는다.
