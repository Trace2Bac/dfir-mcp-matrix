# F04 발견사항·결론 기록 관리

### 비적용

**판단.** 서버에는 발견사항, 결론, 가설을 받아 남기는 도구가 없다.
도구 78개는 Velociraptor에 조회, 수집, hunt, 대응 조치를 요청하고 그 결과를 돌려주는 도구다 [1].
도구 인자는 대상 단말과 조직, 아티팩트 이름과 그 매개변수, 정규식과 날짜 같은 조회 조건, 반환할 열이고 발견사항이나 메모를 받는 인자가 없다 [1].
`hunt_across_fleet`의 `description`은 Velociraptor hunt에 붙는 설명 글이고 서버는 이를 hunt 요청에 실어 넘긴다 [2][3].
서버 코드에는 파일이나 DB에 쓰는 호출이 없고 도구 호출 사이에 값을 쌓아 두는 변수도 없다 [4].
모듈 수준에서 값을 바꾸는 곳은 gRPC 연결 객체 `stub`을 만드는 `init_stub` 하나다 [5].
같은 저장소의 `agent_poc/mcp_agent.py`가 쓰는 결과 파일에는 모델이 쓴 요약이 실린다 [6].
이 파일은 MCP 클라이언트가 자기 쪽에 쓰는 산출물이고 서버가 받는 기록이 아니다.

```python
def init_stub(config_path: str | None = None):
    global stub
    resolved_path = resolve_config_path(config_path)
    config = yaml.safe_load(resolved_path.read_text())
    creds = grpc.ssl_channel_credentials(
        root_certificates=config["ca_certificate"].encode("utf-8"),
        private_key=config["client_private_key"].encode("utf-8"),
        certificate_chain=config["client_cert"].encode("utf-8")
    )
    channel_opts = (('grpc.ssl_target_name_override', "VelociraptorServer"),)
    channel = grpc.secure_channel(config["api_connection_string"], creds, options=channel_opts)
    stub = api_pb2_grpc.APIStub(channel)
```
