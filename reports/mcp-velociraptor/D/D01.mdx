# D01 파생물 보관

### 미구현

**판단.** 서버는 도구 결과를 응답으로 돌려주기만 하고 파일이나 DB에 남기지 않는다.
도구는 결과를 `_json_success`로 JSON 글로 만들어 반환값으로 돌려준다 [1].
서버를 이루는 세 파일에는 파일을 쓰거나 폴더를 만드는 호출이 없다 [2].
서버가 여는 파일은 설정을 읽는 두 가지다.
`load_environment`는 `.env` 파일을 읽어 환경변수로 올린다 [3].
`init_stub`은 API 설정 파일을 읽어 Velociraptor API로 가는 gRPC 연결을 만든다 [4].
도구 다섯 개를 부른 뒤 서버 프로세스가 열어 둔 대상에 일반 파일은 없었고 저장소 폴더의 파일 목록은 호출 전과 같았다 [5].

수집 요청과 그 결과는 Velociraptor 서버가 보관한다.
수집 도구는 VQL `collect_client`로 수집을 요청하고 Velociraptor 서버가 수집마다 flow를 만든다 [6].
`collect_artifact`를 부른 뒤 Velociraptor 서버의 데이터 저장소에는 그 `flow_id` 이름으로 요청, 기록, 결과 행 파일이 생겼다 [5].
`get_collection_results`와 `get_hunt_results_tool`은 그 결과를 VQL `source`와 `hunt_results`로 읽어 돌려주고 서버 쪽에 사본을 두지 않는다 [7].
`collect_file`은 `Generic.Collectors.File` 수집을 요청하고 파일 찾기 도구 `linux_file_finder`·`macos_file_finder`·`windows_hash_search`는 `Upload_File`을 아티팩트 매개변수로 넘긴다 [8].
이 수집에서 단말이 올리는 파일도 Velociraptor 서버가 받아 보관하고 서버에는 그 파일을 받아 두는 코드가 없다 [9][2].
같은 저장소의 `agent_poc/mcp_agent.py`는 분석 결과를 `agent_poc/output/` 아래 JSON 파일로 쓴다 [10].
이 파일은 MCP 클라이언트가 자기 쪽에 쓰는 것이라 서버의 파생물로 세지 않는다.

```python
    return json.dumps({"ok": True, "data": data}, default=str)

    return json.dumps({"ok": False, "error": message})


def _run_json_tool(func, *args, **kwargs) -> str:

    except Exception as exc:
        return _json_error(str(exc))
```

```python
def load_environment() -> None:
    """Load dotenv values without overriding existing environment."""
    repo_root = Path(__file__).resolve().parent
    configured_env = os.environ.get("VELOCIRAPTOR_ENV_FILE", "").strip()

    if configured_env:
        configured_path = Path(configured_env).expanduser()
        if not configured_path.is_absolute():
            configured_path = repo_root / configured_path
        _load_env_file(configured_path)

    _load_env_file(repo_root / ".env")


def _load_env_file(env_path: Path) -> None:
    if not env_path.is_file():
        return
    try:
        from dotenv import load_dotenv
    except ImportError:
        _load_simple_env(env_path)
        return

    load_dotenv(env_path, override=False)
```

```python
    client_id: str,
    artifact: str,
    parameters: Mapping[str, ParameterValue] | None = None,
```
