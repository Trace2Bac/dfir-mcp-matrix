# D03 파생물 무결성 검증

### 비적용

**판단.** 서버는 파생물을 남기지 않는다.
도구 결과는 응답으로만 나가고 서버가 여는 파일은 읽기만 하는 `.env`와 API 설정 파일이다 [1][2].
그래서 서버가 기준값을 남기거나 다시 대조할 파생물이 없다.

서버 코드는 해시를 계산하지 않는다.
`linux_file_finder`·`macos_file_finder`·`windows_hash_search`의 `Calculate_Hash`는 Velociraptor 아티팩트에 넘기는 매개변수이고 해시는 단말에서 실행되는 아티팩트가 계산한다 [3][4].
같은 저장소의 `agent_poc/mcp_agent.py`가 쓰는 결과 파일에도 해시나 서명은 붙지 않는다 [5].
이 파일은 MCP 클라이언트가 쓰는 것이라 서버의 파생물로 보지 않는다.
