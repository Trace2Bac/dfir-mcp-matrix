# D05 파생물 저장 실패 처리

### 비적용

**판단.** 서버는 도구 출력, 파생물, 보고 산출물을 저장하지 않고 응답으로만 돌려준다.
도구는 결과를 `_json_success`로 JSON 글로 만들어 반환값으로 돌려준다 [1].
서버 코드에는 파일이나 DB에 쓰는 호출이 없어 저장이 실패하는 경로가 없다 [2].
수집 결과를 데이터 저장소에 쓰는 일은 Velociraptor 서버가 한다.
같은 저장소의 `agent_poc/mcp_agent.py`는 결과 파일을 예외 처리 없이 쓴다 [3].
쓰기가 실패하면 `analyze_endpoint`가 예외로 끝나지만 이는 MCP 클라이언트의 동작이라 서버 구현으로 세지 않는다 [3][4].

### 근거

[1] 도구 결과는 JSON 글로 만들어 돌려준다.

```python
def _json_success(data) -> str:
    return json.dumps({"ok": True, "data": data}, default=str)


def _json_error(message: str) -> str:
    return json.dumps({"ok": False, "error": message})


def _run_json_tool(func, *args, **kwargs) -> str:
    try:
        return _json_success(func(*args, **kwargs))
    except Exception as exc:
        return _json_error(str(exc))
```

```python
    def _save_results(self, hostname: str, analysis_type: str, results: Dict[str, Any]):
        """Save analysis results to JSON file."""
        os.makedirs(self.output_dir, exist_ok=True)

        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        filename = f"{self.output_dir}/{hostname}_{analysis_type}_{timestamp}.json"

        with open(filename, "w") as file_handle:
            json.dump(results, file_handle, indent=2)

        print(f"✓ Results saved to: {filename}", flush=True)
```
