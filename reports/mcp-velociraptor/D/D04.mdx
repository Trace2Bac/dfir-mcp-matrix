# D04 출력 경로 제한

### 비적용

**판단.** 서버는 파생물을 담은 파일이나 DB를 만들거나 고치거나 지우지 않는다.
서버 코드에는 파일을 쓰거나 지우는 호출이 없고 어떤 도구도 서버 쪽 출력 위치를 인자로 받지 않는다 [1][2].
`collect_file`의 `path`와 파일 찾기 도구의 glob은 단말에서 읽을 대상을 가리키는 값이고 Velociraptor 아티팩트의 매개변수로 전달된다 [3].
수집 결과가 놓이는 위치는 Velociraptor 서버가 `client_id`와 `flow_id`로 정한다 [4].

서버가 읽는 설정 파일의 위치는 환경변수와 정해 둔 후보 경로로 정해진다.
`.env`는 환경변수 `VELOCIRAPTOR_ENV_FILE`의 경로와 저장소 루트에서 찾는다 [5].
API 설정 파일은 환경변수 `VELOCIRAPTOR_API_CONFIG`의 경로, 작업 폴더의 `api_client.yaml`, `~/.config/api_client.yaml` 순서로 찾는다 [6].
같은 저장소의 `agent_poc/mcp_agent.py`는 결과 파일을 `agent_poc/output/` 아래에 쓰고 파일 이름에 `hostname` 인자를 검사 없이 넣는다 [7].
이는 MCP 클라이언트의 동작이라 서버 구현으로 보지 않는다.

```python
def resolve_config_path(config_path: str | None = None) -> Path:
    explicit_path = config_path or os.environ.get("VELOCIRAPTOR_API_CONFIG")
    if explicit_path:
        resolved = Path(explicit_path).expanduser()
        if resolved.is_file():
            return resolved
        raise FileNotFoundError(
            f"Velociraptor API config not found: {resolved}. "
            "Set VELOCIRAPTOR_API_CONFIG to a valid file path."
        )

    candidates = [
        Path("api_client.yaml"),
        Path.home() / ".config" / "api_client.yaml",
    ]
    for candidate in candidates:
        resolved = candidate.expanduser()
        if resolved.is_file():
            return resolved

    raise FileNotFoundError(
        "Velociraptor API config not found. Checked ./api_client.yaml and "
        "~/.config/api_client.yaml. Set VELOCIRAPTOR_API_CONFIG to override."
    )
```
