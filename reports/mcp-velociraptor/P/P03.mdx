# P03 조사 진척 판단

### 미구현

**판단.** 서버는 조사에서 수행한 작업과 남은 작업을 표현하지 않고 완료 판단을 모델에 맡긴다.
서버는 부른 도구, 요청한 아티팩트, 다룬 단말을 기록하지 않으므로 수행 기록과 대조할 기준 목록도 진행 단계도 없다 [1].
등록한 도구 78개는 단말·org 조회, 수집·hunt 요청, 결과 조회, 아티팩트 목록 조회, VQL 실행 도구이고 진척이나 범위를 조회하거나 적는 도구는 없다 [2].
도구 응답은 `ok`와 `data`, 실패하면 `ok`와 `error`만 싣는다 [3].

`get_collection_results`는 flow 하나가 끝났는지를 판별하지만 이는 수집 한 건의 종료 여부다 [4][5].
이 도구가 부르는 함수 `get_flow_status`는 flow 기록에 `Collection <아티팩트> is done after`로 시작하는 문구가 있으면 `FINISHED`를, 없으면 `RUNNING`을 돌려준다 [4].
`get_collection_results`는 `FINISHED`가 될 때까지 `retry_delay`초씩 `max_retries`번 기다리고 끝내 끝나지 않으면 오류 문구 하나를 돌려준다 [5].
이 오류 문구는 flow가 끝나지 않은 이유나 그때의 flow 상태를 싣지 않는다 [5].
`hunt_across_fleet` 응답의 `state` 값 `STARTED`는 코드에 적은 문자열이고 Velociraptor에서 읽은 hunt 상태가 아니다 [6].
`get_hunt_results_tool`은 `hunt_results()`의 행만 돌려주고 응답한 단말 수나 아직 응답하지 않은 단말을 싣지 않는다 [7].
실시간 수집 도구는 Velociraptor가 precondition 때문에 질의를 건너뛴 경우에도 `ok`가 참이고 `data`가 빈 목록인 응답을 돌려주어 건너뛴 사실과 사유가 응답에 없다 [8].

같은 저장소의 MCP 클라이언트 예제 `agent_poc/`는 분석 결과 JSON에 역할별 `status`, 실행하지 않은 역할과 사유를 담은 `skipped`, 실패한 역할을 담은 `errors`를 적는다 [9][10].
이 기록은 클라이언트 코드가 만들므로 다른 MCP 클라이언트로 붙으면 남지 않고 서버 응답에도 실리지 않는다 [9][3].

```python
    return json.dumps({"ok": True, "data": data}, default=str)


def _json_error(message: str) -> str:
    return json.dumps({"ok": False, "error": message})


def _run_json_tool(func, *args, **kwargs) -> str:
    try:
        return _json_success(func(*args, **kwargs))
    except Exception as exc:
        return _json_error(str(exc))
```

```python
def get_flow_status(client_id: str, flow_id: str, artifact: str, org_id: str | None = None) -> str:
    artifact_pattern = f"^Collection {re.escape(normalize_artifact_name(artifact))} is done after"
    vql = (
        f"SELECT * FROM flow_logs(client_id={vql_literal(client_id)}, flow_id={vql_literal(flow_id)}) "
        f"WHERE message =~ {vql_literal(artifact_pattern)} "
        "LIMIT 100"
    )

    results = run_vql_query(vql, org_id=org_id)

    if results and isinstance(results, list) and len(results) > 0:
        return "FINISHED"

    return "RUNNING"
```
