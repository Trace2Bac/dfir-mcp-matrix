# P04 조사 단위 관리

### 미구현

**판단.** 서버에는 조사를 사건이나 세션으로 묶거나 나누는 장치가 없다.
사건이나 세션을 만들거나 여는 도구가 없고 서버가 정하는 ID도 없다 [1].
도구가 받는 식별자는 `org_id`, `client_id`, `flow_id`, `hunt_id`이고 모두 Velociraptor가 정한 값이다 [2].
`org_id`는 Velociraptor의 다중 테넌트 단위인 org를 가리킨다 [2].
`org_id` 인자가 비면 서버는 환경변수 `VELOCIRAPTOR_ORG_ID`의 값을 쓰고 그 값도 비면 org를 정하지 않고 요청한다 [3].
서버는 `org_id`를 검사하거나 앞선 호출의 org와 대조하지 않고 gRPC 요청의 `org_id` 필드에 싣는다 [3].
Velociraptor에 없는 org를 주면 Velociraptor의 `Org not found` 오류가 응답의 `error`에 실린다 [4].
`client_info`는 `search_all_orgs`가 참이고 `org_id`가 없으면 모든 org에서 단말을 찾아 가장 최근에 접속한 한 건을 `OrgId`와 함께 돌려준다 [5].
`VELOCIRAPTOR_ORG_ID`가 있으면 `org_id` 인자를 비워도 org가 정해지므로 `search_all_orgs`를 참으로 주어도 서버는 그 org 하나에서만 찾는다 [3][5].
서버는 이렇게 찾은 org를 뒤의 호출에 이어 두지 않으므로 모델이 `org_id`를 호출마다 다시 넘겨야 한다 [3][5].
`list_orgs`는 `org_id`를 받지 않고 `VELOCIRAPTOR_ORG_ID`가 정한 org나 기본 org에서 `orgs()`를 조회한다 [6].

서버는 시작한 flow와 hunt의 ID를 보관하지 않고 응답으로만 돌려준다 [7].
`get_collection_results`와 `get_hunt_results_tool`은 받은 `flow_id`와 `hunt_id`를 이 서버가 시작한 flow·hunt와 대조하지 않는다 [8].
그래서 다른 서버 프로세스가 시작한 flow의 결과도 `client_id`와 `flow_id`를 알면 조회된다 [9].
수집 요청 VQL은 `client_id`, 아티팩트 이름, 매개변수, 시간 제한만 넘기고 조사나 MCP 서버를 가리키는 표시를 붙이지 않는다 [10].
`hunt_across_fleet`는 `description`이 비면 `MCP Hunt: <아티팩트 이름>`을 hunt 설명으로 붙인다 [11].
이 설명은 `hunt()`가 hunt ID를 돌려주지 않았을 때 설명이 같은 가장 최근 hunt를 찾는 데 쓰이고 조사 단위를 나누지 않는다 [11][12].
`description` 없이 같은 아티팩트로 만든 hunt는 설명이 같아 이 조회로는 서로 구별되지 않는다 [11][12].
서버는 `mcp.run()`을 인자 없이 불러 stdio 전송으로 실행되므로 서버 프로세스 하나에 클라이언트 연결이 하나다 [13][14].
서버는 연결이나 프로세스마다 따로 두는 조사 상태가 없다 [15].

같은 저장소의 MCP 클라이언트 예제 `agent_poc/`는 분석 한 번마다 호스트 이름으로 단말을 찾아 `client_id`·`org_id`·OS를 담은 `CaseContext`를 만든다 [16].
`agent_poc/`는 역할마다 서버 프로세스를 새로 실행해 붙고 분석 결과를 `<호스트 이름>_<분석 종류>_<시각>.json` 파일 하나에 쓴다 [17][18].
이 묶음은 클라이언트 코드가 정하므로 다른 MCP 클라이언트로 붙으면 적용되지 않고 서버는 그 단위를 인자로 받지 않는다 [16][2].

```python
def _find_hunt_id_by_description(
    description: str,
    org_id: str | None = None,
) -> str:
    rows = run_vql_query(
        "SELECT hunt_id, create_time, hunt_description "
        "FROM hunts() "
        f"WHERE hunt_description = {vql_literal(description)} "
        "ORDER BY create_time DESC LIMIT 1",
        org_id=org_id,
    )
    if not rows:
        return ""
    return str(rows[0].get("hunt_id") or "")
```
