# I03 외부 전송 범위 구성

### I03.02 메타데이터·추출 값 전송

**구현.** 이 방식은 Velociraptor에 질의를 보내는 도구에 적용된다 [1].
서버가 Velociraptor로 보내는 것은 `run_vql_query`가 요청에 넣는 VQL 문장과 org ID다 [1].
도구는 호출 인자를 VQL의 정해진 자리에 넣는다 [2][3].
수집 도구는 `client_id`, 아티팩트 이름, 아티팩트 매개변수를 `collect_client` 호출에 넣는다 [2].
아티팩트 이름은 도구마다 코드에 정해져 있고 매개변수 이름도 도구가 정한다 [4].
매개변수 값은 프로세스 이름·경로·사용자 이름에 대조할 정규식, 파일 경로 glob, 해시, 날짜, PID, YARA 규칙 같은 값이다 [4][5].
단말 조회 도구는 호스트 이름과 검색 정규식을 `clients()` 질의의 조건에 넣는다 [3].
결과 조회 도구는 `client_id`, `flow_id`, `hunt_id`, 아티팩트 이름, 필드 목록을 넣는다 [6].
문자열 값은 `vql_literal`이 작은따옴표 문자열로 바꿔 넣는다 [7].
서버 코드에는 파일을 읽어 Velociraptor나 다른 서비스로 보내는 곳이 없다.
수집 결과는 Velociraptor에서 받아 MCP 응답으로 돌려준다 [1].

파일 검색 도구의 `Upload_File` 인자는 아티팩트 매개변수로 전달된다 [4].
Velociraptor v0.77.1의 `Linux.Search.FileFinder`는 이 매개변수가 참이면 단말에서 찾은 파일을 Velociraptor 서버로 올린다 [8].
이 전송은 단말의 Velociraptor 클라이언트가 한다.

같은 저장소의 `agent_poc`는 역할마다 모은 증거 묶음을 JSON 글로 요약 요청에 넣어 모델 서비스로 보낸다 [9].
증거 묶음에는 도구마다 행 수, 조건으로 고른 행 8개까지, 앞 3행이 들어 있다 [9].
모델 서비스는 기본값이 Ollama이고 `VELOCIRAPTOR_MODEL_PROVIDER`가 `azure`면 Azure OpenAI다 [9][10].
이 전송은 MCP 클라이언트인 `agent_poc`가 하며 서버 코드에는 모델 서비스로 보내는 곳이 없다 [10].

**한계.** `run_vql`이 보내는 VQL은 호출자가 인자로 쓴 질의이며 보낼 값을 코드가 정하지 않는다 [11].
이 도구는 `ENABLE_DANGEROUS_TOOLS`를 켜야 실행된다 [11].
`collect_artifact`와 `hunt_across_fleet`는 아티팩트 이름과 매개변수 이름·값을 호출자가 정한다 [12].
두 도구는 `ENABLE_DANGEROUS_TOOLS`를 확인하지 않는다 [12].
이 두 도구에서 서버는 이름의 글자 형식과 값의 자료형만 검사한다 [13].

[1] `run_vql_query`는 요청에 VQL과 `org_id`를 넣어 `stub.Query`로 보내고 응답을 모아 돌려준다.

```python
def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```

    client_id: str,
    artifact: str,
    parameters: Mapping[str, ParameterValue] | None = None,
    fields: str = "*",
    result_scope: str = "",
    org_id: str | None = None,

    normalized_fields = normalize_fields(fields)
    normalized_parameters = normalize_env_dict(parameters)

        f"LET collection <= collect_client(urgent='TRUE',client_id={vql_literal(client_id)}, "
        f"artifacts={vql_literal(normalized_artifact)}, env=dict({normalized_parameters})) "
        f"LET get_monitoring = SELECT * FROM watch_monitoring(artifact='System.Flow.Completion') WHERE FlowId = collection.flow_id LIMIT 1 "

    )

def list_all_clients(
    search: str = ".",
    os_filter: str = ".",
    limit: int = 100,
    org_id: str | None = None,
) -> list[dict]:
    search_pattern = search or "."
    os_pattern = os_filter or "."
    vql = (
        "SELECT client_id,"
        "timestamp(epoch=first_seen_at) as FirstSeen,"
        "timestamp(epoch=last_seen_at) as LastSeen,"
        "os_info.hostname as Hostname,"
        "os_info.fqdn as Fqdn,"
        "os_info.system as OSType,"
        "os_info.release as OS,"
        "os_info.machine as Machine,"
        "agent_information.version as AgentVersion,"
        "last_ip as LastIP "
        "FROM clients() "
        f"WHERE (os_info.hostname =~ {vql_literal(search_pattern)} "
        f"OR os_info.fqdn =~ {vql_literal(search_pattern)} "
        f"OR client_id =~ {vql_literal(search_pattern)}) "
        f"AND os_info.system =~ {vql_literal(os_pattern)} "
        f"ORDER BY LastSeen DESC LIMIT {int(limit)}"
    )
    return run_vql_query(vql, org_id=org_id)

[7] `vql_literal`은 값을 VQL 리터럴로 바꾼다.

```python
def vql_literal(value: ParameterValue) -> str:
    if isinstance(value, list):
        return "[" + ", ".join(vql_literal(item) for item in value) + "]"
    if value is None:
        return "null"
    if isinstance(value, bool):
        return "TRUE" if value else "FALSE"
    if isinstance(value, (int, float)) and not isinstance(value, bool):
        return str(value)

    escaped = str(value).replace("\\", "\\\\").replace("'", "\\'")
    return f"'{escaped}'"
```
