# I01 외부 연동 대상 관리

### I01.02 자격증명 존재로 활성화

**구현.** 이 방식은 서버 코드가 여는 외부 연결인 Velociraptor API 접속에 적용된다 [1].
`mcp_velociraptor_bridge.py`는 모듈을 가져오는 단계에서 `init_stub`을 불러 API 설정 파일을 읽고 gRPC 채널을 만든다 [1][2].
API 설정 파일은 Velociraptor 서버가 `config api_client`로 만들어 주는 파일이고 접속 주소와 CA 인증서, 클라이언트 인증서, 클라이언트 개인 키를 담는다 [2][3].
`resolve_config_path`는 이 파일을 찾지 못하면 `FileNotFoundError`를 낸다 [4].
그래서 API 설정 파일이 없으면 서버가 시작되지 않고 Velociraptor로 가는 요청도 없다 [5].
이 연결을 따로 켜거나 끄는 환경변수나 시작 인자는 없다.

채널은 시작할 때 만들고 요청은 도구가 `run_vql_query`를 부를 때 나간다 [6].
접속되지 않는 주소를 적은 설정 파일로도 서버는 시작했고 도구 호출이 gRPC 오류를 담은 오류 응답으로 끝났다 [7].

### I01.06 설정으로 목적지 지정

**구현.** 이 방식은 Velociraptor API 접속에 적용된다 [2].
목적지는 API 설정 파일의 `api_connection_string` 값이다 [2].
설정 파일 경로는 `VELOCIRAPTOR_API_CONFIG`, 현재 폴더의 `api_client.yaml`, `~/.config/api_client.yaml` 순서로 정한다 [4].
`VELOCIRAPTOR_API_CONFIG`는 환경변수로 주거나 `.env` 파일에 적는다 [8].
`.env` 파일은 `VELOCIRAPTOR_ENV_FILE`이 가리키는 파일과 저장소 폴더의 `.env`를 읽고 이미 있는 환경변수는 덮어쓰지 않는다 [8].
도구 인자에는 접속 주소나 설정 파일 경로를 받는 것이 없다 [9].
`run_vql`에 `http_client()`를 쓰는 VQL을 넘기면 Velociraptor 서버가 VQL에 적힌 주소로 요청을 보낸다 [10].
이 연결은 Velociraptor 서버가 여는 것이고 서버 코드가 여는 연결의 목적지는 바뀌지 않는다 [6].
도구의 `org_id` 인자는 같은 Velociraptor 서버 안에서 질의할 org를 고르는 값으로 요청의 `org_id` 필드에 넣으며 접속 주소를 바꾸지 않는다 [6].
`init_stub`은 채널 옵션 `grpc.ssl_target_name_override`에 `VelociraptorServer`를 넣는다 [2].
이 값은 코드에 고정되어 있고 설정으로 바꿀 수 없다 [2].
서버는 `api_connection_string`의 주소를 허용 목록과 대조하지 않고 설정 파일에 적힌 주소로 그대로 연결한다 [2].

같은 저장소의 `agent_poc`는 요약을 만들 때 모델 서비스에 연결한다 [11].
모델 서비스는 환경변수 `VELOCIRAPTOR_MODEL_PROVIDER`로 고르고 기본값은 Ollama다 [11].
값이 `azure`면 `AZURE_OPENAI_BASE_URL`·`AZURE_OPENAI_ENDPOINT`·`OPENAI_BASE_URL` 가운데 먼저 있는 값의 주소로 연결하고 `AZURE_OPENAI_API_KEY`가 없으면 예외를 낸다 [11].
이 연결은 MCP 클라이언트가 여는 것이고 서버 코드는 모델 서비스에 연결하지 않는다.

**한계.** `agent_poc`가 서버를 실행할 때는 `env=None`으로 실행하므로 SDK가 정한 기본 환경변수만 서버에 전달된다 [12][13].
이때 셸에 둔 `VELOCIRAPTOR_API_CONFIG`는 서버에 전달되지 않아 서버는 `.env`나 기본 위치의 설정 파일만 찾는다 [14].
셸에 둔 `VELOCIRAPTOR_ENV_FILE`과 `agent_poc/README.md`가 여러 org 배치에서 내보내라고 안내하는 `VELOCIRAPTOR_ORG_ID`도 SDK의 기본 환경변수 목록에 없어 서버에 전달되지 않는다 [12][13][15].
이 두 변수가 전달되지 않는 것은 실행으로 확인하지 않았다.

```python
def resolve_config_path(config_path: str | None = None) -> Path:
    explicit_path = config_path or os.environ.get("VELOCIRAPTOR_API_CONFIG")
    if explicit_path:
        resolved = Path(explicit_path).expanduser()
        if resolved.is_file():
            return resolved
        raise FileNotFoundError(
            f"Velociraptor API config not found: {resolved}. "
            "Set VELOCIRAPTOR_API_CONFIG to a valid file path."
        )

    candidates = [
        Path("api_client.yaml"),
        Path.home() / ".config" / "api_client.yaml",
    ]
    for candidate in candidates:
        resolved = candidate.expanduser()
        if resolved.is_file():
            return resolved

    raise FileNotFoundError(
        "Velociraptor API config not found. Checked ./api_client.yaml and "
        "~/.config/api_client.yaml. Set VELOCIRAPTOR_API_CONFIG to override."
    )
```

[6] `run_vql_query`는 요청에 VQL과 `org_id`를 넣어 `stub.Query`로 보낸다.

```python
def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```

```python
def load_environment() -> None:
    """Load dotenv values without overriding existing environment."""
    repo_root = Path(__file__).resolve().parent
    configured_env = os.environ.get("VELOCIRAPTOR_ENV_FILE", "").strip()

    if configured_env:
        configured_path = Path(configured_env).expanduser()
        if not configured_path.is_absolute():
            configured_path = repo_root / configured_path
        _load_env_file(configured_path)

    _load_env_file(repo_root / ".env")


def _load_env_file(env_path: Path) -> None:
    if not env_path.is_file():
        return
    try:
        from dotenv import load_dotenv
    except ImportError:
        _load_simple_env(env_path)
        return

    load_dotenv(env_path, override=False)
```
