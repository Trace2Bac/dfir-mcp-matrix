# mcp-velociraptor 기능→셀 대응표

`python tools/coverage.py mcp-velociraptor`가 이 파일 머리말의 기능 목록(`tools`)과 셀 원고로 만든 표다. 표는 손으로 고치지 않고, 기능 목록을 고친 뒤 다시 만든다.
기능 목록: MCP 도구 78개(본문에 없음 11개).
이름이 원고 본문에 나오는지만 찾으므로 이름이 나오지 않는다고 그 기능을 조사하지 않았다는 뜻은 아니다. 공통 처리기 설명으로 덮였을 수 있으므로 조사 범위를 다시 볼 때 출발점으로 쓴다.
같은 이름이 여러 클래스에 있으면 어느 클래스의 것인지 가리지 못한다(마지막 열).
