# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 아티팩트 수집 결과, hunt 결과, `run_vql` 결과의 시각 열에 적용된다 [1][2].
서버는 Velociraptor가 돌려준 행을 JSON으로 읽어 `json.dumps`로 다시 글로 만들고 시각 열을 찾거나 바꾸는 코드를 두지 않는다 [1][2].
시각 열의 표기는 Velociraptor와 아티팩트가 정한 그대로다 [1].
`linux_pslist`의 `CreateTime`은 `2026-10-11T05:34:45Z`처럼 초까지 실렸고 `linux_file_finder`의 `MTime`은 `2026-10-11T05:42:37.844584649Z`처럼 나노초 자리까지 실렸다 [3].
`_json_success`가 `json.dumps`에 주는 `default=str`은 JSON으로 바꿀 수 없는 값을 글로 바꾸는 인자다 [2].
행은 `json.loads`가 만든 값이어서 시각은 이미 문자열이고 이 인자가 시각 값을 바꾸는 경로는 없다 [1][2].

시각 범위 인자를 받는 도구 11개는 `DateAfter`·`DateBefore`나 `MoreRecentThan`·`ModifiedBefore`를 문자열로 받아 아티팩트 매개변수로 넘긴다 [4][5].
서버는 이 값의 형식을 검사하거나 시간대를 바꾸지 않는다 [5][6].
`linux_file_finder`에 `MoreRecentThan`으로 `notadate`를 주자 오류 없이 이 인자를 주지 않았을 때와 같은 1행이 왔다 [7].

### R08.03 시간대·단위·정밀도 표시

**구현.** 이 방식은 `list_clients`와 `client_info`가 싣는 `FirstSeen`·`LastSeen`에 적용된다 [8][9].
서버가 만드는 질의는 단말 기록의 epoch 값 `first_seen_at`·`last_seen_at`을 VQL `timestamp(epoch=…)`로 바꿔 `FirstSeen`·`LastSeen`으로 고른다 [8][9].
Velociraptor의 `timestamp`는 UTC 시각을 돌려주고 응답에는 `2026-10-11T05:29:53Z`처럼 끝에 `Z`가 붙은 RFC 3339 문자열로 실린다 [10][11].
`first_seen_at`은 초 단위 정수, `last_seen_at`은 마이크로초 단위 정수여서 `FirstSeen`은 초까지, `LastSeen`은 소수 여섯 자리까지 실렸다 [11].
소수 부분 끝의 0은 빠지므로 값마다 자릿수가 다르다 [11].
질의가 원래의 epoch 값을 고르지 않아 응답에는 바꾼 값만 있다 [8][9].

아티팩트 수집 결과의 시각 열에는 서버가 시간대나 단위 표시를 붙이지 않는다 [1][2].
이 열의 표기는 Velociraptor와 아티팩트가 정하고 실행해 본 `linux_pslist`의 `CreateTime`과 `linux_file_finder`의 `MTime`은 끝에 `Z`가 붙은 값이었다 [3].

```python
def vql_literal(value: ParameterValue) -> str:
    if isinstance(value, list):
        return "[" + ", ".join(vql_literal(item) for item in value) + "]"
    if value is None:
        return "null"
    if isinstance(value, bool):
        return "TRUE" if value else "FALSE"
    if isinstance(value, (int, float)) and not isinstance(value, bool):
        return str(value)

    escaped = str(value).replace("\\", "\\\\").replace("'", "\\'")
    return f"'{escaped}'"
```

```python
def normalize_env_dict(parameters: Mapping[str, ParameterValue] | None = None) -> str:
    if parameters is None:
        return ""
    if not isinstance(parameters, Mapping):
        raise TypeError("parameters must be a mapping or None")

    items = []
    for key, value in parameters.items():
        if not VALID_PARAMETER_NAME_RE.fullmatch(key):
            raise ValueError(f"Invalid parameter name: {key!r}")
        normalized_value = normalize_parameter_value(value)
        items.append(f"{key}={vql_literal(normalized_value)}")

    return ",".join(items)
```

```python
def list_all_clients(
    search: str = ".",
    os_filter: str = ".",
    limit: int = 100,
    org_id: str | None = None,
) -> list[dict]:
    search_pattern = search or "."
    os_pattern = os_filter or "."
    vql = (
        "SELECT client_id,"
        "timestamp(epoch=first_seen_at) as FirstSeen,"
        "timestamp(epoch=last_seen_at) as LastSeen,"
        "os_info.hostname as Hostname,"
        "os_info.fqdn as Fqdn,"
        "os_info.system as OSType,"
        "os_info.release as OS,"
        "os_info.machine as Machine,"
        "agent_information.version as AgentVersion,"
        "last_ip as LastIP "
        "FROM clients() "
        f"WHERE (os_info.hostname =~ {vql_literal(search_pattern)} "
        f"OR os_info.fqdn =~ {vql_literal(search_pattern)} "
        f"OR client_id =~ {vql_literal(search_pattern)}) "
        f"AND os_info.system =~ {vql_literal(os_pattern)} "
        f"ORDER BY LastSeen DESC LIMIT {int(limit)}"
    )
    return run_vql_query(vql, org_id=org_id)
```
