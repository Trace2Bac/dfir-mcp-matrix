# R01 결과 가공

### R01.01 가공 없이 전달

**구현.** 이 방식은 열 선택이 `*`인 수집 결과 응답과 `run_vql`의 응답에 적용된다 [1][2].
`run_vql_query`는 Velociraptor API가 보낸 응답마다 `Response`의 JSON 글을 `json.loads`로 읽어 행 목록 하나로 모은다 [1].
도구는 그 목록을 `{"ok": true, "data": [...]}`에 넣고 `json.dumps`로 만든 글 하나를 돌려준다 [2].
단말에서 아티팩트를 실행하고 끝날 때까지 기다리는 도구 62개는 `realtime_collection`이 만든 `SELECT {Fields} FROM …` 질의의 결과 행을 싣는다 [3].
그 가운데 44개는 `Fields`의 기본값이 `*`여서 아티팩트가 낸 열을 모두 싣는다 [4].
`get_collection_results`와 `get_hunt_results_tool`의 `fields`도 기본값이 `*`다 [5][6].
`run_vql`은 모델이 준 VQL 문장의 결과 행을 싣는다 [7].
서버는 행의 열 이름을 바꾸거나 값을 고치지 않는다 [1][2].
모델이 `Fields`에 열 이름을 주면 서버는 그 이름으로 `SELECT` 절을 만들고 Velociraptor가 그 열만 돌려준다 [8][3].
응답에는 행 목록만 있고 아티팩트 이름, flow ID, 행 수는 없다 [2][3].
FastMCP는 도구가 돌려준 글을 `content`의 글 항목 하나와 `structuredContent`의 `result` 문자열에 함께 싣는다 [9][10].

**한계.** 서버는 `result_scope`가 빈 도구에서 `source()`에 아티팩트 이름만 넘긴다 [3].
`result_scope`를 정한 도구는 `/Analysis`를 넘기는 `windows_scheduled_tasks` 하나다 [11].
Velociraptor v0.77.1의 `Linux.Sys.Crontab`은 소스 세 개(`CronTabs`·`CronScripts`·`Uploaded`)에 모두 이름이 있다 [12].
`linux_crontab`을 부르자 flow는 세 소스에 30행을 모았지만 응답은 `{"ok": true, "data": []}`였다 [12].
`windows_mutants`가 부르는 `Windows.Detection.Mutants`와 `windows_srum`이 부르는 `Windows.Forensics.SRUM`도 v0.77.1 정의에서 소스에 모두 이름이 있다 [13].
v0.77.1 정의와 대조했을 때 소스에 모두 이름이 있는데 서버가 소스 이름 없이 읽는 실시간 수집 도구는 `linux_crontab`과 이 두 도구였다 [13].
뒤의 두 도구는 Windows 단말이 없어 실행으로 확인하지 않았다.
`SELECT` 절의 열 이름이 결과에 없으면 Velociraptor는 그 열을 `null`로 돌려주고 서버는 이를 오류 없이 싣는다 [14].

### R01.02 구조화 파싱·필드 선택

**구현.** 이 방식은 서버가 응답에 실을 열을 정하는 도구에 적용된다 [15][16].
실시간 수집 도구 18개는 `Fields`의 기본값이 열 이름 목록이다 [15].
`windows_pslist`는 `Pid`·`Ppid`·`TokenIsElevated`·`Name`·`Exe`·`CommandLine`·`Username`·`Authenticode.Trusted` 8개를 기본값으로 둔다 [15].
`windows_usn_journal`은 `Usn`·`Timestamp`·`Filename`·`FullPath`·`Reason`·`FileAttributes`·`SourceInfo` 7개를 기본값으로 둔다 [15].
`windows_services`는 `UserAccount`·`Created`·`ServiceDll`·`FailureCommand`·`FailureActions`·`AbsoluteExePath`·`HashServiceExe`·`CertinfoServiceExe`·`HashServiceDll`·`CertinfoServiceDll` 10개를 기본값으로 둔다 [17].
Velociraptor v0.77.1의 `Windows.System.Services`가 내는 서비스 이름 `Name`·`DisplayName`과 상태 `State`는 이 기본값에 없다 [17][18].
모델이 `Fields`를 주지 않으면 서버는 이 목록으로 `SELECT` 절을 만들어 아티팩트가 낸 열 가운데 이 열만 싣는다 [3][15].
모델이 `Fields`에 `*`나 다른 열 이름을 주면 그 값이 쓰인다 [8].

`client_info`와 `list_clients`는 Velociraptor `clients()`의 행에서 서버가 정한 열을 골라 이름을 바꿔 싣는다 [16][19].
`client_info`는 `client_id`·`FirstSeen`·`LastSeen`·`Hostname`·`Fqdn`·`OSType`·`OS`·`Machine`·`AgentVersion` 9개를 싣고 `list_clients`는 여기에 `LastIP`를 더한다 [16][19].
org가 `org_id` 인자나 환경변수 `VELOCIRAPTOR_ORG_ID`로 정해졌으면 서버는 Velociraptor가 돌려준 행에 그 값을 `OrgId`로 더해 10개를 싣는다 [20].
org가 정해지지 않았고 `search_all_orgs`가 참이면 질의가 `OrgId`와 `OrgName`을 더 골라 11개를 싣는다 [16].
`org_id`를 `root`로 주자 `OrgId`가 `root`인 행이 왔다 [21].
`list_orgs`는 `orgs()`에서 `OrgId`·`Name`·`Nonce`를 고른다 [22].
`list_windows_artifacts`·`list_linux_artifacts`·`list_macos_artifacts`는 아티팩트 정의에서 `name`·`description`·`parameters`만 읽어 `name`·`short_description`·`parameters`를 싣는다 [23].
`parameters`는 매개변수 이름 목록이고 `include_parameter_details`가 참이면 매개변수 정의 전체다 [23].
수집을 시작만 하는 도구 6개는 `collect_client`의 결과에서 `flow_id`·`artifacts`·`timeout`·`specs`를 골라 첫 행을 싣는다 [24][25].
`hunt_across_fleet`은 Velociraptor `hunt()`의 결과에서 hunt ID만 읽고 서버가 받은 인자, 서버가 정한 값, 매개변수 대조 결과, `hunt_update`의 결과로 응답 `dict`를 만든다 [26].
아티팩트 매개변수를 준 hunt의 응답은 `parameter_validation`에 요청한 매개변수 `parameters`와 `compiled_env`를 싣는다 [27].
`compiled_env`는 서버가 Velociraptor `hunt_info()`의 `compiled_collector_args`에서 읽은 `env`의 이름과 값이다 [27].
`Linux.Search.FileFinder`에 매개변수 2개를 주어 hunt를 만들자 `compiled_env`에는 요청하지 않은 `ExcludePathRegex`와 `ACCESSOR`를 포함해 14개가 실렸다 [28].
아티팩트 매개변수를 주지 않은 hunt의 `start_result`는 `hunt_update(start=TRUE)`가 돌려준 값이고 매개변수를 준 hunt의 `start_result`는 서버가 넣은 hunt ID다 [26].

**한계.** 기본 열 목록으로 줄인 응답에는 빠진 열이 있다는 표시가 없다 [2][3].
기본 열 목록의 이름이 아티팩트 결과에 없으면 그 열은 `null`로 실린다 [14].
Velociraptor는 `SELECT` 절의 열 이름에서 대소문자를 구분한다 [14].
기본 열 목록 18개를 v0.77.1 아티팩트 정의가 내는 열 이름과 대조하자 10개는 이름이 모두 정의에 있었다 [29].
`windows_mounted_mass_storage_usb`가 부르는 `Windows.Mounted.Mass.Storage`는 정의가 없었다 [29].
나머지 7개 도구의 기본 열 목록에는 정의가 내지 않는 이름이 모두 20개 있었다 [29].
`windows_execution_amcache`의 9개 가운데 정의에 있는 이름은 `SHA1`과 `Publisher`뿐이었고 `windows_browser_history`의 7개 가운데 정의에 있는 이름은 `User`뿐이었다 [29].
`windows_shellbags`의 `Name`·`_OSPath`·`Path`, `windows_scheduled_tasks`의 `ExpandedCommand`, `windows_recentdocs`의 `Value`, `windows_execution_shimcache`의 `ControlSet`, `windows_usn_journal`의 `FullPath`도 정의에 없었다 [29].
`Windows.Forensics.Shellbags`는 폴더 경로를 `FullPath` 열로 내고 이 열은 `windows_shellbags`의 기본 열 목록에 없다 [29].
`windows_services`의 기본 열 가운데 `HashServiceExe`·`CertinfoServiceExe`·`HashServiceDll`·`CertinfoServiceDll`은 아티팩트 매개변수 `Calculate_hashes`나 `CertificateInfo`가 참일 때만 값이 있다 [18].
두 매개변수의 정의 기본값은 `N`이고 이 도구는 아티팩트 매개변수를 넘기지 않는다 [17][18].
이 도구들이 Windows 단말에서 돌려주는 행은 실행으로 확인하지 않았다.
`client_info`의 도구 설명은 `search_all_orgs`가 참이면 응답에 `OrgId`와 `OrgName`이 실릴 수 있다고 적는다 [30].
`search_all_orgs` 질의의 바깥 `SELECT`는 `Name`을 `OrgName`으로 고르지만 안쪽 질의가 돌려주는 행에는 `Name` 열이 없다 [16].
`search_all_orgs`를 참으로 주자 응답의 `OrgId`는 `root`였고 `OrgName`은 `null`이었다 [21].
org가 여러 개인 배치에서는 실행으로 확인하지 않았다.
아티팩트 목록 도구 3개는 설명 전문, 소스 이름, 유형(`type`)을 싣지 않는다 [23].

### R01.06 응답 항목 선별

**구현.** 이 방식은 서버가 만든 VQL이나 서버가 정한 인자 기본값이 응답에 실을 행을 고르는 다음 도구에 적용된다 [16][23][31].
`client_info`는 호스트 이름이나 FQDN이 일치하는 단말을 `LastSeen` 내림차순으로 정렬하고 `LIMIT 1`로 첫 행만 싣는다 [16].
`search_all_orgs`가 참이면 org마다 한 행을 고른 뒤 그 가운데 다시 한 행을 고른다 [16].
아티팩트 목록 도구 3개는 `type =~ 'client'`와 OS 접두 정규식(`^windows\.`, `linux\.`, `macos\.`)에 맞는 정의만 싣는다 [23][32].
`linux_netstat_enriched`는 `ConnectionStatusRegex`의 기본값이 `LISTEN|ESTAB`다 [31].
이 값은 v0.77.1의 `Linux.Network.NetstatEnriched` 정의가 같은 이름의 매개변수에 둔 기본값과 같다 [33].
모델이 이 인자를 주지 않고 부르자 14행이 왔고 `.`을 주자 88행이 왔다 [34].
`windows_ntfs_mft`는 `FileRegex`의 기본값이 `^velociraptor\.exe$`다 [35].
v0.77.1의 `Windows.NTFS.MFT` 정의에서 `FileRegex`의 기본값은 `.`이다 [33].
그래서 모델이 `FileRegex`를 주지 않으면 서버는 이름이 `velociraptor.exe`인 항목만 찾는 매개변수 값을 아티팩트에 넘긴다 [35].
이 도구는 Windows 단말이 없어 실행으로 확인하지 않았다.

**한계.** `client_info`는 일치하는 단말이 여럿이어도 가장 최근에 본 하나만 싣고 응답에는 다른 단말이 있었다는 표시가 없다 [16].
기본값으로 거른 `linux_netstat_enriched`의 응답에는 적용한 정규식이 실리지 않는다 [34].
`type =~ 'client'`는 정규식 일치여서 유형이 `client_event`인 정의도 목록에 실린다 [23][36].
v0.77.1에서 `list_linux_artifacts`의 52개 가운데 8개, `list_windows_artifacts`의 199개 가운데 33개가 `client_event`였다 [36].
`linux\.`와 `macos\.`는 이름의 처음에 고정되지 않아 이름 중간에 그 글자가 있는 정의도 일치한다 [32].
v0.77.1의 기본 정의에서는 `list_linux_artifacts`의 52개가 모두 `Linux.`로 시작했다 [36].

```python
def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```

```python
def realtime_collection(
    client_id: str,
    artifact: str,
    parameters: Mapping[str, ParameterValue] | None = None,
    fields: str = "*",
    result_scope: str = "",
    org_id: str | None = None,
) -> list[dict]:
    normalized_artifact = normalize_artifact_name(artifact)
    normalized_result_artifact = normalize_artifact_name(f"{artifact}{result_scope}")
    normalized_fields = normalize_fields(fields)
    normalized_parameters = normalize_env_dict(parameters)
    vql = (
        f"LET collection <= collect_client(urgent='TRUE',client_id={vql_literal(client_id)}, "
        f"artifacts={vql_literal(normalized_artifact)}, env=dict({normalized_parameters})) "
        f"LET get_monitoring = SELECT * FROM watch_monitoring(artifact='System.Flow.Completion') WHERE FlowId = collection.flow_id LIMIT 1 "
        f"LET get_results = SELECT * FROM source(client_id=collection.request.client_id, flow_id=collection.flow_id,artifact={vql_literal(normalized_result_artifact)}) "
        f"SELECT {normalized_fields} FROM foreach(row=get_monitoring, query=get_results) "
    )

    return run_vql_query(vql, org_id=org_id)
```

```python
def normalize_fields(fields: str) -> str:
    cleaned = fields.strip()
    if not cleaned:
        raise ValueError("Fields must not be empty.")
    if cleaned == "*":
        return cleaned

    result = []
    for field in cleaned.split(","):
        candidate = field.strip()
        if not candidate or not VALID_FIELD_RE.fullmatch(candidate):
            raise ValueError(
                "Invalid field selection. Use '*' or a comma-separated list of field "
                "names such as 'Pid, Name, CommandLine'."
            )
        result.append(candidate)

    return ", ".join(result)
```
