# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 서버는 단말에서 수집한 값을 응답에 싣고 그 가운데 비밀 값을 가리거나 빼는 처리를 두지 않는다.
`run_vql_query`는 Velociraptor가 돌려준 행을 JSON으로 읽어 모으고 `_json_success`는 그 행을 `json.dumps`로 글 하나로 만든다 [1][2].
두 함수 사이에는 값을 검사하거나 바꾸는 코드가 없다 [1][2].

셸 기록을 수집하는 `linux_bash_history`·`macos_bash_history`·`windows_powershell_history`는 `Fields`의 기본값이 `*`여서 아티팩트가 낸 기록의 줄을 모두 싣는다 [3].
내용이 `password=FAKE_SECRET_TOKEN_123`인 줄을 둔 시험용 파일을 `Linux.Sys.BashHistory`로 수집해 읽자 그 줄이 `Line` 값으로 그대로 실렸다 [4].
`linux_bash_history`를 Linux 단말에 부르자 사용자 셸 기록 528줄이 `Line`과 `OSPath` 두 열로 실렸다 [5].
`linux_ssh_authorized_keys`는 `Linux.Sys.SSHAuthorizedKeys`를 요청하고 결과 행을 그대로 싣는다 [6].
Velociraptor v0.77.1의 아티팩트 목록에는 이 이름이 없어 이 도구의 응답은 실행으로 확인하지 못했다 [7].
`windows_browser_history`와 `macos_browser_history`는 브라우저 방문 기록 아티팩트를 요청하고 서버에는 방문한 URL을 가리는 처리가 없다 [8].
`macos_browser_history`는 `Fields`의 기본값이 `*`다 [8].
`windows_browser_history`의 기본 `Fields`는 `URL`을 적지만 v0.77.1의 `Windows.Applications.Chrome.History`는 방문한 URL을 `visited_url` 열로 낸다 [8][9].
그래서 기본 `Fields`로는 방문한 URL 열이 골라지지 않는다 [8][9].
두 도구는 Windows·macOS 단말이 없어 실행으로 확인하지 않았다.
`windows_event_logs`는 사건의 `EventData`를, `windows_powershell_scriptblock`은 실행된 스크립트의 글 `EventData.ScriptBlockText`를 기본 `Fields`에 넣는다 [10].
`windows_pslist`는 프로세스의 명령 줄 `CommandLine`을 기본 `Fields`에 넣는다 [10].
`run_vql`은 모델이 준 질의의 결과 행을 그대로 싣는다 [11].
`Fields` 인자는 모델이 응답에 실을 열을 고르는 값이고 서버가 비밀 값이 있는 열을 빼는 처리가 아니다 [12].

`list_orgs`는 `orgs()`에서 `OrgId`·`Name`·`Nonce`를 고른다 [13].
Velociraptor에서 nonce는 클라이언트가 서버에 제시하는 공유 값이고 서버는 이 값으로 클라이언트가 속한 조직을 찾는다 [14].
이 값은 단말에서 수집한 값이 아니라 Velociraptor 서버가 조직마다 둔 설정 값이다 [14].
v0.77.1의 `orgs()`는 행에 `Name`·`OrgId`·`_client_config`만 싣고 `Nonce` 열을 싣지 않는다 [15].
`list_orgs`를 부르자 `Nonce`는 `null`이었다 [16].

서버 기록에 단말에서 수집한 값을 남기는 코드는 없다.
`run_vql_query`가 로거에 넘기는 것은 `DEBUG_VQL`이 켜졌을 때의 요청 VQL뿐이고 응답 행은 넘기지 않는다 [1].
MCP 서버에는 보고서를 만드는 도구가 없다.

def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```

def _json_success(data) -> str:
    return json.dumps({"ok": True, "data": data}, default=str)


def _json_error(message: str) -> str:
    return json.dumps({"ok": False, "error": message})


def _run_json_tool(func, *args, **kwargs) -> str:
    try:
        return _json_success(func(*args, **kwargs))
    except Exception as exc:
        return _json_error(str(exc))
```

```python
def normalize_fields(fields: str) -> str:
    cleaned = fields.strip()
    if not cleaned:
        raise ValueError("Fields must not be empty.")
    if cleaned == "*":
        return cleaned

    result = []
    for field in cleaned.split(","):
        candidate = field.strip()
        if not candidate or not VALID_FIELD_RE.fullmatch(candidate):
            raise ValueError(
                "Invalid field selection. Use '*' or a comma-separated list of field "
                "names such as 'Pid, Name, CommandLine'."
            )
        result.append(candidate)

    return ", ".join(result)
```
