# T03 실행 조건 확인

### 미구현

**판단.** 서버에는 앞선 작업 상태, 승인, 호출자 신원, 실행 자원으로 호출을 막거나 미루는 코드가 없다.
수집 도구는 인자 검사를 마치면 바로 Velociraptor에 수집을 요청한다 [1].
`get_collection_results`와 `get_hunt_results_tool`은 `flow_id`와 `hunt_id`를 앞선 호출이 돌려준 값과 대조하지 않고 받은 값으로 조회한다 [2].
`get_collection_results`는 `get_flow_status`가 `FINISHED`를 돌려줄 때까지 결과 조회를 미루고 정한 횟수를 다 쓰면 오류를 돌려준다 [3].
이 대기는 결과를 읽으려는 바로 그 수집이 끝났는지 확인하는 동작이고 다른 도구의 호출을 막지 않는다 [3].
`run_vql`·`quarantine_host`·`kill_process`는 환경변수 `ENABLE_DANGEROUS_TOOLS`가 꺼져 있으면 Velociraptor에 요청하지 않고 오류를 돌려준다 [4].
이 값은 사용자가 서버를 시작하기 전에 정하고 서버가 시작할 때 한 번 읽는 설정이다 [4].
이 값은 호출마다 받는 승인이 아니고 앞선 호출이 만든 작업 상태도 아니다 [4].
서버에는 사용자가 낸 승인 토큰이나 승인 기록을 요청과 대조하는 코드가 없다.
`hunt_across_fleet`는 인자 없는 hunt를 멈춘 상태로 만든 뒤 같은 호출 안에서 바로 시작하고 그 사이에 승인을 받지 않는다 [5].
서버는 `mcp.run()`을 기본 전송 방식인 stdio로 실행하므로 원격 MCP 연결을 받지 않는다 [6].
API 설정 파일의 인증서는 서버가 Velociraptor에 붙을 때 쓰는 자격증명이고 MCP 호출자를 확인하는 값이 아니다 [7].
Velociraptor v0.77.1의 API는 그 인증서의 사용자에게 질의 권한이 있는지 확인하지만 이는 Velociraptor가 하는 일이다 [8].

동시 실행 수를 정하는 장치도 없다.
도구 함수는 `run_vql_query`의 gRPC 응답을 이벤트 루프 안에서 `await` 없이 기다린다 [9].
MCP Python SDK 1.28.1의 FastMCP는 받은 메시지마다 같은 이벤트 루프의 작업으로 도구 함수를 부른다 [10].
그래서 한 호출이 Velociraptor의 응답을 기다리는 동안 다른 요청은 처리되지 않는다 [9][10].
`get_collection_results`만 재시도 사이에 `asyncio.sleep`으로 기다리므로 그 시간에는 다른 요청이 처리된다 [3].
이는 서버가 정한 제한이 아니라 도구 함수가 응답을 기다리는 방식에서 생기는 동작이다.

```python
def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```
