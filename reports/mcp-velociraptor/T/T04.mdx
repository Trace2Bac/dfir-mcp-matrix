# T04 실행 방식

### T04.06 원격 API 작업 요청

**구현.** 이 방식은 도구 78개 모두에 적용된다 [1].
서버 프로세스는 증거를 직접 읽거나 해석하지 않고 Velociraptor 서버의 gRPC API에 VQL 문장을 보내 돌아온 행을 받는다 [1].
`init_stub`은 서버를 시작할 때 API 설정 파일의 인증서와 키로 TLS 채널을 만들어 `api_connection_string` 주소에 붙는다 [2].
`run_vql_query`는 VQL 문장 하나를 `VQLCollectorArgs`에 담아 `stub.Query`로 보내고 응답의 `Response`를 `json.loads`로 해석해 행 목록으로 모은다 [1].
단말에서 수집하는 도구 62개는 `realtime_collection`으로 `collect_client`를 요청하고 같은 질의 안에서 `System.Flow.Completion` 이벤트를 기다린 뒤 `source()`로 결과 행을 읽는다 [3].
`collect_artifact`·`collect_file`·`collect_forensic_triage`·`quarantine_host`·`unquarantine_host`·`kill_process`는 `start_collection`으로 `collect_client`만 요청하고 `flow_id`를 돌려받는다 [4].
두 수집 함수는 `collect_client`에 `urgent='TRUE'`를 고정해 넘기고 이 값을 바꾸는 도구 인자는 없다 [3][4].
Velociraptor v0.77.1은 `urgent`를 그 수집을 단말에서 대기 중인 다른 수집보다 먼저 처리하게 하는 인자로 설명한다 [5].
실행 확인에서 `collect_artifact`로 요청한 flow의 `request.urgent`는 `true`였다 [6].
`hunt_across_fleet`는 `hunt()`를 요청한다 [7].
`start_hunt`가 `hunt()`에 넘기는 인자는 `description`, `artifacts`, `spec`, `os`, `pause`다 [7].
대상 단말을 좁히는 인자는 `os` 하나이고 만료 시각 `expires`, 라벨 조건 `include_labels`·`exclude_labels`, 실행 시간과 행 수와 업로드 크기의 상한 `timeout`·`max_rows`·`max_bytes`는 넘기지 않는다 [7][8].
아티팩트를 단말에서 실행하는 것은 단말의 Velociraptor 클라이언트이고 수집을 예약하고 결과를 보관하는 것은 Velociraptor 서버다.
`list_clients`·`client_info`·`list_orgs`·`get_hunt_results_tool`·`get_collection_results`와 아티팩트 목록 도구 3개가 보내는 질의는 Velociraptor 서버에 보관된 기록을 읽는다 [9].
`ENABLE_DANGEROUS_TOOLS`가 켜진 `run_vql`은 모델이 쓴 VQL 문장을 같은 경로로 보낸다 [10].
Velociraptor v0.77.1의 API는 질의마다 인증서 사용자의 이름으로 권한 관리자를 만들어 질의 실행 범위에 넣는다 [11].
서버 코드는 `subprocess`를 불러오지 않고 `os`와 `asyncio`는 `os.environ`과 `asyncio.sleep`에만 쓴다 [12].
그래서 서버가 외부 실행 파일을 하위 프로세스로 실행하는 경로는 없다 [12].
서버 프로세스 안에서 하는 일은 인자 검사, VQL 문장 구성, 응답 JSON 해석이다 [1][3].

```python
def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```

```python
def init_stub(config_path: str | None = None):
    global stub
    resolved_path = resolve_config_path(config_path)
    config = yaml.safe_load(resolved_path.read_text())
    creds = grpc.ssl_channel_credentials(
        root_certificates=config["ca_certificate"].encode("utf-8"),
        private_key=config["client_private_key"].encode("utf-8"),
        certificate_chain=config["client_cert"].encode("utf-8")
    )
    channel_opts = (('grpc.ssl_target_name_override', "VelociraptorServer"),)
    channel = grpc.secure_channel(config["api_connection_string"], creds, options=channel_opts)
    stub = api_pb2_grpc.APIStub(channel)
```
