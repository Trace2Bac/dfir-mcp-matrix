# T01 입력 검증

### T01.01 인자 구조·값 검사

**구현.** 이 방식은 VQL 문장을 만들기 전에 아티팩트 이름, 열 이름, 아티팩트 인자의 이름과 값을 검사하는 `velociraptor_api.py`의 함수와 hunt 인자를 Velociraptor가 받아들인 값과 대조하는 `validate_hunt_parameters`에 적용된다 [1][2].
MCP Python SDK 1.28.1의 FastMCP는 도구 함수의 매개변수 자료형으로 만든 pydantic 모델로 인자를 검사한 뒤 함수를 부른다 [3].
자료형이 맞지 않거나 필수 인자가 없으면 SDK가 함수를 부르지 않고 `Error executing tool`로 시작하는 오류 응답을 돌려준다 [3][4].
이 검사는 정수로 읽히는 문자열을 정수로 바꾸고 입력 schema에 없는 인자는 버린다 [4].
자료형이 `str`이 아닌 매개변수에 JSON 객체나 배열을 적은 문자열이 오면 SDK가 먼저 JSON으로 해석해 검사한다 [3][4].
서버 코드의 검사는 그 뒤에 이루어진다.
`normalize_artifact_name`은 아티팩트 이름의 앞뒤 공백을 지우고 영문자, 숫자, `_`, `.`, `:`, `/`, `-`만으로 된 이름인지 확인한다 [1].
`normalize_fields`는 `Fields`가 `*`이거나 쉼표로 나눈 이름마다 영문자나 `_`로 시작하고 영문자, 숫자, `_`, `.`만 담는지 확인한다 [5].
`normalize_env_dict`와 `normalize_parameter_dict`는 아티팩트 인자의 이름이 영문자나 `_`로 시작하고 영문자, 숫자, `_`만 담는지 확인한다 [6].
`normalize_parameter_value`는 인자 값이 `None`, 문자열, 숫자, 논리값이거나 그런 값만 담은 list인지 확인한다 [7].
이 검사에 어긋나면 함수가 `ValueError`를 내고 도구는 Velociraptor에 요청하지 않고 `{"ok": false, "error": …}`를 돌려준다 [8][9].
`limit`은 `int()`로 바꿔 `LIMIT` 뒤에 넣고 `kill_process`의 `pid`도 `int()`로 바꾼다 [10].
`list_clients`의 `search`·`os_filter`와 아티팩트 목록 도구의 `name_regex`는 빈 문자열이면 `.`으로 바꾼다 [11].
`collect_artifact`와 `hunt_across_fleet`는 `parameters`와 `legacy_parameters`를 함께 받으면 거부한다 [12].
`legacy_parameters`는 `{`로 시작하면 JSON 객체로 읽고 아니면 쉼표로 나눈 `이름=값` 목록으로 읽는다 [13].
`이름=값` 목록의 값은 따옴표나 `[`로 시작하면 `ast.literal_eval`로 읽고 그 밖에는 `null`·`none`·`true`·`false`와 정수, 소수만 받는다 [14].
그 밖의 값, 닫지 않은 따옴표, `=`가 없는 항목은 거부한다 [13][14][9].
`macos_browser_history`는 `URLRegex`가 기본값 `.`이 아니면 Velociraptor에 요청하지 않고 오류를 돌려준다 [15].
`client_info`는 `hostname`을 `re.escape`로 바꾸고 앞뒤에 `^`와 `$`를 붙여 정규식 값으로 쓴다 [16].

`hunt_across_fleet`는 인자가 있는 hunt를 만든 뒤 Velociraptor의 `hunt_info()`로 그 hunt의 `compiled_collector_args`를 읽어 요청한 인자 이름과 값이 `env`에 있는지 대조한다 [2][17].
대조 기준은 서버 코드에 둔 값이 아니라 Velociraptor가 아티팩트 정의에 따라 hunt 요청을 컴파일해 만든 값이다 [2].
`validate_hunt_parameters`는 `compiled_collector_args`의 항목 가운데 `artifacts`나 `Query`에 아티팩트 이름이 들어 있는 항목을 고르고 그런 항목이 없으면 모든 항목을 대조 대상으로 삼는다 [18].
고른 항목 가운데 하나라도 요청한 인자를 모두 담고 있으면 통과로 정한다 [2].
값은 그대로 같거나 문자열로 바꾼 값이 같으면 맞는 것으로 본다 [19].
요청한 값이 논리값이면 `true`·`y`·`1`이나 `false`·`n`·`0`과 대조하고 list이면 Velociraptor의 값을 JSON으로 읽어 대조한다 [19].
이름이 없거나 값이 다르면 `hunt_update(stop=TRUE)`로 그 hunt를 멈추고 오류를 돌려준다 [17].
`start_request`나 `compiled_collector_args`를 읽지 못한 경우에도 같은 경로로 hunt를 멈추고 오류를 돌려준다 [2][17].
시험 서버에서 `Linux.Sys.Pslist`의 정의에 없는 인자 이름으로 hunt를 요청하자 오류가 왔고 그 hunt의 상태는 `STOPPED`였다 [20].
정의에 있는 이름 `processRegex`로 요청한 hunt는 응답의 `parameter_validation.validated`가 `true`였다 [20].
`Linux.Search.FileFinder`의 `Calculate_Hash`를 참으로 준 hunt는 Velociraptor의 값 `Y`와 맞아 `validated`가 `true`였다 [21].
`processRegex`를 `null`로 준 요청과 원소가 둘인 list로 준 요청은 대조에서 어긋나 오류가 왔고 만들어진 두 hunt의 상태는 `STOPPED`였다 [21].
인자 없는 hunt는 이 대조를 하지 않고 `parameter_validation`에 `no_parameters_requested`를 적는다 [17][20].

**한계.** 인자가 있는 hunt는 `pause=TRUE` 없이 만들어지고 대조는 그 뒤에 이루어진다 [17].
Velociraptor v0.77.1의 `hunt()`는 `pause`가 없으면 hunt를 `RUNNING` 상태로 만든다 [22].
그래서 대조에서 어긋난 hunt도 멈추기 전까지는 시작된 상태다 [17][22].
이때 돌아오는 오류 문구는 `Refusing to start parameterized hunt`로 시작해 hunt를 시작하지 않은 것으로 읽힌다 [2].
시험 서버에서 정의에 있는 인자 이름으로 만든 hunt는 응답의 `created_paused`가 `false`였고 바로 뒤에 읽은 상태가 `RUNNING`이었다 [23].
정의에 없는 인자 이름으로 만들어 멈춘 hunt는 시작 시각이 만든 시각과 같았고 수집이 예약된 단말은 없었다 [23].
`_get_hunt_info`가 hunt 정보를 읽지 못해 예외를 내면 그 호출이 `try` 바깥이라 hunt를 멈추지 않고 오류만 돌려준다 [17].
단말 수집 경로는 아티팩트 인자 이름을 아티팩트 정의와 대조하지 않는다 [24].
시험 서버에서 `collect_artifact`에 정의에 없는 인자 이름을 함께 주자 수집이 시작되었고 응답의 `specs`에는 정의에 있는 인자만 있었다 [25].
`linux_pslist`는 인자 이름 `ProcessRegex`를 넘기는데 시험 서버의 `Linux.Sys.Pslist`가 정의한 이름은 `processRegex`다 [25][26].
시험 서버에서 이 도구는 `ProcessRegex`에 값을 주어도 인자 없이 부른 때와 같은 76행을 돌려주었다 [25].
아티팩트 이름 검사는 형식만 확인하고 그 이름이 Velociraptor 서버에 있는지는 확인하지 않는다 [1].
`get_collection_results`는 flow가 끝났는지 먼저 조회하고 끝난 뒤에 `fields`를 검사한다 [27].
그래서 형식에 어긋난 `fields`를 주어도 상태 조회 질의는 Velociraptor에 전달되고 flow가 끝나지 않았으면 `fields` 오류가 아니라 대기를 그만둔다는 문구가 온다 [27][28].
`client_id`, `hunt_id`, `flow_id`, `org_id`, `os_filter`, `description`, 정규식 인자, `YaraRule`, `collect_file`의 `path`는 서버가 형식을 검사하지 않는다 [29].
`org_id`는 요청의 `org_id` 필드에 넣고 나머지는 문자열 값으로 VQL 문장에 넣는다 [29].
서버는 `client_id`가 등록된 단말인지 확인하지 않는다 [29].
시험 서버에서 등록되지 않은 `client_id`와 서버에 없는 아티팩트 이름은 둘 다 `Failed to start collection: []`라는 같은 오류로 돌아왔다 [30].
Velociraptor v0.77.1의 `collect_client`는 `client_id`를 확인해 맞지 않으면 질의 기록에 사유를 남기고 빈 값을 돌려준다 [31].
`hunt_across_fleet`의 `os_filter`에 Velociraptor가 받지 않는 값을 주면 Velociraptor는 hunt를 만들지 않고 서버는 설명이 같은 hunt가 없을 때 `Velociraptor hunt() did not return a hunt id.` 오류를 돌려준다 [30][32][33].
설명이 같은 hunt가 이미 있으면 서버는 이 오류를 돌려주지 않고 그 hunt의 ID로 인자 대조와 시작 요청을 이어 간다 [33][17].
`description`을 주지 않으면 설명은 `MCP Hunt: <아티팩트 이름>`이어서 같은 아티팩트로 앞서 만든 hunt가 여기에 해당한다 [34].
시험 서버에서 `Linux.Mounts` hunt를 만들어 멈춘 뒤 `os_filter`만 `plan9`로 더해 다시 부르자 오류 없이 앞선 hunt의 ID를 담은 응답이 왔고 그 hunt의 상태는 `RUNNING`이 되었다 [35].
정규식 인자는 서버가 컴파일해 보지 않으며 시험 서버에서 `list_clients`의 `search`에 닫지 않은 괄호 하나를 주자 오류 없이 빈 목록이 왔다 [30].
`limit`에는 범위 검사가 없어 시험 서버에서 `-1`을 준 `list_clients`가 단말 행을 돌려주었다 [10][30].
`legacy_parameters`는 쉼표로 항목을 나눌 때 대괄호를 확인하지 않아 원소가 둘 이상인 list 값을 거부한다 [13][30].
`collect_artifact`의 도구 설명은 이 인자가 list 값을 받는다고 적는다 [36].

```python
def normalize_fields(fields: str) -> str:
    cleaned = fields.strip()
    if not cleaned:
        raise ValueError("Fields must not be empty.")
    if cleaned == "*":
        return cleaned

    result = []
    for field in cleaned.split(","):
        candidate = field.strip()
        if not candidate or not VALID_FIELD_RE.fullmatch(candidate):
            raise ValueError(
                "Invalid field selection. Use '*' or a comma-separated list of field "
                "names such as 'Pid, Name, CommandLine'."
            )
        result.append(candidate)

    return ", ".join(result)
```

def normalize_parameter_value(value) -> ParameterValue:
    if value is None or isinstance(value, SCALAR_PARAMETER_TYPES):
        return value
    if isinstance(value, list):
        normalized_items = []
        for item in value:
            if isinstance(item, list):
                raise ValueError(
                    "Parameter lists must contain scalar values only."
                )
            normalized_items.append(normalize_parameter_value(item))
        return normalized_items
    raise ValueError(
        "Parameter values must be JSON scalars or lists of scalar values."
    )
```

def _parse_legacy_parameter_value(raw_value: str):
    value = raw_value.strip()
    if not value:
        raise ValueError("Parameter values must not be empty.")

    if value[0] in ("'", '"', "["):
        try:
            parsed = ast.literal_eval(value)
        except (SyntaxError, ValueError) as exc:
            raise ValueError(f"Invalid legacy parameter value: {value!r}") from exc
        return normalize_parameter_value(parsed)

    lowered = value.lower()
    if lowered == "null" or lowered == "none":
        return None
    if lowered == "true":
        return True
    if lowered == "false":
        return False
    if re.fullmatch(r"-?\d+", value):
        return int(value)
    if re.fullmatch(r"-?(?:\d+\.\d*|\.\d+)", value):
        return float(value)

    raise ValueError(
        "Legacy parameters must use scalar values or list literals like "
        "Name='value', Count=1, Enabled=true, or Targets=['_BasicCollection']."
    )
```

def _compiled_arg_mentions_artifact(compiled_arg: dict, artifact: str) -> bool:
    haystack_parts = []
    for item in compiled_arg.get("artifacts") or []:
        if isinstance(item, dict):
            haystack_parts.append(str(item.get("name") or ""))
        else:
            haystack_parts.append(str(item))

    if actual == expected:
