# T07 도구 부재 처리

### 미구현

**판단.** 서버가 분석과 수집에 쓰는 것은 Velociraptor 서버와 그 서버에 등록된 아티팩트 정의이고 서버는 요청 전에 둘 다 있는지 확인하지 않는다 [1][2].
Velociraptor 서버에 닿지 못하면 예외 문구가 가공 없이 `error`에 실린다 [3].
아티팩트 정의가 없으면 응답이 돌아오지 않거나 다른 시작 실패와 같은 문구가 돌아온다 [4][5].

서버가 쓰는 외부 프로그램은 Velociraptor 서버 하나이고 이 프로그램에 닿지 못할 때 쓰는 다른 경로는 없다 [1].
모든 도구는 접속 설정 파일의 주소와 인증서로 만든 gRPC 채널로 질의를 보낸다 [1].
`resolve_config_path`는 환경변수 `VELOCIRAPTOR_API_CONFIG`가 있으면 그 경로만 보고 그 파일이 없으면 다른 경로를 보지 않고 `FileNotFoundError`를 낸다 [6].
환경변수가 없으면 현재 작업 폴더의 `api_client.yaml`, 사용자 홈의 `.config/api_client.yaml` 차례로 보고 처음 있는 파일을 쓴다 [6].
둘 다 없으면 확인한 두 경로와 환경변수 이름을 적은 `FileNotFoundError`를 낸다 [6].
`mcp_velociraptor_bridge.py`는 모듈 수준에서 `init_stub`을 부르므로 이 예외가 나면 서버 프로세스는 MCP 연결을 열기 전에 끝난다 [7].
실행 확인에서 설정 파일이 없는 환경과 없는 경로를 준 환경으로 서버를 시작하면 두 경우 모두 이 문구를 표준 오류에 내고 종료 코드 1로 끝났다 [8].
작업 폴더와 홈 폴더에 모두 파일을 두면 작업 폴더의 파일이 골라졌다 [8].
`init_stub`은 고른 설정 파일에 `ca_certificate`·`client_private_key`·`client_cert`·`api_connection_string`이 있는지 확인하지 않고 읽는다 [1].
실행 확인에서 빈 파일은 `TypeError`, `api_connection_string`만 적은 파일은 `KeyError: 'ca_certificate'`, YAML로 읽히지 않는 파일은 `yaml.parser.ParserError`를 표준 오류에 내고 서버가 종료 코드 1로 끝났다 [8].
고른 설정 파일의 경로는 응답에 실리지 않는다.
이 파일은 서버의 접속 설정이고 외부 도구의 실행 파일이나 참조 자료가 아니다.

서버는 설정 파일이 있는지만 확인하고 Velociraptor 서버에 닿는지는 시작할 때 확인하지 않는다 [1].
`init_stub`은 `grpc.secure_channel`로 채널 객체만 만들고 질의를 보내지 않는다 [1].
실행 확인에서 닫힌 포트를 가리키는 설정으로 서버 모듈을 불러오면 오류 없이 불러와졌다 [8].
그 상태에서 `list_clients`를 부르면 gRPC 예외의 문자열 표현이 `{"ok": false, "error": …}`의 `error`에 그대로 실렸다 [8][3].
이 문자열에는 `StatusCode.UNAVAILABLE`과 연결 거부 문구가 있지만 서버가 Velociraptor에 닿지 못했다는 사실을 따로 구분해 알리는 처리는 없다 [3].

아티팩트 정의는 Velociraptor 서버에 있고 MCP 서버는 수집을 요청하기 전에 그 아티팩트가 있는지 조회하지 않는다 [2].
고정된 아티팩트를 요청하는 도구 67개가 넘기는 아티팩트 이름은 63개이고 그 가운데 13개는 Velociraptor v0.77.1에 들어 있는 정의 437개에 없다 [4].
이 13개 이름은 도구 13개가 하나씩 요청한다 [4].
`linux_arp_cache`의 `Linux.Network.ArpCache`, `kill_process`의 `Generic.Utils.KillProcess`, `collect_forensic_triage`의 `Windows.Triage.Targets`가 그 예다 [4].
Velociraptor의 `collect_client`는 모르는 아티팩트 이름을 받으면 질의 로그에 `Unknown artifact`를 적고 값 없이 끝난다 [4].
서버는 질의 로그를 읽지 않으므로 이 문구는 응답에 실리지 않는다 [3].
결과를 기다렸다 돌려주는 도구는 이때 오지 않는 수집 완료 알림을 기다리는 질의를 보내므로 응답을 돌려주지 못한다 [2].
실행 확인에서 `linux_arp_cache`는 90초 동안 응답이 없어 호출을 끊었고 그 사이 그 단말에 새 flow는 만들어지지 않았다 [4].
수집만 시작하는 도구는 `Failed to start collection: []`를 돌려준다 [5].
`hunt_across_fleet`은 설명이 같은 hunt가 없으면 `Velociraptor hunt() did not return a hunt id.`를 돌려준다 [9].
설명이 같은 hunt가 이미 있으면 `start_hunt`는 이 문구를 돌려주지 않고 그 hunt의 ID로 처리를 이어 간다 [9].
두 문구는 아티팩트가 없다는 사실을 다른 시작 실패와 구분하지 않는다 [4].
없는 `client_id`를 주었을 때도 같은 동작과 같은 문구다 [4].

단말의 OS에 맞는 아티팩트인지도 요청 전에 확인하지 않는다 [2].
실행 확인에서 Linux 단말에 `windows_dns_cache`를 부르면 Velociraptor 클라이언트가 실행 조건에 맞지 않는 질의를 건너뛰었고 응답은 `{"ok": true, "data": []}`였다 [4].
같은 단말에 `macos_pslist`를 부르면 그 단말의 프로세스 40행이 왔다 [4].

서버는 시작할 때 설정 파일 `.env`를 읽는다 [10].
`velociraptor_api`는 불러올 때 `load_environment`를 실행하고 이 함수는 `VELOCIRAPTOR_ENV_FILE`이 가리키는 파일과 저장소의 `.env`를 차례로 읽는다 [11].
파일을 읽을 때 `python-dotenv`를 `import`하고 실패하면 서버 코드의 `_load_simple_env`로 같은 파일을 읽는다 [10].
대체했다는 사실은 응답에도 표준 오류에도 남기지 않는다 [10].
`VELOCIRAPTOR_ENV_FILE`이 가리키는 경로에 파일이 없으면 `_load_env_file`은 오류 없이 돌아오고 서버는 저장소의 `.env`와 이미 있는 환경변수로 시작한다 [10][11].
이때도 그 파일을 건너뛴 사실은 응답과 표준 오류에 남지 않는다 [10].
`VELOCIRAPTOR_ENV_FILE`에 상대 경로를 주면 작업 폴더가 아니라 `velociraptor_env.py`가 있는 폴더를 기준으로 파일을 찾는다 [11].
실행 확인에서 없는 경로를 준 서버 모듈은 표준 오류 출력 없이 불러와졌고 작업 폴더에만 있는 파일을 상대 경로로 가리키면 그 파일의 값은 읽히지 않았다 [12].
`requirements.txt`는 `python-dotenv`를 의존성으로 적으므로 이 대체는 그 패키지가 설치되지 않은 환경에서만 일어난다 [13].
두 경로 모두 이미 있는 환경변수를 덮어쓰지 않으므로 MCP 클라이언트가 준 환경변수가 `.env`의 값보다 먼저 쓰인다 [10].
이 파일에서 읽는 `VELOCIRAPTOR_API_CONFIG`와 `VELOCIRAPTOR_ORG_ID`는 모든 질의가 쓰는 접속 설정 파일과 기본 org를 정한다 [14].
`ENABLE_DANGEROUS_TOOLS`는 `run_vql`·`quarantine_host`·`kill_process`를 실행할지를 정한다 [14].
`python-dotenv`는 서버가 시작할 때 설정을 읽는 데만 쓰는 모듈이고 도구 호출이 쓰는 외부 도구가 아니다 [10][11].

`python-dotenv` 경로와 `_load_simple_env` 경로는 같은 `.env` 파일을 다르게 읽는다 [10].
`_load_simple_env`는 줄을 첫 `=`에서 나누고 값 양끝의 따옴표만 떼므로 `export` 접두어와 값 뒤의 주석을 처리하지 않는다 [10].
실행 확인에서 `export FOO=bar` 줄은 `python-dotenv` 경로에서 이름 `FOO`가 되고 대체 경로에서 이름 `export FOO`가 되었다 [15].
`VELOCIRAPTOR_ORG_ID=abc # note` 줄의 값은 `python-dotenv` 경로에서 `abc`, 대체 경로에서 `abc # note`가 되었다 [15].

def run_vql_query(vql: str, org_id: str | None = None):
    if stub is None:
        raise RuntimeError("Stub not initialized. Call init_stub() first.")
    request = api_pb2.VQLCollectorArgs(Query=[api_pb2.VQLRequest(VQL=vql)])
    resolved_org_id = resolve_org_id(org_id)
    if resolved_org_id:
        request.org_id = resolved_org_id
    results = []
    if DEBUG_VQL:
        logger.debug("VQL request: %s", request)
    
    for resp in stub.Query(request):
        if hasattr(resp, "error") and resp.error:
            raise RuntimeError(f"Velociraptor API error: {resp.error}")
        if hasattr(resp, "Response") and resp.Response:
            results.extend(json.loads(resp.Response))
    return results
```

def resolve_config_path(config_path: str | None = None) -> Path:
    explicit_path = config_path or os.environ.get("VELOCIRAPTOR_API_CONFIG")
    if explicit_path:
        resolved = Path(explicit_path).expanduser()
        if resolved.is_file():
            return resolved
        raise FileNotFoundError(
            f"Velociraptor API config not found: {resolved}. "
            "Set VELOCIRAPTOR_API_CONFIG to a valid file path."
        )

    candidates = [
        Path("api_client.yaml"),
        Path.home() / ".config" / "api_client.yaml",
    ]
    for candidate in candidates:
        resolved = candidate.expanduser()
        if resolved.is_file():
            return resolved

    raise FileNotFoundError(
        "Velociraptor API config not found. Checked ./api_client.yaml and "
        "~/.config/api_client.yaml. Set VELOCIRAPTOR_API_CONFIG to override."
    )

def _load_env_file(env_path: Path) -> None:
    if not env_path.is_file():
        return
    try:
        from dotenv import load_dotenv
    except ImportError:
        _load_simple_env(env_path)
        return

    load_dotenv(env_path, override=False)


def _load_simple_env(env_path: Path) -> None:
    for line in env_path.read_text().splitlines():
        stripped = line.strip()
        if not stripped or stripped.startswith("#") or "=" not in stripped:
            continue

        key, value = stripped.split("=", 1)
        key = key.strip()
        value = value.strip().strip("\"'")
        if key and key not in os.environ:
            os.environ[key] = value
```

def load_environment() -> None:
    """Load dotenv values without overriding existing environment."""
    repo_root = Path(__file__).resolve().parent
    configured_env = os.environ.get("VELOCIRAPTOR_ENV_FILE", "").strip()

    if configured_env:
        configured_path = Path(configured_env).expanduser()
        if not configured_path.is_absolute():
            configured_path = repo_root / configured_path
        _load_env_file(configured_path)

    _load_env_file(repo_root / ".env")
