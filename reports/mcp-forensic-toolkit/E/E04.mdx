# E04 분석 입력 준비

### 비적용

**판단.** 서버는 이미지, 보관 파일, 수집물 같은 증거 입력을 받지 않는다.
도구가 읽는 것은 서버를 실행한 호스트의 시스템 로그와 호출 인자로 받은 파일이나 폴더다 [1][2].
`file_metadata`와 `hash_directory`는 받은 파일을 형식과 관계없이 바이트로 읽어 해시와 파일 상태 값만 낸다 [2].
서버가 불러오는 모듈은 표준 라이브러리 `os`·`hashlib`·`datetime`·`platform`·`subprocess`와 `dotenv`, `mcp`뿐이다 [3].
서버 코드에는 보관 파일을 풀거나 이미지를 열거나 작업 사본을 만드는 처리가 없다 [3][4].

    results = {}
    for root, _, files in os.walk(path):
        for f in files:
            full_path = os.path.join(root, f)
            try:
                with open(full_path, "rb") as fp:
                    content = fp.read()
                    results[full_path] = hashlib.sha256(content).hexdigest()
            except Exception as e:
                results[full_path] = f"Error: {str(e)}"
    return results
