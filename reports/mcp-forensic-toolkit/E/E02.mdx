# E02 증거 무결성 검증

### E02.02 도구를 요청해 기준값 계산

**구현.** 이 방식은 `file_metadata`와 `hash_directory`에 적용된다 [1][2].
`file_metadata`는 `SAFE_BASE` 아래 파일 하나의 내용 전체를 읽어 SHA-256을 계산하고 크기, `st_ctime`, `st_mtime`과 함께 응답의 `dict`에 싣는다 [1].
`hash_directory`는 받은 폴더 아래 파일마다 내용 전체를 읽어 SHA-256을 계산하고 전체 경로를 키로 한 `dict`로 돌려준다 [2].
읽지 못한 파일은 해시 자리에 `Error: `로 시작하는 오류 문구를 싣는다 [2].
기준값은 모두 내용의 SHA-256이고 응답에만 실린다 [1][2].
서버는 이 값을 파일이나 메모리에 보관하지 않는다 [3].
`hash_directory`는 `SAFE_BASE`와 경로를 대조하지 않아 서버 프로세스가 읽을 수 있는 폴더면 `SAFE_BASE` 밖의 폴더도 해시한다 [2][4].
`SAFE_BASE` 밖의 서버 설치 폴더를 주자 파일 3개의 SHA-256이 돌아왔고 같은 서버에서 `file_metadata`는 `SAFE_BASE` 밖의 파일을 거부했다 [5].

`correlate_file_and_logs`는 안에서 `file_metadata`를 불러 SHA-256까지 계산하지만 응답에는 수정 시각만 옮기고 해시는 싣지 않는다 [6].
`generate_forensic_report`도 같은 결과를 옮기므로 해시가 실리지 않는다 [6].
두 도구의 응답 키에 `sha256`이 없었다 [5].
도구 5개 가운데 해시를 앞선 값과 대조하는 도구는 없다 [7].

**한계.** `hash_directory`는 `os.walk`를 기본 인자로 부른다 [2].
Python 3.11.9의 `os.walk`는 기본 인자에서 목록을 읽지 못한 폴더를 오류 없이 건너뛰고 폴더를 가리키는 링크를 따라가지 않는다 [8].
그래서 그런 폴더 아래 파일은 해시하지 않고 응답에도 싣지 않는다 [2][8].
권한을 없앤 하위 폴더와 폴더 링크를 둔 시험 폴더에서 두 곳 아래 파일은 응답에 없었다 [5].
파일을 가리키는 링크는 링크 대상의 내용을 해시하고 키에는 링크 경로를 적는다 [2].
시험 폴더 밖 파일을 가리키는 링크의 값은 그 대상 파일의 SHA-256이었다 [5].

[1] `file_metadata`는 `SAFE_BASE` 안의 파일 내용 전체를 해시한다.

```python
@mcp.tool()
def file_metadata(path: str) -> dict:
    """
    Return metadata and SHA-256 hash for a file within the SAFE_BASE directory.
    """
    if not is_safe_path(path):
        return {"error": "Access denied: path is outside the allowed directory scope."}

    try:
        stat = os.stat(path)
        with open(path, "rb") as f:
            content = f.read()
        return {
            "size_bytes": stat.st_size,
            "created_at": datetime.datetime.fromtimestamp(stat.st_ctime).isoformat(),
            "modified_at": datetime.datetime.fromtimestamp(stat.st_mtime).isoformat(),
            "sha256": hashlib.sha256(content).hexdigest(),
        }
    except Exception as e:
        return {"error": str(e)}
```

```python
@mcp.tool()
def hash_directory(path: str) -> dict:
    """
    Recursively compute SHA-256 hashes for all files in a directory.
    """
    if not os.path.isdir(path):
        return {"error": "Provided path is not a directory."}

    results = {}
    for root, _, files in os.walk(path):
        for f in files:
            full_path = os.path.join(root, f)
            try:
                with open(full_path, "rb") as fp:
                    content = fp.read()
                    results[full_path] = hashlib.sha256(content).hexdigest()
            except Exception as e:
                results[full_path] = f"Error: {str(e)}"
    return results
```
