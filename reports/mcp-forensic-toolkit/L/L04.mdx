# L04 기록 위변조 방지

### 비적용

**판단.** 서버는 MCP 도구 호출의 기록을 담은 파일이나 DB를 만들지 않는다 [1].
`server.py`는 `logging`을 불러오지 않고 파일을 쓰는 곳도 없다 [1][2].
서버 프로세스의 표준 오류에는 MCP Python SDK 1.9.3의 요청 종류 줄이 나간다 [3].
이 출력을 어디에 어떻게 남길지는 서버를 실행한 MCP 클라이언트가 정한다 [3].
서버 기록이 없으므로 수정, 삭제, 순서 변경을 막거나 찾아내는 장치를 볼 대상이 없다.

`file_metadata`와 `hash_directory`가 계산하는 SHA-256은 호스트 파일의 해시이고 기록의 해시가 아니다 [4].

    results = {}
    for root, _, files in os.walk(path):
        for f in files:
            full_path = os.path.join(root, f)
            try:
                with open(full_path, "rb") as fp:
                    content = fp.read()
                    results[full_path] = hashlib.sha256(content).hexdigest()
            except Exception as e:
                results[full_path] = f"Error: {str(e)}"
