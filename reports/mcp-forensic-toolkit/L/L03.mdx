# L03 기록 실패 처리

### 비적용

**판단.** 서버는 MCP 도구 호출의 기록을 쓰지 않는다 [1].
`server.py`는 `logging`을 불러오지 않고 파일을 쓰는 곳도 없다 [1][2].
서버 프로세스의 표준 오류에 남는 줄은 MCP Python SDK 1.9.3이 쓰는 요청 종류 줄이다 [3].
기록을 쓰는 호출이 없으므로 쓰기가 실패할 때의 처리를 볼 대상이 없다.

### 근거

[1] 서버 코드 전체에 기록하는 곳과 파일을 쓰는 곳이 없다: [`mcp_forensic_toolkit/server.py:1-227`](https://github.com/axdithyaxo/mcp-forensic-toolkit/blob/b81db06088b2b5a3003549c98592fde40f8f3c58/mcp_forensic_toolkit/server.py#L1-L227).
