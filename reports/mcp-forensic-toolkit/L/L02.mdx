# L02 기록 구성

### 비적용

**판단.** 서버는 MCP 도구 호출을 파일이나 DB에 기록하지 않는다 [1].
`server.py`는 `logging`을 불러오지 않고 파일을 쓰는 곳도 없다 [1][2].
MCP Python SDK 1.9.3이 표준 오류에 쓰는 줄은 요청 종류뿐이고 도구 이름과 인자는 담지 않는다 [3].
서버 기록이 없으므로 요청, 처리, 결과 상태, 결과 참조를 무엇으로 남기는지 볼 대상이 없다.
