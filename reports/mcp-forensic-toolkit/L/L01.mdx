# L01 기록 방식

### 미구현

**판단.** 서버 코드에는 MCP 도구 호출을 기록하는 코드가 없다 [1].
`server.py`는 `logging`을 불러오지 않고 파일을 쓰는 곳도 없다 [1][2].

서버는 MCP Python SDK 1.9.3의 `FastMCP`를 기본 로그 설정으로 만든다 [3].
SDK 1.9.3의 `FastMCP`는 만들어질 때 루트 로거를 `INFO` 수준으로 설정하고 표준 오류로 내보낸다 [4].
SDK의 요청 처리기는 요청마다 `Processing request of type CallToolRequest`처럼 요청 종류만 `INFO`로 쓴다 [5].
이 줄에는 도구 이름과 인자가 없다 [5].
도구 함수가 오류를 돌려주거나 인자 검사가 실패해도 SDK는 로그를 쓰지 않고 오류 결과만 돌려준다 [6].
도구 호출 26번을 보낸 서버의 표준 오류에는 `Processing request of type …` 줄만 남았다 [7].
그래서 도구 호출에는 도구 이름도 인자도 담지 않는 진단 줄만 남는다 [5][7].

`cli_demo.py`는 `generate_forensic_report`를 직접 불러 결과를 화면에 출력하는 사용자 CLI이고 MCP 서버를 거치지 않으며 기록을 남기지 않는다 [8].
저장소에는 MCP 클라이언트 설정 파일과 훅이 없고 README는 Claude Desktop에 서버를 등록하는 설정 예시만 적는다 [9].

[8] `cli_demo.py`는 서버 함수를 직접 불러 출력한다.

```python
import argparse
from server import generate_forensic_report

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Run forensic correlation analysis.")
    parser.add_argument("filename", help="Path to the file to analyze")
    parser.add_argument("keyword", nargs="?", default="modified", help="Keyword to search in logs")
    args = parser.parse_args()

    report = generate_forensic_report(args.filename, args.keyword)

    if report.get("status") == "error":
        print("Failed:", report.get("message", "Unknown error"))
    else:
        print(f"File: {report['filename']}")
        print(f"Keyword searched in logs: '{report['keyword']}'")
        print(f"File modified at: {report['file_modified_time']}")
        print("Matching log entries (sample):")
        for line in report.get("log_hits", []):
            print("  •", line.strip())
        print("\n✅ Correlation found:" if report["correlation_found"] else "\nCorrelation found: No")
```
