# mcp-forensic-toolkit 원고

이 파일은 서버 개요다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 그 방식이 적용되지 않는 경로나 조건이 있으면 **한계**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`b81db06`](https://github.com/axdithyaxo/mcp-forensic-toolkit/tree/b81db06088b2b5a3003549c98592fde40f8f3c58)(2025-06-10).
줄 번호는 모두 이 커밋 기준이다.

**범위.** 패키지 `mcp_forensic_toolkit`의 `server.py`가 MCP 서버 하나다.
`server.py`는 MCP Python SDK의 `FastMCP`로 서버(이름 `ForensicToolkit`)를 만들고 도구 5개, 리소스 1개(`toolkit://about`), 프롬프트 4개를 등록하며 초기화 지침은 두지 않는다(실행 확인).
도구는 서버를 실행한 호스트의 시스템 로그에서 키워드를 찾는 `scan_syslog`, 환경변수 `SAFE_BASE` 아래 파일의 메타데이터와 SHA-256을 내는 `file_metadata`·`hash_directory`, 두 결과를 묶는 `correlate_file_and_logs`·`generate_forensic_report`다.
`server.py`에는 서버를 시작하는 진입점이 없다.
README는 MCP CLI의 `mcp dev`로 서버를 띄우게 한다.
시스템 로그는 Linux에서 `/var/log/syslog`를 읽고 macOS에서 `log` 명령을 실행해 얻는다.
이 명령은 서버가 실행하는 도구로 본다.

`mcp_forensic_toolkit/cli_demo.py`는 서버 함수를 불러 쓰는 사용자 CLI다.
`tests/`, `docs/`, `assets/`, `.Rhistory`, `.github/`는 서버 구현으로 보지 않는다.
저장소에는 MCP 클라이언트 설정 파일이나 훅이 없다.
README의 설명(보장 문구)은 코드로 확인한 것만 사실로 쓴다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
라이브러리 동작은 아래 버전 기준의 소스로 확인했다.
근거의 "실행 확인"은 기준 커밋을 `git archive`로 풀어 둔 사본을 Docker 컨테이너에서 실행해 본 결과다.
컨테이너는 `.python-version`이 정한 Python 3.11.9의 `python:3.11.9-slim`에 `uv.lock`의 버전을 제약으로 의존성을 설치한 것이다.
`uv.lock`에는 MCP CLI가 들어 있지 않으므로 서버는 `server.py`를 불러 `FastMCP` 객체의 `run()`을 stdio로 실행해 띄웠다.
`SAFE_BASE`와 시스템 로그 파일은 컨테이너 안의 시험 폴더와 시험 파일로 주었고 이 호스트의 로그와 파일은 읽지 않았다.
컨테이너는 네트워크를 끈 상태(`--network none`)로 실행했다.

**외부 도구 버전 기준.** `pyproject.toml`은 `mcp (>=1.9.3,<2.0.0)`처럼 범위로만 적고 `uv.lock`이 모든 의존성의 버전을 고정한다.
그래서 의존성은 잠금 파일의 버전을 쓴다(MCP Python SDK 1.9.3, pydantic 2.11.5, python-dotenv 1.1.0).
`requirements.txt`는 다른 패키지 `fastmcp==2.7.0`을 적지만 서버 코드는 MCP SDK의 `mcp.server.fastmcp`를 불러오므로 이 패키지는 서버가 쓰지 않는다.
Python은 `.python-version`의 3.11.9다.

- MCP Python SDK 1.9.3의 소스는 태그 `v1.9.3`의 커밋 `5441767`, CPython 3.11.9의 소스는 태그 `v3.11.9`의 커밋 `de54cf5`로 확인한다.
- macOS `log` 명령은 소스가 공개되지 않아 Apple 문서 「Viewing Log Messages」만 근거로 쓰고 실행하지 않았다.
- 원고에서 인용한 그 밖의 버전과 소스 커밋은 이 단락에 더한다.

**바뀔 수 있는 것.** 범위와 외부 도구 버전 기준은 조사하며 맞지 않는 곳이 나오면 검토를 거쳐 바꾼다.
