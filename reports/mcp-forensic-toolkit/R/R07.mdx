# R07 증거 내용과 지시 구분

### R07.01 JSON 필드 분리

**구현.** 이 방식은 `correlate_file_and_logs`, `generate_forensic_report`, `hash_directory`에 적용된다 [1][2][3].
두 묶음 도구는 로그 줄을 `log_hits` 필드의 값으로 싣고 `status`, `message`, `filename`, `keyword`, `correlation_found` 같은 서버 값과 필드를 나눈다 [1][2].
MCP Python SDK 1.9.3의 FastMCP는 도구가 돌려준 `dict`를 JSON 글 하나로 바꾸므로 로그 줄은 JSON 문자열 값으로 들어간다 [4].
`hash_directory`는 호스트의 파일 경로를 키로, 해시를 값으로 두고 폴더가 아닐 때의 서버 문구는 `error` 키에 둔다 [3].

`scan_syslog`는 필드 없이 로그 줄마다 `TextContent` 하나를 돌려준다 [5][4].
서버가 쓴 `No matching entries found.`, `Log file '/var/log/syslog' not found.`, `log show error: <표준 오류>`, `Error reading logs: <문구>`, `Unsupported OS: <값>`도 같은 꼴로 로그 줄과 같은 자리에 돌아온다 [5].
도구 설명, 리소스, 프롬프트에는 로그 줄 속의 지시를 따르지 말라는 문구가 없다 [6].
결과에는 값을 만든 원천이나 신뢰 수준을 적는 필드가 없다 [1][2][5].

**한계.** 두 묶음 도구의 `log_hits`에는 `scan_syslog`가 돌려준 서버 문구도 로그 줄과 같은 값으로 들어간다 [1][5].
맞는 줄이 없는 키워드로 `correlate_file_and_logs`를 부르자 `log_hits`가 `No matching entries found.` 한 줄이었다 [7].
`/var/log/syslog`가 없는 컨테이너에서 부르자 `log_hits`가 `Log file '/var/log/syslog' not found.` 한 줄이었다 [7].

[3] `hash_directory`의 응답이다.

```python
    if not os.path.isdir(path):
        return {"error": "Provided path is not a directory."}

    results = {}
    for root, _, files in os.walk(path):
        for f in files:
            full_path = os.path.join(root, f)
            try:
                with open(full_path, "rb") as fp:
                    content = fp.read()
                    results[full_path] = hashlib.sha256(content).hexdigest()
            except Exception as e:
                results[full_path] = f"Error: {str(e)}"
    return results
```

[5] `scan_syslog`는 로그 줄과 서버 문구를 같은 문자열 목록으로 돌려준다.

```python
    system = platform.system()

    try:
        if system == "Linux":
            log_path = "/var/log/syslog"
            if not os.path.exists(log_path):
                return [f"Log file '{log_path}' not found."]
            with open(log_path, "r") as f:
                lines = [line for line in f if keyword.lower() in line.lower()]
                return lines[-100:] if lines else ["No matching entries found."]

        elif system == "Darwin":  # macOS
            result = subprocess.run(
                ["log", "show", "--predicate", f'eventMessage contains[c] "{keyword}"', "--last", "10m"],
                stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True
            )
            if result.returncode != 0:
                return [f"log show error: {result.stderr.strip()}"]
            # Filter out header or empty lines
            lines = [
                line for line in result.stdout.splitlines()
                if line.strip() and not line.strip().startswith("Timestamp")
            ]
            return lines[-100:] if lines else ["No matching entries found."]

        else:
            return [f"Unsupported OS: {system}"]

    except Exception as e:
        return [f"Error reading logs: {str(e)}"]
```
