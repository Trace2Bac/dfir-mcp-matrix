# P06 조사 상태 유지

### 미구현

**판단.** 서버는 조사 상태를 두지 않는다.
도구는 호출마다 시스템 로그와 파일을 다시 읽어 응답을 만들고 결과를 보관하지 않는다 [1][2].
`correlate_file_and_logs`도 호출마다 `scan_syslog`와 `file_metadata`를 다시 부른다 [3].
요청 사이에 프로세스에 남는 값은 시작할 때 읽은 `SAFE_BASE`와 도구를 등록한 `FastMCP` 객체 `mcp`다 [4].
이 값은 설정과 서버 객체이고 조사에서 부른 도구나 받은 결과를 담지 않는다 [4].
조사 상태를 지니는 것은 클라이언트와 모델이다.
