# P04 조사 단위 관리

### 미구현

**판단.** 서버에는 사건 ID나 세션 ID가 없다.
도구는 호출마다 키워드나 파일·폴더 경로를 인자로 받고 그 호출이 어느 조사에 속하는지 구별하지 않는다 [1].
서버는 증거, 기록, 파생물을 둘 폴더 배치를 정하지 않는다.
`SAFE_BASE`는 `file_metadata`가 읽을 경로를 한정하는 기준 폴더 하나이고 조사마다 나뉘지 않는다 [2].
서버 코드에는 세션이나 연결별로 상태를 나누는 코드가 없다 [3].
