# P05 사건 자료 정리

### 비적용

**판단.** 서버는 사건 자료를 파일, DB, 메모리 어디에도 남기지 않는다.
서버 코드에는 파일을 쓰는 호출이 없다 [1][2].
모듈 수준에 남는 값은 `SAFE_BASE`와 `FastMCP` 객체 `mcp`이고 도구는 호출 사이에 값을 모아 두지 않는다 [3].
서버는 호출 기록을 남기지 않는다 [1].
서버에는 자료를 지우거나 초기화하는 도구나 명령도 없다 [1].

### 근거

[1] 서버 코드 전체다: [`mcp_forensic_toolkit/server.py:1-227`](https://github.com/axdithyaxo/mcp-forensic-toolkit/blob/b81db06088b2b5a3003549c98592fde40f8f3c58/mcp_forensic_toolkit/server.py#L1-L227).

[2] (실행 확인) 컨테이너 안에 시험용 `/var/log/syslog`와 시험 파일을 만들고 도구 함수를 모두 부른 전후로 작업 폴더, `/tmp`, 서버 설치 폴더의 파일과 수정 시각을 대조하자 새로 생기거나 바뀐 파일이 없었다.

[3] 모듈 수준의 값이다.

```python
load_dotenv()

SAFE_BASE = os.getenv("SAFE_BASE")
if not SAFE_BASE:
    raise RuntimeError("SAFE_BASE is not set. Please define it in your .env file.")

# -------------------- Helpers --------------------
def is_safe_path(path: str, base_dir: str = SAFE_BASE) -> bool:
    return os.path.abspath(path).startswith(os.path.abspath(base_dir))

# -------------------- MCP Server --------------------
mcp = FastMCP("ForensicToolkit")
```
