# T05 분석 도구 검증

### 미구현

**판단.** 서버가 코드 밖에서 쓰는 분석 도구는 macOS에서 실행하는 `log` 명령이고 서버는 그 버전을 고정하지도, 설정으로 정하지도, 실행할 때 확인하지도 않는다 [1].
`scan_syslog`는 `PATH`에서 찾은 `log`를 실행하고 그 위치나 버전을 정하는 설정이나 인자는 없다 [1][2].
Apple 문서는 명령 줄에서 로그를 읽는 도구로 `log`를 안내한다 [3].
저장소의 설치 정의인 `pyproject.toml`, `uv.lock`, `poetry.lock`, `requirements.txt`에는 이 명령이 없다 [4].
서버는 macOS나 `log`의 버전을 읽지 않는다 [1].
참조 자료(룰, 시그니처, 목록)는 없다 [5].

Linux 경로와 파일 도구는 Python 표준 라이브러리(`os`, `hashlib`, `datetime`)로 분석한다 [5].
`.python-version`은 Python 3.11.9를 적고 `pyproject.toml`은 Python 3.10 이상을 적는다 [6][4].
표준 라이브러리는 서버를 실행하는 Python의 일부로 보고 분석 도구로 보지 않았다.
`uv.lock`이 고정하는 MCP Python SDK 1.9.3, pydantic 2.11.5, python-dotenv 1.1.0은 증거를 해석하지 않는 서버 실행용 라이브러리다 [4].
