# T09 대상 시스템 대응 조치 처리

### 비적용

**판단.** 서버는 조사하는 대상 시스템을 바꾸는 기능을 두지 않는다.
서버가 조사하는 곳은 서버를 실행한 호스트이고 도구는 그 호스트의 시스템 로그와 파일을 읽기만 한다 [1][2][3].
`scan_syslog`는 `/var/log/syslog`를 읽기 모드로 열거나 `log show`를 실행한다 [1].
`file_metadata`와 `hash_directory`는 파일을 `rb` 모드로 열어 읽는다 [2][3].
서버 코드에는 파일을 쓰거나 지우는 곳과 프로세스, 계정, 설정을 바꾸는 곳이 없다 [4].
README도 시스템 로그를 읽기 전용으로 다룬다고 적는다 [5].

### 근거

[1] `scan_syslog`는 로그 파일을 읽기 모드로 열거나 `log show`를 실행한다.

            )

[3] `hash_directory`는 파일을 읽기만 한다.

```python
    results = {}
    for root, _, files in os.walk(path):
        for f in files:
            full_path = os.path.join(root, f)
            try:
                with open(full_path, "rb") as fp:
                    content = fp.read()
                    results[full_path] = hashlib.sha256(content).hexdigest()
            except Exception as e:
                results[full_path] = f"Error: {str(e)}"
    return results
```
