# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 스스로 외부에 연결하지 않는다 [1].
`server.py`는 표준 라이브러리 `os`·`hashlib`·`datetime`·`platform`·`subprocess`와 `dotenv`, `mcp`만 불러오고 네트워크 모듈(`socket`·`urllib`·`http`)을 불러오지 않는다 [1].
`subprocess`는 macOS에서 로컬 `log` 명령 하나를 실행하는 데만 쓴다 [2].
`load_dotenv`는 로컬 `.env` 파일을 읽어 환경변수로 올린다 [3].
네트워크를 끈 컨테이너에서 도구 5개는 모두 응답을 돌려주었다 [4].

### 근거

[1] 서버가 불러오는 모듈이다.

```python
import os
import hashlib
import datetime
import platform
import subprocess
from dotenv import load_dotenv
from mcp.server.fastmcp.server import FastMCP
```
