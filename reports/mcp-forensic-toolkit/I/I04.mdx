# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다.
서버는 네트워크 모듈을 불러오지 않고 외부 연결을 열지 않는다 [1].
서버 코드가 읽는 환경변수는 `SAFE_BASE` 하나이고 이 값은 읽을 경로의 기준 폴더다 [2].
도구 인자에도 자격증명을 받는 인자가 없다 [3].

### 근거

import os
import hashlib

from mcp.server.fastmcp.server import FastMCP

[2] 서버가 읽는 환경변수다.

```python
# -------------------- Load Environment --------------------
load_dotenv()

SAFE_BASE = os.getenv("SAFE_BASE")
if not SAFE_BASE:
    raise RuntimeError("SAFE_BASE is not set. Please define it in your .env file.")

# -------------------- Helpers --------------------
def is_safe_path(path: str, base_dir: str = SAFE_BASE) -> bool:
    return os.path.abspath(path).startswith(os.path.abspath(base_dir))
```
