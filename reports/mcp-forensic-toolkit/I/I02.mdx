# I02 분석 도구 통신 차단

### 미구현

**판단.** 서버는 macOS에서 `log` 명령을 실행하지만 그 명령의 통신을 끊거나 끄는 장치가 없다 [1].
`scan_syslog`는 `log show`를 `subprocess.run`으로 실행하고 네트워크를 끊는 옵션이나 실행 환경을 주지 않는다 [1].
하위 프로세스는 서버의 환경변수를 그대로 물려받는다 [1].
저장소에는 네트워크를 끊는 실행 구성(컨테이너 설정 등)이 없다 [2].
`log` 명령이 스스로 통신하는지는 Apple 문서에 적혀 있지 않아 확인하지 못했다 [3].

Linux에서는 외부 명령을 실행하지 않고 서버 코드가 `/var/log/syslog`를 직접 읽는다 [4].
해시는 표준 라이브러리 `hashlib`로 계산한다 [5].
