# D01 파생물 보관

### 미구현

**판단.** 서버는 도구 결과를 응답으로 돌려주기만 하고 파일이나 DB에 남기지 않는다.
도구 5개는 결과를 `list`나 `dict`로 돌려준다 [1].
MCP Python SDK 1.9.3의 `FastMCP`는 `list`의 항목마다 글 하나를 만들고 `dict`는 JSON 글로 바꿔 응답에 싣는다 [2].
`scan_syslog`가 macOS에서 실행하는 `log show`의 표준 출력도 줄로 나눠 응답에만 싣는다 [3].
서버 코드에는 파일을 쓰거나 폴더를 만드는 호출이 없고 서버가 여는 파일은 모두 읽기 모드로 연다 [4].
서버가 시작할 때 `load_dotenv`가 `.env` 파일을 읽는 것도 읽기다 [5].
도구를 모두 부른 뒤 새로 생기거나 바뀐 파일이 없었다 [6].
같은 저장소의 사용자 CLI `cli_demo.py`는 `generate_forensic_report`의 결과를 표준 출력에 적고 파일을 쓰지 않는다 [7].
