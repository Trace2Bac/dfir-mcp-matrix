# D04 출력 경로 제한

### 비적용

**판단.** 서버는 파생물을 담은 파일이나 DB를 만들거나 고치거나 지우지 않는다.
서버 코드에는 파일을 쓰거나 지우는 호출이 없다 [1][2].
도구의 경로 인자 `path`와 `filename`은 읽을 대상을 가리키고 출력 위치를 받는 인자는 없다 [3].
`SAFE_BASE`는 `file_metadata`가 읽을 경로를 대조하는 기준 폴더이고 쓰기 위치가 아니다 [4].

```python
SAFE_BASE = os.getenv("SAFE_BASE")
if not SAFE_BASE:
    raise RuntimeError("SAFE_BASE is not set. Please define it in your .env file.")

# -------------------- Helpers --------------------
def is_safe_path(path: str, base_dir: str = SAFE_BASE) -> bool:
    return os.path.abspath(path).startswith(os.path.abspath(base_dir))
```
