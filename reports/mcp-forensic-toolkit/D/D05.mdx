# D05 파생물 저장 실패 처리

### 비적용

**판단.** 서버는 도구 출력, 파생물, 보고 산출물을 저장하지 않고 응답으로만 돌려준다.
서버 코드에는 파일이나 DB에 쓰는 호출이 없어 저장이 실패하는 경로가 없다 [1][2].
`generate_forensic_report`도 결과를 `dict`로 돌려줄 뿐 파일을 쓰지 않는다 [3].
같은 저장소의 사용자 CLI `cli_demo.py`는 이 결과를 표준 출력에 적는다 [4].

### 근거

[1] 서버 코드 전체다: [`mcp_forensic_toolkit/server.py:1-227`](https://github.com/axdithyaxo/mcp-forensic-toolkit/blob/b81db06088b2b5a3003549c98592fde40f8f3c58/mcp_forensic_toolkit/server.py#L1-L227).

[2] (실행 확인) 컨테이너 안에 시험용 `/var/log/syslog`와 시험 파일을 만들고 도구 함수를 모두 부른 전후로 작업 폴더, `/tmp`, 서버 설치 폴더의 파일과 수정 시각을 대조하자 새로 생기거나 바뀐 파일이 없었다.

[3] `generate_forensic_report`는 `dict`를 돌려준다.

```python
    result = correlate_file_and_logs(filename, keyword)
    if "error" in result:
        return {
            "status": "error",
            "message": result["error"],
            "filename": filename,
            "keyword": keyword
        }

    return {
        "status": "ok",
        "filename": result["filename"],
        "keyword": result["keyword"],
        "file_modified_time": result["file_modified_time"],
        "log_hits": result["log_hits"],
        "correlation_found": result["correlation_found"]
    }
```

[4] 사용자 CLI는 결과를 출력한다.

```python
    report = generate_forensic_report(args.filename, args.keyword)

    if report.get("status") == "error":
        print("Failed:", report.get("message", "Unknown error"))
    else:
        print(f"File: {report['filename']}")
        print(f"Keyword searched in logs: '{report['keyword']}'")
        print(f"File modified at: {report['file_modified_time']}")
        print("Matching log entries (sample):")
        for line in report.get("log_hits", []):
            print("  •", line.strip())
        print("\n✅ Correlation found:" if report["correlation_found"] else "\nCorrelation found: No")
```
