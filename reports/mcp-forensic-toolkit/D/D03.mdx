# D03 파생물 무결성 검증

### 비적용

**판단.** 서버는 파생물을 남기지 않는다.
도구 결과는 응답으로만 나가고 서버 코드에는 파일이나 DB에 쓰는 호출이 없다 [1][2].
`file_metadata`와 `hash_directory`가 계산하는 SHA-256은 도구 인자로 받은 파일의 해시이고 응답에만 실린다 [3].
서버는 응답이나 응답의 해시를 남기지 않는다 [1].

### 근거

[1] 서버 코드 전체다: [`mcp_forensic_toolkit/server.py:1-227`](https://github.com/axdithyaxo/mcp-forensic-toolkit/blob/b81db06088b2b5a3003549c98592fde40f8f3c58/mcp_forensic_toolkit/server.py#L1-L227).

[2] (실행 확인) 컨테이너 안에 시험용 `/var/log/syslog`와 시험 파일을 만들고 도구 함수를 모두 부른 전후로 작업 폴더, `/tmp`, 서버 설치 폴더의 파일과 수정 시각을 대조하자 새로 생기거나 바뀐 파일이 없었다.

[3] 두 도구는 받은 파일의 해시를 응답에 싣는다.

```python
    results = {}
    for root, _, files in os.walk(path):
        for f in files:
            full_path = os.path.join(root, f)
            try:
                with open(full_path, "rb") as fp:
                    content = fp.read()
                    results[full_path] = hashlib.sha256(content).hexdigest()
            except Exception as e:
                results[full_path] = f"Error: {str(e)}"
    return results
```
