# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
서버가 불러오는 모듈은 표준 라이브러리, `dotenv`, `mcp`이고 모델 API 클라이언트가 없다 [1].
도구 함수 5개는 `Context`를 인자로 받지 않아 클라이언트에 모델 호출(sampling)을 요청하지 않는다 [2].
프롬프트 4개는 사용자가 고르면 클라이언트 모델에게 가는 글이다 [3].
