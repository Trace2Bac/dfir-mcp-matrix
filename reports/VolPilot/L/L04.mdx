# L04 기록 위변조 방지

### 비적용

**판단.** 서버는 MCP 도구 호출의 기록을 담은 파일이나 DB를 만들지 않는다 [1].
서버 코드가 로거에 남기는 줄은 시작할 때의 이미지 쓰기 권한 경고 하나다 [2].
서버 프로세스의 표준 오류에는 MCP Python SDK 1.27.0과 Volatility 3의 진단 줄이 함께 나간다 [3].
이 출력을 어디에 어떻게 남길지는 서버를 실행한 MCP 클라이언트가 정한다 [3].
서버 기록이 없으므로 수정, 삭제, 순서 변경을 막거나 찾아내는 장치를 볼 대상이 없다.

`verify_image_integrity`가 다시 계산해 대조하는 해시는 메모리 이미지의 해시이고 기록의 해시가 아니다 [4].
