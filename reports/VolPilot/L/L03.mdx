# L03 기록 실패 처리

### 비적용

**판단.** 서버는 MCP 도구 호출의 기록을 쓰지 않는다 [1].
서버 코드가 로거를 쓰는 곳은 시작할 때 이미지 파일의 쓰기 권한을 확인하는 `Session._verify_read_only` 하나다 [2].
서버 프로세스의 표준 오류에 남는 그 밖의 줄은 MCP Python SDK 1.27.0과 Volatility 3의 진단 줄이다 [3].
기록을 쓰는 호출이 없으므로 쓰기가 실패할 때의 처리를 볼 대상이 없다.
