# L02 기록 구성

### 비적용

**판단.** 서버는 MCP 도구 호출을 파일이나 DB에 기록하지 않는다 [1].
서버 코드가 로거에 남기는 줄은 시작할 때 이미지 파일에 쓰기 권한이 있다는 경고 하나다 [2].
MCP Python SDK 1.27.0이 표준 오류에 쓰는 줄은 요청 종류와 목록에 없는 도구 이름뿐이고 등록된 도구의 이름과 인자는 담지 않는다 [3].
Volatility 3가 같은 표준 오류에 쓰는 automagic 진단 줄에도 도구 이름과 인자가 없다 [4].
서버 기록이 없으므로 요청, 처리, 결과 상태, 결과 참조를 무엇으로 남기는지 볼 대상이 없다.

            json.dump(config_dict, f, sort_keys=True, indent=2)
            f.write("\n")
