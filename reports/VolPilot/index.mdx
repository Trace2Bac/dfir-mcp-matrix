# VolPilot 원고

이 파일은 서버 개요다. 셀마다 이 폴더 아래 축 폴더의 `<축>/<셀ID>.mdx`에 쓴다.
셀과 상세 항목의 정의는 `matrix/cells/<축>/<셀ID>.mdx`를 따른다.
상세 항목마다 **구현**을 쓰고 그 방식이 적용되지 않는 경로나 조건이 있으면 **한계**를 따로 쓴다.
본문의 [번호]는 그 파일 끝 **근거**의 같은 번호를 가리킨다.

**기준 커밋.** [`5c84851`](https://github.com/cpuu/VolPilot/tree/5c848519cfa2e86a86abbe613c7249fddeffc6df)(2026-10-06).
줄 번호는 모두 이 커밋 기준이다.

**범위.** 저장소 최상위의 `mcp_server.py`, `session.py`, `plugins/`가 MCP 서버 하나다.
`mcp_server.py`가 MCP Python SDK의 `FastMCP`로 서버(이름 `VolPilot`)를 만들고 도구 96개와 초기화 지침(`instructions`)을 등록하며 리소스와 프롬프트는 두지 않는다(실행 확인).
도구는 Volatility 3 Windows 플러그인을 하나씩 감싼 도구 88개, 여러 플러그인 결과를 서버 규칙으로 대조하는 도구 7개, 이미지 해시를 다시 대조하는 `verify_image_integrity`다.
진입점은 `python mcp_server.py`이고 전송은 stdio다.
`session.py`는 서버를 시작할 때 환경변수 `VOL_IMAGE_PATH`의 메모리 이미지 하나를 세션에 묶고 Volatility 3를 Python 라이브러리로 불러 플러그인을 실행한다.
Volatility 3는 서버가 라이브러리로 불러 쓰는 분석 도구로 본다.

저장소는 연구 논문의 공개 산출물이다.
`evaluation/`(실행 시간·출력 크기 비교, 플러그인 선택, 사용자 연구, 증거 보존 공격 시험의 자료·하네스·다른 서버용 패치)은 서버 구현으로 보지 않는다.
`README.md`, `TOOL_CATALOG.md`, `ARTIFACT.md`, `png/`는 문서다.
저장소에는 MCP 클라이언트 설정 파일이나 훅이 없고 README가 클라이언트 등록 예시만 적는다.
README와 평가 문서의 설명(보장 문구, 시험 결과 수치)은 코드로 확인한 것만 사실로 쓴다.

**확인 방법.** 코드는 기준 커밋을 `git show`로 읽었다.
분석 도구와 라이브러리의 동작은 아래 버전 기준의 소스로 확인했다.
근거의 "실행 확인"은 기준 커밋을 `git archive`로 풀어 둔 사본을 Docker 컨테이너에서 실행해 본 결과다.
컨테이너는 README가 고르는 Python 3.12의 `python:3.12-slim`(CPython 3.12.16)에 `uv.lock`의 버전을 제약으로 서버 의존성과 Volatility 3의 `full` 추가 의존성을 설치한 것이다.
Windows 메모리 이미지와 Windows 심볼 파일은 내려받지 않았다.
그래서 서버는 컨테이너 안에서 만든 무작위 바이트 파일을 이미지로 주어 시작했다.
플러그인 실행은 이미지 해석이 실패하는 경로와 서버 쪽 처리만 확인했다.
컨테이너는 네트워크를 끈 상태(`--network none`)로 실행했다.

**외부 도구 버전 기준.** `pyproject.toml`은 `volatility3==2.28.0`을 고정하고 `uv.lock`은 모든 의존성의 버전을 고정한다.
README는 `uv sync --frozen --python 3.12`로 이 잠금 파일대로 설치하게 한다.
그래서 의존성은 잠금 파일의 버전을 쓴다(Volatility 3 2.28.0, MCP Python SDK 1.27.0, pydantic 2.12.5, yara-python 4.5.4, capstone 5.0.9, pycryptodome 3.23.0).
Python은 README가 고르는 3.12다.

- Volatility 3 2.28.0의 소스는 태그 `v2.28.0`의 커밋 `d61335e`, MCP Python SDK 1.27.0의 소스는 태그 `v1.27.0`의 커밋 `6524782`로 확인한다.
- 라이브러리 근거의 줄 번호는 컨테이너에 설치한 같은 버전 파일에서 읽었고 링크는 위 태그 커밋으로 둔다.
- 원고에서 인용한 그 밖의 버전과 소스 커밋은 이 단락에 더한다.

**바뀔 수 있는 것.** 범위와 외부 도구 버전 기준은 조사하며 맞지 않는 곳이 나오면 검토를 거쳐 바꾼다.
