# P01 분석 방법 적합성 확인

### 미구현

**판단.** 서버는 이미지 형식이나 OS를 판별하지 않고 도구마다 정해 둔 Volatility 3 Windows 플러그인을 대조 없이 실행한다 [1][2].
플러그인 도구는 도구 하나에 `windows.pslist`처럼 Windows 플러그인 하나가 정해져 있다 [1].
서버는 시작할 때 이미지 경로를 Volatility 3 설정에 넣고 플러그인마다 Volatility 3가 고른 automagic을 실행한다 [3][2].
이미지의 계층 형식을 알아내고 Windows 커널과 심볼을 찾는 일은 Volatility 3의 automagic이 한다 [2].
서버 코드는 형식을 정하려고 이미지 이름이나 앞부분 바이트를 보지 않는다 [3][4].
무작위 바이트 파일을 이미지로 주고 `windows_info`를 부르자 `The plugin configuration failed to validate` 오류 응답이 돌아왔다 [5].
README는 지원하는 증거를 Windows 메모리 이미지로 적는다 [6].

`windows_info`는 OS 버전과 `Is64Bit` 같은 값을 돌려주지만 서버는 이 값으로 도구나 플러그인을 고르지 않는다 [7].
`windows_info`의 설명은 OS 버전을 보고 어떤 아티팩트와 동작을 기대할지 정하라고 모델에게 적는다 [7].

일부 도구는 플러그인이 이미지에 맞지 않아 끝난 경우를 빈 결과로 바꾼다.
`windows_crashinfo`는 이미지가 crash dump가 아니어서 플러그인이 `No active exception to reraise` 문구의 `RuntimeError`로 끝나면 빈 결과를 돌려준다 [8].
`windows_virtmap`은 커널 심볼에 필요한 심볼이 없어 `SymbolError`가 나면 빈 결과를 돌려준다 [9].
`detect_service_tampering`은 `svclist` 결과가 비면 `os_compatible`을 거짓으로 두고 `svcscan`과의 비교를 건너뛴다 [10].
이 값은 OS를 판별한 결과가 아니라 `svclist` 결과가 비었는지다 [10].

```python
    def _verify_read_only(file_path: str) -> None:
        """Verify the image file is opened read-only.

        Opens the file with O_RDONLY to confirm read access, then checks
        whether the file is writable. If writable, logs a warning
        recommending the analyst set the file to read-only.
        """
        logger = logging.getLogger(__name__)
        fd = os.open(file_path, os.O_RDONLY)
        os.close(fd)
        if os.access(file_path, os.W_OK):
            logger.warning(
                "Image file is writable: %s — "
                "consider setting it to read-only (e.g., attrib +R or "
                "chmod 444) to prevent accidental modification.",
                file_path,
            )

    @staticmethod
    def _compute_sha256(file_path: str) -> str:
        """Compute SHA-256 hash of a file, reading in 64 KiB chunks."""
        h = hashlib.sha256()
        with open(file_path, "rb") as f:
            while chunk := f.read(65536):
                h.update(chunk)
        return h.hexdigest()
```

```python
def run_crashinfo(session: Session) -> dict:
    """Run windows.crashinfo and return crash dump header information.

    Only produces data when the image is an actual Windows crash dump
    (.dmp), not a raw/VM memory snapshot. volatility3's own plugin has a
    bug on that path: it logs "This plugin requires a Windows crash
    dump" and then executes a bare ``raise`` outside any except block,
    which Python turns into ``RuntimeError("No active exception to
    reraise")`` instead of returning cleanly. Caught here and translated
    into an empty result, matching how sibling tools (svclist, consoles,
    truecrypt, ...) report "not applicable to this image" without
    crashing the MCP call.
    """
    try:
        treegrid = run_plugin(session, crashinfo.Crashinfo)
    except RuntimeError as e:
        if "No active exception to reraise" in str(e):
            return {"plugin": "crashinfo", "results": []}
        raise
    return {"plugin": "crashinfo", "results": parse_treegrid(treegrid)}
```

```python
def run_virtmap(session: Session) -> dict:
    """Run windows.virtmap and return virtual mapped sections.

    Some Windows builds' kernel PDB lacks both symbols volatility3 knows
    how to read the system VA layout from (MiVisibleState,
    MiSystemVaType); the plugin raises SymbolError uncaught in that case
    instead of returning empty like similarly version-gated plugins
    (e.g. svclist). Caught here and translated into an empty result.
    """
    try:
        treegrid = run_plugin(session, virtmap.VirtMap)
    except exceptions.SymbolError:
        return {"plugin": "virtmap", "results": []}
    return {"plugin": "virtmap", "results": parse_treegrid(treegrid)}
```

```python
    svcscan_data = session.run_plugin("svcscan")
    svcscan_services = svcscan_data["results"]

    # Attempt svclist — may return empty on incompatible OS
    svclist_data = session.run_plugin("svclist")
    svclist_services = svclist_data["results"]

    os_compatible = len(svclist_services) > 0

    hidden_services: list[dict] = []
    if os_compatible:
        svclist_names = {s["Name"] for s in svclist_services if s.get("Name")}
        for svc in svcscan_services:
            name = svc.get("Name", "")
            if name and name not in svclist_names:
                hidden_services.append({**svc, "source": "svcscan_only"})

    # Also include malware.svcdiff results if available on this OS
    svcdiff_results = []
    if os_compatible:
        try:
            svcdiff_data = session.run_plugin("malware.svcdiff")
            svcdiff_results = svcdiff_data["results"]
        except Exception:
            pass  # svcdiff may fail on incompatible OS
```
