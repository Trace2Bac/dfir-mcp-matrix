# P04 조사 단위 관리

### 미구현

**판단.** 서버에는 사건이나 세션 같은 조사 단위를 정하거나 나누는 장치가 없다.
서버 프로세스 하나는 시작할 때 `VOL_IMAGE_PATH`로 받은 이미지 하나만 다루고 모듈 변수 `session` 하나를 모든 도구가 함께 쓴다 [1].
도구는 사건 ID나 세션 ID를 받지 않는다 [2].
결과 캐시, Volatility 3 문맥, 저장한 설정은 이 `Session` 객체에 하나씩 있다 [3].
저장한 설정의 파일 이름은 이미지 경로 뒤에 `.vol3cfg.json`을 붙여 정하고 사건을 가리키는 값은 담지 않는다 [3].
덤프 파일을 쓰는 폴더 `VOL_DUMP_DIR`은 사용자가 시작할 때 정하고 서버는 사건별 하위 폴더나 파일 이름을 정하지 않는다 [4][5].
서버는 stdio 전송으로만 실행하므로 서버 프로세스 하나에 연결이 하나다 [6].

        def close(self):
            if self.closed:
                return None
            self.seek(0)

            output_path = os.path.join(output_dir, self.preferred_filename)
            base, ext = os.path.splitext(output_path)
            counter = 1
            while os.path.exists(_long_path_safe(output_path)):
                output_path = f"{base}-{counter}{ext}"
                counter += 1
