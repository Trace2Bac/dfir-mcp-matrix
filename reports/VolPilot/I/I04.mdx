# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버가 읽는 환경변수는 이미지 경로 `VOL_IMAGE_PATH`와 덤프 폴더 `VOL_DUMP_DIR` 두 개다 [2].
서버가 부르는 Volatility 3 2.28.0의 심볼 내려받기는 인증 없이 심볼 서버 주소에 요청한다 [3].

`windows_registry_hashdump`, `windows_registry_lsadump`, `windows_registry_cachedump`, `windows_truecrypt`가 돌려주는 비밀번호 해시와 비밀은 증거에서 나온 값이고 서버가 외부 접속에 쓰는 자격증명이 아니다 [4].

### 근거

        """Run windows.registry.hashdump and return LM/NT password hashes.
