# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 스스로 외부에 연결하지 않는다 [1].
`mcp_server.py`, `session.py`, `plugins/`는 표준 라이브러리, `mcp`, `volatility3`만 불러오고 네트워크 모듈(`socket`·`urllib`·`http`)을 불러오지 않는다 [1].
서버는 stdio로 MCP 요청을 받는다 [2].
서버는 Volatility 3를 Python 라이브러리로 불러 이미지 파일 하나를 읽는다 [3].

Volatility 3 2.28.0은 Windows 커널의 심볼 표가 로컬에 없으면 Microsoft 심볼 서버에서 PDB를 받는다 [4].
이 연결은 서버 코드가 아니라 분석 라이브러리가 스스로 여는 연결이다 [4].
서버에는 외부 서비스에 묻는 도구가 없다 [1].
