# I03 외부 전송 범위 구성

### 비적용

**판단.** 서버 코드는 외부 서비스에 조사 자료를 보내지 않는다 [1].
서버 코드는 네트워크 모듈을 불러오지 않고 외부 서비스에 묻는 도구도 두지 않는다 [1].
서버는 stdio로 받은 MCP 요청에 응답만 돌려준다 [2].

서버가 부르는 Volatility 3 2.28.0이 심볼 서버에 보내는 요청은 이미지에서 찾은 커널 PDB의 이름, GUID, age로 만든 내려받기 주소다 [3].
이 요청은 서버 코드가 아니라 분석 라이브러리가 스스로 여는 연결에서 나간다 [3].

### 근거

[1] 서버 코드가 불러오는 모듈에 네트워크 모듈이 없다: [`mcp_server.py:3-8`](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/mcp_server.py#L3-L8), [`session.py:3-12`](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/session.py#L3-L12), [`plugins/_common.py:3-14`](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/plugins/_common.py#L3-L14).

[2] 진입점은 stdio 전송으로 서버를 실행한다.

```python

if __name__ == "__main__":
    mcp.run()
```
