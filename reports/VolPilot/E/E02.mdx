# E02 증거 무결성 검증

### E02.01 등록 시 기준값 자동 계산

**구현.** 이 방식은 서버를 시작할 때 `VOL_IMAGE_PATH`의 이미지로 `Session`을 만드는 경로에 적용된다 [1].
`Session`은 모델의 요청 없이 이미지 파일 전체의 SHA-256을 계산해 `image_sha256`에 둔다 [1].
해시 범위는 이미지 파일 하나의 처음부터 끝까지이고 `_compute_sha256`이 파일을 `rb` 모드로 64 KiB씩 읽는다 [2].
기준값은 서버 프로세스 메모리에만 두고 파일이나 기록에 쓰지 않는다 [1].
`windows_info`는 이 값을 응답의 `image.sha256`으로 돌려준다 [3].
그 설명은 이 값을 조사 처음의 기준값으로 적어 두고 보고하기 전에 `verify_image_integrity`로 다시 확인하라고 적는다 [3].
직접 만든 1 MiB 파일로 `Session`을 만들자 `image_sha256`은 Python `hashlib`로 계산한 값과 같았다 [4].
`Session`의 인자 `compute_hash`를 거짓으로 주면 해시를 계산하지 않지만 `mcp_server.py`는 이 인자를 주지 않는다 [1][5].
서버는 사용자나 수집 도구가 남긴 해시를 받지 않는다 [1].
그래서 서버를 시작하기 전에 바뀐 이미지는 바뀐 상태가 기준값이 된다.

**한계.** 해시 범위는 `VOL_IMAGE_PATH`의 파일 하나이고 Volatility 3가 그 이미지와 함께 읽는 파일은 포함되지 않는다 [2][6].
Volatility 3 2.28.0은 이미지 이름이 `.vmem`으로 끝나면 같은 이름의 `.vmss` 파일을, 없으면 `.vmsn` 파일을 찾아 함께 연다 [6].
README의 설정 예시는 이미지 경로를 `memory.vmem`으로 적는다 [7].

### E02.04 도구를 요청해 검증

**구현.** 이 방식은 `verify_image_integrity`에 적용된다 [8].
모델이 이 도구를 부르면 서버는 `_compute_sha256`으로 이미지 파일 전체의 SHA-256을 다시 계산해 시작할 때의 `image_sha256`과 대조한다 [8][2].
응답은 두 값이 같은지(`match`), 기준값(`expected_sha256`), 다시 계산한 값(`actual_sha256`), 경로, 크기, 대조한 시각(`verified_at`)을 싣는다 [8].
초기화 지침은 보고서를 만들기 전에 이 도구를 불러 이미지가 바뀌지 않았는지 확인하라고 적는다 [9].
stdio 클라이언트로 서버를 시작한 뒤 이미지 끝에 8바이트를 더하고 부르자 `match`가 거짓이고 `actual_sha256`이 기준값과 다른 응답이 돌아왔다 [10].
다른 도구는 호출 중에 이미지를 기준값과 대조하지 않고 플러그인을 실행하거나 결과 캐시를 돌려준다 [11].

**한계.** 해시가 어긋나도 서버는 `match`가 거짓인 정상 응답을 돌려줄 뿐 경고 문구를 붙이거나 이후 호출을 막지 않는다 [8][10].
도구 설명은 `match`가 거짓이면 앞의 분석 결과가 모두 무효일 수 있으므로 보고서에 무결성 훼손을 표시해야 한다고 적는다 [12].
응답의 `image_size`는 다시 읽은 크기가 아니라 시작할 때 읽은 값이다 [8].
8바이트를 더한 이미지에서도 응답의 `image_size`는 처음 값 1048576이었다 [10].
기준값은 서버를 시작할 때마다 새로 계산하므로 서버 실행 사이에 바뀐 이미지는 이 도구로 드러나지 않는다 [1].

[2] `_compute_sha256`은 파일을 `rb`로 열어 64 KiB씩 읽는다.

```python
    @staticmethod
    def _compute_sha256(file_path: str) -> str:
        """Compute SHA-256 hash of a file, reading in 64 KiB chunks."""
        h = hashlib.sha256()
        with open(file_path, "rb") as f:
            while chunk := f.read(65536):
                h.update(chunk)
        return h.hexdigest()
```

```python
    def run_plugin(self, plugin_name: str, **kwargs) -> dict:
        """Run a plugin by name, returning cached results if available.

        Extra kwargs are forwarded to the plugin's runner function and used
        to key the cache, so calling the same parameterized plugin twice
        with identical arguments returns the cached result, while different
        arguments trigger a fresh run.
        """
        cache_key = (plugin_name, frozenset(kwargs.items())) if kwargs else plugin_name
        if cache_key in self._cache:
            return self._cache[cache_key]
        if plugin_name not in PLUGIN_MAP:
            raise ValueError(f"Unknown plugin: {plugin_name}")
        result = PLUGIN_MAP[plugin_name](self, **kwargs)
        self._cache[cache_key] = result
        return result
```
