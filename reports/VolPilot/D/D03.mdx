# D03 파생물 무결성 검증

### 미구현

**판단.** 서버는 덤프 파일과 설정 파일을 남기지만 그 기준값을 계산하지도 대조하지도 않는다.
`DumpFileHandler`는 모은 바이트를 파일에 쓰기만 하고 해시나 크기를 계산하지 않는다 [1].
덤프 도구의 응답에는 파일 이름만 들어가고 해시가 없다 [2][3].
설정 파일은 쓴 뒤 다시 읽을 때 내용을 대조하지 않고 JSON으로 읽어 그대로 쓴다 [4].
파생물 경로를 받아 해시를 계산하거나 대조하는 도구가 없다 [5].

서버가 해시를 계산하는 대상은 원본 메모리 이미지 하나다.
`Session`은 시작할 때 이미지의 SHA-256을 계산하고 `verify_image_integrity`는 이를 다시 계산해 대조한다 [6][7].
