# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 플러그인을 감싼 도구와 `triage_process`, `network_process_correlation`, `detect_hidden_processes`에 적용된다 [1][2][3].
Volatility 3 2.28.0은 Windows 시각을 UTC 시간대가 붙은 `datetime`으로 돌려준다 [4].
서버의 `_serialize_value`는 이 `datetime`을 시각이나 시간대를 바꾸지 않고 `str`로 바꿔 싣는다 [1].
`wintime_to_datetime`이 만든 값은 `2026-03-15 14:22:01+00:00`이 되었다 [5].
시각이 0이거나 바꿀 수 없으면 Volatility 3는 값이 없다는 표시를 내고 서버는 이를 `None`으로 싣는다 [4][1][5].
`triage_process`와 `network_process_correlation`은 `pslist` 행의 `CreateTime` 문자열을 `create_time`에 그대로 옮긴다 [2].
`detect_hidden_processes`는 `psscan` 행을 시각 필드까지 그대로 싣는다 [3].

`build_timeline`은 이 방식을 쓰지 않는다 [6].
이 도구는 시각 문자열을 `_parse_timestamp`로 해석해 `isoformat()` 글로 바꾸고 원래 문자열은 싣지 않는다 [6].
`_parse_timestamp`는 시간대가 붙은 글을 해석하지 못하므로 Volatility 3가 낸 시각으로는 사건을 만들지 않는다 [6][5].

### R08.03 시간대·단위·정밀도 표시

**구현.** 이 방식은 플러그인을 감싼 도구와 Volatility 3 시각을 옮겨 싣는 교차 분석 도구에 적용된다 [1][2][3].
Volatility 3의 `datetime`에는 UTC 시간대가 붙어 있어 `str`로 바꾼 값 끝에 `+00:00`이 들어 있다 [4][1][5].
그래서 응답의 시각 값마다 시간대가 값으로 표시된다 [5].
`build_timeline`의 `timestamp`는 `_parse_timestamp`가 해석한 시간대 없는 시각의 `isoformat()` 글이라 `2026-03-15T14:22:01`처럼 오프셋이 붙지 않는다 [6][7].
Volatility 3 2.28.0이 낸 시각은 이 함수가 해석하지 못하므로 `timestamp`가 실린 사건은 시간대 없는 시각 글이 들어올 때만 만들어진다 [6][5].

**한계.** Volatility 3 2.28.0의 `wintime_to_datetime`은 100나노초 단위의 FILETIME을 초 단위로 버린 뒤 바꾼다 [4].
그래서 응답의 시각 값에는 초 아래 자리가 없고 응답은 그 정밀도를 적지 않는다 [1][4].

```python
def _serialize_value(val: Any) -> Any:
    """Convert a volatility3 rendered value to a JSON-serializable type."""
    if isinstance(val, BaseAbsentValue):
        return None
    if isinstance(val, format_hints.Hex):
        return hex(val)
    if isinstance(val, format_hints.MultiTypeData):
        return _serialize_multitypedata(val)
    if isinstance(val, renderers.LayerData):
        return _serialize_layerdata(val)
    if isinstance(val, renderers.Disassembly):
        return _bytes_to_hex(val.data)
    if isinstance(val, bytes):
        # Covers format_hints.HexBytes too (a plain bytes subclass).
        return _bytes_to_hex(val)
    if isinstance(val, (int, float, bool, str)):
        return val
    return str(val)
```

```python
def _parse_timestamp(val: str | None) -> str | None:
    """Normalize a Volatility3 timestamp string to ISO 8601, or None."""
    if not val or val == "N/A" or val == "None":
        return None
    val = val.strip()
    # Already ISO-ish: "2026-03-15 14:22:01.000000" → "2026-03-15T14:22:01"
    try:
        from datetime import datetime
        # Handle "YYYY-MM-DD HH:MM:SS.ffffff" (most common vol3 format)
        for fmt in ("%Y-%m-%d %H:%M:%S.%f", "%Y-%m-%d %H:%M:%S", "%Y-%m-%dT%H:%M:%S.%f", "%Y-%m-%dT%H:%M:%S"):
            try:
                dt = datetime.strptime(val, fmt)
                return dt.isoformat()
            except ValueError:
                continue
    except Exception:
        pass
    return None
```
