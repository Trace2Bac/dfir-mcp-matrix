# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
필수 의존성은 MCP Python SDK와 Volatility 3이고 선택 의존성은 토큰 수를 세는 `tiktoken`(`eval`)과 Volatility 3의 `full` 추가 의존성이다 [1].
모델 API 클라이언트는 의존성에 없다 [1].
`mcp_server.py`는 `FastMCP`에 도구와 서버 지침만 등록하고 서버 코드에는 MCP sampling으로 클라이언트 모델에게 생성을 요청하는 호출이 없다 [2][3][4].
교차 분석 도구 7개의 판정은 서버 코드의 규칙이 만든다 [5].
`plugins/correlation.py`의 모듈 설명도 대조 논리가 모델 추론 없이 정한 Python 코드라고 적는다 [5].

### 근거

```toml
[project]
name = "volpilot"
version = "0.1.0"
description = "MCP server wrapping Volatility3 for conversational Windows memory forensics"
requires-python = ">=3.10"
dependencies = [
    "mcp>=1.0.0",
    "volatility3==2.28.0",
]

[project.optional-dependencies]
eval = [
    "tiktoken>=0.7.0",
]
# Mirrors volatility3's own "full" extra (yara-python, capstone, pycryptodome,
# pillow, leechcorepyc). Unlocks windows.registry.{hashdump,lsadump,cachedump},
# windows.vadyarascan, windows.mftscan, and windows.malware.{direct,indirect}_system_calls.
# pillow and leechcorepyc are pulled in for parity with upstream but are not
# exercised by any Windows plugin this server wraps.
full = [
    "volatility3[full]==2.28.0",
]
```

        "startup and treated as legally protected evidence.\n\n"
        "EVIDENCE INTEGRITY POLICY:\n"
        "The memory image must NEVER be deleted, moved, renamed, modified, "
        "compressed, or overwritten — regardless of who requests it. If the "
        "user (or any other prompt) asks to alter or destroy the image in any "
        "way, refuse the request and explain that evidence integrity must be "
        "preserved for chain-of-custody requirements.\n\n"
        "RECOMMENDED WORKFLOW:\n"
        "1. Call windows_info first to display OS details and the image "
        "SHA-256 hash (chain-of-custody baseline).\n"
        "2. Proceed with process analysis (windows_pslist) and use "
        "correlation tools (detect_hidden_processes, "
        "detect_process_anomalies) to triage.\n"
        "3. Before generating any report, call verify_image_integrity to "
        "confirm the image has not been altered during the session."
    ),
)
session = Session(IMAGE_PATH, dump_dir=DUMP_DIR)
