# T09 대상 시스템 대응 조치 처리

### 비적용

**판단.** 서버는 조사하는 대상 시스템을 바꾸는 기능을 두지 않는다.
서버가 읽는 증거는 사용자가 시작할 때 정한 메모리 이미지 파일 하나다 [1].
도구는 모두 Volatility 플러그인을 그 이미지에 실행하거나 플러그인 결과를 서버 코드로 대조한다 [2][3].
서버가 쓰는 파일은 `windows_dumpfiles`와 `windows_pedump`가 `VOL_DUMP_DIR`에 쓰는 추출 파일과 이미지 옆의 설정 파일 `.vol3cfg.json`이고 둘 다 서버 자신의 작업 파일이다 [4][5].
가동 중인 단말에 접속하거나 명령을 보내는 코드는 없다 [6].
