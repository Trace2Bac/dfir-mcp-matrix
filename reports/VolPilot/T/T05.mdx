# T05 분석 도구 검증

### T05.01 저장소·의존성 고정

**구현.** 이 방식은 분석 도구 Volatility 3와 Volatility가 쓰는 추가 라이브러리, 교차 분석 도구의 판단 목록에 적용된다 [1][2][3].
`pyproject.toml`은 `volatility3==2.28.0`을 적고 선택 의존성 `full`도 `volatility3[full]==2.28.0`으로 적는다 [1].
잠금 파일 `uv.lock`은 `volatility3` 2.28.0과 배포 파일의 sha256을 적는다 [2].
같은 잠금 파일은 `full`이 설치하는 `yara-python` 4.5.4, `capstone` 5.0.9, `pycryptodome` 3.23.0과 그 sha256도 적는다 [4].
README는 `uv sync --frozen --python 3.12`로 잠금 파일 그대로 설치하게 하고 선택 의존성도 `--frozen`과 함께 설치하게 한다 [5].
MCP Python SDK도 잠금 파일에 고정되어 있지만 증거를 해석하지 않는 서버 실행용 라이브러리라 이 방식으로 보지 않는다 [1][2].

교차 분석 도구가 쓰는 판단 목록은 서버 코드의 상수다 [3].
한 개만 있어야 하는 프로세스, 프로세스마다 기대하는 부모, 세션 0에서 실행되어야 하는 프로세스, 이름을 흉내 내는지 대조할 정상 이름이 여기에 있다 [3].
그래서 기준 커밋이 이 목록의 내용을 정한다 [3].

Volatility가 쓰는 Windows 심볼은 고정하지 않는다.
저장소에는 심볼 파일이 없고 README는 처음 분석할 때 맞는 Windows 심볼을 내려받을 수 있다고 적는다 [5].
서버는 Volatility의 심볼 폴더, 오프라인 여부, 심볼 서버 설정을 바꾸지 않는다 [6].
Volatility 2.28.0은 패키지 안의 심볼 폴더와 사용자 캐시 폴더에서 심볼을 찾고 없으면 Microsoft 심볼 서버에서 PDB를 받아 변환해 저장한다 [7][8].
서버는 실행 중에 Volatility나 심볼의 버전을 묻거나 읽지 않는다 [6].

**한계.** `pyproject.toml`만 따라 설치하면 `full`이 설치하는 라이브러리는 Volatility 2.28.0이 적은 범위 안에서 정해진다 [9].
`yara-python`은 4.5.1 이상 5 미만, `capstone`은 5.0.3 이상 6 미만, `pycryptodome`은 3.21.0 이상 4 미만이다 [9].
서버는 설치된 버전을 확인하지 않는다 [6].

### T05.02 설정·호출 인자로 지정

**구현.** 이 방식은 서버가 이미지 옆에 저장하는 Volatility 설정 파일 `<이미지 경로>.vol3cfg.json`에 적용된다 [10].
저장된 설정이 아직 없으면 서버는 플러그인 객체를 만들고 `run()`을 부른 뒤 그 플러그인의 `build_configuration()` 결과를 이 파일에 저장한다 [10].
저장한 뒤에는 같은 세션의 다음 플러그인 실행과 서버를 다시 시작한 뒤의 실행 모두 이 설정을 플러그인의 설정 위치에 넣는다 [10][11].
Volatility 2.28.0의 `build_configuration`은 플러그인 요구 사항의 값 가운데 `None`이 아닌 값을 모으고 계층과 심볼 표 요구 사항은 그 객체의 하위 설정을 모은다 [12][13].
Volatility 2.28.0의 심볼 표는 자기 설정에 ISF 파일 위치 `isf_url`을 넣는다 [14].
Volatility 2.28.0의 automagic 가운데 가장 먼저 실행되는 `ConstructionMagic`은 설정에 들어 있는 값으로 계층과 심볼 표를 만든다 [15].

**한계.** 서버는 이 파일을 처음 한 번만 쓰고 그 뒤에는 바꾸지 않는다 [10].
서버는 이 파일에 적힌 심볼 위치나 그 내용을 대조하지 않는다 [10].
Windows 이미지로 플러그인을 실행하지 못해 파일의 실제 내용은 확인하지 못했다.

    def apply_config(self, plugin_name: str):
        """Splice saved config into a plugin's config path if available."""
        if self._saved_config is not None:
            plugin_config_path = path_join(BASE_CONFIG_PATH, plugin_name)
            self.ctx.config.splice(
                plugin_config_path,
                HierarchicalDict(self._saved_config),
            )

    def save_config(self, config_dict: dict):
        """Save plugin configuration to JSON file for fast subsequent loads."""
        self._saved_config = config_dict
        with open(self._config_path, "w") as f:
            json.dump(config_dict, f, sort_keys=True, indent=2)
