# T06 실행 환경정보 표시

### 미구현

**판단.** 서버는 Volatility 3로 결과를 내지만 응답과 파생물 어디에도 Volatility나 심볼의 버전을 싣지 않는다.
플러그인 도구의 응답은 실행 함수가 정한 `plugin` 이름과 `results`만 담는다 [1].
`windows_info`는 여기에 이미지 경로, 크기, 시작할 때 계산한 SHA-256을 담은 `image`를 더하고 버전은 더하지 않는다 [2].
Volatility 2.28.0의 `windows.info`가 내는 행에는 심볼 파일 위치 `Symbols`가 있다 [3].
서버는 이 행을 다른 행과 같이 `results`의 키와 값으로 바꿀 뿐 따로 읽어 싣지 않는다 [4].
교차 분석 도구의 응답에도 대조에 쓴 플러그인의 버전은 없다 [5].
`windows_dumpfiles`와 `windows_pedump`가 쓰는 추출 파일에는 Volatility가 만든 바이트만 들어가고 서버는 manifest를 만들지 않는다 [6].
설정 파일 `.vol3cfg.json`은 Volatility 설정을 저장하고 서버 코드가 버전을 넣지 않는다 [7].
서버는 도구 호출 기록을 남기지 않는다 [8].

서버 자신의 버전도 싣지 않는다.
서버는 FastMCP를 이름과 지침만 주어 만들고 MCP Python SDK 1.27.0은 버전이 없으면 초기화 응답 `serverInfo.version`에 `mcp` 패키지의 버전을 넣는다 [9][10].
초기화 응답의 `serverInfo`는 이름 `VolPilot`, 버전 `1.27.0`이었고 `pyproject.toml`의 서버 버전은 0.1.0이다 [11][12].

서버는 모델을 부르지 않는다.

def run_info(session: Session) -> dict:
    """Run windows.info and return system information."""
    treegrid = run_plugin(session, info.Info)
    results = {}
    for row in parse_treegrid(treegrid):
        results[row["Variable"]] = row["Value"]
    return {"plugin": "info", "results": results}
