# T03 실행 조건 확인

### 미구현

**판단.** 서버에는 도구 인자 밖의 조건으로 호출을 막거나 미루는 코드가 없다.
도구 함수는 받은 인자를 실행 함수에 넘겨 바로 플러그인을 실행한다 [1].
서버 지침은 `windows_info`를 먼저 부르고 보고서를 만들기 전에 `verify_image_integrity`를 부르라고 안내하지만 이 순서를 확인하는 코드는 없다 [2].
`windows_info`를 부르지 않은 세션에서 `windows_pslist`를 부르자 플러그인이 실행되어 이미지 해석 오류가 돌아왔다 [3].
`verify_image_integrity`의 결과는 저장되지 않고 다른 도구는 그 결과를 보지 않는다 [4].
교차 분석 도구는 필요한 플러그인을 그 호출 안에서 실행하고 앞선 호출이 있었는지 보지 않는다 [5].
결과 캐시에 같은 키의 결과가 있으면 다시 실행하지 않고 그 결과를 돌려주는데 이는 호출을 막거나 미루는 조건이 아니다 [6].
서버는 `mcp.run()`을 기본 전송 방식인 stdio로 실행하므로 원격 MCP 연결을 받지 않는다 [7][8].
실행 전에 메모리나 디스크 같은 자원 상태를 확인하는 코드도 없다 [1][6].

동시 실행 수를 정하는 장치도 없다.
도구 함수가 모두 동기 함수라서 MCP Python SDK 1.27.0의 FastMCP는 이벤트 루프에서 함수를 await 없이 바로 부른다 [9].
한 호출이 끝날 때까지 같은 이벤트 루프의 다른 요청은 처리되지 않으므로 도구 호출은 하나씩 차례로 실행된다 [9].
이는 서버가 정한 제한이 아니라 SDK가 동기 함수를 부르는 방식에서 생기는 동작이다.

```python
def run_triage_process(session: Session, *, pid: int) -> dict:
    """Collect cmdline, dlllist, handles, netscan, and malfind for one PID.

    Returns a consolidated view so the analyst (or LLM) can assess a
    single process without issuing five separate tool calls.
    """
    pslist_data = session.run_plugin("pslist")
    proc_match = next(
        (p for p in pslist_data["results"] if p["PID"] == pid), None,
    )
    if proc_match is None:
        return {
            "plugin": "triage_process",
            "results": {"pid": pid, "error": f"PID {pid} not found in pslist"},
        }

    cmdline_data = session.run_plugin("cmdline")
    dlllist_data = session.run_plugin("dlllist")
    handles_data = session.run_plugin("handles")
    netscan_data = session.run_plugin("netscan")
    malfind_data = session.run_plugin("malware.malfind")
```

[6] `Session.run_plugin`은 캐시에 있는 결과를 돌려주고 없으면 실행한다.

```python
    def run_plugin(self, plugin_name: str, **kwargs) -> dict:
        """Run a plugin by name, returning cached results if available.

        Extra kwargs are forwarded to the plugin's runner function and used
        to key the cache, so calling the same parameterized plugin twice
        with identical arguments returns the cached result, while different
        arguments trigger a fresh run.
        """
        cache_key = (plugin_name, frozenset(kwargs.items())) if kwargs else plugin_name
        if cache_key in self._cache:
            return self._cache[cache_key]
        if plugin_name not in PLUGIN_MAP:
            raise ValueError(f"Unknown plugin: {plugin_name}")
        result = PLUGIN_MAP[plugin_name](self, **kwargs)
        self._cache[cache_key] = result
        return result
```
