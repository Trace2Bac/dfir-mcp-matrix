# P04 조사 단위 관리

### 미구현

**판단.** 서버에는 사건이나 세션 같은 조사 단위를 정하거나 나누는 장치가 없다.
분석 도구는 호출마다 캡처 파일 경로 `pcap_file`을 받고 사건 ID나 세션 ID를 받지 않는다 [1].
진입점 도구 `wireshark_open_file`도 결과 글만 돌려주고 연 파일을 서버에 남기지 않으므로 다음 호출은 경로를 다시 받는다 [2].

서버를 만들 때 `tshark` 실행 객체 `WiresharkSuiteClient`는 하나만 만들어지고 모든 도구가 그 객체를 쓴다 [3].
결과 캐시 `ResultCache`도 그 객체에 하나만 있다 [4].
캐시 키는 파일의 실제 경로, 수정 시각, 크기와 실행한 명령이고 조사 단위를 담지 않는다 [5].
SSE·Streamable HTTP 전송에서도 이 서버 객체 하나로 모든 연결을 받으므로 캐시는 연결 사이에 나뉘지 않는다 [3][6].

`WIRESHARK_MCP_ALLOWED_DIRS`는 서버가 읽고 쓸 수 있는 폴더를 정하는 설정이고 사건을 가리키지 않는다 [7].
파일을 쓰는 도구는 모델이 준 출력 경로에 쓰고 서버가 사건별 폴더나 파일 이름을 정하지 않는다 [8].
`wireshark_yara_scan`이 만드는 임시 폴더는 허용 폴더 가운데 처음으로 쓸 수 있는 곳에 무작위 이름으로 생기고 호출이 끝나면 지워진다 [9].
저장소의 `Dockerfile`은 이미지 안에 `/captures`와 `/results` 폴더를 만들지만 서버 코드는 이 두 폴더를 따로 다루지 않는다 [10].

```python
    def _make_key(self, pcap_file: str, cmd: list[str]) -> tuple[str, str] | None:
        """Build a cache key and resolved path from file identity and command args."""
        try:
            path = Path(pcap_file).resolve()
            if not path.exists():
                return None
            stat = path.stat()
            identity = f"{path}:{stat.st_mtime_ns}:{stat.st_size}"
        except OSError:
            return None

        cmd_str = "\x00".join(cmd)
        raw = f"{identity}\x01{cmd_str}"
        return hashlib.sha256(raw.encode()).hexdigest()[:32], str(path)
```
