# P06 조사 상태 유지

### P06.02 프로세스 메모리에만 보관

**구현.** 서버 프로세스 메모리에 두는 상태는 `tshark` 결과 캐시 `ResultCache`, 컴파일한 YARA 규칙, 사용자가 둔 JA3 값 목록, GeoIP 데이터베이스를 여는 객체다 [1][2][3][4].
결과 캐시는 명령 인자에 `-r`이 있는 명령의 표준 출력 전체를 담고 `-r` 다음 인자를 캐시 키의 캡처 파일로 쓴다 [1][5].
`-w`나 `--export-objects`로 파일을 쓰는 `tshark` 명령과 고른 프레임을 새 파일에 쓰는 `editcap -r` 명령도 캐시를 거친다 [5][6].
같은 명령을 다시 받으면 그 명령을 실행하지 않고 담아 둔 출력에서 요청한 `limit`·`offset` 범위를 잘라 돌려준다 [5].
출력 파일을 지운 뒤 `wireshark_extract_frames`를 같은 인자로 다시 부르자 성공 응답이 돌아왔고 출력 파일은 다시 생기지 않았다 [7].
캐시는 서버를 만들 때 생기는 실행 객체 하나에 있고 모든 도구와 연결이 함께 쓴다 [8].

다음 출력은 캐시에 넣지 않는다.

- 출력 바이트 상한을 넘었거나 줄 수 상한으로 읽기를 멈춘 출력 [5][9]
- 종료 코드가 0이 아닌 출력(잘린 캡처 파일이라 부분 결과를 돌려준 경우 포함) [5]
- 크기가 캐시 전체 한도의 4분의 1(12.5 MiB)을 넘는 출력 [10]
- `capinfos`, `mergecap`, `text2pcap`, `-r`을 쓰지 않는 `editcap` 명령처럼 명령에 `-r`이 없는 출력과 `wireshark_aggregate`가 쓰는 필드 스트림 [5][11]

YARA 규칙은 처음 검사할 때 내장 규칙과 `~/.wireshark-mcp/yara/`의 규칙 파일을 컴파일해 모듈 변수에 두고 그 뒤로는 다시 읽지 않는다 [2].
`wireshark_extract_fingerprints`가 대조하는 JA3 값 목록도 처음 읽은 `~/.wireshark-mcp/fingerprints/`의 내용을 모듈 변수에 두고 다시 읽지 않는다 [3].
`wireshark_geoip_enrich`는 처음 찾은 GeoIP 데이터베이스를 연 객체를 모듈 변수에 둔다 [4].
이 상태는 파일이나 DB에 쓰지 않으므로 프로세스가 끝나면 사라진다 [1][2][3][4].

열린 사건, 작업 목록, 진행 기록 같은 상태는 없다.
파일을 쓰는 도구가 만든 캡처 파일과 내보낸 객체는 도구의 출력이고 서버는 이 파일을 다시 읽어 상태로 쓰지 않는다.

### P06.05 만료

**구현.** 이 방식은 결과 캐시에 적용된다 [1].
캐시는 항목마다 넣은 시각을 두고 300초가 지난 항목은 다시 찾을 때 버린다 [1][12].
항목이 128개에 닿거나 담은 출력이 모두 50 MiB를 넘으면 가장 오래 쓰지 않은 항목부터 버린다 [1][10].
키에는 캡처 파일의 실제 경로, 수정 시각(나노초), 크기, 실행한 명령이 들어 있어 수정 시각이나 크기가 바뀐 파일은 새 항목이 된다 [13].
명령이 `-w`로 파일을 쓰면 그 출력 파일의 항목을 지운다 [14].
출력 경로를 `-w` 없이 받는 `editcap`과 `text2pcap` 명령에는 이 처리가 적용되지 않는다 [14][15].
수정 시각을 바꾼 캡처 파일에 같은 도구를 다시 부르자 캐시 대신 새로 실행한 결과가 돌아왔다 [16].

YARA 규칙, JA3 값 목록, GeoIP 데이터베이스 객체에는 만료가 없다 [2][3][4].
그래서 서버가 실행되는 동안 규칙 파일이나 JA3 목록 파일을 바꾸거나 더해도 처음 읽은 내용으로 검사하고 대조한다 [2][3].

**한계.** 유효 시간이 지난 항목은 같은 키를 다시 찾거나 개수·크기 한도로 밀려나기 전에는 메모리에 남는다 [12][10].
키는 파일 내용을 보지 않으므로 수정 시각과 크기를 그대로 둔 채 내용을 바꾼 캡처 파일에는 앞서 담아 둔 결과를 돌려준다 [13].
첫 패킷의 출발지 주소 한 바이트를 바꾸고 수정 시각을 되돌린 캡처 파일에 같은 서버로 `wireshark_stats_endpoints`를 다시 부르자 바꾸기 전과 같은 종단점 목록이 돌아왔다 [16].
새로 시작한 서버는 바뀐 주소를 실었다 [16].

TLS 복호화 도구 `wireshark_decrypt_tls`와 `wireshark_verify_ssl_decryption`이 부르는 `decrypt_tls_traffic`과 `decrypt_ssl`은 키 기록 파일 경로를 `tls.keylog_file:<경로>` 설정 인자로 명령에 넣는다 [17][18].
그래서 두 도구가 실행한 명령의 캐시 키에는 키 기록 파일의 경로 문자열만 들어 있고 그 파일의 내용, 수정 시각, 크기는 들어 있지 않다 [18][13].
키가 없는 키 기록 파일로 `decrypt_tls_traffic`을 부른 뒤 같은 경로의 파일에 실제 키를 써 넣고 같은 실행 객체로 다시 부르자 복호화한 행이 없는 첫 결과가 그대로 돌아왔다 [19].
새로 만든 실행 객체는 같은 인자로 복호화한 HTTP 요청과 응답 두 행을 돌려주었다 [19].

```python
    def put(self, pcap_file: str, cmd: list[str], result: str) -> None:
        """Store a result in the cache."""
        made = self._make_key(pcap_file, cmd)
        if made is None:
            return
        key, path = made

        result_size = len(result.encode("utf-8", errors="replace"))

        if result_size > self._max_bytes // 4:
            return

        if key in self._cache:
            old_result, _ = self._cache[key]
            self._current_bytes -= len(old_result.encode("utf-8", errors="replace"))
            del self._cache[key]

        while self._current_bytes + result_size > self._max_bytes and self._cache:
            self._evict_oldest()

        while len(self._cache) >= self._max_entries:
            self._evict_oldest()

        self._cache[key] = (result, time.time())
        self._key_paths[key] = path
        self._current_bytes += result_size
```

```python
        """Look up a cached result. Returns None on miss."""
        made = self._make_key(pcap_file, cmd)
        if made is None:
            self._misses += 1
            return None
        key, _ = made

        entry = self._cache.get(key)
        if entry is None:

            return None

        result, timestamp = entry
        if time.time() - timestamp > self._ttl:

            self._misses += 1
            return None

        self._cache.move_to_end(key)
        self._hits += 1
```

```python
    def _make_key(self, pcap_file: str, cmd: list[str]) -> tuple[str, str] | None:
        """Build a cache key and resolved path from file identity and command args."""
        try:
            path = Path(pcap_file).resolve()
            if not path.exists():
                return None
            stat = path.stat()
            identity = f"{path}:{stat.st_mtime_ns}:{stat.st_size}"
        except OSError:
            return None

        cmd_str = "\x00".join(cmd)
        raw = f"{identity}\x01{cmd_str}"
        return hashlib.sha256(raw.encode()).hexdigest()[:32], str(path)
```

```python
            target = str(Path(pcap_file).resolve())
        except OSError:
            return 0

        keys = [key for key, path in self._key_paths.items() if path == target]
        for key in keys:
            entry = self._cache.get(key)
            if entry is not None:
                self._evict(key, len(entry[0].encode("utf-8", errors="replace")))
            self._key_paths.pop(key, None)
        return len(keys)
```
