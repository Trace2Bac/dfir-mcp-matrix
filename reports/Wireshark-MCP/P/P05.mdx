# P05 사건 자료 정리

### P05.01 모델 도구로 삭제·초기화

**구현.** 이 방식은 `wireshark_capture`의 `ring_buffer` 인자에 적용된다 [1].
`wireshark_capture`는 `ring_buffer`로 파일 크기(`filesize`)와 파일 개수(`files`)를 받으면 캡처 실행 파일(`dumpcap`, 없으면 `tshark`)에 `-b filesize:<KiB>`와 `-b files:<개수>`를 넘긴다 [1].
서버는 파일 개수를 1개에서 10개까지 받는다 [1].
`ring_buffer`를 받지 않은 호출은 링 버퍼를 쓰지 않고 서버가 이 값을 스스로 정하는 경로는 없다 [1].
Wireshark 4.0.17의 링 버퍼는 새 파일을 열 때 개수 한도를 넘으면 같은 자리를 쓰던 가장 오래된 파일을 지운다 [2].
루프백에서 파일 크기 4 KiB, 개수 2개로 캡처하자 번호가 187번까지 올라간 파일 가운데 마지막 2개만 남았다 [3].
링 버퍼 캡처의 응답은 `Capture completed but file not found`였고 남은 파일과 지운 파일을 적지 않았다 [3][4].

이 인자 밖에는 사건 자료를 지우거나 초기화하는 MCP 도구와 사용자 명령이 없다.
결과 캐시를 비우는 `ResultCache.clear`는 있지만 서버 코드에서 부르는 곳이 없다 [5].
사용자 CLI의 `uninstall`은 클라이언트 설정에서 이 서버의 항목을 지우고 캡처 파일이나 서버가 만든 파일은 건드리지 않는다 [6].

### P05.03 자동 정리

**구현.** 이 방식은 `wireshark_yara_scan`의 임시 내보내기 폴더에 적용된다 [7].
`wireshark_yara_scan`은 `dest_dir`를 받지 않으면 허용 폴더 안에 `wireshark_yara_` 접두어의 임시 폴더를 `mkdtemp`로 만들고 객체를 그 폴더로 내보낸다 [7][8].
검사를 마치거나 도중에 실패하면 `finally`에서 그 폴더를 통째로 지운다 [7].
`dest_dir`를 받은 호출은 내보낸 파일을 지우지 않는다 [7].
임시 폴더를 쓴 두 호출 뒤에 허용 폴더에는 원래 캡처 파일만 남았고 `dest_dir`를 준 호출 뒤에는 내보낸 파일이 남았다 [9].
내보낼 객체가 없던 호출에서도 임시 폴더가 지워졌다 [9].

**한계.** `wireshark_yara_scan`의 응답은 호출이 끝나면 지워지는 임시 폴더를 `Exported files: <경로> (temporary)`로 적고 지웠다는 사실은 적지 않는다 [7][9].
`wireshark_yara_scan`은 임시 폴더를 `ignore_errors=True`로 지우므로 지우지 못해도 알리지 않는다 [7].

### P05.04 원본 증거까지 삭제 대상에 포함

**구현.** 이 방식은 `wireshark_capture`의 링 버퍼 캡처에 적용된다 [1].
링 버퍼가 지우는 파일은 서버가 실시간 캡처로 수집한 캡처 파일이다 [1][2].
서버는 개수 한도만 넘기고 한도를 넘어 지워질 파일을 다른 곳으로 옮기거나 남기지 않는다 [1].
그래서 한도를 넘는 동안 수집한 앞부분의 패킷은 캡처 파일로 남지 않는다 [3].

### P05.05 원본 증거를 삭제 대상에서 제외

**구현.** 이 방식은 `wireshark_yara_scan`의 임시 폴더 정리에 적용된다 [7].
지우는 대상은 그 호출이 `mkdtemp`로 새로 만든 폴더 하나다 [7][8].
분석한 캡처 파일은 이 폴더 밖에 있으므로 지우는 대상에 없다 [9].

```python
    def _create_temporary_output_dir(self, prefix: str) -> dict[str, Any]:
        """Create a private temporary directory inside an explicitly allowed root."""
        if not self._allowed_dirs:
            return {
                "success": False,
                "error": {
                    "type": "PermissionDenied",
                    "message": (
                        "Temporary file writes are disabled. Set WIRESHARK_MCP_ALLOWED_DIRS "
                        "to one or more dedicated writable directories."
                    ),
                },
            }

        for root in self._allowed_dirs:
            try:
                return {"success": True, "path": tempfile.mkdtemp(prefix=prefix, dir=root)}
            except OSError:
                continue
        return {
            "success": False,
            "error": {
                "type": "PermissionDenied",
                "message": "No configured allowed directory is writable",
            },
        }
```
