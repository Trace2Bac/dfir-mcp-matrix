# E01 증거 등록 관리

### 미구현

**판단.** 서버는 캡처 파일을 도구마다 경로 인자로 받아 그 호출에서만 읽는다 [1].
증거를 등록하는 MCP 도구는 없고 증거를 식별하는 목록이나 등록 정보도 남기지 않는다.
진입점 도구 `wireshark_open_file`은 `capinfos`의 파일 정보와 프로토콜 목록을 응답으로 돌려주고 연 파일을 서버에 남기지 않는다 [2].
`capinfos`의 파일 정보에는 파일 이름, 크기, 첫 패킷과 마지막 패킷 시각, 해시가 있지만 서버는 이 값을 응답에만 싣는다 [2][3].

서버 메모리의 결과 캐시는 실제 경로, 수정 시각, 크기, 명령을 키로 `tshark` 출력을 담는다 [4].
이 캐시는 같은 명령을 다시 실행하지 않으려고 두는 것이고 캐시 내용을 돌려주는 도구가 없다.
그래서 이 캐시는 증거 등록 목록에 해당하지 않는다.

서버가 시작하는 수집도 서버 쪽 목록에 오르지 않는다.
`wireshark_capture`는 모델이 준 인터페이스에서 모델이 준 출력 경로로 캡처하고 그 경로에 파일이 있으면 `Capture saved to <경로>`를 돌려준다 [5].
캡처한 인터페이스, 시작 시각, 크기는 응답에 싣지 않고 따로 남기지 않는다 [5].
링 버퍼로 캡처하면 `dumpcap`이 출력 경로에 번호와 시각을 붙인 이름으로 파일을 만든다 [6].
서버는 받은 출력 경로에 파일이 있는지만 보므로 이때 응답은 `Capture completed but file not found`이고 실제로 만들어진 파일의 이름을 싣지 않는다 [5][7].

```python
    def _make_key(self, pcap_file: str, cmd: list[str]) -> tuple[str, str] | None:
        """Build a cache key and resolved path from file identity and command args."""
        try:
            path = Path(pcap_file).resolve()
            if not path.exists():
                return None
            stat = path.stat()
            identity = f"{path}:{stat.st_mtime_ns}:{stat.st_size}"
        except OSError:
            return None

        cmd_str = "\x00".join(cmd)
        raw = f"{identity}\x01{cmd_str}"
        return hashlib.sha256(raw.encode()).hexdigest()[:32], str(path)
```

```python
    async def wireshark_capture(
        interface: str,
        output_file: str,
        duration_seconds: int = 10,
        packet_count: int = 0,
        capture_filter: str = "",
        ring_buffer: str = "",
    ) -> str:
        """Capture live network traffic. capture_filter: BPF syntax. ring_buffer: "filesize:1024,files:5"."""
        res = await client.capture_packets(
            interface, output_file, duration_seconds, packet_count, capture_filter, ring_buffer=ring_buffer
        )

        wrapped = parse_tool_result(res)
        if not wrapped["success"]:
            return normalize_tool_result(wrapped)

        if os.path.exists(output_file):
            return success_response(f"Capture saved to {output_file}\n{wrapped['data']}")

        return success_response(f"Capture completed but file not found:\n{wrapped['data']}")
```
