# E02 증거 무결성 검증

### E02.01 등록 시 기준값 자동 계산

**구현.** 이 방식은 `capinfos`를 실행하는 `wireshark_open_file`, `wireshark_get_file_info`, `wireshark_quick_analysis`에 적용된다 [1][2][3].
세 도구는 받은 캡처 파일 경로로 `capinfos`를 옵션 없이 실행한다 [1].
Wireshark 4.0.17의 `capinfos`는 옵션이 없으면 모든 항목을 출력하고 그 가운데 파일 바이트 전체의 SHA256, RIPEMD160, SHA1을 계산해 싣는다 [4].
해시는 `capinfos`가 파일을 `rb`로 열어 처음부터 끝까지 읽어 계산하므로 압축된 캡처 파일이면 압축된 파일 바이트의 해시다 [4].
`capinfos`는 파일이 캡처 형식으로 열린 뒤에 해시를 계산하므로 캡처 파일로 열리지 않는 파일은 해시하지 않는다 [4].
모델이 해시를 요청하지 않아도 `wireshark_open_file`과 `wireshark_get_file_info`의 응답에는 이 해시 줄이 실린다 [2][5].
`wireshark_get_file_info`의 도구 설명은 형식, 패킷 수, 기간, 크기를 돌려준다고 적고 해시는 적지 않는다 [2].
직접 만든 캡처 파일에서 응답의 SHA256과 SHA1은 Python `hashlib`로 계산한 값과 같았다 [5].
보조 환경(Windows)의 Wireshark 4.6.7 `capinfos`는 SHA256과 SHA1만 내고 RIPEMD160은 내지 않았다 [6][7].

서버는 이 해시를 따로 보관하지 않고 어느 도구도 이 값을 다시 읽어 지금 파일과 대조하지 않는다.
해시 값은 그 응답에만 있다.
같은 파일의 끝 바이트를 바꾸고 `wireshark_get_file_info`를 다시 부르자 다른 SHA256이 실렸고 앞 값과 다르다는 표시는 없었다 [5].
결과 캐시 키에 들어가는 파일의 수정 시각과 크기는 캐시 항목을 고르는 데만 쓰이고 서버는 그 값이 바뀐 사실을 알리지 않는다 [8].

같은 저장소의 `skills/tshark-cli-analysis/scripts/run_tshark.py`는 클라이언트 모델이 MCP를 거치지 않고 실행하는 스크립트다 [9].
이 스크립트는 `tshark`를 실행하기 전과 뒤에 입력 파일의 SHA-256을 계산해 다르면 실행 기록에 `input_changed`를 참으로 적고 종료 코드 1로 끝난다 [9].
서버는 이 스크립트를 실행하지 않는다.

**한계.** `capinfos`를 찾지 못하면 해시를 계산하지 않는다 [10].
서버 설정은 `capinfos`를 필수가 아닌 권장 도구로 두어 `capinfos`가 없어도 서버가 시작된다 [10].
`capinfos` 경로를 없는 파일로 정한 서버에서 `wireshark_open_file`은 파일 정보 대신 `Detailed file metadata unavailable` 문장을 싣고 나머지 결과를 돌려주었다 [5].
같은 서버의 `wireshark_get_file_info`는 `ToolNotFound` 오류였다 [5].
`wireshark_quick_analysis`는 파일 정보 절을 10줄에서 자르므로 해시 줄이 응답에 실리지 않는다 [3][5].
기준값은 도구를 부를 때마다 그 시점의 파일에서 새로 계산한다 [1].
그래서 서버가 읽기 전에 바뀐 캡처 파일은 바뀐 상태가 그 응답의 기준값이 된다.

```python
    def _make_key(self, pcap_file: str, cmd: list[str]) -> tuple[str, str] | None:
        """Build a cache key and resolved path from file identity and command args."""
        try:
            path = Path(pcap_file).resolve()
            if not path.exists():
                return None
            stat = path.stat()
            identity = f"{path}:{stat.st_mtime_ns}:{stat.st_size}"
        except OSError:
            return None

        cmd_str = "\x00".join(cmd)
        raw = f"{identity}\x01{cmd_str}"
        return hashlib.sha256(raw.encode()).hexdigest()[:32], str(path)
```

    def _require_tool(self, tool_name: str) -> dict[str, Any]:
        """Return success or a ToolNotFound error payload for an optional suite tool."""
        tool_path = self._tool_paths.get(tool_name)
        if self._tool_is_available(tool_path):
            return {"success": True}

            "success": False,

                "message": f"{tool_name} tool not found",
                "details": {
                    "tool": tool_name,
                    "requirement": WIRESHARK_TOOL_REQUIREMENTS[tool_name],
                    "env_var": self._TOOL_ENV_VARS[tool_name],
                },
            },
        }
