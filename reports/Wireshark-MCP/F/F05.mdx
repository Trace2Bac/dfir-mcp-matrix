# F05 발견사항·결론 근거 검증

### 비적용

**판단.** 서버에는 발견사항, 결론, 부재 주장을 받거나 저장하거나 보고하는 경로가 없다.
도구 52개 가운데 발견사항이나 주장을 인자로 받는 도구가 없고 보고 산출물을 쓰는 도구도 없다 [1][2].

서버가 스스로 만드는 판정과 부재 발견사항은 응답으로만 돌아간다.
`wireshark_detect_port_scan`, `wireshark_detect_dns_tunnel`, `wireshark_detect_dos_attack`은 지표가 없으면 관찰되지 않았다는 발견사항을 응답의 `findings`에 싣는다 [3].
`wireshark_detect_port_scan`과 `wireshark_detect_dos_attack`은 하위 조회가 실패한 검사가 있으면 그 발견사항의 `confidence`를 `candidate`로 두고 실패한 검사를 `coverage.failed_checks`에 싣는다 [3].
서버는 이 발견사항을 저장하거나 다른 도구의 입력으로 다시 받지 않는다 [1][4].

### 근거

[1] (실행 확인) `wireshark-mcp serve`를 stdio로 실행해 MCP SDK 클라이언트로 도구 52개의 입력 schema 인자 이름을 모았다.
발견사항, 주장, 근거 참조를 받는 인자는 없었다.

[2] 파일을 쓰는 도구 목록이다.
