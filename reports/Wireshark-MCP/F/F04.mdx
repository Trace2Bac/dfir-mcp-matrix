# F04 발견사항·결론 기록 관리

### 비적용

**판단.** 서버에는 발견사항, 결론, 가설, 단서 메모를 받아 남기는 도구가 없다.
도구 52개의 입력 인자는 캡처 파일과 출력 경로, 표시 필터, 필드, 상한, 문턱, 복호화 입력 같은 실행 조건이고 발견사항이나 메모를 받는 인자가 없다 [1].
파일을 쓰는 도구 10개와 실시간 캡처 도구는 캡처 파일을 자르거나 합치거나 거르거나 객체를 내보내거나 내보낸 객체를 검사하는 도구이고 모두 증거에서 얻은 자료를 쓴다 [2].
`wireshark_yara_scan`은 `dest_dir`을 주지 않으면 내보낸 객체를 검사 뒤 임시 폴더째 지운다 [3].

탐지 도구가 만드는 `findings`와 요약은 응답으로만 돌려주고 서버에 남기지 않는다 [4].
실행기의 결과 캐시는 tshark 표준 출력을 캡처 파일과 명령에 대응시켜 프로세스 메모리에 두는 것이고 발견사항을 담지 않는다 [5].

인자는 `pcap_file`, `output_file`, `display_filter`, `fields`, `limit`, `threshold`, `keylog_file` 같은 실행 조건 61가지였다.
