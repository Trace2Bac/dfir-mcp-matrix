# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 서버는 처리 중에 모델을 부르지 않는다.
필수 의존성은 MCP SDK, CLI·설정 라이브러리, Starlette 같은 웹 구성 요소이고 모델 API 클라이언트는 없다 [1].
선택 의존성은 GeoIP 조회용 `geoip2`와 YARA 검사용 `yara-python`뿐이다 [1].
`_build_server`는 도구, 리소스, 프롬프트, 서버 지침만 등록하고 `src/wireshark_mcp/`에는 MCP sampling으로 클라이언트 모델에게 생성을 요청하는 호출이 없다 [2].
MCP SDK 클라이언트로 서버를 실행하자 `initialize` 응답의 기능은 `tools`, `resources`, `prompts`였다 [3].
판정 문장과 요약은 모두 서버 코드가 규칙과 문자열 조립으로 만든다.
`wireshark_quick_analysis`도 tshark 조회 일곱 개의 결과를 절마다 줄 수를 잘라 이어 붙인 글을 돌려준다 [4].
