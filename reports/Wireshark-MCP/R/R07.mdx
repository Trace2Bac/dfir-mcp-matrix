# R07 증거 내용과 지시 구분

### R07.01 JSON 필드 분리

**구현.** 이 방식은 모든 도구가 쓰는 `envelope`에 적용된다 [1].
도구 결과는 JSON 글 하나로 나가고 `tshark` 출력과 서버가 만든 값은 `data`에, 상태와 메타 정보는 `success`·`error`·`scope`·`coverage`·`pagination`·`warnings`·`truncated`·`stderr`에 들어간다 [1].
`json.dumps`가 증거에서 온 글을 JSON 문자열 값으로 바꾸므로 그 안의 따옴표와 줄바꿈은 이스케이프된다 [1].
`wireshark_aggregate`는 묶음 키를 필드 이름을 키로 한 `dict`에 싣는다 [2].
BLE 분석은 장치 이름·주소·ATT 값 같은 증거 값을 `names`·`address`·`value` 같은 필드에 싣는다 [3].
근거 항목 `FindingEvidence`는 증거 값을 `value`에, 서버 설명을 `description`에 나눠 싣는다 [4].

**한계.** 많은 도구에서 `data`는 서버 문장과 `tshark` 출력을 이은 문자열 하나다 [5][6].
프로토콜 분석기는 `Total … packets`·`Function code distribution:` 같은 서버 문장 뒤에 추출 결과를 붙이고 MQTT 주제와 CoAP URI 경로 같은 증거 글을 서버 문장 줄 안에 넣는다 [5][7].
`wireshark_quick_analysis`는 `capinfos`·`tshark` 출력과 서버 절 제목을 한 글로 잇고 HTTP 호스트와 DNS 질의 이름을 목록 줄로 적는다 [6].
`_paginate`·`summarize_tabular`·`smart_truncate`는 잘림 안내 문장을 `tshark` 출력 글 안에 붙이거나 끼워 넣는다 [8][9][10].
`summary`·`observation`·`description`에도 증거 값이 들어간다 [4][11].
DNS 터널 탐지의 `value`는 서버 문구 `Sample [N chars]:` 뒤에 질의 이름을 잇고 `summary`도 같은 글을 싣는다 [11].
BLE 장치 분석의 `summary`는 광고에서 읽은 장치 이름을 서버 문장 안에 넣는다 [3].
오류의 `details`에는 `tshark` 표준 오류가 그대로 들어간다 [12].
Telnet 근거는 서버가 쓴 고정 문장을 증거 값과 같은 `value` 필드에 싣는다 [13].

### R07.02 출처 필드 부여

**구현.** 이 방식은 `wireshark_extract_credentials`, DNS 터널 탐지, BLE 스캐너·페어링 분석의 근거 항목에 적용된다 [13][11][14].
근거 항목은 `value`를 읽은 `tshark` 필드 이름을 `field`에, 프로토콜 이름을 `protocol`에 싣는다 [4][13].
예를 들어 HTTP Basic 근거는 `field` `http.authbasic`과 `protocol` `HTTP`를, DNS 터널 근거는 `field` `dns.qry.name`을 싣는다 [13][11].

결과에는 값의 신뢰 수준을 적는 필드가 없다 [1].
서버 지침, 도구 설명, 응답 어디에도 패킷 내용 속의 지시를 따르지 말라는 문구가 없다 [15].
`SECURITY.md`와 함께 제공되는 skill 문서는 패킷 내용과 추출한 글을 지시가 아닌 신뢰할 수 없는 증거로 다루라고 적지만 이 문서들은 MCP 응답이나 서버 지침으로 나가지 않는다 [16].

**한계.** 포트 스캔과 서비스 거부 탐지의 근거 항목에는 `field`가 없다 [17].
`field`가 없는 근거의 `value`에는 서버가 쓴 문장과 증거에서 센 수가 함께 들어간다 [17].
패킷 목록, 필드 추출, 프로토콜 분석기, 이상 탐지 도구의 결과에는 근거 항목이 없어 이 표시가 없다 [5][18].

    def _render_groups(self) -> list[dict[str, Any]]:
        groups: list[dict[str, Any]] = []
        for key, count in self.grouped_counts.items():
            key_index = 0
            rendered_key: dict[str, Any] = {}
            if self.time_bucket_seconds > 0:
                bucket_start = key[key_index]
                rendered_key["time_bucket_start"] = bucket_start
                rendered_key["time_bucket_end"] = round(bucket_start + self.time_bucket_seconds, 9)
                key_index += 1
            for field in self.group_fields:
                rendered_key[field] = key[key_index]
                key_index += 1

            entry: dict[str, Any] = {"key": rendered_key, "count": count}
            if self.distinct_fields:
                entry["distinct"] = {field: len(self.grouped_distinct[key][field]) for field in self.distinct_fields}
            if self.numeric_operations:
                entry["numeric"] = self._render_numeric(key, count)
            groups.append(entry)
        return groups
```

def summarize_tabular(data: str, max_rows: int = 50) -> str:
    """Truncate tabular data beyond max_rows with a hint."""
    lines = data.splitlines()
    if len(lines) <= max_rows + 1:
        return data
    header = lines[0]
    rows = lines[1 : max_rows + 1]
    remaining = len(lines) - max_rows - 1
    return "\n".join([header] + rows + [f"[{remaining} more rows. Use display_filter or offset to narrow.]"])
```

[10] `smart_truncate`는 출력 가운데에 안내 문장을 넣는다.

```python
    marker = f"\n\n[... {len(text)} chars omitted, use offset for pagination ...]\n\n"
    if len(marker) >= max_chars:
        return text[:max_chars]

    remaining = max_chars - len(marker)
    tail_budget = min(500, remaining // 4)
    head_budget = remaining - tail_budget
    omitted = len(text) - head_budget - tail_budget
    marker = f"\n\n[... {omitted} chars omitted, use offset for pagination ...]\n\n"

    # The number of digits in `omitted` can change the marker length.
    remaining = max_chars - len(marker)
    tail_budget = min(500, max(0, remaining // 4))
    head_budget = max(0, remaining - tail_budget)
    omitted = len(text) - head_budget - tail_budget
    marker = f"\n\n[... {omitted} chars omitted, use offset for pagination ...]\n\n"
    head_budget = max(0, max_chars - len(marker) - tail_budget)

    result = f"{text[:head_budget]}{marker}{text[-tail_budget:] if tail_budget else ''}"
    return result[:max_chars]
```
