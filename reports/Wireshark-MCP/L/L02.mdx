# L02 기록 구성

### L02.03 외부 실행 명령 기록

**구현.** 이 방식은 공통 실행 함수 `_run_command`가 쓰는 항목에 적용된다 [1].
`_run_command`는 실행 직전의 `DEBUG` 항목과 실패, 시간 초과, 출력 상한 초과, 잘린 캡처의 `WARNING` 항목에 `_redact_command`로 만든 명령 줄을 넣는다 [1].
`_redact_command`는 실행 파일 경로와 인자를 공백으로 이어 붙인 문자열 하나를 만든다 [2].
그래서 항목에는 인자 사이의 경계가 남지 않는다 [2].
`_redact_command`는 WPA 암호를 담은 `uat:80211_keys:` 인자와 TLS 키 기록 파일 경로를 담은 `tls.keylog_file:` 인자를 `<redacted>`로 바꾼다 [2].
`DEBUG` 수준으로 실행한 서버의 항목에는 실행 파일의 전체 경로, 서버가 붙인 옵션, 모델이 준 캡처 파일 경로와 표시 필터가 들어간 명령 줄이 남았다 [3].
`wireshark_decrypt_wpa` 호출의 항목에서 암호 인자는 `uat:80211_keys:<redacted>`로 남았다 [3].
캐시에서 결과를 돌려준 호출의 `Cache hit for:` 항목에는 명령 배열의 앞 4개 값만 남는다 [4].

항목에는 MCP 도구 이름과 도구가 받은 인자 원문을 담는 칸이 없다 [1].
명령 줄은 서버가 기본값을 채우고 값을 바꾼 뒤의 인자로 만든다 [3].
항목에는 호출 ID도 없어 여러 명령을 실행하는 도구의 항목을 한 호출로 잇지 못한다 [1].

**한계.** 기본 수준 `WARNING`에서는 실행 직전 항목이 출력되지 않으므로 성공한 실행의 명령 줄은 남지 않는다 [1][5].

### L02.05 결과 상태·실행 시점 기록

**구현.** 이 방식은 `_run_command`가 실행이 끝난 뒤 쓰는 `WARNING`·`ERROR` 항목에 적용된다 [1].
항목 형식은 `serve`가 `basicConfig`에 준 `%(asctime)s [%(name)s] %(levelname)s: %(message)s`이다 [5].
그래서 항목마다 시각, 로거 이름, 수준, 메시지가 남는다 [5].
메시지는 실행 결과마다 다르고 모두 뒤에 명령 줄이 붙는다 [1].

- 0이 아닌 종료 코드로 끝나면 `Command failed (exit <코드>)`를 쓴다 [1].
- 시간 제한을 넘으면 `Command timed out after <초>s`를 쓴다 [1].
- 출력 상한을 넘어 프로세스를 끝내면 `Command exceeded output limit and was terminated`를 쓴다 [1].
- `tshark`가 잘린 캡처 파일을 읽고 부분 결과를 돌려주면 `tshark reported a truncated capture (exit <코드>); returning partial output`을 쓴다 [1].
- 실행 중 예외가 나면 `Command execution failed`와 예외 추적 정보를 `ERROR`로 쓴다 [1].

기본 수준에서 잘못된 표시 필터로 부른 `wireshark_get_packet_list`는 `Command failed (exit 2)` 항목을 남겼다 [3].
잘린 캡처 파일로 부른 `wireshark_get_packet_list`는 잘린 캡처 항목을 남겼고 응답은 성공으로 나갔다 [3].
성공한 실행에는 끝난 뒤의 항목이 없고 `DEBUG` 수준의 실행 직전 항목만 있다 [1].
허용 목록에 없는 실행 파일을 막을 때는 그 실행 파일 이름만 담은 `ERROR` 항목을 쓴다 [4].

**한계.** 성공한 실행은 끝난 뒤의 항목을 남기지 않는다 [1].
그래서 실행 직전 항목 뒤에 실패 항목이 없다는 사실로는 그 실행이 성공했는지 끝나지 않았는지 구별하지 못한다.
기본 수준에서는 실행 직전 항목도 출력되지 않으므로 성공한 실행은 기록에 아무 항목도 남기지 않는다 [5][3].

줄 상한으로 출력을 자른 실행은 0이 아닌 코드로 끝나도 결과 상태 항목을 남기지 않는다 [6].
뒤쪽에 손상된 레코드가 있는 캡처 파일을 `limit` 5로 읽은 `wireshark_get_packet_list` 호출은 `DEBUG` 수준에서도 `Executing:` 항목만 남겼고 `limit` 1000으로 읽은 호출은 `Command failed (exit 2)` 항목을 남겼다 [7].

### L02.06 결과 참조·요약값 기록

**구현.** 이 방식은 `WiresharkMCP._cap_content`가 결과 글을 자를 때 쓰는 `DEBUG` 항목에 적용된다 [8].
항목에는 도구 이름과 자르기 전·후 결과 글의 글자 수가 남는다 [8].
이 글자 수는 분석 도구의 원래 출력이 아니라 도구가 돌려준 JSON 응답 글(`envelope`)의 글자 수다 [8].
결과 상한을 600자로 둔 서버에서 `wireshark_get_packet_list` 호출은 `Capped wireshark_get_packet_list result from 3056 to 600 chars` 항목을 남겼다 [3].
결과의 해시, 행 수, 저장 경로는 어느 항목에도 없다 [1][8].

**한계.** 결과 글이 상한을 넘지 않은 호출은 크기를 남기지 않는다 [8].
기본 수준 `WARNING`에서는 이 항목이 출력되지 않는다 [5].

```python
    @staticmethod
    def _redact_command(cmd: list[str]) -> str:
        """Render a command without exposing passphrases or key-log paths."""
        redacted: list[str] = []
        for arg in cmd:
            if arg.startswith("uat:80211_keys:"):
                redacted.append("uat:80211_keys:<redacted>")
            elif arg.startswith("tls.keylog_file:"):
                redacted.append("tls.keylog_file:<redacted>")
            else:
                redacted.append(arg)
        return " ".join(redacted)
```

```python
    def _cap_content(self, result: Any, tool_name: str) -> Any:
        """Apply the ceiling to text blocks, leaving other content shapes alone."""
        # Structured tools return (content, structured_data); cap only the text side.
        if isinstance(result, tuple) and len(result) == 2:
            return (self._cap_content(result[0], tool_name), result[1])

        if not isinstance(result, (list, tuple)):
            return result

        capped: list[Any] = []
        for block in result:
            if isinstance(block, TextContent):
                text = cap_result_text(block.text, self._max_result_chars)
                if text != block.text:
                    logger.debug("Capped %s result from %d to %d chars", tool_name, len(block.text), len(text))
                    block = block.model_copy(update={"text": text})
            capped.append(block)
        return capped
```
