# T06 실행 환경정보 표시

### T06.04 환경 조회 도구에서만 반환

**구현.** 이 방식은 `wireshark_get_capabilities`에 적용된다 [1].
`wireshark_get_capabilities`는 `check_capabilities`의 결과를 돌려주고 이 결과는 Wireshark 도구 6개마다 `available`, `requirement`, `purpose`, `version`을 싣는다 [1][2].
`version`은 도구마다 `-v`를 실행해 표준 출력 첫 줄을 공백으로 나눈 마지막 낱말이다 [2].
`-v` 실행이 5초 안에 끝나지 않거나 예외가 나면 `version`은 `unknown`이 된다 [2].
도구를 찾지 못하면 `available`을 거짓으로 두고 `version` 필드를 싣지 않는다 [2].
같은 결과의 `_meta.capture_backend`에는 실시간 캡처에 쓸 실행 파일의 이름을 싣는다 [3].
리소스 `wireshark://capabilities`는 같은 표를 `-v` 실행 없이 만들어 `version` 없이 돌려준다 [3][4].
실행 확인에서 도구 6개의 `version`은 주 환경에서 모두 `4.0.17-0+deb12u3).`, Windows에서 모두 `(v4.6.7-0-gb439fb7b47a9).`였다 [5].

분석 결과를 돌려주는 응답에는 버전이 없다.
Wireshark 도구를 실행하는 도구의 응답은 실행기 `_run_command`가 만든 `success`, `data`, `stderr`, `truncated` 필드나 그 결과로 다시 만든 JSON 응답 `envelope`이고 버전 필드는 없다 [6][7].
탐지 도구가 더하는 `scope`와 `coverage`에는 대상 파일, 문턱값, 상한, 건수, 실패한 검사 이름만 있다 [8].
`wireshark_yara_scan`의 결과는 일치한 룰의 이름과 메타데이터만 싣고 쓴 룰 파일의 이름이나 식별값을 싣지 않는다 [9].
`wireshark_geoip_enrich`의 결과는 IP마다 국가, 도시, ASN만 싣고 읽은 GeoLite2 데이터베이스의 경로나 빌드 정보를 싣지 않는다 [10].
`yara-python`과 `geoip2`의 버전은 `wireshark_get_capabilities`에도 실리지 않는다 [2].
서버가 남기는 파일은 Wireshark 도구가 쓰는 캡처 파일과 내보낸 객체뿐이고 서버는 버전을 적은 파일을 따로 만들지 않는다.
`mergecap`은 pcapng 출력의 섹션 헤더에 자기 이름과 버전을 적고 서버는 이 값을 읽거나 따로 적지 않는다 [11][12].

서버 자신의 버전 `__version__`은 초기화 응답의 `serverInfo.version`에만 실린다 [13][14].
실행 확인에서 이 값은 `3.1.0`이었다 [15].
서버는 모델을 부르지 않는다.

**한계.** `version`에 실리는 값은 버전 번호만 담지 않는다 [2][5].
Debian 패키지의 도구는 첫 줄 끝에 패키지 버전을 괄호에 담아 붙이고 Windows용 4.6.7은 git 설명을 괄호에 담아 붙이므로 마지막 낱말에 괄호와 마침표가 따라온다 [5].
Windows에서는 버전 번호 대신 git 설명 전체가 `version`에 실린다 [5].
프로필 `core`는 `wireshark_get_capabilities`를 등록하지 않으므로 이 프로필에서는 도구 버전을 돌려주는 도구가 없다 [16][15].

    def _capability_snapshot(self) -> dict[str, Any]:
        """Return the current suite capability map without version probing."""
        capabilities: dict[str, Any] = {}
        for tool_name in WIRESHARK_TOOL_ORDER:
            path = self._tool_paths.get(tool_name)
            capabilities[tool_name] = {
                "available": self._tool_is_available(path),
                "requirement": WIRESHARK_TOOL_REQUIREMENTS[tool_name],
                "purpose": WIRESHARK_TOOL_PURPOSES[tool_name],
            }

        capabilities["_meta"] = {
            "required": [name for name, level in WIRESHARK_TOOL_REQUIREMENTS.items() if level == "required"],
            "recommended": [name for name, level in WIRESHARK_TOOL_REQUIREMENTS.items() if level == "recommended"],
            "optional": [name for name, level in WIRESHARK_TOOL_REQUIREMENTS.items() if level == "optional"],
            "capture_backend": self._select_capture_backend(),
        }
        return capabilities

    @staticmethod
    def _ok(data: str, stderr: str = "", truncated: bool = False) -> str:
        """Wrap successful command output in the canonical success envelope.

        Every client method returns this shape (or an error envelope), so the
        raw text lives in ``data`` and is never re-parsed by consumers — output
        that happens to look like JSON can no longer be mistaken for an error.
        Diagnostic stderr is kept in a separate field so it never corrupts
        structured (``-T json`` / ``-T fields``) output in ``data``.
        """
        envelope: dict[str, Any] = {"success": True, "data": data}
        if stderr:
            envelope["stderr"] = stderr
        if truncated:
            envelope["truncated"] = True
        return json.dumps(envelope)

    async def merge_pcap_files(self, output_file: str, input_files: list[str]) -> str:
        """Mergecap: Merge multiple pcaps."""
        required = self._require_tool("mergecap")
        if not required["success"]:
            return json.dumps(required)

        for f in input_files:
            validation = self._validate_file(f)
            if not validation["success"]:
                return json.dumps(validation)

        output_validation = self._validate_output_path(output_file)
        if not output_validation["success"]:
            return json.dumps(output_validation)

        mergecap_path = self._get_checked_tool_path("mergecap")
        cmd = [mergecap_path, "-w", output_file] + input_files
        return await self._run_command(cmd)
