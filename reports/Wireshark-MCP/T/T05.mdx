# T05 분석 도구 검증

### T05.01 저장소·의존성 고정

**구현.** 이 방식은 선택 의존성 `yara-python`·`geoip2`와 패키지에 함께 넣은 YARA 규칙 파일에 적용된다 [1][2][3].
`pyproject.toml`은 두 라이브러리를 선택 의존성 `yara`·`geoip`·`all`에 하한만 적는다 [1].
`uv.lock`은 `yara-python` 4.5.4와 `geoip2` 5.3.0을 배포 파일 해시와 함께 고정한다 [2].
`geoip2`가 데이터베이스 파일을 읽는 데 쓰는 `maxminddb`도 `uv.lock`이 3.1.1로 고정한다 [2].
YARA 규칙 `data/yara/basic_rules.yar`는 패키지에 들어 있으므로 기준 커밋이 내용을 정한다 [3].
MCP SDK `mcp` 2.1.1도 `uv.lock`이 고정하지만 증거를 해석하지 않는 서버 실행용 라이브러리라 이 방식으로 보지 않는다 [2].

Wireshark 도구는 저장소가 버전을 정하지 않는다 [4][5].
`Dockerfile`은 Debian 패키지 `tshark`를 버전 없이 설치하고 기반 이미지는 태그 `python:3.12-slim-bookworm`으로만 정한다 [4].
Homebrew 정의는 `wireshark`에 버전 없이 의존한다 [5].

사용자 폴더의 참조 자료는 저장소가 내용이나 버전을 정하지 않는다 [6][7].
`wireshark_yara_scan`은 `~/.wireshark-mcp/yara/`의 `.yar`·`.yara` 파일을 저장소 규칙과 함께 컴파일한다 [6].
컴파일에 성공하면 그 결과를 모듈 변수에 두고 서버가 끝날 때까지 규칙 파일을 다시 읽지 않는다 [6].
사용자 규칙은 확장자를 뺀 파일 이름으로 묶이므로 이름이 같은 `.yar`·`.yara` 파일이 있으면 `.yara` 파일만 컴파일된다 [6].
`wireshark_extract_fingerprints`는 `~/.wireshark-mcp/fingerprints/`의 JSON 파일에서 JA3 목록을 읽고 처음 읽은 목록을 서버가 끝날 때까지 쓴다 [7].

**한계.** README가 적은 설치 방법 `pip install wireshark-mcp`는 `uv.lock`을 쓰지 않는다 [8].
Claude·Codex 플러그인 설정은 서버를 `uv run --locked --no-dev`로 실행하지만 선택 의존성을 고르는 인자는 없다 [9].
`Dockerfile`은 PyPI의 `wireshark-mcp==3.1.0`을 `pip`로 설치하고 선택 의존성을 설치하지 않는다 [4].
그래서 두 라이브러리의 고정 버전은 사용자가 저장소의 잠금 파일로 선택 의존성을 설치할 때만 적용된다 [1][2].

### T05.02 설정·호출 인자로 지정

**구현.** 이 방식은 Wireshark 도구 6개의 실행 파일 위치와 GeoIP 데이터베이스 파일 위치에 적용된다 [10][11].
서버는 시작할 때 도구마다 `WIRESHARK_MCP_TSHARK_PATH` 같은 환경변수를 읽고 값이 있으면 그 값을 실행 경로로 쓴다 [10][12].
값이 없으면 `PATH`에서 도구 이름을 찾는다 [12].
`wireshark_geoip_enrich`는 환경변수 `GEOIP_DB_PATH`를 먼저 보고 없으면 사용자 폴더의 GeoLite2 파일 3개와 시스템 폴더 3곳의 `GeoLite2-City.mmdb`를 차례로 찾아 처음 있는 파일을 쓴다 [11].
두 경우 모두 위치만 정하고 그 파일의 버전은 정하지 않는다 [11][12].
환경변수가 가리키는 실행 파일은 실행기가 실행 직전에 파일 이름만 도구 이름과 대조하고 내용과 버전은 보지 않는다 [13].
이름이 `tshark`인 대리 실행 파일을 `WIRESHARK_MCP_TSHARK_PATH`로 가리키자 서버가 도구를 실행할 때마다 그 파일을 실행했다 [14].
GeoIP 리더는 처음 연 파일을 서버가 끝날 때까지 쓴다 [15].

**한계.** `GEOIP_DB_PATH`가 없는 파일을 가리키면 알리지 않고 다음 후보를 찾는다 [11].

### T05.03 실행 시 버전 조회

**구현.** 이 방식은 `wireshark_get_capabilities`에 적용된다 [16].
`check_capabilities`는 실행할 수 있는 도구마다 `-v`를 실행해 표준 출력 첫 줄의 마지막 낱말을 `version`으로 돌려준다 [17].
5초 안에 끝나지 않거나 예외가 나면 `unknown`으로 둔다 [17].
이 값은 이 도구의 응답에만 실리고 다른 도구의 실행 조건이나 결과에 쓰이지 않는다 [16][18].
`wireshark://capabilities` 리소스는 버전을 묻지 않고 실행 파일이 있는지만 적는다 [19].
`core` 프로필은 `wireshark_get_capabilities`를 등록하지 않는다 [20].
`yara-python`·`geoip2`의 버전과 YARA 규칙, GeoIP 데이터베이스의 버전은 읽지 않는다 [6][15].

**한계.** 첫 줄의 마지막 낱말은 버전 번호만 담지 않는다 [17].
Debian 패키지 4.0.17에서는 `4.0.17-0+deb12u3).`가, Windows의 4.6.7에서는 `(v4.6.7-0-gb439fb7b47a9).`가 `version`으로 돌아왔다 [21][22].

```python
def _find_geoip_db() -> Path | None:
    """Search for GeoLite2 database in standard locations."""
    candidates = []

    env_path = os.environ.get("GEOIP_DB_PATH")
    if env_path:
        candidates.append(Path(env_path))

    user_dir = Path.home() / ".wireshark-mcp" / "geoip"
    candidates.extend(
        [
            user_dir / "GeoLite2-City.mmdb",
            user_dir / "GeoLite2-Country.mmdb",
            user_dir / "GeoLite2-ASN.mmdb",
        ]
    )

    system_paths = [
        Path("/usr/share/GeoIP"),
        Path("/usr/local/share/GeoIP"),
        Path("/opt/homebrew/share/GeoIP"),
    ]
    for sp in system_paths:
        candidates.append(sp / "GeoLite2-City.mmdb")

    for p in candidates:
        if p.exists():
            return p
    return None
```
