# T04 실행 방식

### T04.01 서버 프로세스 안 분석

**구현.** 이 방식은 YARA 검사, GeoIP 조회, tshark 출력을 받아 집계하거나 판정하는 도구에 적용된다 [1][2][3][4].
`wireshark_yara_scan`은 tshark로 꺼낸 객체 파일마다 `yara-python`의 `rules.match`를 서버 프로세스 안에서 부른다 [1].
`wireshark_geoip_enrich`는 tshark로 뽑은 공인 IP 주소마다 `geoip2` 리더의 `city`를 서버 프로세스 안에서 부른다 [2].
`wireshark_aggregate`는 tshark의 필드 행을 흘려 받으며 서버 코드의 `_AggregateAccumulator`로 묶고 센다 [3].
탐지 도구와 BLE 분석 처리기는 tshark가 낸 필드 표를 서버 코드로 묶고 세어 문턱값과 비교한다 [4].
패킷 해석과 객체 꺼내기는 모두 tshark 하위 프로세스가 한다 [5].

### T04.02 같은 권한의 별도 프로세스

**구현.** 이 방식은 서버가 `tshark`·`capinfos`·`mergecap`·`editcap`·`dumpcap`·`text2pcap`을 실행하는 모든 도구에 적용된다 [5].
실행기 `_run_command`와 `_stream_field_rows`는 `asyncio.create_subprocess_exec`에 인자 배열을 넘기고 셸을 거치지 않는다 [5][6].
표준 입력은 `DEVNULL`로 두고 표준 출력과 표준 오류는 파이프로 받는다 [5].
Windows에서는 `CREATE_NO_WINDOW`를 붙여 콘솔 창을 만들지 않는다 [5].
작업 위치(`cwd`)와 환경변수를 따로 정하지 않으므로 자식 프로세스는 서버의 작업 위치와 환경을 그대로 쓴다 [5].
자식 프로세스는 서버와 같은 계정과 권한으로 실행된다.
시간 제한은 기본 30초다 [7].
`wireshark_capture`는 `duration_seconds`에 10초를 더한 값과 30초 가운데 큰 값을, `wireshark_aggregate`는 환경변수 `WIRESHARK_MCP_AGGREGATE_TIMEOUT`로 5~600초 사이에서 정한 값을 시간 제한으로 쓴다 [7].
버전 확인의 `-v` 실행은 5초를 시간 제한으로 쓴다 [8].

저장소 `Dockerfile`은 서버와 Wireshark 도구를 한 이미지에 설치하고 비루트 사용자 `wireshark-mcp`로 서버를 실행한다 [9].
그래서 그 이미지에서도 도구는 서버와 같은 컨테이너와 계정에서 실행된다 [9].
같은 기반 이미지로 만든 실행 환경의 기본 계정은 uid 10001의 `wireshark-mcp`였고 `dumpcap`에는 setuid 비트와 파일 capability가 없었다 [10].
`wireshark_yara_scan`이 만드는 임시 폴더는 객체를 꺼낼 출력 위치이고 tshark의 작업 위치로 쓰지 않는다 [11].

[9] `Dockerfile`은 도구와 서버를 한 이미지에 두고 비루트 사용자로 실행한다.

```dockerfile
RUN apt-get update \
    && DEBIAN_FRONTEND=noninteractive apt-get install --yes --no-install-recommends ca-certificates tshark \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/* \
    && python -m pip install --no-cache-dir --upgrade "setuptools>=83" \
    && python -m pip install --no-cache-dir "wireshark-mcp==${WIRESHARK_MCP_VERSION}" \
    && groupadd --gid 10001 wireshark-mcp \
    && useradd --uid 10001 --gid 10001 --create-home wireshark-mcp \
    && mkdir --parents /captures /results \
    && chown wireshark-mcp:wireshark-mcp /captures /results

USER wireshark-mcp
WORKDIR /captures

EXPOSE 8080

ENTRYPOINT ["wireshark-mcp"]
CMD ["serve", "--transport", "streamable-http", "--host", "0.0.0.0", "--port", "8080", "--allow-insecure-http", "--profile", "analysis"]
```
