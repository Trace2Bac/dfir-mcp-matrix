# D04 출력 경로 제한

### D04.01 서버가 출력 위치 결정

**구현.** 이 방식은 `dest_dir` 없이 부른 `wireshark_yara_scan`이 캡처에서 꺼낸 파일을 두는 임시 폴더에 적용된다 [1].
서버는 `_create_temporary_output_dir`로 허용 폴더 목록의 앞에서부터 `mkdtemp`를 시도해 처음 만든 `wireshark_yara_` 접두어의 폴더를 쓴다 [2].
이 폴더를 `tshark --export-objects`의 목적지로 넘기고 호출이 끝나면 `finally`에서 지운다 [1].
허용 폴더가 없으면 임시 폴더를 만들지 않고 `PermissionDenied`로 끝난다 [2][3].
허용 폴더 목록에 입력 캡처 파일의 폴더를 앞에 적은 서버에서는 임시 폴더가 그 입력 폴더 안에 생겼다 [3].
그 밖의 파일을 쓰는 도구는 목적지를 호출 인자 `output_file`, `output_prefix`, `dest_dir`로 받는다 [4].

### D04.02 실제 경로와 허용 폴더 대조

**구현.** 이 방식은 파일을 쓰는 도구 11개의 목적지 인자에 적용된다 [4][5].
허용 폴더는 환경변수 `WIRESHARK_MCP_ALLOWED_DIRS`에 쉼표로 나눠 적은 폴더다 [6].
서버는 시작할 때 이 값을 `resolve()`로 실제 경로로 바꾸고 폴더가 아닌 값이 있으면 `ValueError`를 낸다 [6].
`_validate_output_path`는 허용 폴더가 없으면 쓰기를 거부한다 [5].
허용 폴더가 있으면 목적지를 `resolve()`로 링크와 `..`를 해석한 실제 경로로 바꾸고 허용 폴더 가운데 하나의 아래인지 `relative_to`로 대조한다 [5][7].
밖이면 `PermissionDenied`로 거부한다 [5].
허용 폴더 밖의 절대 경로, 허용 폴더 안에서 밖을 가리키는 링크를 거치는 경로, 상위 폴더로 나가는 경로는 모두 거부되었고 파일이 생기지 않았다 [8].
저장된 파생물을 고치거나 지우는 전용 도구는 없다.
`Dockerfile`은 `/captures`와 `/results` 폴더를 만들지만 `WIRESHARK_MCP_ALLOWED_DIRS`는 정하지 않고 서버를 `analysis` 프로필로 실행한다 [9].

**한계.** 서버는 대조에 쓴 실제 경로가 아니라 받은 문자열을 그대로 분석 도구 명령에 넣는다 [10].
대조한 뒤 도구가 파일을 열기 전에 경로 안의 링크가 바뀌는 경우는 실행으로 확인하지 않았다.
`wireshark_editcap_split`과 `ring_buffer`를 준 `wireshark_capture`는 대조한 경로 자체가 아니라 그 경로로 지은 다른 이름에 쓴다 [11][12].
`editcap`과 `dumpcap`은 받은 경로에서 마지막 조각의 `.` 앞까지를 접두어로 삼고 그 뒤에 `_`, 번호, 시각을 붙인 이름으로 파일을 만든다 [11][12].
그래서 허용 폴더 자체를 `output_prefix`나 `output_file`로 주면 대조는 통과하고 파일은 허용 폴더의 상위 폴더에 생겼다 [13].
`wireshark_set_protocol_prefs`는 받은 `prefs`를 검사 없이 `tshark`의 `-o`로 넘기고 이 경로에는 목적지 대조가 적용되지 않는다 [14].
이 도구는 파일을 쓰는 도구 목록에 없어 `analysis` 프로필에서도 등록된다 [15].
허용 폴더를 정하지 않은 `analysis` 프로필 서버에서 출력 파일 경로를 값으로 받는 해석 설정으로 다른 폴더의 경로를 넘기자 성공 응답이 왔고 그 경로에 `tshark`가 쓴 파일이 생겼다 [16].

### D04.04 이름·확장자·충돌 검사

**구현.** 이 방식은 Windows에서 실행한 서버가 받는 목적지 경로에 적용된다 [17].
`_is_unsafe_windows_path`는 `\\.\`나 `\\?\`로 시작하는 장치 경로, 조각에 `:`가 있는 경로, `CON`·`NUL`·`COM1`·`LPT1` 같은 예약 이름 조각을 거부한다 [17].
`_validate_output_path`는 허용 폴더 대조보다 먼저 이 검사를 해 `InvalidParameter`로 거부한다 [17].
Windows에서 예약 이름이나 `:`가 있는 목적지를 준 `wireshark_editcap_trim`과 장치 경로를 준 `wireshark_export_objects`는 모두 거부되었고 파일이 생기지 않았다 [18].
다른 운영체제에서 이 함수는 검사 없이 `False`를 돌려준다 [17].
확장자와 이미 있는 이름은 검사하지 않는다.

### D04.05 서버가 파일 이름 결정

**구현.** 이 방식은 `wireshark_export_objects`와 `dest_dir`를 준 `wireshark_yara_scan`이 꺼낸 파일의 이름에 적용된다 [19][1].
목적지 폴더는 호출 인자 `dest_dir`이고 그 안의 파일 이름은 서버 코드가 아니라 Wireshark 4.0.17의 `tshark`가 정한다 [19][20].
`tshark`는 전송에 적힌 파일 이름을 쓰고 이름이 없으면 `object`와 프레임 번호, 콘텐츠 유형으로 이름을 짓는다 [20].
이름 안의 `<`, `>`, `:`, `"`, `/`, `\`, `|`, `?`, `*`와 제어 문자는 `%`와 16진수 두 자리로 바꾼다 [21].
같은 이름의 파일이 이미 있으면 확장자 앞에 `(1)`, `(2)` 같은 번호를 붙인 새 이름을 지어 앞 파일을 덮어쓰지 않는다 [20][21].
`report.txt`가 이미 있는 폴더로 내보내자 앞 파일은 그대로 남고 `report(1).txt`가 새로 생겼다 [22].
서버 코드는 이 이름을 검사하거나 바꾸지 않는다 [19].

**한계.** 원래 이름과 `(1)`부터 `(999)`까지의 이름이 모두 있으면 `tshark`는 `(999)` 이름의 파일을 덮어쓴다 [20][23].

    def _create_temporary_output_dir(self, prefix: str) -> dict[str, Any]:
        """Create a private temporary directory inside an explicitly allowed root."""
        if not self._allowed_dirs:
            return {
                "success": False,
                "error": {
                    "type": "PermissionDenied",
                    "message": (
                        "Temporary file writes are disabled. Set WIRESHARK_MCP_ALLOWED_DIRS "
                        "to one or more dedicated writable directories."
                    ),
                },
            }

        for root in self._allowed_dirs:
            try:
                return {"success": True, "path": tempfile.mkdtemp(prefix=prefix, dir=root)}
            except OSError:
                continue
        return {
            "success": False,
            "error": {
                "type": "PermissionDenied",
                "message": "No configured allowed directory is writable",
            },
        }

    def _is_path_within(path: Path, parent: Path) -> bool:
        """Check if path is within parent directory (symlink-safe)."""
        try:

    @staticmethod
    def _is_unsafe_windows_path(filepath: str) -> bool:
        """Reject Windows device namespaces, reserved names, and NTFS ADS paths."""
        if sys.platform != "win32":
            return False

        normalized = filepath.replace("/", "\\")
        if normalized.startswith(("\\\\.\\", "\\\\?\\")):
            return True

        path = PureWindowsPath(filepath)
        parts = path.parts[1:] if path.anchor else path.parts
        for part in parts:
            if ":" in part:
                return True
            base_name = part.rstrip(" .").split(".", 1)[0].rstrip(" ").upper()
            if base_name in _WINDOWS_RESERVED_NAMES:
                return True
        return False
