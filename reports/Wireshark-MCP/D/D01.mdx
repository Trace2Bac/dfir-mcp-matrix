# D01 파생물 보관

### D01.01 파생물 파일 보관

**구현.** 이 방식은 파일을 쓰는 도구 11개와 `tshark` 환경설정 값을 받는 `wireshark_set_protocol_prefs`에 적용된다 [1][2].
이 도구는 `wireshark_capture`, `wireshark_merge_pcaps`, `wireshark_text2pcap_import`, `wireshark_filter_save`, `wireshark_editcap_trim`, `wireshark_editcap_split`, `wireshark_editcap_time_shift`, `wireshark_editcap_deduplicate`, `wireshark_extract_frames`, `wireshark_export_objects`, `wireshark_yara_scan`이다 [1].
캡처 파일을 만드는 도구는 호출 인자 `output_file`이나 `output_prefix`가 가리키는 경로에 `dumpcap`, `mergecap`, `text2pcap`, `tshark`, `editcap`이 쓴 pcap·pcapng 파일을 남긴다 [3].
`wireshark_export_objects`는 `tshark --export-objects`가 캡처 안의 HTTP·SMB·TFTP·IMF·DICOM 전송에서 꺼낸 파일을 호출 인자 `dest_dir` 폴더에 남긴다 [4].
`wireshark_yara_scan`은 `dest_dir`를 받으면 같은 방법으로 꺼낸 파일을 그 폴더에 남긴다 [5].
꺼낸 파일마다 YARA 규칙을 대조한 결과는 응답에만 싣는다 [5].
서버 코드에는 이 파일을 호출 뒤에 지우는 곳이 없다 [3][4].
도구를 부른 뒤 출력 파일과 꺼낸 파일은 서버를 끝낸 뒤에도 목적지에 남아 있었다 [6].
`wireshark_set_protocol_prefs`는 받은 `prefs`를 `tshark`의 `-o`로 넘기므로 기록 파일 경로를 정하는 환경설정을 주면 `tshark`가 그 경로에 파일을 쓴다 [2][7].
이 파일도 서버가 지우지 않는다 [7].
남긴 파일 전체의 보관 기간, 용량, 대상을 정하는 설정이나 코드는 없다.
한 호출이 도구의 원래 출력과 그 가공본을 함께 파일로 남기는 경로는 없다.

파일을 쓰는 도구 11개의 출력은 사용자가 허용 폴더를 정했을 때만 생긴다.
환경변수 `WIRESHARK_MCP_ALLOWED_DIRS`가 없으면 파일을 쓰는 도구는 도구를 실행하지 않고 `PermissionDenied`로 끝난다 [8][6].
도구 프로필 `analysis`와 `core`는 이 11개 도구를 등록하지 않는다 [9].
저장소의 `Dockerfile`이 만드는 이미지는 기본 명령에서 `analysis` 프로필로 서버를 실행한다 [10].
`wireshark_set_protocol_prefs`는 허용 폴더를 정하지 않아도 실행되고 `analysis` 프로필에서도 등록되며 `core` 프로필에서만 빠진다 [7][9][11].

`wireshark_yara_scan`에 `dest_dir`를 주지 않으면 서버는 허용 폴더 안에 `wireshark_yara_` 접두어의 임시 폴더를 만들어 꺼낸 파일을 두고 `finally`에서 그 폴더를 지운다 [5].
이 호출 뒤에는 임시 폴더가 남지 않았다 [6].
그 밖의 도구는 결과를 응답으로만 돌려준다.
`tshark` 실행 결과를 담는 캐시 `ResultCache`는 프로세스 메모리에만 두고 파일로 쓰지 않는다 [12].

```python
    async def export_objects(self, pcap_file: str, protocol: str, dest_dir: str) -> str:
        """Export Objects (--export-objects protocol,dest_dir)."""
        validation = self._validate_file(pcap_file)
        if not validation["success"]:
            return json.dumps(validation)

        proto_validation = self._validate_protocol(protocol, self.VALID_EXPORT_PROTOCOLS)
        if not proto_validation["success"]:
            return json.dumps(proto_validation)

        output_validation = self._validate_output_path(dest_dir)
        if not output_validation["success"]:
            return json.dumps(output_validation)

        os.makedirs(dest_dir, exist_ok=True)
        cmd = [
            self.tshark_path,
            "-r",
            pcap_file,
            "--export-objects",
            f"{protocol},{dest_dir}",
        ]
        return await self._run_command(cmd)
```

```python
class ResultCache:
    """LRU cache for tshark command results, keyed by file identity + command."""

    def __init__(
        self,
        max_entries: int = DEFAULT_MAX_ENTRIES,
        max_bytes: int = DEFAULT_MAX_BYTES,
        ttl_seconds: int = DEFAULT_TTL_SECONDS,
    ) -> None:
        self._cache: OrderedDict[str, tuple[str, float]] = OrderedDict()
        # key -> resolved file path, so a single file can be invalidated on write.
        self._key_paths: dict[str, str] = {}
        self._max_entries = max_entries
        self._max_bytes = max_bytes
        self._ttl = ttl_seconds
        self._current_bytes = 0
        self._hits = 0
        self._misses = 0
```
