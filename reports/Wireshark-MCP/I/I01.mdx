# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 스스로 외부에 연결하지 않는다.
`pyproject.toml`의 필수 의존성은 `mcp`·`click`·`cryptography`·`pyjwt`·`python-multipart`·`pyyaml`·`starlette`·`tomlkit`이다 [1].
MCP SDK가 의존하는 HTTP 클라이언트 `httpx2`가 함께 설치되지만 서버 코드는 이를 불러 쓰지 않는다 [2][3].
`src/wireshark_mcp/`에는 HTTP 클라이언트나 소켓 모듈을 불러오는 코드가 없다 [3].
사용자 CLI `install`·`update`·`uninstall`·`config`·`doctor`·`clients`도 같은 패키지에 속하고 외부에 연결하지 않는다 [3].

SSE와 Streamable HTTP 전송은 클라이언트의 연결을 받기만 한다 [4].
`serve`는 이 두 전송을 `--host`·`--port`에서 열고 `--host`의 기본값은 `127.0.0.1`이다 [4].
루프백이 아닌 주소에 열려면 `--allow-insecure-http`를 함께 줘야 하고 주지 않으면 시작하지 않는다 [5].
`0.0.0.0`에 `--allow-insecure-http` 없이 열자 서버는 오류로 끝났고 그 값을 주자 경고 한 줄을 쓴 뒤 요청을 받기 시작했다 [6].
`Dockerfile`의 기본 명령은 Streamable HTTP를 `0.0.0.0`의 8080 포트에 `--allow-insecure-http`와 `--profile analysis`로 연다 [7].
이 명령도 요청을 받는 연결만 연다 [7][6].
이미지를 만들 때 `pip`이 PyPI에서 패키지를 받는 것은 서버 밖에서 실행하는 설치 명령이다 [7].

`wireshark_geoip_enrich`는 GeoIP 조회에 외부 서비스를 쓰지 않는다 [8].
이 도구는 `geoip2`의 `Reader`로 로컬 GeoLite2 데이터베이스 파일을 연다 [8].
파일은 `GEOIP_DB_PATH`, `~/.wireshark-mcp/geoip/`, 시스템 GeoIP 폴더에서 찾는다 [8].
파일이 없으면 내려받을 주소를 적은 오류 글을 돌려주고 내려받지 않는다 [8].
`geoip2` 5.3.0의 `Reader`는 `maxminddb.open_database`로 로컬 파일을 연다 [9].

분석 도구가 이름 풀이를 하며 보내는 DNS 조회는 분석 도구가 스스로 하는 통신이고 서버 코드가 여는 연결이 아니다.

def _is_loopback_host(host: str) -> bool:
    """Return whether a bind host is unambiguously local-only."""
    if host.lower().rstrip(".") == "localhost":
        return True
    try:
        return ip_address(host).is_loopback
    except ValueError:
        return False

[6] (실행 확인) `--network none` 컨테이너 안에서 `wireshark-mcp serve --transport streamable-http --host 0.0.0.0`을 실행하자 `Refusing to expose an unauthenticated MCP transport beyond loopback` 오류와 종료 코드 2로 끝났다.

[7] 이미지는 빌드할 때 `pip`으로 패키지를 설치하고 기본 명령으로 Streamable HTTP를 `0.0.0.0`에 연다.

```dockerfile
RUN apt-get update \
    && DEBIAN_FRONTEND=noninteractive apt-get install --yes --no-install-recommends ca-certificates tshark \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/* \
    && python -m pip install --no-cache-dir --upgrade "setuptools>=83" \
    && python -m pip install --no-cache-dir "wireshark-mcp==${WIRESHARK_MCP_VERSION}" \
    && groupadd --gid 10001 wireshark-mcp \
    && useradd --uid 10001 --gid 10001 --create-home wireshark-mcp \
    && mkdir --parents /captures /results \
    && chown wireshark-mcp:wireshark-mcp /captures /results

USER wireshark-mcp
WORKDIR /captures

EXPOSE 8080

ENTRYPOINT ["wireshark-mcp"]
CMD ["serve", "--transport", "streamable-http", "--host", "0.0.0.0", "--port", "8080", "--allow-insecure-http", "--profile", "analysis"]
```
