# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버 코드는 스스로 외부 연결을 열지 않는다 [1].
`wireshark_geoip_enrich`는 `geoip2`의 웹 서비스 클라이언트가 아니라 로컬 파일을 여는 `geoip2.database.Reader`를 쓰므로 MaxMind 계정이나 라이선스 키를 읽지 않는다 [2].
`wireshark_decrypt_wpa`가 받는 WPA 암호와 `wireshark_decrypt_tls`가 받는 TLS 키 기록 파일은 캡처 파일을 복호화하는 입력이고 외부 접속에 쓰는 자격증명이 아니다 [3].
서버가 읽는 환경변수는 허용 폴더, 분석 도구 경로, 결과 글자 수 상한, 집계 행 수와 시간 상한, GeoIP 데이터베이스 경로를 정하고 자격증명을 담는 것은 없다 [4].

```python
def _get_reader() -> Any:
    """Get or create a GeoIP2 database reader (singleton)."""
    global _geoip2_reader
    if _geoip2_reader is not None:
        return _geoip2_reader

    db_path = _find_geoip_db()
    if db_path is None:
        return None

    _geoip2_reader = geoip2.database.Reader(str(db_path))
    logger.info("GeoIP database loaded: %s", db_path)
    return _geoip2_reader
```

```python
    @mcp.tool()
    async def wireshark_decrypt_wpa(
        pcap_file: str, wpa_passphrase: str, ssid: str = "", display_filter: str = ""
    ) -> str:
        """[Decrypt] Decrypt WPA/WPA2 traffic with passphrase (+SSID)."""
        key = f"{wpa_passphrase}:{ssid}" if ssid else wpa_passphrase
        return normalize_tool_result(await client.decrypt_wpa_traffic(pcap_file, [key], display_filter))
```
