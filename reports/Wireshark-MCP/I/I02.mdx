# I02 분석 도구 통신 차단

### I02.02 DNS 조회 끄기

**구현.** 이 방식은 `wireshark_aggregate`가 `tshark`를 실행하는 `stream_fields`에 적용된다 [1].
`stream_fields`는 `tshark` 명령의 실행 파일 바로 뒤에 `-n`을 두고 그 뒤에 모델이 준 필드와 표시 필터를 붙인다 [1].
Wireshark 4.0.17에서 `-n`은 네트워크 주소 이름 해석과 외부 resolver 사용을 포함한 이름 해석 설정을 모두 끈다 [2].
`tshark` 설명서는 `-n`과 `-N`이 `-o`로 준 값을 포함한 환경설정의 이름 해석 값보다 앞선다고 적는다 [3].
이름 해석 설정이 꺼져 있으면 `tshark`는 주소의 역방향 DNS 조회도 표시 필터에 적힌 호스트 이름의 조회도 하지 않는다 [4].
사용자 환경설정 파일에서 네트워크 이름 해석을 켠 상태로 `wireshark_aggregate`를 부르자 DNS 조회가 나가지 않았다 [5].

서버가 `tshark`를 실행하는 다른 경로는 `-n`을 붙이지 않는다 [6].
Wireshark 4.0.17의 기본 환경설정은 네트워크 주소 이름 해석을 끄고 외부 resolver 사용을 켠다 [7].
그래서 환경설정이 기본값이면 다른 경로도 DNS 조회를 하지 않는다 [7][5].
기본 환경설정에서 `wireshark_get_packet_list`를 부른 호출과 호스트 이름을 넣은 표시 필터로 부른 호출은 조회를 보내지 않았다 [5].
`tshark`는 실행한 사용자의 환경설정을 읽은 뒤 명령 행 옵션을 적용한다 [8].
같은 사용자 환경설정 파일에서 네트워크 이름 해석을 켜자 `wireshark_get_packet_list`와 `wireshark_extract_fields`는 캡처 파일의 주소마다 역방향 조회를 보냈다 [5].

`wireshark_set_protocol_prefs`는 모델이 준 `prefs` 값을 `;`로 나눠 각각 `tshark`의 `-o` 값으로 넘기고 값을 목록과 대조하지 않는다 [9].
그래서 모델은 이 도구로 네트워크 이름 해석을 켤 수 있다 [9][8].
이 도구로 네트워크 이름 해석을 켜자 캡처 파일의 주소마다 역방향 조회가 나갔고 표시 필터에 넣은 호스트 이름의 조회도 나갔다 [5].
이 도구는 `full`과 `analysis` 프로필에 등록되고 `core` 프로필에서는 빠진다 [10].

다른 분석 도구에도 통신을 끊거나 끄는 장치가 없다.
`_run_command`와 `_stream_field_rows`는 하위 프로세스에 `env`를 주지 않아 분석 도구는 서버 프로세스의 환경변수를 그대로 물려받는다 [11].
저장소에는 분석 도구를 네트워크 없는 컨테이너나 network namespace에서 실행하는 구성이 없다.
`Dockerfile`에도 분석 도구의 네트워크를 끊는 설정이 없다 [12].
`wireshark_capture`는 모델이 준 `interface` 값을 캡처 실행 파일의 `-i` 값으로 그대로 넘긴다 [13].
Debian 패키지 4.0.17을 설치한 이미지에서 원격 캡처 주소 형식의 장치 이름을 주자 `dumpcap`은 그런 장치가 없다는 오류로 끝났고 그 주소로 연결을 시도하지 않았다 [14].
원격 캡처를 지원하는 다른 libpcap 빌드에서 이 값이 연결을 여는지는 확인하지 못했다.
`geoip2` 5.3.0의 `Reader`는 로컬 데이터베이스 파일만 연다 [15].
YARA 라이브러리가 스스로 통신하는지는 확인하지 않았다.

[1] `stream_fields`는 `tshark` 명령에 `-n`을 넣고 모델이 준 필드와 표시 필터를 더한다.

```python
    async def stream_fields(
        self,
        pcap_file: str,
        fields: list[str],
        consumer: FieldRowConsumer,
        display_filter: str = "",
        max_rows: int = 1_000_000,
        timeout: int = 30,
    ) -> FieldStreamResult:
        """Consume tshark field rows without materializing its complete stdout."""
        validation = self._validate_file(pcap_file)
        if not validation["success"]:
            error = validation.get("error")
            return {"success": False, "error": error if isinstance(error, dict) else {"message": str(error)}}

        cmd = [self.tshark_path, "-n", "-r", pcap_file, "-T", "fields"]
        for field in fields:
            cmd.extend(["-e", field])
        if display_filter:
            cmd.extend(["-Y", display_filter])
        cmd.extend(["-E", "header=y", "-E", "separator=/t", "-E", "aggregator=,", "-E", "quote=d"])
        return await self._stream_field_rows(cmd, consumer, max_rows=max_rows, timeout=timeout)
```

```python
    @mcp.tool()
    async def wireshark_set_protocol_prefs(
        pcap_file: str,
        prefs: str,
        fields: str = "",
        display_filter: str = "",
        limit: int = 100,
    ) -> str:
        """[Dissection] Protocol preference overrides. Prefs: 'tcp.desegment_tcp_streams:TRUE;http.ssl.port:8443'."""
        pref_list = [p.strip() for p in prefs.split(";") if p.strip()]
        field_list = [f.strip() for f in fields.split(",") if f.strip()] if fields else []
        return normalize_tool_result(
            await client.extract_with_prefs(pcap_file, pref_list, field_list, display_filter, limit)
        )
```
