# D02 파생물 추적

### D02.01 ID·경로 참조

**구현.** 이 방식은 `baseline_create`가 쓰는 기준선 파일에 적용된다 [1].
기준선 파일의 `_metadata`에는 기준선을 만든 증거 폴더의 실제 경로 `root_path`와 생성 시각 `created_at`이 들어간다 [1].
항목마다 그 파일의 `root_path` 기준 상대 경로가 들어가 각 해시가 어느 증거 파일에서 나왔는지 가리킨다 [1].
같은 호출의 호출 기록 항목에는 도구 이름, 모델이 준 `root_path`, 실제로 쓴 기준선 파일 경로가 `params`로 남는다 [2].
그래서 기준선 파일에서 사용한 증거 폴더로, 호출 기록 항목에서 기준선 파일로 경로가 이어진다 [1][2].

호출 기록 항목에는 호출 ID가 없고 시각·도구 이름·인자·결과 요약만 있다 [3].
기준선 파일에도 그것을 만든 호출을 가리키는 값이 없어 둘은 경로와 시각으로만 대응한다 [1][3].
`baseline_diff`는 기준선 파일을 입력으로 읽지만 결과를 파일로 남기지 않고 호출 기록 항목에 `root_path`와 기준선 파일 경로만 남긴다 [4].
경로만 남기고 입력·출력 내용의 해시를 함께 남기는 곳이 없다.
파생물 곁에 manifest를 두지 않고 중간 입력의 버전도 남기지 않는다.

**한계.** 같은 목적지로 `baseline_create`를 다시 부르면 기준선 파일을 덮어쓴다 [5].
그 뒤에는 앞 호출의 호출 기록 항목이 나중 호출이 쓴 기준선 파일을 가리킨다 [2][5].

```python
def _build_baseline(root: Path) -> dict:
    entries: list[FileEntry] = []
    for path, severity in _expand_tracked_paths(root):
        entry = _stat_entry(root, path, severity)
        if entry is not None:
            entries.append(entry)

    return {
        "_metadata": {
            "created_at": datetime.now(tz=timezone.utc).isoformat(),
            "root_path": str(root),
            "tool_version": "findevil-fim-1",
            "entry_count": len(entries),
        },
        "entries": [asdict(e) for e in entries],
    }
```

def _audit(tool: str, params: dict, result_summary: str) -> None:
    """Write a structured audit log entry for every tool invocation."""
    entry = {
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "tool": tool,
        "params": params,
        "result_summary": result_summary[:500],
    }
    audit_logger.info(json.dumps(entry))
