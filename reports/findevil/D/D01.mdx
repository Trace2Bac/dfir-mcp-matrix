# D01 파생물 보관

### D01.01 파생물 파일 보관

**구현.** 이 방식은 파일 무결성 기준선을 만드는 `baseline_create`와, 응답 앞부분을 호출 기록에 넣는 `file_info`·`hash_file`·`log_search`에 적용된다 [1][2].
`baseline_create`는 증거 폴더 안 `root_path` 아래에서 정해 둔 계정·SSH·cron·systemd·PAM 등의 파일을 골라 파일마다 SHA-256·크기·권한·소유자·수정 시각·심각도를 담은 항목을 만든다 [3].
서버 코드는 이 항목 목록에 생성 시각·`root_path`·형식 표시 `findevil-fim-1`·항목 수를 담은 `_metadata`를 붙여 JSON 파일 하나로 쓴다 [3][1].
목적지는 `output_file`이 비면 `FINDEVIL_LOGS_DIR`(기본값 `./logs`) 아래 `baseline.json`이고 값을 주면 그 경로다 [4].
서버는 이 파일을 호출 뒤에 지우지 않고 `baseline_diff`가 `baseline_file` 인자로 다시 읽어 현재 상태와 비교한다 [5].
보관 기간·용량·대상을 정하는 설정이나 코드는 없다.

호출 기록 파일 `audit.json`의 항목마다 `result_summary`가 있고 서버는 그 값을 500자에서 자른다 [6].
`file_info`와 `hash_file`은 `file`·`stat` 또는 `md5sum`·`sha256sum`의 출력을 이어 붙인 응답 전체를 `result_summary`로 넘긴다 [2].
`log_search`는 `grep` 출력으로 만든 응답의 앞 200자를 넘긴다 [2].
그래서 이 세 도구에서는 분석 도구 출력의 앞부분이 호출 기록 파일에 남는다 [2][6].
다른 도구는 건수나 판정 요약 문장만 호출 기록에 넘기고 출력은 응답으로만 돌려준다.
분석 도구의 원래 출력과 가공본을 함께 남기는 도구는 없어 D01.03에는 연결하지 않는다.
DB나 객체 저장소에 출력을 넣는 코드도 없어 D01.02에도 연결하지 않는다.

사용자 CLI `scripts/investigate.py`는 반복마다 `assess_coverage` 응답 전체와 `claude` 실행 정보를 `logs/progress/<증거 이름>/iteration-NN.json`에 쓴다 [7].
이 파일은 사용자 CLI가 만드는 것이라 서버 구현으로 세지 않는다.

**한계.** 호출 기록에 남는 출력은 앞부분뿐이다 [6][2].
`file_info`·`hash_file` 응답이 500자를, `log_search` 응답이 200자를 넘으면 그 뒤는 남지 않는다 [6][2].
`baseline_create`는 읽지 못한 파일을 항목에서 빼므로 기준선 파일에 고른 파일이 모두 남지 않을 수 있다 [8].

```python
def _resolve_output_path(output_file: str) -> Path:
    """Pick the baseline output path. Default is LOGS_DIR/baseline.json.

    Late import of `server` is intentional — tests monkeypatch
    `server.LOGS_DIR` and we want to see the current value, not a
    captured-at-import-time copy.

    Security: refuses output paths inside EVIDENCE_DIR. Without this,
    a user (or prompt-injected tool arg) could tell baseline_create to
    write its JSON output over an evidence file, violating the
    "no-write-to-evidence" architectural guarantee.
    """
    from findevil import server

    if not output_file:
        return server.LOGS_DIR / "baseline.json"
    p = Path(output_file)
    if not p.is_absolute():
        p = Path.cwd() / p
    resolved = p.resolve()
    evidence_resolved = server.EVIDENCE_DIR.resolve()
    try:
        resolved.relative_to(evidence_resolved)
    except ValueError:
        return resolved  # not inside evidence — allowed
    raise ValueError(
        f"baseline output path {output_file} resolves inside the evidence "
        f"directory ({server.EVIDENCE_DIR}); refusing to write over evidence."
    )
```

```python
def _hash_file(path: Path, chunk_size: int = 65536) -> str:
    """Compute SHA256 streaming. Returns empty string on permission error."""
    h = hashlib.sha256()
    try:
        with path.open("rb") as f:
            while True:
                chunk = f.read(chunk_size)
                if not chunk:
                    break
                h.update(chunk)
    except (OSError, PermissionError):
        return ""
    return h.hexdigest()
```
