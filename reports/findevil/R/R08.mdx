# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 auth 도구, `analyze_nginx_access`, 메모리 도구, 명령 출력을 싣는 기본 도구에 적용된다 [1].
`auth_successful_logins`·`auth_sudo_commands`·`auth_user_events`는 syslog 줄의 `Apr 15 14:23:05` 꼴 시각 문자열을 바꾸지 않고 싣는다 [1][2].
`analyze_nginx_access`는 웹셸 업로드 사슬의 업로드 시각을 access log의 시각 문자열 그대로 싣는다 [3].
`analyze_memory_bash_history`는 Volatility 행의 `CommandTime` 값을 그대로 싣는다 [4].
`file_info`와 `list_evidence`는 `stat`과 `ls -lahR`이 출력한 시각을 그대로 싣는다 [5].

다른 도구는 시각을 바꿔 싣고 원래 값을 함께 싣지 않는다.
`analyze_journal`은 `__REALTIME_TIMESTAMP`의 마이크로초 정수를, `analyze_bash_history`는 `#<epoch>` 줄을 ISO 8601 문자열로 바꿔 싣는다 [6][7].
`build_timeline`은 모든 출처의 시각을 ISO 8601 문자열로 바꾼 값만 표에 싣고 원래 값 대신 기록 파일 이름과 줄 번호를 싣는다 [8].
`analyze_package_logs`는 apt·dpkg·pip 시각을 `_normalize_ts`로 바꾼 값만 표에 싣고 바꾸지 못한 yum 시각은 원래 문자열 그대로 싣는다 [9][10].

### R08.03 시간대·단위·정밀도 표시

**구현.** 서버가 epoch 값이나 파일 시각에서 만든 시각은 UTC 오프셋 `+00:00`을 붙인 ISO 8601 문자열이다 [11].
`stat_file`·`find_recent_changes`·`find_timestamp_anomalies`는 파일의 mtime·ctime·atime을 UTC 시간대를 붙인 `datetime`으로 바꿔 `isoformat()`으로 싣는다 [11].
`analyze_journal`과 `analyze_bash_history`가 바꾼 시각도 UTC 오프셋을 붙여 싣는다 [6][7].
FIM 기준의 파일 시각과 만든 시각, `verify_finding`이 판정 근거에 싣는 mtime도 같은 방식이다 [12].
`build_timeline`도 출처마다 바꾼 시각을 이 꼴로 싣는다 [8].

**한계.** `build_timeline`은 syslog 시각에 원래 없던 UTC 오프셋을 붙이고 access log 시각의 원래 오프셋은 버린다 [13][14].
syslog 시각에는 연도와 시간대가 없는데 `_normalize_syslog_ts`는 인자 `fallback_year`(기본값 2026)를 연도로 넣고 UTC로 정한다 [13].
`_normalize_nginx_ts`는 access log 시각 뒤의 오프셋(`+0000` 등)을 읽지 않고 UTC로 정한다 [14].
그래서 기록이 UTC가 아닌 시간대로 적혔으면 응답의 `+00:00` 시각은 실제 UTC 시각과 다르고 응답에는 연도나 시간대를 가정했다는 표시가 없다 [8][13][14].

apt·dpkg·pip 시각은 `_normalize_ts`가 `YYYY-MM-DDTHH:MM:SS` 꼴로 바꾸고 시간대를 붙이지 않는다 [9].
`build_timeline`은 이 값과 `+00:00`이 붙은 값을 한 표에 두고 문자열 차례로 정렬한다 [8][9].
`analyze_package_logs`도 시각 문자열 차례로 정렬하므로 원래 꼴로 남은 yum 시각(`Apr 15 …`)은 실제 시각과 관계없이 ISO 꼴 시각 뒤에 놓인다 [10].

`analyze_journal`은 `__REALTIME_TIMESTAMP`를 정수로 읽지 못하면 원래 값을 그대로 시각 칸에 싣고 바꾸지 못했다는 표시를 붙이지 않는다 [15].
값이 없는 항목은 빈 시각으로 실린다 [15].

def _parse_timestamp(value: str) -> str:
    """Convert journal's microsecond-since-epoch string to ISO 8601 UTC."""
    try:
        micros = int(value)
        return datetime.fromtimestamp(micros / 1_000_000, tz=timezone.utc).isoformat()
    except (ValueError, TypeError, OverflowError):

def _normalize_ts(raw: str) -> str:
    """Best-effort convert to ISO 8601; return raw on failure."""
    raw = raw.strip()
    for fmt in (
        "%Y-%m-%d %H:%M:%S",
        "%Y-%m-%dT%H:%M:%S",
        "%Y-%m-%d",
    ):
        try:
            return datetime.strptime(raw, fmt).isoformat()
        except ValueError:
            continue
    return raw
```

def _normalize_syslog_ts(raw: str, fallback_year: int) -> str:
    """Convert `Apr 12 14:30:04` -> ISO 8601 UTC. fallback_year required
    because syslog lines don't carry a year."""
    m = _SYSLOG_TS_RE.match(raw.strip())
    if not m:
        return raw
    month, day, h, mn, s = m.groups()
    try:
        dt = datetime(
            fallback_year, _MONTH_TO_NUM[month], int(day),
            int(h), int(mn), int(s), tzinfo=timezone.utc,
        )
        return dt.isoformat()
    except (KeyError, ValueError):
        return raw
```
