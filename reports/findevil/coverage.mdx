# findevil 기능→셀 대응표

`python tools/coverage.py findevil`가 이 파일 머리말의 기능 목록(`tools`)과 셀 원고로 만든 표다. 표는 손으로 고치지 않고, 기능 목록을 고친 뒤 다시 만든다.
기능 목록: MCP 도구(server) 6개(본문에 없음 0개), MCP 도구(ai_signatures) 1개(본문에 없음 0개), MCP 도구(autonomy) 2개(본문에 없음 0개), MCP 도구(fim) 2개(본문에 없음 0개), MCP 도구(linux_auth) 5개(본문에 없음 0개), MCP 도구(linux_containers) 1개(본문에 없음 0개), MCP 도구(linux_journal) 1개(본문에 없음 0개), MCP 도구(linux_memory) 7개(본문에 없음 0개), MCP 도구(linux_packages) 2개(본문에 없음 0개), MCP 도구(linux_persistence) 5개(본문에 없음 0개), MCP 도구(linux_shell_history) 2개(본문에 없음 0개), MCP 도구(linux_timeline) 4개(본문에 없음 0개), MCP 도구(linux_web) 2개(본문에 없음 0개), MCP 도구(self_correction) 3개(본문에 없음 0개), MCP 도구(threat_intel) 2개(본문에 없음 0개).
