# E02 증거 무결성 검증

### E02.02 도구를 요청해 기준값 계산

**구현.** 이 방식은 `hash_file`과 `baseline_create`에 적용된다 [1][2].
증거를 읽는 다른 도구 가운데 `verify_package_integrity`와 `baseline_diff`도 해시를 계산하지만 기준값으로 남기지 않고 그 자리에서 대조에만 쓴다 [3][4].
서버가 증거 폴더에 처음 접근하거나 도구를 처음 부를 때 스스로 해시하는 경로도 없다.

`hash_file`은 받은 경로가 증거 폴더 안에 있고 존재하면 `md5sum`과 `sha256sum`을 차례로 실행해 두 출력을 응답에 싣는다 [1].
해시 범위는 받은 파일 하나다 [1].
도구 설명은 증거가 바뀌지 않았는지 확인하거나 위협 정보에서 해시를 조회할 때 쓰라고 적는다 [1].
응답 글의 앞 500자는 호출 기록 `audit.json` 항목의 `result_summary`에 남는다 [5].
서버는 이 값을 기준값으로 따로 보관하지 않고 어느 도구도 이 값을 다시 읽어 대조하지 않는다.

`baseline_create`는 증거 폴더 안의 파일시스템 루트를 받아 정해 둔 경로 목록에 있는 파일마다 64 KiB씩 읽어 SHA-256을 계산한다 [2][6].
경로 목록은 계정·sudoers·SSH 설정, cron, systemd unit, PAM, 커널 모듈 설정, 사용자 홈의 `authorized_keys`·셸 시작 파일 같은 파일이다 [7].
파일마다 크기·권한·UID·GID·수정 시각과 경로별로 정한 심각도를 함께 적어 JSON 파일로 쓴다 [6].
쓰는 곳은 `output_file`이 없으면 `FINDEVIL_LOGS_DIR`의 `baseline.json`이고 있으면 그 경로다 [2].
도구 설명은 이미 침해된 호스트가 아니라 깨끗한 상태에서 기준을 만들라고 적는다 [2].

`verify_package_integrity`는 증거 안 파일의 MD5를 계산해 증거 안의 dpkg `.md5sums` 기록과 대조한다 [3].
이 대조의 기준값은 증거에 이미 적힌 값이고 서버가 계산해 남긴 값이 아니어서 이 상세의 구현으로 세지 않았다.

**한계.** 환경변수 `FINDEVIL_FAULT_RATE`가 0보다 크면 `_run_tool`은 그 비율로 명령을 실행하지 않고 시간 제한으로 끝났다는 시험용 문구를 돌려준다 [8].
이때 `hash_file` 응답의 `## MD5`·`## SHA256` 아래에는 해시 대신 이 문구가 실리고 호출 기록에도 그대로 남는다 [1][8].
`md5sum`이나 `sha256sum`이 실패하면 `_run_tool`은 표준 오류를 덧붙인 출력을 돌려주고 `hash_file`은 이를 해시 자리에 실어 오류 응답으로 구별하지 않는다 [1][8].
`baseline_create`는 상태를 읽거나 해시하지 못한 파일을 기준에서 빼고 응답에 빠진 파일을 적지 않는다 [6].
`hash_file`은 `md5sum`과 `sha256sum`을 각각 120초 시간 제한으로 실행하고 `_run_tool`은 시간 제한 초과 예외를 처리하지 않는다 [1][9].
그래서 이 시간 안에 해시하지 못하는 큰 증거는 처리하지 않은 예외로 끝나 해시도 호출 기록도 남지 않는다 [9].
`output_file` 없이 `baseline_create`를 다시 부르면 기록 폴더의 `baseline.json`에 있던 기준값을 알림 없이 새 값으로 바꾼다 [10].

### E02.09 도구를 요청해 검증

**구현.** 이 방식은 `baseline_diff`에 적용된다 [4].
`baseline_diff`는 받은 파일시스템 루트에서 같은 경로 목록을 다시 훑어 SHA-256을 계산하고 기준 파일의 항목과 경로별로 대조한다 [4].
기준 파일 경로는 증거 폴더 안인지 검사하지 않는다 [4].
대조하는 값은 SHA-256·크기·권한·소유자이고 수정 시각만 다른 파일은 바뀐 것으로 보지 않는다 [11].
결과는 새로 생긴 파일, 없어진 파일, 바뀐 파일로 나뉜다 [11].
해시 도구가 낸 값을 다시 대조하는 도구는 없다.

**한계.** 서버는 기준 파일의 `_metadata.root_path`가 이번에 받은 `root_path`와 같은지 확인하지 않는다 [4][12].
다른 루트로 만든 기준과 대조해도 응답은 두 루트를 머리에 적은 뒤 차이를 그대로 변경으로 적는다 [12].
지금 상태에서 상태를 읽거나 해시하지 못한 파일은 현재 목록에서 빠진다 [6].
그래서 기준에 있던 그 파일은 "File present in baseline but missing now"인 없어진 파일로 표시된다 [11].

### E02.08 불일치 시 중단·경고

**구현.** 이 방식은 `baseline_diff`의 응답에 적용된다 [12].
차이가 있으면 응답 머리의 판정 칸에 심각도별 경고를 싣는다 [12].
`critical` 경로가 하나라도 바뀌면 "LIKELY COMPROMISE"를 적고 `warn` 경로만 바뀌면 정상 변경인지 검토하라는 경고를 적는다 [12].
심각도는 경로 목록에서 경로마다 정해 둔 값이다 [7].
판정 문구는 기준 뒤에 호스트가 바뀌었다는 침해 판정이고 증거 사본이 바뀌었다는 뜻으로 구별해 적지 않는다 [12].
호출 기록 항목의 `result_summary`에는 바뀐 항목 수와 그 가운데 `critical` 수가 남는다 [13].
차이가 있어도 서버는 다른 도구 호출을 막지 않는다.

@mcp.tool()
def hash_file(path: str) -> str:
    """Compute MD5 and SHA256 hashes of a file for evidence integrity verification.

    Use this to verify evidence hasn't been tampered with or to look up file hashes
    in threat intelligence databases.

    Args:
        path: Path to the file inside /evidence
    """
    try:
        validated = _validate_evidence_path(path)
    except ValueError as e:
        return f"Error: {e}"
    if not validated.exists():
        return f"File not found: {path}"

    md5 = _run_tool(["md5sum", str(validated)])
    sha256 = _run_tool(["sha256sum", str(validated)])

    result = f"## MD5\n{md5}\n## SHA256\n{sha256}"
    _audit("hash_file", {"path": path}, result)
    return result

```python
def _hash_file(path: Path, chunk_size: int = 65536) -> str:
    """Compute SHA256 streaming. Returns empty string on permission error."""
    h = hashlib.sha256()
    try:
        with path.open("rb") as f:
            while True:
                chunk = f.read(chunk_size)
                if not chunk:
                    break
                h.update(chunk)
    except (OSError, PermissionError):
        return ""
    return h.hexdigest()
```

def _stat_entry(root: Path, path: Path, severity: str) -> FileEntry | None:
    """Build a FileEntry from a real file. Returns None if unreadable."""
    try:
        st = path.stat()
    except (OSError, PermissionError):
        return None
    sha = _hash_file(path)
    if not sha:
        return None
    rel = str(path.relative_to(root))
    return FileEntry(
        path=rel,
        sha256=sha,
        size=st.st_size,
        mode=oct(st.st_mode)[-4:],
        uid=st.st_uid,
        gid=st.st_gid,
        mtime=datetime.fromtimestamp(st.st_mtime, tz=timezone.utc).isoformat(),
        severity=severity,
    )
