# E02 증거 무결성 검증

### E02.02 도구를 요청해 기준값 계산

**구현.** 이 방식은 `hash_file`에 적용된다 [1].
`hash_file`은 받은 경로가 증거 폴더 안에 있고 존재하면 `md5sum`과 `sha256sum`을 차례로 실행해 두 출력을 응답에 싣는다 [1].
해시 범위는 받은 파일 하나다 [1].
도구 설명은 증거가 바뀌지 않았는지 확인하거나 위협 정보에서 해시를 조회할 때 쓰라고 적는다 [1].
응답 글의 앞 500자는 호출 기록 `audit.json` 항목의 `result_summary`에 남는다 [2].
서버는 이 값을 기준값으로 따로 보관하지 않고 어느 도구도 이 값을 다시 읽어 대조하지 않는다.
서버가 증거 폴더에 처음 접근하거나 도구를 처음 부를 때 스스로 해시하는 경로도 없다.

증거를 읽는 다른 도구 가운데 해시를 계산하는 도구는 증거 무결성 검증에 해당하지 않는다.
`verify_package_integrity`는 증거 안 파일의 MD5를 계산해 증거 안의 dpkg `.md5sums` 기록과 대조한다 [3].
이 대조의 기준값은 증거에 이미 적힌 값이고 서버가 계산해 남긴 값이 아니다 [3].
`baseline_create`와 `baseline_diff`는 정해 둔 경로 목록의 파일마다 SHA-256과 상태 값을 묶은 기준선을 만들고 다른 상태와 비교해 바뀐 파일을 찾는 파일 무결성 감시 도구다 [4][5].
도구 설명은 기준선을 이미 침해된 호스트가 아니라 깨끗한 상태에서 만들라고 적고 `baseline_diff`는 critical 경로가 바뀌면 "LIKELY COMPROMISE"라는 침해 판정을 낸다 [4][6].

**한계.** 환경변수 `FINDEVIL_FAULT_RATE`가 0보다 크면 `_run_tool`은 그 비율로 명령을 실행하지 않고 시간 제한으로 끝났다는 시험용 문구를 돌려준다 [7].
이때 `hash_file` 응답의 `## MD5`·`## SHA256` 아래에는 해시 대신 이 문구가 실리고 호출 기록에도 그대로 남는다 [1][7].
`md5sum`이나 `sha256sum`이 실패하면 `_run_tool`은 표준 오류를 덧붙인 출력을 돌려주고 `hash_file`은 이를 해시 자리에 실어 오류 응답으로 구별하지 않는다 [1][7].
`hash_file`은 `md5sum`과 `sha256sum`을 각각 120초 시간 제한으로 실행하고 `_run_tool`은 시간 제한 초과 예외를 처리하지 않는다 [1][8].
그래서 이 시간 안에 해시하지 못하는 큰 증거는 처리하지 않은 예외로 끝나 해시도 호출 기록도 남지 않는다 [8].

@mcp.tool()
def hash_file(path: str) -> str:
    """Compute MD5 and SHA256 hashes of a file for evidence integrity verification.

    Use this to verify evidence hasn't been tampered with or to look up file hashes
    in threat intelligence databases.

    Args:
        path: Path to the file inside /evidence
    """
    try:
        validated = _validate_evidence_path(path)
    except ValueError as e:
        return f"Error: {e}"
    if not validated.exists():
        return f"File not found: {path}"

    md5 = _run_tool(["md5sum", str(validated)])
    sha256 = _run_tool(["sha256sum", str(validated)])

    result = f"## MD5\n{md5}\n## SHA256\n{sha256}"
    _audit("hash_file", {"path": path}, result)
    return result
```

_FAULT_RATE = float(os.environ.get("FINDEVIL_FAULT_RATE", "0"))
_fault_rng = None
if _FAULT_RATE > 0:
    import random as _random
    _fault_rng = _random.Random(int(os.environ.get("FINDEVIL_FAULT_SEED", "1")))


def _run_tool(cmd: list[str], timeout: int = 120) -> str:
    """Run a SIFT tool as a subprocess, capture output, never modify evidence."""
    # Fault injection: only active when FINDEVIL_FAULT_RATE > 0. Lets
    # tests/harness/fault_injection_test.py exercise graceful degradation.
    if _fault_rng is not None and _fault_rng.random() < _FAULT_RATE:
        return (
            f"[STDERR]: simulated fault — {cmd[0]} exited 124 (timeout). "
            "FINDEVIL_FAULT_RATE is set; this is a test harness injection, "
            "not a real tool failure."
        )
    result = subprocess.run(
        cmd,
        capture_output=True,
        text=True,
        timeout=timeout,
    )
    output = result.stdout
    if result.returncode != 0:
        output += f"\n[STDERR]: {result.stderr}"
    return output
```
