# T06 실행 환경정보 표시

### T06.03 파생물 manifest에 버전 표시

**구현.** 이 방식은 `baseline_create`가 쓰는 기준 파일에 적용된다 [1].
`baseline_create`는 기준 파일의 `_metadata`에 생성 시각, 대상 루트, 항목 수와 함께 `tool_version` 값 `findevil-fim-1`을 적는다 [1].
이 값은 추적할 파일 목록과 해시 방식을 정한 서버 안의 FIM 코드에 적어 둔 식별값이다 [1].

서버가 내는 다른 결과에는 도구나 참조 자료의 버전이 실리지 않는다.
호출 기록 항목은 시각, 도구 이름, 인자, 결과 요약 네 필드뿐이다 [2].
운영체제 명령을 실행하는 `_run_tool`은 표준 출력을 그대로 돌려주고 종료 코드가 0이 아닐 때만 표준 오류를 덧붙인다 [3].
Volatility 도구는 실행이 실패하면 `vol`의 표준 오류 앞부분을 응답 본문에 싣는다 [4].
이 글에 Volatility가 쓴 버전 줄이 있더라도 서버가 읽지 않고 본문째 넘긴다 [4].
IOC 목록 `threat_intel.json`의 `_metadata`에는 갱신 날짜 `last_updated`가 있지만 `bulk_ioc_lookup`의 응답은 항목마다 출처 `source`만 싣는다 [5][6].
서버는 FastMCP를 이름과 서버 지침만 주어 만들고 MCP Python SDK 1.27.2는 버전이 없으면 초기화 응답 `serverInfo.version`에 `mcp` 패키지의 버전을 넣는다 [7][8].
그래서 `serverInfo.version`은 `pyproject.toml`의 서버 버전 0.1.0이 아니라 `1.27.2`다 [9][10].
서버는 모델을 부르지 않는다.

**한계.** `tool_version`은 코드에 적어 둔 고정 문자열이고 서버 패키지 버전이나 git 커밋과 묶이지 않는다 [1][9].
`baseline_create`와 `baseline_diff`의 응답은 이 값을 싣지 않는다 [11].
`baseline_diff`는 기준 파일의 `_metadata`에서 생성 시각과 대상 루트만 꺼내 보여 주고 `tool_version`을 지금 코드의 값과 대조하지 않는다 [12].
