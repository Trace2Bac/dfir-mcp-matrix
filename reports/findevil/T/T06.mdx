# T06 실행 환경정보 표시

### 미구현

**판단.** 서버는 운영체제 명령과 Volatility 3으로 결과를 내지만 응답, 호출 기록, 파생물 어디에도 그 도구의 버전을 싣지 않는다.
호출 기록 항목은 시각, 도구 이름, 인자, 결과 요약 네 필드뿐이다 [1].
운영체제 명령을 실행하는 `_run_tool`은 표준 출력을 그대로 돌려주고 종료 코드가 0이 아닐 때만 표준 오류를 덧붙인다 [2].
Volatility 도구는 실행이 실패하면 `vol`의 표준 오류 앞부분을 응답 본문에 싣는다 [3].
이 글에 Volatility가 쓴 버전 줄이 있더라도 서버가 읽지 않고 본문째 넘긴다 [3].

참조 자료의 식별값도 결과에 싣지 않는다.
IOC 목록 `threat_intel.json`의 `_metadata`에는 갱신 날짜 `last_updated`가 있지만 `bulk_ioc_lookup`의 응답은 항목마다 출처 `source`만 싣는다 [4][5].
`baseline_create`가 쓰는 기준 파일의 `_metadata`에는 서버 코드에 정해 둔 상수 `tool_version`(`findevil-fim-1`)이 있다 [6].
이 상수는 서버의 FIM 코드가 정한 값이고 외부 도구나 참조 자료의 버전이 아니다 [6].
`baseline_create`와 `baseline_diff`의 응답은 이 값을 싣지 않는다 [7].

서버 자신의 버전도 싣지 않는다.
서버는 FastMCP를 이름과 서버 지침만 주어 만들고 MCP Python SDK 1.27.2는 버전이 없으면 초기화 응답 `serverInfo.version`에 `mcp` 패키지의 버전을 넣는다 [8][9].
그래서 `serverInfo.version`은 `pyproject.toml`의 서버 버전 0.1.0이 아니라 `1.27.2`다 [10][11].

서버는 모델을 부르지 않는다.
