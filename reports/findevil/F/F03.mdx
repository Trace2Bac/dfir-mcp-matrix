# F03 서버 안 모델 입력 구성

### 비적용

**판단.** findevil 서버는 처리 중에 모델을 부르지 않는다.
`pyproject.toml`이 정한 서버 의존성은 MCP SDK `mcp[cli]` 하나다 [1].
서버 모듈이 가져오는 것은 표준 라이브러리, FastMCP, 서버 자신의 모듈뿐이고 모델 API 클라이언트나 HTTP 클라이언트는 없다 [2].
서버 코드에는 FastMCP `Context`를 쓰는 곳이 없어 MCP sampling으로 클라이언트 모델에게 생성을 요청하는 호출도 없다 [2].
서버가 외부 프로그램을 실행하는 곳은 운영체제 명령을 실행하는 `_run_tool`과 Volatility를 실행하는 `_run_vol_plugin` 두 곳이다 [3].
`ai_signatures.py`에 적힌 `api.anthropic.com` 같은 모델 API 주소는 증거에서 찾는 정규식이다 [4].
모델은 같은 저장소의 `scripts/investigate.py`가 `claude -p`로 실행하는 클라이언트에서 쓰이고 그 호출은 서버가 도구를 처리하는 중의 호출이 아니다 [5].

```python
def _run_tool(cmd: list[str], timeout: int = 120) -> str:
    """Run a SIFT tool as a subprocess, capture output, never modify evidence."""
    # Fault injection: only active when FINDEVIL_FAULT_RATE > 0. Lets
    # tests/harness/fault_injection_test.py exercise graceful degradation.
    if _fault_rng is not None and _fault_rng.random() < _FAULT_RATE:
        return (
            f"[STDERR]: simulated fault — {cmd[0]} exited 124 (timeout). "
            "FINDEVIL_FAULT_RATE is set; this is a test harness injection, "
            "not a real tool failure."
        )
    result = subprocess.run(
        cmd,
        capture_output=True,
        text=True,
        timeout=timeout,
    )
    output = result.stdout
    if result.returncode != 0:
        output += f"\n[STDERR]: {result.stderr}"
    return output
```
