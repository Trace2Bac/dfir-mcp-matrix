# F04 발견사항·결론 기록 관리

### 미구현

**판단.** 서버에는 발견사항과 결론을 받는 도구가 있지만 받은 내용을 서버에 남기지 않는다.
`finalize_report`와 `find_contradictions`는 주장 `list`를 JSON 글로 받고 `assess_coverage`는 발견사항 JSON을 선택 인자로 받는다 [1][2][3].
`finalize_report`는 받은 주장을 검사해 받아들인 주장의 목록이나 거부 사유를 응답으로 돌려준다 [1].
`finalize_report`의 호출 기록에는 주장 수와 거부·모순 건수만 남는다 [1].
`find_contradictions`의 호출 기록에는 주장 수와 모순 건수만, `assess_coverage`의 호출 기록에는 발견사항을 넘겼는지만 남는다 [2][3].
`verify_finding`의 호출 기록에는 주장 유형, 검증 인자, 판정이 남는다 [4].
이것은 검증 호출의 기록이고 이 도구는 주장 문장, 확신도, 인용을 받지 않는다 [4].
서버에는 발견사항, 결론, 가설을 저장하거나 다시 읽는 도구가 없고 발견사항을 모아 두는 파일이나 DB도 없다.
서버 지침은 모델에게 발견사항을 구조화한 주장으로 모아 `finalize_report`에 넘기라고 안내하므로 발견사항은 클라이언트 모델의 문맥에 남는다 [5].
