# P01 분석 방법 적합성 확인

### P01.01 이름·확장자 판별

**구현.** 증거 폴더 전체의 자료 종류를 정하는 곳은 `assess_coverage`가 부르는 목록 함수 `_inventory_evidence` 하나다 [1].
`_inventory_evidence`는 `FINDEVIL_EVIDENCE_DIR` 아래 경로를 모두 모아 경로마다 `_match_artifact`로 자료 종류를 정한다 [1][2].
`_match_artifact`는 파일 이름이 `auth.log`·`secure`이거나 `auth.log`로 시작하면 인증 로그로 본다 [2].
이름에 `journal`이 있거나 이름이 `.journal`로 끝나면 journal 내보내기로 본다 [2].
이름이 `access.log`로 시작하거나 상위 폴더 이름이 `nginx`·`apache2`·`httpd`이면 웹 서버 접근 로그로 본다 [2].
`authorized_keys`·`sshd_config`·`sudoers`와 `sudoers.d` 아래 파일, 셸 기록 이름 4개, `dpkg.log`와 `apt/history.log`도 이름으로 정한다 [2].
이름이 `daemon.json`·`config.v2.json`·`hostconfig.json`이거나 경로에 `docker`·`containerd`가 있으면 컨테이너 자료로 본다 [2].
확장자가 `.lime`·`.mem`·`.raw`·`.vmem`·`.dump`이면 메모리 이미지로 본다 [2].
`_ARTIFACT_CHECKS`는 자료 종류마다 그 종류를 다룰 도구 묶음과 실행할 작업 문구를 정해 두고 판별한 종류를 이 표와 맞춘다 [3].
판별한 종류와 경로는 `assess_coverage` 응답의 자료 범위 표와 남은 작업 문구에 실린다 [4].

도구 안에서 고정 경로와 이름으로 처리 경로를 정하는 곳도 있다.
`build_timeline`은 받은 폴더 바로 아래의 `auth.log`·`secure.log`·`secure`, `journal.jsonl`·`journal.json`, `access.log`·`access_log`를 찾아 이름마다 정한 파서로 읽는다 [5].
`fs_subpath` 아래에서는 `var/log/apt/history.log`, `var/log/dpkg.log`, `root/.pip/pip.log`, `root`와 `home/*`의 `.bash_history`를 같은 방식으로 찾는다 [5].
`analyze_package_logs`는 파일 경로로 apt·dpkg·yum·pip 파서를 고른다 [6].
`find_webshells`는 정해 둔 웹 루트 아래에서 확장자가 `_EXEC_EXTENSIONS`에 있는 파일만 검사하고 확장자로 `php`·`jsp`·`asp`·`cgi_perl` 분류를 정한다 [7].
`analyze_container_artifacts`는 `config.v2.json`, `daemon.json`, `docker-compose*.y*ml`, Kubernetes 폴더 아래의 `*.yaml`·`*.yml`을 이름으로 골라 파일마다 정한 검사기를 쓴다 [8].
`find_persistence`는 systemd unit을 `.service`·`.timer`·`.socket`·`.path` 접미사로, modprobe 설정을 `.conf`로, udev 규칙을 `.rules`로 고른다 [9].

**한계.** `_match_artifact`는 확장자가 `.raw`·`.dump`인 파일을 모두 메모리 이미지로 본다 [2].
그래서 `.raw` 디스크 이미지도 메모리 이미지로 분류되고 `assess_coverage`는 `analyze_memory_summary`와 Volatility 3 도구를 실행하라고 권한다 [2][3].
이름이 `.journal`로 끝나는 이진 형식 journal 파일도 journal 내보내기로 분류되어 `analyze_journal`을 권하지만 `analyze_journal`은 JSON으로 읽히는 줄만 처리한다 [2][3][10].
`_inventory_evidence`는 경로를 200,000개까지만 모으고 그 뒤 경로는 판별하지 않는다 [1].
컨테이너 자료 판별은 파일 이름 말고도 증거 폴더의 절대 경로까지 포함한 전체 경로 문자열에서 `docker`·`containerd`를 찾는다 [2][1].
그래서 증거 폴더의 경로에 `docker`가 들어 있으면 그 아래 모든 파일이 컨테이너 자료로 분류된다 [2][1].
`hostconfig.json`은 컨테이너 자료로 분류되지만 권하는 `analyze_container_artifacts`는 이 파일을 읽지 않는다 [2][8].
이름이 `auth.log`로 시작하면 `auth.log.2.gz` 같은 압축 회전 로그도 인증 로그로 분류된다 [2].
인증 도구는 이 파일을 글로 읽어 인식한 사건이 없다는 응답을 내고 호출 기록을 남긴다 [11].
`.zsh_history`도 셸 기록으로 분류되어 `analyze_bash_history`를 권한다 [2][3].
`analyze_bash_history`의 파서는 `#`와 epoch 초로 된 줄만 시각으로 읽고 나머지 줄은 모두 명령으로 센다 [12].
`build_timeline`의 설명은 증거 루트 아래 어디에 있든 찾는다고 적지만 코드는 위의 고정 경로만 본다 [5][13].
`analyze_package_logs`의 설명은 `/var/log/apt/term.log`를 다룬다고 적지만 코드는 apt 기록으로 `history.log`와 `history.log.1`만 읽는다 [6][14].

### P01.02 메타데이터 조회

**구현.** `_inventory_evidence`는 폴더 안에 `etc` 폴더가 있으면 그 폴더를 파일 시스템 루트로 본다 [15][1].
파일 시스템 루트로 본 폴더는 지속성 조사 대상으로 분류되고 `_ARTIFACT_CHECKS`에서 `find_persistence`를 실행하라는 작업과 맞춰진다 [3].
서버가 증거의 OS나 파티션을 판별하는 코드는 없다.

**한계.** `_inventory_evidence`가 훑는 경로에는 증거 폴더 자신이 포함되지 않는다 [1].
그래서 `FINDEVIL_EVIDENCE_DIR`이 파일 시스템 루트를 가리키면 그 루트는 지속성 조사 대상으로 분류되지 않고 `find_persistence`를 권하지 않는다 [1][15].
`etc` 폴더를 가진 폴더는 `usr/local`처럼 파일 시스템 루트 안의 하위 폴더여도 파일 시스템 루트로 분류된다 [15].

### P01.03 내용·헤더 검사

**구현.** `find_ai_signatures`의 스크립트 검사는 확장자가 없거나 `.sh`·`.bash`이거나 이름이 `run`·`main`인 파일의 앞 32,768바이트를 읽는다 [16].
내용이 `#!`로 시작하는 파일만 스크립트로 보고 작성 습관 패턴을 맞춘다 [16].

서버가 바이트를 읽는 다른 곳은 판별 자체가 분석 결과인 도구다.
`find_persistence`는 `dev/shm` 아래 파일의 앞 4바이트로 ELF나 스크립트를 가려 그 파일을 발견사항으로 싣는다 [17].
`file_info`는 `file -b`의 출력을 그대로 돌려주고 서버는 그 결과로 처리 경로를 정하지 않는다 [18].

메모리 도구는 받은 경로가 파일인지만 보고 메모리 이미지인지 확인하지 않는다 [19].
Volatility 3가 실패하면 서버는 표준 오류의 문구로 심볼 문제인지 정하고 `banners.Banners`로 읽은 커널 배너를 심볼 안내와 함께 돌려준다 [20][21].
서버는 그 배너를 가진 심볼과 대조하지 않는다 [21].
고른 방법을 판별한 형식이나 OS와 대조하는 코드는 없다.

```python
def _match_artifact(path: Path, kind: str) -> bool:
    name = path.name.lower()
    parent = path.parent.name.lower()
    full = str(path).lower()
    if kind == "auth":
        return name in {"auth.log", "secure"} or name.startswith("auth.log")
    if kind == "journal":
        return name.endswith(".journal") or "journal" in name
    if kind == "weblog":
        return name.startswith("access.log") or parent in {"nginx", "apache2", "httpd"}
    if kind == "authkeys":
        return name == "authorized_keys"
    if kind == "sshdconfig":
        return name == "sshd_config"
    if kind == "sudoers":
        return name == "sudoers" or parent == "sudoers.d"
    if kind == "history":
        return name in {".bash_history", "bash_history", ".zsh_history", "zsh_history"}
    if kind == "pkglog":
        return name == "dpkg.log" or full.endswith("apt/history.log")
    if kind == "container":
        return name in {"daemon.json", "config.v2.json", "hostconfig.json"} or (
            "docker" in full or "containerd" in full
        )
    if kind == "memory":
        return name.endswith((".lime", ".mem", ".raw", ".vmem", ".dump", ".lime.raw"))
    return False
```

```python
_TS_RE = re.compile(r"^#(\d{9,11})$")


def parse_history(content: str) -> list[HistoryEntry]:
    """Parse both plain and extended (HISTTIMEFORMAT) shell histories."""
    entries: list[HistoryEntry] = []
    pending_ts: str | None = None

    for lineno, raw in enumerate(content.splitlines(), 1):
        if not raw.strip():
            continue
        m = _TS_RE.match(raw.strip())
        if m:
            try:
                pending_ts = datetime.fromtimestamp(
                    int(m.group(1)), tz=timezone.utc
                ).isoformat()
            except (ValueError, OSError):
                pending_ts = None
            continue
        entries.append(HistoryEntry(line_number=lineno, command=raw, timestamp=pending_ts))
        pending_ts = None

    return entries
```

```python
def _identify_kernel(dump: Path) -> tuple[str, list[str]]:
    """Run banners.Banners and return (best_banner, all_banners).

    The kernel banner determines which symbol table Volatility needs.
    Returning the banner gives the agent something to act on if symbols
    are missing.
    """
    res = _run_vol_plugin(dump, "banners.Banners", json_output=True)
    banners: list[str] = []
    for row in res.rows:
        b = row.get("Banner") or row.get("banner")
        if isinstance(b, str) and b.strip():
            banners.append(b.strip())
    # Prefer the longest Linux banner (kernel header banner is usually verbose)
    linux_banners = [b for b in banners if "Linux version" in b]
    best = max(linux_banners, key=len) if linux_banners else (banners[0] if banners else "")
    return best, banners
```
