# P05 사건 자료 정리

### P05.02 사용자 명령으로 삭제·초기화

**구현.** 이 방식은 사용자 CLI `scripts/capture_example_run.py`에 적용된다 [1].
이 CLI는 실행할 때 기록 폴더의 `audit.json`을 지운다 [1].
기록 폴더 인자 `--logs-dir`의 기본값은 저장소의 `logs/`이고 저장소 루트에서 실행한 서버의 기본 기록 폴더와 같다 [2][3].
이 CLI는 예시 시나리오의 도구 함수를 직접 불러 새 `audit.json`을 만들고 그 파일을 `--output` 경로로 복사한다 [4].
지우기 전에 앞 호출 기록을 옮기거나 복사하지 않고 지운 사실도 남기지 않는다 [1].

서버에는 사건 자료를 지우거나 초기화하는 MCP 도구가 없다.
서버가 종료나 작업 완료 때 사건 자료를 스스로 지우는 코드도 없다.

### 근거

[1] 사용자 CLI가 기록 폴더의 `audit.json`을 지운다.

```python
def _setup_env(scenario_dir: Path, logs_dir: Path) -> None:
    """Point the findevil server at the scenario's evidence and a temp log dir."""
    os.environ["FINDEVIL_EVIDENCE_DIR"] = str(scenario_dir.parent.resolve())
    os.environ["FINDEVIL_LOGS_DIR"] = str(logs_dir.resolve())
    logs_dir.mkdir(parents=True, exist_ok=True)
    # Wipe any pre-existing audit.json so the captured trace is just this run.
    audit_path = logs_dir / "audit.json"
    if audit_path.exists():
        audit_path.unlink()
```
