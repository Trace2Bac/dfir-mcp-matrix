# P06 조사 상태 유지

### P06.02 프로세스 메모리에만 보관

**구현.** 서버 프로세스 메모리에 두는 조사 상태는 위협 정보 캐시 하나다 [1].
`_load_cache`는 처음 조회할 때 `data/threat_intel.json`을 읽고 `lru_cache`로 프로세스가 끝날 때까지 그 내용을 다시 쓴다 [1].
파일을 읽지 못하면 오류 문구와 빈 조회 표 셋을 담은 `dict`를 같은 방식으로 남겨 프로세스가 끝날 때까지 모든 조회가 캐시에 없다고 답한다 [1].
이 캐시에는 유효 시간이나 개수 한도가 없다 [1].
열린 사건이나 작업 목록 같은 상태는 없고 `auth_summary` 같은 분석 도구는 호출마다 증거 파일을 다시 읽어 결과를 만든다 [2].

### P06.03 조사 상태를 파일·DB에 저장

**구현.** 서버는 도구 호출마다 시각, 도구 이름, 인자, 결과 요약 500자를 JSON 한 줄로 기록 폴더의 `audit.json`에 덧붙인다 [3].
기록 처리기는 서버 모듈을 불러올 때 한 번 만들고 기존 파일에 이어 쓴다 [3].
`get_audit_trail`은 자기 호출을 `audit.json` 대신 `get_audit_trail_invocations.jsonl`에 덧붙인다 [4].
`baseline_create`는 기준선을 파일로 쓰고 `baseline_diff`는 받은 경로의 기준선 파일을 다시 읽는다 [5].
`finalize_report`·`find_contradictions`·`assess_coverage`가 받은 발견사항과 claim의 본문은 파일에 쓰지 않고 `assess_coverage`의 호출 기록에는 `findings_json`을 받았는지만 남는다 [6].
`verify_finding`은 claim 유형, 해석한 인자 객체, 판정을 호출 기록에 남긴다 [7].
사용자 CLI `scripts/investigate.py`는 반복마다 남은 작업 보고서와 `claude` 실행 정보를 `logs/progress/<이름>/iteration-NN.json`에 쓴다 [8].

**한계.** `audit.json`은 조사마다 나뉘지 않고 서버를 다시 시작하거나 다른 증거를 조사해도 같은 파일에 이어 쓴다 [3].
서버가 호출 기록 파일에 쓰지 못해도 도구는 정상 응답을 돌려주고 이 사실을 알리지 않는다 [9][10].
`baseline_create`는 증거 폴더 밖이면 어느 경로에도 기준선을 쓰므로 `output_file`로 `audit.json`을 주면 그때까지의 호출 기록이 기준선 JSON으로 바뀐다 [11].

### P06.04 재시작 뒤 자동 복구

**구현.** `assess_coverage`는 호출될 때마다 `audit.json` 전체를 다시 읽어 실행한 도구 이름과 `verify_finding` 호출 수를 정한다 [12].
`get_audit_trail`도 호출마다 같은 파일을 다시 읽는다 [13].
그래서 서버를 다시 시작해도 모델이 따로 복구하지 않고 앞 프로세스의 호출을 수행 기록으로 이어 쓴다 [12].
`finalize_report`·`assess_coverage`에 넘긴 발견사항과 claim은 서버에 남지 않으므로 모델이 `findings_json`·`claims_json`으로 다시 보내야 한다 [6].

**한계.** 다시 읽은 호출 기록은 조사를 구별하지 않아 앞선 다른 조사의 호출도 이번 조사의 수행으로 처리한다 [12][3].
JSON으로 읽히지 않는 줄은 알림 없이 건너뛴다 [12].

```python
@lru_cache(maxsize=1)
def _load_cache() -> dict[str, Any]:
    """Load the bundled IOC cache once."""
    try:
        return json.loads(_DATA_FILE.read_text())
    except (OSError, json.JSONDecodeError) as e:
        # Fail closed — an unusable cache is still usable (all lookups miss)
        return {"_error": str(e), "ips": {}, "hashes": {}, "domains": {}}
```

```python
def _audited_tool_calls() -> list[dict]:
    """Return every audit.json entry as a dict (best-effort, never raises)."""
    audit_path = LOGS_DIR / "audit.json"
    if not audit_path.is_file():
        return []
    try:
        raw = audit_path.read_text(errors="replace").splitlines()
    except OSError:
        return []
    out: list[dict] = []
    for line in raw:
        line = line.strip()
        if not line:
            continue
        try:
            out.append(json.loads(line))
        except json.JSONDecodeError:
            continue
    return out


def _called_tool_names(entries: list[dict]) -> set[str]:
    return {e.get("tool", "") for e in entries}
```
