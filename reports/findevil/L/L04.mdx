# L04 기록 위변조 방지

### 미구현

**판단.** 호출 기록 `audit.json`의 항목은 `timestamp`·`tool`·`params`·`result_summary`뿐이고 앞 항목과 잇는 해시도, 서명도, 일련번호도 없다 [1].
서버는 `logging.FileHandler`의 기본 모드로 파일을 덧붙여 쓸 뿐 파일 권한이나 추가 전용 속성을 정하지 않는다 [1].
`get_audit_trail`은 이 파일을 줄마다 JSON으로 읽고 해석하지 못한 줄은 건너뛰며 건너뛴 줄 수를 응답에 적지 않는다 [2].
`assess_coverage`도 같은 방식으로 읽은 항목의 도구 이름으로 살펴본 아티팩트와 `verify_finding` 호출 수를 정한다 [3][4].
그래서 파일에 덧붙이거나 지운 줄은 출처를 묻지 않고 이 두 도구의 결과에 반영된다.
JSON으로 해석되지만 객체가 아닌 줄(숫자 하나 등)은 건너뛰지 않고 항목 목록에 넣는다 [5].
이런 줄이 하나라도 있으면 두 도구는 항목에서 `get`을 부르다 `AttributeError`로 끝나 오류 결과를 돌려준다 [5].
기록을 다시 계산해 대조하는 도구나 명령도 없다.
그래서 기록의 수정, 삭제, 순서 변경을 막거나 알아보는 장치가 없다.

모델 도구 `baseline_create`의 `output_file`이나 사용자 CLI `scripts/capture_example_run.py`로 호출 기록 파일을 통째로 바꾸거나 지워도 이를 알아보는 장치가 없다 [6][7][8].
`baseline_create`로 호출 기록 파일을 바꾼 뒤에도 기록 처리기는 서버 모듈을 불러올 때 연 파일 끝에 다음 항목을 이어 쓰므로 그 뒤의 호출 기록은 기준선 JSON 뒤에 남는다 [1].
`get_audit_trail`과 `assess_coverage`는 JSON으로 읽히지 않는 줄을 건너뛰므로 바뀐 앞부분의 호출은 두 도구의 결과에서 빠진다 [2][3].
`baseline_create`의 호출 기록 항목에는 쓴 경로와 항목 수가 남고 기존 파일을 바꿨다는 사실은 남지 않는다 [9].

# by tool modules). Without this check, the handler is registered twice and
# every audit entry gets written twice.
if not audit_logger.handlers:
    _handler = logging.FileHandler(LOGS_DIR / "audit.json")
    _handler.setFormatter(logging.Formatter("%(message)s"))
    audit_logger.addHandler(_handler)


def _audit(tool: str, params: dict, result_summary: str) -> None:
    """Write a structured audit log entry for every tool invocation."""
    entry = {
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "tool": tool,
        "params": params,
        "result_summary": result_summary[:500],
    }
    audit_logger.info(json.dumps(entry))

def _audited_tool_calls() -> list[dict]:
    """Return every audit.json entry as a dict (best-effort, never raises)."""
    audit_path = LOGS_DIR / "audit.json"
    if not audit_path.is_file():
        return []
    try:
        raw = audit_path.read_text(errors="replace").splitlines()
    except OSError:
        return []
    out: list[dict] = []
    for line in raw:
        line = line.strip()
        if not line:
            continue
        try:
            out.append(json.loads(line))
        except json.JSONDecodeError:
            continue
    return out
```

def _setup_env(scenario_dir: Path, logs_dir: Path) -> None:
    """Point the findevil server at the scenario's evidence and a temp log dir."""
    os.environ["FINDEVIL_EVIDENCE_DIR"] = str(scenario_dir.parent.resolve())
    os.environ["FINDEVIL_LOGS_DIR"] = str(logs_dir.resolve())
    logs_dir.mkdir(parents=True, exist_ok=True)
    # Wipe any pre-existing audit.json so the captured trace is just this run.
    audit_path = logs_dir / "audit.json"
    if audit_path.exists():
        audit_path.unlink()
```
