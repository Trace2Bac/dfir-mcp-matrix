# I03 외부 전송 범위 구성

### 비적용

**판단.** 서버 코드는 외부 서비스에 연결하지 않으므로 조사 자료를 보내지 않는다 [1].
평판 조회 도구 `bulk_ioc_lookup`은 글에서 뽑은 IP 주소·도메인·해시를 패키지에 함께 담긴 `data/threat_intel.json`의 값과 대조할 뿐 밖으로 보내지 않는다 [2].

사용자 CLI `scripts/investigate.py`는 `claude` CLI를 실행해 조사를 맡긴다 [3].
그 CLI의 모델이 받는 서버 도구 응답에는 증거에서 읽은 기록 줄, 명령, 파일 내용 일부가 들어 있다.
모델 API로 무엇을 보내는지는 `claude` CLI가 정한다 [3].
저장소 코드는 보내기 전에 값을 고르거나 가리지 않는다 [3].

[2] IP 주소 조회는 패키지 안의 자료에서 찾는다.

```python
def _lookup_ip(ip: str) -> IOCVerdict:
    cache = _load_cache()
    entry = (cache.get("ips") or {}).get(ip)
    if not entry:
        return IOCVerdict(False, "unknown", [], "n/a", "-", "not in local IOC cache")
    return IOCVerdict(
        known=True,
        category=entry.get("category", "unknown"),
        tags=list(entry.get("tags", [])),
        confidence=entry.get("confidence", "n/a"),
        source=entry.get("source", "-"),
        notes=entry.get("notes", ""),
    )
```
