# I01 외부 연동 대상 관리

### 비적용

**판단.** 서버 코드는 스스로 외부에 연결하지 않는다.
`src/findevil/`의 모듈은 표준 라이브러리와 `mcp`만 불러온다 [1].
이 모듈들은 네트워크 모듈(`socket`·`urllib.request`·`http`)을 불러오지 않는다 [1].
`linux_web.py`가 불러오는 `urllib.parse`는 접근 기록의 URL 인코딩을 푸는 데만 쓴다 [1].
서버는 stdio로 MCP 요청을 받는다 [2].
서버는 운영체제 명령과 Volatility 3을 자식 프로세스로 실행하고 호출 기록 파일을 쓴다 [2][3].

평판 조회 도구 `bulk_ioc_lookup`은 외부 서비스에 묻지 않고 패키지에 함께 담긴 `data/threat_intel.json`만 읽어 대조한다 [4].
서버는 처리 중에 모델 API를 부르지 않는다 [1].

외부 연결은 서버 밖의 사용자 CLI에 있다.
`scripts/investigate.py`는 `claude` CLI를 `-p` 모드로 실행한다 [5].
모델 API 접속은 그 CLI가 한다 [5].

@lru_cache(maxsize=1)
def _load_cache() -> dict[str, Any]:
    """Load the bundled IOC cache once."""
    try:
        return json.loads(_DATA_FILE.read_text())
    except (OSError, json.JSONDecodeError) as e:
        # Fail closed — an unusable cache is still usable (all lookups miss)
        return {"_error": str(e), "ips": {}, "hashes": {}, "domains": {}}
