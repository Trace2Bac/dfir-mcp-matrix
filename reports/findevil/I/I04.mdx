# I04 서버 자격증명 처리

### 비적용

**판단.** 서버 코드는 자격증명이 필요한 외부 연동을 하지 않는다 [1].
서버 코드가 읽는 환경변수는 증거 폴더 `FINDEVIL_EVIDENCE_DIR`, 기록 폴더 `FINDEVIL_LOGS_DIR`, 시험용 오류 주입 값 `FINDEVIL_FAULT_RATE`·`FINDEVIL_FAULT_SEED`, Volatility 실행 파일 `FINDEVIL_VOL`뿐이다 [2].
Volatility 3 2.28.0 패키지 코드가 읽는 환경변수는 캐시와 설정 파일의 위치를 정하는 `XDG_CACHE_HOME`·`APPDATA`뿐이다 [3].

사용자 CLI `scripts/investigate.py`는 `claude` CLI를 실행한다 [4].
모델 API 자격증명은 그 CLI가 스스로 다룬다 [4].
이 스크립트는 자격증명을 읽거나 인자로 넘기지 않는다 [4].
