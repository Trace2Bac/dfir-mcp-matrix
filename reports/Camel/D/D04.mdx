# D04 출력 경로 제한

### D04.01 서버가 출력 위치 결정

**구현.** 서버가 출력 위치를 정하는 방식은 사건 호출 기록 파일과 워크플로 세 곳의 기본 출력 경로에 있다.
사건 호출 기록 파일 `audit-<caseId>.clef`에는 호출 기록과 함께 `auditFinding`이 남기는 발견사항 항목이 들어간다 [1].
이 파일의 폴더는 서버를 시작할 때 정해지며 `--case-dir`이 있으면 그 사건 폴더의 `logs/`, 없으면 실행 파일 폴더의 `logs/`다 [2].
파일 이름은 `SetCaseId`로 받은 사건 ID를 `SanitizeCaseId`로 고친 값을 `audit-`와 `.clef` 사이에 넣어 정한다 [3].
`SanitizeCaseId`는 사건 ID에서 `Path.GetInvalidFileNameChars`가 돌려주는 문자와 공백을 `_`로 바꾼다 [3].
`GenerateFilesystemTimelineAsync`는 `bodyfilePath` 인자 없이 불리면 `/tmp/camel_bodyfile_{offset}.txt`(오프셋이 없으면 0) 경로에 fls bodyfile을 만든다 [4][5].
메서드는 이 파일을 지우지 않고 결과의 `BodyfilePath`에 그 경로를 담아 돌려준다 [4].
`ListDeletedFilesAsync`는 경로 인자를 받지 않고 `/tmp/camel_deleted_<GUID>.body`에 bodyfile을 만든다 [6].
`RunIdsAsync`는 `outDir` 인자가 없으면 `/tmp/camel_suricata_<GUID>` 폴더를 Suricata 출력 폴더로 쓴다 [7].

다른 파생물 메서드는 목적지 경로를 `Execute` 스크립트가 넘긴 인자로 받아 그대로 명령에 넣는다 [8].
목적지를 허용 폴더와 대조하거나 경로 구분자·`..`·링크를 검사하는 코드가 없다 [8].
목적지에 거는 검사는 `FailIfEvidenceSpoliationRisk`가 그 경로가 등록한 원본 증거 파일이나 그 파일이 있는 폴더와 같은지 보는 것 하나다 [9].

**한계.** `GenerateFilesystemTimelineAsync`에 `bodyfilePath`를 넘기거나 `RunIdsAsync`에 `outDir`를 넘기면 그 값을 검사 없이 목적지로 쓴다 [4][5][7].
사건 ID에 들어 있는 `/` 같은 경로 구분자가 파일 이름에서 바뀌는지는 `Path.GetInvalidFileNameChars`가 서버를 실행한 운영체제에서 돌려주는 문자에 달려 있고 그 소스는 확인하지 못했다 [3].

```csharp
    private static string SanitizeCaseId(string caseId)
    {
        if (string.IsNullOrWhiteSpace(caseId)) return "unknown";
        var invalid = System.IO.Path.GetInvalidFileNameChars();
        var chars = caseId.Trim().Select(c => Array.IndexOf(invalid, c) >= 0 || c == ' ' ? '_' : c).ToArray();
        return new string(chars);
    }
```

```csharp
    public async Task<WorkflowResult<FilesystemTimeline>> GenerateFilesystemTimelineAsync(
        string imageFile, int? offset = null, string timezone = "UTC", string? bodyfilePath = null)
    {
        bodyfilePath ??= $"/tmp/camel_bodyfile_{offset ?? 0}.txt";
        using var _audit = AuditScope();
        using var op = Begin("Generating filesystem timeline for {0} (offset {1})", imageFile, offset?.ToString() ?? "none");

        // Confirm a filesystem actually lives at the offset before walking it (avoids an empty/garbage timeline).
        var fs = await DiskAnalysis.FsStatAsync(imageFile, offset);
        if (fs is null || string.IsNullOrWhiteSpace(fs.FileSystemType))
            return WorkflowResult<FilesystemTimeline>.Failure(
                $"No valid filesystem found at sector offset {offset} of '{imageFile}'. " +
                $"Check the partition table (mmls) for a correct partition start sector.");

        // Walk the filesystem into a mactime bodyfile, then sort it into a timeline.
        if (!await DiskAnalysis.FlsBodyfileAsync(imageFile, bodyfilePath, offset))
            return WorkflowResult<FilesystemTimeline>.Failure(
                $"Failed to generate the fls bodyfile for '{imageFile}' (offset {offset}).");

        var entries = await DiskAnalysis.MactimeAsync(bodyfilePath, timezone);
        if (entries is null)
            return WorkflowResult<FilesystemTimeline>.Failure($"mactime failed to process bodyfile '{bodyfilePath}'.");

        op.Complete();
        return WorkflowResult<FilesystemTimeline>.Success(
            new FilesystemTimeline(bodyfilePath, entries),
            $"Generated {entries.Length} timeline entries for the {fs.FileSystemType} filesystem (offset {offset}).");
    }
```

```csharp
    public void FailIfEvidenceSpoliationRisk(string targetPath)
    {
        var evidence = FindEvidenceForPath(targetPath);
        if (evidence is not null) throw new EvidenceSpoliationRiskException(evidence, targetPath);
    }

    // The registered evidence that <paramref name="path"/> would put at risk (the evidence file itself or its
    // containing directory), or null if the path is not protected. Shared by the check and the guard so both
    // apply identical normalization and case-sensitivity rules.
    private EvidenceInfo? FindEvidenceForPath(string path)
    {
        if (string.IsNullOrWhiteSpace(path) || CaseEvidence.Length == 0) return null;
        var comparison = IsWindows ? StringComparison.OrdinalIgnoreCase : StringComparison.Ordinal;
        var normalized = NormalizeEvidencePath(path);
        return CaseEvidence.FirstOrDefault(e =>
        {
            var file = NormalizeEvidencePath(e.FilePath);
            return file.Equals(normalized, comparison) || GetEvidenceDirectory(file).Equals(normalized, comparison);
        });
    }
```
