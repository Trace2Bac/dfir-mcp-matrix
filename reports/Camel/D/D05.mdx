# D05 파생물 저장 실패 처리

### D05.01 오류·부분 완료 표시

**구현.** 파일을 만드는 SDK 메서드는 도구 명령이 0이 아닌 종료 코드로 끝나면 `false`나 `null`을 돌려준다 [1][2].
로컬 실행 환경은 종료 코드가 0이 아니면 명령 결과를 `Error` 상태로 만들고 툴킷 공통 함수는 그 결과에서 `null`을 돌려준다 [1].
SSH 실행 환경도 원격 명령의 종료 코드가 0이 아니면 `Error` 상태로 만든다 [3].
워크플로 메서드는 그 값을 받아 실패 이유를 담은 `WorkflowResult.Failure`를 돌려준다 [4].
원본 증거 경로를 목적지로 주면 `EvidenceSpoliationRiskException`이 나고 스크립트가 처리하지 않으면 `Execute`가 `IsError` 응답으로 끝난다 [5][6].
`Execute` 응답에는 스크립트가 `log`·`error`로 낸 줄만 실리므로 SDK가 돌려준 실패가 응답에 드러나는지는 스크립트가 정한다 [6].
`TimelinerBodyfileAsync`는 쓴 뒤 `test -s`로 파일이 비어 있지 않은지만 보고 이번 실행이 쓴 파일인지는 가리지 않는다 [7].

**한계.** 실패한 명령이 쓰다 만 파일은 지우지 않는다 [2].
셸 `>`로 표준 출력을 쓰는 `IcatAsync` 같은 메서드는 도구가 중간에 실패해도 목적지 파일이 이미 만들어져 남는다 [2].
`Log2TimelineAsync`가 실패하며 남긴 저장 파일도 그 자리에 있고 같은 경로로 다시 부르면 그 파일에 이어 쓴다 [8].
그 저장 파일을 읽는 타임라인 워크플로는 사건 수가 0이 아닌지만 보고 앞 실행이 끝까지 됐는지는 보지 않는다 [9].

### D05.03 알림 없이 계속

**구현.** Volatility 덤프 메서드는 플러그인이 `File output` 칸에 `Error`를 적은 행을 빼고 나머지 파일만 돌려준다 [10].
쓰지 못한 덤프가 있어도 메서드는 성공 목록을 돌려주고 빠진 항목을 알리지 않는다 [10].
`FindAnomalousMemoryIndicatorsAsync`는 PID마다 덤프 메서드가 `null`을 돌려주면 건너뛰고 문자열 추출에 실패한 파일도 빼고 성공으로 끝난다 [11][12].
응답 메시지에는 덤프한 개수와 대상 프로세스 수만 실린다 [12].
`camel` CLI의 `bake-report`도 데이터 파일 쓰기 예외를 표준 오류에만 적고 계속하지만 CLI 동작이라 서버 구현으로 세지 않는다 [13].

    static async Task<string[]> DumpEachAsync(string imageFile, int[] pids, string dir,
        Func<string, int, string, Task<string[]?>> dump)
    {
        var paths = new List<string>();
        foreach (var pid in pids)
            if (await dump(imageFile, pid, dir) is { } files)
                paths.AddRange(files);
        return paths.ToArray();
    }

    // Extracts ASCII and Unicode strings (min 8 chars) from each dumped memory image into stringsDir,
    // returning the per-process strings files produced (named strings_<dump>_ascii.txt / _unicode.txt).
    async Task<string[]> ExtractStringsFromDumpsAsync(string[] memoryDumps, string stringsDir)
    {
        var outputs = new List<string>();
        foreach (var dump in memoryDumps)
        {
            var stem = System.IO.Path.GetFileNameWithoutExtension(dump);
            var ascii = $"{stringsDir.TrimEnd('/')}/strings_{stem}_ascii.txt";
            var unicode = $"{stringsDir.TrimEnd('/')}/strings_{stem}_unicode.txt";
            if (await MemoryAnalysis.ExtractStringsAsync(dump, ascii, unicode: false)) outputs.Add(ascii);
            if (await MemoryAnalysis.ExtractStringsAsync(dump, unicode, unicode: true)) outputs.Add(unicode);
        }
        return outputs.ToArray();
    }
