# D04 출력 경로 제한

### 미구현

**판단.** 파생물을 만드는 SDK 메서드는 목적지 경로를 `Execute` 스크립트가 넘긴 인자로 받아 그대로 명령에 넣는다 [1].
목적지를 허용 폴더와 대조하거나 경로 구분자·`..`·링크를 검사하는 코드가 없다 [1].
목적지에 거는 검사는 `FailIfEvidenceSpoliationRisk`가 그 경로가 등록한 원본 증거 파일이나 그 파일이 든 폴더와 같은지 보는 것 하나이고 E03에서 본다 [2].

같은 작업을 다시 할 때 앞 파생물과 구분하는 장치도 없다.
표준 출력을 경로로 돌려 쓰는 메서드는 같은 경로로 다시 부르면 셸 `>`로 앞 파일을 알리지 않고 덮어쓴다 [3].
`Log2TimelineAsync`는 같은 저장 파일에 이어 쓰고 그 뒤 `PsortAsync`는 두 실행이 넣은 사건을 가리지 않고 함께 내보낸다 [4].
`RunToDirAsync`는 도구를 실행한 뒤 `outputDir`의 파일을 모두 나열해 돌려주므로 같은 폴더를 다시 쓰면 앞 실행의 파일이 이번 결과 목록에 섞인다 [5].
`ForemostAsync`·`BulkExtractorAsync`의 설명은 `outputDir`이 미리 없어야 한다고 적지만 서버 코드는 폴더가 있는지 보지 않고 외부 도구에 맡긴다 [6].
foremost와 bulk_extractor가 이미 있는 폴더를 거부하는지는 실행해 보지 않아 확인하지 못했다.

서버가 이름을 정하는 경로는 임시 파일·폴더뿐이다.
툴킷 공통 함수는 `/tmp/camel_ez_<GUID>`처럼 GUID를 넣은 임시 이름을 만들고 호출 안에서 지운다 [7].
호출이 끝나면 지우는 임시 이름만 유일하므로 D04.06에는 연결하지 않는다.

        return CaseEvidence.FirstOrDefault(e =>

            return file.Equals(normalized, comparison) || GetEvidenceDirectory(file).Equals(normalized, comparison);
        });

    // Runs a tool that writes files into outDir; creates the dir (as login user), runs, hands files back, lists them.
    private async Task<string[]?> RunToDirAsync(string outDir, bool sudo, Func<Task<string?>> run)
    {
        auditEnvironment.FailIfEvidenceSpoliationRisk(outDir);
        await auditEnvironment.ExecuteCommandAsync("mkdir", $"-p {Q(outDir)}", false);
        if (await run() is null) return null;
        if (sudo) await auditEnvironment.ExecuteCommandAsync("chown", $"-R $(id -un):$(id -gn) {Q(outDir)}", true);
        var find = await auditEnvironment.ExecuteCommandAsync("find", $"{Q(outDir)} -maxdepth 1 -type f -printf '%p\\n'", false);
        return find.IsCompleted
            ? find.Output.Split('\n', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries).ToArray()
            : [];
    }

    public async Task<T[]?> ExecuteToolJsonAsync<T>(string name, string args, string pattern = "*.json")
    {
        string dir = "/tmp/camel_ez_" + Guid.NewGuid().ToString("N");
        await auditEnvironment.ExecuteCommandAsync("mkdir", $"-p {dir}", false);
        try
        {
            if (await ExecuteToolTextAsync(name, $"{args} --json {dir}") is null) return null;
            return await DownloadJsonLinesAsync<T>(dir, pattern);
