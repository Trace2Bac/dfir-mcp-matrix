# D06 결론 도출

### D06.01 규칙·키 기반 상관

**구현.** 결론을 만드는 곳은 스크립트가 부르는 워크플로 메서드이고 결과는 스크립트에 돌려줄 뿐 서버 저장소에 남지 않는다.
`FindHiddenProcessAsync`는 `windows.pslist`와 `windows.psscan` 결과를 PID로 맞춰 목록에 없는 프로세스를 숨은 프로세스와 끝난 프로세스로 나눈다 [1].
`FindMalwareAsync`는 여러 단계의 신호를 PID로 묶고 이미 지목된 PID에만 원격 연결을 덧붙인다 [2].
`ValidateProcessTreeAsync`는 내장 `process_expectations.yaml`의 자식 금지·의심 부모·허용 부모·경로·사용자 규칙과 프로세스마다 맞춰 보고 위반을 심각도와 함께 돌려준다 [3].
`HuntLateralMovementAsync`는 이벤트 ID 4624·4648·5140·4697·7045로 원격 로그온·명시적 자격 증명·관리 공유 접근·서비스 설치를 가른다 [4].
`CategorizeTimelineAsync`는 Plaso 태그 규칙 파일로 저장 파일에 태그를 붙이고 태그 이름별로 사건을 묶는다 [5].
공격 단계(tactic)로 나누거나 흐름 문장을 만드는 코드는 없어 D06.06에는 연결하지 않는다.

**예외.** `ValidateProcessTreeAsync`가 `windows.pslist` 결과를 받으면 PPID의 이름을 같은 PID를 가진 마지막 행에서 찾는다 [6].
PID가 다시 쓰인 이미지에서는 실제 부모가 아닌 프로세스의 이름으로 부모 규칙을 판정한다 [6].
코드 주석도 PID가 다시 쓰이면 마지막 행을 쓴다고 적는다 [6].

`HuntLateralMovementAsync`는 System 로그 경로를 받았는데 그 파싱이 실패하면 빈 목록으로 바꿔 계속한다 [4].
그 경우 결과의 서비스 설치 목록에는 7045 이벤트가 빠지고 실패 사실은 결과에 실리지 않는다 [4].

### D06.02 시간·공간 근접성 연결

**구현.** `DetectTimelinePivotsAsync`는 hayabusa 경보마다 그 시각 앞뒤 `sliceSizeMinutes`분의 저장 파일 사건을 잘라 경보와 묶는다 [7].
같은 분에 든 경보는 하나로 줄이고 이른 차례로 `maxPivots`개까지만 본다 [7].
`AutoPivotExpansionAsync`는 이상 탐지로 뽑은 상위 지점마다 같은 방식으로 앞뒤 사건을 붙인다 [8].
`AnomalyDetectionToolkit`의 탐지기 묶음은 같은 종류의 사건이 60초 구간 안에 들면 한 묶음으로 합친다 [9].

**예외.** 두 메서드는 앞뒤 사건을 자르는 `PsortAsync`가 실패해 `null`을 돌려주면 빈 목록으로 바꿔 넣는다 [7][8].
그 경우 결과는 경보 주변에 사건이 없는 것과 구별되지 않는다 [7][8].

### D06.03 통계·점수 산정

**구현.** `TriageTimelineAsync`는 저장 파일의 사건을 정규화해 `AnomalyDetectionToolkit`의 탐지기 다섯(드문 종류·드문 전이·건수 급증·주기적 반복·내용)에 넣는다 [10].
탐지기마다 사건의 놀라움을 bit 값으로 매기고 묶음마다 bit를 더해 큰 차례로 `budget`개를 고른다 [9].
`HuntDnsTunnelingAsync`는 고유 하위 도메인 수·레이블 길이·엔트로피·레코드 종류·질의 수에 정한 점수를 더해 기준을 넘은 도메인을 돌려준다 [11].
`FindMalwareAsync`의 용의 프로세스는 신호 범주가 2개 이상이면 `IsHighConfidence`가 되고 범주 수·신호 수 차례로 정렬된다 [2][12].
스크립트는 `AnomalyDetectionToolkit`을 전역 객체로 직접 부를 수도 있다 [13].
`Camel.Inference`는 학습한 모델 없이 계산만 한다 [9].
문장 임베딩 모델을 쓰는 `Camel.Search`는 서버 프로젝트가 참조하지 않아 D06.04에는 연결하지 않는다 [14].

**예외.** `TriageTimelineAsync`는 `PsortReducedAsync`로 사건마다 메시지를 1,024자에서 자른 뒤 탐지기에 넣는다 [10][15].
내용 탐지기의 길이 판단과 이유 문장의 길이 값은 잘린 길이로 계산된다 [15][16].
`PsortReducedAsync` 설명은 키워드 신호에 영향이 없다고 적지만 1,024자 뒤에 있는 키워드는 잘린 메시지에서 빠져 세지 않는다 [15][16].
줄여 쓰는 스크립트는 JSON으로 읽지 못한 줄을 건너뛰고 그 수를 알리지 않는다 [15].

### D06.05 사용 근거·변환 기록

**구현.** 워크플로 메서드는 `AuditScope`로 워크플로·메서드 이름을 기록 문맥에 넣고 그 안에서 실행한 명령 항목마다 이 이름이 붙는다 [17].
그래서 결론을 돌려준 `Execute` 호출의 `ExecutionId`로 그 결론이 읽은 도구 명령과 인자를 사건 호출 기록에서 찾을 수 있다 [17][18].
결과에도 적용한 규칙이 실린다.
이상 탐지 결과의 항목마다 탐지기 이름과 이유 문장, 묶은 사건 번호가 실린다 [9].
`ValidateProcessTreeAsync`의 위반 항목은 규칙 종류와 기대값·실제값을 싣고 `HuntDnsTunnelingAsync`의 도메인 항목은 점수를 더한 이유를 싣는다 [3][11].

**예외.** `ValidateProcessTreeAsync`에 스크립트가 만든 `ProcessNode` 목록을 넘기거나 `AnomalyDetectionToolkit`을 스크립트에서 직접 부르면 명령이 실행되지 않아 결론의 입력이 명령 항목으로 남지 않는다 [3][13].
그 호출의 호출 기록에는 스크립트 원문만 남고 스크립트가 실행 중에 넘긴 값은 남지 않는다 [18].

    public TriageReport Triage(CanonicalEvent[] baseline, CanonicalEvent[] target, int budget, double episodeGapSeconds = 60.0)
    {
        long bucket = Math.Max(1, (long)(episodeGapSeconds * 1_000_000));
        int quota = Math.Max(1, (int)Math.Ceiling((double)budget / detectors.Length));

        // Per-detector quota: each detector collapses its findings into episodes (same token within a time bucket,
        // so one burst is one entry) and contributes only its top `quota`. This keeps the shortlist DIVERSE across
        // kinds of anomaly — a detector that emits astronomically-large bits (a volume burst) can't crowd out a
        // detector whose signal is smaller in magnitude but just as interesting (a rare event type).
        var picked = new List<(string Token, long Bucket, double Bits, Finding Peak, int[] Members)>();
        foreach (var d in detectors)
            picked.AddRange(d.Detect(baseline, target)
                .GroupBy(f => (f.Token, f.Ts / bucket))
                .Select(g =>
                {
                    var peak = g.MaxBy(f => f.Bits)!;
                    return (peak.Token, g.Key.Item2, peak.Bits, peak, g.Select(f => f.EventIndex).Distinct().ToArray());
                })
                .OrderByDescending(e => e.Bits)
                .Take(quota));

            {
                double mean = sum[token] / c;
