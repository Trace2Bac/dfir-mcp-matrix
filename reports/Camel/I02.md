# I02 분석 도구 통신 차단

### I02.03 DNS 조회 끄기

**구현.** 이 방식은 `PacketAnalysisToolkit`의 `tshark`·`tcptrace` 호출에 있다 [1][2].
`tshark`를 부르는 메서드 일곱 곳은 모두 이름 풀이를 끄는 `-n`을 붙인다 [1].
`TcpTraceAsync`는 `tcptrace -n`으로 호스트·서비스 이름 풀이를 끈다 [2].

다른 분석 도구에는 통신을 끊거나 끄는 장치가 없다.
Volatility 3 플러그인은 메모리 파일, 출력 형식, 플러그인 이름만 넘기고 오프라인 옵션을 붙이지 않는다 [3].
코드 주석은 리눅스 커널이 알려진 것이면 `vol`이 공개 심볼 서버에서 심볼을 스스로 받는다고 적는다 [3].
Windows 플러그인이 심볼을 내려받는지는 실행해 보지 않아 확인하지 못했다.
SSH 실행 환경은 명령 문자열을 원격 셸에 그대로 넘기고 네트워크를 끊는 설정이나 프록시 환경변수를 붙이지 않는다 [4].
로컬 실행 환경도 호출자가 넘긴 환경변수만 더하고 네트워크를 막는 설정을 두지 않는다 [5].
저장소에는 분석 도구를 네트워크 없는 컨테이너나 network namespace에서 실행하는 구성이 없다 [3].
서버 코드가 일부러 여는 도구 준비 내려받기는 I01에서 본다.

**예외.** `ConversationsAsync`·`EndpointsAsync`·`FollowStreamAsync`의 `proto`와 `ExportObjectsAsync`의 `kind`는 따옴표 없이 `tshark` 인자 문자열에 들어간다 [6].
그래서 스크립트가 이 값에 공백과 다른 `tshark` 옵션을 이어 붙이면 그 옵션이 `-n` 뒤에 더해진다 [6].
뒤에 붙은 `-N` 옵션이 이름 풀이를 다시 켜는지는 실행해 보지 않아 확인하지 못했다 [6].
