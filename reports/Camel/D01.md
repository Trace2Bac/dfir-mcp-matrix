# D01 파생물 보관

### D01.02 도구가 만든 파생물 유지

**구현.** 파일을 만드는 SDK 메서드는 `Execute` 스크립트가 넘긴 경로에 도구 결과를 쓰고 호출이 끝난 뒤에도 그 파일을 지우지 않는다 [1][2].
`IcatAsync`·`FlsBodyfileAsync`·`MactimeToFileAsync`는 도구의 표준 출력을 인자 `outputFile` 경로로 돌려 쓴다 [1].
`ForemostAsync`·`TskRecoverAsync`·`DumpFilesAsync`·`ExportObjectsAsync`는 도구가 인자 `outputDir` 폴더에 복구하거나 꺼낸 파일을 쓰게 한다 [2].
`Log2TimelineAsync`는 Plaso 저장 파일을 인자 `storageFile` 경로에 만들고 타임라인 워크플로는 그 경로를 나중에 다시 걸러 볼 저장 파일로 돌려준다 [3].
이 경로는 명령을 실행하는 실행 환경(로컬 또는 SSH로 붙은 SIFT 워크스테이션)의 경로이고 서버는 폴더나 이름을 정하지 않는다 [1][2].
보관 기간·용량·대상을 정하는 설정이나 코드는 없다.

다른 메서드는 도구 출력을 임시 파일로 받고 호출 안에서 지운다.
`ExecuteToolJsonAsync`와 `ExecuteToolJsonLinesFileAsync`는 `/tmp/camel_*` 아래 GUID 이름의 임시 폴더·파일에 도구 출력을 쓰게 한 뒤 읽고 `finally`에서 지운다 [4].
`CarveUnallocatedSpaceAsync`는 할당되지 않은 영역을 꺼낸 중간 파일을 카빙이 끝나면 지운다 [5].

도구의 표준 출력과 `Execute` 응답 본문은 파일로 남지 않는다 [6].
`Execute`는 스크립트가 `log`·`error`로 낸 줄을 메모리의 `StringBuilder`에 모아 응답으로만 돌려준다 [6].
사건 호출 기록 파일 `audit-<caseId>.clef`의 명령 항목에는 호스트·명령·인자·종료 코드·시간만 있고 출력은 없다 [6].
스크립트가 `auditInfo`로 넘긴 줄만 호출 기록에 함께 남는다 [7].
스크립트가 `Session`에 넣은 결과는 프로세스 메모리에만 있고 P04에서 본다 [8].

**예외.** `ListDeletedFilesAsync`는 `/tmp/camel_deleted_<GUID>.body` 본문 파일을 만들어 읽은 뒤 지우지 않는다 [9].
이 중간 파일이 언제까지 남는지는 서버 코드가 정하지 않아 확인하지 못했다.

같은 경로로 다시 실행하면 앞 실행의 파생물이 따로 남지 않는다.
표준 출력을 경로로 돌려 쓰는 메서드는 같은 `outputFile`로 다시 부르면 셸 `>`로 앞 파일을 덮어쓴다 [1].
`Log2TimelineAsync`는 `storageFile`이 이미 있으면 그 파일에 이어 쓰고 `PsortTagAsync`는 저장 파일 안의 태그를 그 자리에서 고친다 [3][10].
다시 실행할 때 앞 파생물을 구분하는 방식은 D04에서 본다.

    public async Task<WorkflowResult<DeletedFilesReport>> ListDeletedFilesAsync(string image, int? offset = null, int maxFiles = 2000)
    {
        using var _audit = AuditScope();
        using var op = Begin("Listing deleted files in {0} (offset {1})", image, offset?.ToString() ?? "none");

        var bodyfile = $"/tmp/camel_deleted_{Guid.NewGuid():N}.body";
        if (!await DiskAnalysis.FlsBodyfileAsync(image, bodyfile, offset))
            return WorkflowResult<DeletedFilesReport>.Failure(
                $"Failed to walk '{image}' (offset {offset}) for deleted files. Check the offset (mmls) and that a filesystem exists there.");

        // The bodyfile names every deleted entry with a "(deleted)" / "(deleted-realloc)" suffix; pull just those
        // server-side rather than transferring the whole bodyfile.
        var lines = await DiskAnalysis.GrepLinesAsync(bodyfile, ["deleted"], ignoreCase: false);
        if (lines is null)
            return WorkflowResult<DeletedFilesReport>.Failure($"Could not read the bodyfile '{bodyfile}'.");

        var entries = lines.Select(ParseDeletedRow).Where(e => e is not null).Select(e => e!)
            .OrderByDescending(e => e.Size).Take(maxFiles).ToArray();

        op.Complete();
        var report = new DeletedFilesReport { DeletedFiles = entries, Count = entries.Length };
        return WorkflowResult<DeletedFilesReport>.Success(report,
            entries.Length == 0
                ? $"No deleted files found in '{image}' (offset {offset})."
                : $"Found {lines.Length} deleted entry/entries in '{image}'; {entries.Count(e => e.Recoverable)} recoverable. " +
                  $"Largest: {string.Join("; ", entries.Take(3).Select(e => $"{e.Path} ({e.Size} bytes)"))}.");
    }

    /// <summary>
    /// Runs psort's <c>tagging</c> analysis plugin over <paramref name="storageFile"/>, labelling events that
    /// match the rules in <paramref name="taggingFile"/> (the Plaso-shipped <c>tag_windows.txt</c> /
    /// <c>tag_linux.txt</c> / <c>tag_macos.txt</c>). The tags are <em>persisted back into the storage file</em>
    /// (written with <c>-o null</c>, no timeline emitted), so a subsequent <see cref="PsortAsync"/> can filter
    /// on them (<c>"tag contains 'application_execution'"</c>) and each returned event carries its
    /// <see cref="TimelineEvent.Labels"/>. Idempotent in effect — re-tagging re-applies the same labels.
    /// Returns true on success.
    /// </summary>
    public async Task<bool> PsortTagAsync(string storageFile, string taggingFile)
    {
        auditEnvironment.FailIfEvidenceSpoliationRisk(storageFile);   // tagging rewrites the storage file in place
        return await ExecuteToolTextAsync("Psort",
            $"-q --analysis tagging --tagging-file {Q(taggingFile)} -o null {Q(storageFile)}") is not null;
    }
