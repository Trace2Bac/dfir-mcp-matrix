# P05 사건 자료 정리

### P05.01 모델 도구로 삭제·초기화

**구현.** 사건 자료를 지우거나 사건을 초기화하는 MCP 도구는 없다.
`Execute` 스크립트는 SDK 메서드 `DiskAnalysisToolkit.DeleteFileAsync`로 워크스테이션의 파일 하나를 지울 수 있다 [1].
이 메서드는 등록한 증거인지 검사한 뒤 sudo 없이 로그인 계정 권한으로 `rm -f`를 실행한다 [1].
docstring은 카빙용 비할당 영역 추출본 같은 중간 파일을 치우는 메서드라고 적지만 대상 경로를 그런 파일로 제한하지는 않는다 [1].
스크립트는 `delete Session["key"]`로 세션의 캐시 결과를 지울 수 있고 사건 `CLAUDE.md` 견본이 큰 캐시를 이렇게 비우라고 안내한다 [2][3].
등록한 증거 목록은 세션에 한 번만 들어가고 지우거나 바꾸는 도구가 없다 [4].
`SetCaseId`로 사건을 바꿔도 앞 사건의 호출 기록이나 파생물은 지워지지 않는다 [5].

### P05.03 자동 정리

**구현.** 툴킷의 공통 실행 함수는 도구 출력을 받을 임시 폴더·파일을 워크스테이션의 `/tmp/camel_*`에 GUID 이름으로 만들고 결과를 읽은 뒤 `finally`에서 `rm`으로 지운다 [6].
SSH 환경에서 서버 쪽으로 내려받은 JSON 파일도 파싱한 뒤 지운다 [7].
`DiskAnalysisWorkflow.CarveUnallocatedSpaceAsync`는 비할당 영역을 뽑은 중간 파일을 카빙이 끝나면 `DeleteFileAsync`로 지운다 [8].
SSH 실행 환경 객체는 정리될 때 서버 쪽 임시 폴더의 작업 폴더를 지운다 [9].
워크스테이션에서 실행한 `rm`은 명령 기록으로 호출 기록에 남고 서버 쪽 파일을 지운 일은 남지 않는다 [7][9][10].
`ListDeletedFilesAsync`가 만드는 bodyfile처럼 임시 경로에 만들고 지우지 않는 파일도 있다 [11].

서버 안의 세션 정리기는 4시간 넘게 호출이 없는 세션을 지우고 그 세션의 사건 ID, 등록한 증거, `Session` 저장소를 버린다 [12][13].
도구 호출이 진행 중인 세션은 지우지 않는다 [12].
세션을 지운 사실은 서버 로그에만 남고 사건 호출 기록에는 남지 않는다 [12].

### P05.05 원본 증거를 삭제 대상에서 제외

**구현.** `DeleteFileAsync`는 지우기 전에 `FailIfEvidenceSpoliationRisk`로 대상 경로가 등록한 증거 파일이나 그 파일을 담은 폴더인지 보고 그렇다면 예외를 던진다 [1][14].
비교는 역슬래시를 `/`로 바꾸고 끝의 구분자를 지운 문자열 비교이고 Windows 환경에서만 대소문자를 무시한다 [15].
`CarveUnallocatedSpaceAsync`가 지우는 중간 파일은 서버가 `/tmp`에 GUID 이름으로 만든 파일이다 [8].
`rm -f`는 파일만 지우므로 이 메서드로 폴더를 통째로 지우지는 못한다 [1].

**한계.** `SetEvidence`를 부르지 않은 세션은 보호 목록이 비어 `DeleteFileAsync`가 원본 증거 파일도 지운다 [14].
`SetEvidence`는 폴더도 증거로 받지만 검사는 등록한 경로 자신과 그 상위 폴더만 보므로 등록한 폴더 안의 파일은 보호하지 않는다 [14][16].
주석은 겹친 구분자를 하나로 줄인다고 적지만 코드는 `//`·`./`·`..`나 심볼릭 링크를 해석하지 않아 같은 파일을 다른 표기로 주면 검사를 지난다 [15].
`Toolkit`의 `auditEnvironment` 필드는 `public`이고 그 객체의 `ExecuteCommandAsync`는 증거 검사 없이 받은 명령을 실행한다 [17].
고정 Jint 4.9.2 소스상 엔진은 묶은 툴킷 객체의 공개 필드를 거르지 않고 스크립트에 드러낸다 [17][18][19].
그래서 스크립트는 이 검사를 거치지 않고 파일을 지울 수 있다.
이 경로를 실제로 실행해 시험하지는 않았다.

### P05.09 삭제 사실 기록

**구현.** `DeleteFileAsync`와 자동 정리가 워크스테이션에서 실행한 `rm`은 공통 명령 실행 함수가 호스트·명령·인자·sudo 여부·종료 코드와 함께 사건 호출 기록에 남긴다 [10].
그 항목에는 호출을 일으킨 `Execute`의 실행 ID와 workflow·툴킷 이름이 기록 문맥으로 붙고 `Execute`가 실행한 스크립트 전문도 같은 파일에 남는다 [10][20].
`delete Session["key"]`처럼 스크립트 안에서 지운 캐시는 스크립트 전문으로만 남는다 [20].
증거 보호 검사가 막은 삭제는 예외로 스크립트가 멈추고 그 `Execute`가 `failed`로 기록된다 [14][21].

**한계.** 로컬 실행 환경에서는 서버가 호출 기록을 쓰는 폴더가 `DeleteFileAsync`가 파일을 지우는 같은 컴퓨터에 있다 [22].
호출 기록 파일은 증거 보호 목록에 포함되지 않아 `DeleteFileAsync`의 대상에서 빠지지 않는다 [14][22].

```csharp
    {
        var now = DateTimeOffset.UtcNow;
        foreach (var kv in sessions)
        {
            if (!kv.Value.IsValueCreated) continue;
            var ctx = kv.Value.Value;
            if (ctx.IsBusy) continue;                       // a call in flight must keep its connection
```

```csharp
    public void FailIfEvidenceSpoliationRisk(string targetPath)
    {
        var evidence = FindEvidenceForPath(targetPath);
        if (evidence is not null) throw new EvidenceSpoliationRiskException(evidence, targetPath);
    }

    // The registered evidence that <paramref name="path"/> would put at risk (the evidence file itself or its
    // containing directory), or null if the path is not protected. Shared by the check and the guard so both
    // apply identical normalization and case-sensitivity rules.
    private EvidenceInfo? FindEvidenceForPath(string path)
    {
        if (string.IsNullOrWhiteSpace(path) || CaseEvidence.Length == 0) return null;
        var comparison = IsWindows ? StringComparison.OrdinalIgnoreCase : StringComparison.Ordinal;
        var normalized = NormalizeEvidencePath(path);
        return CaseEvidence.FirstOrDefault(e =>
        {
            var file = NormalizeEvidencePath(e.FilePath);
            return file.Equals(normalized, comparison) || GetEvidenceDirectory(file).Equals(normalized, comparison);
        });
    }
```

```csharp
    // Collapse mixed/duplicate separators to this environment's separator and strip a trailing one so that
    // equivalent spellings of the same path compare equal.
    private string NormalizeEvidencePath(string path)
    {
        var p = path.Trim().Replace('\\', '/').Replace('/', PathSeparator[0]);
        return p.Length > 1 ? p.TrimEnd(PathSeparator[0]) : p;
    }

    // The parent directory of an already-normalized evidence path (empty if it has no separator).
    private string GetEvidenceDirectory(string normalizedPath)
    {
        var i = normalizedPath.LastIndexOf(PathSeparator[0]);
        return i <= 0 ? normalizedPath[..(i + 1)] : normalizedPath[..i];
    }
```
