# R04 도구 결과 해석 주의

### R04.02 결과 조건별 주의

**구현.** 이 절은 SDK 메서드가 Execute 스크립트에 돌려주는 객체를 결과로 본다.
그 객체가 응답 글에 실리는지는 호출자 코드가 정한다.
결과에 따라 고르는 주의는 무결성 확인, Linux 악성코드 검사, Suricata IDS 검사에 있다.
`VerifyImageAsync`는 ewfverify가 해시 불일치를 내면 `Message`에 이 이미지를 믿지 말라고 적는다 [1].
`VerifyEvidence`는 해시가 다르면 chain-of-custody 문제로 보고 멈추라는 문구를 응답에 싣는다 [2].
`ScanForMalwareAsync`는 ClamAV 탐지가 0건이면 보고서의 `Note`에 서명 DB가 최신인지 확인하라고 적는다 [3].
`RunIdsAsync`는 Suricata 경보가 0건이면 `Message`에 룰 묶음을 suricata-update로 설치했는지 확인하라는 문구를 붙인다 [4].

**한계.** `EwfVerifyAsync`는 `ExecuteToolTextAsync`로 ewfverify를 실행하고 명령이 0이 아닌 종료 코드로 끝나면 `null`을 받는다 [5][6].
이때 `VerifyImageAsync`는 주의 문구 없이 ewfverify가 끝나지 않았다는 실패 결과를 돌려준다 [5].
ewfverify가 해시 불일치에서 어떤 종료 코드를 내는지는 저장소에서 확인하지 못했다.
`ScanForMalwareAsync`는 ClamAV 실행이 실패해도 결과를 빈 배열로 채우므로 `Note`가 ClamAV가 탐지하지 않았다고 적는다 [3].
`SuricataAsync`는 `eve.json`이 없거나 읽지 못해 경보 줄을 꺼내는 `grep`이 실패해도 빈 배열을 돌려준다 [7].
이때 `RunIdsAsync`는 경보 0건일 때의 문구를 그대로 붙여 출력 파일을 읽지 못한 경우도 룰 묶음 확인으로 안내한다 [4][7].

도구 설명과 응답에 결과와 관계없이 붙는 해석 주의는 없어 R04.01에는 연결하지 않는다.

### R04.03 추가 확인 도구·증거 추천

**구현.** `camel-sdk-discipline` 리소스는 발견사항을 기록하기 전에 메모리·디스크·이벤트 로그·timeline 가운데 독립된 출처 둘 이상으로 확인하라고 권한다 [8].
결과가 비어 있으면 로그가 지워졌거나 순환됐거나 켜지지 않았는지 확인하라고 권한다 [9].
`ScanForMalwareAsync`의 `Note`는 ClamAV 탐지가 0건일 때 freshclam으로 서명 DB를 확인하라고 권한다 [3].

**한계.** R04.02의 한계와 같이 ClamAV 실행이 실패한 경우에도 `Note`는 탐지가 없었다는 전제로 DB 확인만 권한다 [3].

    public async Task<SuricataAlert[]?> SuricataAsync(string pcap, string outDir, bool sudo = false)
    {
        auditEnvironment.FailIfEvidenceSpoliationRisk(outDir);
        await auditEnvironment.ExecuteCommandAsync("mkdir", $"-p {Q(outDir)}", false);
        if (await RunAsync("Suricata", $"-r {Q(pcap)} -l {Q(outDir)}", sudo || Tools["Suricata"].Sudo) is null) return null;
        if (Tools["Suricata"].Sudo || sudo)
            await auditEnvironment.ExecuteCommandAsync("chown", $"-R $(id -un):$(id -gn) {Q(outDir)}", true);

        // Pull only the alert lines out of (a potentially large) eve.json.
        var eve = $"{outDir.TrimEnd('/')}/eve.json";
        var r = await auditEnvironment.ExecuteCommandAsync("bash", $"-c \"grep '\\\"event_type\\\":\\\"alert\\\"' {Q(eve)} 2>/dev/null\"", false);
        if (!r.IsCompleted) return [];
        var alerts = new List<SuricataAlert>();
        foreach (var line in Lines(r.Output))
        {
            if (TryParseAlert(line) is { } a) alerts.Add(a);
        }
        return alerts.ToArray();
