# E03 원본 변경 방지

### E03.01 실행 환경의 읽기 전용 강제

**구현.** 디스크 이미지를 파일시스템으로 올리는 SDK 메서드는 읽기 전용으로 올린다.
`EwfMountLoopbackAsync`·`EwfMountNtfsAsync`·`DDMountAsync`는 `mount`에 `ro` 옵션을 고정해 넘기고 모델이 바꿀 인자가 없다 [1][2].
`EwfMountRawAsync`는 `ewfmount`에 이미지와 마운트 폴더만 넘기고 `BdeMountAsync`는 `bdemount`에 자격 정보와 경로만 넘긴다 [1][3].
`DiskAnalysisWorkflow.MountEwfImageAsync`는 `ewfmount`로 원시 디스크를 올리고 `MountFileSystemAsync`는 그 위의 파티션을 커널 NTFS 드라이버(`ro,loop`), 안 되면 `ntfs-3g`(`ro,force`), NTFS가 아니면 `ro,loop`로 올린다 [4].
파일 찾기 `FindFilesAsync`와 EZ 도구 같은 파일 단위 파서는 이 마운트 아래 경로를 입력으로 받는다 [5].
마운트는 모델이 스크립트에서 이 메서드를 부를 때만 일어난다.

**한계.** `ewfmount`와 `bdemount`에는 읽기 전용 옵션을 넘기지 않아 두 마운트가 읽기 전용인지는 도구 자체의 동작에 달려 있다 [1][3].
메서드 설명은 둘 다 읽기 전용으로 올린다고 적지만 두 도구가 쓰기를 지원하지 않는지는 실행해 확인하지 않았다 [1][3].

### E03.02 서버 코드의 원본 쓰기 제한

**구현.** 서버 코드의 장치는 등록한 증거 경로와 쓰기 대상을 견주는 `FailIfEvidenceSpoliationRisk`다 [6].
이 검사는 대상 경로가 등록한 증거 파일과 같거나 그 파일이 든 폴더와 같으면 `EvidenceSpoliationRiskException`을 던져 작업을 거부한다 [6][7].
견주기 전에 경로 구분자를 실행 환경의 것으로 바꾸고 끝의 구분자를 떼며 Windows 실행 환경에서는 대소문자를 가리지 않는다 [6].
출력 파일·폴더를 받는 SDK 메서드는 명령을 실행하기 전에 이 검사를 부른다 [8].
`icat`·`tsk_recover`·`blkls`·카빙 도구 출력, `fls` bodyfile·`mactime` 출력, 압축 풀기·복사 대상, plaso 저장 파일, Volatility 덤프 폴더, EZ 도구 CSV 출력, YARA 규칙 컴파일 출력이 여기에 포함된다 [8].
검사는 `SetEvidence`로 증거를 등록한 세션에서만 적용되고 등록하지 않은 세션에서는 아무 경로도 막지 않는다 [6].
증거 등록 여부는 모델에게 달려 있고 사건 폴더 지침이 조사 시작 때 등록하라고 적는다.

**한계.** 검사는 경로가 같은지만 보므로 증거 폴더 안의 새 파일이나 하위 폴더를 대상으로 하면 거부하지 않는다 [6].
`IcatAsync`의 출력 파일을 증거 이미지 옆에 두거나 `UnzipAsync`의 풀 폴더를 증거 폴더의 하위 폴더로 주면 그대로 쓴다 [6][9].
증거를 폴더(마운트한 볼륨 등)로 등록해도 그 폴더 아래 파일에 쓰는 작업은 막지 않는다 [6].
`SetEvidence` 설명은 증거 경로나 그 경로가 든 폴더에 쓰거나 풀어 넣거나 바꾸는 작업을 거부한다고 적는다 [10].

경로 정규화는 `..`·`.` 조각, 겹친 구분자, 상대 경로, 심볼릭 링크를 해석하지 않아 같은 파일을 다른 철자로 가리키면 검사를 지난다 [6].
주석은 겹친 구분자를 합친다고 적지만 코드는 구분자 문자만 바꾼다 [6].

쓰기 대상을 받는데 검사를 부르지 않는 메서드도 있다.
`MakeDirAsync`는 받은 경로를 검사 없이 `sudo mkdir -p`로 만든다 [11].
Toolkit 객체의 필드 `auditEnvironment`는 공개이고 스크립트 엔진에는 CLR 멤버 접근을 막는 설정이 없다 [12].
스크립트가 이 필드로 `ExecuteCommandAsync`를 부르면 검사 없이 명령을 실행하고 `admin`을 참으로 주면 `sudo`로 실행한다 [12][13].
고정 Jint 4.9.2 소스상 엔진은 묶은 객체의 공개 필드를 거르지 않고 스크립트에 드러내므로 스크립트는 이 경로로 `ExecuteCommandAsync`에 닿는다 [14][15].
이 경로를 실제로 실행해 시험하지는 않았다.

세션이 4시간 넘게 쉬어 지워지면 같은 세션 ID의 다음 호출은 등록 목록이 빈 새 실행 환경을 받아 검사가 아무것도 막지 않는다 [16].

### E03.03 외부 도구·플랫폼에 위임

**구현.** TSK(`fls`·`icat`·`mmls`·`fsstat`), Volatility, plaso, EZ 도구 같은 외부 도구에는 증거 경로나 마운트 아래 경로를 읽기 인자로 그대로 넘긴다 [17].
`FailIfEvidenceSpoliationRisk`는 출력 경로만 보고 입력으로 넘기는 증거 경로는 보지 않는다 [8].
설정은 TSK 도구 대부분과 Volatility·카빙 도구를 `sudo`로 실행하게 한다 [18].
이 경로에서 원본을 지키는 것은 외부 도구가 증거를 읽기만 한다는 동작뿐이다.
세션에서 `SetEvidence`를 부르지 않았으면 출력 경로 검사도 적용되지 않아 이 도구들의 동작 말고는 원본을 지키는 것이 없다 [6].

**한계.** 외부 도구가 원본을 읽기 모드로 여는지는 서버 개요의 외부 도구 버전 기준으로 소스를 확인하지 못해 실제 보호 미확인이다 [17].

    /// Refuses an operation that targets registered evidence by throwing
    /// <see cref="EvidenceSpoliationRiskException"/> if <paramref name="targetPath"/> is an evidence file or its
    /// containing directory (see <see cref="CheckAgainstEvidencePaths"/>). Call this from any toolkit/workflow
    /// path that writes, overwrites, or deletes before it touches the filesystem so original evidence cannot be
    /// disturbed — turning spoliation protection into an architectural guard rather than a convention.
    /// </summary>
    public void FailIfEvidenceSpoliationRisk(string targetPath)
    {

        if (evidence is not null) throw new EvidenceSpoliationRiskException(evidence, targetPath);

    // The registered evidence that <paramref name="path"/> would put at risk (the evidence file itself or its
    // containing directory), or null if the path is not protected. Shared by the check and the guard so both
    // apply identical normalization and case-sensitivity rules.
    private EvidenceInfo? FindEvidenceForPath(string path)
    {
        if (string.IsNullOrWhiteSpace(path) || CaseEvidence.Length == 0) return null;
        var comparison = IsWindows ? StringComparison.OrdinalIgnoreCase : StringComparison.Ordinal;
        var normalized = NormalizeEvidencePath(path);
        return CaseEvidence.FirstOrDefault(e =>
        {
            var file = NormalizeEvidencePath(e.FilePath);
            return file.Equals(normalized, comparison) || GetEvidenceDirectory(file).Equals(normalized, comparison);
        });
    }

    // Collapse mixed/duplicate separators to this environment's separator and strip a trailing one so that
    // equivalent spellings of the same path compare equal.
    private string NormalizeEvidencePath(string path)
    {
        var p = path.Trim().Replace('\\', '/').Replace('/', PathSeparator[0]);
        return p.Length > 1 ? p.TrimEnd(PathSeparator[0]) : p;
    }

    // The parent directory of an already-normalized evidence path (empty if it has no separator).
    private string GetEvidenceDirectory(string normalizedPath)
    {
        var i = normalizedPath.LastIndexOf(PathSeparator[0]);
        return i <= 0 ? normalizedPath[..(i + 1)] : normalizedPath[..i];
    }
