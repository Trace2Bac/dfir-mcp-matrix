# P03 조사 진척 판단

### P03.04 모델이 적은 진행 기록 보관

**구현.** 이 방식은 `forensic-mcp`의 할 일 도구 `add_todo`, `list_todos`, `update_todo`, `complete_todo`와 `case-mcp`의 `record_action`에 적용된다 [1][2][3].
`add_todo`는 설명, 담당자, 우선순위, 관련 발견사항 ID를 받아 `TODO-<검토자>-<번호>` 항목을 상태 `open`으로 사건 폴더의 `todos.json`에 더한다 [1].
할 일 항목에는 호스트나 증거를 적는 칸이 없어 작업 대상은 설명 글로만 남는다 [1].
`update_todo`는 상태를 `open`이나 `completed`로 바꾸고 메모를 적은 사람과 시각과 함께 `notes`에 덧붙이며 `completed`로 바꾸면 `completed_at`을 적는다 [2].
`complete_todo`는 상태를 `completed`로 바꾸는 `update_todo` 호출이다 [2].
`list_todos`는 상태(`open`, `completed`, `all`)와 담당자로 골라 돌려준다 [4].
게이트웨이는 할 일 도구에 API 키의 검토자 이름을 `analyst_override`로 넣고 할 일 항목의 `created_by`와 메모의 `by`에 그 이름이 들어간다 [5][1].
`case-mcp`의 `case_status`는 `todos.json`에서 열린 항목 수와 전체 수를 세어 `todo_open`과 `todo_total`로 싣는다 [6].
`record_action`은 모델이 적은 작업 설명과 도구 이름, 명령을 `actions.jsonl`에 `source: mcp`로 덧붙이고 `forensic-mcp`의 `get_actions`가 최근 50개를 돌려준다 [3][7].
할 일 두 개를 만들고 하나를 마치자 `case_status`는 `todo_open` 1과 `todo_total` 2를 돌려주었다 [8].

서버가 대상 유형마다 해야 할 작업 목록을 두고 수행 기록과 대조하거나 완료 조건을 판단하는 도구는 없다.
`forensic-mcp`의 아티팩트별 수집 점검표는 정해 둔 문서로만 돌려주고 할 일이나 호출 기록과 대조하지 않는다 [9].

**한계.** 서버는 할 일의 완료 표시를 호출 기록이나 발견사항과 대조하지 않는다 [2].
`update_todo`는 `open`과 `completed`가 아닌 상태 값을 알리지 않고 무시한 채 `updated`를 돌려준다 [2].
우선순위도 `high`, `medium`, `low`가 아니면 알리지 않고 `medium`으로 저장한다 [1].
우선순위 `urgent`로 만든 할 일은 `medium`으로 저장되었다 [8].

```python
    def list_todos(self, status: str = "open", assignee: str = "") -> list[dict]:
        """List local TODOs, filtered by status and/or assignee."""
        case_dir = self._require_active_case()
        todos = self._load_todos(case_dir)

        if status != "all":
            todos = [t for t in todos if t.get("status") == status]
        if assignee:
            todos = [t for t in todos if t.get("assignee") == assignee]

        return todos
```

```python
    def get_actions(self, limit: int = 50) -> list[dict]:
        """Return recent actions from actions.jsonl."""
        case_dir = self._require_active_case()
        entries = []
        actions_file = case_dir / "actions.jsonl"
        if actions_file.exists():
            try:
                with open(actions_file, encoding="utf-8") as f:
                    for line in f:
                        line = line.strip()
                        if line:
                            try:
                                entries.append(json.loads(line))
                            except json.JSONDecodeError:
                                logger.warning("Corrupt JSONL line in %s", actions_file)
            except OSError as e:
                logger.warning("Failed to read actions file %s: %s", actions_file, e)
        entries.sort(key=lambda e: e.get("ts", ""))
        return entries[-limit:]
```

```python
def get_checklist(artifact_type: str) -> dict:
    """Get collection checklist for an artifact type."""
    result = loader.get_collection_checklist(artifact_type)
    if result is None:
        # List what's available
        available = []
        for at in ("registry", "event_logs", "memory", "filesystem"):
            if loader.get_collection_checklist(at) is not None:
                available.append(at)
        return {
            "error": f"Unknown artifact type '{artifact_type}'",
            "available": sorted(available),
        }
    return result
```
