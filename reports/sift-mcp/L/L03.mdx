# L03 기록 실패 처리

### L03.02 경고 후 계속

**구현.** 이 방식은 공통 기록기 `AuditWriter`로 항목을 쓰는 게이트웨이와 백엔드 7개의 모든 호출에 적용된다 [1].
모든 경로는 도구를 실행한 뒤 항목을 쓴다 [2][3].
`AuditWriter._write_entry`는 쓰기에서 `OSError`가 나면 예외를 올리지 않고 운영 로그에 경고를 남긴 뒤 거짓을 돌려준다 [1].
`AuditWriter.log`는 이때 운영 로그에 경고를 하나 더 남기고 `None`을 돌려준다 [4].
기록 폴더를 만들지 못한 경우도 운영 로그에 경고를 남기고 `None`을 돌려준다 [5].
운영 로그는 표준 오류와 `~/.vhir/logs/<서비스>.jsonl`에 JSON 줄로 쓴다 [6].

백엔드 도구는 `None`을 받으면 결과에 `warning`으로 `Audit write failed — action not recorded`를 붙여 돌려준다 [2][3].
`sift-mcp.jsonl`과 `forensic-mcp.jsonl` 자리에 폴더를 두어 쓰기가 실패하게 하자 `run_command`는 명령을 실행해 결과와 이 경고를 돌려줬고 `add_todo`는 할 일을 저장한 뒤 이 경고를 돌려줬다 [7].
두 호출 모두 응답의 `audit_id`는 `null`이었고 표준 오류에는 쓰지 못한 호출 ID를 담은 경고가 남았다 [7].
게이트웨이는 기록 결과를 응답에 반영하지 않고 운영 로그의 경고만 남는다 [8][9].
`log_lookup`도 쓰기가 실패하면 그 백엔드의 운영 로그에 경고를 남기고 호출을 계속한다 [10].

`forensic-mcp`의 `record_finding`은 반박 검토 결과가 철회인 발견사항을 저장하지 않고 항목만 쓴다 [11][12].
이 항목을 쓰지 못하면 같은 발견사항을 `withdrawal_unlogged`로 다시 처리해 검토자가 볼 초안으로 저장하고 항목을 한 번 더 쓴다 [11][12].
초안에는 철회를 기록하지 못해 검토자에게 넘긴다는 메모가 들어간다 [13].
이 분기는 실행하지 않았고 코드로만 확인했다.

**한계.** 사건 폴더를 찾지 못해 항목을 쓰지 않은 경우에도 `AuditWriter.log`는 `None`을 돌려주므로 백엔드는 같은 쓰기 실패 경고를 붙인다 [4][2].
사건이 없을 때 `run_command`를 부르자 쓰기를 시도하지 않았는데도 응답에 `Audit write failed — action not recorded`가 붙었다 [7].
`_write_entry`는 `OSError`만 처리하고 그 밖의 예외는 도구 함수로 올린다 [1].

### 근거

[1] `_write_entry`는 덧붙이기 모드로 열어 쓰고 `OSError`가 나면 경고를 남기고 거짓을 돌려준다.

```python
        try:
            log_file = audit_dir / f"{self.mcp_name}.jsonl"
            # Non-blocking, and only into a regular file: a FIFO there would
            # wait for a reader, or hand the entry to one
            fd = os.open(
                log_file, os.O_WRONLY | os.O_APPEND | os.O_CREAT | os.O_NONBLOCK, 0o666
            )
            try:  # the descriptor is closed on any failure before fdopen owns it
                if not stat.S_ISREG(os.fstat(fd).st_mode):
                    raise OSError(f"{log_file} is not a regular file")
                f = os.fdopen(fd, "a", encoding="utf-8")
            except BaseException:
                os.close(fd)
                raise
            with f:
                f.write(json.dumps(entry, default=str) + "\n")
                f.flush()
                os.fsync(f.fileno())
            return True
        except OSError as e:
            logger.warning(
                "Failed to write audit entry for audit_id=%s tool=%s: %s "
                "(this audit_id was NOT recorded to the audit trail)",
                entry.get("audit_id"),
                entry.get("tool"),
                e,
            )
            return False
```
