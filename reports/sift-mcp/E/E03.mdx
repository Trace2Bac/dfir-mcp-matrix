# E03 원본 변경 방지

### E03.02 서버 코드의 원본 쓰기 제한

**구현.** 이 방식은 `sift-mcp`의 `run_command`가 실행 전에 하는 대상 검사와 서버 코드가 증거를 해시할 때 여는 방식에 적용된다 [1][2][3].
`run_command`는 `rm`, `shred`, `unlink`, `truncate`, `tee`, `mv`, `cp`, `install`, `ln`의 대상이 사건 `evidence/` 아래의 기존 파일이나 비어 있지 않은 `evidence/` 폴더이면 실행하지 않는다 [2].
`mv`는 증거 파일을 옮겨 내는 경우도 거부한다 [2].
`rm`은 사건 폴더 전체와 `/cases`, `/evidence` 아래를 대상으로 하면 실행하지 않는다 [3].
`evidence/`의 파일을 `rm`, `truncate`, `cp`로 지우거나 덮어쓰는 명령은 거부되었다 [4].
`evidence/`에 새 파일을 복사해 넣는 명령은 실행되었다 [4].
증거를 등록하거나 검증하며 해시할 때는 파일을 읽기 전용으로 연다 [5][6].

원본을 지키는 장치가 없는 다른 경로도 있다.
모델은 `run_command`로 `mount`, `ewfmount`, `losetup` 같은 마운트 도구를 원하는 옵션으로 실행할 수 있고 서버는 마운트된 지점을 호출 기록에 적기만 한다 [7].
사용자 CLI `vhir evidence lock`은 증거 폴더의 파일을 444, 폴더를 555로 바꾸지만 서버는 이 명령을 실행하지 않는다 [8].
Claude Code 설정의 셸 명령 검사 훅 `case-data-guard.sh`는 같은 사건 기록 목록을 클라이언트 쪽에서 검사한다 [9].

**한계.** 출력 경로 검사는 출력 인자가 열린 사건 폴더 안이면 통과시키고 `evidence/`도 사건 폴더 안이다 [10].
도구 설명은 분석 도구의 출력 옵션, `bash -c`, `python -c`, `dd`를 이 검사가 보지 않는다고 적는다 [1].
등록한 증거 파일을 `sort`의 출력 옵션 `-o` 값으로 준 명령은 거부되지 않았고 그 뒤 `evidence_verify`는 그 파일을 `MODIFIED`로 돌려주었다 [4].
검사 함수의 주석은 사건 폴더 밖 파일을 가리키는 증거 링크와 값을 받는 감싸기 명령 옵션도 검사하지 않는다고 적는다 [2].
검사는 등록 목록이 아니라 `evidence/` 폴더 이름으로 원본을 정하므로 사건 폴더 안 다른 폴더에 등록한 증거는 `truncate` 같은 명령으로 바꿀 수 있다 [2][11].
사건의 다른 폴더에 등록한 증거를 `truncate`로 비우는 명령은 실행되었고 `evidence_verify`는 그 파일을 `MODIFIED`로 돌려주었다 [12].

### E03.03 외부 도구·플랫폼에 위임

**구현.** 이 방식은 `run_command`로 실행하는 분석 도구가 증거를 읽는 경로에 적용된다 [1][13].
`run_command`는 모델이 만든 명령 목록의 실행 파일만 정해 둔 경로에서 찾아 바꾸고 나머지 인자는 검사를 통과하면 그대로 넘긴다 [13].
Sleuth Kit의 `fls`, `icat`, `mmls`처럼 이미지를 읽는 도구에서 원본을 지키는 것은 그 도구가 이미지를 읽기 모드로 연다는 동작이다 [14].
Sleuth Kit 4.11.1은 원시 이미지를 `O_RDONLY`로, EWF 이미지를 libewf의 `LIBEWF_OPEN_READ`로 연다 [14].

**한계.** Volatility 3, Zimmerman 도구, Plaso, RegRipper, Hayabusa, `ewfmount`가 원본을 읽기 모드로 여는지는 서버 개요의 버전 기준 소스로 확인하지 못해 실제 보호 미확인이다 [13].
마운트 도구는 모델이 준 옵션으로 실행되므로 읽기 전용 마운트인지는 그 호출의 인자에 따른다 [7][13].

```python
def _harms_under(real: str, root: str, lead: list[str], new_ok: bool) -> bool:
    if real == "/" or root.startswith(real.rstrip("/") + "/"):
        return True  # an ancestor of a protected root
    if real != root and not real.startswith(root + "/"):
        return False
    parts = lead + [x for x in real[len(root) :].split("/") if x]
    if not parts:  # the cases root
        return True
    if len(parts) == 1:  # a case root, while it holds anything
        return os.path.isdir(real) and bool(os.listdir(real))
    top = parts[1]
    if top == "audit" or (top in _CASE_RECORDS and len(parts) == 2):
        return True
    if top == "evidence":
        if len(parts) == 2:  # evidence/ itself, while it holds anything
            return os.path.isdir(real) and bool(os.listdir(real))
        return os.path.lexists(real) or not new_ok
    return False
```

```python
def hash_file(path) -> HashResult:
    """The SHA-256 of the whole file, however large. The file is opened
    non-blocking and checked before any read, so a FIFO never blocks."""
    fd = os.open(str(path), os.O_RDONLY | os.O_NONBLOCK)
    st = os.fstat(fd)
    if not stat.S_ISREG(st.st_mode):
        os.close(fd)
        raise NotRegularFile(f"{path} is not a regular file")
    with os.fdopen(fd, "rb") as f:
        h, read = hashlib.sha256(), 0
        while chunk := f.read(_CHUNK):
            h.update(chunk)
            read += len(chunk)

    if fields or read != st.st_size:
        raise FileChanged(path, fields or ["size"])
    return HashResult(str(path), h.hexdigest(), st.st_size, st.st_dev, st.st_ino,
```

```python
def validate_output_path(path: str, base: str | None = None) -> str:
    """Validate that an output path is safe to write to.

    Stricter than validate_input_path. When VHIR_CASE_DIR is set, the
    output path must be inside the case directory. When not set, only
    /tmp and the current working directory are allowed.

    Case-dir containment is checked first so that case directories
    under /home are allowed.
    """
    resolved = str(Path(_at(path, base)).resolve())

    # Case-dir containment: if inside case dir, it's allowed
    case_dir = resolve_case_dir()
    if case_dir:
        case_resolved = str(Path(case_dir).resolve())
        if resolved == case_resolved or resolved.startswith(case_resolved + "/"):
            return resolved
        raise ValueError(
            f"Output path '{path}' resolves to '{resolved}' which is "
            f"outside the case directory '{case_resolved}'"
```
