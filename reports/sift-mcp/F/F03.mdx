# F03 서버 안 모델 입력 구성

### 비적용

**판단.** 게이트웨이와 백엔드 일곱 개, 검토 포털, 서버가 불러 쓰는 `vhir-cli` 모듈은 처리 중에 언어 모델을 부르지 않는다 [1][2].
설치에 쓰는 잠금 파일 `deps/vhir.lock`에는 모델 API 클라이언트 패키지가 없다 [1].
기준 커밋의 `packages/` 아래 Python 파일과 `vhir-cli`의 `src/`에서 `anthropic`, `openai`, `create_message`, `messages.create`, `chat.completions`, `sampling`을 찾았고 서버 코드에서는 나오지 않았다 [2].
MCP sampling으로 클라이언트 모델에게 생성을 요청하는 코드도 나오지 않았다 [2].
`rag-mcp`는 검색할 때 허용 목록에 있는 문장 임베딩 모델로 질의를 벡터로 바꾸고 가까운 문서를 찾는다 [3].
이 모델은 질의 벡터를 만들 뿐 발견사항, 판단, 요약, 계획을 만들지 않는다 [3].
발견사항의 반론 검토는 클라이언트 쪽 별도 에이전트가 하고 서버는 그 결과 `challenged`를 받는다 [4].
`report-mcp`의 보고서 서술은 클라이언트 모델이 `generate_report`의 자료로 써서 `save_report`로 넘긴다 [5].

```python
            # The server appends the verification block; the content can't
            # replace it (the saved file is still writable on this box). Its
            # fence is longer than any backtick run inside it, so no text in
            # the block can end it early. How a viewer renders the report
            # still depends on the content above it; the raw file and
            # `vhir review --findings --verify` are authoritative.
            view = approved_view(case_dir)
            # every IOC of the case is written defanged, the block too: it's a
            # display copy, and nothing reads its text back
            iocs = _report_iocs(case_dir, view)
            content = _defang_iocs(content, iocs)
            block = [
                _defang_iocs(line, iocs)
                for line in verification_block(view) + [""] + provenance_block(view)
            ]
            runs = [len(r) for r in re.findall(r"`+", "\n".join(block))]
            fence = "`" * max(3, max(runs, default=0) + 1)
            saved = (
                content.rstrip("\n")
                + f"\n\n{fence}\n"
                + "\n".join(block)
                + f"\n{fence}\n"
            )
            _atomic_write(report_path, saved)
```
