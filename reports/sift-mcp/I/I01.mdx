# I01 외부 연동 대상 관리

### I01.01 명시적 설정으로 활성화

**구현.** 이 방식은 `opencti-mcp`의 MISP 조회, 게이트웨이의 HTTP 백엔드 연결, `case-mcp`가 부르는 `wintools-mcp` 사건 알림에 적용된다 [1][2][3].
`opencti-mcp`는 환경변수 `THREATINTEL_PROVIDERS`에 적힌 조회처만 만들고 이 값이 없으면 OpenCTI 하나만 쓴다 [1].
그래서 MISP는 사용자가 `THREATINTEL_PROVIDERS`에 `misp`를 적어야 `lookup_ioc`의 조회처가 된다 [1][4].
게이트웨이는 설정 파일 `gateway.yaml`의 `backends`에서 `type: http`이고 `enabled`가 거짓이 아닌 항목만 연결한다 [2][5].
설정 예시는 원격 HTTP 백엔드 4개를 모두 `enabled: false`로 둔다 [5].
`case-mcp`의 `case_init`·`case_activate`는 `~/.vhir/samba.yaml`에 공유 이름이 있을 때만 `vhir_cli`의 `notify_wintools_case_activated`를 부른다 [3][6].
이 함수는 `gateway.yaml`에 `wintools-mcp`의 주소와 토큰이 없으면 연결하지 않는다 [7].
게이트웨이는 시작할 때 연결된 HTTP 백엔드마다, 주기 점검에서는 `wintools-mcp`에만 활성 사건 ID를 보낸다 [8][9].

### I01.02 자격증명 존재로 활성화

**구현.** 이 방식은 `opencti-mcp`의 OpenCTI 조회와 MISP 조회에 적용된다 [10][4].
OpenCTI는 조회처 목록의 기본값이지만 토큰을 읽지 못하면 설정이 없는 것으로 처리하고 연결하지 않는다 [10][11].
그때 `lookup_ioc`는 OpenCTI를 `UNAVAILABLE`로 돌려주고 OpenCTI 전용 도구 7개는 `opencti_not_configured` 오류를 돌려준다 [12][13].
토큰 없이 `opencti-mcp`를 게이트웨이에 붙여 `lookup_ioc`를 부르자 연결 없이 `UNAVAILABLE`과 토큰이 없다는 이유를 돌려줬다 [14].
토큰이 있으면 시작할 때 연결을 확인하는 기능 `FF_STARTUP_VALIDATION`이 기본으로 켜져 있어 첫 호출 전에도 OpenCTI에 연결한다 [15].
MISP는 `MISP_URL`과 `MISP_KEY`가 모두 있어야 조회처가 되고 하나라도 없으면 그 이유를 담은 `UNAVAILABLE` 조회처로 남는다 [4][16].

### I01.06 설정으로 목적지 지정

**구현.** 이 방식은 서버 코드가 여는 외부 연결 모두에 적용된다 [10][4][2][7].
OpenCTI 주소는 환경변수 `OPENCTI_URL`에서 읽고 없으면 `http://localhost:8080`을 쓴다 [10].
서버는 주소의 스킴이 `http`·`https`이고 호스트가 있는지만 검사하고 호스트를 목록과 대조하지 않는다 [17].
MISP 주소는 `MISP_URL`에서 읽고 같은 스킴 검사만 한다 [4].
게이트웨이의 HTTP 백엔드 주소는 `gateway.yaml`의 `url`이고 설정 파일의 `${VAR}`는 환경변수 값으로 바꾼다 [2][18].
`wintools-mcp`는 일회용 가입 코드를 가진 Windows 쪽 프로그램이 가입 API로 보낸 주소와 토큰을 게이트웨이가 `gateway.yaml`에 저장해 붙인다 [19].
`case-mcp`의 사건 알림은 `gateway.yaml`의 `wintools-mcp` 주소에서 경로만 `/cases/activate`로 바꿔 보낸다 [7].
어느 도구도 접속할 호스트나 URL을 인자로 받지 않는다 [12].

인증서 검증은 연결마다 다르다.
- OpenCTI는 `OPENCTI_SSL_VERIFY`, MISP는 `MISP_SSL_VERIFY`로 끌 수 있고 기본은 검증한다 [20][4].
- 게이트웨이의 HTTP 백엔드 연결은 `tls_cert`가 있으면 그 인증서로만 검증한다 [21].
- 게이트웨이가 HTTP 백엔드에 사건 ID를 보내는 요청은 `verify=False`로 보낸다 [8].

def create() -> MispAdapter:
    url = os.getenv("MISP_URL", "").strip().rstrip("/")
    key = os.getenv("MISP_KEY", "").strip()
    if not url:
        raise ProviderConfigError("MISP_URL is not set")
    parsed = urlparse(url)
    if parsed.scheme not in ("http", "https") or not parsed.netloc:
        raise ProviderConfigError(f"MISP_URL is not an http(s) URL: {url}")
    if not key:
        raise ProviderConfigError("MISP_KEY is not set")
    raw_timeout = os.getenv("MISP_TIMEOUT", "30")
    try:
        timeout = float(raw_timeout)
    except ValueError as e:
        raise ProviderConfigError(f"MISP_TIMEOUT is not a number: {raw_timeout}") from e
    if timeout <= 0:
        raise ProviderConfigError(f"MISP_TIMEOUT must be positive: {raw_timeout}")
    return MispAdapter(url, key, _verify(os.getenv("MISP_SSL_VERIFY", "true")), timeout)
```

def _wintools_configured() -> bool:
    """Check if Samba sharing is set up (samba.yaml exists with share_name)."""
    import yaml

    p = Path.home() / ".vhir" / "samba.yaml"
    if not p.is_file():
        return False
    try:
        doc = yaml.safe_load(p.read_text())
        return bool(doc and doc.get("share_name"))
    except Exception:
        return False

        """Send case activation to an HTTP backend after reconnect."""
        from sift_gateway.backends.http_backend import HttpMCPBackend

        if not isinstance(backend, HttpMCPBackend):
            return

            import httpx

            async with httpx.AsyncClient(verify=False) as client:

                    json={"case_id": active_case},

            else:
                logger.info(

def _validate_url(url: str) -> str:
    """Validate and normalize OpenCTI URL.

    Security: Prevents SSRF by restricting URL schemes.
    """
    url = url.strip().rstrip("/")

    if not url:
        raise ConfigurationError("OpenCTI URL cannot be empty")

    parsed = urlparse(url)

    # Only allow http/https
    if parsed.scheme not in ("http", "https"):
        raise ConfigurationError(
            f"Invalid URL scheme: {parsed.scheme}. Use http or https."
        )

    # Must have a host
    if not parsed.netloc:
        raise ConfigurationError("Invalid URL: missing host")
```
