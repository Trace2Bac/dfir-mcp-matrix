# I02 분석 도구 통신 차단

### 미구현

**판단.** 서버가 실행하는 분석 도구와 부르는 라이브러리의 통신을 끊거나 끄는 장치가 서버 코드와 저장소의 실행 구성에 없다.

`sift-mcp`의 `run_command`는 모델이 준 인자 배열을 셸 없이 하위 프로세스로 실행한다 [1][2].
서버는 실행 파일 경로를 바꾸고 인자를 검사하지만 오프라인 옵션이나 이름 해석을 끄는 옵션을 더하지 않는다 [2][3].
하위 프로세스는 서버 프로세스와 같은 네트워크에서 실행되고 서버는 네트워크를 나누는 설정을 하지 않는다 [1].
같은 저장소의 Claude Code 설정은 sandbox를 켜고 설치 스크립트는 이 sandbox가 클라이언트의 Bash 명령을 분리된 네트워크에서 실행한다고 적는다 [4].
게이트웨이는 systemd 사용자 서비스로 실행되므로 게이트웨이와 백엔드가 실행하는 분석 도구에는 이 sandbox가 적용되지 않는다 [4].
`run_command`의 도구 설명은 `curl`·`wget`도 실행할 수 있다고 적는다 [5].

`rag-mcp`는 색인을 처음 쓰는 호출에서 sentence-transformers로 임베딩 모델을 이름으로 불러온다 [6].
모델 이름은 코드에 적은 허용 목록 5개 가운데 하나여야 한다 [7].
sentence-transformers 6.1.0의 `SentenceTransformer`는 `local_files_only`가 기본으로 거짓이고 서버는 이 값을 넘기지 않는다 [8][6].
게이트웨이 설정 예시와 설치 스크립트가 만드는 설정은 `forensic-rag-mcp`에 내려받기를 끄는 환경변수를 주지 않는다 [9][10].
설치 스크립트 `setup-sift.sh`가 만드는 `gateway.yaml`과 Lite 구성의 클라이언트 설정 예시는 `rag-mcp`에 `ANONYMIZED_TELEMETRY`를 `False`로 넘긴다 [10][11].
chromadb 1.5.9의 제품 사용 통계 클라이언트 `Posthog.capture`는 아무것도 보내지 않는 함수라 이 값과 관계없이 통계 전송은 없다 [12].
저장소의 설정 예시 `gateway.yaml.example`에는 이 값이 없다 [9].

`windows-triage-mcp`는 내려받아 둔 SQLite 정상 기준 DB만 읽고 외부 분석 도구를 실행하지 않는다 [13].

    def load(self) -> None:
        """Load the embedding model and ChromaDB index into memory."""
        with self._lock:
            if self._loaded:
                return

            # Security: validate model name against allowlist
            if self.model_name not in ALLOWED_MODELS:
                raise ValueError(
                    f"Model '{self.model_name}' is not allowed. "
                    "Use one of the approved embedding models."
                )

            logger.info(f"Loading embedding model: {self.model_name}")

        entry['env']['VHIR_CASES_DIR'] = '\${VHIR_CASES_DIR}'
    if name == "threatintel-mcp":
