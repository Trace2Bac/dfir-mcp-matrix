# D05 파생물 저장 실패 처리

### D05.01 오류·부분 완료 표시

**구현.** 이 방식은 `forensic-mcp`의 발견사항·타임라인 기록, `report-mcp`의 `save_report`, `case-mcp`의 `backup_case`, 검토 포털 `case-dashboard`의 서명 커밋에 적용된다 [1][2][3][4].
`forensic-mcp`의 기록 도구는 저장 중 난 예외를 처리해 `error` 필드에 예외 문구를 담은 응답을 돌려준다 [1].
`record_finding`은 `findings.json`을 먼저 저장하고 자동 타임라인 사건과 IOC 기록은 그 뒤에 저장한다 [5].
뒤의 두 저장이 실패하면 발견사항은 남기고 응답의 `warning`에 `Timeline auto-creation failed`나 `IOC processing failed`를 싣는다 [5].
`save_report`는 쓰기에서 난 `OSError`를 `error` 응답으로 돌려준다 [2].
`backup_case`도 폴더를 만들거나 파일을 복사하다 난 `OSError`를 `error` 응답으로 돌려준다 [3].
`forensic-mcp`와 `report-mcp`는 임시 파일에 다 쓴 뒤 이름을 바꾸고 실패하면 임시 파일을 지우므로 정한 이름의 파일이 반쯤 쓰인 채 남지 않는다 [6][7].
검토 포털은 서명 커밋에서 사건 자료를 끝내 저장하지 못하면 `SAVE_FAILED` 오류로 응답한다 [8].
사건 폴더를 읽기 전용으로 바꾸고 `record_finding`을, `reports/`를 읽기 전용으로 바꾸고 `save_report`를, 읽기 전용 목적지로 `backup_case`를 부르자 셋 다 `Permission denied`를 담은 `error` 응답이 왔다 [9].

**한계.** 자동 타임라인 사건 저장이 실패해도 이미 저장한 발견사항에는 그 사건의 ID `timeline_event_id`가 남는다 [5].
`backup_case`가 복사 도중 실패하면 `.incomplete` 이름의 폴더와 진행 중 표시 파일 `.backup-in-progress`가 목적지에 남고 서버는 지우지 않는다 [10].

### D05.03 알림 없이 계속

**구현.** 이 방식은 `sift-mcp`의 `run_command`가 보관하는 표준 출력·표준 오류와 작업 폴더, 게이트웨이의 참조 응답 사본에 적용된다 [11][12][13].
`run_command`는 표준 출력이나 표준 오류 파일을 쓰다 난 `OSError`를 경고 로그에만 남기고 성공 응답을 돌려준다 [11].
이때 응답에는 `full_output_path`가 없고 호출 기록 항목의 `output_file`은 빈 값이며 저장 실패를 알리는 필드는 없다 [11][14].
분석 도구가 작업 폴더의 쓰기 권한을 없애게 하자 응답은 `success: true`, `full_output_path: null`, `warning: null`이었고 폴더에는 도구가 쓴 파일만 남았다 [15].
작업 폴더를 만들지 못하면 경고 로그만 남기고 서버 프로세스의 현재 폴더에서 분석 도구를 실행한다 [12].
게이트웨이는 참조 응답 사본을 쓰거나 그 항목을 기록하다 난 예외를 경고 로그에만 남기고 조회 응답은 그대로 돌려준다 [13].
`extractions/`를 읽기 전용으로 두고 참조 기록 함수를 부르자 `None`을 돌려주었고 사본은 생기지 않았다 [16].

### D05.04 재시도·대체 저장

**구현.** 이 방식은 검토 포털 `case-dashboard`의 서명 커밋이 사건 자료를 저장할 때 적용된다 [4].
검토 포털은 서명한 결정을 원장에 쓴 뒤 `findings.json`·`timeline.json`·`iocs.json` 저장이 실패하면 한 번 다시 저장한다 [4].
다시 저장해도 실패하면 결정은 기록되었고 사건 자료는 저장되지 않았다는 문구와 다시 커밋할 항목 ID를 `SAVE_FAILED` 오류에 싣는다 [8].

```python
def _atomic_write(path: Path, content: str) -> None:
    """Write file atomically via temp file + rename to prevent data loss on crash."""
    fd, tmp_path = tempfile.mkstemp(dir=path.parent, suffix=".tmp")
    try:
        with os.fdopen(fd, "w") as f:
            f.write(content)
            f.flush()
            os.fsync(f.fileno())
        os.replace(tmp_path, path)
    except BaseException:
        try:
            os.unlink(tmp_path)
        except OSError:
            pass
        raise
```
