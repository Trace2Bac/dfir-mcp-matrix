# D03 파생물 무결성 검증

### D03.01 기준값 자동 계산

**구현.** 이 방식은 `sift-mcp`의 `run_command`가 보관한 표준 출력과 출력 파일, `case-mcp`의 `log_external_action`이 적은 출력 파일, 게이트웨이의 참조 응답 사본, `backup_case`의 복사본, 검토 포털 `case-dashboard`가 승인을 커밋한 발견사항·타임라인 사건에 적용된다 [1][2][3][4][5].
도구 출력과 사본의 기준값은 키를 쓰지 않는 SHA-256이다 [1][2][3][4].
`run_command`는 분석 도구가 쓴 표준 출력 바이트를 메모리에서 해시해 `output_sha256`으로 응답과 호출 기록 항목의 `result_summary`에 남긴다 [1][6].
출력이 `max_output_bytes`에서 잘리면 읽은 앞부분의 해시이고 `output_sha256_scope`를 `prefix`로 적는다 [1].
작업 폴더의 파일과 출력 인자 경로에서 새로 생기거나 바뀐 파일은 파일 전체의 SHA-256, 크기, inode, 수정 시각을 호출 기록 항목의 `outputs`에 남긴다 [2][7].
한 호출에서 해시할 크기의 합이 1 GB를 넘으면 나머지 파일은 백그라운드 작업이 해시해 `audit/file-identity.jsonl`의 `hash_complete` 항목에 남긴다 [2][8].
해시하는 동안 파일의 장치·inode·크기·수정 시각·변경 시각이 바뀌면 해시를 버리고 실패로 적는다 [9].
`log_external_action`은 모델이 알린 출력 파일을 같은 함수로 해시해 `outputs`에 남긴다 [10].
게이트웨이는 참조 응답 사본을 쓸 때 쓴 바이트의 SHA-256을 그 조회 항목의 `reference.response.sha256`에 남긴다 [3].
`backup_case`는 복사하며 읽은 바이트로 파일마다 SHA-256을 계산해 `backup-manifest.json`에 적는다 [4].
검토 포털은 승인 결정을 커밋할 때 그 항목의 서명 대상 내용 `content_snapshot`과 그 SHA-256 `content_sha256`을 원장 줄에 담는다 [5].
검토자의 브라우저가 검토자 키로 원장 줄에 서명하고 서버는 원장에 쓰기 전에 서명을 검사한다 [11].
모델이 해시 도구를 부르지 않아도 서버가 계산한다.
`run_command`와 참조 사본의 기준값은 대조 대상과 같은 사건 폴더의 호출 기록 파일에 들어간다 [6][3].
시험용 실행 파일로 `run_command`를 부르자 호출 기록 항목에 표준 출력의 SHA-256과 도구가 쓴 파일의 SHA-256·크기·inode·수정 시각이 남았다 [12].

표준 오류 파일의 해시는 호출 기록 항목에 들어가지 않는다 [6].
`save_report`가 쓴 보고서 파일에는 기준값이 없다 [13].

**한계.** 표준 출력 파일 쓰기가 실패해도 `output_sha256`은 기록되고 `output_file`은 빈 값이 된다 [14].
활성 사건이 없으면 1 GB를 넘는 출력 파일은 해시하지 않는다 [8].

### D03.02 도구 호출 중 자동 검증

**구현.** 이 방식은 `forensic-mcp`의 `record_finding`과 승인 항목을 읽는 `report-mcp`의 `generate_report`·`save_report`, `forensic-mcp`의 `get_findings`·`get_timeline`, `case-mcp`의 `case_status`·`export_bundle`에 적용된다 [15][16][17].
`record_finding`은 인용 `artifacts`마다 인용 줄이 인용한 호출의 출력에 있는지 찾으며 그 출력을 기준값과 대조한다 [15][18].
`run_command` 호출이면 보관한 표준 출력을 먼저 읽고 줄이 남으면 `outputs`의 파일을 차례로 읽는다 [18].
파일은 1 MiB씩 읽으며 해시하고 다 읽은 해시가 호출 기록의 SHA-256과 같을 때만 그 파일에서 찾은 줄을 인정한다 [19].
기록된 해시가 `pending:<job>`이면 그 작업의 `hash_complete` 값으로 대조한다 [18].
게이트웨이의 참조 응답 사본은 파일 전체를 읽어 기록된 SHA-256과 같을 때만 그 값을 쓴다 [20].
모델이나 사용자가 검증을 따로 요청하지 않아도 발견사항을 기록할 때마다 대조한다.
인용한 호출의 보관 표준 출력 끝에 한 줄을 덧붙인 뒤 같은 줄을 인용해 발견사항을 기록하자 대조가 맞지 않아 `CITED-UNVERIFIED`로 저장되었다 [21].
승인 항목을 읽는 도구는 호출마다 `vhir_cli`의 `approved_view`로 승인한 발견사항·타임라인 사건의 현재 내용 해시를 원장 줄의 `content_sha256`과 대조한다 [16][22][23].

**한계.** 인용 줄을 모두 찾으면 남은 출력 파일은 읽지 않으므로 그 파일이 바뀌었는지는 대조하지 않는다 [18].
64 MiB를 넘는 출력 파일은 읽지 않고 건너뛴 이유만 남긴다 [18][19].
`artifacts` 없이 `audit_ids`나 `supporting_commands`만 준 발견사항은 대조하지 않는다 [15].
발견사항을 기록한 뒤에는 인용한 출력을 다시 대조하지 않는다.
`generate_report`와 `save_report`는 저장된 출처 판정을 옮겨 적고 인용한 출력 파일을 다시 해시하지 않는다 [16].
`backup-manifest.json`의 해시를 대조하는 MCP 도구는 없고 사용자 CLI `vhir backup --verify`가 대조한다 [24].

### D03.04 불일치 시 중단·경고

**구현.** 이 방식은 `record_finding`의 대조 결과와 승인 항목을 읽는 도구의 대조 결과에 적용된다 [15][16].
대조가 어긋난 파일에서는 인용 줄을 찾지 못한 것으로 보아 그 인용을 `CITED-UNVERIFIED`로 판정한다 [19][25].
발견사항은 거부하지 않고 DRAFT로 저장하며 응답의 `message`에 판정과 이유를 싣는다 [26].
판정과 이유는 발견사항의 `provenance_grade`·`provenance_reason`·`provenance_break`에 남는다 [15].
발견사항 전체의 `provenance_grade`는 참조 자료 인용을 뺀 인용 판정 가운데 가장 낮은 값이다 [27].
승인 뒤 `save_report`가 덧붙이는 출처 목록은 이 판정을 그대로 적는다 [28].
시험에서 응답의 `message`는 "Finding staged as CITED-UNVERIFIED"로 시작했고 같은 판정이 `findings.json`에 남았다 [21].
승인 항목의 내용 해시가 원장 줄과 다르면 `verify_case`는 그 항목을 `ALTERED_AFTER_APPROVAL`로 판정한다 [22].
`generate_report`는 그 항목을 보고 자료에서 빼고 `integrity_warning`을 싣는다 [16][29].
`save_report`가 붙이는 검증 블록은 그 항목의 ID와 상태를 싣고 출처 블록은 그 항목을 싣지 않는다 [30].
조회 도구는 그 항목의 `approval_verification`에 상태를 적고 응답의 `warning`에 항목 ID를 싣는다 [23].
승인한 뒤 관찰을 바꾼 발견사항은 보고 자료에서 빠지고 `not_verified`에 `ALTERED_AFTER_APPROVAL`로 실렸다 [31].
같은 사건에서 `get_findings`는 그 발견사항을 `warning`에 적었다 [31].

**한계.** 판정 이유는 인용 줄이 출력에 없다고만 적고 출력이 기록 뒤에 바뀐 경우와 인용 줄이 처음부터 없던 경우를 구별하지 않는다 [25][21].
`run_command`가 같은 출력 인자 경로에 다시 쓰면 앞 호출이 기록한 파일이 바뀐다 [32].
그 앞 호출을 인용하자 같은 이유로 `CITED-UNVERIFIED`가 되었다 [32].

def output_records(case_dir, paths, requested_by: str = "") -> list[dict]:
    """The files a call wrote, each hashed with its size, inode and mtime:
    in the call while their summed sizes stay within the inline limit, the
    rest in one background job (``pending:<job_id>``)."""
    paths = [str(p) for p in paths]
    batch = fi.hash_files_for_call(
        [p for p in paths if os.path.isfile(p)],  # a missing one: nothing to hash
        case_dir=case_dir or "",
        requested_by=requested_by,
        inline_limit=fi.INLINE_LIMIT,  # read now: the limit in force
    )
    recs = []
    for p in paths:
        rec = place(p)
        h = batch.done.get(p)
        if h is not None:
            rec.update(
                sha256=h.sha256, size=h.size, st_ino=h.st_ino, mtime_ns=h.mtime_ns
            )
        else:
            if batch.job_id and p in batch.pending:
                rec["sha256"] = f"pending:{batch.job_id}"
            try:
                st = os.stat(p)
                rec.update(size=st.st_size, st_ino=st.st_ino, mtime_ns=st.st_mtime_ns)
            except OSError:
                pass
        recs.append(rec)
    return recs
```

def hash_file(path) -> HashResult:
    """The SHA-256 of the whole file, however large. The file is opened
    non-blocking and checked before any read, so a FIFO never blocks."""
    fd = os.open(str(path), os.O_RDONLY | os.O_NONBLOCK)
    st = os.fstat(fd)
    if not stat.S_ISREG(st.st_mode):
        os.close(fd)
        raise NotRegularFile(f"{path} is not a regular file")
    with os.fdopen(fd, "rb") as f:
        h, read = hashlib.sha256(), 0
        while chunk := f.read(_CHUNK):
            h.update(chunk)
            read += len(chunk)
        # the bytes hashed are the file's only if nothing changed while they were read
        fields = _changed(_stat_key(st), _stat_key(os.fstat(f.fileno())))
    if fields or read != st.st_size:
        raise FileChanged(path, fields or ["size"])
    return HashResult(str(path), h.hexdigest(), st.st_size, st.st_dev, st.st_ino,
                      st.st_mtime_ns, st.st_ctime_ns)  # fmt: skip
```

def _run_missing(case: Case, e: dict, quote: list[str]) -> tuple[list[str], list[str]]:
    """The quoted lines a run's saved output and recorded output files don't
    hold, each file only while it has its recorded hash; and the files too
    large to check. The saved stdout is searched first, then each output file
    (up to the size cap) only while lines are still missing."""
    rs = e.get("result_summary") if isinstance(e.get("result_summary"), dict) else {}
    missing, skipped = list(quote), []
    sources = [
        (relocated(case, e, rs.get("output_file")), rs.get("output_sha256"), None)
    ]
    sources += [(p, h, _QUOTE_FILE_CAP) for p, h in _outputs(case, e)]
    for path, sha256, cap in sources:
        if not missing:
            break
        if not path:
            continue
        if isinstance(sha256, str) and sha256.startswith("pending:"):
            sha256, got = _job(case, os.path.realpath(path), sha256.split(":", 1)[1])
            if not sha256:  # the job is still running or failed: not checkable yet
                skipped.append(got.reason)
                continue
        found, why = _found_in(path, sha256, missing, cap)
        if why:
            skipped.append(why)
        missing = [q for q in missing if q not in found]
    return missing, skipped

[19] 파일을 조각으로 읽으며 해시하고 기록된 해시와 같을 때만 찾은 줄을 돌려준다.

```python
def _found_in(path, sha256, lines: list[str], cap: int | None) -> tuple[set, str]:
    """Which quoted lines a saved file holds, read in bounded chunks with an
    overlap (whitespace normalized across them), the file counted only when it
    still has its recorded SHA-256. Returns (found, why skipped): a file over
    `cap` isn't read at all, and says so."""
    try:
        size = os.path.getsize(path)
    except (OSError, TypeError):
        return set(), ""
    if cap is not None and size > cap:
        return set(), f"output too large to check ({path})"
    if not sha256:
        return set(), ""
    digest = hashlib.sha256()
    decode = codecs.getincrementaldecoder("utf-8")(errors="replace").decode
    keep = max((len(q) for q in lines), default=0)
    found, carry = set(), ""
    try:
        with open_regular(path) as f:
            for chunk in iter(lambda: f.read(_CHUNK), b""):
                digest.update(chunk)
                text = re.sub(r"\s+", " ", decode(chunk))
                if carry.endswith(" ") and text.startswith(" "):
                    text = text[1:]
                window = carry + text
                found |= {q for q in lines if q in window}
                carry = window[-keep:] if keep else ""
    except (OSError, NotRegularFile):
        return set(), ""
    return (found if digest.hexdigest() == sha256 else set()), ""
```
