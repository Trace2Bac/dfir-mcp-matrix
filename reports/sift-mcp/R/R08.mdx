# R08 시간값 처리

### R08.01 시간 변환 전 값 유지

**구현.** 이 방식은 `sift-mcp`의 `run_command`와 `opencti-mcp`의 조회 도구에 적용된다 [1][2][3].
`run_command`는 분석 도구가 출력한 시각 문자열을 바꾸지 않고 `stdout`에 싣거나 CSV·JSON·텍스트로 파싱한 값 그대로 싣는다 [1].
서버는 분석 도구를 실행할 때 시간대 환경변수나 시각 형식 인자를 더하지 않으므로 도구가 정한 형식이 그대로 실린다 [4].
(실행 확인) `TimeCreated` 열에 `2024-03-01 12:00:01.1234567`을 쓰는 `EvtxECmd` 시험용 실행 파일의 응답에서 그 값이 `rows`에 그대로 실렸다 [5].
`opencti-mcp`의 검색 결과와 `get_entity`는 OpenCTI의 `created`·`modified`·`valid_from`·`published`·`first_seen` 같은 시각 값을 바꾸지 않고 싣는다 [2].
`lookup_ioc`는 플랫폼 레코드의 시각을 그대로 싣고 최상위 `created`에는 철회되지 않은 OpenCTI 일치 레코드의 `created` 문자열 가운데 문자열 비교로 가장 작은 것을 바꾸지 않고 싣는다 [3].
(실행 확인) `created`가 `2024-01-02T03:04:05.000Z`인 지표를 결과 항목 함수에 넘기고 같은 값의 레코드로 `lookup_ioc`를 부르자 두 응답 모두 같은 문자열을 실었다 [6].

`run_command` 응답의 `field_notes`는 FK에 적힌 아티팩트 시각 필드의 뜻을 싣는다 [7].
이 값은 응답에 실린 시각 값의 시간대나 정밀도 표시가 아니므로 시간대 표시 방식으로 보지 않는다 [7].
`lookup_ioc`의 `queried_at`과 `report-mcp`의 `generated_at` 같은 서버가 만든 시각은 UTC ISO 문자열이고 도구 출력의 시각이 아니다 [8].
