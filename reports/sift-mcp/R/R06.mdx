# R06 증거에서 추출한 민감정보 노출 제어

### 미구현

**판단.** 게이트웨이와 백엔드 7개는 증거에서 나온 비밀 값을 응답, 호출 기록, 보고서에 싣고 그 값을 가리거나 빼는 처리를 두지 않는다.

응답에서는 `sift-mcp`의 `run_command`가 실행한 도구의 출력을 그대로 돌려준다 [1].
표준 출력이 응답 예산 이하이면 `stdout`과 `stderr`를 그대로, 넘으면 파싱한 줄·행·항목을 값의 변경 없이 싣는다 [1][2].
`run_command`는 정해 둔 몇 가지 실행 파일만 막고 나머지 명령은 실행한다 [3].
서버가 읽는 FK의 Volatility 3 지식은 비밀번호 해시, LSA secret, 캐시된 도메인 자격증명을 꺼내는 플러그인 `windows.hashdump`·`windows.lsadump`·`windows.cachedump`를 도구의 기능으로 적는다 [4].
이 플러그인을 `run_command`로 실행한 출력도 위 경로로 응답에 실린다 [1][3].

기록에서는 `run_command`가 표준 출력 앞 500자를 호출 기록의 `stdout_head`에 남기고 사건 안의 실행은 표준 출력과 표준 오류 전체를 `extractions/` 아래 파일로 남긴다 [5][6].
두 곳 모두 쓰기 전에 값을 바꾸지 않는다 [5][6].

보고서에서는 `forensic-mcp`의 `record_finding`이 모델이 인용한 도구 출력을 발견사항의 `artifacts[].content`에 저장한다 [7].
`report-mcp`의 `generate_report`는 승인된 발견사항에서 정해 둔 내부 필드만 빼고 `artifacts`와 IOC를 보고서 자료에 싣는다 [8][9].

가림 코드는 `opencti-mcp`에 있지만 이 셀에 해당하지 않는다 [10].
`sanitize_for_log`는 키 이름에 `token`·`password`·`secret`·`key` 같은 낱말이 들어간 인자 값을 `***REDACTED***`로 바꾼다 [10].
이 함수는 입력 검사 실패를 서버 운영 로그에 적을 때만 쓰이고 응답, 호출 기록, 보고서에는 쓰이지 않는다 [10][11].
위협 정보 플랫폼의 오류 문구를 응답에 옮기지 않는 처리도 서버가 외부에 접속할 때 쓰는 토큰이 응답에 들어가지 않게 하는 처리다 [12].

```python
def _filter_sensitive(data: dict[str, Any]) -> dict[str, Any]:
    """Filter sensitive fields from data before logging."""
    result = {}
    for key, value in data.items():
        key_lower = key.lower()
        if any(s in key_lower for s in SENSITIVE_FIELDS):
            result[key] = "***REDACTED***"
        elif isinstance(value, dict):
            result[key] = _filter_sensitive(value)
        elif isinstance(value, str):
            result[key] = sanitize_for_log(value)
        else:
            result[key] = value
    return result
```

```python
def transport_reason(platform: str, error: BaseException) -> str:
    """Why `platform` couldn't be reached (refused, name not found, TLS)."""
    text = str(error)
    if "CERTIFICATE_VERIFY_FAILED" in text or "SSL" in text or "TLS" in text:
        return f"can't reach {platform}: its TLS certificate wasn't accepted"
    return f"can't reach {platform}"


def http_reason(platform: str, status: int, credential: str) -> str:
    """The reason for an HTTP answer other than 200."""
    if status in (401, 403):
        return f"{platform} refused the {credential} (HTTP {status})"
    if status == 429:
        return f"{platform} rate-limited the lookup: {RATE_LIMITED} (HTTP 429)"
    return f"{platform} answered HTTP {status}"
```
