---
id: T07
name: 도구 부재 처리
question: 필요한 외부 도구와 참조 자료가 있는지 확인하는 방식과 없거나 실패할 때 처리하고 알리는 방식을 분류합니다.
conditional: false
boundary: 입력 증거의 검사와 입력을 다른 입력으로 바꿔 실행하는 것은 T01에서, 도구 버전의 고정과 확인은 T05에서, 부속 입력이 고른 방법에 맞는지 대조하는 것은 P01에서 봅니다.
scope: 외부 도구나 참조 자료가 있어야 실행되는 호출이 적용 범위입니다. 외부 도구는 실행 파일, 모듈, 런타임이고 참조 자료는 룰, 맵, 심볼입니다. 서버가 작업을 맡기는 백엔드와 그 백엔드에 등록된 작업 정의(아티팩트 등)도 외부 도구와 참조 자료로 봅니다. 서버가 시작할 때 설정을 읽는 데만 쓰는 모듈은 포함하지 않습니다.
not_implemented: 외부 도구나 참조 자료를 쓰는데 실행 전에 있는지 확인하지 않고 없을 때 실행 오류를 가공 없이 넘기거나 성공처럼 돌려주는
  경우입니다.
not_applicable: 서버가 자기 코드 밖의 도구나 참조 자료를 쓰지 않는 경우입니다. 서버와 함께 배포되어 서버가 시작할 때 실리는 라이브러리만 쓰는 경우도 포함합니다.
details:
- id: T07.01
  name: 실행 전 도구·참조 자료 가용성 검사
  include: 서버가 실행 전에 실행 파일, 모듈, 런타임, 참조 자료가 있는지 확인하고 없으면 실행하지 않는 경우입니다. 확인 방법은 PATH
    탐색, 파일 존재 확인, import나 시험 실행 같은 것입니다.
- id: T07.02
  name: 대체 없는 실패 처리·도구 부재 알림
  include: 필요한 도구나 참조 자료가 없을 때, 서버가 다른 경로로 바꾸지 않고 도구가 없다는 사실을 응답으로 알리는 경우입니다. 알리는
    내용은 오류 종류나 설치 안내 같은 것입니다.
  exclude: 일반 실행 오류만 돌려주고 도구가 없다는 사실을 따로 구분하지 않는 경우는 해당하지 않습니다.
- id: T07.03
  name: 알림 없는 대체 실행
  include: 도구나 경로를 얻지 못하거나 실행이 실패하면 서버가 다른 프로그램이나 경로로 처리하고 대체한 사실을 응답에 알리지 않는 경우입니다.
    출처 이름이나 추출기 이름이 달라서 대체했다는 것을 짐작만 할 수 있는 경우도 해당합니다.
- id: T07.04
  name: 실행 환경별 경로 분기
  include: 서버가 실행 환경에 따라 정해 둔 순서로 실행 파일이나 경로를 고르는 경우입니다. 실행 환경은 설치 위치, 런타임, OS, 권한
    같은 것입니다.
  exclude: 앞 경로가 실패해서 다른 경로를 쓰는 경우는 해당하지 않습니다.
- id: T07.05
  name: 대체 사실을 응답·기록에 표시
  include: 대체 프로그램이나 경로로 실행했다는 사실과 원래 경로를 응답이나 기록의 필드로 밝히는 경우입니다.
  exclude: 서버 로그에만 남기는 경우는 해당하지 않습니다.
- id: T07.06
  name: 대체에 따른 검증·입력 범위 변화 표시
  include: 대체 경로로 바뀌면서 달라진 검증 수준, 입력 범위, 결과의 뜻을 응답이나 기록에 밝히는 경우입니다. 꺼낸 범위가 줄어든 것,
    다른 플러그인이라 결과의 의미가 다른 것이 그 예입니다.
- id: T07.07
  name: 실행 전 부재 도구 자동 설치
  include: 서버가 도구나 참조 자료를 처음 쓰기 전에 있는지 확인하고 없으면 정해 둔 출처(패키지 관리자, 내려받기 주소)에서 설치한 뒤 실행하는
    경우입니다.
- id: T07.08
  name: 일부 제외 후 계속 실행
  include: 필요한 도구나 참조 자료 가운데 일부가 없거나 쓸 수 없을 때 서버가 그 부분(단계, 출처, 룰 파일)만 빼고 나머지로 실행을 계속하는 경우입니다.
  exclude: 없는 부분을 다른 프로그램이나 경로로 대체하는 경우는 해당하지 않습니다. 하나라도 없으면 실행하지 않는 경우는 해당하지 않습니다.
- id: T07.09
  name: 별도 점검 도구로 가용성 알림
  include: 서버가 분석 호출과 별도인 도구에서 외부 도구나 참조 자료가 있는지 항목마다 확인해 그 결과를 돌려주는 경우입니다. 분석 도구의 실행은 그
    결과로 막지 않습니다.
  exclude: 분석 호출이 실행 전에 직접 확인하고 없으면 실행하지 않는 경우와, 도구가 필요했던 호출의 응답에서 없다는 사실을 알리는 경우는 해당하지 않습니다.
