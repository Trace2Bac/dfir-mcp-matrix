---
id: T07
name: 도구 부재 처리
question: 필요한 외부 도구와 참조 자료가 있는지 실행 전에 확인하나요? 없거나 실패할 때 다른 프로그램이나 경로로 처리하나요? 그 사실과,
  그로 인해 결과의 의미가 달라진 점을 알리나요?
conditional: false
scope: 외부 도구나 참조 자료가 있어야 실행되는 호출이 적용 범위입니다. 외부 도구는 실행 파일, 모듈, 런타임이고 참조 자료는 룰, 맵, 심볼입니다.
not_implemented: 외부 도구나 참조 자료를 쓰는데 실행 전에 있는지 확인하지 않고 없을 때 실행 오류를 가공 없이 넘기거나 성공처럼 돌려주는
  경우입니다.
not_applicable: 서버가 자기 코드 밖의 도구나 참조 자료를 쓰지 않는 경우입니다.
details:
- id: T07.01
  name: 실행 전 도구·참조 자료 가용성 검사
  include: 서버가 실행 전에 실행 파일, 모듈, 런타임, 참조 자료가 있는지 확인하고 없으면 실행하지 않는 경우입니다. 확인 방법은 PATH
    탐색, 파일 존재 확인, import나 시험 실행 같은 것입니다.
  exclude: 입력 증거가 있는지 검사하는 것은 T01에서 봅니다. 버전이 맞는지 보는 것은 T05에서 봅니다. 부속 입력이 고른 방법이나 입력에
    맞는지 대조하는 경우는 P01.04에서 봅니다.
- id: T07.02
  name: 대체 없는 실패 처리·도구 부재 알림
  include: 필요한 도구나 참조 자료가 없을 때, 서버가 다른 경로로 바꾸지 않고 도구가 없다는 사실을 응답으로 알리는 경우입니다. 알리는
    내용은 오류 종류나 설치 안내 같은 것입니다.
  exclude: 일반 실행 오류만 돌려주고 도구가 없다는 사실을 따로 구분하지 않는 경우는 해당하지 않습니다.
- id: T07.03
  name: 등록·검증된 대체만 실행
  include: 원래 도구를 쓸 수 없을 때, 서버가 미리 등록하고 검증한 대체 도구나 경로만 실행하고 그 밖의 대체는 거부하는 경우입니다.
  exclude: 정해 둔 순서로 다른 경로를 시도하기만 하고 등록이나 검증이 없는 경우는 T07.04나 T07.06에서 봅니다.
- id: T07.04
  name: 알림 없는 대체 실행
  include: 도구나 경로를 얻지 못하거나 실행이 실패하면 서버가 다른 프로그램이나 경로로 처리하고 대체한 사실을 응답에 알리지 않는 경우입니다.
    출처 이름이나 추출기 이름이 달라서 대체했다는 것을 짐작만 할 수 있는 경우도 해당합니다.
  exclude: 대체한 사실을 응답이나 기록의 필드로 밝히는 경우는 T07.06에서 봅니다. 실패와 관계없이 실행 환경에 따라 처음부터 경로를
    고르는 경우는 T07.05에서 봅니다. 입력을 얻지 못해 다른 입력으로 실행하는 경우는 T01.08에서 봅니다.
- id: T07.05
  name: 실행 환경별 경로 분기
  include: 서버가 실행 환경에 따라 정해 둔 순서로 실행 파일이나 경로를 고르는 경우입니다. 실행 환경은 설치 위치, 런타임, OS, 권한
    같은 것입니다.
  exclude: 앞 경로가 실패해서 다른 경로를 쓰는 경우는 T07.04나 T07.06에서 봅니다.
- id: T07.06
  name: 대체 사실을 응답·기록에 표시
  include: 대체 프로그램이나 경로로 실행했다는 사실과 원래 경로를 응답이나 기록의 필드로 밝히는 경우입니다.
  exclude: 서버 로그에만 남기는 경우는 T07.04에서 봅니다.
- id: T07.07
  name: 대체에 따른 검증·입력 범위 변화 표시
  include: 대체 경로로 바뀌면서 달라진 검증 수준, 입력 범위, 결과의 뜻을 응답이나 기록에 밝히는 경우입니다. 꺼낸 범위가 줄어든 것,
    다른 플러그인이라 결과의 의미가 다른 것이 그 예입니다.
  exclude: 대체했다는 사실과 원래 경로만 밝히는 경우는 T07.06에서 봅니다.
- id: T07.08
  name: 실행 전 부재 도구 자동 설치
  include: 서버가 도구나 참조 자료를 처음 쓰기 전에 있는지 확인하고 없으면 정해 둔 출처(패키지 관리자, 내려받기 주소)에서 설치한 뒤 실행하는
    경우입니다.
  exclude: 설치하는 버전을 고정하고 확인하는 것은 T05에서 봅니다. 도구가 없을 때 실행하지 않고 멈추는 경우는 T07.01에서 봅니다.
