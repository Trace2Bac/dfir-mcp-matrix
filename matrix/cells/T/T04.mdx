---
id: T04
name: 실행 방식
question: 실제 분석을 실행하는 방식과 그 실행의 권한과 작업 공간을 서버와 나누는 방식을 분류합니다.
conditional: false
boundary: 서버가 모델 API에 검토, 계획, 판정을 묻는 호출은 실제 분석이 아니며 P02·D06·D07에서 봅니다. 모델이 넘긴 값이 명령 문자열에 들어가는 것을 막는 검사는 T02에서 봅니다.
scope: 서버가 실제 분석을 수행하는 모든 경로가 적용 범위입니다. 실제 분석은 파싱, 검색, 외부 도구 실행, 원격 작업 요청을 말합니다. 서버와
  같은 권한, 파일, 네트워크에 닿는 별도 프로세스는 격리에 해당하지 않습니다.
not_implemented: 없습니다. 모든 서버가 어느 한 실행 방식에는 해당합니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: T04.01
  name: 서버 프로세스 안 라이브러리 호출
  include: 서버가 분석을 자기 프로세스 안에서 라이브러리 함수로 수행하는 경우입니다.
  exclude: 라이브러리는 서버의 권한과 메모리를 함께 쓰므로 격리에 해당하지 않습니다.
- id: T04.02
  name: 같은 권한의 별도 프로세스
  include: 서버가 외부 실행 파일을 자식 프로세스로 실행하면서 인자 목록을 넘기는 경우입니다. 이 자식 프로세스는 서버와 같은 계정, 파일,
    네트워크 권한을 가집니다.
  exclude: 서버 전체를 컨테이너에서 실행해도 도구가 서버와 같은 컨테이너와 계정에서 실행되면 해당합니다.
- id: T04.03
  name: 셸 명령 문자열 실행
  include: 서버가 셸이 해석하는 명령 문자열(`shell=True`, `sh -c` 등)로 외부 도구를 실행하는 경우입니다.
- id: T04.04
  name: 권한을 나눈 실행
  include: 서버가 외부 도구를 서버와 다른 계정이나 다른 권한으로 실행하는 경우입니다. 권한을 바꾸는 방법에는 sudo, 사용자 전환, capability
    제거 등이 있습니다.
  exclude: 서버와 도구를 함께 비루트 계정이나 root로 실행하는 것은 서버 전체의 권한을 정한 것이므로 해당하지 않습니다.
- id: T04.05
  name: 실행별 작업 폴더
  include: 서버가 호출마다 새 작업 폴더를 만들고 그 폴더를 작업 위치(`cwd`)로 두어 외부 도구를 실행하는 경우입니다.
  exclude: 출력 파일만 임시 폴더에 쓰게 하는 것은 해당하지 않습니다. 실행별 작업 폴더는 다른 폴더에 접근하는 것을 막지 않으므로 격리 장치에 해당하지 않습니다.
- id: T04.08
  name: 원격 API 작업 요청
  include: 서버가 분석을 원격 백엔드나 플랫폼 API에 작업으로 요청하고 결과를 받는 경우입니다.
  exclude: 위협 정보 조회처럼 결과에 정보를 보태는 외부 질의는 I축에서 봅니다.
- id: T04.09
  name: SSH 원격 호스트 명령 실행
  include: 서버가 SSH로 별도 분석 호스트나 조사 대상 단말에 접속해 그 호스트의 접속 계정 권한으로 명령이나 외부 도구를 실행하고 출력을
    받는 경우입니다.
  exclude: 도구가 서버 호스트와 다른 기계에서 실행되더라도 분석 호스트 안에서 계정이나 파일을 분리하지 않으면 격리 장치(T04.04)에 해당하지 않습니다.
