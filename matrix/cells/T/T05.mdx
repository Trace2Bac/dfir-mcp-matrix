---
id: T05
name: 분석 도구 검증
question: 분석 도구와 참조 자료의 버전을 정하고 확인하는 방식을 분류합니다.
conditional: false
boundary: 확인한 버전을 결과나 기록에 싣는 것은 T06에서, 도구가 실행되는지만 보는 것은 T07에서 봅니다.
scope: 서버가 실행하거나 불러오는 분석 도구와, 그 도구나 서버 코드가 판단에 쓰거나 조회 결과로 모델에게 돌려주는 참조 자료가 적용 범위입니다.
  분석 도구는 실행 파일, 라이브러리, 컨테이너 이미지이고 참조 자료는 룰, 시그니처, 심볼, 매핑, IOC 목록, 지식 데이터입니다.
  무결성 확인은 사용 직전의 실제 대상과 대조할 때만 해당합니다.
not_implemented: 서버가 쓰는 도구나 참조 자료가 있는데 그 버전을 저장소에 고정하지도, 설정이나 인자로 정하지도, 실행할 때 확인하지도
  않는 경우입니다.
not_applicable: 서버가 자기 코드 밖의 분석 도구, 라이브러리, 참조 자료를 쓰지 않는 경우입니다.
details:
- id: T05.01
  name: 저장소·의존성 고정
  include: 저장소의 설치 정의(의존성 잠금 파일, 자산 목록, Dockerfile, 설치 스크립트)에 도구와 참조 자료의 고정 값(버전, 태그,
    커밋, 해시)을 적어 설치되는 버전을 정하면 해당합니다. 설치할 때 받은 파일의 해시를 그 값과 대조하는 것도 해당합니다. 룰, 아티팩트, 매핑
    파일을 저장소에 함께 넣어 커밋으로 내용이 정해지는 경우도 해당합니다.
  exclude: 버전 범위(`>=`)만 적거나 버전 값 없이 브랜치나 최신(`HEAD`, `latest`)을 받는 경우는 고정에 해당하지 않습니다. 증거를 해석하지
    않는 서버 실행용 라이브러리(MCP SDK, DB 드라이버, SSH, 스크립트 엔진 등)의 고정도 해당하지 않습니다. 도구를 쓰기 직전에 실제 파일을 대조하는 경우는 해당하지 않습니다.
- id: T05.02
  name: 설정·호출 인자로 지정
  include: 서버가 실행할 때 읽는 설정 파일, 환경변수, 호출 인자로 쓸 도구나 참조 자료의 버전 또는 위치를 정하는 경우입니다. 위치만 받고 그 내용의 버전은 모르는
    경우도 해당합니다.
  exclude: 빌드할 때만 쓰는 환경변수나 설정은 해당하지 않습니다.
- id: T05.03
  name: 실행 시 버전 조회
  include: 서버가 실행 중에 도구에 버전을 묻거나 도구 출력이나 라이브러리 속성에서 버전을 읽는 경우입니다.
- id: T05.04
  name: 참조 자료 버전·식별값 조회
  include: 서버가 실행 중에 룰, 시그니처, 심볼, 매핑의 버전이나 식별값을 읽는 경우입니다. 식별값은 룰 저장소 커밋, 심볼 GUID와
    age, 시그니처 DB 버전 같은 것입니다.
  exclude: 해시를 계산해 기준값과 대조하는 경우는 해당하지 않습니다.
- id: T05.05
  name: 사용 전 기대값 대조
  include: 서버가 도구나 참조 자료를 쓰기 직전에 기대값(해시, 파일 목록, 식별값)과 대조해 다르면 실행하지 않는 경우입니다.
  exclude: 설치할 때만 대조하는 경우는 해당하지 않습니다. 값을 계산하거나 읽기만 하고 대조하지 않는 경우와 형식 검사로 쓸 수 있는 파일만 고르는 경우는 해당하지 않습니다.
