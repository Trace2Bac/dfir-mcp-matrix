---
id: T01
name: 입력 검증
question: 실행 전에 호출 인자와 입력을 검사하고 허용한 접근 범위와 대조하는 방식을 분류합니다.
conditional: false
boundary: 도구와 참조 자료를 쓸 수 있는지와 같은 입력을 다른 도구로 얻는 것은 T07에서, 연산·플러그인·질의를 목록이나 틀로 좁히는 검사는 T02에서, 쓰기 위치의 검사는 D04에서 봅니다. 입력 schema가 알리는 인자와 처리기가 읽는 인자가 다른 것은 T10에서 봅니다.
scope: 모델이 넘긴 인자나 입력 경로로 실행하는 호출이 적용 범위입니다.
not_implemented: 서버 코드가 인자와 입력을 실행 전에 검사하지 않고 그대로 백엔드나 외부 도구에 넘기는 경우입니다. MCP SDK가
  입력 schema로 자료형만 검사하는 경우, 도구 설명으로 올바른 값을 안내만 하는 경우도 미구현으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: T01.01
  name: 인자 구조·값 검사
  include: 서버 코드가 인자의 구조와 값(허용 값 목록, 범위, 형식, 필수 항목)을 검사해 어긋나면 거부하거나 정한 기본값으로 바꾸면 해당합니다.
    기준은 서버 코드에 둔 값이어도 되고 서버가 실행할 때 읽은 값(설치된 외부 도구나 백엔드가 지원한다고 알린 값, 사용자가 설정 파일이나 환경변수로
    정한 값)이어도 됩니다.
  exclude: 외부 도구가 할 연산이나 플러그인을 고르는 값을 설치된 도구가 지원하는 값과 대조하는 검사와 정한 연산 안의 값(형식, 인코딩, 범위) 검사는 여기서 봅니다.
- id: T01.02
  name: 입력 존재·읽기 가능 검사
  include: 서버가 실행 전에 입력 파일, 폴더, 대상이 있는지나 읽을 수 있는지 확인하고 없으면 외부 도구나 백엔드를 부르지 않고 거부하면 해당합니다.
- id: T01.04
  name: 실제 경로로 변환해 허용 폴더 대조
  include: 서버가 읽기 경로 인자를 실제 경로로 변환해(`..`와 심볼릭 링크를 해석해) 허용 폴더 안에 있는지 대조하고 밖이면 거부하면 해당합니다.
    파일은 변환한 경로로 엽니다.
- id: T01.05
  name: 문자열 경로 검사
  include: 서버가 경로로 쓰이는 인자를 파일시스템을 보지 않고 문자열로만 검사하면 해당합니다. 경로 구분자, `..`, 절대 경로, 제어
    문자를 거부하거나 접두어를 비교하는 방식이 그 예입니다. 대응 조치가 다룰 원격 대상의 경로를 검사하는 것도 해당합니다.
- id: T01.06
  name: 등록된 ID와 대조
  include: 모델이 인자로 서버에 등록된 증거, 자료, 호출 기록의 ID나 등록된 경로를 넘기고 서버가 그 값을 등록 목록과 대조해 없으면 거부하는
    경우입니다. 그 ID로 도구가 읽을 입력을 고르는 경우와 그 ID를 결과의 근거로 남기는 경우가 모두 해당합니다.
  exclude: 같은 인자가 등록 목록 밖의 경로도 받으면 그 경로는 해당하지 않습니다.
- id: T01.07
  name: 고정 입력 경로 사용
  include: 모델이 입력 경로를 고르지 않고 서버가 설정이나 앞선 적재 기록에서 정한 입력만 읽는 경우입니다.
  exclude: 모델이 경로를 주지 않았을 때만 기본 경로를 쓰는 경우는 해당하지 않습니다.
- id: T01.08
  name: 입력 부재 시 다른 입력으로 대체
  include: 입력 파일이나 경로를 찾지 못하거나 이미지에서 꺼내지 못했을 때 서버가 거부하지 않고 다른 파일, 경로, 범위로 입력을 바꿔 실행하는
    경우입니다. 대소문자나 구분자만 다른 경로로 바꾸는 경우도 해당합니다.
