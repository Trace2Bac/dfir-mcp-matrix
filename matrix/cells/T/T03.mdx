---
id: T03
name: 실행 조건 확인
question: 서버는 도구 인자 밖의 조건으로 호출을 허용할지와 언제 실행할지를 어떻게 정하나요? 그런 조건은 앞선 작업이나 판정 상태, 모델
  밖 승인자의 승인, 원격 호출자의 신원, 서버의 실행 자원 상태입니다.
conditional: false
scope: 도구 인자 밖의 조건을 걸어 둔 호출이 적용 범위입니다. 그런 조건은 앞선 호출이 만든 상태, 모델 밖 승인자의 승인, 원격 호출자의
  신원, 서버의 실행 자원 상태입니다. 도구 명세나 설명에 선행 조건이나 승인을 적어 둔 호출도 포함합니다.
not_implemented: 도구 인자 밖의 조건으로 호출을 막거나 미루는 코드가 없는 경우입니다. 서버 지침이나 도구 설명으로 순서나 승인을 안내만
  하는 경우, 도구 annotation만 있는 경우도 미구현으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: T03.01
  name: 선행 결과 대조
  include: 서버가 앞선 호출이 만든 결과나 작업 상태를 확인하고 그 상태가 호출 조건에 맞지 않으면 호출을 거부하는 경우입니다. 필요한 결과가
    아직 없는 경우, 앞선 작업이 끝나지 않은 경우, 한 번만 허용하는 작업이 이미 이루어진 경우가 그 예입니다. 결과는 보유 능력, 적재한 입력,
    등록한 증거, 기준선 파일 같은 것입니다.
  exclude: 결과를 어디에 두고 얼마나 남기는지는 P04에서 봅니다. 결과가 통과 판정인지까지 확인하는 경우는 T03.03에서 봅니다. 인자로
    받은 ID가 등록 목록에 있는지 보는 검사는 인자 값 검사이므로 T01.06에서 봅니다.
- id: T03.02
  name: 조사 단계 검사
  include: 서버가 조사 단계를 두고 지금 단계에서 허용하지 않는 호출이나 조건을 채우지 않은 단계 이동을 거부하는 경우입니다.
  exclude: 단계를 안내하거나 보여 주기만 하는 경우는 P02와 P03에서 봅니다.
- id: T03.03
  name: 앞선 점검·판정 결과 대조
  include: 앞선 점검이나 검토 호출이 낸 판정이 통과인지 확인하고 통과가 아니면 호출을 거부하는 경우입니다. 판정은 보고 준비 완료, 검토 통과
    같은 것입니다.
  exclude: 판정을 내리고 심사하는 방식은 D07에서 봅니다.
- id: T03.04
  name: 반복 호출 제한
  include: 같은 호출이 같은 결과를 정해 둔 횟수만큼 되풀이하면 서버가 다음 호출을 거부하는 경우입니다.
  exclude: 알리기만 하고 막지 않는 경우는 해당하지 않습니다.
- id: T03.06
  name: 승인 토큰·서명 대조
  include: 모델 밖의 승인자(사용자나 외부 승인 경로)가 낸 토큰, 서명, 기록을 서버가 대조해 없으면 호출을 거부하는 경우입니다. 저장소가
    함께 제공하는 클라이언트 훅이나 플러그인이 사용자 입력을 서버가 읽는 기록에 남긴 것도 승인자 기록으로 인정합니다.
  exclude: 모델이 같은 대화 안에서 만들 수 있는 값은 승인자의 기록으로 보지 않습니다. 승인한 내용이 요청과 맞는지는 T03.07에서 봅니다.
- id: T03.07
  name: 승인 내용과 요청 대조
  include: 승인에 묶인 작업, 대상, 인자가 실제 요청과 같은지 대조하고 다르면 호출을 거부하는 경우입니다. 승인 기록을 요청의 식별자로 정한
    위치에 저장하고 실행할 때 같은 식별자로 찾는 것도 대조로 봅니다.
  exclude: 승인이 있는지만 확인하는 경우는 T03.06에서 봅니다.
- id: T03.08
  name: 승인 만료·소모·재승인
  include: 승인에 유효 시간이나 사용 횟수를 두거나 요청이 바뀌면 승인을 다시 받게 하는 경우입니다.
  exclude: T03.06이나 T03.07에 해당하지 않으면 이 상세도 해당하지 않습니다.
- id: T03.09
  name: 원격 호출자 인증
  include: 원격 MCP 연결에서 서버가 프로토콜 인증, API key, 서명, 세션으로 호출자를 확인하는 경우입니다.
  exclude: stdio 서버를 실행하는 프로세스 권한은 이 셀에서 보지 않습니다. stdio 서버에 이 항목이 없는 것을 결함으로 보지 않습니다.
    서버가 백엔드에 접속할 때 쓰는 자격증명은 I04에서 봅니다.
- id: T03.10
  name: 앞단 게이트웨이 인증에 위임
  include: 서버는 호출자를 확인하지 않고 저장소가 지원하는 배포 구성의 앞단 프록시나 게이트웨이 인증에 맡기는 경우입니다.
  exclude: 그런 배포 구성이 저장소에 없으면 해당하지 않습니다.
- id: T03.11
  name: 실행 자원 확인
  include: 서버가 실행 전에 메모리·CPU 사용률이나 디스크 여유 공간 같은 자원 상태를 확인하고 기준에 맞지 않으면 실행을 미루거나 거부하는
    경우입니다.
  exclude: 동시에 진행 중인 실행 수를 세어 제한하는 경우는 T03.12에서 봅니다. 분석 도구 자체의 시간 제한은 T08.02에서 봅니다.
- id: T03.12
  name: 동시 실행 수 제한
  include: 서버가 세마포어, 용량 제한기, 큐, 스레드 풀로 동시에 진행 중인 분석 실행 수를 정해 둔 개수로 제한하고 자리가 없으면 기다리게
    하는 경우입니다. 모든 실행을 하나씩 차례로 실행하는 큐도 해당합니다.
  exclude: 자원 상태를 읽는 경우는 T03.11에서, 특정 도구만 따로 차례로 실행하는 순서 제약은 T03.13에서 봅니다.
- id: T03.13
  name: 특정 도구 차례 실행
  include: 서버가 자원을 많이 쓰는 특정 도구를 다른 작업과 겹치지 않게 같은 묶음의 병렬 작업이 끝난 뒤 하나씩 실행하는 경우입니다.
  exclude: 모든 실행을 한 큐로 차례로 실행하는 경우는 T03.12에서 봅니다. 결과를 입력 순서로 돌려주는 것은 해당하지 않습니다.
