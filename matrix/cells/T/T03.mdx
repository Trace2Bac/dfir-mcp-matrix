---
id: T03
name: 실행 조건 확인
question: 도구 인자 밖의 조건(앞선 작업 결과, 승인, 호출자 신원, 실행 자원)으로 호출을 허용하거나 미루는 방식을 분류합니다.
conditional: false
boundary: 증거가 기준값과 다를 때 막는 것은 E02에서, 이미 있는 결과를 다시 만들지 않거나 덮어쓸지 고르게 하는 것은 D06에서, 인자로 받은 ID가 등록 목록에 있는지 보는 검사는 T01에서 봅니다. 단계를 안내하기만 하는 것은 P02·P03에서, 서버가 판정을 내리는 방식은 F02에서, 발견사항을 심사하는 방식은 F05에서, 서버가 외부에 접속할 때 쓰는 자격증명은 I04에서 봅니다.
scope: 도구 인자 밖의 조건을 걸어 둔 호출이 적용 범위입니다. 그런 조건은 앞선 호출이나 사용자, 서버를 담은 프로그램이 만든 작업 상태, 모델 밖 승인자의 승인, 원격 호출자의
  신원, 서버의 실행 자원 상태입니다. 도구 명세나 설명에 선행 조건이나 승인을 적어 둔 호출도 포함합니다.
not_implemented: 앞선 작업·판정 상태, 모델 밖 승인자의 승인, 원격 호출자의 신원, 서버의 실행 자원 상태로 호출을 막거나 미루는
  코드가 없는 경우입니다. 서버 지침이나 도구 설명으로 순서나 승인을 안내만 하는 경우, 도구 annotation만 있는 경우도 미구현으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: T03.01
  name: 선행 결과 대조
  include: 서버가 앞선 호출의 결과나 작업 상태를 확인해 조건에 맞지 않는 호출을 막는 경우입니다. 결과는 보유 능력, 불러온 입력, 등록한 증거, 기준선 파일 같은 것입니다.
  exclude: 결과가 통과 판정인지까지 확인하는 경우는 해당하지 않습니다.
- id: T03.02
  name: 조사 단계 검사
  include: 서버가 조사 단계를 두고 지금 단계에서 허용하지 않는 호출이나 단계 이동을 막는 경우입니다.
- id: T03.03
  name: 앞선 점검·판정 결과 대조
  include: 앞선 점검이나 검토 호출이 낸 판정이 통과인지 확인하고 통과가 아니면 호출을 거부하는 경우입니다. 판정은 보고 준비 완료, 검토 통과
    같은 것입니다.
- id: T03.04
  name: 반복 호출 제한
  include: 같은 호출이 같은 결과를 정해 둔 횟수만큼 되풀이하면 서버가 다음 호출을 거부하는 경우입니다.
  exclude: 알리기만 하고 막지 않는 경우는 해당하지 않습니다.
- id: T03.05
  name: 승인 토큰·서명 대조
  include: 모델 밖의 승인자(사용자나 외부 승인 경로)가 낸 토큰, 서명, 기록을 서버가 대조해 없으면 호출을 거부하는 경우입니다. 저장소가
    함께 제공하는 클라이언트 훅이나 플러그인이 사용자 입력을 서버가 읽는 기록에 남긴 것도 승인자 기록에 해당합니다.
  exclude: 모델이 같은 대화 안에서 만들 수 있는 값은 승인자의 기록에 해당하지 않습니다.
- id: T03.06
  name: 승인 내용과 요청 대조
  include: 승인에 묶인 작업, 대상, 인자가 실제 요청과 같은지 대조하고 다르면 호출을 거부하는 경우입니다. 승인 기록을 요청의 식별자로 정한
    위치에 저장하고 실행할 때 같은 식별자로 찾는 것도 대조로 봅니다.
- id: T03.07
  name: 승인 만료·소모·재승인
  include: 승인에 유효 시간이나 사용 횟수를 두거나 요청이 바뀌면 승인을 다시 받게 하는 경우입니다.
  exclude: 서버가 승인 토큰이나 서명, 또는 승인 내용을 요청과 대조하지 않으면 해당하지 않습니다.
- id: T03.08
  name: 원격 호출자 인증
  include: 원격 MCP 연결에서 서버가 프로토콜 인증, API key, 서명, 세션으로 호출자를 확인하는 경우입니다. 서버를 이루는 프로그램 사이의 로컬 연결에서 토큰 같은 값으로 호출자를 확인하는 경우도 해당합니다.
  exclude: stdio 서버를 실행하는 프로세스 권한은 해당하지 않습니다.
- id: T03.09
  name: 실행 자원 확인
  include: 서버가 실행 전에 메모리·CPU 사용률이나 디스크 여유 공간 같은 자원 상태를 확인하고 기준에 맞지 않으면 실행을 미루거나 거부하는
    경우입니다.
- id: T03.10
  name: 동시 실행 수 제한
  include: 서버가 세마포어, 용량 제한기, 큐, 스레드 풀로 동시에 진행 중인 분석 실행 수를 정해 둔 개수로 제한하고 자리가 없으면 기다리게
    하는 경우입니다. 모든 실행을 하나씩 차례로 실행하는 큐도 해당합니다.
- id: T03.11
  name: 특정 도구 차례 실행
  include: 서버가 자원을 많이 쓰는 특정 도구를 다른 작업과 겹치지 않게 같은 묶음의 병렬 작업이 끝난 뒤 하나씩 실행하는 경우입니다.
  exclude: 모든 실행을 한 큐로 차례로 실행하는 경우와 결과를 입력 순서로 돌려주는 것은 해당하지 않습니다.
