---
id: T06
name: 실행 환경정보 표시
question: 서버가 확인한 도구와 환경의 버전을 해당 결과와 기록에 어떻게 연결하나요?
conditional: false
boundary: 선언한 버전을 붙였는지, 실행에서 확인한 버전을 붙였는지 구분합니다. 이 셀의 버전에는 참조 자료의 식별값(룰 저장소 커밋, 심볼 GUID
  등)도 포함합니다.
scope: 원고의 구현 단락에 버전을 싣는다고 적은 결과, 기록, 파생물이 적용 범위입니다. 다음 경우에는 †를 붙입니다. 그 안에서 버전이 빠지거나
  잘려 보이지 않는 경로가 있는 경우, 같은 도구를 다른 호출 경로(일괄 실행이나 비동기 실행)로 부를 때 버전이 빠지는 경우, 실행한 대상과 묶이지
  않은 값을 싣는 경우입니다. 버전을 싣지 않는 다른 도구에는 †를 붙이지 않고 원고의 구현 단락에 씁니다.
not_implemented: 서버가 도구나 참조 자료를 써서 결과를 내는데, 응답, 호출 기록, 파생물 어디에도 버전을 싣지 않는 경우입니다.
not_applicable: 없습니다. 서버 자신의 버전(T06.05)도 보므로 모든 서버에 적용합니다.
details:
- id: T06.01
  name: 응답 메타데이터에 버전 표시
  include: 분석 결과를 돌려주는 응답에, 그 결과를 만든 도구와 참조 자료의 버전을 필드로 실으면 해당합니다. 선언한 버전인지, 실행에서
    읽어 확인한 버전인지 원고의 구현 단락에 씁니다.
  exclude: 버전을 알게 된 호출(설치나 환경 조회)의 응답에만 버전이 있는 경우는 T06.04에서 봅니다. 실행한 도구와 묶이지 않은 소스
    상수는 해당하지 않습니다. 도구가 출력 본문에 적은 버전 줄을 서버가 읽지 않고 본문째 넘기기만 하는 경우도 해당하지 않습니다.
- id: T06.02
  name: 호출 기록 메타데이터에 버전 표시
  include: 그 버전으로 실행한 호출의 호출 기록 항목에 도구와 참조 자료의 버전을 실으면 해당합니다.
  exclude: 버전을 알게 된 호출(설치나 환경 조회)의 기록에만 버전이 있는 경우는 T06.04에서 봅니다. 호출과 이어지지 않는 별도 파일은
    T06.03에서 봅니다.
- id: T06.03
  name: 파생물 manifest에 버전 표시
  include: 서버가 만든 파생물의 manifest나 메타데이터에, 그 파생물을 만든 도구와 참조 자료의 버전을 적으면 해당합니다. 파생물은
    출력 파일, 사건 DB, 보고서를 말합니다.
  exclude: 도구가 출력 본문에 적은 버전 줄이 파생물에 남기만 하는 경우는 해당하지 않습니다. 버전을 담을 자리만 있고 채우지 않는 경우도
    해당하지 않습니다.
- id: T06.04
  name: 환경 조회 도구에서만 반환
  include: 환경이나 도구 상태를 묻는 별도 도구가 버전을 돌려주지만, 분석 결과나 기록에는 버전을 싣지 않는 경우입니다.
  exclude: 분석 결과에도 버전을 싣는 경우는 T06.01이나 T06.02에서 봅니다.
- id: T06.05
  name: 서버 자신의 버전 표시
  include: 서버 자신의 버전을 응답, 호출 기록, 보고서에 실으면 해당합니다. 서버 자신의 버전은 패키지 버전, git 커밋, 코드 해시를
    말합니다.
  exclude: 명령 행 `--version`이나 시작 문구로만 버전이 보이는 경우는 해당하지 않습니다. MCP 규격(2025-11-25)은 모든
    서버가 초기화 응답의 `serverInfo`에 이름과 버전을 싣도록 요구합니다. 이 값은 규격의 기본 동작이고 분석 결과나 기록과 묶이지 않으므로
    해당하지 않습니다. 그 값이 실제 버전과 다르면 원고의 구현 단락에 씁니다.
- id: T06.06
  name: 모델·버전 표시
  include: 서버 안에서 모델을 부르는 경우, 그 모델의 이름과 버전을 결과나 호출 기록에 실으면 해당합니다.
  exclude: 서버가 모델을 부르지 않으면 이 상세는 보지 않습니다. 모델 입력과 응답을 보존하는지는 L02에서 봅니다.
