---
id: F02
name: 결론 도출
question: 규칙이나 모델로 판정, 관계, 점수, 의심 후보, 공격 흐름 서술 같은 발견사항과 결론을 만들고 그 근거와 확신 수준을 남기는 방식을 분류합니다.
conditional: false
boundary: 서버가 만든 발견사항이나 결론이 기록되면 그 근거 심사는 F05에서, 발견사항의 등급을 근거로 정하는 것은 F05.03에서 봅니다. 발견사항으로 저장하는 것은 F04에서, 보고 산출물에 싣는 것은 F06에서 봅니다. 발견사항과 결론을 응답에 싣는 형태(잘림, 출처, 상태)는 R축에서 봅니다. 도구가 낸 판정이나 결론을 서버가 다시 엮거나 판정을 더하지 않고 그대로 옮기는 것은 R축에서 봅니다. 이미 만든 결과에서 응답 목록만 고르는 것은 R01.11에서, 형식 변환과 건수 집계는 R01.03에서, 관측을 줄이거나 다시 서술하기만 하는 모델 요약은 R01.04에서, 외부 도구가 준 확신 값을 계산 없이 옮기는 것은 R01에서 봅니다. 서버 안 모델에게 넘기는 입력의 구성은 F03에서 봅니다. 결론을 담은 파일은 D축에서 봅니다.
scope: 서버가 규칙이나 모델로 만드는 발견사항과 결론을 봅니다. 서버가 도구 결과나 발견사항을 정한 규칙으로 분류·판정하거나 결과끼리 잇거나 점수, 공격 흐름 서술을 만드는 도구와 경로가 적용 범위입니다. 도구 출력 하나에 규칙을 대어 판정하는 경우도 포함합니다. 판정 규칙 안에서 분석 대상이나 의심 후보를 정하는 제외 조건(알려진 정상 목록, 탐지 전 필터)도 포함합니다. 반환값이 원래 행의 부분집합이어도 그 집합이 의심 후보나 숨은 항목 같은 조사 의미를 가지면 포함합니다. 서버가 조사 자료로 만든 규칙을 원격 엔진이 적용하고 그 결과를 서버가 받는 경로도 포함합니다. 도구 설명에 그런 결론을 만든다고 적힌 도구와 보고 산출물을 만들면서 계산하는 경로도 포함합니다.
not_implemented: 서버는 도구 출력을 옮기거나 형식을 바꾸거나 모델이 준 조건으로 걸러서 돌려줄 뿐, 규칙으로 판정하거나 결과끼리 잇거나 점수, 흐름 서술을 만들지 않는 경우입니다. 판단은 클라이언트 모델이 하고 모델이 기록으로 낸 주장은 발견사항(F04)으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: F02.01
  name: 규칙·키 기반 판정·상관
  include: 서버가 정한 규칙(키워드, 이벤트 ID, 포트 목록)이나 공유 키(PID, IP, 실행 파일 이름, 근거 호출 ID)로 결과 항목을 분류하거나 잇는 경우입니다. 규칙 안에서 분석 대상이나 의심 후보를 정하는 제외 조건과, 차집합으로 후보를 고르는 규칙도 포함합니다.
- id: F02.02
  name: 시각·위치 근접 연결
  include: 정한 시각 차이나 시간 범위, 또는 증거 안 위치(오프셋, MFT 레코드 번호처럼 차례가 위치를 뜻하는 번호)의 거리를 기준으로 서로 다른 결과 항목을 잇거나 묶는 경우입니다.
  exclude: 결과를 시각순으로 정렬하기만 하는 경우는 해당하지 않습니다.
- id: F02.03
  name: 통계·점수 산정
  include: 정한 가중치, 평균, 유사도, 건수로 항목마다 점수나 등급을 계산해 결과에 싣거나 정렬, 병합 같은 판단에 쓰는 경우입니다.
  exclude: 외부 서비스가 준 점수를 합치지 않고 옮기기만 하는 경우는 해당하지 않습니다. 검색어 일치 수 같은 조회 정렬 값도 해당하지 않습니다.
- id: F02.04
  name: 서버 안 모델의 추론·서술
  include: 서버 안에서 부른 모델이 도구 결과나 발견사항을 읽고 관계, 판단, 가설, 공격 흐름 서술을 만드는 경우입니다.
  exclude: 클라이언트 모델이 써서 제출한 서술을 저장하기만 하는 경우는 해당하지 않습니다.
- id: F02.05
  name: 사용 근거·변환 기록
  include: 결론을 만들 때 읽은 입력(하위 조회, 호출 ID, 자료 이름)과 적용한 규칙이나 변환을 호출 기록이나 결과에 남기는 경우입니다.
  exclude: 빠진 입력 목록만 싣고 실제로 쓴 입력을 남기지 않는 경우는 해당하지 않습니다.
- id: F02.06
  name: 규칙 기반 공격 단계 분류·흐름 서술
  include: 정한 규칙으로 발견사항이나 지표를 공격 단계로 나누거나 시간 순서에 따른 흐름 문장이나 표를 만드는 경우입니다. 규칙은 키워드, ATT&CK 기법과 tactic의 대응, 킬체인 순서 같은 것입니다.
  exclude: 모델이 써서 제출한 서술을 저장해 보고서에 싣기만 하는 경우는 해당하지 않습니다.
- id: F02.07
  name: 조사 자료로 만든 탐지 규칙의 원격 적용
  include: 서버가 조사 자료(기준선, 지표 목록)로 탐지 규칙을 만들어 외부 수집·분석 엔진에 올리고 그 엔진이 규칙에 맞춘 결과를 받아 경보나 결과로 돌려주는 경우입니다.
  exclude: 외부 도구의 고정 규칙 묶음이나 모델이 써서 넘긴 규칙을 그대로 실행하고 결과를 옮기기만 하는 경우는 해당하지 않습니다.
- id: F02.08
  name: 결론의 확신 수준·추정 범위 표시
  include: 서버가 낸 판정이나 추정에 확신 수준, 추정 범위, 판단 보류를 값으로 싣는 경우입니다.
