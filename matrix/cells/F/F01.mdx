id: F01
name: 판단 지침
question: 조사 전체의 해석 원칙과 발견사항·결론을 서술하고 확인하는 방식을 모델에게 안내하는 방식을 분류합니다.
conditional: false
boundary: 특정 도구 결과의 해석 주의와 추가 확인 권고는 R04에서, 다음에 할 작업을 권하는 것은 P02에서, 증거 속 지시를 따르지 말라는 안내는 R07에서 봅니다. 안내를 따랐는지 검사해 기록을 거부하거나 한정하는 장치는 F05에서, 서버가 만든 발견사항과 결론의 확신 수준은 F02에서 봅니다. 서버 안 모델에게 주는 지시는 F03에서 봅니다. 도구 명세가 만들어지는 방식은 T10에서 봅니다.
scope: 서버가 판단에 관해 안내하는 도구 설명, 서버 지침(instructions), MCP 리소스와 프롬프트, 응답 문구가 적용 범위입니다. 안내를 고르는 계산은 원고의 구현 단락에 적습니다. 안내는 그 안내를 따르게 하는 장치로 세지 않습니다.
not_implemented: 도구 설명, 서버 지침, 리소스, 응답 어디에도 판단에 관한 원칙, 서술 방식, 단서를 적지 않는 경우입니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: F01.01
  name: 조사 전체 해석 원칙
  include: 서버 지침(instructions), MCP 리소스, MCP 프롬프트, 또는 도구와 관계없이 응답에 공통으로 붙는 문구에 조사 전체에 걸치는 해석 원칙을 적는 경우입니다. 부재가 무죄를 뜻하지 않는다는 원칙이나 근접이 인과가 아니라는 원칙이 그 예입니다.
  exclude: 지침을 둔 것은 실행 차단이나 검증에 해당하지 않습니다.
- id: F01.02
  name: 결론 서술 방식 안내
  include: 결론을 어떻게 서술할지 안내하는 경우입니다. 확정하지 못한 결론을 후보나 가설로 서술하라, 관찰과 해석을 나눠 적어라, 대안 설명과 반대 근거를 함께 적어라, 판단할 수 없으면 판단 보류로 표시하라는 안내가 그 예입니다.
  exclude: 증거나 아티팩트가 무엇을 뜻하는지에 관한 원칙과, 반대 근거나 다른 출처를 찾아보라는 확인 안내는 해당하지 않습니다.
  seen_in: [mcp_dfir]
- id: F01.03
  name: 발견사항별 보완 안내
  include: 기록하려거나 이미 기록한 발견사항·결론마다 그 내용·근거 수·등급을 보고 보완할 점(더할 근거, 확인할 도구, 등급, 빠진 값, 나눌 주장)을 싣는 경우입니다. 도구 설명이나 리소스의 고정된 글은 근거 수나 등급 같은 조건을 달아 안내할 때만 해당합니다.
  exclude: 기록을 거부하거나 한정하는 장치는 이 상세에 해당하지 않습니다. 조건 없이 늘 같은 문구로 확인 절차를 안내하는 것도 해당하지 않습니다.
- id: F01.04
  name: 공통 확인 절차 안내
  include: 발견사항·결론을 기록하거나 보고하기 전에 근거가 된 호출이나 증거를 다시 확인하라는 안내를, 발견사항의 내용과 관계없이 늘 같은 문구로 도구 설명, 서버 지침, 리소스, 프롬프트, 응답에 싣는 경우입니다. 반대 근거나 다른 출처를 찾아보라는 안내도 포함합니다.
  exclude: 발견사항마다 내용·근거 수·등급에 따라 다른 안내를 싣는 경우는 해당하지 않습니다.
- id: F01.05
  name: 조사 상태에 따른 판단 편향 경고
  include: 호출 이력이나 가설 상태 같은 조사 상태를 보고, 모델의 판단이 한쪽으로 치우쳤을 수 있다고 알리는 경우입니다.
