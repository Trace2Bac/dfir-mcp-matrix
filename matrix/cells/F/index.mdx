# F 발견사항과 결론

DFIR MCP 서버가 조사에서 나온 발견사항과 결론을 만들고, 기록하고, 검증해 보고 산출물로 엮는 방식을 분류합니다.
발견사항은 조사에서 확인했거나 의심하는 개별 사실이고, 결론은 발견사항이나 다른 정보를 엮어 내린 해석입니다.
둘 다 도구, 서버의 규칙, 서버 안의 모델, 클라이언트 모델 가운데 어디서든 나올 수 있으며, 이 축은 누가 만들었는지가 아니라 서버가 그것을 어떻게 다루는지를 분류합니다.
해석 원칙을 안내하는 방식, 서버가 규칙이나 모델로 발견사항과 결론을 만드는 방식, 서버 안 모델에게 줄 입력을 구성하는 방식, 발견사항을 기록하는 방식, 그 근거를 검증하는 방식, 보고 산출물을 구성하는 방식이 이 축에 속합니다.
발견사항과 결론을 응답에 싣는 형태(잘림, 출처, 상태)는 R축에서, 그것을 담은 파일의 보관·경로·해시는 D축에서 봅니다.
