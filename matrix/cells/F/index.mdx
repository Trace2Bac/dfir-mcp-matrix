# F 발견사항·결론 관리

DFIR MCP 서버가 조사에서 나온 판단을 다루는 방식을 분류합니다.
판단은 서버가 규칙이나 모델로 만드는 결론과, 서버가 기록으로 받는 발견사항·가설입니다.
판단을 만들고, 판단 방법을 안내하고, 남기고, 근거를 확인하고, 보고 내용으로 구성하는 방식이 이 축에 속합니다.
판단을 응답에 싣는 형태(잘림, 출처, 상태)는 R축에서, 판단을 담은 파일의 보관·경로·해시는 D축에서 봅니다.
