question: 기록으로 받는 발견사항과 가설의 내용, 판정, 근거, 시각, 수정과 철회, 배제 처분을 저장하는 방식을 분류합니다.
conditional: false
boundary: 근거를 서버가 심사하는 방식과 근거가 서버 기록에 있는지 대조하는 것은 F05에서, 보고서 본문 서술만 받는 것은 F06에서 봅니다. 기록하려는 발견사항에 붙는 단서와 확인 권고는 F01에서 봅니다. 대상별 수행 범위 기록은 P03에서 봅니다. 발견사항을 담은 DB나 파일의 보관 위치와 형태는 D01에서, 경로는 D04에서, 해시는 D03에서, 저장 실패는 D09에서 봅니다.
scope: 서버가 발견사항, 가설, 단서 메모, 배제 처분을 기록으로 받아 남기는 도구와 저장소가 대상입니다. 프로세스 메모리에 두는 기록도 포함합니다.
not_implemented: 발견사항을 받는 도구는 있지만 그 내용을 서버에 남기지 않고 응답으로 되돌려주기만 하는 경우입니다.
not_applicable: 서버에 발견사항이나 가설을 받아 남기는 기능이 없는 경우입니다.

- id: F04.01
  name: 자유 노트
  include: 발견사항이나 단서를 정해진 판정 필드 없이 자유로운 글로 남기는 경우입니다(노트, 북마크 메모).
- id: F04.02
  name: 발견사항 필드 구분 저장
  include: 발견사항을 제목, 설명, 판정(심각도, 확신도 등)으로 나눈 필드로 받아 남기는 경우입니다.
- id: F04.03
  name: 근거 증거·호출 참조
  include: 발견사항에 근거로 삼은 증거, 호출, 파생물의 ID나 이름을 필드로 남기는 경우입니다.
- id: F04.04
  name: 사건 시각과 작성 시각 분리
  include: 발견사항이 가리키는 사건의 시각과 발견사항을 쓴 시각을 서로 다른 필드로 남기는 경우입니다.
  exclude: 작성 시각만 있는 경우는 이 상세에 연결하지 않습니다.
- id: F04.05
  name: 수정·철회 이력
  include: 발견사항이나 가설을 고치거나 철회할 때, 또는 가설 상태가 바뀔 때, 앞 값이나 바뀐 사실을 서버 저장소나 기록에 남겨, 무엇이 어떤 차례로 바뀌었는지 다시 볼 수 있는 경우입니다.
  exclude: 현재 값만 덮어쓰고 앞 값도 바뀐 사실도 남기지 않는 경우는 이 상세에 연결하지 않습니다.
- id: F04.06
  name: 파일·DB에 저장
  include: 발견사항을 파일이나 DB에 써서 서버를 다시 시작해도 남는 경우입니다.
  exclude: 프로세스 메모리에만 두는 경우는 이 상세에 연결하지 않습니다.
- id: F04.07
  name: 가설 지지·반박 근거 연결
  include: 가설을 발견사항과 따로 두고 그 가설을 지지하거나 반박하는 근거(호출, 발견사항)를 연결해 남기는 경우입니다.
- id: F04.08
  name: 가설 상태 관리
  include: 가설에 상태(열림, 지지, 기각 등)를 두고 서버가 정한 규칙이나 도구 호출로 상태를 바꾸는 경우입니다.
  exclude: 제목 접두어 같은 표기 규칙만 있는 경우는 해당하지 않습니다.
- id: F04.10
  name: 판정·분류 값 기준 대조
  include: 심각도나 확신도 같은 판정 값, 또는 ATT&CK 기법 ID 같은 분류 값이 서버가 정한 기준(코드에 정한 값 목록이나 서버가 읽는 참조 표)에 있는지 검사하고 어긋나면 거부하는 경우입니다.
  exclude: 값 목록을 도구 설명이나 안내문에만 적고 서버가 검사하지 않는 경우는 해당하지 않습니다.
- id: F04.11
  name: 근거·확신도 필드 필수 입력
  include: 발견사항을 받는 도구가 근거(근거 호출 ID, 증거 참조, 추론 설명)나 확신도를 입력 schema의 필수 인자로 두고 서버가 빈 값을 거부하는 경우입니다.
  exclude: schema에 필수로 적었지만 서버가 빈 값을 받는 경우는 해당하지 않습니다. 근거 필드가 있는지만 보면 F04.03에서 봅니다.
  seen_in: [mulder, sift-kernel, trudi]
- id: F04.12
  name: 관련 없음·배제 처분 기록
  include: 모델이 검토한 대상(출처, 상대방, 호스트, 단서)을 관련 없음, 잡음, 범위 밖, 배제로 정리한 처분을 대상과 사유와 함께 서버에 남기는 도구가 있는 경우입니다.
  exclude: 가설의 처분은 F04.07·F04.08에서 봅니다. 판정 필드에 benign 같은 값을 적는 노트는 F04.02에서 봅니다.
  seen_in: [trudi, Camel]
