---
id: P03
name: 조사 진척 판단
question: 대상별로 수행한 작업과 남은 작업, 완료 여부를 표현하고 판단하는 방식을 분류합니다.
conditional: false
boundary: 작업 목록이나 단계를 안내하기만 하는 것은 P02에서, 진척 판단으로 호출을 막는 것은 T03에서, 범위나 진행과 관계없는 조사 메모는 D05에서 봅니다.
scope: 서버가 수행 범위, 남은 작업, 완료를 표현하거나 판단하는 도구와 조건이 적용 범위입니다.
not_implemented: 서버가 무엇을 수행했고 무엇이 남았는지 표현하지 않고 완료 판단을 모델에 맡기는 경우입니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: P03.01
  name: 기준 작업 목록 대조
  include: 서버가 대상 유형마다 해야 할 작업 목록을 두고 실제 수행 기록과 대조해 수행한 작업과 남은 작업을 알려 주면 해당합니다.
- id: P03.03
  name: 단계 상태·완료 조건 대조
  include: 서버가 조사 단계나 완료 조건을 두고 지금 상태가 그 조건을 채우는지 판단해 알려 주면 해당합니다. 완료 조건은 최소 결과 수, 필수
    작업 호출, 진행 중인 작업의 종료 같은 것입니다.
- id: P03.04
  name: 미조사 범위·생략 사유 보고
  include: 서버가 다루지 않은 대상이나 자료, 건너뛴 작업과 그 사유를 응답에 실어 주면 해당합니다.
- id: P03.05
  name: 모델이 적은 진행 기록 보관
  include: 모델이 대상별로 마친 작업, 다룬 질문, 확인하지 못한 범위를 도구로 적으면 서버가 이를 저장하는 경우입니다.
  exclude: 서버가 호출 기록으로 직접 집계한 시도와 결과는 해당하지 않습니다(후보 P03.02).
