conditional: false
boundary: 수행 범위와 완료를 판단하는 것은 P03에서, 권고를 따르지 않은 호출을 막는 것은 T03에서 봅니다. 저장한 조사 상태를 유지하거나 복구하는 장치는 P06에서 봅니다.
scope: 서버가 절차, 작업 묶음, 다음 작업을 정하거나 권하는 도구와 응답이 적용 범위입니다.
not_implemented: 서버가 절차나 다음 작업을 정하거나 권하지 않고 모델이 도구 목록만 보고 고르는 경우입니다. 도구 하나의 설명에 순서
  안내가 적혀 있기만 한 경우도 미구현으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: P02.01
  name: 고정 문서·프로필 반환
  include: 서버가 미리 정한 절차서, 도구 안내, 조사 프로필을 도구나 리소스, 지침으로 돌려주면 해당합니다.
- id: P02.02
  name: 규칙·조사 상태로 추천
  include: 서버가 규칙과 조사 상태를 보고 다음에 할 작업을 응답에 실어 주면 해당합니다. 조사 상태는 적재한 자료, 호출 기록, 판별한
    형식, 남은 조건 같은 것입니다.
- id: P02.03
  name: 모델 계획 생성
  include: 서버 안에서 부른 모델이 조사 상태를 받아 절차나 다음 작업 계획을 만들면 해당합니다.
  exclude: 서버를 쓰는 클라이언트나 오케스트레이터의 모델이 세운 계획은 해당하지 않습니다.
- id: P02.04
  name: 서버 코드에 고정한 분석 절차
  include: 서버가 한 조사 목적을 위한 분석 단계와 그 차례, 결과를 합치는 방법을 코드로 묶어 도구나 메서드로 두면 해당합니다. 모델은 묶음과
    인자만 고르고 그 안의 단계는 서버가 정합니다.
- id: P02.05
  name: 문맥 손실 뒤 재조회 절차 안내
  include: 서버가 도구 설명, 서버 지침, MCP 리소스에서, 클라이언트 문맥이 압축되거나 끊긴 뒤 저장한 조사 상태를 다시 읽는 도구를 부르라고 안내하는 경우입니다.
