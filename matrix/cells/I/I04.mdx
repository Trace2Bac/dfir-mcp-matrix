id: I04
name: 서버 자격증명 처리
question: 서버가 외부에 접속할 때 쓰는 API 키, 인증서, 토큰을 어디에 보관하고 응답과 기록에서 어떻게 빼나요?
conditional: false
boundary: 서버를 부르는 호출자의 인증은 T03에서, 증거에서 나온 비밀 값은 R06에서 봅니다.
scope: 서버 코드가 외부 서비스나 백엔드에 접속할 때 쓰는 자격증명(API 키, 토큰, 인증서, 비밀번호)이 적용 범위입니다.
not_implemented: 자격증명을 코드나 저장소 파일에 그대로 적어 두거나 도구 인자로 받고 응답이나 기록에서 빼는 처리도 없는 경우입니다.
not_applicable: 서버 코드가 자격증명이 필요한 외부 연동을 하지 않는 경우입니다.
details:
- id: I04.01
  name: 환경변수·설정 파일에 분리 보관
  include: 자격증명을 코드 밖의 환경변수나 설정 파일에 두고 서버가 실행 중에 읽는 경우입니다.
  exclude: 비밀 관리 도구나 실행 환경이 실행할 때 넣어 주고 서버 설정에는 남기지 않는 경우는 I04.02에서 봅니다.
- id: I04.02
  name: 실행 시 주입
  include: 비밀 관리 도구(vault, keyring, 컨테이너 secret)나 클라이언트가 실행할 때 자격증명을 넣어 주고 서버 설정에는 값을
    두지 않는 경우입니다.
  exclude: 사용자가 미리 설정한 환경변수를 읽기만 하는 경우는 I04.01에서 봅니다.
- id: I04.03
  name: 설정 파일 권한 검사
  include: 자격증명을 담은 파일의 소유자와 권한을 서버가 검사하고 권한이 너무 넓으면 경고하거나 거부하는 경우입니다.
  exclude: 문서가 권한 설정을 권하기만 하는 경우는 해당하지 않습니다.
- id: I04.04
  name: 도구 인자 수신 금지
  include: 자격증명을 도구 인자로 받지 않고 서버가 직접 읽어서 모델이 값을 보거나 넘기지 않는 경우입니다. 프로필 이름처럼 값이 아닌 이름만
    인자로 고르게 해도 해당합니다.
  exclude: 응답이나 기록에서 자격증명 값을 지우는 것은 I04.05에서 봅니다.
- id: I04.05
  name: 응답·기록·오류에서 비밀값 제거
  include: 응답, 호출 기록, 로그, 오류 문구에서 자격증명 값을 찾아 지우거나 가리는 경우입니다.
  exclude: 자격증명을 처음부터 응답이나 기록에 넣지 않는 것은 해당하지 않습니다.
- id: I04.06
  name: 권한·수명 제한
  include: 서버가 쓰는 자격증명의 권한 범위(읽기 전용 등)나 유효 기간을 서버 코드나 저장소의 구성이 좁히는 경우입니다.
  exclude: 문서가 좁은 권한을 권하기만 하는 경우는 해당하지 않습니다.
