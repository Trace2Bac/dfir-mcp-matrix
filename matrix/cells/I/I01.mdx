---
id: I01
name: 외부 연동 대상 관리
question: 외부 연동이 켜지는 조건과 접속 대상을 정하고 제한하는 방식을 분류합니다.
conditional: false
boundary: 사용자가 정한 원격 분석 호스트에 서버 코드가 여는 연결도 I01·I03·I04에서 보고, 그 호스트에서 분석을 실행하는 방식은 T04에서 봅니다. 서버 코드가 연결하려고 실행하는 클라이언트 프로그램(ssh, 평판 조회 프로그램)의 연결도 I01에서 보고, 그 프로그램이나 분석 도구가 의도한 연결 밖에서 스스로 하는 통신은 I02에서 봅니다. 자격증명의 보관과 가림은 I04에서 봅니다.
scope: 서버 코드가 스스로 여는 외부 연결이 적용 범위입니다. 외부 API 질의, 원격 저장소나 자료의 갱신, 원격 백엔드 접속이 그 예입니다.
  서버 밖에서 실행하는 설치 명령의 내려받기는 보지 않습니다.
not_implemented: 없습니다. 외부에 연결하는 서버는 연결을 켜는 조건을 가리키는 상세(명시적 설정으로 활성화, 자격증명 존재로 활성화, 기본 활성화, 호출별 선택)와 목적지를 가리키는 상세(고정 목적지, 설정으로 목적지 지정)에서 하나 이상씩 해당합니다.
not_applicable: 서버 코드가 스스로 외부에 연결하지 않는 경우입니다.
details:
- id: I01.01
  name: 명시적 설정으로 활성화
  include: 사용자가 설정 파일, 환경변수, 시작 인자로 외부 연동을 켜야만 연결이 생기는 경우입니다.
- id: I01.02
  name: 자격증명 존재로 활성화
  include: 외부 서비스의 자격증명(API 키 등)이 설정되어 있으면 그 서비스로 요청하고 없으면 요청하지 않는 경우입니다.
- id: I01.03
  name: 기본 활성화
  include: 켜는 설정이나 자격증명이 없어도 기본으로 외부에 연결하는 경우입니다. 끄는 설정이 있거나 설치 상태에 따라 연결을 건너뛰어도 해당합니다.
- id: I01.04
  name: 호출별 선택
  include: 연동을 쓸지, 어느 외부 서비스를 쓸지를 호출할 때마다 호출 인자로 고르는 경우입니다. 사용자 설정에 등록한 대상 가운데
    하나를 이름으로 고르는 경우도 포함합니다.
  exclude: 접속할 호스트나 URL 자체를 인자로 받는 경우는 해당하지 않습니다.
- id: I01.05
  name: 고정 목적지
  include: 목적지 주소를 코드에 고정해 두어 설정이나 호출 인자로 바꿀 수 없는 경우입니다.
  exclude: 인자 값이 고정 주소의 경로나 질의 값에만 들어가는 것은 목적지 지정에 해당하지 않습니다.
- id: I01.06
  name: 설정으로 목적지 지정
  include: 목적지를 사용자 설정(설정 파일, 환경변수, 설치된 자산의 원격 주소 등)이 정하고 호출 인자로는 바꿀 수 없는 경우입니다. 코드에
    기본값이 있어도 설정으로 바꿀 수 있으면 해당합니다.
- id: I01.07
  name: 목적지 허용 목록
  include: 서버가 허용한 호스트나 주소 목록을 두고 그 밖의 목적지로 가는 연결을 거부하는 경우입니다.
  exclude: 코드에 주소를 고정했을 뿐 목록과 대조하지 않는 경우는 I01.05에서 봅니다.
