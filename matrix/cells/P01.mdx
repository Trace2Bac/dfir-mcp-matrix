---
id: P01
name: 분석 방법 적합성 확인
question: 서버는 무엇으로 증거 형식과 OS, 대상 환경을 정하고, 고른 분석 방법·프로필·참조 자료가 그 입력에 맞는지 어떻게 확인하나요?
conditional: false
boundary: 호출자가 준 유형을 서버가 대조하지 않고 그대로 받으면 미구현입니다.
scope: 서버가 증거 형식, OS, 대상 영역을 판별하는 경로가 적용 범위입니다. 그 판별로 방법을 고르거나 고른 방법을 대조한다고 원고의 구현
  단락에 적은 도구도 포함합니다. 다음 경우에는 †를 붙입니다. 같은 입력을 경로마다 다르게 판별하는 경우, 그 도구의 일부 실행 경로에서 판별이나
  대조가 빠지는 경우, 판별 중 오류가 났는데 알리지 않고 판별 없이 진행하는 경우입니다. 판별이나 대조가 없는 다른 도구에는 †를 붙이지 않고
  원고의 구현 단락에 씁니다.
not_implemented: 서버가 증거 형식이나 OS를 판별하지 않고, 호출자가 준 유형이나 방법을 대조 없이 받는 경우입니다. 도구 설명으로
  맞는 입력을 안내하기만 하는 경우도 미구현으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: P01.01
  name: 이름·확장자 판별
  include: 파일 이름, 확장자, 폴더 이름으로 증거 형식이나 처리 경로를 정하면 해당합니다.
  exclude: 같은 판별 과정에서 내용을 읽어 확인도 하면 P01.03에도 함께 연결합니다.
- id: P01.02
  name: 메타데이터 조회
  include: 파일 속성이나, 분석 도구가 읽은 파티션 표나 파일 시스템 정보를 조회해 형식과 대상 영역을 정하면 해당합니다. 파일 속성은 파일
    크기나 함께 있는 파일 같은 정보입니다.
  exclude: 서버가 입력의 바이트를 직접 읽어 서명을 대조하는 경우는 여기가 아니라 P01.03에서 봅니다.
- id: P01.03
  name: 내용·헤더 검사
  include: 서버가 입력의 바이트를 읽거나 형식 라이브러리로 열어 보고, 서명이나 헤더, 구조로 형식을 확인하면 해당합니다.
  exclude: 파일 위장 탐지처럼 형식을 판별하는 것 자체가 분석 결과인 도구는 해당하지 않습니다.
- id: P01.04
  name: 방법과 형식·OS 대조
  include: 고른 방법이 판별한 형식, OS, 입력과 맞는지 서버가 대조하면 해당합니다. 대조 대상은 도구, 플러그인, 프로필과 그 부속 입력(심볼,
    규칙, 매핑, 하이브 유형 등)입니다. 맞지 않으면 실행하지 않거나, 실행 결과로 쓰지 않거나, 맞는 방법으로 돌립니다.
  exclude: 실행이 실패한 뒤 오류 문구만 보고 원인을 추정하는 경우는 해당하지 않습니다. 실패한 뒤라도 입력을 다시 판별해 대조하면 연결합니다.
    부속 입력 파일이 있는지만 확인하는 경우는 여기가 아니라 T07.01에서 봅니다.
- id: P01.06
  name: 지원 카탈로그·검증 목록 대조
  include: 서버가 형식이나 OS별로 지원하는 방법 목록 또는 검증한 조합 목록을 두고, 실행 전에 고른 방법이 그 목록에 있는지 대조하면
    해당합니다.
  exclude: 목록을 모델에게 보여 주기만 하는 경우는 여기가 아니라 P02.01에서 봅니다. 실행한 뒤에 수행했는지를 대조하는 경우는 P03.01에서
    봅니다.
retired:
- id: P01.05
  name: 필수 입력 확인
  merged_into: P01.04
  reason: 부속 입력이 맞는지는 P01.04에서 보고, 부속 입력이 있는지만 확인하는 검사는 T07.01에서 봅니다(docs/decisions/0010).
