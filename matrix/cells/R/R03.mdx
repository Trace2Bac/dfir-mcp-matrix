scope: 서버가 호출자에게 실행 결과의 상태와 실행 중 상태를 알리는 응답과 알림이 적용 범위입니다.
not_implemented: 응답에 성공과 실패를 구분하는 값이 없고 MCP 오류 결과도 쓰지 않는 경우입니다. 문장으로만 알리는 경우도 미구현으로

  name: 구조화 status·error
  include: 응답의 정해진 필드(status, 오류 종류)나 MCP 오류 결과(isError)로 성공과 실패를 구분하는 경우입니다.
- id: R03.02
  name: 찾지 못함과 실패 구분
  include: 결과가 없는 것(일치 0건, 대상 없음)을 실행 실패나 입력 부재와 다른 상태 값이나 필드로 돌려주는 경우입니다. 필드 이름이 `error`여도 정상 결과 안에서 실패와 다른 값으로 돌려주면 해당합니다.
  exclude: 빈 결과와 실패를 같은 값으로 돌려주거나 문장으로만 구분하는 경우는 해당하지 않습니다.
- id: R03.03
  name: 입력별 성공·실패·생략 목록
  include: 입력이나 하위 작업 여러 개를 처리한 응답에, 항목마다 성공, 실패, 생략 여부와 그 식별자를 싣는 경우입니다.
  exclude: 개수만 싣는 경우는 해당하지 않습니다.
- id: R03.04
  name: 시간 초과·부분 완료 표시
  include: 시간 초과나 중단으로 결과가 없거나 일부만 나왔다는 사실을 상태 값이나 필드로 알리는 경우입니다.
  exclude: 결과 본문에 문장만 덧붙이는 경우는 해당하지 않습니다.
- id: R03.05
  name: 실행 중 경과·생존 알림
  include: 오래 걸리는 호출이 끝나기 전에 서버가 MCP 진행 알림 같은 경로로 실행 중이라는 사실과 경과 시간, 진행 정도를 호출자에게 보내는
    경우입니다. 실제 분석 진행률이 아니라 경과 시간이나 살아 있다는 사실만 알려도 해당합니다.
