# R 실행 결과 전달

DFIR MCP 서버가 도구에서 얻은 관측과 서버가 만든 분석 결과를 모델에게 표현하고 전달하는 방식을 분류합니다.
출력 가공, 응답 항목 선별, 대량 결과 전달, 상태 알림, 도구 결과의 해석 주의, 출처 표시, 민감정보 처리, 증거 내용과 지시의 구분, 시간값 처리가 이 축에 속합니다.
같은 결과를 무엇으로 판단하고 기록하고 검증하는지는 F축에서, 저장된 표현을 어떻게 보관하고 지키는지는 D축에서 봅니다.
code-mode 서버는 SDK 메서드가 모델의 코드에 돌려주는 객체를 R01~R06과 R08의 결과로 보고, R07은 MCP 응답 글을 봅니다.
