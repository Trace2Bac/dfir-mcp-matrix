---
id: R05
name: 결과 출처 표시
question: 결과 항목마다 그 출처(증거, 파일, 레코드 또는 참조 지식)를 응답에 표시하는 방식을 분류합니다.
conditional: false
boundary: 결과의 식별자로 저장한 출력을 다시 읽는 방식은 R02에서, 자료 전체의 버전은 T06에서 봅니다. 발견사항의 근거 필드는 F04에서, 보고 산출물의 근거 링크는 F06에서 봅니다.
scope: 서버가 증거나 참조 지식에서 나온 결과를 돌려주는 도구가 적용 범위입니다. 참조 지식은 공격 기법 목록, 아티팩트 지식, 악용 가능 실행
  파일 목록, 외부 위협 정보 조회 결과처럼 사건 증거가 아닌 자료를 말합니다.
not_implemented: 결과에 출처를 가리키는 값도, 참조 지식이 증거가 아니라는 구분 표시도 없는 경우입니다. 출처를 가리키는 값은 증거나
  파일의 ID, 증거 안의 경로, 레코드 키, 오프셋, 참조 지식의 원문 주소나 원문 ID를 말합니다.
not_applicable: 서버가 증거에서 나온 결과도 참조 지식도 돌려주지 않는 경우입니다.
details:
- id: R05.01
  name: 증거·파일 ID
  include: 결과나 결과 항목에 그 결과가 나온 증거 파일의 ID나 경로가 있는 경우입니다. 서버가 붙인 저장 자료 ID나 이름으로 증거 경로를
    찾는 조회가 있는 경우도 여기에 해당합니다.
  exclude: 출처 이름이 증거 경로로 이어지지 않는 경우는 해당하지 않습니다.
- id: R05.02
  name: 증거 내부 경로
  include: 디스크 이미지나 압축 파일처럼 파일을 담은 증거에서, 결과가 나온 파일의 증거 안 경로를 결과 항목에 싣는 경우입니다. 외부 도구
    출력에 있는 경로를 그대로 전달해도 여기에 해당합니다.
  exclude: 서버가 증거에서 꺼낸 파일을 둔 작업 폴더의 경로는 증거 안의 경로가 아니므로 해당하지 않습니다.
- id: R05.03
  name: 레코드 키·번호
  include: 결과 항목에, 증거 안에서 그 레코드를 다시 찾을 수 있는 키나 번호가 있는 경우입니다. inode, 이벤트 레코드 번호, 레지스트리
    키 경로, DB 행 키가 그런 값입니다. 외부 도구 출력에 있는 값을 그대로 전달해도 여기에 해당합니다.
  exclude: 서버가 결과를 저장하면서 매긴 ID는 증거 안의 레코드가 아니므로 해당하지 않습니다.
- id: R05.04
  name: 바이트·섹터·행 오프셋
  include: 결과 항목이 증거 안 어디에 있는지를 바이트나 섹터 오프셋, 또는 텍스트 증거의 줄 번호로 싣는 경우입니다. 외부 도구 출력에
    있는 값을 그대로 전달해도 여기에 해당합니다.
  exclude: 서버가 저장한 출력 안의 줄 번호나 위치는 해당하지 않습니다. 메모리 분석의 가상 주소는 해당하지 않고 물리 오프셋은 해당합니다.
- id: R05.05
  name: 참조 지식 원문 출처
  include: 참조 지식 조회 결과의 항목마다 그 지식의 원문 위치(공식 페이지 주소, 원문 ID)를 싣는 경우입니다.
  exclude: 조회한 키를 되풀이하기만 하는 경우는 해당하지 않습니다.
- id: R05.06
  name: 참조 지식과 증거 결과 구분
  include: 서버가 돌려주거나 덧붙이는 참조 지식을 증거 결과와 다른 필드에 두고 그 필드가 증거가 아니라는 것을 코드나 설명에서 밝히는 경우입니다.
  exclude: 필드를 나누기만 하고 증거가 아니라고 밝히지 않으면 해당하지 않습니다.
