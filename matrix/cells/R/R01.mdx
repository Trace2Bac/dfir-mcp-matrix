---
id: R01
name: 결과 가공
question: 도구 출력과 서버가 만든 분석 결과를 응답에 맞게 가공하는 방식과 가공 사실을 표시하는 방식을 분류합니다.
conditional: false
boundary: 잘림과 보관한 출력의 재조회는 R02에서, 시각 값의 변환과 표시는 R08에서, 증거 내용과 지시를 구분하는 것은 R07에서, 항목마다 붙는 출처 표시는 R05에서 봅니다. 판정, 관계, 점수·등급, 흐름 서술을 만드는 것과, 계산한 값을 판정에 쓰는 것, 분석 대상이나 의심 후보를 정하는 제외 규칙과 차집합으로 후보를 고르는 규칙은 F02에서 봅니다(결정 0023·0034). 서버 안 모델이 관계, 가설, 판정을 새로 만드는 것은 F02에서, 그 모델에게 넘기는 입력의 구성은 F03에서 봅니다. 같은 호출이 가공과 판단을 함께 하면 두 셀에 함께 연결합니다.
scope: 서버가 도구 출력이나 분석 결과를 모델에게 돌려주는 응답이 적용 범위입니다.
not_implemented: 없습니다. 결과를 돌려주는 서버는 가공 방식 상세(R01.01~R01.03, R01.10, R01.11) 중 하나 이상에 해당합니다.
not_applicable: 서버가 도구 출력이나 분석 결과를 모델에게 돌려주지 않는 경우입니다.
details:
- id: R01.01
  name: 가공 없이 전달
  include: 서버가 도구 출력을 바꾸지 않고 응답이나 조회 도구로 돌려주는 경우입니다.
- id: R01.02
  name: 구조화 파싱·필드 선택
  include: 서버가 도구 출력을 파싱해 필드로 나누거나 그중 일부 필드나 값만 골라 응답하는 경우입니다.
  exclude: 모델이 인자로 고른 범위나 필드로 줄인 것은 가공에 해당하지 않습니다. 결과 항목(행)을 고르거나 빼는 것은 R01.11에서 봅니다.
- id: R01.03
  name: 형식 변환·건수 집계
  include: 서버가 도구 출력을 다른 형식으로 바꾸거나 여러 출력이나 레코드를 묶어 건수, 합계, 고유 값 수 같은 값을 계산해 응답하는 경우입니다.
- id: R01.05
  name: 가공 사실·대상 표시
  include: 응답이 서버가 가공한 결과라는 사실과, 가공에 쓴 원래 출력(source, 파일, 도구)을 응답에 적는 경우입니다.
- id: R01.10
  name: 호출자 코드로 가공
  include: 서버가 도구 출력을 파싱한 객체를 호출자(모델)가 보낸 코드에 넘기고 그 코드가 무엇을 골라 어떤 글로 응답에 실을지 정하는 경우입니다(code-mode).
- id: R01.11
  name: 응답 항목 선별
  include: 서버가 정해 둔 목록이나 규칙으로 응답에 실을 결과 항목을 고르거나 빼는 경우입니다. 이미 만든 관측이나 분석 결과 가운데 무엇을 응답 목록에 실을지만 정하고, 남은 항목의 뜻은 바뀌지 않습니다.
  exclude: 모델이 인자로 준 조건으로 거른 것은 해당하지 않습니다. 응답 크기 상한으로 자른 것은 해당하지 않습니다.
