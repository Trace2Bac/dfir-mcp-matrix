---
id: E02
name: 증거 무결성 검증
question: 어떤 바이트·범위를 언제 해시하고, 그 기준값과 현재 증거를 어떻게 대조해 차이를 처리하는가?
conditional: false
scope: 서버가 증거를 해시하거나 그 해시를 기준값과 대조한다고 구현에 적은 도구·경로다. 그 경로가 해시한다고 밝힌 증거 가운데 해시하지 않고
  지나가는 것이 있거나, 해시·대조를 설정·인자로 끄거나, 해시 실패·불일치에도 그대로 진행하면 †를 붙인다. 해시하지 않는 다른 도구는 †가 아니라
  구현에 적는다.
not_implemented: 서버가 증거 바이트의 해시를 계산하지 않는다. 증거 안에 적힌 해시 값(수집 도구 CSV의 해시 열 등)을 옮겨 싣기만
  하는 경우도 여기에 둔다.
not_applicable: 서버가 파일·바이트로 받는 증거가 없다(살아 있는 시스템을 조회만 하는 서버 등).
details:
- id: E02.01
  name: 등록 시 기준값 자동 계산
  include: 증거를 등록하거나 처음 열 때 모델의 요청 없이 서버가 해시를 계산한다. 해시 범위(파일 전체·분할 조각·이미지 안 파일·파티션)와
    그 값을 기준값으로 보관하는지 구현에 적는다.
  exclude: 서버가 만든 파생물·사건 DB의 해시는 D03이다. EWF 같은 컨테이너 형식이면 컨테이너 파일의 해시인지 담긴 매체 데이터의
    해시인지 구현에 적는다.
- id: E02.02
  name: 도구를 요청해 기준값 계산
  include: 모델이 해시 도구를 부를 때만 증거의 해시를 계산한다. 서버가 외부 해시 도구를 실행하는 경우도 든다. 해시 범위와 그 값을 기준값으로
    보관하는지 구현에 적는다.
  exclude: 분석 도구가 결과에 덧붙이는 해시는 구현에 적는다. 계산한 값을 기준값과 대조하면 E02.09다. 꺼낸 사본을 파생물로 보관하고
    그 해시를 남기는 것은 D03이다.
- id: E02.07
  name: 도구 호출 중 자동 검증
  include: 증거를 읽는 도구를 호출하는 과정에서 서버가 필요할 때 스스로 증거를 기준값과 대조한다. 대조 방법(전체 해시 재계산·크기·수정
    시각)과 기준값을 어디서 가져오는지(등록 때 받은 값·서버가 앞서 계산한 값·이미지 형식 안의 수집 해시) 구현에 적는다.
  exclude: 모델이 검증 도구를 따로 불러야 대조하면 E02.09다. 기준값이 없는 증거를 어떻게 처리하는지 구현에 적는다.
- id: E02.09
  name: 도구를 요청해 검증
  include: 모델이 검증 도구를 따로 불러야 서버가 증거를 기준값과 대조한다. 대조 방법과 기준값을 어디서 가져오는지 구현에 적는다.
  exclude: 다른 도구를 호출하는 과정에서 서버가 스스로 대조하면 E02.07이다. 기준값 없이 계산만 하면 E02.02다. 기준값이 없는
    증거를 어떻게 처리하는지 구현에 적는다.
- id: E02.08
  name: 불일치 시 중단·경고
  include: 해시 대조가 어긋나면 서버가 오류 응답·경고 문구·호출 기록 사건으로 알리거나 이후 분석 호출을 막는다.
  exclude: 경고만 하는지 실행을 막는지와 해시를 계산하지 못한 경우를 불일치로 다루는지 구현에 적는다. 표시 없이 대조 결과 값만 돌려주는
    것은 세지 않는다.
