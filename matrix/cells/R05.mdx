---
id: R05
name: 결과 출처 표시
question: 각 결과 항목이 어느 증거, 파일, 레코드에서 나왔는지 서버가 응답에 어떻게 표시하나요?
conditional: false
boundary: 결과의 식별자로 다시 읽고 대조하는 일은 뒤이어 오는 다른 호출이므로 이 셀에서 보지 않습니다. 저장한 출력을 다시 읽는 방식은
  R02에서, 파생물 대조는 D03에서 봅니다.
scope: 원고의 구현 단락에 연결한 상세의 출처 표시가 적용된다고 적은 도구의 결과가 적용 범위입니다. 그 도구 안에서 출처 표시가 빠지거나 실제와
  다른 출처를 적는 경로가 있으면 †를 붙입니다. 다른 반환 형식, 값 잘림, 상수로 적은 출처, 여러 증거를 한 이름으로 묶는 경우가 그 예입니다.
  출처 표시가 없는 다른 도구에는 †를 붙이지 않고 원고의 구현 단락에 씁니다.
not_implemented: 결과에 출처를 가리키는 값이 없는 경우입니다. 출처를 가리키는 값은 증거나 파일의 ID, 증거 안의 경로, 레코드 키,
  오프셋을 말합니다.
not_applicable: 서버가 증거에서 나온 결과를 돌려주지 않는 경우입니다.
details:
- id: R05.01
  name: 증거·파일 ID
  include: 결과나 결과 항목에 그 결과가 나온 증거 파일의 ID나 경로가 있는 경우입니다. 서버가 붙인 저장 자료 ID나 이름으로 증거 경로를
    찾는 조회가 있는 경우도 여기에 해당합니다.
  exclude: 증거 안의 파일 경로는 R05.02에서, 증거 안의 레코드는 R05.03에서 봅니다. 출처 이름이 증거 경로로 이어지지 않는 경우는
    해당하지 않습니다. 출처 값이 다른 인자와 구분 없이 이어 붙어 경계를 알 수 없으면 †를 붙입니다.
- id: R05.02
  name: 증거 내부 경로
  include: 디스크 이미지나 압축 파일처럼 파일을 담은 증거에서, 결과가 나온 파일의 증거 안 경로를 결과 항목에 싣는 경우입니다. 외부 도구
    출력에 있는 경로를 그대로 전달해도 여기에 해당합니다.
  exclude: 서버가 증거에서 꺼낸 파일을 둔 작업 폴더의 경로는 증거 안의 경로가 아니므로 해당하지 않습니다.
- id: R05.03
  name: 레코드 키·번호
  include: 결과 항목에, 증거 안에서 그 레코드를 다시 찾을 수 있는 키나 번호가 있는 경우입니다. inode, 이벤트 레코드 번호, 레지스트리
    키 경로, DB 행 키가 그런 값입니다. 외부 도구 출력에 있는 값을 그대로 전달해도 여기에 해당합니다.
  exclude: 서버가 결과를 저장하면서 매긴 ID는 증거 안의 레코드가 아니므로 해당하지 않습니다.
- id: R05.04
  name: 바이트·섹터·행 오프셋
  include: 결과 항목이 증거 안 어디에 있는지를 바이트나 섹터 오프셋, 또는 텍스트 증거의 줄 번호로 싣는 경우입니다. 외부 도구 출력에
    있는 값을 그대로 전달해도 여기에 해당합니다.
  exclude: 서버가 저장한 출력 안의 줄 번호나 위치는 증거 안의 위치가 아니므로 해당하지 않습니다. 메모리 분석의 가상 주소는 이미지 안의
    위치가 아니므로 해당하지 않습니다. 물리 오프셋은 해당하며, 이미지 형식에 따라 파일 안 위치와 다를 수 있다는 점을 원고에 씁니다.
retired:
- id: R05.05
  name: 원본 범위 재읽기
  reason: 결과의 식별자로 다시 읽는 일은 뒤이어 오는 다른 호출이므로, 결과를 전달하는 이 셀에서 보지 않습니다(docs/decisions/0008).
- id: R05.06
  name: 작업 사본·저장 출력 조회
  reason: 저장한 출력을 다시 읽는 방식은 R02에서 봅니다(docs/decisions/0008).
- id: R05.07
  name: 재조회 시 해시·내용 대조
  reason: 결과를 전달하는 이 셀에서 보지 않습니다(docs/decisions/0008).
- id: R05.08
  name: 별도 검증 도구 연계
  reason: 파생물 대조는 D03에서, 원본 증거 대조는 E02에서 봅니다(docs/decisions/0008).
