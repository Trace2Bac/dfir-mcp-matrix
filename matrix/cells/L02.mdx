---
id: L02
name: 기록 구성
question: 기록 항목에 요청, 실제 실행, 결과 상태, 모델 호출, 외부 요청 중 어떤 사건과 내용을 어떤 형태로 남기나요?
conditional: false
scope: 서버 기록에 항목이 남는 호출과 외부 요청이 적용 범위입니다. 기록을 만드는 장치와, 그 장치를 거치지 않는 호출은 L01에서 봅니다.
  다음 경우에는 †를 붙입니다. 그 항목에서 해당 상세의 내용이 빠지거나 다르게 남는 도구나 경로가 있는 경우, 기록에서 인자 사이의 경계가 사라지는
  경우입니다.
not_implemented: 기록은 남지만, 요청 내용(도구, 인자, 명령)도 결과 상태도 남기지 않는 경우입니다.
not_applicable: 서버가 기록을 남기지 않는 경우입니다.
details:
- id: L02.01
  name: 요청 원문 기록
  include: 모델이 보낸 도구 이름과 인자를 받은 그대로 기록하는 경우입니다.
  exclude: 서버가 바꾼 뒤의 값만 남는 경우는 여기가 아니라 L02.02에서 봅니다.
- id: L02.02
  name: 서버가 바꾼 인자 기록
  include: 서버가 dispatch, 기본값, 경로 변환을 적용한 뒤의 도구 이름과 인자를 기록하는 경우입니다.
  exclude: 외부 도구나 프로세스에 넘긴 명령을 기록하는 경우는 L02.03에서 봅니다. 요청 원문도 함께 남기면 L02.04에도 연결합니다.
- id: L02.03
  name: 실제 실행 명령 기록
  include: 외부 도구나 프로세스에 실제로 넘긴 실행 파일과 인자를 기록하는 경우입니다.
  exclude: 인자를 공백으로 이어 붙여 인자 사이의 경계가 사라지면, †를 붙이고 원고의 예외 단락에 씁니다. 서버 안의 함수만 부르는 도구는
    이 상세의 적용 범위가 아닙니다.
- id: L02.04
  name: 요청과 실행의 연결
  include: 요청 원문과, 서버가 바꾼 값 또는 실제 실행 명령을 함께 기록하고, 둘의 관계를 남기는 경우입니다.
  exclude: 어느 한쪽만 남긴 기록은 해당하지 않습니다.
- id: L02.05
  name: 모델 호출의 입력·응답 기록
  include: 서버가 부른 모델의 입력, 응답, 모델 식별 정보를 기록에 남기는 경우입니다. 판단을 다시 검토할 수 있도록 다음 내용도 함께
    남기는지 봅니다. 프롬프트나 판정 정책의 식별값, 추론 설정(온도 등), 그리고 모델 호출이 실패했을 때 그 사실과 그 뒤의 판정(통과 또는
    거부)입니다.
  exclude: 모델 이름과 버전만 남기는 경우는 T06의 "모델·버전 표시"에서 봅니다. 모델 호출이 실패했을 때 통과시키는지 막는지는 T03에서
    보는 게이트 동작입니다.
- id: L02.06
  name: 실행 시작·종료·결과 상태 기록
  include: 한 실행의 시작과 종료, 그리고 결과 상태(성공, 거부, 실패, 시간 초과)를 기록에 남기는 경우입니다.
  exclude: 실패를 알아차리는 방식은 T08에서, 응답으로 알리는 방식은 R03에서 봅니다. 기록 쓰기 자체가 실패할 때의 처리는 L03에서
    봅니다.
- id: L02.07
  name: 비동기 작업 최종 상태 기록
  include: 호출이 끝난 뒤에야 끝나는 작업(수집, 헌트, 백그라운드 실행)의 최종 상태를, 처음 호출의 기록에 이어서 남기는 경우입니다.
  exclude: 최종 상태를 조회하는 방식만 있는 경우는 T08에서 봅니다.
- id: L02.08
  name: 호출 ID·시각으로 항목 연결
  include: 한 호출에서 나온 여러 항목(요청, 실행, 결과, 외부 요청)을 같은 호출 ID나 시각으로 묶는 경우입니다.
  exclude: 입력이나 파생물과 실행을 잇는 것은 D02에서 봅니다.
- id: L02.09
  name: 외부 요청 내용 기록
  include: 서버가 외부 서비스에 보낸 요청의 목적지, 보낸 자료의 요약, 응답을, 그 요청을 일으킨 호출과 함께 기록하는 경우입니다.
  exclude: 무엇을 보내는지 자체는 I03에서, 자격증명이 기록에 섞이는지는 I04에서 봅니다.
