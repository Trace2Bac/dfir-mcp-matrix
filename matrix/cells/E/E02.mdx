id: E02
name: 증거 무결성 검증
question: 증거의 기준값을 계산하고 현재 증거와 대조해 차이를 처리하는 방식을 분류합니다.
conditional: false
boundary: 서버가 만든 파생물과 사건 DB의 기준값과 대조는 D03에서 봅니다. 참조 기준선과 비교해 바뀐 파일을 찾아 침해를 판정하는 분석(파일 무결성 감시 등)은 F02에서 봅니다.
scope: 서버가 증거의 기준값을 계산하거나 기준값과 대조하는 도구와 경로가 적용 범위입니다. 기준값은 내용의 해시, 키를 쓴 MAC이나 서명, 또는 상태 값(크기, 수정 시각, inode)을 묶은 값입니다. 상태 값은 서버가 기준값으로 남기거나 대조에 쓸 때만 기준값으로 봅니다. 응답에 파일 메타데이터를 보여 주기만 하는 것은 해당하지 않습니다.
not_implemented: 서버가 증거의 기준값을 계산하지도 대조하지도 않는 경우입니다. 증거 안에 이미 적힌 해시 값을 옮겨 싣기만 하는 경우도 미구현입니다.
not_applicable: 서버가 파일이나 바이트 형태로 받는 증거가 없는 경우입니다.
details:
- id: E02.01
  name: 등록 시 기준값 자동 계산
  include: 증거를 등록하거나 처음 열 때, 모델이 요청하지 않아도 서버가 기준값을 계산하면 해당합니다.
- id: E02.02
  name: 도구를 요청해 기준값 계산
  include: 모델이 기준값을 계산하는 도구를 부를 때만 서버가 증거의 기준값을 계산하면 해당합니다. 서버가 외부 해시 도구를 실행하는 경우도 해당합니다.
  exclude: 분석 도구가 결과에 덧붙이는 해시만으로는 해당하지 않습니다.
- id: E02.03
  name: 도구 호출 중 자동 검증
  include: 모델이 검증을 따로 요청하지 않은 다른 도구(증거를 읽는 도구, 발견사항 제출·심사 도구, 보고 도구 등)를 호출하는 과정에서 서버가
    스스로 증거를 기준값과 대조하면 해당합니다.
- id: E02.04
  name: 도구를 요청해 검증
  include: 모델이 검증 도구를 따로 불렀을 때만 서버가 증거를 기준값과 대조하면 해당합니다.
- id: E02.05
  name: 불일치 시 중단·경고
  include: 대조 결과가 어긋날 때 서버가 오류 응답, 경고 문구, 호출 기록의 사건으로 이를 알리거나 이후의 분석 호출을 막으면 해당합니다.
  exclude: 별도 표시 없이 대조 결과 값만 돌려주는 경우는 해당하지 않습니다.
