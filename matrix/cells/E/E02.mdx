---
id: E02
name: 증거 무결성 검증
question: 증거의 어떤 바이트 범위를 언제 해시하고 그 기준값과 현재 증거를 어떻게 대조해 차이를 처리하나요?
conditional: false
scope: 서버가 증거를 해시하거나 기준값과 대조하는 도구와 경로가 적용 범위입니다.
not_implemented: 서버가 증거 바이트의 해시를 계산하지 않는 경우입니다. 증거 안에 이미 적힌 해시 값을 옮겨 싣기만 하는 경우도 미구현입니다.
not_applicable: 서버가 파일이나 바이트 형태로 받는 증거가 없는 경우입니다.
details:
- id: E02.01
  name: 등록 시 기준값 자동 계산
  include: 증거를 등록하거나 처음 열 때, 모델이 요청하지 않아도 서버가 해시를 계산하면 해당합니다.
  exclude: 서버가 만든 파생물이나 사건 DB의 해시는 D03에서 봅니다.
- id: E02.02
  name: 도구를 요청해 기준값 계산
  include: 모델이 해시 도구를 부를 때만 서버가 증거의 해시를 계산하면 해당합니다. 서버가 외부 해시 도구를 실행하는 경우도 해당합니다.
  exclude: 계산한 값을 기준값과 대조하는 경우는 E02.09에서, 꺼낸 사본을 파생물로 보관하고 그 해시를 남기는 경우는 D03에서 봅니다.
    분석 도구가 결과에 덧붙이는 해시만으로는 해당하지 않습니다.
- id: E02.07
  name: 도구 호출 중 자동 검증
  include: 모델이 검증을 따로 요청하지 않은 다른 도구(증거를 읽는 도구, 발견사항 제출·심사 도구, 보고 도구 등)를 호출하는 과정에서 서버가
    스스로 증거를 기준값과 대조하면 해당합니다. 해시를 다시 계산하지 않고 크기나 수정 시각 같은 상태 값만 비교해도 해당합니다.
  exclude: 모델이 검증 도구를 따로 불러야 대조가 일어나는 경우는 E02.09에서 봅니다.
- id: E02.09
  name: 도구를 요청해 검증
  include: 모델이 검증 도구를 따로 불렀을 때만 서버가 증거를 기준값과 대조하면 해당합니다.
  exclude: 다른 도구를 호출하는 과정에서 서버가 스스로 대조하는 경우는 E02.07에서, 기준값 없이 해시를 계산만 하는 경우는 E02.02에서
    봅니다.
- id: E02.08
  name: 불일치 시 중단·경고
  include: 대조 결과가 어긋날 때 서버가 오류 응답, 경고 문구, 호출 기록의 사건으로 이를 알리거나 이후의 분석 호출을 막으면 해당합니다.
  exclude: 별도 표시 없이 대조 결과 값만 돌려주는 경우는 해당하지 않습니다.
