---
id: E04
name: 분석 입력 준비
question: 이미지나 보관 파일, 수집물에서 어떤 범위를 어떤 입력으로 준비하고, 트랜잭션 로그나 분할 이미지 같은 부속 자료는 어떻게 찾아
  반영하나요?
conditional: false
scope: 서버가 이미지, 보관 파일, 수집물에서 분석 입력을 만드는 도구와 경로가 적용 범위입니다. 그 입력에 딸린 부속 자료를 찾아 반영하는
  경로도 포함합니다. 부속 자료는 분할 조각, 트랜잭션 로그, `-wal` 등입니다. 원고의 구현 단락에 적은 경로를 기준으로, 다음 경우에는 예외 표시를
  붙입니다. 그 방식이 설명과 다르게 입력을 만드는 경우(다른 출처의 파일을 섞거나 일부만 준비하는 경우), 설정이나 인자로 그 방식을 끄는 경우,
  누락이 생겨도 알리지 않고 지나가는 경우입니다. 입력을 얻지 못해 다른 입력으로 바꿔 실행하는 경로는 여기가 아니라 T01.08에서 봅니다. 받은
  경로를 그대로 외부 도구에 넘길 뿐 입력을 준비하지 않는 다른 도구에는 예외 표시를 붙이지 않고 원고의 구현 단락에 씁니다.
not_implemented: 서버가 이미지, 보관 파일, 수집물을 받지만 입력을 따로 준비하지 않는 경우입니다. 받은 경로를 그대로 외부 도구에
  넘기고, 부속 자료도 다루지 않습니다.
not_applicable: 서버가 이미지, 보관 파일, 수집물 같은 증거 입력을 받지 않는 경우입니다.
details:
- id: E04.01
  name: 작업 사본 생성
  include: 서버가 증거 파일이나 보관 파일의 내용 전체를 별도 작업 위치에 복사하거나 풀고, 그 사본을 분석 입력으로 쓰면 해당합니다.
  exclude: 이미지에서 필요한 파일만 꺼내는 경우는 여기가 아니라 E04.02에서 봅니다. 사본을 만드는 것은 원본 변경 방지(E03)로 인정하지
    않습니다. 사본을 어디에 쓰고 덮어쓰는지는 D04에서 봅니다.
- id: E04.02
  name: 선택 추출
  include: 이미지, 보관 파일, 폴더에서 경로, 이름, inode로 고른 파일만 분석 입력으로 쓰면 해당합니다. 사본을 꺼내는지, 제자리에서
    고르는지, 링크로 모으는지는 원고의 구현 단락에 씁니다.
  exclude: 파일을 고르는 기준(경로를 대조하는 방식)과 꺼낸 위치를 원고에 씁니다. 꺼낸 범위를 응답이나 기록에 남기는지는 E04.05에서
    봅니다.
- id: E04.03
  name: 전체·부분 마운트
  include: 이미지 전체나 그 안의 파티션, 볼륨을 파일시스템 단위로 열어 분석 범위로 삼으면 해당합니다. 다음 두 방식이 여기에 해당합니다.
    하나는 파일시스템으로 마운트해 그 아래 파일을 읽게 하는 방식입니다. 다른 하나는 서버가 고른 파티션의 시작 위치를 분석 도구에 넘겨 그 파티션만
    읽게 하는 방식입니다.
  exclude: 마운트가 읽기 전용인지는 E03.01에서 봅니다. 분석 도구에 넘길 파티션 시작 위치를 모델이 인자로 주게만 하는 경우는
    해당하지 않으며 원고에 씁니다. 파일시스템으로 마운트하는 경우는 시작 위치를 누가 정하든 해당하고, 누가 정하는지 원고에 씁니다. 파티션을 고르는 기준과, 고른 값을 언제 다시 정하는지 원고에 씁니다. 이미지를 평면 파일로만 보이게 하는 장치라면 그 범위도 원고에
    씁니다.
- id: E04.04
  name: 메모리 사본 파싱
  include: 서버가 메모리 덤프를 분석하기 전에 형식을 바꾸거나 사본을 만들고, 그것을 분석 입력으로 쓰면 해당합니다.
  exclude: 덤프를 그대로 분석 도구에 넘기는 경우는 입력 준비로 인정하지 않습니다. 덤프에서 파일이나 프로세스를 꺼내는 경우는 여기가 아니라
    E04.02에서 봅니다.
- id: E04.05
  name: 추출·생략 범위 기록
  include: 서버가 준비한 입력의 범위나, 빼거나 꺼내지 못한 범위를 응답이나 기록에 남기면 해당합니다. 입력의 범위란 꺼낸 파일 목록, 건수,
    크기를 말합니다.
  exclude: 도구 출력이 잘리는 문제는 R02에서, 실행 실패 상태는 R03과 T08에서 봅니다. 서버 운영 로그에만 남기는 경고는 해당하지
    않으며 원고에 씁니다. 호출 기록에 모델이 준 인자가 그대로 남는 것만으로는 해당하지 않습니다. 서버가 준비한 입력으로 바꾼 인자가 기록에
    남으면 해당합니다.
- id: E04.06
  name: 동반 파일 탐색
  include: 서버 코드가 입력 옆에 있는 부속 파일을 찾아 입력과 함께 넘기거나 옮기면 해당합니다. 부속 파일은 분할 조각, 트랜잭션 로그,
    `-wal` 같은 파일입니다.
  exclude: 다음 경우는 해당하지 않으며 원고에 씁니다. 외부 도구가 스스로 부속 파일을 찾는 경우, 경로 대조에 우연히 걸려 함께 꺼내지는
    경우입니다.
- id: E04.07
  name: 부속 자료 누락·로그 미반영 표시
  include: 서버가 분석 입력의 부속 자료(트랜잭션 로그, `-wal` 등)가 없거나 입력에 반영되지 않았다는 것을 응답에 표시하는 경우입니다.
  exclude: 부속 자료를 찾아 함께 옮기는 일은 E04.06에서, 로그를 적용하는 일은 E04.08에서 봅니다. 도구 설명에만 적은 경우는 해당하지
    않습니다.
- id: E04.08
  name: 로그 재생·복원
  include: 서버 코드가 다음 방법 중 하나로 마지막 상태의 입력을 만들면 해당합니다. 트랜잭션 로그나 `-wal`을 입력에 직접 적용하는
    방법, 로그를 적용하는 외부 도구에 로그를 함께 넘기는 방법, 적용할지를 인자로 정하는 방법입니다.
  exclude: 로그를 찾아 함께 옮기는 일은 E04.06에서, 로그를 적용했는지 응답에 표시하는 일은 E04.07에서 봅니다. 적용을 외부 도구에
    맡기는 경우에는, 그 사실과 실제 적용을 확인했는지를 원고에 씁니다. 외부 도구가 서버의 관여 없이 스스로 로그를 찾아 적용하는 경우는
    해당하지 않으며 그 사실을 원고에 씁니다.
