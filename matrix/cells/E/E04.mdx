---
id: E04
name: 분석 입력 준비
question: 이미지, 보관 파일, 수집물에서 분석 입력을 준비하고 분할 조각이나 트랜잭션 로그 같은 부속 자료를 찾아 반영하는 방식을 분류합니다.
conditional: false
boundary: 입력을 얻지 못해 다른 입력으로 바꿔 실행하는 것은 T01에서, 원본을 바꾸지 않게 막는 장치(읽기 전용 마운트 등)는 E03에서, 사본을 쓸 위치는 D04에서, 다시 만들 때의 덮어쓰기는 D10에서 봅니다. 어느 파티션을 분석 대상으로 고르는지는 P01에서 봅니다.
scope: 서버가 이미지, 보관 파일, 수집물에서 분석 입력을 만드는 도구와 경로, 그리고 그 입력에 딸린 부속 자료(분할 조각, 트랜잭션 로그,
  `-wal` 등)를 찾아 반영하는 경로가 적용 범위입니다.
not_implemented: 서버가 이미지, 보관 파일, 수집물을 받지만 입력을 따로 준비하지 않고 받은 경로를 그대로 외부 도구에 넘기며 부속
  자료도 다루지 않는 경우입니다.
not_applicable: 서버가 이미지, 보관 파일, 수집물 같은 증거 입력을 받지 않는 경우입니다.
details:
- id: E04.01
  name: 작업 사본 생성
  include: 서버가 증거 파일이나 보관 파일의 내용 전체, 또는 이미지 안 파일시스템의 파일을 한꺼번에 별도 작업 위치에 복사하거나 풀거나 꺼내
    분석 입력으로 쓰면 해당합니다. 서버가 꺼낸 사본을 같은 호출에서 다음 분석에 넘기는지와 관계없이 분석에 쓰도록 꺼내 두면 해당합니다.
- id: E04.02
  name: 선택 추출
  include: 이미지, 보관 파일, 폴더에서 경로, 이름, inode로 고른 파일이나 내용 서명으로 찾아 잘라 낸 범위만 분석 입력으로 쓰면 해당합니다.
    사본으로 꺼내거나 제자리에서 고르거나 링크로 모으는 경우 모두 해당합니다.
- id: E04.03
  name: 전체·부분 마운트
  include: 이미지 전체나 그 안의 파티션, 볼륨을 파일시스템 단위로 열어 분석 범위로 삼으면 해당합니다. 파일시스템으로 마운트해 그 아래 파일을
    읽게 하는 방식과 서버가 고른 파티션의 시작 위치를 분석 도구에 넘겨 그 파티션만 읽게 하는 방식이 해당합니다. 파일시스템으로 마운트하는 경우는
    시작 위치를 누가 정하든 해당합니다.
  exclude: 분석 도구에 넘길 파티션 시작 위치를 모델이 인자로 주게만 하는 경우는 해당하지 않습니다.
- id: E04.05
  name: 추출·생략 범위 기록
  include: 서버가 준비한 입력의 범위(꺼낸 파일 목록, 건수, 크기)나 빼거나 꺼내지 못한 범위를 응답이나 기록에 남기면 해당합니다. 서버가
    준비한 입력으로 바꾼 인자가 호출 기록에 남는 경우도 해당합니다.
  exclude: 서버 운영 로그에만 남기는 경고와 호출 기록에 모델이 준 인자가 그대로 남는 것은 해당하지 않습니다.
- id: E04.06
  name: 부속 자료 탐색
  include: 서버 코드가 입력 옆에 있는 부속 자료를 찾아 입력과 함께 넘기거나 옮기면 해당합니다. 부속 자료는 분할 조각, 트랜잭션 로그, `-wal`
    같은 파일입니다.
  exclude: 외부 도구가 스스로 부속 자료를 찾는 경우와 경로 대조에 맞아 우연히 함께 꺼내지는 경우는 해당하지 않습니다.
- id: E04.07
  name: 부속 자료 누락·로그 미반영 표시
  include: 서버가 분석 입력의 부속 자료(트랜잭션 로그, `-wal` 등)가 없거나 입력에 반영되지 않았다는 것을 응답에 표시하는 경우입니다.
  exclude: 도구 설명에만 적은 경우는 해당하지 않습니다.
- id: E04.08
  name: 로그 재생·복원
  include: 서버 코드가 다음 방법 중 하나로 마지막 상태의 입력을 만들면 해당합니다. 트랜잭션 로그나 `-wal`을 입력에 직접 적용하는
    방법, 로그를 적용하는 외부 도구에 로그를 함께 넘기는 방법, 적용할지를 인자로 정하는 방법입니다.
  exclude: 외부 도구가 서버의 관여 없이 스스로 로그를 찾아 적용하는 경우는 해당하지 않습니다.
