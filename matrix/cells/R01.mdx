---
id: R01
name: 도구 출력 가공
question: 서버는 도구 출력을 어떤 변환, 추출, 요약을 거쳐 응답하나요? 시간값은 어떻게 변환하고 표현하며, 가공했다는 사실과 변환 전 값은
  어떻게 드러내나요?
conditional: false
boundary: 잘림은 R02에서, 증거 내용과 지시를 구분하는 것은 R07에서 봅니다.
scope: 원고의 구현 단락에 연결한 상세의 가공, 표시, 시간 처리가 적용된다고 적은 응답 경로가 적용 범위입니다. 다음 경우에는 †를 붙입니다.
  그 경로 안에서 설명과 다르게 가공하는 경우, 가공 대상이나 변환 전 값, 시간대를 알리는 표시가 빠지거나 실제와 다른 경우입니다. 그 방식을
  쓰지 않는 다른 도구에는 †를 붙이지 않고 원고의 구현 단락에 씁니다.
not_implemented: 이 셀에서는 미구현을 쓰지 않습니다. 도구 출력을 돌려주는 서버는 가공 방식 상세(R01.01~R01.04) 중 하나
  이상에 해당하기 때문입니다. 가공 사실이나 변환 전 값을 드러내지 않는 경우는 R01.05~R01.09에 연결하지 않고 원고의 구현 단락에 씁니다.
not_applicable: 서버가 도구 출력이나 그 가공 결과를 모델에게 돌려주지 않는 경우입니다.
details:
- id: R01.01
  name: 가공 없이 전달
  include: 서버가 도구 출력을 바꾸지 않고 응답이나 조회 도구로 돌려주는 경우입니다.
  exclude: 길이나 건수만 잘라 넘기는 것은 R02에서 봅니다. 서버가 필드를 고르거나 형식을 바꾸는 경우는 R01.02나 R01.03에서
    봅니다.
- id: R01.02
  name: 구조화 파싱·필드 선택
  include: 서버가 도구 출력을 파싱해 필드로 나누거나, 그중 일부 필드나 값만 골라 응답하는 경우입니다.
  exclude: 모델이 인자로 고른 범위나 필드로 줄인 것은 가공으로 인정하지 않습니다. 증거 내용을 서버 문구와 다른 필드에 두는 것이 지시와의
    구분이 되는지는 R07에서 봅니다.
- id: R01.03
  name: 형식 변환·집계
  include: 서버가 도구 출력을 다른 형식으로 바꾸거나, 여러 출력이나 레코드를 묶어 건수, 점수, 차집합, 상관 같은 값을 계산해 응답하는
    경우입니다.
  exclude: 계산한 값을 바탕으로 결론이나 공격 흐름을 서술하는 방식은 D06에서 봅니다.
- id: R01.04
  name: 모델 요약
  include: 서버가 모델을 불러 도구 출력을 요약하거나 해석한 글을 응답하는 경우입니다.
  exclude: 모델 호출의 입력과 응답 기록은 L02에서, 모델과 그 버전의 표시는 T06에서 봅니다.
- id: R01.05
  name: 가공 사실·대상 표시
  include: 응답이 서버가 가공한 결과라는 사실과, 가공에 쓴 원래 출력(source, 파일, 도구)을 응답에 적는 경우입니다.
  exclude: 잘림 표시는 R02에서, 응답 항목마다 붙는 출처 식별자와 그 재조회는 R05에서 봅니다.
- id: R01.06
  name: 시간 변환 전 값 유지
  include: 서버가 시각을 바꾸지 않고, 도구 출력의 원래 시각 표기를 그대로 전달하는 경우입니다.
  exclude: 바꾼 값과 원래 값을 함께 주는 경우는 R01.07에서 봅니다. 원래 값이 길이 상한에 걸려 잘리는 것은 R02에서 봅니다.
- id: R01.07
  name: 정규화 시간과 변환 전 값 병기
  include: 서버가 바꾼 시각과 원래 값(원래 문자열, 정수, 바이트)을 같은 응답 항목에 함께 싣는 경우입니다.
  exclude: 원래 값을 버리고 바꾼 값만 싣는 도구는 이 상세에 연결하지 않고 원고의 구현 단락에 씁니다.
- id: R01.08
  name: 시간대·단위·정밀도 표시
  include: 응답의 시각 값에 시간대(UTC 표기나 오프셋), 단위, 정밀도를 값이나 필드 이름으로 밝히는 경우입니다.
  exclude: 도구 설명에만 적고 응답 값에는 없는 경우는 해당하지 않습니다. 서버 지침이나 설명이 모든 시각의 시간대를 단언하는데 실제 값의
    시간대가 다르면 †를 붙입니다.
- id: R01.09
  name: 시간 변환·추정 사실 표시
  include: 서버가 바꾸거나 추정해 채운 시각이라는 사실을 응답의 필드, 값, 문구로 알리는 경우입니다. 연도나 시간대를 가정해 채운 경우가
    그 예입니다.
  exclude: 바꾼 값을 따로 두기만 하고, 무엇을 가정했는지 알리지 않는 경우는 해당하지 않습니다.
- id: R01.10
  name: 호출자 코드로 가공
  include: 서버가 도구 출력을 파싱한 객체를 호출자(모델)가 보낸 코드에 넘기고, 그 코드가 무엇을 골라 어떤 글로 응답에 실을지 정하는
    경우입니다(code-mode). 서버는 응답 형식을 강제하지 않습니다.
  exclude: 서버 코드가 가공하는 단계는 R01.02~R01.05에서 함께 봅니다. 호출자 코드가 그 객체를 어떻게 가공했는지는 서버가 정하지
    않으므로 †를 붙이지 않습니다.
