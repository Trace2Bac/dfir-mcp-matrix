id: D04
name: 출력 경로 제한
question: 파생물을 만들고 고치고 지우는 경로를 정하고 제한하는 방식을 분류합니다.
conditional: false
boundary: 원본 증거와 겹치는지 검사하는 것은 E03에서, 누가 지우는지와 흔적이 남는지는 P05에서 봅니다. 서버 기록 파일이 발견사항 같은 파생물도 함께 담으면 그 파일의 경로는 이 셀에서 보고, 서버 기록만 담은 파일의 위치와 이어 쓰기는 L01·L04에서 봅니다. 같은 작업을 다시 할 때 앞 산출물과 구분하는 방식과, 이름이 겹칠 때 앞 결과를 돌려주거나 덮어쓸지 고르게 하는 방식은 D10에서 봅니다.
scope: 서버가 파생물을 만들거나 고치거나 지우는 대상 경로가 대상입니다. 서버 코드가 정하는 목적지와, 서버가 부르는 외부 도구가 정하는 목적지를 모두 포함합니다.
not_implemented: 생성, 수정, 삭제 대상 경로를 호출 인자로 받아 그대로 쓰는 경우입니다.
not_applicable: 서버가 파생물을 담은 파일이나 DB를 만들거나 고치거나 지우지 않는 경우입니다.
details:
- id: D04.01
  name: 서버가 출력 위치 결정
  include: 생성 위치를 호출 인자가 아니라 서버가 정한 폴더와 이름 규칙으로 정하는 경우입니다. 호출 인자는 경로 구분자가 없는 이름 한 조각으로만 들어갑니다.
- id: D04.02
  name: 실제 경로와 허용 폴더 대조
  include: 호출 인자로 받은 목적지를, 링크와 `..`를 해석한 실제 경로로 바꿔 허용 폴더 안인지 대조하고 대조한 그 경로를 쓰는 경우입니다.
- id: D04.03
  name: 파생물 ID로만 수정·삭제
  include: 저장된 파생물을 고치거나 지우는 도구가, 경로가 아니라 서버가 매긴 ID로 대상을 고르는 경우입니다.
- id: D04.04
  name: 이름·확장자·충돌 검사
  include: 목적지 이름을 문자열로 검사해 거부하거나 건너뛰는 경우입니다. 목적지 이름은 호출 인자, 또는 압축 항목이나 이미지 안의 이름입니다. 검사 대상은 경로 구분자, `..`, 절대 경로, 제어 문자, 확장자, 또는 이미 있는 이름과 겹치는지 여부입니다.
