name: 기록 위변조 방지
question: 기록의 수정, 삭제, 순서 변경을 서버가 어떻게 막거나 알아차리나요?
conditional: false
boundary: 모델이 부를 수 있는 도구로 기록 전체를 지우거나 초기화하는 기능은 P05.01에서, 출력과 파생물의 위변조 확인은 D03에서 봅니다.
scope: MCP 도구 호출의 서버 기록을 담은 파일과 DB가 적용 범위입니다. 클라이언트 기록은 대상이 아닙니다.
not_implemented: 기록의 수정, 삭제, 순서 변경을 막거나 알아차리는 장치가 없는 경우입니다. 파일을 덧붙이기 모드로 여는 것만으로는
  막는 장치에 해당하지 않습니다.
not_applicable: 서버가 기록을 남기지 않는 경우입니다.
details:
- id: L04.01
  name: 해시 체인
  include: 항목마다 앞 항목의 해시를 넣어 해시를 잇는 경우입니다.
  exclude: 항목마다 따로 계산한 해시는 해당하지 않습니다. 해시 체인을 검증하는 도구는 L04.06에서 봅니다.
- id: L04.02
  name: 서명·MAC
  include: 항목이나 해시 체인의 끝 값에 키로 서명이나 MAC을 붙여 키가 없는 쪽이 고친 항목을 알아볼 수 있게 하는 경우입니다.
  exclude: 키 없이 계산하는 해시만 있는 경우는 L04.01에서 봅니다.
- id: L04.03
  name: 일련번호
  include: 항목에 일련번호를 매겨, 중간 항목이 삭제되거나 끼워 넣어진 것을 드러내는 경우입니다.
  exclude: 호출 ID처럼 순서가 없는 식별자는 일련번호가 아닙니다.
- id: L04.05
  name: 쓰기 권한 분리·추가 전용 저장
  include: 서버 프로세스나 모델 도구가 고칠 수 없는 권한이나 저장소에 기록을 두는 경우입니다. 추가 전용 속성, 별도 계정, 덮어쓸 수
    없는 저장소가 그 예입니다.
  exclude: 파일을 덧붙이기 모드로 여는 것만으로는 해당하지 않습니다.
- id: L04.06
  name: 검증 도구
  include: 기록의 해시 체인, 서명, 일련번호를 다시 계산해 어긋난 항목을 알려 주는 도구나 명령이 있는 경우입니다.
  exclude: 기록이 아닌 증거나 파생물의 해시를 검증하는 도구는 해당하지 않습니다.
