---
id: L02
name: 기록 구성
question: MCP 도구 호출의 기록 항목에 요청, 처리, 결과 상태, 결과 참조를 남기는 방식을 분류합니다.
conditional: false
boundary: 기록을 만드는 장치와 그 장치를 거치지 않는 호출은 L01에서, 기록 쓰기 실패 처리는 L03에서 봅니다. 도구 출력의 보관은 D01에서, 입력·파생물·실행의 추적은 D02에서 봅니다. 실행 결과를 알아차리는 방식은 T08에서, 응답으로 알리는 방식은 R03에서, 모델 이름과 버전 표시는 T06에서 봅니다.
scope: MCP 도구 호출을 처리하며 서버 기록에 항목을 남기는 경로가 적용 범위입니다. 클라이언트 기록은 대상이 아닙니다. 외부 요청의 목적지·전송
  내용·응답 기록은 상세로 나누지 않습니다.
not_implemented: 서버 기록은 남지만 요청·처리 내용, 결과 상태·실행 시점, 결과 참조·요약값 가운데 어느 것도 남기지 않는 경우입니다.
not_applicable: 서버가 기록을 남기지 않는 경우입니다.
details:
- id: L02.01
  name: MCP 요청 기록
  include: 모델이 보낸 MCP 도구 이름과 인자를, 서버가 값의 뜻을 바꾸기 전 값으로 실행 명령과 별도 필드에 기록하는 경우입니다.
  exclude: 서버가 변환한 뒤의 값만 남는 경우는 L02.02에서, 인자 값이 실행 명령 안에만 들어 있는 경우는 L02.03에서 봅니다. SDK가
    해석한 인자를 기록하는 것만으로 전송된 요청 원문을 그대로 보관한다고 보지 않습니다.
- id: L02.02
  name: 서버가 변환한 연산·인자 기록
  include: 서버가 dispatch, 기본값, 경로 변환, 값 범위 조정처럼 인자 값의 뜻을 바꾼 뒤의 연산과 인자를 기록하는 경우입니다. 이 변환 뒤 외부 도구에 넘기기 전의 값도 포함합니다.
- id: L02.03
  name: 외부 실행 명령 기록
  include: 외부 도구나 프로세스에 실제로 넘긴 실행 파일과 인자를 기록하는 경우입니다. 인자 배열을 공백으로 이어 인자 사이의 경계를 잃은 기록도
    해당합니다.
  exclude: 서버가 셸에 넘긴 명령 문자열을 그대로 기록한 것은 경계를 잃은 기록에 해당하지 않습니다. 서버 안의 함수만 부르는 도구는 해당하지
    않습니다.
- id: L02.04
  name: 모델 호출의 입력·응답 기록
  include: MCP 도구 호출을 처리하는 중 서버가 부른 모델의 입력, 응답, 모델 식별 정보를 기록에 남기는 경우입니다. 프롬프트나 판정 정책의
    식별값, 추론 설정, 모델 호출 실패와 그 뒤의 판정(통과 또는 거부)을 남기는 것도 포함합니다.
- id: L02.05
  name: 결과 상태·실행 시점 기록
  include: 실행의 결과 상태(성공, 거부, 실패, 시간 초과)와 실행 시점을 기록에 남기는 경우입니다. 완료 항목 하나로 남기거나 시작·끝을
    따로 남기는 방식 모두 포함합니다.
  exclude: 결과 상태 없이 시각과 걸린 시간만 남기는 경우는 해당하지 않습니다.
- id: L02.06
  name: 결과 참조·요약값 기록
  include: 기록 항목에 출력 해시, 보관 출력의 번호·경로, 크기, 행 수 같은 결과 참조나 요약값을 남기는 경우입니다.
  exclude: 출력의 미리보기만 담는 경우는 해당하지 않습니다.
- id: L02.07
  name: 호출 ID로 항목 연결
  include: 한 호출에서 나온 여러 항목을 같은 호출 ID·묶음 ID로 잇거나 그 ID를 참조하여 연결하는 경우입니다.
  exclude: 시각이나 사건 ID만 같은 경우는 해당하지 않습니다. 항목마다 서로 다른 ID가 있다는 것만으로는 연결에 해당하지 않습니다.
