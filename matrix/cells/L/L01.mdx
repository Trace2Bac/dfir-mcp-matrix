  인자도 담지 않는 진단 로그만 있는 경우도 미구현으로 봅니다.

    기록하는 경우는 L01.09에서 봅니다. 도구마다 따로 붙이는 데코레이터는 공통 단계에 해당하지 않습니다.

  exclude: 실행 함수를 거치지 않는 도구는 그 도구가 쓰는 장치의 상세에서 봅니다. 실행 함수가 기록하지 않고 결과만 돌려주는 경우는 해당하지

  seen_in:

  name: 클라이언트의 MCP 호출 기록
  include: 같은 저장소가 함께 제공하는 클라이언트 코드, 훅, 설정이 MCP 도구 호출을 식별할 수 있는 기록을 서버 기록과 별도로 남기는 경우입니다.
    요청·응답을 빠짐없이 담지 않은 기록과 서버 기록 없이 클라이언트 쪽에만 있는 기록도 해당합니다.
  exclude: 클라이언트 자체 도구 호출, 클라이언트가 부른 모델 호출, 사용자 입력만 남기는 경우는 해당하지 않습니다. 이 기록의 품질은 L02~L04에서
    평가하지 않습니다.
