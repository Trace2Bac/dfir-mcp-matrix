name: 외부 전송 범위 구성
question: 외부 서비스에 어떤 자료를 어떤 변환·가림을 거쳐 보내는가?
conditional: false
boundary: 응답·기록·보고서 안의 민감정보 가림은 R06, 외부 요청의 기록은 L02
scope: 서버 코드가 외부 서비스로 보내는 요청 내용(I01에서 본 연결)이다. 그 연결에서 구현에 적은 범위보다 많은 자료가 나가거나 구현에
  적은 변환·가림을 거치지 않는 도구·인자·설정이 있으면 †를 붙인다.
not_implemented: 외부 서비스에 조사 자료를 보내는데 무엇을 보내는지 코드가 정하지 않아 호출이 넘긴 임의 자료를 그대로 보낸다.
not_applicable: 서버 코드가 외부 서비스에 조사 자료를 보내지 않는다. 외부 연결이 없거나 받기만 하는 경우다.
details:
- id: I03.01
  name: 해시 전송
  include: 파일 내용 대신 파일 해시 값을 보낸다.
  exclude: 해시와 함께 파일이나 내용을 올리면 I03.03에도 연결한다.
- id: I03.02
  name: 메타데이터·추출 값 전송
  include: 증거에서 뽑은 값(IP 주소·도메인·URL·파일 이름·사용자 이름 등)이나 메타데이터를 보낸다.
  exclude: 해시 값만이면 I03.01이다. 보내기 전에 값을 거르거나 가리면 I03.04에도 연결한다.
- id: I03.03
  name: 증거 내용·파일 전송
  include: 증거 파일이나 그 내용(기록 원문·추출한 본문)을 외부 서비스로 올린다.
  exclude: 모델 클라이언트에 돌려주는 응답은 외부 전송으로 세지 않고 R06에서 본다.
- id: I03.04
  name: 필드 선택·가림 후 전송
  include: 보내기 전에 서버가 보낼 필드를 고르거나 민감한 값(내부 주소·사용자 이름 등)을 빼거나 가린다.
  exclude: 값의 형식만 검사해 형식이 다른 값을 보내지 않는 것은 가림으로 세지 않고 원고 구현에 적는다.
