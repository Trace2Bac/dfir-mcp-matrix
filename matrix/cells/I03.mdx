id: I03
name: 외부 전송 범위 구성
question: 서버는 외부 서비스에 어떤 자료를, 어떤 변환이나 가림을 거쳐 보내나요?
conditional: false
boundary: 응답, 기록, 보고서 안의 민감정보를 가리는 것은 R06에서, 외부 요청을 기록하는 것은 L02에서 봅니다.
scope: 서버 코드가 외부 서비스로 보내는 요청 내용이 적용 범위입니다. 여기서 외부 서비스 연결은 I01에서 본 연결을 말합니다. 그 연결에서
  다음 경우에는 †를 붙입니다. 원고의 구현 단락에 적은 범위보다 많은 자료가 나가는 경우, 원고의 구현 단락에 적은 변환이나 가림을 거치지 않는
  도구, 인자, 설정이 있는 경우입니다.
not_implemented: 외부 서비스에 조사 자료를 보내는데, 무엇을 보낼지 코드가 정하지 않아서 호출이 넘긴 임의의 자료를 그대로 보내는 경우입니다.
not_applicable: 서버 코드가 외부 서비스에 조사 자료를 보내지 않는 경우입니다. 외부 연결이 없거나 받기만 하는 경우가 여기에 해당합니다.
details:
- id: I03.01
  name: 해시 전송
  include: 파일 내용 대신 파일의 해시 값을 보내는 경우입니다.
  exclude: 해시와 함께 파일이나 내용도 올리면 I03.03에도 연결합니다.
- id: I03.02
  name: 메타데이터·추출 값 전송
  include: 증거에서 뽑은 값이나 메타데이터를 보내는 경우입니다. 뽑은 값은 IP 주소, 도메인, URL, 파일 이름, 사용자 이름 등입니다.
  exclude: 해시 값만 보내는 경우는 I03.01에서 봅니다. 보내기 전에 값을 거르거나 가리면 I03.04에도 연결합니다.
- id: I03.03
  name: 증거 내용·파일 전송
  include: 증거 파일이나 그 내용(기록 원문, 추출한 본문)을 외부 서비스로 올리는 경우입니다.
  exclude: 모델 클라이언트에 돌려주는 응답은 외부 전송으로 인정하지 않고 R06에서 봅니다.
- id: I03.04
  name: 필드 선택·가림 후 전송
  include: 보내기 전에 서버가 보낼 필드를 고르거나, 민감한 값(내부 주소, 사용자 이름 등)을 빼거나 가리는 경우입니다.
  exclude: 값의 형식만 검사해 형식이 다른 값을 보내지 않는 것은 가림으로 인정하지 않고, 원고의 구현 단락에 씁니다.
