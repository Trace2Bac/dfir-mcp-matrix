---
id: T01
name: 입력 검증
question: 이번 호출의 인자·입력·실행 조건이 올바르고 허용한 접근 범위 안에 있는지 실행 전에 어떻게 확인하는가?
conditional: false
boundary: 실행 도구·참조 자료의 가용성은 T07
scope: 모델이 넘긴 인자·입력 경로로 실행하는 호출이다. 검사가 걸린다고 구현에 적은 도구·인자에서 그 검사를 거치지 않는 호출 경로나 같은
  값을 검사 없이 바꾸는 다른 도구가 있거나, 호출 인자·설정으로 검사를 끄거나 허용 범위를 넓힐 수 있거나, 검사 중 오류가 나면 통과시키면 †를
  붙인다. 검사가 없는 다른 도구·인자는 †가 아니라 구현에 적는다.
not_implemented: 서버 코드가 인자·입력을 실행 전에 검사하지 않고 그대로 백엔드·외부 도구에 넘긴다. MCP SDK가 입력 schema로
  자료형만 검사하는 경우와 도구 설명으로 올바른 값을 안내만 하는 경우도 여기에 둔다.
not_applicable: 없음. 모든 서버에 적용한다.
details:
- id: T01.01
  name: 인자 구조·값 검사
  include: 서버 코드가 인자의 구조와 값(허용 값 목록, 범위, 형식, 필수 항목)을 검사해 어긋나면 거부하거나 정한 기본값으로 바꾼다.
  exclude: MCP SDK가 함수 서명·입력 schema로 자료형만 검사하는 것은 세지 않는다. 할 수 있는 연산·플러그인·질의를 좁히는 검사는
    T02다. 경로가 되는 값의 검사는 T01.04·T01.05다.
- id: T01.02
  name: 입력 존재·읽기 가능 검사
  include: 실행 전에 입력 파일·폴더·대상이 있는지나 읽을 수 있는지 보고 없으면 외부 도구·백엔드를 부르지 않고 거부한다.
  exclude: 실행 도구·참조 자료가 설치돼 있는지는 T07이다. 입력이 허용 범위 안인지는 T01.04~T01.07이다.
- id: T01.03
  name: 백엔드 지원·설정 검사
  include: 인자 값이나 실행 조건을 백엔드·외부 도구가 지원하는 값, 운영자 설정, 실행 환경의 여유(디스크 공간 등)와 실행 전에 대조하고
    맞지 않으면 거부한다.
  exclude: 도구·참조 자료가 설치돼 있는지만 보면 T07이다. 서버 코드에 고정한 값 목록과 대조하면 T01.01, 연산·플러그인을 좁히는
    목록이면 T02.07이다.
- id: T01.04
  name: 실제 경로로 풀어 허용 폴더 대조
  include: 읽기 경로 인자를 실제 경로로 풀어(`..`·심볼릭 링크 해석) 허용 폴더 안인지 대조하고 밖이면 거부한다. 푼 경로로 파일을
    연다.
  exclude: 쓰기·출력 경로의 대조는 D04다. 허용 폴더를 모델이 호출 인자로 정하거나 넓힐 수 있으면 †를 붙인다.
- id: T01.05
  name: 문자열 경로 검사
  include: 경로가 되는 인자를 파일시스템을 보지 않고 문자열로 검사한다(경로 구분자·`..`·절대 경로·제어 문자 거부, 접두어 비교 등).
  exclude: 실제 경로로 풀어 대조하면 T01.04다. 압축 항목 이름처럼 쓰기 위치를 정하는 문자열 검사는 D04다.
- id: T01.06
  name: 등록된 증거 ID로만 조회
  include: 모델이 경로 대신 서버에 등록된 증거·자료의 ID나 등록된 경로를 지정하고 서버가 등록 목록과 대조해 없으면 거부한다.
  exclude: 등록 절차와 등록 정보는 E01이다. 같은 인자에 등록 목록 밖의 경로도 받으면 그 경로는 이 항목에 넣지 않는다.
- id: T01.07
  name: 고정 입력 경로 사용
  include: 모델이 입력 경로를 고르지 않고 서버가 설정이나 앞선 적재 기록에서 정한 입력만 읽는다.
  exclude: 모델이 경로를 주지 않았을 때만 기본 경로를 쓰는 경우는 제외한다. 그 입력이 원본인지 작업 사본인지는 E04다.
- id: T01.08
  name: 입력 부재 시 다른 입력으로 대체
  include: 입력 파일·경로를 찾지 못하거나 이미지에서 꺼내지 못하면 거부하지 않고 다른 파일·경로·범위를 입력으로 바꿔 실행한다. 대체 사실을
    응답·기록에 알리는지 구현에 적는다.
  exclude: 같은 입력을 다른 도구·경로로 얻으면 T07이다. 대체한 입력에 다른 출처의 파일이 섞이는지는 구현에 적는다.
