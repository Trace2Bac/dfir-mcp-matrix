---
id: T01
name: 입력 검증
question: 이번 호출의 인자와 입력, 실행 조건이 올바르고 허용한 접근 범위 안에 있는지 서버가 실행 전에 어떻게 확인하나요?
conditional: false
boundary: 실행 도구와 참조 자료를 쓸 수 있는지는 이 셀이 아니라 T07에서 봅니다.
scope: 모델이 넘긴 인자나 입력 경로로 실행하는 호출이 적용 범위입니다. 다음 경우에는 †를 붙입니다. 원고의 구현 단락에 검사가 적용된다고 적은
  도구나 인자에 그 검사를 거치지 않는 호출 경로가 있는 경우, 같은 값을 검사 없이 바꾸는 다른 도구가 있는 경우, 호출 인자나 설정으로 검사를
  끄거나 허용 범위를 넓힐 수 있는 경우, 검사 중 오류가 나면 그냥 통과시키는 경우입니다. 검사가 없는 다른 도구나 인자에는 †를 붙이지 않고
  원고의 구현 단락에 씁니다.
not_implemented: 서버 코드가 인자와 입력을 실행 전에 검사하지 않고 그대로 백엔드나 외부 도구에 넘기는 경우입니다. MCP SDK가
  입력 schema로 자료형만 검사하는 경우, 도구 설명으로 올바른 값을 안내만 하는 경우도 미구현으로 봅니다.
not_applicable: 없습니다. 모든 서버에 적용합니다.
details:
- id: T01.01
  name: 인자 구조·값 검사
  include: 서버 코드가 인자의 구조와 값을 검사하고, 어긋나면 거부하거나 정한 기본값으로 바꾸면 해당합니다. 검사 내용은 허용 값 목록,
    범위, 형식, 필수 항목입니다.
  exclude: MCP SDK가 함수 서명이나 입력 schema로 자료형만 검사하는 것은 해당하지 않습니다. 외부 도구가 할 연산이나 모드, 플러그인,
    질의를 고르는 값의 검사는 T02에서 보고, 정한 연산 안의 값(형식, 인코딩, 범위)은 여기서 봅니다. 경로로 쓰이는 값의 검사는 T01.04와 T01.05에서 봅니다.
- id: T01.02
  name: 입력 존재·읽기 가능 검사
  include: 서버가 실행 전에 입력 파일, 폴더, 대상이 있는지나 읽을 수 있는지 확인하고, 없으면 외부 도구나 백엔드를 부르지 않고 거부하면
    해당합니다.
  exclude: 실행 도구나 참조 자료가 설치되어 있는지는 T07에서 봅니다. 입력이 허용 범위 안인지는 T01.04~T01.07에서 봅니다.
- id: T01.03
  name: 백엔드 지원·설정 검사
  include: 서버가 인자 값이나 실행 조건을 실행 전에 대조하고, 맞지 않으면 거부하면 해당합니다. 대조 대상은 백엔드나 외부 도구가 지원하는
    값, 운영자 설정, 실행 환경의 여유(디스크 공간 등)입니다.
  exclude: 도구나 참조 자료가 설치되어 있는지만 확인하는 경우는 T07에서 봅니다. 서버 코드에 고정한 값 목록과 대조하는 경우는 T01.01에서,
    연산이나 플러그인을 좁히는 목록과 대조하는 경우는 T02.07에서 봅니다.
- id: T01.04
  name: 실제 경로로 풀어 허용 폴더 대조
  include: 서버가 읽기 경로 인자를 실제 경로로 풀어(`..`와 심볼릭 링크를 해석해) 허용 폴더 안에 있는지 대조하고, 밖이면 거부하면
    해당합니다. 파일은 푼 경로로 엽니다.
  exclude: 쓰기 경로와 출력 경로의 대조는 D04에서 봅니다. 모델이 호출 인자로 허용 폴더를 정하거나 넓힐 수 있으면 †를 붙입니다.
- id: T01.05
  name: 문자열 경로 검사
  include: 서버가 경로로 쓰이는 인자를 파일시스템을 보지 않고 문자열로만 검사하면 해당합니다. 경로 구분자, `..`, 절대 경로, 제어
    문자를 거부하거나 접두어를 비교하는 방식이 그 예입니다. 대응 조치가 다룰 원격 대상의 경로를 검사하는 것도 해당합니다.
  exclude: 실제 경로로 풀어 대조하는 경우는 여기가 아니라 T01.04에서 봅니다. 압축 항목 이름처럼 쓰기 위치를 정하는 문자열의 검사는
    D04에서 봅니다.
- id: T01.06
  name: 등록된 증거 ID로만 조회
  include: 모델이 경로 대신 서버에 등록된 증거나 자료의 ID, 또는 등록된 경로를 지정하고, 서버가 이를 등록 목록과 대조해 없으면 거부하는
    경우입니다.
  exclude: 등록 절차와 등록 정보는 E01에서 봅니다. 같은 인자가 등록 목록 밖의 경로도 받는다면, 그 경로는 이 항목에 넣지 않습니다.
- id: T01.07
  name: 고정 입력 경로 사용
  include: 모델이 입력 경로를 고르지 않고, 서버가 설정이나 앞선 적재 기록에서 정한 입력만 읽는 경우입니다.
  exclude: 모델이 경로를 주지 않았을 때만 기본 경로를 쓰는 경우는 해당하지 않습니다. 그 입력이 원본인지 작업 사본인지는 E04에서 봅니다.
- id: T01.08
  name: 입력 부재 시 다른 입력으로 대체
  include: 입력 파일이나 경로를 찾지 못하거나 이미지에서 꺼내지 못했을 때, 서버가 거부하지 않고 다른 파일, 경로, 범위로 입력을 바꿔
    실행하는 경우입니다. 대소문자나 구분자만 다른 경로로 바꾸는 경우도 해당합니다. 입력을 바꾼 사실을 응답이나 기록으로 알리는지는 원고의
    구현 단락에 씁니다.
  exclude: 같은 입력을 다른 도구나 경로로 얻는 경우는 여기가 아니라 T07에서 봅니다. 바꾼 입력에 다른 출처의 파일이 섞이는지는 원고의
    구현 단락에 씁니다.
