id: T05
name: 분석 도구 검증
question: 실제 사용하는 도구·라이브러리·룰·심볼·이미지의 버전을 어떻게 확인하고 기준값과 대조하는가?
conditional: false
boundary: 무결성은 사용 직전의 실제 대상과 대조할 때만 셈. 확인한 버전을 결과·기록에 싣는 것은 T06
scope: 서버가 실행하거나 불러오는 분석 도구(실행 파일·라이브러리·컨테이너 이미지)와 그 도구가 판단에 쓰는 참조 자료(룰·시그니처·심볼·매핑·IOC
  목록)다. 구현에 적은 선언·확인·대조가 걸리는 대상에서 실제로 쓰는 버전이 선언과 달라지는 경로(실행할 때 다른 설치 위치를 먼저 찾음, 실행
  중 갱신, 일부 설치 방식·아키텍처에서만 고정)가 있거나, 버전을 정하는 설정·인자가 설명과 다르게 동작하거나, 확인·대조가 실패해도 그대로 진행하면
  †를 붙인다. 선언·확인·대조가 없는 다른 도구는 †가 아니라 구현에 적는다.
not_implemented: 서버가 쓰는 도구·참조 자료가 있는데 그 버전을 저장소에 고정하지도, 설정·인자로 정하지도, 실행할 때 확인하지도 않는다.
not_applicable: 서버가 자기 코드 밖의 분석 도구·라이브러리·참조 자료를 쓰지 않는다.
details:
- id: T05.01
  name: '선언: 저장소·의존성 고정'
  include: 저장소의 설치 정의(의존성 잠금 파일·자산 목록·Dockerfile·설치 스크립트)에 도구·참조 자료의 고정 값(버전·태그·커밋·해시)을
    적어 설치되는 버전을 정한다. 설치할 때 받은 파일의 해시를 그 값과 대조하는 것도 여기에 적는다.
  exclude: 버전 범위(`>=`)만 적거나 브랜치·최신(`HEAD`·`latest`)을 받으면 고정으로 세지 않고 구현에 적는다. MCP SDK·DB
    드라이버·SSH·스크립트 엔진처럼 증거를 해석하지 않는 서버 실행용 라이브러리의 고정은 세지 않고 구현에 사실로 적는다. 도구를 쓰기 직전에
    실제 파일을 대조하면 T05.05~T05.08이다.
- id: T05.02
  name: '선언: 설정·호출 인자 지정'
  include: 설정 파일·환경변수·호출 인자로 쓸 도구·참조 자료의 버전이나 위치를 정한다.
  exclude: 정한 값으로 실제 버전을 읽어 확인하면 T05.03·T05.04다. 위치만 받고 그 내용의 버전을 모르면 여기에 두고 구현에 그렇다고
    적는다.
- id: T05.03
  name: '확인: 실행 시 버전 조회'
  include: 서버가 실행 중에 도구에 버전을 묻거나 도구 출력·라이브러리 속성에서 버전을 읽는다.
  exclude: 실행되는지 보려고 버전 명령을 부르고 값을 버리면 T07.01이다. 룰·심볼 같은 참조 자료의 버전은 T05.04다.
- id: T05.04
  name: '확인: 참조 자료 버전·식별값 조회'
  include: 서버가 실행 중에 룰·시그니처·심볼·매핑의 버전이나 식별값(룰 저장소 커밋, 심볼 GUID·age, 시그니처 DB 버전)을 읽는다.
  exclude: 해시를 계산해 기준값과 대조하면 T05.05다. 읽은 식별값을 결과·기록에 싣는 것은 T06이다.
- id: T05.05
  name: 해시 기대값 대조
  include: 도구·참조 자료를 쓰기 직전에 실제 파일의 해시를 계산해 저장소·설정에 적은 기대값과 대조하고 다르면 실행하지 않는다.
  exclude: 설치할 때만 대조하면 T05.01에 적는다. 해시를 계산만 하고 대조하지 않으면 세지 않는다.
- id: T05.06
  name: 서명 검사
  include: 도구·참조 자료를 쓰기 전에 배포자의 서명(코드 서명·GPG·sigstore)을 검사하고 맞지 않으면 실행하지 않는다.
  exclude: 설치할 때 패키지 관리자가 하는 서명 검사만 있으면 T05.01에 적는다.
- id: T05.07
  name: 컨테이너 digest 대조
  include: 서버가 띄우는 컨테이너 이미지를 digest로 지정하거나 실행 전에 이미지 digest를 기대값과 대조한다.
  exclude: 태그만 지정하면 T05.01·T05.02에 적는다.
- id: T05.08
  name: 사용 전 참조 자료 검사
  include: 룰·심볼·매핑을 쓰기 직전에 그 내용이 기대한 버전·묶음인지(파일 목록·개수·식별값) 기준값과 대조하고 다르면 실행하지 않는다.
  exclude: 컴파일·형식 검사로 쓸 수 있는 파일만 고르는 것은 T07.01이다.
