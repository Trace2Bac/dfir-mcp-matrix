---
id: R02
name: 대량 결과 전달
question: 응답 제한·잘림·나머지 결과 접근을 어떻게 처리하는가?
conditional: false
scope: 그 상한·표시·조회가 걸린다고 구현에 적은 도구의 결과다. 모델이 호출 인자로 상한을 올리거나 끌 수 있거나, 그 도구 안에서 상한·표시가
  설명과 다르게 빠지거나 틀리는 경로가 있으면 †를 붙인다. 상한·표시가 없는 다른 도구는 †가 아니라 구현에 적는다.
not_implemented: 응답 크기·건수에 상한이 없고 값을 자르지도 않는다.
not_applicable: 응답이 늘 짧은 고정 형식이라 대량 결과가 생기지 않는다.
details:
- id: R02.01
  name: 문자·항목 상한
  include: 서버가 전달하는 문자열 길이·항목 수를 제한한다.
  exclude: 상한만으로 잘림 고지나 전체 조회 가능성을 인정하지 않는다. 모델이 호출 인자로 상한을 올리거나 끌 수 있으면 예외 표시(†)를
    붙인다.
- id: R02.02
  name: 전체·반환 건수 표시
  include: 전체 수량과 이번 응답의 반환 수량·범위를 구별해 알린다.
  exclude: 이번 응답의 길이만 표시한 경우는 제외한다.
- id: R02.03
  name: 페이지·cursor 조회
  include: 나머지 결과를 이어서 읽을 페이지·cursor와 조회 경로가 있다.
  exclude: 상한을 늘려 다시 요청하라는 안내만 있는 경우는 제외한다.
- id: R02.04
  name: 파일·리소스로 전체 결과 조회
  include: 제한된 응답과 연결된 전체 자료를 MCP 도구·리소스로 끝까지 다시 읽을 수 있다.
  exclude: 자료를 파일로 보관한 사실만 있으면 D01에서 본다. 보관한 자료의 일부만 다시 읽을 수 있으면 R02.08이다.
- id: R02.05
  name: 상한 초과 시 거부
  include: 결과가 상한을 넘으면 자르지 않고 오류로 거부한다.
  exclude: 거부 문구에 전체 크기나 나눠 받는 방법이 있으면 함께 적는다.
- id: R02.06
  name: 값 단위 잘림
  include: 결과 목록이 아니라 값 하나(문자열·이진 값)를 정해진 길이에서 자른다.
  exclude: 건수 상한과 따로 센다. 잘린 값에 표시가 있는지는 보고서에 적는다.
- id: R02.07
  name: 건수 없는 잘림 표시
  include: 잘렸다는 문구나 표시는 붙이지만 전체·반환 건수는 알리지 않는다.
  exclude: 전체·반환 건수까지 알리면 R02.02다.
- id: R02.08
  name: 보관한 출력의 일부 재조회
  include: 잘린 응답과 연결된 출력을 서버가 보관하고 질의·필터로 그 일부를 다시 돌려준다.
  exclude: 보관한 출력 전체를 끝까지 읽을 수 있으면 R02.04다. 파일로 보관한 사실만 있으면 D01에서 본다.
