# 1.2-B1 설정한 실행 파일 경로나 검색 설정이 적용되지 않아 프로그램을 찾지 못하거나 설정하지 않은 프로그램을 실행함

원고 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 [1.2.2 실행 파일 선택](/problems/1/1.2/1.2.2)

## 현상과 피해

설정한 추가 폴더에만 둔 도구를 찾지 못한다(sift-mcp, 오류는 드러남). 설정한 실행 파일이 없으면 PATH나 고정 위치의 다른 YARA, tshark, Volatility, hashcat으로 분석하고, 결과에는 도구 이름만 남거나 실행 파일 정보가 없다(agentic-dfir, WireMCP, verdict-dfir, findevil, CIIT). 대체 사실은 표준 오류에만 남거나(agentic-dfir, WireMCP) 어디에도 남지 않는다. 같은 서버 안에서 도구마다 다른 방식으로 Volatility를 찾아 한 사건 안에서 판이 갈릴 수 있다(mulder).
