# P1012 입력으로 고른 실행 대상을 확인하지 않아 정하지 않은 프로그램이 실행됨

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.1 「실행할 프로그램과 기능의 제한」

## 정의

**전제** 모델 입력으로 실행할 프로그램이나 수집 기능을 고르게 하고, 서버가 실행할 수 있는 대상을 정해 둔 서버에서

**결함** 입력으로 고른 프로그램이나 기능이 서버가 정한 실행 대상에 맞는지 실행 전에 확인하지 않는다.

**피해** 서버가 정하지 않은 프로그램이나 기능이 분석 호스트에서 실행된다.

**경계** 실행할 프로그램을 고정한 뒤 인자나 질의 검사가 옵션을 빠뜨리는 것과, 다른 도구에서 막은 기능을 이 도구로 수행하는 것은 포함하지 않는다.
