# P0012 실행할 프로그램이나 수집 정의를 모델 입력이 고름

원고 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.1 「실행할 프로그램과 기능의 범위」

## 현상과 피해

요청이 정한 프로그램이 분석 호스트에서 실행된다(verdict-dfir `verify_finding`의 명령 배열, winforensics-mcp `sidr_path`). 수집 정의 이름이 형식만 검사되고 백엔드로 넘어가 분석 호스트에서 명령을 실행하거나 분석 호스트 자료를 돌려줄 수 있다(verdict-dfir `vel_collect`). 처리 모듈 이름이 서버 목록과 대조되지 않아 정의를 내려받는 모듈이 실행되고 성공으로 응답한다(Cyber-Incident-Investigation-and-Triage-MCP-Server `kape_module` Sync_KAPE). 스크립트 실행 기능에 노출한 객체로 서버 호스트 명령을 실행할 수 있는데 문서는 네트워크 수단이 없다고 적는다(Camel).
