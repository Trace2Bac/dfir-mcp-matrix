# P1016 대체 프로그램의 기능을 확인하지 않아 하지 않은 작업을 성공으로 처리함

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.3 「대체 프로그램 선택과 실행」

## 정의

**전제** 필요한 프로그램이 없을 때 다른 이름의 프로그램으로 대체해 실행하는 서버에서

**결함** 대체 프로그램이 원래 기능을 수행하는지 확인하지 않고 같은 인자로 실행한 뒤 종료 코드만으로 성공을 판단한다.

**피해** 원래 기능이 수행되지 않은 실행이 성공으로 처리되어, 해시를 확인하지 않은 증거가 무결성이 확인된 것으로 제시되는 것처럼 결과가 사실과 다르게 전달된다.

**경계** 같은 프로그램을 다른 위치에서 찾아 실행하는 것은 포함하지 않는다.
