# N1 조사 중 참조 자료 자동 갱신

원고 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 「분석용 참조 자료 관리」

## 현상과 피해

YARA 검사 전에 커뮤니티 룰 저장소에서 `git pull --ff-only`를 프로세스마다 한 번 실행하고(끄는 설정 없음) 응답과 호출 기록에 룰의 판이 없다. 같은 증거를 다시 검사해도 그 사이 룰이 바뀌어 결과가 달라질 수 있고 어느 판으로 검사했는지 남지 않는다(mulder).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.

## 문제가 관찰된 서버 (1)

### [mulder](/problems/servers/mulder)

- YARA 검사 전 _update_community_rules가 signature-base 클론에서 git pull --ff-only를 프로세스당 한 번 실행해(끄는 설정 없음) 조사 중에 룰이 바뀔 수 있다. 코드: [src/mulder/server/tools/yara.py:72-116](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/yara.py#L72-L116)(_update_community_rules, 103-109행 git pull --ff-only), 303-308(_build_rules_args가 스캔마다 부름), 585-603(응답에 룰 판 없음), 627-631(호출 기록 인자는 rules 유무·ruleset만)
