# P1019 설치된 참조 자료의 버전을 확인하지 않아 있는 항목을 없다고 판정함

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.5 「참조 자료 선택과 사용」

## 정의

**전제** 분석 호스트에 설치해 둔 참조 자료로 항목이 있는지 없는지 판정하는 서버에서

**결함** 설치된 참조 자료가 필요한 버전인지 확인하지 않고, 설치나 갱신 때 옛 자료를 그대로 둔다.

**피해** 옛 자료로 실제 있는 항목을 없다고 판정하는데, 응답으로는 옛 자료 때문인지 가릴 수 없다.

**경계** 검사에 쓴 룰의 목록과 내용 식별값을 결과에 남기지 않는 것은 포함하지 않는다.
