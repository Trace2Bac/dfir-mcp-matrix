# A2 고정한 프로그램의 인자·질의 검사가 추가 코드나 범위 밖 기능을 놓침

원고 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 「실행할 프로그램과 기능의 범위」

## 현상과 피해

분석 컨테이너 안에서 요청 인자로 지정한 폴더의 플러그인 코드가 실행돼 결과에 섞인다(mcp_dfir `--plugin-dirs`). `-exec`만 거부하는 검사를 `-fprint`, `-fprintf`가 통과해 파일을 쓴다(mcp_dfir `run_find`). 차단 문자열 목록에 없는 pandas 함수로 파일을 쓰거나 읽는다(SAVVYDFIR-MCP). 낱말 목록 검사를 통과한 하위 질의가 증거 밖 파일을 읽어 오류 문자열에 싣는다(agentic-dfir). 읽기 전용 연결 모드에 기대고 질의 연산을 검사하지 않아 오류 응답 뒤에 새 DB 파일이 생긴다(CIIT). 프로필 값이 플러그인 경로가 돼 폴더 밖 `.pl`을 실행할 수 있다(mulder).
