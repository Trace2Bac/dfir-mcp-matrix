# P0016 다른 기능의 프로그램으로 대체하고 종료 코드만으로 성공을 판단함

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.3 「대체 프로그램 선택과 실행」

## 현상과 피해

`ewfverify`가 없으면 같은 인자로 `img_stat`을 실행하고 종료 코드 0을 성공으로 처리해 해시 확인 없이 `integrity_verified`가 생긴다(sift-kernel).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 문제가 없음을 증명하지 못한 판정이다. 코드 위치가 있으면 그 문제를 찾아 코드를 보았으나 발견하지 못한 것이고, 없으면 근거 대장의 묶음 분모에서 옮겨 아직 이 문제로 코드를 보지 않은 것이다.
