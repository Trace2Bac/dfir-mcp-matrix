# P0017 설정이나 코드에 적힌 버전을 실제 사용한 프로그램의 버전으로 기록함

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.3 「실제 사용한 프로그램 정보 확인」

## 현상과 피해

실행 파일과 기대 해시를 설정으로 바꿀 수 있는데 결과의 `tool_version`은 코드 상수이고 `analyzer_sha256`은 실제 파일을 따른다. 같은 결과의 두 식별 정보가 서로 다른 것을 가리킨다(MyIRTeam).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 근거 대장의 묶음 분모에서 옮긴 판정으로, 아직 코드로 다시 확인하지 않았다.
