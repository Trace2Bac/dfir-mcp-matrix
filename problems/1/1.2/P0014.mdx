# P0014 막은 기능을 다른 도구나 감싸는 명령으로 수행함

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.1 「실행할 프로그램과 기능의 제한」

위험 기능 설정을 끈 서버에서 `run_vql`과 `kill_process`는 거부되지만 `collect_artifact`로 단말 VQL 실행과 프로세스 종료가 일어난다(mcp-velociraptor). 끄는 설정에 적은 `run_analysis`가 그대로 실행된다(SAVVYDFIR-MCP). 거부 목록 검사가 명령 배열의 첫 이름만 봐 `timeout`, `nice` 뒤의 거부 도구가 통과한다(sift-mcp). 조치 템플릿을 대조하는 도구와 달리 `misc.batch_run`은 받은 명령을 그대로 원격에서 실행한다(trudi).
