# P0018 다시 쓰거나 모아 불러온 룰의 실제 내용을 결과에 연결하지 않음

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.5 「참조 자료 선택과 사용」

컴파일한 룰을 프로세스에 보관해 다시 쓰고 응답에는 일치한 룰 이름만 있어, 디스크의 룰과 실제 검사 룰이 달라도 알 수 없다(Wireshark-MCP). 여러 경로의 룰을 모을 때 없는 경로와 다른 확장자가 알림 없이 빠지고 같은 이름 규칙은 하나만 남으며, 경로 목록 키로 1시간 재사용한다(winforensics-mcp). 검증에서 뺀 룰 파일 수는 서버 로그에만 남는다(mulder). 포함 파일로 불러온 룰이 응답의 규칙 해시 목록에서 빠진다(MyIRTeam).
