# P1017 실행한 프로그램에서 버전을 얻지 않아 결과의 버전이 실제와 다름

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.4 「실제 사용한 프로그램 정보 확인」

## 정의

**전제** 외부 프로그램을 실행하고 결과에 그 프로그램의 버전을 남기는 서버에서

**결함** 결과에 실제로 실행한 프로그램에서 얻은 버전이 아니라 코드나 설정에 적힌 버전을 남긴다.

**피해** 결과의 프로그램 식별 정보가 실제로 실행한 프로그램과 달라지고, 같은 결과의 식별 정보끼리 서로 다른 프로그램을 가리키게 된다.

**경계** 결과에 버전을 남기지 않는 것은 포함하지 않는다.
