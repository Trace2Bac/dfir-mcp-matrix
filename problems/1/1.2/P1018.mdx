# P1018 검사에 쓴 참조 자료의 식별값을 남기지 않아 판정 근거를 되짚을 수 없음

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.5 「참조 자료 선택과 사용」

## 정의

**전제** 룰이나 위협 정보 같은 참조 자료를 불러오거나 조회해 검사하는 서버에서

**결함** 검사에 실제로 쓴 참조 자료의 목록, 내용 식별값, 버전, 조회 시점을 결과에 남기지 않거나 자료 묶음의 버전 표시처럼 내용을 따르지 않는 값만 남기고, 조사 중에 바뀌는 자료를 고정하지 않는다.

**피해** 빠지거나 바뀐 자료가 있어도 결과로는 알 수 없고, 같은 증거를 다시 검사한 결과가 달라져도 어느 자료로 판정했는지 되짚을 수 없다.

**경계** 분석 호스트에 설치해 둔 참조 자료가 필요한 버전인지 확인하지 않는 것은 포함하지 않는다.
