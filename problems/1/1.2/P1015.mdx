# P1015 정한 실행 파일 위치를 지키지 않아 다른 위치의 프로그램을 실행함

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.2 「실행 파일 선택」

## 정의

**전제** 실행 파일 경로를 설정이나 문서로 정하거나 코드에 찾는 순서를 정해 외부 프로그램을 실행하는 서버에서

**결함** 정한 경로나 순서를 일부 실행 경로에서 적용하지 않거나, 정한 파일이 없을 때 알리지 않고 다른 위치에서 찾아 실행한다.

**피해** 정한 프로그램을 찾지 못하거나 다른 위치나 다른 버전의 프로그램으로 분석되는데, 결과와 기록에는 실제로 실행한 프로그램이 드러나지 않는다.

**경계** 모델 입력으로 실행 파일을 고르는 것과, 정한 프로그램이 없어 다른 이름의 대체 프로그램을 일부러 실행하는 것은 포함하지 않는다.
