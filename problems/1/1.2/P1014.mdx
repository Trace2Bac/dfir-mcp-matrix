# P1014 실행 제한을 일부 호출 경로에서만 확인해 막은 기능이 실행됨

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.1 「실행할 프로그램과 기능의 제한」

## 정의

**전제** 설정, 역할, 거부 목록, 조치 템플릿으로 일부 도구나 프로그램의 실행을 막는 서버에서

**결함** 그 제한을 일부 호출 경로에서만 확인하고, 다른 도구, 묶음 실행, 다른 프로그램을 감싸 실행하는 명령, 또는 확인이 빠진 도구 자신의 호출 경로에서는 확인하지 않는다.

**피해** 막았다고 여긴 기능이 실행되어 분석 시스템이나 대상 시스템에서 명령이 실행되거나 프로세스가 종료된다.

**경계** 입력으로 고른 프로그램에 실행 대상 제한을 두지 않은 것과, 고정한 프로그램의 인자 검사가 옵션을 빠뜨리는 것은 포함하지 않는다.
