# P1013 고정한 프로그램에 넘기는 인자 검사가 일부만 막아 허용 밖 기능이 실행됨

항목 [1.2 분석 도구 관리](/problems/1/1.2) · 소제목 1.2.1 「실행할 프로그램과 기능의 제한」

## 정의

**전제** 실행할 프로그램이나 질의 엔진을 고정하고 모델이 준 인자나 질의를 넘기는 서버에서

**결함** 인자나 질의에서 일부 옵션과 함수만 막거나 연결 모드에만 기대어 넘겨, 추가 코드 실행, 허용 범위 밖 파일의 읽기와 쓰기, 외부 전송처럼 서버가 허용하지 않은 기능을 통과시킨다.

**피해** 분석 시스템에서 추가 코드가 실행되거나 파일이 쓰이고 지워지며, 허용 범위 밖 파일의 내용이 응답으로 나간다.

**경계** 입력으로 실행할 프로그램 자체를 고르는 것과, 막은 기능이 다른 도구나 다른 프로그램을 감싸는 명령으로 실행되는 것은 포함하지 않는다.
