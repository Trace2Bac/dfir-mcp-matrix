# P0021 다음 작업 안내가 실제로 쓸 수 있는 도구와 맞지 않음

원고 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.1 「조사 절차 안내」

## 현상과 피해

안내한 작업을 수행할 수 없거나(등록되지 않은 도구, 설치되지 않은 도구), 안내대로 해도 자료가 생기지 않아 0건 success가 자료 없음으로 읽히며(mulder), 실행 조건을 갖추지 못한 도구나 다른 대상을 가리키는 인자가 권고된다(sift-kernel, SAVVYDFIR-MCP).
