# P1023 절차 안내 장치의 적용 조건이 조사 상태와 어긋나 맞지 않는 절차가 쓰임

항목 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.1 「조사 절차 안내」

## 정의

**전제** 서버가 조사 상태, 요청 내용, 연결 방식에 따라 절차 안내를 붙이거나 절차를 강제하거나 시작하는 장치를 둘 때

**결함** 그 장치를 실제 조사 상태나 요청 내용과 다른 조건으로 적용하거나, 서버 문서가 안내하는 연결 방식 가운데 일부에서 적용하지 않는다.

**피해** 정상 흐름에서 절차 안내와 차단이 빠지거나, 다른 상태를 기준으로 절차가 강제되거나, 요청과 관계없는 절차가 사용자 확인 없이 시작된다.

**경계** 장치는 바르게 적용됐지만 안내한 작업 자체를 실행할 수 없는 것은 포함하지 않는다.
