# P1027 남은 작업을 판단에 넣지 않아 조사를 완료로 표시함

항목 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.4 「조사 완료 판단」

## 정의

**전제** 서버가 조사 완료, 보고 준비, 단계 완료, 진척 비율을 판단하거나 표시할 때

**결함** 실행하지 않은 도구나 끝나지 않은 작업처럼 남은 작업을 바르게 계산해 판단에 넣지 않고 완료나 준비됨으로 표시한다.

**피해** 조사하지 않은 범위가 남은 채로 조사 완료나 보고 준비로 전달되고, 같은 시점에 서로 다른 완료 판단이 나온다.

**경계** 완료 판단과 별개로 보고서에 미완료 범위를 싣지 않는 것은 포함하지 않는다.
