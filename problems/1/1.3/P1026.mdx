# P1026 앞선 실행 결과를 반영하지 않아 같은 작업을 되풀이해 추천함

항목 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.3 「후속 분석 작업 추천」

## 정의

**전제** 서버가 앞선 실행 결과에 따라 다음 작업을 추천하거나 요구할 때

**결함** 추천이나 요구를 앞선 실행 결과와 지금 상태에 맞춰 바꾸지 않아, 이미 수행했거나 같은 조건으로 다시 해도 결과가 같은 작업을 되풀이해 추천하거나 요구한다.

**피해** 조사가 같은 작업에 묶여 다음 단계로 넘어가지 못하거나 보고서를 만들지 못한다.

**경계** 추천이 반복되는 원인이 앞서 만든 자료나 캐시를 지금 상태와 대조하지 않고 다시 쓰는 데 있는 것은 포함하지 않는다.
