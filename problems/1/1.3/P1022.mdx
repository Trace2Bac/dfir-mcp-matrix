# P1022 백그라운드 작업의 완료 상태를 구별하지 않아 끝나지 않은 결과가 전달됨

항목 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.1 「조사 절차 안내」

## 정의

**전제** 서버가 백그라운드 작업을 시작하고 그 결과를 나중에 조회하게 할 때

**결함** 작업이 끝났는지와 어떻게 끝났는지를 구별하지 않은 채 후속 분석을 안내하거나 결과를 돌려주거나, 완료를 확인할 방법을 알리지 않는다.

**피해** 적재 전 자료로 분석이 진행되거나, 일부만 끝난 결과와 끝나지 않은 작업, 오류로 끝난 작업이 전체 결과나 결과 없음으로 전달된다.

**경계** 안내한 도구가 등록되지 않았거나 실행 조건을 갖추지 못한 것은 포함하지 않는다.
