# P0022 백그라운드 작업이 끝나기 전에 후속 분석을 안내하거나 결과 확인 방법을 안내하지 않음

원고 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.1 「조사 절차 안내」

## 현상과 피해

같은 batch에 대해 시작 도구는 기다리지 말고 복합 분석을 하라고, 상태 도구는 끝나기 전에 넘어가지 말라고 안내해 적재 전 자료로 복합 분석을 돌릴 수 있다(mulder). hunt 결과 조회가 완료 여부를 보지 않고 hunt 상태만 보는 도구도 없어, 일부 단말만 응답한 결과를 전체로 읽을 수 있다(mcp-velociraptor). 끝나지 않음과 결과 없음, 오류로 끝난 flow를 한 문장으로 돌려준다(mcp-velociraptor, 오류 응답이라 약함).
