# A3 백그라운드 작업이 끝나기 전에 후속 분석을 안내하거나 결과 확인 방법을 안내하지 않음

원고 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 「조사 절차 안내」

## 현상과 피해

같은 batch에 대해 시작 도구는 기다리지 말고 복합 분석을 하라고, 상태 도구는 끝나기 전에 넘어가지 말라고 안내해 적재 전 자료로 복합 분석을 돌릴 수 있다(mulder). hunt 결과 조회가 완료 여부를 보지 않고 hunt 상태만 보는 도구도 없어, 일부 단말만 응답한 결과를 전체로 읽을 수 있다(mcp-velociraptor). 끝나지 않음과 결과 없음, 오류로 끝난 flow를 한 문장으로 돌려준다(mcp-velociraptor).

## 문제가 관찰된 서버 (2)

### [mcp-velociraptor](/problems/servers/mcp-velociraptor)

- hunt_across_fleet은 hunt 메타데이터만 돌려주고, 설명이 완료된 hunt의 행을 가져온다고 적는 get_hunt_results_tool은 완료 여부를 보지 않으며 hunt 상태만 보는 도구가 없다. 코드: [mcp_velociraptor_bridge.py:306](https://github.com/mgreen27/mcp-velociraptor/blob/1f97a4f4e64d27faf07fe684d8cbfe270b57757d/mcp_velociraptor_bridge.py#L306)–347; [mcp_velociraptor_bridge.py:350](https://github.com/mgreen27/mcp-velociraptor/blob/1f97a4f4e64d27faf07fe684d8cbfe270b57757d/mcp_velociraptor_bridge.py#L350)–361
- get_collection_results가 기본 10회×30초 안에 flow가 FINISHED가 아니면 결과 없음과 끝나지 않음을 한 문장으로 돌려주고, FINISHED 판정은 로그 문구로만 해 오류로 끝난 flow도 같은 문장이 된다. 코드: [mcp_velociraptor_bridge.py:1988](https://github.com/mgreen27/mcp-velociraptor/blob/1f97a4f4e64d27faf07fe684d8cbfe270b57757d/mcp_velociraptor_bridge.py#L1988)–2000; [velociraptor_api.py:588](https://github.com/mgreen27/mcp-velociraptor/blob/1f97a4f4e64d27faf07fe684d8cbfe270b57757d/velociraptor_api.py#L588)–601

### [mulder](/problems/servers/mulder)

- start_extraction_batch는 batch를 기다리지 말고 복합 도구 분석을 이어 하라고 안내하고, 같은 batch를 조회한 check_extraction_status는 실행 중이면 복합 분석으로 넘어가지 말라고 경고한다. 코드: [src/mulder/server/tools/jobs.py:190](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/jobs.py#L190)–194; [src/mulder/server/tools/jobs.py:271](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/jobs.py#L271)–276; [src/mulder/server/tools/jobs.py:213](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/jobs.py#L213)–215
