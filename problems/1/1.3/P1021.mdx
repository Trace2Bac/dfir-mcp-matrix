# P1021 다음 작업 안내를 실행 조건과 대조하지 않아 따를 수 없는 작업을 안내함

항목 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 1.3.1 「조사 절차 안내」

## 정의

**전제** 서버가 도구 응답, 도구 설명, 지침이나 절차 파일로 다음에 할 작업을 안내할 때

**결함** 안내하는 도구, 인자, 선행 작업이 실제로 등록된 도구와 그 도구가 받는 인자, 지금 갖춰진 실행 조건과 맞는지 확인하지 않는다.

**피해** 안내를 따라도 작업을 수행할 수 없거나 다른 대상을 처리하거나 자료 없이 성공으로 끝나, 분석하지 못한 자료가 자료 없음으로 읽힌다.

**경계** 안내한 작업은 실행할 수 있지만 백그라운드 작업이 끝나기 전에 후속 분석을 안내하는 것과, 절차 안내 장치가 조사 상태나 요청을 잘못 읽어 켜지거나 꺼지는 것은 포함하지 않는다.
