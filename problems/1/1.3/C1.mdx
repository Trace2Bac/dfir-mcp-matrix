# C1 재시작이나 다시 시작한 뒤 진척 상태를 잘못 판단함

원고 [1.3 조사 절차와 진행 관리](/problems/1/1.3) · 소제목 「조사 재개와 초기화」

## 현상과 피해

풀지 않은 압축 증거를 다시 풀지 말라는 안내를 받고(mulder), 재개 직후 첫 판단이 증거 종류와 남은 작업 없이 이뤄진다(trudi). 실행 중이던 작업이 재시작으로 완료 판단에서 사라지고(mulder), 재시작 뒤 보고서가 빠진 발견사항을 적지 않으며(sift-kernel), 세션 만료로 등록 증거와 보호가 사라진다(Camel). 초기화 뒤 앞 조사의 가설과 증거 유형이 다음 조사에 쓰인다(sift-kernel, trudi).
