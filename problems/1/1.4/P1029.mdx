# P1029 이름만으로 증거 유형을 정해 실제 내용과 다른 유형으로 판별함

항목 [1.4 증거 형식 확인과 분석 입력 준비](/problems/1/1.4) · 소제목 1.4.1 「증거 형식 판별과 처리 경로 선택」

## 정의

**전제** 파일 이름, 확장자, 경로 글자를 써서 증거나 입력 파일의 유형을 정할 때

**결함** 내용을 확인하지 않고 이름 규칙만으로 유형을 정하거나, 내용으로 판별한 결과를 이름 규칙으로 바꾼다.

**피해** 실제 내용과 다른 유형의 처리와 대조 방식이 적용되어, 맞는 분석이 빠지거나 맞지 않는 분석 결과와 거짓 불일치가 정상 결과로 전달된다.

**경계** 유형을 정하지 못해 처리 대상에서 빼거나 기본 유형으로 두는 것과, 도구가 받은 입력을 형식 확인 없이 처리하는 것은 포함하지 않는다.
