# A2 알아보지 못하거나 판별을 건너뛴 증거를 알리지 않고 처리 대상에서 빼거나 기본 유형으로 다룸

원고 [1.4 증거 유형별 처리](/problems/1/1.4) · 소제목 「증거 유형 확인」

## 현상과 피해

사건에 있는 캡처를 없다고 판단해 IOC 범위를 해당 없음으로 둔다(trudi). 디스크 이미지가 점검 목록에서 빠진다(findevil). 확장자 없는 브라우저 DB에 쓸 도구를 안내하지 않는다(CIIT). 분류하지 못한 파일이 증거 목록에서 빠지고 응답에 빠진 수가 없다(mulder). 유형이 unknown으로 남아 Windows 기준 목록을 쓰고 Linux 연산을 막는다(sift-kernel).
