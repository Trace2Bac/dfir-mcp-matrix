# 2.2-D10 요구한 종류와 다른 하이브를 받아도 오류 없이 빈 결과를 돌려줌

원고 [1.4 증거 형식 확인과 분석 입력 준비](/problems/1/1.4) · 소제목 [1.4.3 분석 입력 형식 확인](/problems/1/1.4/1.4.3)

같은 묶음의 다른 사례는 [2.2.1 인자 구조와 값 검사](/problems/2/2.2/2.2.1/2.2-D10), [2.2.2 경로 인자 해석과 검사](/problems/2/2.2/2.2.2/2.2-D10), [4.1.2 결과 상태와 실패 이유 전달](/problems/4/4.1/4.1.2/2.2-D10), [4.2.3 분석 범위와 해석 한계 표시](/problems/4/4.2/4.2.3/2.2-D10)에 있다.

## 현상과 피해

`registry_get_usb_history`, `registry_get_network`, `registry_get_system_info`에 SYSTEM 하이브 자리에 SAM 하이브를 주면 오류 없이 빈 목록이나 모든 필드가 `None`인 결과가 돌아온다(winforensics-mcp).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.
