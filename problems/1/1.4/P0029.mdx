# P0029 이름·확장자나 이름 규칙으로 정한 유형이 실제 내용과 달라 다른 유형으로 판별함

항목 [1.4 증거 형식 확인과 분석 입력 준비](/problems/1/1.4) · 소제목 1.4.1 「증거 형식 판별」

디스크 이미지에 메모리 도구를 해야 할 일로 싣고 디스크 도구는 요구하지 않는다(mulder, findevil). EWF2를 raw로 넘겨 VSS 삭제 가능성이라는 발견사항이 남을 수 있다(SAVVYDFIR-MCP). 다른 형식 파일에 맞지 않는 도구를 권한다(Cyber-Incident-Investigation-and-Triage-MCP-Server). 로그 파일에 하이브 모듈을 실행하거나 다른 하이브를 다른 이름표로 적재할 수 있다(Cyber-Incident-Investigation-and-Triage-MCP-Server, mulder). 메모리 덤프가 아닌 파일을 `Memory dump ready`로 돌려준다(SAVVYDFIR-MCP). 다른 이름의 EWF에 컨테이너 해시를 대조해 거짓 불일치가 난다(Camel).
