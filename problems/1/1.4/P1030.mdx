# P1030 증거 유형을 판별하지 못하거나 처리에 넘기지 않아 분석에서 빠지거나 다른 기준이 적용됨

항목 [1.4 증거 형식 확인과 분석 입력 준비](/problems/1/1.4) · 소제목 1.4.1 「증거 형식 판별과 처리 경로 선택」

## 정의

**전제** 증거 목록을 만들거나 증거의 유형을 판별해 처리 대상, 처리 경로, 진척 기준을 정할 때

**결함** 알아보지 못했거나 판별 단계를 거치지 않은 증거를 응답에 알리지 않고 처리 대상에서 빼거나 기본 유형으로 처리하거나, 판별한 유형을 처리 경로 선택과 진척 계산에 넘기지 않는다.

**피해** 사건에 있는 증거가 분석 범위와 점검 목록에서 빠지거나 다른 유형의 기준으로 분석되고, 그 사실이 결과에 드러나지 않는다.

**경계** 이름 규칙으로 실제와 다른 유형을 붙이는 것은 포함하지 않는다.
