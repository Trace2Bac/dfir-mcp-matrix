# P0030 알아보지 못하거나 판별을 건너뛴 증거를 알리지 않고 처리 대상에서 빼거나 기본 유형으로 다룸

항목 [1.4 증거 형식 확인과 분석 입력 준비](/problems/1/1.4) · 소제목 1.4.1 「증거 형식 판별」

## 현상과 피해

사건에 있는 캡처를 없다고 판단해 IOC 범위를 해당 없음으로 둔다(trudi). 디스크 이미지가 점검 목록에서 빠진다(findevil). 확장자 없는 브라우저 DB에 쓸 도구를 안내하지 않는다(Cyber-Incident-Investigation-and-Triage-MCP-Server). 분류하지 못한 파일이 증거 목록에서 빠지고 응답에 빠진 수가 없다(mulder). 유형이 unknown으로 남아 Windows 기준 목록을 쓰고 Linux 연산을 막는다(sift-kernel).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 문제가 없음을 증명하지 못한 판정이다. 코드 위치가 있으면 그 문제를 찾아 코드를 보았으나 발견하지 못한 것이고, 없으면 근거 대장의 묶음 분모에서 옮겨 아직 이 문제로 코드를 보지 않은 것이다.
