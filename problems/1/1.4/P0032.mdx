# P0032 도구가 받은 입력의 형식을 확인하지 않고 처리해 다른 형식의 결과를 정상 결과로 돌려줌

원고 [1.4 증거 유형별 처리](/problems/1/1.4) · 소제목 1.4.2 「유형별 처리와 입력 대조」

## 현상과 피해

사용자 명령 기록이 예약 작업으로 `parsed` 보고된다(sift-kernel). SYSTEM 자리에 SAM 하이브를 주면 빈 목록과 None이 오류 없이 돌아온다(winforensics-mcp). 맞지 않는 경로와 설명이 지원한다고 적은 Firefox 형식에서 0건이 정상으로 돌아온다(agentic-dfir). Linux 단말에 Windows용 도구는 빈 성공, macOS용 도구는 Linux 프로세스를 돌려준다(mcp-velociraptor). 처리하지 못한 EWF2의 빈 출력이 VSS 삭제 가능성 발견사항(확신도 0.80)이 된다(SAVVYDFIR-MCP).
