# P1043 획득 때 값이 아닌 기준값을 원본 기준값으로 삼아 앞선 변경을 놓침

항목 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.4 「증거 기준값 보관과 대조」

## 정의

**전제** 증거 기준값을 만들어 나중의 대조 기준으로 쓰는 서버에서

**결함** 기준값을 저장하지 않거나 서버를 시작할 때마다 새로 계산하고, 서버가 처음 계산한 값이나 작업 사본처럼 다른 대상에서 계산한 값을 획득 때의 원본 기준값처럼 표시한다.

**피해** 기준값을 만들기 전에 생긴 변경을 알아채지 못하고, 기준값이 언제 어디서 나왔는지 되짚을 수 없게 된다.

**경계** 기준값의 계산 범위가 증거 전체와 다른 것은 포함하지 않는다.
