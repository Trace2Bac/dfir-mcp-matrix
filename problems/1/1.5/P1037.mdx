# P1037 서버가 정한 쓰기 위치가 증거 폴더 안이라 증거 폴더에 파일이 생김

항목 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.1 「증거 쓰기 차단」

## 정의

**전제** 서버가 기본값이나 고정 규칙으로 쓰기 위치를 정하거나, 스스로 쓰기도 하는 외부 프로그램에 폴더를 넘길 때

**결함** 그 쓰기 위치나 넘긴 폴더가 보호 대상 증거 폴더 안이라, 출력 위치를 주지 않은 호출에도 그 폴더에 서버 파일이나 분석 출력을 만든다.

**피해** 증거 폴더에 증거가 아닌 파일이 섞여 증거 폴더의 구성이 바뀐다.

**경계** 모델이 출력 위치로 증거 폴더를 준 것, 원본 증거 파일의 내용이 바뀌는 것, 입력 폴더가 보호 대상이 아닌 작업 공간인 구성은 포함하지 않는다.
