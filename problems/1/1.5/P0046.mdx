# P0046 불일치나 대상 변경 뒤에도 앞선 검증 결과가 남음

항목 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.5 「증거 기준값 대조」

불일치 뒤에도 분석 결과가 `integrity_ok: true`로 나간다(protocol-siftpp). 다른 이미지를 다시 붙이거나 나중 검증이 실패해도 검증 능력이 남아 선행 조건을 통과한다(sift-kernel). 불일치 호출이 `success: true`와 `VERIFIED`로 기록된다(trudi).
