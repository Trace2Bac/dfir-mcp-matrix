# P0037 서버가 정한 쓰기 위치가 증거 폴더와 겹침

원고 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.1 「보호할 증거의 범위」

## 현상과 피해

이미지 경로 뒤에 붙인 이름으로 설정 파일을 써 이미지 폴더에 서버 파일이 생겼다(VolPilot, MCP). 압축 해제 기본 폴더가 증거 경로 아래다(SAVVYDFIR-MCP). 호스트 구분 없는 고정 이름으로 써 앞 단말에서 수집한 증거 사본이 바뀐다(winforensics-mcp, 1.1 주 배치).
