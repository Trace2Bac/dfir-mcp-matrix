# P0047 대조 범위가 기준값의 범위와 맞지 않음

원고 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.4 「기준값 대조와 검증 결과」

## 현상과 피해

다른 이름의 EWF를 컨테이너 파일 해시로 계산해 획득 해시와 비교하므로 내용이 같아도 불일치가 난다(Camel, P0029과 함께). 분할 이미지의 등록 파일 하나만 해시한다(Camel). E01 조각 파일의 바이트를 해시해 매체 해시와 비교한다(trudi, 맞는 도구 `ewf_verify`가 따로 있음).
