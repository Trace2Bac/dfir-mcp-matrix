# P1044 기준값과 일치를 확인하지 못한 대조를 검증 성공으로 알림

항목 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.4 「증거 기준값 보관과 대조」

## 정의

**전제** 증거를 기준값과 대조해 검증 결과를 응답하거나 기록할 때

**결함** 기대 기준값 없이 부른 호출처럼 기준값과 일치함을 확인하지 못했거나 불일치로 끝난 대조를 검증 성공으로 응답하거나 기록한다. 내용을 다시 계산하지 않고 크기와 수정 시각만 비교한 경우도 같다.

**피해** 증거 변경을 알아채지 못한 채 검증된 것으로 전달되고 기록이 실제 검증 결과와 달라진다.

**경계** 앞선 검증 상태가 뒤의 실패나 대상 변경 뒤에도 남는 것, 다시 계산한 값의 범위가 기준값과 다른 것은 포함하지 않는다.
