# P1039 읽기 모드만 믿고 증거를 열어 증거 폴더에 부속 파일이 생김

항목 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.2 「증거 열기와 읽기 설정」

## 정의

**전제** 증거 폴더의 파일을 사본 없이 읽기 모드로 열 때

**결함** 읽기 모드가 막지 못하는 부속 파일 쓰기를 막지 않거나, 경로 글자나 연결 방식 때문에 읽기 전용 지정 없이 원본을 연다.

**피해** SQLite 공유 메모리 파일 같은 파일이 증거 폴더에 생기거나 바뀐다.

</Case>
