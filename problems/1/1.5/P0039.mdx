# P0039 읽기만 하는 처리가 증거 폴더에 파일을 만들거나 바꿈

원고 [1.5 증거 무결성 관리](/problems/1/1.5) · 소제목 1.5.2 「증거를 읽는 방법과 작업 사본」

## 현상과 피해

SQLite를 읽기 모드로 열어도 `-shm`이 바뀌거나 새로 생긴다(mulder, agentic-dfir, winforensics-mcp). 경로의 `#` 때문에 `mode=ro`가 빠져 원본 폴더에 0바이트 파일이 생긴다(winforensics-mcp 코드). 원본을 사본 없이 열거나 SQLCipher로 URI 없이 연다(mulder). 외부 프로그램이 입력 폴더에 결과 CSV를 쓴다(MyIRTeam, 문서에 밝혀 둔 설계).
