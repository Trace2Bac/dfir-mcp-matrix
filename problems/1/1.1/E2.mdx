# E2 전환·재시작 뒤 도구마다 다른 대상 정보를 씀

원고 [1.1 증거 및 사건 관리](/problems/1/1.1) · 소제목 「대상의 선택과 변경 및 진행 중 작업의 유지」

## 현상과 피해

같은 호출의 결과와 기록이 서로 다른 사건에 남거나(sift-mcp), 요청한 사건이 아닌 사건의 결과를 돌려주거나(SAVVYDFIR-MCP), 재시작 뒤 다른 작업 폴더의 기록 상태가 복원되거나(trudi), 재시작 뒤 시작 폴더로 돌아간 것을 응답으로 알 수 없다(regipy). 세션 만료 뒤 default 사건이 되고(Camel), 마운트 성공 뒤에도 이후 연산이 앞 이미지를 읽는다(sift-kernel).

## 문제가 관찰된 서버 (6)

### [Camel](/problems/servers/Camel)

- SetCaseId 뒤에도 Session 저장소가 남고, 4시간 호출이 없으면 default 사건이 된다. 코드: [src/Camel.Server/Sessions.cs:110-124](https://github.com/allisterb/Camel/blob/63f4cb2e26a2469a35f847bee607516cf6184e91/src/Camel.Server/Sessions.cs#L110-L124)(새 세션 문맥의 CaseId는 세션 ID), 151-166(SweepIdle: evictTtl을 넘기면 End); [src/Camel.Server/MCPServer.cs:51-66](https://github.com/allisterb/Camel/blob/63f4cb2e26a2469a35f847bee607516cf6184e91/src/Camel.Server/MCPServer.cs#L51-L66)(SetCaseId 설명: 이후 실행이 그 사건 기록 파일에 남음), 531-532(stdio 세션 ID는 default)

### [regipy](/problems/servers/regipy)

- set_hive_directory가 메모리 값만 바꾸고 응답에는 하이브 파일 이름만 있어, 클라이언트 재시작 뒤 시작 인자 폴더의 하이브로 돌아가도 알 수 없다. 코드: [regipy_mcp_server/server.py:130-133](https://github.com/mkorman90/regipy/blob/c6de929abc37d8315d1c31aba5e937db636f3303/regipy_mcp_server/server.py#L130-L133), 71-90

### [SAVVYDFIR-MCP](/problems/servers/SAVVYDFIR-MCP)

- extract_prefetch가 이미 추출한 prefetch 위치를 인자 case_id가 아니라 모듈 상태의 사건(_case_id())으로 정해, CASE-B 요청에 CASE-A의 실행 파일 이름을 돌려준다. 코드: [sift_mcp/tools/disk.py:696-703](https://github.com/kismatkunwar89/SAVVYDFIR-MCP/blob/9ac8e47540d4826227ac8957a5c5f4caf4f6c80b/sift_mcp/tools/disk.py#L696-L703)

### [sift-kernel](/problems/servers/sift-kernel)

- mount_evidence(B)가 성공해도 이후 연산이 A를 읽는다. 코드: [src/server.ts:311](https://github.com/Sathvik-1007/sift-kernel/blob/ea51bec90d4cb543e4aa6063af6e85ae3e4d9396/src/server.ts#L311)(시작 인자 evidencePath로 imagePath 초기화), 1745-1749(마운트 명령 성공 분기는 imagePath가 비었을 때만 바꿈), 1696(fls 대체 분기는 항상 바꿈), 1808·1849(이후 도구는 investigationState.imagePath를 씀)

### [sift-mcp](/problems/servers/sift-mcp)

- 공통 함수 sift_common은 VHIR_CASE_DIR를, case-mcp는 표시 파일 active_case를 먼저 써서, 같은 호출의 추출 폴더·기록은 B 사건에, case-mcp 기록은 A 사건에 남는다. 코드: [packages/case-mcp/src/case_mcp/server.py:227-251](https://github.com/AppliedIR/sift-mcp/blob/5ef6081a35252380ffe5456dca1a5f3355fbe01a/packages/case-mcp/src/case_mcp/server.py#L227-L251); [packages/sift-common/src/sift_common/__init__.py:16-20](https://github.com/AppliedIR/sift-mcp/blob/5ef6081a35252380ffe5456dca1a5f3355fbe01a/packages/sift-common/src/sift_common/__init__.py#L16-L20)

### [trudi](/problems/servers/trudi)

- 공유 session.json에 저장한 사건과 기록 경로를 현재 작업 폴더보다 먼저 복원해, 재시작 뒤 A 폴더의 파일 해시와 출력 사본이 B 사건의 기록에 남는다. 코드: [core/execution_log.py:1012-1025](https://github.com/nebulae/trudi/blob/88fbca78186b6a0ca40423cf5e37a9dc46ae051e/core/execution_log.py#L1012-L1025)
