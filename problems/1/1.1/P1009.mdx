# P1009 처리 대상을 한 번 정해 끝까지 쓰지 않아 결과가 다른 사건에 남음

항목 [1.1 증거 및 사건 관리](/problems/1/1.1) · 소제목 1.1.4 「대상 선택과 전환」

## 정의

**전제** 처리할 사건이나 자료를 현재 대상으로 정해 두고 호출마다 다시 받지 않거나, 처리 중에 대상을 바꿀 수 있는 서버에서

**결함** 처리 도중이나 호출 사이에 대상을 전역 상태나 다른 출처에서 다시 정하거나, 재시작, 세션 만료, 전환 실패로 대상이 바뀐 것을 확인하지 않고 응답에 알리지 않는다.

**피해** 요청한 대상이 아닌 자료의 결과가 돌아오거나 결과와 기록이 다른 사건에 남는데, 응답으로는 대상이 바뀐 것을 알 수 없다.

**경계** 사건을 처음 열 때 자동으로 만든 식별자가 겹치는 것과, 도구 호출마다 받은 사건과 입력을 대조하지 않는 것은 포함하지 않는다.
