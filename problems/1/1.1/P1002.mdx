# P1002 호출마다 받은 사건과 입력을 대조하지 않아 결과가 다른 사건에 남음

항목 [1.1 증거 및 사건 관리](/problems/1/1.1) · 소제목 1.1.1 「증거 등록과 사건 연결」

## 정의

**전제** 도구가 인자로 사건을 받거나 사건에 딸린 입력 자료를 읽고, 출력과 호출 기록을 사건별로 남기는 서버에서

**결함** 인자로 받은 사건이나 입력 자료가 출력과 호출 기록을 남길 사건과 맞는지 대조하지 않고 입출력 위치를 정한다.

**피해** 같은 호출의 출력과 호출 기록이 서로 다른 사건에 남거나, 다른 사건이나 등록하지 않은 자료의 처리 결과가 이 사건의 결과와 기록으로 남는다.

**경계** 인자 없이 서버가 사건 식별자를 만들 때 겹치는 값을 쓰는 것과, 읽기 허용 범위가 사건 단위가 아닌 것은 포함하지 않는다.
