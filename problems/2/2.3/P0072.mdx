# P0072 같은 조건을 일부 도구·경로에서만 검사하거나 서버 밖 설정에만 둠

항목 [2.3 실행 조건 검사](/problems/2/2.3) · 소제목 2.3.1 「선행 작업과 실행 상태 확인」

같은 선행 조건이 필요한 도구나 경로 가운데 일부에만 검사가 있거나, 조건을 도구 설명 안내나 클라이언트 훅 설정에만 두어 서버가 검사하지 않는 경로가 생긴다. 디스크 추출 전 무거운 탐지가 실행되며(SAVVYDFIR-MCP), 준비 점검 없는 보고서와 닫힌 사건의 기록 변경이 생긴다(trudi, sift-mcp).
