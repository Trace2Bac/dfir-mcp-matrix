# 2.3-A3 선행 작업 없이 부른 조회가 빈 결과를 정상으로 돌려줌

원고 [2.3 실행 조건 검사](/problems/2/2.3) · 소제목 [2.3.1 선행 작업과 실행 상태 확인](/problems/2/2.3/2.3.1)

## 현상과 피해

앞선 추출, 색인, ingest의 결과를 읽는 조회 도구가 그 작업이 끝났는지 보지 않거나, 확인하고도 성공 응답으로 돌려줘 이후 처리에서 안내가 사라진다. 빈 결과가 "찾는 기록이 없음"으로 전달된다. 인증 기록이 있는 이미지에서 "인증 기록 없음", 해시와 MIME 검색 0건을 "그 파일 없음", 색인하지 않은 범위 0건을 "연결 없음"으로 읽는다.

- windowed_response는 source 적재 여부와 관계없이 status success와 result_count를 싣는다(parse_usn_journal 등). 코드: [src/mulder/server/helpers.py:274-312](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/helpers.py#L274-L312)(windowed_response가 source 적재 여부를 보지 않고 status success·result_count·total_windows만 실음)
