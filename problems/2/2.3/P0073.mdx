# P0073 선행 작업 없이 부른 조회가 빈 결과를 정상으로 돌려줌

항목 [2.3 실행 조건 검사](/problems/2/2.3) · 소제목 2.3.1 「선행 작업과 실행 상태 확인」

앞선 추출, 색인, ingest의 결과를 읽는 조회 도구가 그 작업이 끝났는지 보지 않거나, 확인하고도 성공 응답으로 돌려줘 이후 처리에서 안내가 사라진다. 빈 결과가 "찾는 기록이 없음"으로 전달된다. 인증 기록이 있는 이미지에서 "인증 기록 없음", 해시와 MIME 검색 0건을 "그 파일 없음", 색인하지 않은 범위 0건을 "연결 없음"으로 읽는다.
