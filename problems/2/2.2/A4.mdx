# A4 등록하거나 저장하는 값을 검사하지 않음

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 「인자 구조와 값 검사」

## 현상과 피해

서버가 저장해 두고 뒤의 판단에 쓰는 값을 저장할 때 형식, 참조 대상, 짝, 개수를 검사하지 않아 뒤의 조회, 검증, 판정이 틀린다. 대조하지 않은 증거가 검증 통과(Camel-1), 0개 등록으로 쓰기 거부가 꺼짐(Camel-2), 없는 ID로 가설 CONFIRMED(SAVVYDFIR-MCP), 탐지에서 빠지고 Unknown(sift-kernel-1), 조회에서 빠지거나 처리 오류(verdict-dfir).
