# P0068 증거를 읽거나 외부 프로그램을 실행한 뒤에 검사함

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.4 「검사 순서와 오류 보고」

## 현상과 피해

거부될 요청이 검사 전에 작업을 시작하거나 되돌리기 어려운 흔적을 남긴다. 외부 수집이 실행됐는데 응답은 형식 오류뿐(MyIRTeam), 등록하지 않은 이미지의 해시가 사건 기록에 남음(sift-mcp), 앞 결과 폴더가 지워짐(verdict-dfir), 거부됐는데 서명된 manifest가 남음(verdict-dfir), 밖 폴더를 읽은 기록(Cyber-Incident-Investigation-and-Triage-MCP-Server), `completed` 없는 감사 기록(SAVVYDFIR-MCP).
