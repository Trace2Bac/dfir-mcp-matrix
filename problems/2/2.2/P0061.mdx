# P0061 값의 형식, 허용 값, 인자 사이의 관계를 검사하지 않음

항목 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.1 「인자 구조와 값 검사」

## 현상과 피해

값의 꼴, 대소문자, 허용 목록, 범위를 검사하지 않아 처리 단계에서 조건에 맞지 않는 값이 그대로 쓰이고 0건이나 거르지 않은 결과가 정상 응답으로 온다. 247개를 읽고 0건(winforensics-mcp), 설치된 지속성에 반증 판정(findevil), SMS가 있는데 `no_artifacts`(mulder), 플러그인 0개(regipy), 거르지 않은 결과에 요청 범위 표시(SAVVYDFIR-MCP).
