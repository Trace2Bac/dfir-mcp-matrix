# P0065 검사가 정상 입력을 거부함

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.1 「인자 구조와 값 검사」

## 현상과 피해

검사가 정상 입력을 거부해 필요한 분석을 할 수 없다. 흔한 질의 `-type f -executable`이 `-exec` 검사에 걸림(mcp_dfir), 경로 꼴이나 `;`가 든 검색어가 경로 접근 거부나 셸 메타 문자로 거부되고 어느 인자가 걸렸는지 알리지 않음(sift-mcp), 서버가 안내한 결과 파일을 다른 도구의 입력으로 주면 허용 위치 밖으로 거부(SAVVYDFIR-MCP).
