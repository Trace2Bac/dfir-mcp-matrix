# P0062 허용하지 않는 값을 거부하지 않고 다른 값으로 바꿈

항목 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.1 「인자 구조와 값 검사」

## 현상과 피해

허용 목록이나 범위 밖의 값, 맞지 않는 인자 조합을 오류로 알리지 않고 기본값이나 다른 값으로 바꿔 실행한다. 응답에는 요청 값이 그대로 실리는 경우가 많다. 다른 배치 파일 실행(agentic-dfir), 앞선 hunt가 조건 없이 다시 시작(mcp-velociraptor), 근거 1건인 발견사항까지 보고서에 들어감(sift-kernel), 정규식을 글자 그대로 검색(Wireshark-MCP).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 문제가 없음을 증명하지 못한 판정이다. 코드 위치가 있으면 그 문제를 찾아 코드를 보았으나 발견하지 못한 것이고, 없으면 근거 대장의 묶음 분모에서 옮겨 아직 이 문제로 코드를 보지 않은 것이다.
