# P0062 허용하지 않거나 맞지 않는 값을 거부하지 않고 바꾸거나 버리거나 잘라서 씀

항목 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.1 「인자 구조와 값 검사」

허용 목록이나 범위 밖의 값, 맞지 않는 인자 조합을 오류로 알리지 않고 기본값이나 다른 값으로 바꿔 실행한다. 응답에는 요청 값이 그대로 실리는 경우가 많다. 다른 배치 파일 실행(agentic-dfir), 앞선 hunt가 조건 없이 다시 시작(mcp-velociraptor), 근거 1건인 발견사항까지 보고서에 들어감(sift-kernel), 정규식을 글자 그대로 검색(Wireshark-MCP). 기록 도구는 시각으로 읽히지 않는 값을 버리거나(SAVVYDFIR-MCP) 기록 글을 정한 길이에서 표시 없이 잘라 저장한다(trudi).
