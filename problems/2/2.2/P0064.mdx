# P0064 같은 인자 검사가 진입점·도구마다 달라 일부 경로에서 거치지 않음

항목 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.1 「인자 구조와 값 검사」

같은 인자 검사가 직접 호출, 일괄 실행, 다른 도구 같은 진입점마다 달라, 한 경로에서는 걸리는 값이 다른 경로로 들어오면 검사 없이 처리된다.
