# P0070 검사를 통과하지 못한 입력을 오류로 알리지 않음

항목 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.4 「검사 순서와 오류 보고」

## 현상과 피해

입력이 처리 조건에 맞지 않아 아무것도 처리하지 못했는데 빈 결과, 0건, 성공이 온다. 검사하지 않은 파일이 IoC 없음(winforensics-mcp), 지우지 않은 결과 폴더가 지운 것으로(trudi), 읽지 않은 입력이 탐지 0건(agentic-dfir), 기록 0건으로 서명된 manifest(verdict-dfir), 거르지 않은 전체 목록이 검색 결과처럼(sift-kernel).
