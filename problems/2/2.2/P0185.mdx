# P0185 검사하지 않은 값을 먼저 저장해 뒤의 조회와 보고서 생성이 실패함

항목 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 2.2.1 「인자 구조와 값 검사」

## 현상과 피해

`update_finding`은 받은 값을 자료 모델 검사 없이 DB에 쓴 뒤 다시 읽어, `severity`에 정해진 값 밖의 문자열이나 빈 `evidence_refs`를 넘기면 저장은 되고 다시 읽는 단계에서 예외로 끝나며, 그 뒤 같은 행을 읽는 `get_findings`와 `finalize_report`도 예외로 끝난다(mulder).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 문제가 없음을 증명하지 못한 판정이다. 코드 위치가 있으면 그 문제를 찾아 코드를 보았으나 발견하지 못한 것이고, 없으면 근거 대장의 묶음 분모에서 옮겨 아직 이 문제로 코드를 보지 않은 것이다.
