# 2.2-D9 오류는 나지만 어떤 인자가 어떤 조건을 어겼는지 알리지 않음

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 [2.2.1 인자 구조와 값 검사](/problems/2/2.2/2.2.1)

## 현상과 피해

잘못된 입력이 오류로 끝나지만 원인 인자와 조건이 없거나 다른 원인을 가리킨다. 입력 오류가 "Autopsy is not reachable"(autopsy), 형식이 틀린 해시가 변조 안내(verdict-dfir), 파일 이름 규칙 차이가 권한 부족(MyIRTeam), 없는 폴더가 하이브 없음과 함께 적재 하이브까지 비움(regipy), 허용 유형 대신 TypeError(regipy), 작업별 오류 글이 KeyError에 묻힘(mulder).
