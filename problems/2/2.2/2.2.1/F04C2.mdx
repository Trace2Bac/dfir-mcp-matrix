# F04C2 검사하지 않은 값을 먼저 저장해 뒤의 조회와 보고서 생성이 실패함

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 [2.2.1 인자 구조와 값 검사](/problems/2/2.2/2.2.1)

## 현상과 피해

`update_finding`은 받은 값을 자료 모델 검사 없이 DB에 쓴 뒤 다시 읽어, `severity`에 정해진 값 밖의 문자열이나 빈 `evidence_refs`를 넘기면 저장은 되고 다시 읽는 단계에서 예외로 끝나며, 그 뒤 같은 행을 읽는 `get_findings`와 `finalize_report`도 예외로 끝난다(mulder).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.
