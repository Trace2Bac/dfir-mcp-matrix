# 2.2-C7 외부 프로그램에 넘기는 값의 역할을 구분하지 않음

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 [2.2.3 외부 프로그램과 라이브러리에 전달할 인자 구성](/problems/2/2.2/2.2.3)

## 현상과 피해

검색어, 경로, 규칙, 플러그인 이름 같은 값이 셸 문법, 옵션, 와일드카드, 질의 문법으로 해석되어 요청과 다른 조건으로 실행되거나 다른 파일을 연다. 다른 검색어로 찾은 결과와 받은 값 그대로의 감사 기록(findevil), `$`가 풀려 다른 경로(WireMCP), 옵션으로 읽힌 플러그인 값(mulder), LIKE 와일드카드로 늘어난 결과(autopsy), 룰 글이 문자열 패턴 옵션으로(VolPilot).
