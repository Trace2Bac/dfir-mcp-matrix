# B6 경로를 해석하고 허용 위치와 대조하는 방법이 틀리거나 빠짐

원고 [2.2 도구 입력 검사](/problems/2/2.2) · 소제목 「경로 인자 검사」

## 현상과 피해

읽기 쪽은 허용 위치 밖 파일의 내용, 해시, 시각이 증거 결과로 오고 분석 호스트 파일이 이미지 결과로 기록된다. 쓰기 쪽은 허용 폴더 밖에 파일이 생기고, 호출 기록이나 등록 증거가 덮어써진다. 규칙 위치 쪽은 플러그인 폴더 밖 Perl 파일이 실행된다(mulder).
