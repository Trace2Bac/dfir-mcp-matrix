# 2.1-B1 입력 인자를 받고도 처리에 쓰지 않음

원고 [2.1 도구 설명](/problems/2/2.1) · 소제목 [2.1.2 입력 스키마와 반환 형식 정의](/problems/2/2.1/2.1.2)

## 현상과 피해

스키마와 설명이 결과를 거르는 인자를 알리지만 처리에 쓰이지 않는다. 기간, 이벤트 ID, 이름, 시간 창, 파티션, 해시 종류로 거른 결과라고 보고 거르지 않은 결과를 해석한다.
