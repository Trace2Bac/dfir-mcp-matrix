# P0051 기능으로 뒷받침되지 않는 우수성 주장, 무조건 사용 지시, 과도한 설명

원고 [2.1 도구 설명](/problems/2/2.1) · 소제목 2.1.1 「설명 내용」

## 현상과 피해

설명이 뒷받침 없는 우수성을 주장하거나(SAVVYDFIR-MCP), 100줄만 읽는 도구를 모든 텍스트 파일에 쓰라고 지시하거나(Cyber-Incident-Investigation-and-Triage-MCP-Server), 3,827자에 개발 이력을 담는다(SAVVYDFIR-MCP). 서버 사례로는 처리 결과가 바뀌지 않아 피해를 보이지 못했다. 피해 근거는 문헌(Hasan 외, Faghih 외)이다.
