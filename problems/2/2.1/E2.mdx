# E2 설명과 표시가 알리지 않은 내려받기, 설치, 외부 통신

원고 [2.1 도구 설명](/problems/2/2.1) · 소제목 「동작 표시와 부수 효과」

## 현상과 피해

도구가 실행 중에 프로그램을 내려받거나 설치하거나 외부 서버에서 자료를 받는데 설명과 표시가 알리지 않는다. 조사자가 승인하지 않은 외부 내려받기와 패키지 설치(Camel), 알리지 않은 외부 심볼 요청(agentic-dfir, README는 "No outbound network").
