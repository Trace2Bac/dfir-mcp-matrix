# F01C2 확인 절차 안내가 서버 연산이 하는 일을 실제와 다르게 설명함

원고 [2.1 도구 설명](/problems/2/2.1) · 소제목 [2.1.1 도구 설명 작성](/problems/2/2.1/2.1.1)

## 현상과 피해

연산별 주의 표의 `build_attack_narrative` 항목은 `verify_chain`을 모든 발견사항에 근거가 있는지 확인하는 연산으로 안내하지만, `verify_chain`은 호출 기록의 해시 체인만 검사하고 발견사항을 읽지 않는다(sift-kernel).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.
