# 2.1-E1 읽기 전용으로 표시한 도구가 파일을 만들거나 바꾸거나 지움

원고 [2.1 도구 설명](/problems/2/2.1) · 소제목 [2.1.4 도구 동작 표시](/problems/2/2.1/2.1.4)

## 현상과 피해

읽기 전용 표시를 받은 도구가 허용 폴더 안 캡처를 덮어쓰고(Wireshark-MCP), 결과 폴더를 지우며(verdict-dfir), 출력 폴더에 보고서와 카빙 파일을 쓴다(sift-kernel, 증거는 그대로).

## 해당 기능이 있는 서버 (3)

[sift-kernel](/problems/servers/sift-kernel), [verdict-dfir](/problems/servers/verdict-dfir), [Wireshark-MCP](/problems/servers/Wireshark-MCP)

## 문제가 관찰된 서버 (3)

### [sift-kernel](/problems/servers/sift-kernel)

- 커널 도구는 mount_evidence·reset_investigation을 빼고 모두, 분류 도구 14개는 모두 readOnlyHint를 참으로 표시하지만 generate_report, carve_files, recover_deleted, generate_timeline은 출력 폴더에 파일을 쓴다. 코드: [src/server.ts:352-375](https://github.com/Sathvik-1007/sift-kernel/blob/ea51bec90d4cb543e4aa6063af6e85ae3e4d9396/src/server.ts#L352-L375)

### [verdict-dfir](/problems/servers/verdict-dfir)

- bulk_extract는 readOnlyHint·idempotentHint 참, destructiveHint 거짓이지만 사건 폴더 아래 이미지 이름의 결과 폴더가 있으면 지우고 다시 만든다. 코드: [services/mcp/src/tools/bulk_extract.rs:309-320](https://github.com/TimothyVang/verdict-dfir/blob/acada5c6b91545639d5a470ba0d92c0e29e73063/services/mcp/src/tools/bulk_extract.rs#L309-L320)

### [Wireshark-MCP](/problems/servers/Wireshark-MCP)

- WRITE_TOOLS에 없는 도구를 모두 read_only_hint로 표시하는데 목록에 없는 wireshark_set_protocol_prefs가 해석 설정을 검사 없이 tshark -o로 넘겨, 지정한 경로에 파일이 생기고 허용 폴더 안 캡처 파일이 덮어써진다. 코드: [src/wireshark_mcp/tool_annotations.py:52-57](https://github.com/bx33661/Wireshark-MCP/blob/0e1b6595a2dcfe097133deb1c0c3128fb7a110d4/src/wireshark_mcp/tool_annotations.py#L52-L57)
