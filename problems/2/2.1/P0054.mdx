# P0054 스키마의 자료형, 기본값, 허용 값, 예시 값이 처리 함수와 다름

원고 [2.1 도구 설명](/problems/2/2.1) · 소제목 2.1.2 「입력과 반환 정의」

## 현상과 피해

스키마나 설명에 적은 자료형, 기본값, 허용 값, 예시 값이 처리 함수가 실제로 받는 값과 달라, 설명대로 전달한 값이 다른 조건으로 처리되거나 거부된다. MD5를 NTLM으로 시도한 "찾지 못함", 예 패턴이 IP 줄을 놓침, 설명대로 준 아티팩트 이름이 300초 대기 뒤 결과 없음, 스키마대로 보낸 문자열이 비교 오류, 지원한다던 형식이 0건 성공, 정규식 검색이 일치가 있는데 0건 성공.
