# P0095 처리 중 난 실패를 빈 결과나 없음 판정으로 바꿈

항목 [4.1 실행 결과 상태 구분](/problems/4/4.1) · 소제목 4.1.2 「결과 상태의 의미」

## 현상과 피해

분석하지 않은 메모리가 이상 없음과 검토 완료로(findevil), 위협 정보를 받지 못한 IP가 블랙리스트에 없는 IP로(WireMCP), 읽지 못한 캡처가 파일 서명과 외부 전송 없음으로(Wireshark-MCP), 있는 레지스트리 키가 없는 키로(regipy), 읽지 못한 syslog가 상관관계 없음으로(mcp-forensic-toolkit), 입력 파일을 읽지 않은 탐지가 0건으로(agentic-dfir) 나온다.
