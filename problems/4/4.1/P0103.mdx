# P0103 실패 원인을 나눠 알리지 않음: 다른 원인으로 알리거나, 원인 인자·조건이나 원인 출력을 빼거나, 정상 입력에 오류를 냄

항목 [4.1 실행 결과 상태 구분](/problems/4/4.1) · 소제목 4.1.2 「결과 상태와 실패 이유 전달」

인자 오류가 Autopsy 연결 실패로 전달되고(autopsy), 증거가 바뀌었다는 판정이 실행 실패나 "검증이 끝나지 않음"과 구별되지 않으며(sift-kernel, Camel), 실행 파일 오류가 시간 초과로 분류되고(mulder), 끝까지 실행된 호출이 중계 계층의 시간 초과 오류로 끝난다(sift-mcp). UTF-8이 아닌 출력에서 명령 기록과 본문을 잃는다(mcp_dfir). 입력 단계에서도 같다. 형식이 틀린 해시가 변조 안내(verdict-dfir), 파일 이름 규칙 차이가 권한 부족(MyIRTeam), 없는 폴더가 하이브 없음과 함께 적재 하이브까지 비움(regipy), 허용 유형 대신 TypeError(regipy), 작업별 오류 글이 KeyError에 묻힘(mulder). 검사를 문자열 일부나 경로 꼴로 대조해 흔한 정상 입력(`-type f -executable`, `/`가 든 검색어)을 거부하고(mcp_dfir, sift-mcp), 서버가 안내한 결과 파일을 다른 도구의 입력으로 주면 허용 위치 밖으로 거부한다(SAVVYDFIR-MCP).
