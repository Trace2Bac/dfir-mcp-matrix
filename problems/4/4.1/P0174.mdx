# P0174 검사를 통과하지 못한 입력을 오류로 알리지 않음

항목 [4.1 실행 결과 상태 구분](/problems/4/4.1) · 소제목 4.1.2 「결과 상태와 실패 이유 전달」

## 현상과 피해

없는 파일, 허용 폴더 밖 파일, 캡처가 아닌 파일, 쓰기 권한이 없는 출력 폴더, 문서가 지원한다고 적은 다른 출력 형식, `~`를 펼치지 않은 사건 폴더처럼 하위 실행이 처리하지 못하는 입력을 주면 그 실패가 일치 없음이나 0건의 성공 응답이 된다(Wireshark-MCP, SAVVYDFIR-MCP, agentic-dfir, trudi). 컴파일되지 않는 정규식, VQL 식, YARA 규칙을 주면 오류를 로그에만 남기거나 건너뛰어 빈 결과나 일치 0건을 돌려주고, 종료 코드를 보지 않거나 늘 0으로 만들어 문법 오류가 빈 배열이 된다(mcp-velociraptor, agentic-dfir, MyIRTeam, Camel). glob 꼴 패턴으로 정규식 생성이 실패하면 예외를 무시하고 거르지 않은 이미지 전체 목록을 검색 결과처럼 성공으로 돌려준다(sift-kernel).

## 서버별 판정
