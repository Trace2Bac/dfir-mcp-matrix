# 4.2-C4 일부 항목을 읽지 못한 검색 결과를 완전한 결과처럼 냄

원고 [4.1 실행 결과 상태 구분](/problems/4/4.1) · 소제목 [4.1.1 외부 프로그램 실행 결과 판단](/problems/4/4.1/4.1.1)

같은 묶음의 다른 사례는 [4.2.3 분석 범위와 해석 한계 표시](/problems/4/4.2/4.2.3/4.2-C4)에 있다.

## 현상과 피해

`FindFilesAsync`는 종료 코드를 보지 않고 표준 출력만 읽어, 읽지 못한 하위 항목이 있어도 표시 없이 일부 결과만 내며, 이 동작은 설명과 주석에 설계로 밝혀 두었다(Camel).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.

## 문제가 관찰된 서버 (1)

### [Camel](/problems/servers/Camel)

- `FindFilesAsync`는 종료 코드를 보지 않고 표준 출력만 읽어, 없는 폴더·`find` 실패·일치 없음이 같은 빈 배열이 되고 읽지 못한 하위 항목이 있어도 표시 없이 일부 결과만 나간다(설명과 주석에 밝혀 둔 설계). 코드: [src/Camel.Toolkits/DiskAnalysis/DiskAnalysisToolkit.cs:224-235](https://github.com/allisterb/Camel/blob/63f4cb2e26a2469a35f847bee607516cf6184e91/src/Camel.Toolkits/DiskAnalysis/DiskAnalysisToolkit.cs#L224-L235), [src/Camel.Toolkits/DiskAnalysis/DiskAnalysisToolkit.cs:238-256](https://github.com/allisterb/Camel/blob/63f4cb2e26a2469a35f847bee607516cf6184e91/src/Camel.Toolkits/DiskAnalysis/DiskAnalysisToolkit.cs#L238-L256)
