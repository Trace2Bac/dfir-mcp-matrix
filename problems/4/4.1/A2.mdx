# A2 종료 코드가 0일 때 표준 오류·출력 내용·만든 파일을 확인하지 않음

원고 [4.1 실행 결과 상태 구분](/problems/4/4.1) · 소제목 「외부 프로그램 실행 결과 판단」

## 현상과 피해

0으로 끝났지만 쓰기에 실패했거나 출력 파일을 만들지 못한 실행이 성공으로 전달되고, 그 결과를 이어받은 검사가 "검사할 파일 없음"을 낸다(Wireshark-MCP). 원격 질의의 실행 오류가 결과 없음이 되고(mcp-velociraptor), hunt ID를 받지 못한 요청이 앞선 hunt의 ID로 성공한다(mcp-velociraptor).
