# P0101 서버가 알아챈 실패·건너뜀·부분 처리가 공통 응답·상태 추론·작업 관리 단계에서 최상위 상태에 반영되지 않음

항목 [4.1 실행 결과 상태 구분](/problems/4/4.1) · 소제목 4.1.2 「결과 상태와 실패 이유 전달」

메모리 분석을 하지 못한 작업이 성공과 completed로 남고(mulder), 실행하지 않은 플러그인 호출이 성공과 검토 범위로 남으며(mulder), 원본 ZIP이 바뀐 분석, 시작하지 못한 수집 도구, 검사하지 못한 YARA 검사가 SUCCESS나 부분 성공으로(MyIRTeam), 해시 불일치가 `finished`로(trudi) 나간다. 끊긴 캡처에서 나온 통계가 완전한 캡처의 통계와 같은 모양으로 전달된다. 응답에 드러나지 않는다.
