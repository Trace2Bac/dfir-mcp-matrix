# P0127 증거 글이 경계 표시를 닫거나 흉내 냄

항목 [4.2 결과 해석 정보와 증거 글의 구분](/problems/4/4.2) · 소제목 4.2.4 「증거 내용과 서버 문구의 구분」

증거 값을 표시 문자열로 감싸면서 값 안의 같은 표시를 바꾸지 않아, 증거 글이 그 표시를 닫고 뒤의 글이 표시 밖 서버 글로 읽힌다. findevil은 이런 꼬리말 위조를 스스로 보안 결함 범위로 둔다.
