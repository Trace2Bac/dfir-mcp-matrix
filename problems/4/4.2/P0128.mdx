# P0128 경계·비신뢰 표시를 일부 도구·필드·응답·끝점에만 적용하거나 닫지 않음

항목 [4.2 결과 해석 정보와 증거 글의 구분](/problems/4/4.2) · 소제목 4.2.4 「증거 내용과 서버 문구의 구분」

같은 서버가 일부 도구나 필드만 감싸고 다른 경로는 서버 머리말, 꼬리말과 함께 표시 없이 내보낸다. 메모리 문자열, `strings` 출력, PowerShell 기록처럼 공격자가 정할 수 있는 긴 글이 표시 없는 경로로 간다. 서버가 "모든 응답에 붙인다"고 밝힌 비신뢰 표시와 지시 무시 안내가 오류 응답, 일부 도구, 묶음 끝점에는 없다. 지시 무시 문장은 여러 안내 문장 가운데 하나로 돌아가며 실려 대부분의 응답에 없다. 서버 안 검토 모델에 증거를 넘길 때 "데이터이지 지시가 아니다"라는 머리말만 있고 닫는 표시가 없으며, 일부 입력 경로에는 머리말이 없다. 머리말이 판정에 주는 효과는 확인하지 못했다.
