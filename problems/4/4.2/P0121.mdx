# P0121 같은 결과인데 도구·반환 경로·호출 횟수에 따라 주의가 빠짐

항목 [4.2 결과 해석 정보와 증거 글의 구분](/problems/4/4.2) · 소제목 4.2.3 「분석 범위와 해석 한계 표시」

일괄 실행, 백그라운드 작업 결과 조회, 같은 기록을 읽는 다른 도구로 나간 결과에는 주의가 없다. 라이브러리가 남긴 모순 목록이 MCP 응답에서 사라진다. 토큰을 줄이려고 도구마다 처음 몇 번만 주의를 싣는 설계에서는 같은 파서로 여러 호스트 로그를 처리하는 평범한 흐름에서 넷째 호출부터 교차 확인 안내가 빠진다.
