# D1 해석하지 못한 시각을 버리거나 비우고, 그 항목을 범위 조건에서 거르지 않으며 알리지 않음

원고 [4.2 결과 해석 정보 표시](/problems/4/4.2) · 소제목 「값의 해석 조건」

## 현상과 피해

시간 순서 정리, timestomp 탐지, 근무 시간 외 판정이 0건이거나 틀린 결과로 정상 응답되고, "시각 없음"과 "못 읽음"이 구별되지 않는다.

## 문제가 관찰된 서버 (5)

### [agentic-dfir](/problems/servers/agentic-dfir)

- 시간 범위와 파생 값에 쓰는 `_parse_ts`가 오프셋이 붙은 시각을 읽지 못해 `None`으로 돌려주고, 범위를 거르는 도구는 `None`이 된 항목을 거르지 않고 싣는다. `analyze_windows_logons`에 `time_window_end`를 주자 시간대 없는 23:30 로그온은 빠지고 `+09:00`이 붙은 23:30 로그온은 실렸으며, 읽지 못한 시각은 `is_after_hours`가 거짓이 된다. 코드: [dfir_mcp/src/dfir_mcp/__init__.py:203-220](https://github.com/Juwon1405/agentic-dfir/blob/a17e90b8a3c5ab5431f0da9f354f315082257f99/dfir_mcp/src/dfir_mcp/__init__.py#L203-L220), 1795-1799, 1823-1829

### [SAVVYDFIR-MCP](/problems/servers/SAVVYDFIR-MCP)

- 메모리 도구의 `_parse_vol_dt`가 시간대 없는 ISO 형식만 읽어, Volatility 3 2.28.2 JSON 출력처럼 `+00:00`이 붙은 시각은 `None`이 되고 그 행의 `create_time`이 `null`로 실린다. 읽지 못했다는 표시가 없다. 코드: [sift_mcp/tools/memory.py:343-358](https://github.com/kismatkunwar89/SAVVYDFIR-MCP/blob/9ac8e47540d4826227ac8957a5c5f4caf4f6c80b/sift_mcp/tools/memory.py#L343-L358)
- `_parse_dt`가 소수점 아래 6자리까지만 읽어, MFTECmd 기본 형식(7자리)의 `Created0x10`·`Created0x30`으로 만든 `extract_mft_timeline`의 `si_created`·`fn_created`가 `null`이 되고 그 행은 timestomp 후보에서 빠진다. 응답에 읽지 못했다는 표시가 없다. 코드: [sift_mcp/tools/disk.py:403-428](https://github.com/kismatkunwar89/SAVVYDFIR-MCP/blob/9ac8e47540d4826227ac8957a5c5f4caf4f6c80b/sift_mcp/tools/disk.py#L403-L428), 1266-1276, 1621-1631

### [VolPilot](/problems/servers/VolPilot)

- `build_timeline`이 Volatility 3 2.28.0이 낸 `+00:00` 붙은 시각 문자열을 `_parse_timestamp`(시간대 없는 형식 네 가지만 시도)로 읽지 못해 모든 행을 사건으로 만들지 않고, 실제 Windows 10 이미지에서 시각 값 277개가 있는데도 `total_events` 0을 오류 없이 돌려준다. 응답에 읽지 못해 뺀 항목 수가 없다. 코드: [plugins/correlation.py:379-396](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/plugins/correlation.py#L379-L396), 415-504, 512-521; [plugins/_common.py:51-68](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/plugins/_common.py#L51-L68); [mcp_server.py:431-434](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/mcp_server.py#L431-L434)

### [winforensics-mcp](/problems/servers/winforensics-mcp)

- `ingest_parsed_csv`는 시각 열이 비었거나 ISO 꼴로 읽히지 않는 CSV 행을 시간 범위 조건에 걸지 않고 통과시켜, 범위를 준 결과에 범위 밖일 수 있는 행이 표시 없이 섞인다. 코드: [winforensics_mcp/parsers/csv_ingestor.py:138-161](https://github.com/x746b/winforensics-mcp/blob/cce7f360873fc9ae564296017cbffe2a603d83dd/winforensics_mcp/parsers/csv_ingestor.py#L138-L161), 363-373, 402-403
- LNK 헤더를 읽지 못해 `pylnk3` 값을 쓰는 대체 경로에서 `_format_datetime`이 `datetime`을 받으면 값을 돌려주지 않아(None만 처리하고 return 없음), `creation_time_utc`·`access_time_utc`·`modification_time_utc`가 모두 `null`로 실린다. `timestamp_source`는 대체 경로라는 것만 적는다. 코드: [winforensics_mcp/parsers/lnk_parser.py:35-38](https://github.com/x746b/winforensics-mcp/blob/cce7f360873fc9ae564296017cbffe2a603d83dd/winforensics_mcp/parsers/lnk_parser.py#L35-L38), 154-162
