# C5 다른 원인으로도 나오는 결과를 확정 판정이나 지표로 내고 다른 원인 주의가 없음

원고 [4.2 결과 해석 정보 표시](/problems/4/4.2) · 소제목 「분석 범위와 해석 한계」

## 현상과 피해

로그인 화면 URL을 연 평범한 요청이 평문 자격 증명 노출로 확정 표시되고, 정상 JIT 영역이 주입 지표로 읽힌다.

## 문제가 관찰된 서버 (3)

### [agentic-dfir](/problems/servers/agentic-dfir)

- psscan 결과에 "high-confidence rootkit signal"이라는 해석 주장을 붙인다. 코드: [dfir_mcp/src/dfir_mcp/sift_adapters/volatility3.py:149-164](https://github.com/Juwon1405/agentic-dfir/blob/a17e90b8a3c5ab5431f0da9f354f315082257f99/dfir_mcp/src/dfir_mcp/sift_adapters/volatility3.py#L149-L164)

### [VolPilot](/problems/servers/VolPilot)

- `detect_dll_injection`은 malfind 결과를 모두 `rwx_region`, "RWX VAD at …"으로 싣고 도구 설명은 이를 셸코드나 반사 적재의 징후로만 적는다. 정상 원인 주의는 `unlinked_dll`에만 있고, JIT 컴파일러나 .NET CLR이 만드는 쓰기·실행 영역에 대한 주의가 없다(mulder는 같은 malfind 결과에 그 주의를 붙인다). 코드: [plugins/correlation.py:223-285](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/plugins/correlation.py#L223-L285); [mcp_server.py:296-305](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/mcp_server.py#L296-L305), [mcp_server.py:1038-1041](https://github.com/cpuu/VolPilot/blob/5c848519cfa2e86a86abbe613c7249fddeffc6df/mcp_server.py#L1038-L1041)

### [Wireshark-MCP](/problems/servers/Wireshark-MCP)

- `wireshark_extract_credentials`는 바이트에 `login`이 있는 패킷을 프로토콜을 가리지 않고 10개까지 찾은 뒤 패킷 목록 글에 `login`·`Password`가 있으면 `protocol` `Telnet` 근거를 더하고, 근거가 하나라도 있으면 `severity` `high`, `confidence` `confirmed`로 둔다. URI `/login`인 평범한 HTTP GET 하나로 Telnet 평문 자격 증명 발견사항이 `confirmed`로 나왔고 다른 원인 가능성은 알리지 않는다. 코드: [src/wireshark_mcp/tools/security.py:110-127](https://github.com/bx33661/Wireshark-MCP/blob/0e1b6595a2dcfe097133deb1c0c3128fb7a110d4/src/wireshark_mcp/tools/security.py#L110-L127), [src/wireshark_mcp/tools/security.py:139-155](https://github.com/bx33661/Wireshark-MCP/blob/0e1b6595a2dcfe097133deb1c0c3128fb7a110d4/src/wireshark_mcp/tools/security.py#L139-L155)
