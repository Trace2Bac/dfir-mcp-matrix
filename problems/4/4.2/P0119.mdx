# P0119 부재를 단정할 수 없는 조건을 알리지 않고 부재·정상·배제로 냄

원고 [4.2 결과 해석 정보 표시](/problems/4/4.2) · 소제목 4.2.3 「분석 범위와 해석 한계」

## 현상과 피해

회전 로그에만 있는 설치 기록이 반증으로 판정되고, 끊긴 캡처의 부재가 `confirmed`로 나가며, "수집하지 않음"과 "보지 못함"이 구별되지 않는다.

### [Camel](/problems/servers/Camel)

<Case n={1} repo="allisterb/Camel" commit="63f4cb2e26a2469a35f847bee607516cf6184e91" refs={[{"path": "src/Camel.Toolkits/DiskAnalysis/DiskAnalysisToolkit.cs", "from": 224, "to": 235}, {"path": "src/Camel.Toolkits/DiskAnalysis/DiskAnalysisToolkit.cs", "from": 238, "to": 256}]} raw={""}>

`FindFilesAsync`는 종료 코드를 보지 않고 표준 출력만 읽어, 없는 폴더·`find` 실패·일치 없음이 같은 빈 배열이 되고 읽지 못한 하위 항목이 있어도 표시 없이 일부 결과만 나간다(설명과 주석에 밝혀 둔 설계).

</Case>

<a id="case-findevil"></a>

### [findevil](/problems/servers/findevil)

<Case n={1} repo="marlyocat/findevil" commit="d1a8d25d9c8c05bd66881506cb1f12314ee7c5e1" refs={[{"path": "src/findevil/tools/self_correction.py", "from": 185, "to": 211}, {"path": "src/findevil/tools/self_correction.py", "from": 336, "to": 359}]} raw={""}>

`verify_finding`의 `_verify_package_installed`는 `var/log/apt/history.log`와 `var/log/dpkg.log` 두 파일만 읽고, 둘 다 없거나 설치 기록이 없으면 `CONTRADICTED`와 "no apt/dpkg install event … found"를 돌려준다. 읽은 로그 파일과 회전 로그(`.1`, `.gz`)를 보지 않았다는 사실은 근거 문장에 없다.

</Case>

<Case n={2} repo="marlyocat/findevil" commit="d1a8d25d9c8c05bd66881506cb1f12314ee7c5e1" refs={[{"path": "src/findevil/tools/linux_packages.py", "from": 566, "to": 569}, {"path": "src/findevil/tools/linux_packages.py", "from": 617, "to": 623}]} raw={""}>

`verify_package_integrity`는 MD5를 계산하지 못한 파일도 `files_checked`에 세고, 불일치가 없으면 "This rules out the timestomped-sshd class of attack"을 고른다.

</Case>

### [Wireshark-MCP](/problems/servers/Wireshark-MCP)

<Case n={1} repo="bx33661/Wireshark-MCP" commit="0e1b6595a2dcfe097133deb1c0c3128fb7a110d4" refs={[{"path": "src/wireshark_mcp/tools/threat.py", "from": 255, "to": 275}, {"path": "src/wireshark_mcp/tools/threat.py", "from": 404, "to": 420}, {"path": "src/wireshark_mcp/tshark/client.py", "from": 598, "to": 609}, {"path": "src/wireshark_mcp/tshark/client.py", "from": 631, "to": 632}]} raw={""}>
