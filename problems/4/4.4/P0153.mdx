# P0153 외부로 보내는 값에서 내부 정보를 거르지 않거나 일부만 거름

항목 [4.4 민감 정보 관리](/problems/4/4.4) · 소제목 4.4.4 「외부 전송 자료 선택과 가림」

공개 평판 조회 서비스로 IP와 도메인 지표를 보내기 전에 사설 주소와 내부 호스트 이름을 거르지 않고 형식도 검사하지 않아, 피해 조직의 내부 정보가 제3자 서비스에 남는다. 보내기 전에 거르는 처리를 두었지만 IP 하나로 해석되는 사설 주소나 식별자 하나에만 적용하고, 내부 호스트 이름, 주소 대역, URL 안 주소, 자유 글이나 다른 식별 필드는 그대로 보낸다. 받는 쪽이 대개 조직 플랫폼이거나 사용자가 켜는 기능이라 피해 폭은 좁다.
