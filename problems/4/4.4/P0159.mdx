# P0159 분석 도구의 외부 통신을 막지 않거나 모델이 도구 설정으로 되돌릴 수 있음

항목 [4.4 민감 정보 관리](/problems/4/4.4) · 소제목 4.4.6 「분석 도구 통신 제어」

한 분석 도구에는 이름 해석 끄기를 붙이면서 심볼을 스스로 내려받는 다른 도구에는 오프라인 옵션을 붙이지 않는다. 피해는 약하다(커널 식별값과 조사 호스트 주소가 심볼 서버에 남음). 외부 통신이 없다고 README에 적은 서버도 Volatility 3에 오프라인 옵션을 넘기지 않아 심볼 서버에 요청한다(agentic-dfir). 서버가 분석 도구의 이름 해석을 끄더라도 모델이 설정 인자로 다시 켤 수 있어, 캡처 주소마다 PTR 질의가 나가 조사 사실과 시점이 드러난다.
