# P0156 사용자가 켜지 않아도 기본으로 외부에 연결함

항목 [4.4 민감 정보 관리](/problems/4/4.4) · 소제목 4.4.5 「외부 연결 설정과 목적지 제한」

키나 설정이 없어도 외부 조회나 공개 터널이 기본으로 켜져, 평문 HTTP로 지표가 공개 서비스에 가고(mulder), 기본 사이트 전부에 지표가 가며(trudi), 인증 없는 서버가 공개 터널에 열린다(Cyber-Incident-Investigation-and-Triage-MCP-Server). 도구를 처음 쓸 때 없는 프로그램과 파일을 설정 확인 없이 wget으로 내려받고 sudo apt-get install로 분석 호스트에 설치한다(Camel).
