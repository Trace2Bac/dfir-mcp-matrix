# P0148 서버 자격증명을 모델이 실행·읽기로 닿거나 기록·출력에 남는 곳(자식 프로세스 환경, 평문 파일, 예외 문구)에 둠

항목 [4.4 민감 정보 관리](/problems/4/4.4) · 소제목 4.4.3 「서버 자격증명 보관과 사용」

서버가 모델 API 키나 외부 조회 키를 자기 환경에 두고 외부 프로그램을 환경 지정 없이 실행해, 모델이 준 명령을 실행하는 도구가 있으면 그 키가 출력으로 나온다. 사건 폴더 설정 파일이나 서버 설정 파일에 접속 비밀번호를 평문으로 두고, 클라이언트의 파일 읽기 허용이나 스크립트의 호스트 명령으로 그 파일에 닿을 수 있다. 외부 라이브러리가 실패할 때 토큰이 든 명령 목록을 예외 문구로 내고, 서버가 그 문구를 로그와 표준 출력에 그대로 적는다. 조건이 좁다(별도 설치, 실패해야 함).
