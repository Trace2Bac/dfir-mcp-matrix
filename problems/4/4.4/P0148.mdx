# P0148 서버 자격증명의 모델 노출

항목 [4.4 민감 정보 관리](/problems/4/4.4) · 소제목 4.4.3 「서버 자격증명 보관과 전송」

서버의 API 키·접속 비밀번호·서명 비밀을 모델이 닿는 곳(모델이 정한 명령을 실행하는 자식 프로세스 환경, 모델이 읽을 수 있는 평문 파일, 도구 인자, 응답)에 두어, 분석에 필요 없는 서버 비밀이 모델 문맥에 들어갈 수 있다.
