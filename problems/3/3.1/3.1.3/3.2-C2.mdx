# 3.2-C2 없는 호출 기록을 기록 0건으로 처리해 서명하거나 검증을 통과시킴

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 [3.1.3 호출 기록 보관과 변경 확인](/problems/3/3.1/3.1.3)

같은 묶음의 다른 사례는 [3.2.3 파생물 기준값 보관과 대조](/problems/3/3.2/3.2.3/3.2-C2)에 있다.

## 현상과 피해

`audit_log_path`에 없는 파일 경로를 주면 `manifest_finalize`가 오류 없이 기록 0건의 manifest를 만들어 서명하고, 같은 경로에 `audit_verify`는 `ok: true`와 `record_count` 0을 돌려주며, `manifest_verify`만 이를 실패로 본다(verdict-dfir). 없는 기록과 실제로 있는 빈 기록이 같은 결과로 처리된다.

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.

## 문제가 관찰된 서버 (1)

### [verdict-dfir](/problems/servers/verdict-dfir)
