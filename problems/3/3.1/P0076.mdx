# P0076 공통 단계를 두었지만 SDK 입력 검증 뒤나 예외를 그대로 넘기는 자리에 있어 일부 호출이 빠짐

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「기록 적용 범위」

## 현상과 피해

공통 단계에서 기록하는 서버에서도 스키마 검증에서 거부된 호출(Cyber-Incident-Investigation-and-Triage-MCP-Server, verdict-dfir)과 하위 서버 예외, 출력 경로 거부(trudi)가 기록에 없다. 모델은 오류 응답을 받으므로 단독 피해는 중간 이하이지만, 공통 단계를 두는 이유로 게시본이 든 "스키마 검증에서 거부된 호출"이 빠진다.
