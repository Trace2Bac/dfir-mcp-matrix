# P0084 기록 밖 끝 값이 없거나 고정한 키에 묶이지 않아 끝 잘림, 전체 삭제, 재작성이 검증을 통과함

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.5 「기록의 보존과 변경 확인」

## 현상과 피해

체인을 다시 쓴 기록을 다른 키나 같은 서버의 `manifest_finalize`로 다시 봉인하면 검증이 통과한다(verdict-dfir). 없는 경로의 `audit_verify`가 `ok: true, record_count: 0`이다(verdict-dfir). 끝 항목을 지운 목록을 번호로 가를 수 없고 중간 삭제 뒤 번호가 겹친다(mcp_dfir). 인자 없는 초기화가 원장을 비우고 GENESIS부터 다시 유효하다(sift-kernel, 원고 서술).
