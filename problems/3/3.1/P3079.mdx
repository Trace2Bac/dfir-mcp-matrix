# P3079 호출 기록에 받은 인자가 누락되거나 바뀌어 호출을 되짚을 수 없음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 정의

**전제** 호출 기록에 받은 요청의 내용을 적을 때

**결함** 실행 조건을 정하는 인자나 요청자를 빼거나, 받은 값 대신 서버가 고친 값이나 해시와 길이 같은 요약 값으로 적는다.

**피해** 기록대로 다시 보낸 요청이 다른 조건으로 실행되고, 누가 어떤 조건으로 요청했는지 기록만으로 알 수 없게 된다.

**경계** 실제로 실행한 명령 문자열에서 인자 경계가 남지 않는 것과 호출 자체가 기록에 없는 것은 포함하지 않는다.
