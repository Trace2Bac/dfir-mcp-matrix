# P0080 호출 번호나 ID가 한 호출을 가리키지 않아 기록과 결과 본문의 대응이 어긋남

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 현상과 피해

같은 사건 폴더를 쓰는 서버 프로세스 둘이 모두 1번을 받아, A의 `get_command_result(1)`이 B의 결과를 돌려주고 마지막 `command_history.json`에는 A가 실행한 두 명령이 없다(mcp_dfir). 한 호출이 실행기를 여러 번 부르면 실행 항목마다 다른 ID가 붙어 응답의 `execution_id`로 찾을 수 없고, 호출 항목의 명령 문자열은 실제 명령과 다를 수 있다(SAVVYDFIR-MCP).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 문제가 없음을 증명하지 못한 판정이다. 코드 위치가 있으면 그 문제를 찾아 코드를 보았으나 발견하지 못한 것이고, 없으면 근거 대장의 묶음 분모에서 옮겨 아직 이 문제로 코드를 보지 않은 것이다.
