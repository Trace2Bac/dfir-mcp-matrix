# P0080 호출 번호나 ID가 한 호출을 가리키지 않아 기록과 결과 본문의 대응이 어긋남

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.2 「요청과 호출 식별」

## 현상과 피해

같은 사건 폴더를 쓰는 서버 프로세스 둘이 모두 1번을 받아, A의 `get_command_result(1)`이 B의 결과를 돌려주고 마지막 `command_history.json`에는 A가 실행한 두 명령이 없다(mcp_dfir). 한 호출이 실행기를 여러 번 부르면 실행 항목마다 다른 ID가 붙어 응답의 `execution_id`로 찾을 수 없고, 호출 항목의 명령 문자열은 실제 명령과 다를 수 있다(SAVVYDFIR-MCP, 코드. 판정 전 x5를 이 사례의 한 면으로 합침).
