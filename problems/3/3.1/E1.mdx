# E1 해시 체인을 만들지만 읽을 때와 재시작 때 검증하지 않거나 검증 결과를 응답에 다르게 실음

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 「기록의 보존과 변경 확인」

## 현상과 피해

서버가 시작할 때 마지막 줄 해시만 이어 받아, 첫 항목을 고치고 마지막 줄을 지운 기록 뒤에 새 항목이 이어지고 출처 조회가 고친 글을 봉인된 것으로 돌려준다(SAVVYDFIR-MCP). HTML 보고서 응답의 `chain_valid`가 체인이 끊겨도 참이고 같은 호출이 쓴 본문은 `BROKEN`이다(sift-kernel).
