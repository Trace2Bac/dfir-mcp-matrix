# P3192 연쇄 기록 파일에 다른 쓰기를 막지 않아 번호와 해시 연결이 깨짐

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.2 「호출 기록 저장과 실패 처리」

## 정의

**전제** 연쇄 기록의 번호와 이전 해시를 이어 가며 기록 파일에 쓸 때

**결함** 번호와 이전 해시를 이어 가는 동안 다른 프로세스나 서버 저장소가 주는 hook이 같은 파일에 쓰는 것을 막지 않는다.

**피해** 번호와 이전 해시가 겹치거나 연결이 끊겨, 고치지 않은 기록이 검증에서 깨진 것으로 나오고 번호로 호출 순서를 알 수 없게 된다.

**경계** 기록 쓰기 자체가 실패해 연결이 깨지는 것은 포함하지 않는다.
