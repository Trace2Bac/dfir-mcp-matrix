# C1 실행 전 항목만 남거나 결과 칸이 실제 결과와 달라 기록만으로 성공과 실패를 가를 수 없음

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 「결과 기록」

## 현상과 피해

시작 항목만 남아 실패인지 실행 중인지 모른다(SAVVYDFIR-MCP `started`만, CIIT `crack_hash`). 결과 칸에 다른 값이 들어가고 조회 도구가 여러 줄 텍스트 기록을 다섯 건 가운데 한 건만 읽는다(CIIT). 실행하지 않은 명령이 `exit_code` 1로 남는다(mcp_dfir, 약함). 백그라운드 작업을 시작한 순간 `success: true`로 남아 나중에 실패해도 기록은 성공이다(sift-kernel).
