# P3193 서버 도구가 호출 기록을 지우면서 삭제 사실을 기록에 남기지 않음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.4 「호출 기록 보존」

## 정의

**전제** 서버 도구가 호출 기록을 지울 때

**결함** 지운 사실과 지운 범위를 새 기록에 남기지 않거나 응답에 알리지 않는다.

**피해** 앞선 호출이 있었다는 것을 기록만으로 알 수 없게 된다.

**경계** 서버 밖에서 기록 파일이 지워지거나 바뀌는 것은 포함하지 않는다.
