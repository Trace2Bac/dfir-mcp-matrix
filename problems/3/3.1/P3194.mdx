# P3194 기록을 읽다 잃은 항목을 알리지 않아 그 호출이 판정에서 사라짐

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.4 「호출 기록 보존」

## 정의

**전제** 서버가 호출 기록을 읽어 조회, 집계, 판정, 인용 확인에 쓸 때

**결함** 기록을 읽을 때 읽지 못하거나 잘못 나눈 항목을 응답이나 기록에 알리지 않고 잃는다.

**피해** 줄이 깨진 호출이 표시 없이 조회와 판정에서 빠지고, 그 호출을 인용한 발견사항이 까닭을 알 수 없이 거부된다.

**경계** 기록 파일 전체를 읽지 못해 빈 기록으로 보는 것과 변경 확인 값을 검증하지 않는 것은 포함하지 않는다.
