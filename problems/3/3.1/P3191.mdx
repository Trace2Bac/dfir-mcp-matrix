# P3191 호출 기록 시각이 실제 실행 시점과 순서를 나타내지 않음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 정의

**전제** 호출 기록에 시각을 적을 때

**결함** 시각을 시간대나 충분한 정밀도 없이 적거나, 실행한 때가 아닌 다른 때의 시각을 적거나, 시작과 끝을 함께 알 수 있게 남기지 않는다. 시작 시각, 끝난 시각, 걸린 시간 가운데 둘이 있으면 시작과 끝을 알 수 있다.

**피해** 기록만으로 호출이 언제 실행되어 얼마나 걸렸고 어떤 순서였는지 알 수 없게 된다.

**경계** 시각에서 만든 항목 ID가 겹치는 것은 포함하지 않는다.
