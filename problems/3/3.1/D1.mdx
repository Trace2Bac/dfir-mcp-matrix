# D1 기록 쓰기가 실패해도 실행 효과가 남고 기록 누락이 알려지지 않음

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 「기록 쓰기 실패 처리」

## 현상과 피해

기록 쓰기가 실패해도 결과를 그대로 돌려주고 표준 오류에만 남긴다(findevil). 쓰지 못한 항목의 `ledger_entry_id`를 응답에 싣는다(sift-kernel). 기억 저장소 행은 남는데 응답은 실패로만 알린다(verdict-dfir). KAPE 출력은 남는데 응답은 KAPE 실행 실패처럼 알리고, 다음 호출은 기록 함수를 거치지 않고 저장된 결과를 돌려준다(CIIT). 기록만으로는 실제로 수행한 작업을 다시 구성할 수 없다.
