# P3106 명령 인자를 경계 없이 한 문자열로 기록해 인자를 구분할 수 없음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 정의

**전제** 실제로 실행한 명령을 기록하는 서버에서

**결함** 명령과 인자를 경계 표시 없이 공백으로 이은 한 문자열로만 기록한다.

**피해** 공백이 들어간 경로나 빈 문자열 인자의 경계가 남지 않아, 기록으로 실제 실행한 명령을 되짚을 수 없게 된다.

**경계** 명령을 기록하지 않거나 인자를 빼고 적는 것은 포함하지 않는다.
