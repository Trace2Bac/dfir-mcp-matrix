# P0077 서버가 호출을 직접 기록하지 않고 모델이나 정해진 실행 경로의 클라이언트에 맡김

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「기록 적용 범위」

## 현상과 피해

verdict-dfir는 모델이 `audit_append`를 불러야 호출이 기록되고 도구 설명이 모든 호출 뒤에 부르라고 안내한다. agentic-dfir는 서버가 예외가 난 호출만 표준 오류에 쓰고, 연쇄 기록은 정해 둔 도구만 부르는 결정적 모드 클라이언트에만 있으며, live 모드는 대화가 끝난 뒤 한 번 써서 도중 예외면 파일이 없다. 기록이 모델이나 클라이언트가 남기기로 한 요청이 되고, 실제 모델이 조사하는 기본 경로에는 기록이 없다. 두 서버의 README는 모든 호출의 연쇄 기록을 약속한다.
