# 3.1-A2 공통 단계를 두었지만 SDK 입력 검증 뒤나 예외를 그대로 넘기는 자리에 있어 일부 호출이 빠짐

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 [3.1.1 요청과 실행 결과 기록](/problems/3/3.1/3.1.1)

## 현상과 피해

공통 단계에서 기록하는 서버에서도 스키마 검증에서 거부된 호출(CIIT, verdict-dfir)과 하위 서버 예외, 출력 경로 거부(trudi)가 기록에 없다. 모델은 오류 응답을 받으므로 단독 피해는 중간 이하이지만, 공통 단계를 두는 이유로 게시본이 든 "스키마 검증에서 거부된 호출"이 빠진다.

## 문제가 관찰된 서버 (3)

### [Cyber-Incident-Investigation-and-Triage-MCP-Server](/problems/servers/Cyber-Incident-Investigation-and-Triage-MCP-Server)

- 저수준 call_tool이 처리기를 고르기 전에 Tool called 줄을 써 목록에 없는 도구 이름까지 남기지만, MCP Python SDK 1.29.1이 call_tool을 부르기 전에 입력 schema를 검사해 필수 인자가 빠진 kape_parse_artifact 호출은 Input validation error만 돌아가고 줄이 남지 않았다 코드: [server.py:512-533](https://github.com/abhiii011/Cyber-Incident-Investigation-and-Triage-MCP-Server/blob/39e85090231cf0c9b7edcb1700d169372e50d8b1/server.py#L512-L533); MCP Python SDK 1.29.1 [src/mcp/server/lowlevel/server.py:530-538](https://github.com/abhiii011/Cyber-Incident-Investigation-and-Triage-MCP-Server/blob/39e85090231cf0c9b7edcb1700d169372e50d8b1/src/mcp/server/lowlevel/server.py#L530-L538)

### [trudi](/problems/servers/trudi)

- NarrationMiddleware.on_call_tool의 docstring은 모든 호출이 trace 항목을 하나 이상 남긴다고 약속하지만 except ToolError: raise로 넘겨, FastMCP 3.4.7이 mount한 하위 서버의 예외를 ToolError로 바꾼 도구 예외와 @output_safe 출력 경로 거부가 trace에 없다. trace가 열려 있지 않으면 게이트 거부도 남지 않는다 코드: [core/middleware.py:624-631](https://github.com/nebulae/trudi/blob/88fbca78186b6a0ca40423cf5e37a9dc46ae051e/core/middleware.py#L624-L631), [core/middleware.py:676-683](https://github.com/nebulae/trudi/blob/88fbca78186b6a0ca40423cf5e37a9dc46ae051e/core/middleware.py#L676-L683), [core/middleware.py:736-737](https://github.com/nebulae/trudi/blob/88fbca78186b6a0ca40423cf5e37a9dc46ae051e/core/middleware.py#L736-L737); [core/paths.py:136-147](https://github.com/nebulae/trudi/blob/88fbca78186b6a0ca40423cf5e37a9dc46ae051e/core/paths.py#L136-L147)

### [verdict-dfir](/problems/servers/verdict-dfir)

- findevil-agent-mcp는 실패한 호출에 표준 오류 항목을 쓰지만 MCP Python SDK 1.27.0이 스키마 밖 인자를 먼저 거부해 그 호출은 agent_mcp_validation_error 항목 없이 끝났다 코드: [services/agent_mcp/findevil_agent_mcp/server.py:170-198](https://github.com/TimothyVang/verdict-dfir/blob/acada5c6b91545639d5a470ba0d92c0e29e73063/services/agent_mcp/findevil_agent_mcp/server.py#L170-L198); MCP Python SDK 1.27.0 [server.py:521-532](https://github.com/TimothyVang/verdict-dfir/blob/acada5c6b91545639d5a470ba0d92c0e29e73063/server.py#L521-L532)
