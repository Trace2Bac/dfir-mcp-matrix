# 3.1-A4 MCP 밖에서 직접 부른 도구 함수의 실행이 같은 호출 기록에 구별 없이 섞임

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 [3.1.1 요청과 실행 결과 기록](/problems/3/3.1/3.1.1)

## 현상과 피해

findevil의 사용자 CLI가 `assess_coverage`를 직접 부른 실행이 `audit.json`에 섞이고 주체를 가르는 필드가 없다. mulder 오케스트레이터가 도구 함수를 직접 불러 `tool_call` 항목을 남기고 마감 관문이 이 기록으로 판단한다. 기록이 모델의 실제 요청보다 많아진다.

## 해당 기능이 있는 서버 (11)

[Camel](/problems/servers/Camel), [Cyber-Incident-Investigation-and-Triage-MCP-Server](/problems/servers/Cyber-Incident-Investigation-and-Triage-MCP-Server), [findevil](/problems/servers/findevil), [mcp_dfir](/problems/servers/mcp_dfir), [mulder](/problems/servers/mulder), [protocol-siftpp](/problems/servers/protocol-siftpp), [SAVVYDFIR-MCP](/problems/servers/SAVVYDFIR-MCP), [sift-kernel](/problems/servers/sift-kernel), [sift-mcp](/problems/servers/sift-mcp), [trudi](/problems/servers/trudi), [verdict-dfir](/problems/servers/verdict-dfir)

## 문제가 관찰된 서버 (2)

### [findevil](/problems/servers/findevil)

- 기록 함수가 도구 함수 안에 있어 사용자 CLI scripts/investigate.py와 scripts/capture_example_run.py가 assess_coverage를 직접 부른 실행도 audit.json에 항목을 더하고, 항목에 쓴 프로세스를 가르는 필드가 없다 코드: scripts/investigate.py; scripts/capture_example_run.py (매트릭스 L01 각주 [12][13])

### [mulder](/problems/servers/mulder)

- 오케스트레이터가 _tool_dispatch_sync로 check_finalize_readiness 같은 도구 함수를 직접 불러 서버 기록에 tool_call 항목을 남기고, 마감 관문이 이 기록으로 판단한다 코드: [src/mulder/orchestrator/evidence.py:299-300](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/orchestrator/evidence.py#L299-L300), [src/mulder/orchestrator/evidence.py:341-347](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/orchestrator/evidence.py#L341-L347); [src/mulder/server/tools/review.py:293-301](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/review.py#L293-L301)
