# 3.1-B1 입력 인자를 골라 적거나 이름과 값을 바꿔 적어 기록대로 같은 요청을 다시 보낼 수 없음

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 [3.1.1 요청과 실행 결과 기록](/problems/3/3.1/3.1.1)

## 현상과 피해

동작을 바꾸는 인자(mulder `force`, sift-mcp `timeout`)가 빠져 기록대로 다시 보낸 요청이 다른 조건으로 실행된다. 등록 때 준 기준 해시가 기록에 없다(Camel). 값 대신 해시나 길이가 남는다(findevil `text_len`, verdict-dfir `sha256`).

## 해당 기능이 있는 서버 (9)

[Camel](/problems/servers/Camel), [Cyber-Incident-Investigation-and-Triage-MCP-Server](/problems/servers/Cyber-Incident-Investigation-and-Triage-MCP-Server), [findevil](/problems/servers/findevil), [mcp_dfir](/problems/servers/mcp_dfir), [mulder](/problems/servers/mulder), [SAVVYDFIR-MCP](/problems/servers/SAVVYDFIR-MCP), [sift-kernel](/problems/servers/sift-kernel), [sift-mcp](/problems/servers/sift-mcp), [verdict-dfir](/problems/servers/verdict-dfir)

- SetCaseId는 받은 값 대신 앞뒤 공백을 지운 값(빈 값이면 세션 ID)을, SetEvidence는 받은 HashType과 HashValue를 빼고 기록해 모델이 등록하며 준 기준 해시가 기록에 없다.
