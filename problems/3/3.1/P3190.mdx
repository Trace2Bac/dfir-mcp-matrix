# P3190 호출 기록의 입력 해시를 앞서 계산한 값으로 적어 읽은 입력과 어긋남

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 정의

**전제** 호출 기록에 입력의 해시를 적을 때

**결함** 이번 실행이 읽은 내용에서 해시를 구하지 않고 등록이나 앞선 실행 때 계산한 값을 적는다.

**피해** 그 사이 입력이 바뀌었으면 기록이 실제로 읽은 입력과 다른 내용을 가리키고, 입력이 바뀐 사실도 알아채지 못하게 된다.

**경계** 실행 앞뒤에 증거가 바뀌었는지 확인하는 처리 자체의 결함은 포함하지 않는다.
