# P3084 검증 기준을 기록 안에만 두어 일부를 잘라내거나 처음부터 다시 계산한 기록도 검증을 통과함

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.3 「호출 기록 기준값 보관과 대조」

## 정의

**전제** 호출 기록의 변경을 검증하는 기능이 있을 때

**결함** 마지막 항목의 해시, 항목 수, 서명 키 같은 검증 기준을 기록 밖에 고정하지 않고 기록 안의 값만으로 검증한다.

**피해** 기록 일부나 전체를 지우거나, 없는 기록 파일을 주거나, 처음부터 다시 계산해 쓴 기록이 검증을 통과하게 된다.

**경계** 검증을 아예 하지 않는 것과 서버 도구가 스스로 기록을 지우는 것은 포함하지 않는다.
