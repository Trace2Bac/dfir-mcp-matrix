# P3083 기록을 다시 쓸 때 변경 확인 값을 검증하지 않아 바뀐 기록을 그대로 조회하고 이어 씀

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.3 「호출 기록 기준값 보관과 대조」

## 정의

**전제** 호출 기록에 해시 연결 같은 변경 확인 값을 만들 때

**결함** 서버가 기록을 다시 열거나 읽어 조회, 보고, 서명, 이어 쓰기에 쓸 때 그 값을 검증하지 않거나 검증 결과와 다른 값을 응답에 싣는다.

**피해** 고친 기록이 변경되지 않은 것으로 조회되거나 보고되고, 그 위에 새 항목이 이어 쓰이게 된다.

**경계** 검증은 하지만 검증 기준이 기록 안에만 있어 삭제나 다시 쓰기를 알아채지 못하는 것은 포함하지 않는다.
