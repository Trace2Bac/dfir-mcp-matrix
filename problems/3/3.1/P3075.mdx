# P3075 서버가 받은 호출이 호출 기록에서 누락되어 호출을 되짚을 수 없음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 정의

**전제** 서버가 받은 호출을 기록하거나, 서버 저장소가 기록 도구, 클라이언트 코드, 절차 파일 같은 기록 수단을 함께 주는 서버에서

**결함** 서버의 호출 처리 단계가 받은 호출 가운데 일부나 전부, 또는 그 호출 안에서 실행한 명령 가운데 일부를 기록에 남기지 않고, 남기지 않은 호출은 모델이나 클라이언트가 기록하기를 기대한다.

**피해** 거부되거나 실패한 호출과 실제로 실행된 명령이 기록에서 빠져, 기록만으로 모델이 무엇을 요청했고 서버가 무엇을 실행했는지 되짚을 수 없게 된다.

**경계** 시작 항목은 남고 끝난 결과가 없는 것, 기록된 호출의 요청 내용이나 결과 칸이 실제와 다른 것은 포함하지 않는다.
