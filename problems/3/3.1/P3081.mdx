# P3081 호출 기록에 실제 실행 결과가 남지 않아 성공 여부와 실패 이유를 구별할 수 없음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

## 정의

**전제** 호출 기록에 실행 결과를 적을 때

**결함** 실행이 끝난 결과를 적지 않고 시작 항목만 남기거나, 결과 칸을 실제 실행 결과와 다르게 적는다.

**피해** 기록만으로 호출이 성공했는지, 실패했다면 왜 실패했는지 구별할 수 없게 된다.

**경계** 호출 자체가 기록에 없는 것, 결과 칸은 맞으나 실행 출력 일부가 결과 본문에 빠지는 것, 완료 항목이 다른 ID로 남아 시작 항목과 이어지지 않는 것, 기록 조회 도구가 기록을 잘못 나눠 읽는 것은 포함하지 않는다.
