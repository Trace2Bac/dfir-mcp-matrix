# A1 기록을 도구 본문에 두어 기록 코드가 없는 도구와 기록 전에 끝난 호출이 빠짐

원고 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 「기록 적용 범위」

## 현상과 피해

서버가 받은 호출 일부만 기록에 남는다. 기록 코드가 없는 도구(sift-kernel 커널 도구 27개 가운데 25개, SAVVYDFIR-MCP 65개 가운데 22개, mcp_dfir 7개), 기록에 닿기 전에 끝난 거부, 오류, 예외(findevil 증거 폴더 밖 경로와 없는 파일, mulder 관문 거부와 경로 정책 거부, protocol-siftpp pid 거부), 없는 도구 이름(SAVVYDFIR-MCP, mcp_dfir, protocol-siftpp)이 빠진다. 거부된 요청의 반복(sift-kernel `registry` 24번)과 허용 밖 시도가 기록에 없어, 기록만으로 모델의 요청을 따라갈 수 없다. 여섯 서버 모두 문서나 안내가 모든 호출을 기록한다고 적는다(2.1과 함께 싣기). mulder는 응답의 `tool_call_id`가 가리키는 항목이 기록에 없다.
