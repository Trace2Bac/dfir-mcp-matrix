# P0106 실행 명령을 따옴표 없이 이어 적어 입력 증거 경로를 정확히 되찾을 수 없음

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.1 「요청과 실행 결과 기록」

`exec_stream`은 명령과 인자를 따옴표 없이 공백 하나로 이어 `command`에 넣어, 빈 문자열 인자는 공백 두 칸으로만 남고 경로에 공백이 있으면 그 경로와 다른 인자의 경계가 남지 않는다(mcp_dfir). 실행기 결과의 `cmd`도 인자를 공백 하나로 이은 문자열이라 증거 경로에 공백이 있으면 경계가 남지 않고, 서버의 출력 읽기 코드는 나뉜 조각을 실제로 있는 경로가 될 때까지 이어 붙여 경로를 추정한다(trudi).
