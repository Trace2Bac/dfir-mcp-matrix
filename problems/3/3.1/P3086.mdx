# P3086 출력 경로가 호출 기록 파일을 가리켜도 막지 않아 기록이 덮어써짐

항목 [3.1 도구 호출 기록](/problems/3/3.1) · 소제목 3.1.4 「호출 기록 보존」

## 정의

**전제** 서버가 호출 기록이나 상태를 파일로 관리하고, 도구가 받은 경로나 증거 안 이름으로 파생물을 쓸 때

**결함** 파생물을 쓰는 경로가 서버가 관리하는 기록 파일이나 상태 파일을 가리켜도 막지 않는다.

**피해** 그 파일이 파생물 내용으로 바뀌어 앞선 호출의 기록과 상태가 사라진다.

**경계** 기록 위치를 정하는 인자가 파생물을 가리켜 기록이 파생물을 덮어쓰는 것은 포함하지 않는다.
