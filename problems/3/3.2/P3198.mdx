# P3198 나중에 조회할 작업 결과 위치를 메모리에만 두어 결과를 찾지 못함

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.3 「파생물 조회와 재사용」

## 정의

**전제** 서버가 나중에 조회할 작업 ID나 결과 위치를 돌려줄 때

**결함** 작업의 상태와 결과 위치를 서버 프로세스 메모리에만 두어, 다른 연결이나 재시작 뒤의 조회에서 찾지 못한다.

**피해** 이미 끝난 작업의 결과를 찾을 수 없게 되고, 그 결과를 호출과 기록에 연결할 수 없게 된다.

**경계** 조회한 결과가 이번 사건과 입력의 것인지 대조하는 것과 결과가 온전한지 확인하는 것은 포함하지 않는다.
