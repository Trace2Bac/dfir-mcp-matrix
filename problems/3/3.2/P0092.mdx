# P0092 재사용 판정이 폴더나 행, 캐시 항목이 있는지만 보고 파생물이 완성됐는지와 지금 상태를 보지 않음

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.4 「파생물의 재사용」

## 현상과 피해

첫 실행이 실패해 빈 폴더만 남은 뒤 정상 실행 파일로 다시 불러도 `CACHED`(Cyber-Incident-Investigation-and-Triage-MCP-Server, MCP). 재시작으로 사라진 추출 폴더를 기록만 보고 있다고 판단해 안내대로 불러도 `skipped`(mulder, MCP). 다른 도구가 같은 출력 경로에 쓴 뒤 같은 인자로 부르면 응답과 파일 내용이 다름(Wireshark-MCP). 앞 호출의 pid가 이미지 옆 설정 파일에 남아 새 이미지의 결과가 표시 없이 줄어듦(VolPilot, MCP). 같은 이름 ZIP, 앞 CSV, 같은 이름 내보내기 폴더를 이번 결과로 돌려줌(MyIRTeam, Cyber-Incident-Investigation-and-Triage-MCP-Server, SAVVYDFIR-MCP).
