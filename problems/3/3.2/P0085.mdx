# P0085 서버가 정한 쓰기 위치가 증거나 입력 폴더 안이라 출력 위치를 주지 않은 호출도 그곳에 씀

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.1 「파생물의 저장 위치와 이름」

## 현상과 피해

이미지 경로 뒤에 붙인 설정 파일이 이미지 폴더에 생긴다(VolPilot, MCP). 압축 해제 기본값이 증거 폴더다(SAVVYDFIR-MCP). 외부 프로그램의 분석 폴더로 원본 폴더를 넘겨 입력 폴더에 CSV가 생긴다(MyIRTeam, 문서에 밝혀 둔 설계). 내보내기 위치가 출력 폴더 밖 공용 위치(`/tmp/pcap_export/`)가 된다(sift-kernel). 외부 프로그램에 출력 위치를 주지 않아 꺼낸 파일이 그 프로그램의 기본 위치에 쓰이고 서버는 위치를 모른다(mulder `run_binwalk`, 이번에 보완한 판정 전 행).
