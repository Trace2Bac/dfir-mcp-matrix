# P0085 추출 결과를 출력 폴더가 아닌 곳에 쓰거나 위치를 정하지 않음

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.1 「파생물 저장 위치와 이름 결정」

## 현상과 피해

캡처 파일을 마운트한 뒤 `extract_files_from_pcap`을 부르면 내보내기 위치가 출력 폴더가 아니라 `<캡처 파일 경로>/pcap_export/`나 `/tmp/pcap_export/`가 된다(sift-kernel). `run_binwalk`는 `extract=True`일 때 목적지와 작업 폴더 없이 `binwalk -e`를 실행해, 꺼낸 파일의 위치를 서버가 정하지도 검사하지도 않는다(mulder).

## 서버별 판정

모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다. 추정은 문제가 없음을 증명하지 못한 판정이다. 코드 위치가 있으면 그 문제를 찾아 코드를 보았으나 발견하지 못한 것이고, 없으면 근거 대장의 묶음 분모에서 옮겨 아직 이 문제로 코드를 보지 않은 것이다.
