# P0088 이름이 실행이나 입력을 구별하지 않아 다른 실행의 파생물을 알리지 않고 덮어씀

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.1 「파생물 저장 위치와 이름 결정」

같은 도구를 다시 실행하자 첫 실행 기록과 발견사항은 첫 해시를 가리키는데 같은 경로 파일은 바뀌었고 어떤 응답도 알리지 않았다(SAVVYDFIR-MCP). 같은 `-o` 경로의 두 호출이 모두 성공하고 파일이 둘째 호출의 내용으로 바뀌었다(sift-mcp). 다른 폴더의 같은 이름 이미지로 이어 부르자 앞 파생물이 사라졌다(verdict-dfir, Cyber-Incident-Investigation-and-Triage-MCP-Server). 같은 사건 폴더를 쓰는 두 프로세스가 같은 번호를 매겨 결과 본문이 바뀌었다(mcp_dfir). 고정 임시 이름으로 겹친 호출이 실패하고 서버가 만들지 않은 같은 이름 파일을 지웠다(WireMCP). 같은 이름 객체가 1,000개를 넘으면 외부 프로그램이 `(999)` 파일을 덮어쓴다(Wireshark-MCP).
