# P0005 후속 작업이 저장된 생성 자료를 사건이나 증거와 대조하지 않고 고름

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.4 「파생물 조회와 재사용」

현재 사건에서 자료를 찾지 못한 YARA 메모리 검사와 `run_evtx_parser`의 `_find_carved_evtx`가 `cfg.db_dir` 아래를 뒤져, 다른 사건의 덤프를 검사하거나 다른 사건의 `Security.evtx`를 이번 이미지 출처로 적재한다(mulder). 여러 입력이 함께 쓰는 폴더 전체를 읽어, 앞 호스트에서 푼 덤프를 고르거나 다른 증거의 타임라인 저장 파일을 받거나 앞 캡처에서 내보낸 파일의 탐지를 이번 결과에 섞는다(SAVVYDFIR-MCP, agentic-dfir, Wireshark-MCP). 기록의 `tool_call` 항목을 명령 문자열 부분 일치로 모아 PID에 프로세스 이름을 붙이면서 어느 메모리 이미지의 출력인지 보지 않는다(trudi).
