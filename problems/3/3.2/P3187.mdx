# P3187 쌓이는 저장 파일을 앞 내용 확인 없이 다시 써 기록이 실제와 달라짐

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.2 「파생물 생성과 저장 완료 확인」

## 정의

**전제** 서버가 항목이 쌓이는 저장 파일을 읽고 고쳐 다시 쓸 때, 또는 앞 실행이 남긴 저장 파일이나 작업 폴더 위에 새 결과를 만들 때

**결함** 다시 쓸 때 읽기 실패, 쓰기 순서, 다른 프로세스의 변경, 앞서 남은 내용을 고려하지 않는다.

**피해** 앞 항목이 빠지거나 다른 입력과 사건의 항목이 섞여, 남은 기록으로 한 일을 되짚을 수 없고 섞인 항목이 이번 결과로 읽힌다.

**경계** 실패하거나 멈춘 저장이 일부만 담긴 파일을 남기는 것은 포함하지 않는다.
