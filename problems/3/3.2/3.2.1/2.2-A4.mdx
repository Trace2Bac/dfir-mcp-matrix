# 2.2-A4 파일 이름으로 쓸 수 없는 제목을 받아 메모 파일 없이 목록에만 저장함

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 [3.2.1 파생물 저장 위치와 이름 결정](/problems/3/3.2/3.2.1)

같은 묶음의 다른 사례는 [2.2.1 인자 구조와 값 검사](/problems/2/2.2/2.2.1/2.2-A4)에 있다.

## 현상과 피해

`add_analyst_note`에 'PowerShell/WMI persistence'처럼 `/`가 들어간 제목을 주면 메모 파일 쓰기가 `No such file or directory`로 실패하지만, 목록과 `analyst_notes.json`에는 제목이 먼저 들어간다(mcp_dfir).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.

## 문제가 관찰된 서버 (1)

### [mcp_dfir](/problems/servers/mcp_dfir)

- add_analyst_note / note.title: 제목에 'PowerShell/WMI persistence'처럼 /를 넣으면 메모 파일 쓰기가 No such file or directory로 실패하지만 목록과 analyst_notes.json에는 제목이 먼저 들어간다 코드: [mcp_dfir/data_manager.py:75-88](https://github.com/Androsh7/mcp_dfir/blob/305fcadb784f4f3e80cc8f8287b0ea57a007f8a5/mcp_dfir/data_manager.py#L75-L88)(목록 JSON을 먼저 쓰고 f"\{note.title\}.md"로 파일을 씀), :96-99 (약속 [models.py:54-55](https://github.com/Androsh7/mcp_dfir/blob/305fcadb784f4f3e80cc8f8287b0ea57a007f8a5/models.py#L54-L55) title은 메모 제목)
