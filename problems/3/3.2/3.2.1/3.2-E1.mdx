# 3.2-E1 추출 결과를 출력 폴더가 아닌 곳에 쓰거나 위치를 정하지 않음

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 [3.2.1 파생물 저장 위치와 이름 결정](/problems/3/3.2/3.2.1)

## 현상과 피해

캡처 파일을 마운트한 뒤 `extract_files_from_pcap`을 부르면 내보내기 위치가 출력 폴더가 아니라 `<캡처 파일 경로>/pcap_export/`나 `/tmp/pcap_export/`가 된다(sift-kernel). `run_binwalk`는 `extract=True`일 때 목적지와 작업 폴더 없이 `binwalk -e`를 실행해, 꺼낸 파일의 위치를 서버가 정하지도 검사하지도 않는다(mulder).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.

## 문제가 관찰된 서버 (2)

### [mulder](/problems/servers/mulder)

- `run_binwalk extract=True`는 목적지·작업 폴더 없이 `binwalk -e`를 실행해 꺼낸 파일의 위치를 서버가 정하지도 검사하지도 않는다(실제 위치 미확인) 코드: [src/mulder/server/tools/extract/carving.py:641-646](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/extract/carving.py#L641-L646), [src/mulder/server/tools/extract/carving.py:678-688](https://github.com/calebevans/mulder/blob/3164843baf74c7fe69e7121dbd6150f8f77ce660/src/mulder/server/tools/extract/carving.py#L678-L688)
