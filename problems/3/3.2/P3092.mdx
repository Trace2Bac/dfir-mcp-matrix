# P3092 파생물이 있는지만 보고 다시 써 온전하지 않은 결과를 돌려줌

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.3 「파생물 조회와 재사용」

## 정의

**전제** 앞 실행의 파생물이나 캐시를 다시 쓸지 판단할 때

**결함** 그 파생물이 끝까지 만들어졌는지와 만든 뒤 바뀌거나 지워지지 않았는지 확인하지 않는다.

**피해** 실패하거나 끊긴 실행의 결과, 지워지거나 바뀐 파일이 이번 실행의 완성된 결과로 돌아간다.

**경계** 파생물이 어느 사건, 입력, 실행 인자에서 나왔는지 대조하는 것은 포함하지 않는다.
