# P0089 저장이 실패하거나 멈춘 뒤 일부만 담긴 파생물이 완성본과 구별되지 않고 남음

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.2 「파생물 생성과 저장 완료 확인」

외부 도구나 저장이 실패하거나 시간 초과로 멈춰도 쓰다 만 출력 파일을 지우지 않아, 0바이트 파일이나 일부만 담긴 파일이 목적지에 남고 등록부 상태 파일도 중간에 끊긴 채 남는다(Cyber-Incident-Investigation-and-Triage-MCP-Server, agentic-dfir, Wireshark-MCP, VolPilot, sift-mcp). 줄 상한과 시간 제한에서 끊긴 출력이 성공으로 원래 출력 파일에 남고, 저장 파일 복사가 실패하면 가공본만 남으며, 실패한 `Log2TimelineAsync`의 저장 파일에 다시 이어 쓴다(sift-kernel, mulder, Camel). 뒤 단계는 완성 여부를 보지 않아, 등록부에 `extracted` True로 남은 폴더를 다음 호출에서 완료된 사본으로 쓰고, `sift_plaso_psort`는 저장 파일을 그대로 받으며 같은 경로의 재실행은 이미 있다며 거부하고, 워크플로는 사건 수가 0이 아닌지만 본다(Cyber-Incident-Investigation-and-Triage-MCP-Server, agentic-dfir, Camel).
