# P3089 중단된 저장의 파생물을 표시하지 않아 일부만 담긴 결과가 완성본으로 남음

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.2 「파생물 생성과 저장 완료 확인」

## 정의

**전제** 서버나 외부 도구가 파생물을 만들어 저장할 때, 또는 외부 시스템이 만든 결과를 받아 돌려줄 때

**결함** 만들기가 실패하거나 시간 제한과 출력 상한에서 멈춰도 쓰다 만 파생물을 지우거나 일부라고 표시하지 않고, 끝나지 않은 결과를 완성된 것으로 돌려준다.

**피해** 일부만 담긴 파생물이 완성본과 같은 이름, 위치, 상태로 남아 뒤 분석이 빠진 내용을 모른 채 완성된 결과로 쓴다.

**경계** 뒤 호출이 남은 파생물을 다시 쓸지 판단하는 것과 항목이 쌓이는 저장 파일을 다시 쓰며 앞 내용이 사라지거나 섞이는 것은 포함하지 않는다.
