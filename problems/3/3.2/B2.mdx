# B2 저장이 실패하거나 멈춘 뒤 일부만 담긴 파생물이 완성본과 구별되지 않고 남음

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 「저장 완료와 실패한 산출물의 처리」

## 현상과 피해

0바이트 추출본이 등록부에 완료로 남아 다음 호출에서 재사용되고(CIIT), 실패 응답 뒤에도 목적지에 부분 파일이 남으며(Wireshark-MCP, VolPilot, agentic-dfir, 실패 응답이 드러나는 경우는 약함), 상한으로 자른 출력이 파일에 완성본처럼 저장되고(trudi, sift-kernel), 등록부 상태 파일을 고쳐 쓰다 121바이트에서 끊겨 등록부 전체가 사라진다(CIIT).
