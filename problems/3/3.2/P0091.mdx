# P0091 검증 결과가 불완전과 변경, 기준값 없음을 가르지 않거나 기록 시점의 판정을 지금 상태처럼 옮김

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.3 「파생물 기준값과 변경 확인」

## 현상과 피해

기준값이 없는 출처가 있어도 전체 상태가 `all_verified`이고 같은 응답의 `no_hash_count`와 모순된다(mulder). 판정 이유가 기록 뒤 변경과 처음부터 없음을 가르지 않고 보고서가 저장된 판정을 옮긴다(sift-mcp). 없는 기록 경로로 기록 0건의 manifest가 서명되고 `audit_verify`가 통과한다(verdict-dfir).
