# P3085 파생물의 저장 위치를 정해 지키지 않아 아무 곳에나 파생물이 생김

항목 [3.2 파생물 관리](/problems/3/3.2) · 소제목 3.2.1 「파생물 저장 위치와 이름 결정」

## 정의

**전제** 도구가 파일 파생물을 만들어 남길 때

**결함** 파생물의 저장 위치를 서버가 정하지 않거나, 정한 위치 밖의 경로를 받거나 스스로 그 밖에 쓴다.

**피해** 파생물이 증거 폴더, 서버의 현재 폴더, 임의의 경로에 생겨 찾고 관리할 수 없게 되고, 증거 폴더에 생긴 파일은 증거를 바꾼다.

**경계** 서버가 관리하는 기록 파일이 파생물로 덮어쓰이는 것과 같은 이름 때문에 앞 파생물이 바뀌는 것은 포함하지 않는다. 받은 값이 경로를 벗어나 정한 폴더 밖을 가리키는 경로 탐색도 포함하지 않는다.
