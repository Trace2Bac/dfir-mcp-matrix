# E2 받은 출력 위치를 정한 저장 위치로 제한하지 않아 사건 폴더 밖이나 서버가 관리하는 기록에 씀

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 「파생물의 저장 위치와 이름」

## 현상과 피해

`baseline_create`의 `output_file`에 기록 폴더의 `audit.json`을 주면 호출 기록이 기준선 JSON이 된다(findevil). `generate_graph`의 `output_path`로 호출 기록 파일을 가리키면 그래프 HTML이 된다(SAVVYDFIR-MCP). 앞선 호출의 기록이 사라진다.
