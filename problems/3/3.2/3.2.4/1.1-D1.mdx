# 1.1-D1 앞서 만든 결과가 있으면 이번 입력과 대조하지 않고 재사용함

원고 [3.2 파생물 관리](/problems/3/3.2) · 소제목 [3.2.4 파생물 조회와 재사용](/problems/3/3.2/3.2.4)

같은 묶음의 다른 사례는 [1.1.4 실행 환경 연결과 재사용](/problems/1/1.1/1.1.4/1.1-D1)에 있다.

## 현상과 피해

추출 폴더 이름(`_archive_slot`)과 완료 표식 확인(`_extraction_is_complete`)이 압축 파일 경로만 비교해, 다른 사건의 같은 경로 압축이 앞 사건의 추출물을 자기 증거로 받는다(mulder). 출력 폴더에 항목이 있거나 `.export`가 있으면 입력 하이브나 `SRUDB.dat`를 대조하지 않고 분석을 건너뛰어, 뒤 사용자나 뒤 호스트의 결과로 앞의 결과가 보고되거나 저장된다(Cyber-Incident-Investigation-and-Triage-MCP-Server, SAVVYDFIR-MCP). 추출 재사용 판정이 사건 raw 폴더에 파일이 있는지만 보아, 한 사건의 둘째 이미지에 첫째 이미지 추출물을 `reused_from_cache`로 돌려준다(SAVVYDFIR-MCP).

## 해당 기능이 있는 서버 (정하지 않음)

이 문제가 생길 수 있는 서버(분모)는 아직 정하지 않았다.

## 문제가 관찰된 서버 (3)

### [Cyber-Incident-Investigation-and-Triage-MCP-Server](/problems/servers/Cyber-Incident-Investigation-and-Triage-MCP-Server)

- analyze_registry 출력 폴더에 항목이 있으면 입력을 대조하지 않고 CACHED (already analyzed)를 돌려줘, 둘째 사용자 하이브가 분석되지 않고 앞 사용자 결과가 그 사용자 결과로 보고된다. 코드: [handlers/registry_forensics_handler.py:334-340](https://github.com/abhiii011/Cyber-Incident-Investigation-and-Triage-MCP-Server/blob/39e85090231cf0c9b7edcb1700d169372e50d8b1/handlers/registry_forensics_handler.py#L334-L340)

### [mulder](/problems/servers/mulder)

- 추출 폴더 이름(_archive_slot)과 완료 표식 확인(_extraction_is_complete)이 압축 파일 경로만 비교해, 다른 사건의 같은 경로 압축이 앞 사건의 추출물을 자기 증거로 받는다. 코드: [src/mulder/server/tools/case.py:852-861](https://github.com/calebevans/mulder/blob/3a1a317/src/mulder/server/tools/case.py#L852-L861) (3a1a317)

### [SAVVYDFIR-MCP](/problems/servers/SAVVYDFIR-MCP)

- SRUM 내보내기 폴더에 .export가 있으면 입력 SRUDB.dat를 대조하지 않고 내보내기를 건너뛰어, 둘째 호스트 상태에 첫째 호스트의 실행 파일 발견사항이 저장된다. 코드: [sift_mcp/server.py:6908-6914](https://github.com/kismatkunwar89/SAVVYDFIR-MCP/blob/9ac8e47540d4826227ac8957a5c5f4caf4f6c80b/sift_mcp/server.py#L6908-L6914)
- 추출 재사용 판정이 사건 raw 폴더에 파일이 있는지만 봐(주석 "Content-presence only - NOT an evidence fingerprint"), 한 사건의 둘째 이미지에 첫째 이미지 추출물을 reused_from_cache로 돌려준다. 코드: [sift_mcp/server.py:7724-7728](https://github.com/kismatkunwar89/SAVVYDFIR-MCP/blob/9ac8e47540d4826227ac8957a5c5f4caf4f6c80b/sift_mcp/server.py#L7724-L7728)
