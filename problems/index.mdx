# 문제 매트릭스

DFIR MCP 서버 구현 가이드라인의 항목마다, 공개 서버 21개에서 관찰된 문제를 소제목별로 묶어 보여 준다.

- 열은 가이드라인의 장, 칸은 항목(1.1~4.4), 칸 안의 줄은 소제목(1.3.2)이고, 네모 하나가 문제 하나(P0001)다. 색이 진할수록 그 문제가 관찰된 서버가 많다.
- 서버 × 문제 지도는 [첫 화면](/)에 있다.
- 문제 화면에서 서버별 판정과 그 근거(코드, 실행 검증)를 확인한다. 모든 판정은 적힌 커밋 기준이며, 서버의 현재 버전과 다를 수 있다.

항목 이름을 누르면 오른쪽 패널에 그 항목을 열고, 네모를 누르면 그 문제를 연다.
